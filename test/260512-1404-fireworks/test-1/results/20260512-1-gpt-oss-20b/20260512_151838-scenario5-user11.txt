아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
코드의 모든 줄에 한 줄씩 주석을 달아, 각 줄이 무엇을 하는지 설명했습니다.

```python
def quick_sort(arr, low, high):                                         # 리스트 arr에서 low 인덱스부터 high 인덱스까지 정렬하는 재귀 함수
    if low < high:                                                     # low가 high보다 작으면(정렬할 부분이 존재하면) 아래 절차를 진행
        pivot_index = partition(arr, low, high)                        # 파티션 함수를 호출해 피봇의 최종 위치를 얻음
        quick_sort(arr, low, pivot_index - 1)                         # 피봇보다 작은 부분을 재귀적으로 정렬
        quick_sort(arr, pivot_index + 1, high)                        # 피봇보다 큰 부분을 재귀적으로 정렬

def partition(arr, low, high):                                          # 파티션 함수: 피봇을 기준으로 작은/큰 값으로 나누고 피봇의 최종 위치를 반환
    pivot_index = (low + high) // 2                                    # 피봇 인덱스로 중간값을 선택
    pivot_value = arr[pivot_index]                                    # 중간값을 피봇 값으로 저장
    arr[pivot_index], arr[high] = arr[high], arr[pivot_index]         # 피봇을 배열의 마지막 위치로 이동시킴
    store_index = low                                                  # 작은 값을 저장할 위치 인덱스 초기화
    for i in range(low, high):                                         # low부터 high-1까지 순회
        if arr[i] < pivot_value:                                      # 현재 원소가 피봇보다 작으면
            arr[i], arr[store_index] = arr[store_index], arr[i]       # 작은 원소를 앞쪽에 위치시키고 store_index 이동
            store_index += 1                                          # store_index를 한 칸 앞으로 옮김
    arr[store_index], arr[high] = arr[high], arr[store_index]         # 피봇을 올바른 위치(소수점)로 이동
    return store_index                                                # 피봇이 정렬된 위치 반환

# 예시 사용법
if __name__ == "__main__":                                            # 직접 실행 시에만 아래 코드 실행
    data = [34, 7, 23, 32, 5, 62]                                     # 정렬할 데이터 리스트
    quick_sort(data, 0, len(data) - 1)                                # 전체 범위(0~len-1)를 정렬
    print(data)                                                       # 정렬된 결과 출력
```

**설명**  
- `quick_sort` 함수는 재귀적으로 배열을 분할하고 정렬합니다.  
- `partition` 함수는 주어진 구간에서 피봇보다 작은 값들을 앞쪽에 모으고, 피봇을 그 옆에 두어 구간을 두 부분으로 나눕니다.  
- 최종적으로 `quick_sort`는 각 구간을 정렬해서 전체 배열을 오름차순으로 정렬합니다.  

이 코드는 입력 리스트에 대해 인덱스 기반으로 바로 교환을 진행하며, 평균적으로 O(n log n)의 시간복잡도를 가집니다.  
필요에 따라 피봇 선택 방식을 바꾸면 최악의 경우 O(n²)까지 내려갈 수도 있으므로, 실무에서는 중간값을 선택하거나 3-수평균(“median of three”)을 사용합니다.
