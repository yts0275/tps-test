아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
주요 동작을 이해하기 쉽도록 **코드의 각 줄마다** 주석(`#`)을 달아 두었습니다.  
리스트를 전달하면 정렬된 새로운 리스트를 반환합니다.  

```python
def quicksort(arr):
    """
    정렬되지 않은 리스트 arr 을 받아서
    새로운 정렬된 리스트를 반환한다.   # 함수 정의: 입력은 arr, 반환값은 정렬된 리스트
    """
    # 1. 리스트의 길이가 0 또는 1이면 이미 정렬돼 있으니 그대로 반환
    if len(arr) <= 1:
        return arr                    # 반환

    # 2. 피벗(pivot)을 선택 (여기서는 마지막 원소를 사용)
    pivot = arr[-1]                   # 피벗 정하기

    # 3. 피벗보다 작은 값들, 피벗, 피벗보다 큰 값들로 나눠서 두 개의 하위 리스트 만들기
    less_than_pivot = []              # 피벗보다 작은 값들을 모으는 리스트
    greater_than_pivot = []           # 피벗보다 큰 값들을 모으는 리스트
    for x in arr[:-1]:                # 피벗을 제외한 모든 원소 순회
        if x < pivot:                # 원소가 피벗보다 작으면
            less_than_pivot.append(x)  # less 리스트에 추가
        else:                        # 피벗보다 크거나 같으면
            greater_than_pivot.append(x)  # greater 리스트에 추가

    # 4. 재귀적으로 두 하위 리스트를 정렬하고 피벗을 중간에 삽입
    return quicksort(less_than_pivot) + [pivot] + quicksort(greater_than_pivot)
    # 재귀 호출 + 연결: 정렬된 작은 리스트 + 피벗 + 정렬된 큰 리스트
```

### 사용 예시

```python
if __name__ == "__main__":
    unsorted = [3, 6, 8, 10, 1, 2, 1]
    sorted_list = quicksort(unsorted)
    print("정렬 전:", unsorted)        # 정렬 전: [3, 6, 8, 10, 1, 2, 1]
    print("정렬 후:", sorted_list)      # 정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

---

#### 프로세스 요약

1. **기저조건**: 길이가 0 또는 1인 리스트는 그대로 반환.  
2. **피벗 선택**: 간단히 마지막 원소를 피벗으로 지정.  
3. **분할**: 피벗보다 작은 원소와 큰 원소를 각각 별도 리스트에 모음.  
4. **재귀·조합**: 두 부분을 재귀적으로 정렬한 뒤 피벗을 중간에 삽입해 최종 정렬 결과를 반환.  

이 구현은 **시간 복잡도 평균 O(n log n)**, 최악의 경우 O(n²)이며, 퀵소트의 전형적인 재귀적 구현입니다. 실전에서는 피벗 선택 전략(예: 중간값, 랜덤 등)을 바꾸거나 꼬리 재귀 제거 등으로 성능을 개선할 수 있습니다.
