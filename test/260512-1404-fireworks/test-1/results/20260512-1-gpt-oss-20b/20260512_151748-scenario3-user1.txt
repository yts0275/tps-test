아래는 **Python**으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
코드의 각 줄 끝에 한 줄씩 주석을 달아 동작 흐름을 명확히 했습니다.  
실행 결과를 확인하려면 마지막 `if __name__ == "__main__":` 블록을 그대로 두고 실행해 보세요.

```python
def quicksort(arr):  # QuickSort 함수 정의(사용자에게 제공되는 인터페이스)
    return _quicksort(arr, 0, len(arr) - 1)  # 내부 재귀 호출 시작, 전체 구간 지정

def _quicksort(arr, low, high):  # 재귀적으로 구간을 정렬하는 내부 함수
    if low < high:  # 왼쪽 인덱스가 오른쪽 인덱스보다 작을 때만 정렬 진행
        pivot_index = partition(arr, low, high)  # 파티션 수행, 피벗 인덱스 반환
        _quicksort(arr, low, pivot_index - 1)  # 피벗 왼쪽 구간 재귀 정렬
        _quicksort(arr, pivot_index + 1, high)  # 피벗 오른쪽 구간 재귀 정렬
    return arr  # 정렬된 배열 반환

def partition(arr, low, high):  # 피벗 기준으로 배열을 분할하는 함수
    pivot = arr[high]  # 가장 오른쪽 원소를 피벗으로 설정
    i = low - 1  # 작은 원소가 놓일 위치(현재 기준보다 작거나 같은 요소)
    for j in range(low, high):  # 피벗 전까지 모든 인덱스 검사
        if arr[j] <= pivot:  # 현재 원소가 피벗보다 작거나 같으면
            i += 1  # 작은 원소 영역을 확장
            arr[i], arr[j] = arr[j], arr[i]  # i+1 위치와 현재 위치를 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치에 옮김
    return i + 1  # 피벗이 최종적으로 배치된 인덱스 반환

# 테스트 코드
if __name__ == "__main__":  # 직접 실행될 때만 아래 코드 실행
    data = [3, 6, 8, 10, 1, 2, 1]  # 정렬 전 배열
    print("정렬 전:", data)  # 원본 배열 출력
    sorted_data = quicksort(data)  # QuickSort 호출
    print("정렬 후:", sorted_data)  # 정렬된 배열 출력
```

#### 핵심 포인트
- **재귀**를 이용해 구간을 분할(`partition`)한 뒤, 피벗을 기준으로 다시 정렬.
- **in‑place** 방식으로 추가 배열 없이 바로 원본 배열을 정렬 → 메모리 사용량 최소화.
- 평균 시간 복잡도는 `O(n log n)`이지만, 피벗 선택에 따라 최악의 경우 `O(n^2)`이 될 수 있음 (무작위 피벗 선택 시 이를 줄일 수 있음).
