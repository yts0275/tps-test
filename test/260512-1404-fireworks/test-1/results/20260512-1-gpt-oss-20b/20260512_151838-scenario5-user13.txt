아래는 **Python** 으로 구현한 간단한 퀵소트(QuickSort) 알고리즘입니다.  
모든 줄마다 한 줄씩 주석을 달아 이해를 돕도록 하였습니다.

```python
# 퀵소트: 재귀적으로 리스트를 정렬하는 알고리즘
# quick_sort 함수는 리스트와 정렬 범위(low~high)를 인자로 받는다.
def quick_sort(arr, low, high):
    # 기본 케이스: 구간이 0개 또는 1개일 때는 이미 정렬되어 있다.
    if low < high:
        # partition 함수는 pivot(피봇)을 기준으로 두 부분으로 분할하고
        # 피봇의 최종 위치인 idx를 반환한다.
        idx = partition(arr, low, high)
        
        # 피봇보다 작은 부분을 재귀적으로 정렬
        quick_sort(arr, low, idx - 1)
        # 피봇보다 큰 부분을 재귀적으로 정렬
        quick_sort(arr, idx + 1, high)

# partition 함수: 피봇을 정해 왼쪽은 작은 값, 오른쪽은 큰 값이 있도록 리스트를 재배열
def partition(arr, low, high):
    # 피봇은 보통 가장 오른쪽 원소를 선택
    pivot = arr[high]
    # i는 "작은 값들의 끝" 위치를 추적
    i = low - 1
    
    # j를 낮은 값부터 high-1까지 순회하며, 피봇보다 작은 값이 나오면 i를 증가시킨 뒤 교환
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            # 두 요소 교환 (i 위치와 j 위치)
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피봇을 올바른 위치(여러 작은 값 뒤 + 1)에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 최종 피봇 위치 반환
    return i + 1

# 사용 예시
if __name__ == "__main__":
    # 테스트할 배열 정의
    data = [3, 6, 8, 10, 1, 2, 1]
    # 정렬 전 상태 출력
    print("정렬 전:", data)
    # 퀵소트 실행 (전체 범위 사용)
    quick_sort(data, 0, len(data) - 1)
    # 정렬 후 상태 출력
    print("정렬 후:", data)
```

#### 주요 포인트
- **재귀 호출**: 퀵소트는 멱분할(Master Theorem) 구조로, 각 단계에서 피봇 하나를 기준으로 정렬되지 않은 부분을 재귀적으로 품니다.
- **in‑place**: `partition` 단계에서 배열을 직접 재배열하므로 추가 메모리 없이 수행됩니다.
- **피봇 선택**: 여기서는 가장 오른쪽 원소를 피봇으로 사용했습니다. 랜덤 피봇을 선택하면 평균 성능을 더 안정화할 수 있습니다.
