아래는 파이썬으로 구현한 퀵소트(QuickSort) 예시이며, **모든 코드 줄마다** 주석을 달아 두었습니다.  
(주석은 한 줄 끝에 `# 주석내용` 형태로 기재했습니다.)

```python
def quicksort(arr):  # quicksort 함수 정의: 입력 리스트를 정렬하여 반환
    if len(arr) <= 1:  # 리스트 길이가 0또는 1이면 이미 정렬 완료된 상태
        return arr  # 그대로 반환
    pivot = arr[-1]  # 기준값(pivot)으로 리스트 마지막 요소를 선택
    left = []  # pivot 이하의 요소를 넣을 리스트 초기화
    right = []  # pivot 초과의 요소를 넣을 리스트 초기화
    for x in arr[:-1]:  # pivot을 제외한 모든 요소를 순회
        if x <= pivot:  # 요소가 pivot 이하이면
            left.append(x)  # 왼쪽 리스트에 추가
        else:  # 요소가 pivot 초과이면
            right.append(x)  # 오른쪽 리스트에 추가
    # 왼쪽 리스트를 재귀적으로 정렬하고 pivot, 오른쪽 리스트를 이어붙여 반환
    return quicksort(left) + [pivot] + quicksort(right)

if __name__ == "__main__":  # 스크립트가 직접 실행될 때 실행
    data = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예시 리스트
    sorted_data = quicksort(data)  # quicksort 호출
    print(sorted_data)  # 정렬 결과 출력
```

이 코드는 재귀적 분할을 이용한 **분할 정복** 방식으로 동작합니다.  
- `pivot`을 기준으로 `left`와 `right` 두 하위 리스트로 분할하고,  
- 각각을 재귀적으로 정렬한 뒤 `left + [pivot] + right` 구조로 합칩니다.  

주석을 보면 각 줄이 수행하는 역할을 명확히 이해할 수 있으므로, 퀵소트 알고리즘이 어떻게 동작하는지 쉽게 파악할 수 있습니다.
