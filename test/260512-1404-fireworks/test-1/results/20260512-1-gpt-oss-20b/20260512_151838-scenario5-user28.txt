아래는 파이썬으로 구현한 **퀵소트**(QuickSort) 알고리즘이며, **각 줄마다 주석**을 달아 이해를 돕고 있습니다.  
(이전과 마찬가지로 출력을 위해 `if __name__ == "__main__":` 블록을 포함했으므로 바로 실행해 볼 수 있습니다.)

```python
# ---------------------------  퀵소트 구현 ----------------------------------
def quicksort_inplace(arr, low, high):
    # (1) [함수] 주어진 배열(arr)에서 low와 high 인덱스 사이를 정렬합니다.
    if low < high:                           # (2) low가 high보다 작을 때만 재귀 호출합니다.
        pivot_index = partition(arr, low, high)  # (3) 배열을 파티션하고 피벗의 최종 위치 반환
        quicksort_inplace(arr, low, pivot_index - 1)  # (4) 파티션 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_index + 1, high) # (5) 파티션 오른쪽 부분 재귀 정렬

def partition(arr, low, high):
    # (6) [함수] 배열(arr) 중 low~high 범위를 파티션합니다. 마지막 원소를 피벗으로 사용.
    pivot = arr[high]                          # (7) 피벗(선택된 기준값)을 설정
    i = low - 1                                # (8) i는 피벗보다 작은 요소가 놓일 위치를 가리킵니다.
    for j in range(low, high):                 # (9) low부터 high-1까지를 순회
        if arr[j] <= pivot:                    # (10) 현재 원소가 피벗보다 작거나 같으면
            i += 1                             # (11) i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]    # (12) i와 j 위치의 원소를 서로 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # (13) 피벗을 정렬된 위치(백터[i+1])에 삽입
    return i + 1                               # (14) 피벗이 놓인 인덱스를 반환

# ---------------------------   사용 예시   ----------------------------------
if __name__ == "__main__":
    # (15) 정렬되지 않은 배열을 정의
    data = [3, 6, 8, 10, 1, 2, 1]              # (16) 예시 데이터
    # (17) 전체 배열(인덱스 0 ~ len-1)을 퀵소트로 정렬
    quicksort_inplace(data, 0, len(data) - 1)   # (18) 실제 정렬 호출
    # (19) 정렬된 결과 출력
    print(data)                                 # (20) 출력: [1, 1, 2, 3, 6, 8, 10]
```

**해설**  
- `quicksort_inplace` 함수는 재귀를 이용해 현재 파티션 영역을 다시 정렬합니다.  
- `partition` 함수는 피벗을 기준으로 왼쪽은 작거나 같은 값, 오른쪽은 큰 값을 배치합니다.  
- 파티션 이후 피벗은 정렬된 최종 위치에 놓이며, 그 인덱스를 반환해 재귀 호출에서 범위를 지정합니다.  

위 코드 그대로 실행하면 `data`가 정렬된 상태를 확인할 수 있습니다.
