아래는 Python으로 구현한 퀵소트 알고리즘입니다.  
각 줄마다 한국어 주석을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr):                               # 1: quicksort 함수 정의 (입력 리스트 arr 정렬 후 새 리스트 반환)
    if len(arr) <= 1:                             # 2: 리스트가 비었거나 한 개 원소만 있으면 이미 정렬 완료
        return arr                                # 3: 그대로 반환 – 더 이상 정렬 필요 없음
    pivot = arr[-1]                               # 4: 피벗을 리스트의 마지막 원소로 선택
    less = []                                     # 5: 피벗보다 작은 값들을 모을 리스트 initialisation
    greater = []                                  # 6: 피벗보다 큰 값들을 모을 리스트 initialisation
    for x in arr[:-1]:                            # 7: 피벗을 제외한 모든 원소를 순회
        if x < pivot:                             # 8: 현재 원소가 피벗보다 작으면 less 리스트에 추가
            less.append(x)                        # 9: less 리스트에 원소 삽입
        else:                                     # 10: 그렇지 않으면 (x ≥ pivot) greater 리스트에 추가
            greater.append(x)                     # 11: greater 리스트에 원소 삽입
    return quicksort(less) + [pivot] + quicksort(greater)  # 12: 재귀 호출로 정렬한 less, 피벗, 정렬한 greater를 연결
```

**사용 예시**

```python
if __name__ == "__main__":                     # 13: 스크립트가 직접 실행될 때만 아래 코드 실행
    arr = [3, 6, 8, 10, 1, 2, 1]               # 14: 정렬하고자 하는 예시 리스트
    sorted_arr = quicksort(arr)                # 15: quicksort 함수 호출
    print(sorted_arr)                          # 16: 정렬된 결과 출력
```

이 코드는 입력 리스트를 변경하지 않고 **새로운 정렬된 리스트**를 반환합니다.  
필요에 따라 in‑place(제자리) 구현으로 바꿀 수도 있지만, 위 구현은 이해하기 쉽고 각 단계가 명확히 드러납니다.
