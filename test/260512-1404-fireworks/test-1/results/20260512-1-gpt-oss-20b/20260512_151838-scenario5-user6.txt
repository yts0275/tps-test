아래는 **Python**으로 구현한 퀵소트(QuickSort) 입니다.  
이 코드는 **in‑place(원본 리스트 자체를 정렬)** 방식으로 동작하며,  
각 라인마다 한 줄씩 주석을 달아 이해를 돕습니다. (주석은 한 줄 끝에 붙였습니다.)

```python
def quick_sort_inplace(arr, low, high):
    # 1. low가 high보다 작으면 정렬이 필요 없으므로 바로 반환(재귀 종료 조건)
    if low < high:
        # 2. 파티션(분할) 함수 호출하여 피벗의 최종 인덱스를 구함
        pi = partition(arr, low, high)
        # 3. 피벗보다 왼쪽(덜 큰) 절반에 대해 재귀적으로 퀵소트 실행
        quick_sort_inplace(arr, low, pi - 1)
        # 4. 피벗보다 오른쪽(덜 작은) 절반에 대해 재귀적으로 퀵소트 실행
        quick_sort_inplace(arr, pi + 1, high)

def partition(arr, low, high):
    # 5. 파티션 시작: 가장 오른쪽 원소를 피벗으로 지정
    pivot = arr[high]
    # 6. 피벗보다 작은 원소들 앞쪽에 모일 인덱스를 표시 (초기값: low - 1)
    i = low - 1
    # 7. 배열의 low 인덱스부터 high-1 인덱스까지 순회
    for j in range(low, high):
        # 8. 현재 원소가 피벗보다 작으면 i를 증가시키고 해당 원소와 교환
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    # 9. 마지막으로 피벗을 올바른 위치에 교환 (i+1 인덱스)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 10. 피벗이 최종적으로 위치한 인덱스를 반환
    return i + 1

# 사용 예시
if __name__ == "__main__":
    # 11. 정렬할 배열 정의
    arr = [12, 4, 5, 6, 7, 3, 1, 15]
    # 12. 전체 범위 (0부터 len(arr)-1까지)를 전달하여 정렬 시작
    quick_sort_inplace(arr, 0, len(arr) - 1)
    # 13. 정렬이 끝난 배열 출력
    print("정렬된 배열:", arr)
```

### 주요 포인트

- **in‑place 퀵소트**: 원본 배열을 그대로 정렬하므로 추가적인 메모리 사용이 최소화됩니다.  
- **피벗 선택**: 가장 오른쪽 원소를 피벗으로 고정했습니다. (다른 전략(중앙값, 랜덤 등)으로 바꿀 수 있음)  
- **시간복잡도**: 평균적으로 `O(n log n)`, 최악(이미 정렬된 데이터에서 작은 피벗)일 때 `O(n²)`  
- **공간복잡도**: 재귀 호출 스택만 사용 → 평균에서 `O(log n)`, 최악에서 `O(n)`  

각 라인에 한 줄씩 주석을 달았으니 코드의 흐름과 의도를 그대로 따라가시면 이해가 쉬울 거예요!
