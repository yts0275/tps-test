아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드 한 줄 한 줄에 자세한 주석을 달아 이해하기 쉽도록 해 두었습니다.  

```python
def quicksort(arr, low, high):  # quicksort 함수 정의 (배열과 정렬 범위 인덱스 전달)
    """
    재귀적으로 배열을 정렬하는 내부 함수
    :param arr: 정렬할 리스트
    :param low: 정렬 범위의 시작 인덱스
    :param high: 정렬 범위의 끝 인덱스
    """
    if low < high:  # 정렬 범위가 2개 이상의 원소를 가질 때만 실행
        pivot_index = partition(arr, low, high)  # 피벗을 기준으로 분할
        quicksort(arr, low, pivot_index - 1)  # 피벗 왼쪽 부분 재귀 정렬
        quicksort(arr, pivot_index + 1, high)  # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):
    """
    피벗을 기준으로 배열을 두 부분으로 분할하고, 피벗의 최종 위치를 반환
    :param arr: 정렬할 리스트
    :param low: 분할 시작 인덱스
    :param high: 분할 끝 인덱스
    :return: 피벗의 최종 인덱스
    """
    pivot = arr[high]  # 가장 오른쪽 원소를 피벗으로 선택
    i = low - 1  # 피벗보다 작은 원소를 저장할 위치 초기화
    for j in range(low, high):  # 피벗을 제외한 모든 원소를 검사
        if arr[j] <= pivot:  # 현재 원소가 피벗 이하이면
            i += 1  # 작은 원소 영역의 끝 인덱스 증가
            arr[i], arr[j] = arr[j], arr[i]  # i와 j 위치 원소 교환
    # 피벗을 작은 원소 영역 끝에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1  # 피벗의 최종 인덱스 반환


def quicksort_main(arr):
    """
    외부에서 바로 호출할 수 있는 퀵소트 래퍼
    :param arr: 정렬할 리스트 (원본이 수정됨)
    """
    if arr:  # 리스트가 비어 있지 않을 때만 정렬 수행
        quicksort(arr, 0, len(arr) - 1)  # 전체 범위에 대해 재귀 호출
    return arr  # 정렬된 리스트 반환 (원본과 동일한 객체)


# --------------------------------------------------------------
# 아래는 사용 예시입니다. 필요하다면 주석을 끄고 실행하세요.
# --------------------------------------------------------------

if __name__ == "__main__":
    sample = [34, 7, 23, 32, 5, 62]  # 정렬할 예시 배열
    print("정렬 전:", sample)
    sorted_arr = quicksort_main(sample)  # quicksort_main 호출
    print("정렬 후:", sorted_arr)
```

### 주요 포인트
1. **재귀**  
   `quicksort` 함수는 피벗을 기준으로 배열을 두 부분으로 나누고, 각 부분에 대해 같은 과정을 재귀적으로 반복합니다.  
2. **피벗 선택**  
   여기서는 가장 오른쪽 원소를 피벗으로 사용했습니다. 다른 전략(중앙값 선택 등)도 가능합니다.  
3. **제자리 정렬**  
   배열 `arr` 자체를 교환하면서 정렬하기 때문에 추가적인 공간을 거의 사용하지 않습니다.  

필요에 따라 `partition` 전략을 바꾸거나 필요에 따라 최적화(예: 인덱스 범위가 작은 경우 삽입 정렬 사용) 등의 확장이 가능합니다.
