아래는 **Python**으로 구현한 퀵소트(QuickSort) 예시입니다.  
각 줄마다 한 줄씩 주석을 붙여 설명을 달았습니다(한국어 주석).

```python
# quicksort.py
# ① 함수 정의: 정렬할 리스트 arr를 인자로 받는다.
def quicksort(arr):  
    # ② 재귀 종료 조건: 리스트가 0개 혹은 1개면 이미 정렬 완료.
    if len(arr) <= 1:  
        # ③ 정렬된 리스트를 그대로 반환한다.
        return arr  

    # ④ 피벗 선택: 여기서는 마지막 원소를 피벗으로 사용한다.
    pivot = arr[-1]  

    # ⑤ 피벗보다 작거나 같은 원소를 모을 리스트 초기화.
    left = []  
    # ⑥ 피벗보다 큰 원소를 모을 리스트 초기화.
    right = []  

    # ⑦ 피벗을 제외한 원소들을 순회하면서 분할한다.
    for x in arr[:-1]:  
        # ⑧ 피벗보다 작거나 같은 경우 left에 추가.
        if x <= pivot:  
            left.append(x)  
        # ⑨ 피벗보다 큰 경우 right에 추가.
        else:  
            right.append(x)  

    # ⑪ 왼쪽 리스트와 오른쪽 리스트를 재귀적으로 정렬하고,
    #     피벗을 가운데에 두어 최종적으로 합친다.
    return quicksort(left) + [pivot] + quicksort(right)
```

---

### 사용 예시

```python
if __name__ == "__main__":
    # ① 정렬할 원본 리스트
    data = [3, 6, 8, 10, 1, 2, 1]
    # ② quicksort 함수를 호출해 정렬된 리스트를 얻는다.
    sorted_data = quicksort(data)
    # ③ 결과를 출력한다.
    print(sorted_data)   # 출력: [1, 1, 2, 3, 6, 8, 10]
```

이 구현은 **비‑in‑place**(새로운 리스트를 만들어 반환) 방식이며,  
가장 간단하고 직관적인 퀵소트 예시입니다.  
필요에 따라 원본 리스트를 직접 정렬하도록 **in‑place** 버전을 추가로 구현할 수도 있습니다.
