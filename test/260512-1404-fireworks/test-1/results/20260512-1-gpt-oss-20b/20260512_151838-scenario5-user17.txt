아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 입니다.  
코드의 각 줄마다 한 줄씩 주석(한국어)도 달아 두었습니다.  
줄 번호를 표시하지 않고, 주석은 코드 바로 옆에 붙여 readability 한 뒤, 기능을 한 눈에 파악할 수 있도록 했습니다.  

```python
def quicksort(arr):                     # 리스트를 인자로 받아 정렬된 리스트를 반환
    """
    빠른 정렬(QuickSort) 알고리즘을 재귀적으로 구현한 함수
    """
    # 빈 리스트나 하나의 원소만 있는 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:                   # 길이 0 또는 1인 리스트는 정렬이 필요 없음
        return arr

    pivot = arr[len(arr) // 2]          # 중간값을 피벗으로 선택(안정성은 없지만 구현 간단)
    left = []                           # 피벗보다 작은 값들을 임시 저장
    equal = []                          # 피벗과 같은 값들을 저장
    right = []                          # 피벗보다 큰 값들을 저장

    # 리스트를 순회하며 각 요소를 적절한 세 리스트에 배치
    for x in arr:                       # 원본 리스트를 하나씩 확인
        if x < pivot:                  # 피벗보다 작은 경우
            left.append(x)             # left 리스트에 저장
        elif x == pivot:              # 피벗과 같은 경우
            equal.append(x)           # equal 리스트에 저장
        else:                         # 피벗보다 큰 경우
            right.append(x)           # right 리스트에 저장

    # 왼쪽, 중간, 오른쪽을 각각 재귀적으로 정렬 후 합치기
    return quicksort(left) + equal + quicksort(right)
```

### 사용 예시

```python
# 정렬할 예시 리스트
data = [3, 6, 8, 10, 1, 2, 1]

# 퀵소트 수행
sorted_data = quicksort(data)

print(sorted_data)  # 출력: [1, 1, 2, 3, 6, 8, 10]
```

**주요 포인트**

- **피벗 선택**: 중간값(`arr[len(arr) // 2]`)을 사용했으나, 평균값 또는 랜덤값을 활용하면 최악의 경우가 줄어듭니다.
- **재귀 종료 조건**: 리스트의 길이가 0 혹은 1일 때 재귀를 멈춤으로써 무한 재귀를 방지합니다.
- **공간 복잡도**: 파이썬 리스트를 복제해 사용하기 때문에 `O(n)`의 추가 공간이 필요합니다.  
  인플레이스(in-place) 버전을 만들려면 퀴즈를 수행하지 않는 변형을 참조하면 됩니다.
