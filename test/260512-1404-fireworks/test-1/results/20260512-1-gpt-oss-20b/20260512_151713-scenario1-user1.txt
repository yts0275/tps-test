아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
코드의 각 줄마다 바로 옆(또는 바로 위)에 한글 주석을 달아 설명했습니다.

```python
def quicksort(arr):  # 빠른 정렬(quick sort) 함수 선언
    if len(arr) <= 1:  # 배열의 길이가 1 이하이면 더 이상 분할할 필요가 없으므로 그대로 반환
        return arr
    pivot = arr[-1]  # 피벗(pivot)으로 배열의 마지막 요소를 선택
    left = [x for x in arr[:-1] if x <= pivot]  # 피벗보다 작거나 같은 원소들만 모아 left 서브배열 생성
    right = [x for x in arr[:-1] if x > pivot]  # 피벗보다 큰 원소들만 모아 right 서브배열 생성
    return quicksort(left) + [pivot] + quicksort(right)  # 재귀 호출로 left와 right를 정렬한 뒤 피벗과 합침

arr = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예시 배열
print(quicksort(arr))  # 정렬 결과를 출력
```

**주요 동작 방식**
1. 피벗을 가장 오른쪽 원소로 잡습니다.  
2. 피벗보다 작거나 같은 것과 큰 것을 두 개의 서브 배열로 분리합니다.  
3. 각각의 서브 배열에 대해 같은 작업을 재귀적으로 반복합니다.  
4. 최종적으로 정렬된 왼쪽 배열 + 피벗 + 정렬된 오른쪽 배열을 합쳐 결과를 반환합니다.  

이렇게 하면 평균적으로 평균 시간복잡도 **O(n log n)** 으로 배열을 정렬할 수 있습니다.
