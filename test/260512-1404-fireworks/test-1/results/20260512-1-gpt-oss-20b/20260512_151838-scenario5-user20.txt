아래는 **파이썬**으로 구현한 퀵소트(QuickSort) 예시입니다.  
각 줄마다 주석을 달아서 코드가 수행하는 일을 설명했습니다.  

```python
def quicksort(arr):                           # quicksort 함수 정의: 입력된 리스트를 정렬해 반환한다
    if len(arr) <= 1:                         # 리스트 길이가 1 이하이면 이미 정렬된 상태라 그대로 반환
        return arr                            # 작은 리스트(0 또는 1개)는 재귀를 끊고 그대로 돌려준다
    pivot = arr[len(arr) // 2]                # 중앙값을 피벗(pivot)으로 선택 (배열의 중앙 원소 사용)
    left = [x for x in arr if x < pivot]      # 피벗보다 작은 원소들만 모아 새로운 리스트 left 생성
    middle = [x for x in arr if x == pivot]   # 피벗과 같은 값들만 모아 새로운 리스트 middle 생성
    right = [x for x in arr if x > pivot]     # 피벗보다 큰 원소들만 모아 새로운 리스트 right 생성
    return quicksort(left) + middle + quicksort(right)   # 재귀적으로 정렬된 left와 right를 합치고 중간값 리스트를 붙여 반환
    

# 사용 예시 --------------------------------------------------------------
example = [3, 6, 8, 10, 1, 2, 1]             # 정렬할 원시 리스트
sorted_list = quicksort(example)              # quicksort 함수 호출
print("원본:", example)                      # 원본 리스트 출력(정렬되진 않는다)
print("정렬:", sorted_list)                  # 정렬된 결과 출력
```

#### 주요 포인트
1. **재귀적 분할**  
   - 재귀 함수 `quicksort`가 리스트를 세 부분(`left`, `middle`, `right`)으로 분리하고,  
   - `left`와 `right`를 다시 재귀 호출로 정렬한다.

2. **피벗 선택**  
   - 중앙값(`len(arr) // 2`)을 피벗으로 고정하면 평균적인 성능을 보장하지만,  
   - 최악의 경우(이미 정렬된 입력)에는 O(n²)의 성능이 될 수 있다.  
   - 더 복잡한 피벗 선택 로직(랜덤, median-of-three 등)은 성능을 향상시킬 수 있다.

3. **불변성**  
   - 함수는 원본 리스트를 변경하지 않고 새 리스트를 만들어 반환한다.  
   - 이는 호출자에서 원본을 그대로 사용하고 싶을 때 유용하지만, 메모리 사용량이 늘어난다.

필요에 따라 **in-place(제자리) 퀵소트** 버전을 구현하거나,  
피벗 선택 방식을 바꾸어 성능을 개선할 수 있습니다.
