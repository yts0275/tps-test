아래는 **파이썬**으로 구현한 퀵소트(quick sort) 예시입니다.  
코드의 각 라인마다 `#` 주석을 달아 그 역할을 명시해 두었습니다.

```python
# quicksort.py
#------------------------------------------------------------------
def quicksort(arr):
    # 재귀 종료 조건: 요소가 0개 또는 1개인 경우 이미 정렬 완료라 그대로 반환
    if len(arr) <= 1:
        return arr
    # 피벗(pivot) 선택: 이 예시에서는 배열 중간값을 기준으로 삼음
    pivot = arr[len(arr)//2]
    # 피벗보다 작은 값들로만 이루어진 리스트 생성
    left = [x for x in arr if x < pivot]
    # 피벗과 같은 값들로만 이루어진 리스트 생성
    middle = [x for x in arr if x == pivot]
    # 피벗보다 큰 값들로만 이루어진 리스트 생성
    right = [x for x in arr if x > pivot]
    # 왼쪽, 중앙, 오른쪽을 재귀적으로 정렬 후 합쳐서 완전한 정렬된 리스트 반환
    return quicksort(left) + middle + quicksort(right)

#------------------------------------------------------------------
if __name__ == "__main__":
    # 테스트용 입력 리스트
    data = [3, 6, 8, 10, 1, 2, 1]
    # quicksort 함수 호출로 정렬 수행
    sorted_data = quicksort(data)
    # 정렬 결과 출력
    print("정렬 전:", data)
    print("정렬 후:", sorted_data)
```

#### 실행 예시
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

모든 라인에 주석을 달았으니, 해당 라인이 어떤 역할을 하는지 바로 파악할 수 있습니다. 필요에 따라 피벗 선택 방법을 바꾸거나, 인-플레이스(In‑place) 버전으로 변형해 보시길 바랍니다.
