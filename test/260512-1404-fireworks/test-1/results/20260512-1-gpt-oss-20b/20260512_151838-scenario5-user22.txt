아래 예시는 **Python 3**로 작성한 퀵소트(Quick Sort) 구현 예시입니다.  
각 줄 끝에 `#` 뒤에 주석을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr):  # 1️⃣ 함수 정의: 리스트 arr를 정렬된 리스트로 반환
    if len(arr) <= 1:  # 2️⃣ 리스트 길이가 1 이하이면 이미 정렬 완료
        return arr      # 3️⃣ 정렬이 끝난 리스트 그대로 반환

    pivot = arr[len(arr)//2]  # 4️⃣ 중간 요소를 피벗(pivot)으로 선택

    left = [x for x in arr if x < pivot]   # 5️⃣ 피벗보다 작은 값들만 모음
    middle = [x for x in arr if x == pivot]  # 6️⃣ 피벗과 같은 값들 (중복 처리)
    right = [x for x in arr if x > pivot]   # 7️⃣ 피벗보다 큰 값들만 모음

    # 8️⃣ 왼쪽, 중간, 오른쪽 리스트를 재귀적으로 정렬 후 합쳐서 반환
    return quicksort(left) + middle + quicksort(right)
```

#### 사용 예시
```python
if __name__ == "__main__":           # 9️⃣ 메인 블록: 직접 실행될 때만 동작
    sample = [3, 6, 8, 10, 1, 2, 1]  # 10️⃣ 정렬하고 싶은 예시 리스트
    print(quicksort(sample))         # 11️⃣ 정렬 결과 출력
```

이 코드는 **재귀 호출**과 **정렬 기준에 따라 리스트를 세 부분(작은값, 같은값, 큰값)** 으로 나누어 다시 정렬한 뒤, 결과를 합치는 방식으로 동작합니다.  
실행 시 `sample` 리스트가 `[1, 1, 2, 3, 6, 8, 10]` 으로 정렬되는 것을 확인할 수 있습니다.
