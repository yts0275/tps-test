아래는 Python으로 구현한 **퀵소트(QuickSort)** 알고리즘 예시입니다.  
코드의 **각 줄마다** 한 줄 주석을 달아 이해를 돕도록 하였습니다.

```python
# QuickSort 알고리즘을 비공간적으로(재귀적으로) 구현한 예시

# 재귀적으로 배열을 정렬하는 메인 함수
def quicksort(arr, low, high):  # quicksort: 재귀 호출로 배열 부분을 정렬
    if low < high:  # 기반 조건: 정렬해야 할 범위가 하나 이상의 요소를 포함할 때
        pi = partition(arr, low, high)  # 피벗을 기준으로 배열을 나눠 피벗 인덱스를 반환
        quicksort(arr, low, pi - 1)  # 피벗 왼쪽 부분 재귀 정렬
        quicksort(arr, pi + 1, high)  # 피벗 오른쪽 부분 재귀 정렬

# 피벗 기준으로 배열을 분할하고 피벗 위치를 반환하는 함수
def partition(arr, low, high):  # 배열을 피벗을 기준으로 재배열
    pivot = arr[high]  # 가장 오른쪽 요소를 피벗으로 선택
    i = low - 1  # 피벗보다 작은 요소의 최종 인덱스를 나타냄
    for j in range(low, high):  # low 부터 high-1 까지 순회
        if arr[j] <= pivot:  # 현재 요소가 피벗보다 작거나 같으면
            i += 1  # i를 한 칸 이동
            arr[i], arr[j] = arr[j], arr[i]  # arr[i]와 arr[j]를 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치에 놓음
    return i + 1  # 피벗이 정렬된 최종 인덱스를 반환

# 외부에서 호출할 수 있도록 배열 전체를 정렬하는 래퍼 함수
def quick_sort(arr):  # 사용자가 간단히 호출할 수 있도록 래퍼 제공
    if arr:  # 배열이 비어있지 않은 경우에만 정렬 시도
        quicksort(arr, 0, len(arr) - 1)  # 전체 범위에 대해 재귀 정렬 호출
    return arr  # 정렬된 배열 반환

# --------------------- 사용 예시 ---------------------

if __name__ == "__main__":  # 스크립트가 직접 실행될 때 실행되는 부분
    numbers = [64, 34, 25, 12, 22, 11, 90]  # 정렬할 데이터
    print("원본 배열:", numbers)  # 정렬 전 배열 표시
    sorted_numbers = quick_sort(numbers.copy())  # deepcopy로 원본 보존 후 정렬
    print("정렬된 배열:", sorted_numbers)  # 정렬 후 결과 표시
```

### 코드 동작 흐름
1. `quick_sort`가 호출되면 `quicksort`를 정점부터 끝까지 재귀적으로 호출합니다.  
2. `partition`은 피벗(여기서는 마지막 원소)을 기준으로 배열을 두 부분(피벗보다 작은/큰)으로 나누고 피벗이 올바른 위치(정렬이 끝난 위치)를 반환합니다.  
3. `quicksort`는 피벗의 좌우 부분(피벗을 제외한)을 재귀적으로 같은 과정으로 정렬합니다.  

이렇게 하면 평균적으로 **O(n log n)**의 시간 복잡도를 갖는 정렬이 수행됩니다.  
ℹ️ **주의**: 심각히 역순 배열이 주어지는 경우, 재귀 깊이가 O(n)이고 최악의 **O(n²)** 성능을 보입니다. `random.shuffle` 등을 이용해 피벗을 무작위 선택하거나, 3번째(중간)을 피벗으로 선택하면 성능 저하를 방지할 수 있습니다.
