아래는 **Python**으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
주석은 **각 코드 줄 바로 뒤에** 달아, 무엇을 하는 줄인지 한눈에 알 수 있도록 했습니다.

```python
def quicksort(arr):                      # 1) 정렬할 리스트를 입력받는 함수 정의
    if len(arr) <= 1:                    # 2) 정렬할 항목이 0개 혹은 1개 이하이면 그대로 반환
        return arr                       # 3) 이미 정렬된 상태이므로 그대로 돌려준다

    pivot = arr[len(arr) // 2]           # 4) 가운데 원소를 피봈(pivot)으로 선정
    left = []                            # 5) 피봈보다 작은 값들을 모을 리스트 초기화
    middle = []                          # 6) 피봈과 같은 값을 모을 리스트 초기화
    right = []                           # 7) 피봈보다 큰 값들을 모을 리스트 초기화

    for x in arr:                        # 8) 입력 리스트의 모든 항목에 대해 반복
        if x < pivot:                    # 9) 현재 값이 피봈보다 작으면
            left.append(x)               # 10) left 리스트에 추가
        elif x == pivot:                 # 11) 현재 값이 피봈과 같으면
            middle.append(x)             # 12) middle 리스트에 추가
        else:                            # 13) 현재 값이 피봈보다 크면
            right.append(x)              # 14) right 리스트에 추가

    # 재귀적으로 정렬한 후 이어붙여 반환
    return quicksort(left) + middle + quicksort(right)   # 15) left와 right를 재귀적으로 정렬하고 연결

# ------------------------ 사용 예시 ------------------------
if __name__ == "__main__":              # 16) 스크립트가 직접 실행될 때만 아래 코드를 동작하도록 함
    arr = [5, 3, 8, 4, 2, 7, 1, 10]     # 17) 정렬할 예시 리스트 선언
    print("원본 리스트:", arr)           # 18) 원본 리스트 출력
    sorted_arr = quicksort(arr)          # 19) 퀵소트를 이용해 정렬
    print("정렬된 리스트:", sorted_arr)  # 20) 정렬된 결과 출력
```

### 주요 포인트
- **피봈 선택**: 가운데 원소를 피봈으로 사용했지만, 실제 구현에서는 무작위 피봈, 첫 번째 원소, 마지막 원소 등 다양한 전략이 있다.
- **재귀**: 자식 리스트(`left`, `right`)를 재귀적으로 정렬함으로써 전체 리스트가 정렬된다.
- **중복 허용**: 피봈과 같은 값은 `middle` 리스트에 별도로 모으므로, 정수/문자열 등 중복이 있는 경우에도 안정적으로 동작한다.

이 예시는 가장 단순하고 가독성이 높은 구현이지만, 대용량 데이터에 대해선 메모리 사용량이 많아질 수 있습니다. 상황에 따라 추가 최적화(배열 기입 변화, 인프레시버, 병합, 버블 정렬 등)를 고려해 보세요.
