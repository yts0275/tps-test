아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 예시입니다.  
코드의 각 줄마다 한 줄 주석을 달아 이해를 돕도록 하였습니다.  

```python
def quicksort(arr):                     # 리스트를 매개변수로 받아 정렬 결과를 반환하는 함수
    if len(arr) <= 1:                   # 리스트가 공백이거나 하나의 원소만 있을 때는 이미 정렬 완료
        return arr                      # 그대로 반환
    pivot = arr[-1]                     # 피벗으로 리스트의 마지막 원소를 선택
    left = [x for x in arr[:-1] if x <= pivot]   # 피벗보다 작거나 같은 원소들을 왼쪽 리스트에 저장
    right = [x for x in arr[:-1] if x > pivot]  # 피벗보다 큰 원소들을 오른쪽 리스트에 저장
    return quicksort(left) + [pivot] + quicksort(right)  # 왼쪽 부분 정렬 + 피벗 + 오른쪽 부분 정렬을 합침
```

#### 예시 실행

```python
if __name__ == "__main__":                 # 스크립트가 직접 실행될 때만 아래 코드 실행
    nums = [3, 6, 1, 8, 4, 5]              # 정렬할 숫자 리스트
    sorted_nums = quicksort(nums)          # 퀵소트 호출
    print("정렬 전:", nums)                # 원본 리스트 출력
    print("정렬 후:", sorted_nums)        # 정렬된 결과 출력
```

**출력:**
```
정렬 전: [3, 6, 1, 8, 4, 5]
정렬 후: [1, 3, 4, 5, 6, 8]
```

> **참고**  
> *에라토스테네스 체 같은 다른 정렬 알고리즘과 비교하면 퀵소트는 평균 **O(n log n)** 성능을 보이지만, 최악의 경우 **O(n²)** 가 됩니다.  
> *위 구현은 부피를 절약(모듈화)하기 위해 리턴값으로 새 리스트를 반환합니다.  
> *인‑플레이스(원본 배열 자체를 바꾸는) 버전이 필요하면 `partition` 함수를 별도로 구현해 주어진 배열을 직접 수정하도록 하면 됩니다.
