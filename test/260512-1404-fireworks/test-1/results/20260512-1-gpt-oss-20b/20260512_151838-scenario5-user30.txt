아래는 파이썬으로 구현한 퀵소트(quick‑sort) 예시입니다.  
**각 줄에 끝에 주석을 달아 이해를 돕도록 구성했습니다.**

```python
def quicksort(a):                                 # 1. 리스트 a를 입력받아 정렬된 리스트 반환
    if len(a) <= 1:                               # 2. 리스트 길이가 0 또는 1이면 이미 정렬 완료
        return a                                  # 3. 그대로 반환
    pivot = a[len(a)//2]                          # 4. 중앙 요소를 피벗으로 선택(가장 큰 경우 발생 방지)
    lows = [x for x in a if x < pivot]           # 5. 피벗보다 작은 모든 요소를 모음
    pivots = [x for x in a if x == pivot]       # 6. 피벗과 같은 값을 가진 모든 요소 (중복 처리용)
    highs = [x for x in a if x > pivot]          # 7. 피벗보다 큰 모든 요소를 모음
    return quicksort(lows) + pivots + quicksort(highs)  # 8. 재귀적으로 정렬 후 합쳐 최종 정렬 반환

# 아래는 사용 예시이며 테스트용 코드입니다.
if __name__ == "__main__":                        # 9. 모듈이 직접 실행될 때만 아래 코드 실행
    arr = [3, 6, 8, 10, 1, 2, 1]                  #10. 테스트할 정렬할 리스트
    print("Original:", arr)                       #11. 원본 출력
    print("Sorted:", quicksort(arr))              #12. 정렬 후 결과 출력
```

> **설명**  
> - `quicksort` 함수는 재귀적으로 작동합니다.  
> - 피벗으로 중앙값을 사용해 데이터가 이미 정렬돼 있을 때의 최악 성능(Θ(N²))을 어느 정도 완화합니다.  
> - `lows`, `pivots`, `highs` 목록을 만들면, 좌우 부분이 완전히 정렬된 후 피벗과 같은 값들을 포함해 하나의 정렬된 배열을 완성합니다.  

필요에 따라 `pivot` 선택 방식을 바꾸거나, 인-place(재귀를 직접 사용하지 않는) 버전을 구현할 수도 있습니다.
