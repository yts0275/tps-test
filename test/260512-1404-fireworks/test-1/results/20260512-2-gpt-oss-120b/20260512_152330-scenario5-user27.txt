아래는 파이썬(Python)으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 어떻게 동작하는지 상세히 설명하는 주석을 달아두었습니다.  

```python
# 퀵소트 알고리즘 구현
def quick_sort(arr):
    # 배열이 비어있거나 원소가 하나이면 그대로 반환 (재귀 종료 조건)
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 요소들을 담을 리스트
    less = []
    # 피벗과 같은 요소들을 담을 리스트 (피벗 자체도 여기 포함)
    equal = []
    # 피벗보다 큰 요소들을 담을 리스트
    greater = []

    # 배열의 모든 요소를 순회하면서 세 개의 리스트에 분류
    for x in arr:
        if x < pivot:          # 현재 요소가 피벗보다 작으면
            less.append(x)     # less 리스트에 추가
        elif x == pivot:       # 현재 요소가 피벗과 같으면
            equal.append(x)    # equal 리스트에 추가
        else:                  # 현재 요소가 피벗보다 크면
            greater.append(x)  # greater 리스트에 추가

    # 재귀적으로 less와 greater 부분을 정렬하고, 
    # 정렬된 less + equal + 정렬된 greater 를 이어 붙여 반환
    return quick_sort(less) + equal + quick_sort(greater)


# ------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트를 호출하여 정렬된 리스트를 받음
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기본 종료 조건** – 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환합니다.  
2. **피벗 선택** – 여기서는 가장 오른쪽에 있는 요소(`arr[-1]`)를 피벗으로 잡았습니다.  
3. **분할 단계** – 리스트 전체를 순회하면서 각 요소를 `less`, `equal`, `greater` 세 그룹으로 나눕니다.  
4. **재귀 호출** – `less`와 `greater` 부분에 대해 각각 다시 `quick_sort`를 호출해 정렬합니다.  
5. **합치기** – 정렬된 `less`, 피벗이 포함된 `equal`, 정렬된 `greater`를 차례대로 이어 붙여 최종 정렬 결과를 만든 뒤 반환합니다.  

이 구현은 **안정적인(stable) 정렬**은 아니지만, 퀵소트의 핵심 아이디어인 **분할‑정복**을 명확히 보여줍니다. 필요에 따라 피벗 선택 전략(예: 무작위 선택, 중앙값 선택 등)을 바꾸면 평균 성능을 더욱 향상시킬 수 있습니다.
