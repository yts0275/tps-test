아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 입니다.  
코드의 **각 줄마다 한국어 주석**을 달아 두었으니, 흐름을 따라가면서 이해하시면 됩니다.

```python
def quick_sort(arr):                     # quick_sort 함수 정의, 정렬할 리스트를 매개변수로 받는다
    if len(arr) <= 1:                    # 리스트 길이가 1 이하이면(빈 리스트·단일 원소) 정렬이 필요 없다
        return arr                        # 그대로 반환한다

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택: 리스트 중간 원소를 기준으로 잡는다
    left = []                            # 피벗보다 작은 원소를 저장할 리스트 초기화
    middle = []                          # 피벗과 같은 원소를 저장할 리스트 초기화
    right = []                           # 피벗보다 큰 원소를 저장할 리스트 초기화

    for x in arr:                        # 입력 리스트 전체를 순회한다
        if x < pivot:                     # 현재 원소가 피벗보다 작으면
            left.append(x)                # left 리스트에 추가한다
        elif x == pivot:                  # 현재 원소가 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가한다
        else:                             # 현재 원소가 피벗보다 크면
            right.append(x)               # right 리스트에 추가한다

    # 재귀 호출을 통해 left, right 부분을 각각 정렬한다
    sorted_left = quick_sort(left)        # left 부분을 정렬하고 결과를 sorted_left에 저장
    sorted_right = quick_sort(right)      # right 부분을 정렬하고 결과를 sorted_right에 저장

    # 정렬된 left + middle(pivot) + 정렬된 right 를 이어 붙여 최종 결과를 만든다
    return sorted_left + middle + sorted_right   # 최종 정렬된 리스트 반환


# ------------------- 사용 예시 -------------------
if __name__ == "__main__":                # 이 파일이 직접 실행될 때만 실행되는 블록
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]   # 정렬되지 않은 샘플 리스트
    print("Original :", unsorted)               # 원본 리스트 출력
    sorted_arr = quick_sort(unsorted)            # quick_sort 함수 호출
    print("Sorted   :", sorted_arr)              # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 바로 반환.  
2. **피벗 선택** – 가운데 원소를 피벗으로 잡아 `left`, `middle`, `right` 세 구간으로 분리.  
3. **재귀 호출** – `left`와 `right` 구간을 각각 다시 `quick_sort` 로 정렬.  
4. **합치기** – `sorted_left + middle + sorted_right` 순서대로 이어 붙여 최종 정렬된 리스트를 만든다.

> **주의**  
> - 파이썬 내장 `list.sort()` 나 `sorted()` 와 달리, 이 구현은 **새로운 리스트를 계속 생성**하므로 메모리 사용량이 크게 늘어날 수 있습니다.  
> - 실제 대용량 데이터를 다룰 때는 제자리(in‑place) 퀵소트나 다른 정렬 알고리즘을 고려하는 것이 좋습니다.
