아래는 파이썬으로 구현한 **퀵소트** 코드이며, 각 줄마다 자세히 설명하는 주석을 달아 두었습니다.  

```python
def quicksort(arr):                         # quicksort 함수 정의, 정렬할 리스트 arr을 매개변수로 받음
    if len(arr) <= 1:                       # 리스트 길이가 1 이하이면(빈 리스트 또는 원소 하나) 이미 정렬된 상태
        return arr                           # 그대로 반환하고 재귀 호출을 종료
    pivot = arr[-1]                          # 피벗(pivot)으로 리스트의 마지막 원소를 선택
    less = []                                # 피벗보다 작거나 같은 원소들을 저장할 빈 리스트 초기화
    greater = []                             # 피벗보다 큰 원소들을 저장할 빈 리스트 초기화
    for x in arr[:-1]:                       # 피벗을 제외한 나머지 원소들을 하나씩 순회
        if x <= pivot:                       # 현재 원소 x가 피벗보다 작거나 같으면
            less.append(x)                   # less 리스트에 추가
        else:                                # 현재 원소 x가 피벗보다 크면
            greater.append(x)                # greater 리스트에 추가
    sorted_less = quicksort(less)            # less 리스트에 대해 재귀적으로 quicksort 실행 → 정렬된 리스트 반환
    sorted_greater = quicksort(greater)      # greater 리스트에 대해 재귀적으로 quicksort 실행 → 정렬된 리스트 반환
    return sorted_less + [pivot] + sorted_greater  # 정렬된 less, 피벗, 정렬된 greater를 차례대로 합쳐 최종 결과 반환
```

### 사용 예시
```python
if __name__ == "__main__":                     # 스크립트를 직접 실행할 때만 실행되는 블록
    unsorted = [33, 10, 55, 71, 29, 2, 18]      # 정렬되지 않은 예시 리스트
    sorted_list = quicksort(unsorted)           # quicksort 함수 호출
    print("정렬 전 :", unsorted)                # 정렬 전 리스트 출력
    print("정렬 후 :", sorted_list)            # 정렬된 리스트 출력
```

**출력 예시**
```
정렬 전 : [33, 10, 55, 71, 29, 2, 18]
정렬 후 : [2, 10, 18, 29, 33, 55, 71]
```

이 구현은 **재귀**와 **분할 정복**을 이용해 리스트를 계속 작은 부분 리스트로 나눈 뒤, 정렬된 부분 리스트들을 합치는 방식으로 동작합니다. 각 단계마다 주석을 확인하면 퀵소트가 어떻게 작동하는지 쉽게 이해할 수 있을 것입니다.
