아래는 Python 로 구현한 **퀵소트(Quick Sort)** 알고리즘 예시입니다.  
각 코드 라인마다 상세히 주석을 달아 두었으니, 흐름을 따라가며 이해하시면 됩니다.

```python
def quick_sort(arr):
    """
    퀵소트 함수
    입력: 정수 혹은 실수 리스트 arr
    반환: 정렬된 새 리스트
    """
    # 리스트가 비었거나 원소가 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 값들을 모아 둘 리스트
    less = []    
    # 피벗과 같은 값들을 모아 둘 리스트 (피벗 자체도 여기 포함)
    equal = []   
    # 피벗보다 큰 값들을 모아 둘 리스트
    greater = [] 

    # 전체 리스트를 순회하면서 값들을 세 그룹으로 나눔
    for x in arr:
        if x < pivot:          # 현재 값이 피벗보다 작으면
            less.append(x)    # less 리스트에 추가
        elif x == pivot:       # 현재 값이 피벗과 같으면
            equal.append(x)   # equal 리스트에 추가
        else:                  # 현재 값이 피벗보다 크면
            greater.append(x) # greater 리스트에 추가

    # 재귀 호출을 통해 less와 greater 부분을 각각 정렬하고,
    # 정렬된 결과와 equal 리스트를 이어 붙여 최종 정렬 리스트를 만든다.
    return quick_sort(less) + equal + quick_sort(greater)


# ------------------------------
# 사용 예시
# ------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 원본 리스트 정의
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # quick_sort 함수를 호출하여 정렬된 리스트를 얻음
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트:", unsorted)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기본 종료 조건** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 요소를 피벗으로 사용했지만, 랜덤 요소 등으로 교체 가능.  
3. **분할 단계** – `less`, `equal`, `greater` 세 리스트에 원소를 분류.  
4. **재귀 정렬** – `less`와 `greater`에 대해 각각 `quick_sort`를 호출해 정렬하고, `equal`과 결합.  
5. **결과 반환** – 완전 정렬된 리스트를 반환한다.

이와 같이 각 라인에 의미를 명확히 적어 두면, 퀵소트가 어떻게 동작하는지 파악하기 쉬워집니다. 필요에 따라 피벗 선택 전략이나 in‑place 구현 등으로 변형해볼 수 있습니다!
