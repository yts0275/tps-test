아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 어떤 역할을 하는지 한글 주석을 달아 두었으니, 코드 흐름을 따라가며 이해하시면 됩니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수를 정의한다.
    """                                 # 함수 설명( docstring )
    입력받은 리스트를 제자리(in‑place) 정렬하고,
    정렬된 리스트를 반환한다.
    """
    _quick_sort(arr, 0, len(arr) - 1)   # 내부 재귀 함수에 전체 구간을 넘겨 호출한다.
    return arr                           # 정렬이 끝난 리스트를 반환한다.


def _quick_sort(arr, low, high):         # 실제 재귀 정렬을 담당하는 헬퍼 함수
    if low < high:                       # 구간의 크기가 2개 이상이면 정렬을 진행한다.
        p = _partition(arr, low, high)   # 피벗을 기준으로 배치를 나누고 피벗 인덱스를 반환한다.
        _quick_sort(arr, low, p - 1)     # 피벗 왼쪽(작은 값) 구간을 재귀적으로 정렬한다.
        _quick_sort(arr, p + 1, high)    # 피벗 오른쪽(큰 값) 구간을 재귀적으로 정렬한다.
    # low >= high 일 때는 구간에 원소가 0개 또는 1개이므로 이미 정렬된 상태이며,
    # 아무 작업도 하지 않고 바로 함수가 종료된다.


def _partition(arr, low, high):          # 배열을 피벗을 기준으로 분할하는 함수
    pivot = arr[high]                    # 가장 오른쪽 원소를 피벗으로 선택한다.
    i = low - 1                          # i는 "작은 값" 구역의 마지막 인덱스를 나타낸다.
    for j in range(low, high):           # 피벗을 제외한 구간을 차례로 살펴본다.
        if arr[j] <= pivot:              # 현재 원소가 피벗보다 작거나 같다면,
            i += 1                       # 작은 값 구역을 하나 확장하고,
            arr[i], arr[j] = arr[j], arr[i]   # 현재 원소를 작은 값 구역 끝으로 스와핑한다.
        # else: 피벗보다 큰 원소는 그대로 두고 탐색을 계속한다.
    # 모든 원소를 검사한 뒤, 피벗을 작은 값 구역 바로 뒤에 놓는다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                         # 피벗이 최종적으로 위치한 인덱스를 반환한다.


# ---------------------------------------------
# 사용 예시
if __name__ == "__main__":               # 스크립트가 직접 실행될 때만 아래 코드를 실행한다.
    sample = [33, 10, 55, 71, 29, 3, 18] # 정렬할 임의의 리스트
    print("정렬 전 :", sample)          # 정렬 전 리스트 출력
    quick_sort(sample)                  # 퀵소트 함수 호출 (제자리 정렬)
    print("정렬 후 :", sample)          # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. `quick_sort` 함수가 외부 인터페이스 역할을 하며, 전체 리스트에 대해 `_quick_sort`를 호출한다.  
2. `_quick_sort`는 재귀적으로 구간을 나누어 `low < high`인 경우에만 정렬을 진행한다.  
3. `_partition`은 피벗(여기선 오른쪽 끝 원소)을 기준으로 **작은 값 구역**과 **큰 값 구역**을 구분하고, 피벗을 정확한 위치에 배치한다.  
4. 피벗을 기준으로 왼쪽 구역(`low ~ p-1`)과 오른쪽 구역(`p+1 ~ high`)을 각각 다시 `_quick_sort`에 넘겨 재귀적으로 정렬한다.  

이 구현은 **제자리(in‑place) 정렬**이며, 평균 시간 복잡도는 `O(n log n)`, 최악의 경우(`이미 정렬된 배열` 등)는 `O(n²)`가 됩니다. 필요에 따라 피벗 선택 전략을 바꾸면 최악의 경우를 완화할 수 있습니다.
