아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 줄마다 무슨 역할을 하는지 설명하는 주석을 한글로 달아 두었으니, 코드를 읽으며 알고리즘 흐름을 이해하시면 됩니다.

```python
def quick_sort(arr):
    """퀵소트를 수행하고 정렬된 리스트를 반환한다."""
    
    # 1. 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 바로 반환한다.
    if len(arr) <= 1:
        return arr
    
    # 2. 피벗(pivot)으로 사용할 원소를 선택한다.
    #    여기서는 리스트의 마지막 원소를 피벗으로 삼는다.
    pivot = arr[-1]
    
    # 3. 피벗보다 작은 원소들을 저장할 리스트를 만든다.
    less = []
    # 4. 피벗과 같은 값을 저장할 리스트를 만든다.
    #    (중복값이 있을 경우에도 올바르게 정렬되도록 하기 위함)
    equal = [pivot]   # 피벗 자체를 미리 equal에 넣어 둔다.
    # 5. 피벗보다 큰 원소들을 저장할 리스트를 만든다.
    greater = []
    
    # 6. 피벗을 제외한 나머지 원소들을 순회하면서 세 개의 리스트에 분배한다.
    for x in arr[:-1]:               # 마지막 원소(pivot)를 제외하고 반복
        if x < pivot:                # 피벗보다 작으면 less 리스트에
            less.append(x)
        elif x > pivot:              # 피벗보다 크면 greater 리스트에
            greater.append(x)
        else:                        # 피벗과 같으면 equal 리스트에
            equal.append(x)
    
    # 7. 재귀적으로 less와 greater 리스트를 각각 정렬한다.
    #    정렬된 less 리스트 + equal 리스트 + 정렬된 greater 리스트를 이어 붙이면 전체가 정렬된 결과가 된다.
    return quick_sort(less) + equal + quick_sort(greater)


# ------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42, 55, 10]
    print("정렬 전 :", unsorted)
    sorted_arr = quick_sort(unsorted)
    print("정렬 후 :", sorted_arr)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 가장 오른쪽 원소를 피벗으로 사용.  
3. **분할** – 피벗보다 작은(`less`), 같은(`equal`), 큰(`greater`) 원소로 나눈다.  
4. **재귀 호출** – `less`와 `greater`에 대해 다시 `quick_sort`를 호출해 정렬한다.  
5. **병합** – 정렬된 `less`, `equal`, `greater`를 차례대로 이어 붙여 최종 정렬 결과를 만든다.

이 구현은 **원본 리스트를 그대로 변형하지 않고** 새 리스트를 반환하므로, 함수 호출이 끝난 뒤에도 원본 데이터는 보존됩니다. 필요에 따라 **제자리(in‑place) 퀵소트** 버전을 원하시면 알려 주세요!
