아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 줄마다 동작을 설명하는 주석을 한글로 달아 두었으니, 코드 흐름을 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):
    """퀵소트를 사용해 리스트를 오름차순 정렬하고 결과 리스트를 반환한다."""
    
    # 1️⃣ 정렬할 대상이 0개 혹은 1개라면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2️⃣ 피벗(pivot) 선정 : 여기서는 리스트의 마지막 원소를 피벗으로 선택
    pivot = arr[-1]
    
    # 3️⃣ 피벗보다 작은 원소들을 담을 리스트 (왼쪽 파티션)
    left = []
    # 4️⃣ 피벗과 같은 원소들을 담을 리스트 (중앙 파티션) – 중복값을 올바르게 처리하기 위해 따로 관리
    middle = [pivot]
    # 5️⃣ 피벗보다 큰 원소들을 담을 리스트 (오른쪽 파티션)
    right = []
    
    # 6️⃣ 피벗을 제외한 모든 원소를 순회하면서 좌·우·중 파티션에 분배
    for element in arr[:-1]:
        if element < pivot:          # 피벗보다 작으면 left에 추가
            left.append(element)
        elif element > pivot:        # 피벗보다 크면 right에 추가
            right.append(element)
        else:                        # 피벗과 같으면 middle에 추가 (중복값 처리)
            middle.append(element)
    
    # 7️⃣ 재귀 호출을 통해 left와 right 파티션을 각각 정렬
    #    - left 파티션이 비어 있지 않다면 quick_sort(left) 호출
    #    - right 파티션도 마찬가지
    sorted_left = quick_sort(left)   # left 파티션 정렬
    sorted_right = quick_sort(right) # right 파티션 정렬
    
    # 8️⃣ 정렬된 left, middle(피벗 및 중복값), sorted_right 를 순서대로 이어 붙여 최종 결과 반환
    return sorted_left + middle + sorted_right


# ========================= 사용 예시 =========================
if __name__ == "__main__":
    # 정렬하고 싶은 무작위 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 84, 55, 29]
    
    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)
    
    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트 :", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 1 이하이면 바로 반환.  
2. **피벗 선택** – 여기서는 가장 오른쪽 요소를 피벗으로 사용.  
3. **파티셔닝** – 피벗을 기준으로 `<`, `==`, `>` 세 구역으로 나눔.  
4. **재귀 정렬** – 좌·우 파티션을 각각 `quick_sort` 로 재귀 호출.  
5. **병합** – 정렬된 좌 파티션 + 피벗(및 중복) + 정렬된 우 파티션을 이어 붙여 반환.  

이 구현은 **안정적인(Stable) 정렬**은 아니지만, 평균 시간 복잡도 `O(N log N)`을 보장합니다.  
피벗 선택 전략을 바꾸면 최악의 경우(`O(N^2)`)를 피할 수 있으니, 실제 프로젝트에서는 랜덤 피벗이나 median‑of‑three 방식을 고려해 보세요.
