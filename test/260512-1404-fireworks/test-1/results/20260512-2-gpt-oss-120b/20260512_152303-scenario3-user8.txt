아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 줄마다 무엇을 하는지 한국어 주석을 달아 두었으니, 알고리즘 흐름을 따라가면서 이해하시면 됩니다.

```python
# 퀵소트 함수 정의: 리스트와 정렬할 구간을 인자로 받는다
def quick_sort(arr, low, high):
    # 구간이 하나 이상의 원소를 포함할 때만 정렬을 수행한다
    if low < high:
        # 파티션(pivot) 위치를 구하고, 파티션을 기준으로 리스트를 두 부분으로 나눈다
        pi = partition(arr, low, high)

        # 파티션 왼쪽 부분(피벗보다 작은 원소들)에 대해 재귀적으로 퀵소트를 수행한다
        quick_sort(arr, low, pi - 1)

        # 파티션 오른쪽 부분(피벗보다 큰 원소들)에 대해 재귀적으로 퀵소트를 수행한다
        quick_sort(arr, pi + 1, high)

# 파티션 함수 정의: 피벗을 기준으로 원소들을 재배치하고 피벗의 최종 인덱스를 반환한다
def partition(arr, low, high):
    # 가장 오른쪽 원소를 피벗(pivot)으로 선택한다
    pivot = arr[high]

    # i는 피벗보다 작은 원소들의 마지막 인덱스를 가리킨다
    i = low - 1

    # j는 low부터 high-1까지 순회하며 피벗보다 작은 원소를 찾는다
    for j in range(low, high):
        # 현재 원소 arr[j]가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            # i를 하나 늘리고, arr[i]와 arr[j]를 교환한다
            i += 1
            arr[i], arr[j] = arr[j], arr[i]   # 교환

    # 마지막 교환: 피벗을 i+1 위치로 옮겨서 피벗보다 작은 원소들 왼쪽, 큰 원소들 오른쪽에 놓는다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]   # 교환

    # 피벗이 최종적으로 위치한 인덱스를 반환한다
    return i + 1

# ---- 사용 예시 ----
if __name__ == "__main__":
    # 정렬하고 싶은 리스트를 정의한다
    data = [34, 7, 23, 32, 5, 62]

    # 퀵소트를 호출한다 (리스트 전체를 정렬하므로 0부터 len-1까지 전달)
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과를 출력한다
    print("정렬된 리스트:", data)
```

### 코드 흐름 요약
1. `quick_sort`는 재귀적으로 호출되어 리스트를 **피벗**을 기준으로 두 부분으로 나눈다.  
2. `partition` 함수는 피벗을 마지막 원소로 잡고, 피벗보다 작은 원소들을 왼쪽에, 큰 원소들을 오른쪽에 배치한다.  
3. 피벗이 최종 위치한 인덱스를 반환하면, 그 인덱스를 기준으로 왼쪽·오른쪽 구간에 대해 다시 `quick_sort`를 실행한다.  
4. 구간의 크기가 1 이하가 될 때 재귀 호출이 멈추면서 정렬이 완료된다.
