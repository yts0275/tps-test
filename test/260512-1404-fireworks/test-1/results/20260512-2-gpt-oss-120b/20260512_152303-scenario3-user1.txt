아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 한글 주석을 달아 어떤 역할을 하는지 상세히 설명했습니다.  

```python
def quick_sort(arr):                     # 퀵소트 함수 정의, 정렬할 리스트 arr를 인자로 받는다
    # 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:                   
        return arr                       

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                       

    # 피벗보다 작은 값들을 저장할 리스트
    left = []                             
    # 피벗보다 큰 값들을 저장할 리스트
    right = []                            

    # 피벗을 제외한 나머지 요소들을 순회하면서 left와 right에 분배
    for element in arr[:-1]:              
        if element <= pivot:               # 현재 요소가 피벗보다 작거나 같으면
            left.append(element)           # left 리스트에 추가
        else:                              # 현재 요소가 피벗보다 크면
            right.append(element)          # right 리스트에 추가

    # 재귀적으로 left와 right 리스트를 각각 정렬하고,
    # 정렬된 left + 피벗 + 정렬된 right 를 합쳐서 반환
    return quick_sort(left) + [pivot] + quick_sort(right)  


# ------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 이 파일이 직접 실행될 때만 아래 코드를 수행
    unsorted = [33, 10, 55, 71, 29, 3, 18] # 정렬되지 않은 샘플 리스트
    sorted_list = quick_sort(unsorted)    # 퀵소트 함수 호출
    print("정렬 전:", unsorted)           # 원본 리스트 출력
    print("정렬 후:", sorted_list)        # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기본 종료 조건** – 리스트 길이가 1 이하이면 바로 반환(재귀 종료).  
2. **피벗 선택** – 여기서는 마지막 요소를 피벗으로 사용했지만, 임의 선택이나 중간값 등으로 바꿀 수 있다.  
3. **분할(Partition)** – 피벗을 기준으로 `left`와 `right` 두 리스트에 나누어 담는다.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 퀵소트를 다시 수행한다.  
5. **결과 합치기** – 정렬된 `left`, 피벗, 정렬된 `right`를 순서대로 이어서 최종 정렬된 리스트를 만든다.  

이 구현은 **제자리(in‑place) 정렬**은 아니고, 새로운 리스트를 만들어 반환하는 형태이지만 이해하기 쉽고, 각 단계별 역할을 명확히 보여주기에 교육용으로 적합합니다. 필요에 따라 `in‑place` 버전으로도 변형할 수 있습니다. 🚀
