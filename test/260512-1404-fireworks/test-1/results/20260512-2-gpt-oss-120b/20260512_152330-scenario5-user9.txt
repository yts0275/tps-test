아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
코드의 각 라인마다 한국어 주석을 달아 어떤 작업을 하는지 자세히 설명했습니다.

```python
# 퀵소트 함수 정의: 리스트와 정렬할 구간의 시작·끝 인덱스를 매개변수로 받음
def quick_sort(arr, low, high):
    # 구간이 하나 이하일 경우(이미 정렬된 경우) 바로 반환
    if low < high:
        # 파티션 수행 → 피벗보다 작은 값들은 왼쪽, 큰 값들은 오른쪽으로 이동
        pi = partition(arr, low, high)

        # 피벗을 기준으로 왼쪽 구간을 재귀적으로 정렬
        quick_sort(arr, low, pi - 1)

        # 피벗을 기준으로 오른쪽 구간을 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)

# 파티션 함수 정의: 피벗을 기준으로 요소들을 재배치하고 최종 피벗 위치 반환
def partition(arr, low, high):
    # 가장 오른쪽 요소를 피벗으로 선택
    pivot = arr[high]

    # i는 피벗보다 작은 요소들의 마지막 인덱스를 가리킴
    i = low - 1

    # low부터 high-1까지 순회하면서 피벗보다 작은 요소를 찾아 앞쪽으로 이동
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 한 칸 앞으로 이동
            i += 1
            # i와 j 위치의 요소를 교환 (작은 값들을 앞으로 모음)
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 i+1 위치와 교환하여 피벗이 정확한 정렬 위치에 오도록 함
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 인덱스를 반환 (재귀 호출에서 사용)
    return i + 1

# 사용 예시
if __name__ == "__main__":
    # 정렬할 리스트 정의
    data = [33, 10, 55, 71, 29, 3, 18, 42]

    # 리스트와 전체 구간을 인수로 넘겨 퀵소트 실행
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과 출력
    print("정렬된 결과:", data)
```

### 코드 흐름 요약
1. `quick_sort` 함수가 재귀적으로 호출되어 리스트를 **분할‑정복** 방식으로 정렬합니다.  
2. `partition` 함수는 현재 구간에서 피벗을 기준으로 작은 값들을 왼쪽, 큰 값들을 오른쪽에 배치하고, 피벗을 최종 위치에 놓습니다.  
3. 피벗을 기준으로 좌·우 구간을 다시 `quick_sort`에 넘겨 같은 과정을 반복하면 전체 리스트가 정렬됩니다.  

이렇게 구현한 퀵소트는 평균 시간 복잡도가 **O(N log N)**이며, 최악 경우(이미 정렬된 경우 등)에는 **O(N²)**가 될 수 있습니다. 필요에 따라 피벗 선택 전략을 바꾸면 최악 경우를 완화할 수 있습니다.
