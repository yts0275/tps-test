아래는 파이썬(Python)으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드의 **각 줄마다** 어떤 동작을 하는지 상세히 설명하는 주석을 달았습니다.  
필요에 따라 리스트를 직접 전달하거나, `quick_sort` 함수를 호출해 정렬된 결과를 얻을 수 있습니다.

```python
def quick_sort(arr):
    """ 퀵소트를 수행하여 정렬된 새로운 리스트를 반환한다.
        입력:  arr  – 정렬하고자 하는 리스트 (복사본을 만들어 사용)
        출력: 정렬이 완료된 리스트 """
    
    # 1. 입력 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:
        return arr                       # (base case)

    # 2. 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 잡는다.
    pivot = arr[-1]                      # (마지막 원소가 피벗)

    # 3. 피벗보다 작은 원소들을 저장할 리스트와,
    #    피벗보다 큰 원소들을 저장할 리스트를 각각 초기화한다.
    less = []                            # 피벗보다 작은 값들을 담을 리스트
    greater = []                         # 피벗보다 큰 값들을 담을 리스트

    # 4. 피벗을 제외한 나머지 원소들을 순회하면서
    #    각각 less 혹은 greater 리스트에 분류한다.
    for item in arr[:-1]:                # 피벗을 제외한 모든 원소에 대해
        if item <= pivot:                # 피벗보다 작거나 같은 경우
            less.append(item)            # less 리스트에 추가
        else:                            # 피벗보다 큰 경우
            greater.append(item)         # greater 리스트에 추가

    # 5. 재귀 호출을 통해 less와 greater 각각을 정렬한다.
    #    이렇게 하면 작은 구간부터 차례대로 정렬이 진행된다.
    sorted_less = quick_sort(less)       # less 부분에 대해 퀵소트 재귀 호출
    sorted_greater = quick_sort(greater) # greater 부분에 대해 퀵소트 재귀 호출

    # 6. 정렬된 less 리스트, 피벗, 정렬된 greater 리스트를 순서대로
    #    합쳐서 최종 정렬 결과를 만든다.
    return sorted_less + [pivot] + sorted_greater
    # (less 결과 + 피벗 하나 + greater 결과) 로 새로운 정렬된 리스트 반환


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 무작위 리스트를 정의한다.
    unsorted_list = [34, 7, 23, 32, 5, 62, 78, 1, 19]

    # quick_sort 함수를 호출해 정렬된 리스트를 얻는다.
    sorted_list = quick_sort(unsorted_list)

    # 결과를 화면에 출력한다.
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트 :", sorted_list)
```

### 코드 흐름 요약
1. **Base case** – 리스트 길이가 0 또는 1이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용.  
3. **분할** – 피벗을 기준으로 `less`와 `greater` 두 부분 리스트로 나눈다.  
4. **재귀** – `less`와 `greater`에 대해 각각 `quick_sort`를 다시 호출한다.  
5. **합치기** – 정렬된 `less`, 피벗, 정렬된 `greater`를 차례대로 연결해 최종 결과를 만든다.  

각 줄에 달아 놓은 주석을 참고하면 퀵소트가 어떻게 동작하는지 쉽게 이해할 수 있을 것입니다. 😊
