아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 상세하게 주석을 달아 두었으니, 동작 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수를 정의한다. (입력: 정렬할 리스트)
    if len(arr) <= 1:                    # 리스트 길이가 0 혹은 1이면 이미 정렬된 상태이므로
        return arr                       # 그대로 반환한다.

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 값을 리스트 중간 요소로 선택한다.
    left = []                            # 피벗보다 작은 요소들을 담을 리스트를 생성한다.
    middle = []                          # 피벗과 같은 요소들을 담을 리스트를 생성한다.
    right = []                           # 피벗보다 큰 요소들을 담을 리스트를 생성한다.

    for x in arr:                        # 원본 리스트의 모든 요소를 순회한다.
        if x < pivot:                    # 현재 요소가 피벗보다 작으면
            left.append(x)                # left 리스트에 추가한다.
        elif x == pivot:                 # 현재 요소가 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가한다.
        else:                            # 현재 요소가 피벗보다 크면
            right.append(x)               # right 리스트에 추가한다.

    # 재귀적으로 left와 right 부분을 정렬하고,
    # 정렬된 left + middle + 정렬된 right 를 합쳐 반환한다.
    return quick_sort(left) + middle + quick_sort(right)


# ---------- 사용 예시 ----------
if __name__ == "__main__":                # 이 파일이 직접 실행될 때만 아래 코드를 수행한다.
    sample = [33, 10, 55, 71, 29, 3, 18] # 정렬할 샘플 리스트를 만든다.
    print("원본 리스트 :", sample)        # 정렬 전 리스트를 출력한다.
    sorted_list = quick_sort(sample)     # 퀵소트 함수를 호출해 정렬한다.
    print("정렬된 리스트:", sorted_list) # 정렬된 결과를 출력한다.
```

**주요 포인트**

1. **피벗 선택**  
   - 여기서는 리스트 중간 요소(`arr[len(arr)//2]`)를 피벗으로 사용했지만, 첫 번째·마지막·무작위 등 다양한 전략을 사용할 수 있습니다.

2. **분할 단계**  
   - `left`, `middle`, `right` 세 개의 리스트에 각각 피벗보다 작은, 같은, 큰 값을 배분합니다.  
   - 이렇게 하면 같은 값이 여러 개 있어도 안정적으로 처리할 수 있습니다.

3. **재귀 호출**  
   - `left`와 `right` 부분에 대해 다시 `quick_sort`를 호출해 각각 정렬합니다.  
   - `middle`은 피벗과 같은 값이므로 이미 정렬된 상태라 그대로 사용합니다.

4. **병합 단계**  
   - 정렬된 `left`, `middle`, `right`를 순서대로 연결(`+`)하여 최종 정렬된 리스트를 반환합니다.

이 구현은 **읽기 쉬운** 형태를 목표로 했으며, **O(n log n)** 의 평균 시간 복잡도와 **O(n)** 의 추가 메모리 사용을 가집니다.  
필요에 따라 **인플레이스(in‑place)** 버전이나 **피벗 선택 전략**을 바꾸어 성능을 최적화할 수 있습니다.
