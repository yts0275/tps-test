아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 코드 라인마다 한글로 자세히 주석을 달아 두었으니, 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):
    """퀵소트를 수행하고 정렬된 새로운 리스트를 반환한다."""
    
    # 1. 리스트가 비어 있거나 원소가 하나만 있으면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                      # 기본 사례(Base case)

    # 2. 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 사용
    pivot = arr[-1]                     # 피벗은 현재 구간에서 마지막 원소

    # 3. 피벗보다 작은 원소들을 담을 리스트와 피벗보다 큰 원소들을 담을 리스트 준비
    less = []    # 피벗보다 작은 값들을 저장
    greater = [] # 피벗보다 큰 값들을 저장

    # 4. 피벗을 제외한 나머지 원소들을 순회하면서 두 리스트에 분류
    for x in arr[:-1]:                  # 마지막 원소(피벗)는 제외하고 탐색
        if x <= pivot:                  # 피벗 이하이면 less 리스트에 추가
            less.append(x)
        else:                           # 피벗 초과이면 greater 리스트에 추가
            greater.append(x)

    # 5. 분할된 두 리스트에 대해 재귀적으로 quick_sort를 호출
    #    정렬된 less 리스트 + 피벗 + 정렬된 greater 리스트를 이어 붙인다.
    return quick_sort(less) + [pivot] + quick_sort(greater)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 임의의 리스트
    sorted_arr = quick_sort(unsorted)       # quick_sort 함수 호출
    print("정렬 전:", unsorted)             # 원본 리스트 출력
    print("정렬 후:", sorted_arr)           # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기본 사례** : 리스트 길이가 1 이하이면 그대로 반환한다.  
2. **피벗 선택** : 여기서는 가장 오른쪽 원소를 피벗으로 잡는다(다른 선택도 가능).  
3. **분할** : 피벗보다 작거나 같은 원소와 큰 원소를 각각 `less`, `greater` 리스트에 나눈다.  
4. **재귀 호출** : `less`와 `greater`에 대해 각각 `quick_sort`를 다시 실행한다.  
5. **합치기** : 정렬된 `less` + 피벗 + 정렬된 `greater` 순서로 새로운 리스트를 만든다.

이렇게 하면 **O(n log n)** (평균) 시간 복잡도로 리스트를 정렬할 수 있습니다.  
피벗 선택 방법을 바꾸면 최악의 경우 **O(n²)** 를 피하거나 성능을 더욱 향상시킬 수 있습니다. 즐겁게 활용해 보세요!
