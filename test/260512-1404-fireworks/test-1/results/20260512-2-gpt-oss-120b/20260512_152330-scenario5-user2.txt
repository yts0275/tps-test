아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 동작을 설명하는 주석을 달아 두었습니다.  
필요에 따라 `quick_sort` (새로운 리스트를 반환)와 `quick_sort_inplace` (제자리 정렬) 두 버전을 모두 제공합니다.

```python
# -------------------------------------------------
# 1) 새로운 리스트를 반환하는 퀵소트 (재귀 버전)
# -------------------------------------------------
def quick_sort(arr):
    # 입력 리스트가 빈 리스트이거나 원소가 하나뿐이면 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 원소들을 모은 리스트 (왼쪽 파트)
    left = [x for x in arr[:-1] if x <= pivot]

    # 피벗보다 큰 원소들을 모은 리스트 (오른쪽 파트)
    right = [x for x in arr[:-1] if x > pivot]

    # 재귀적으로 left와 right를 정렬하고, 피벗과 합쳐서 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# -------------------------------------------------
# 2) 제자리(in‑place) 정렬을 수행하는 퀵소트
# -------------------------------------------------
def quick_sort_inplace(arr, low=0, high=None):
    """
    arr   : 정렬할 리스트
    low   : 현재 정렬 구간의 시작 인덱스
    high  : 현재 정렬 구간의 끝 인덱스 (포함)
    """
    # 처음 호출 시 high값을 리스트 마지막 인덱스로 설정
    if high is None:
        high = len(arr) - 1

    # 구간이 하나 이하이면 더 이상 정렬할 필요 없음
    if low < high:
        # 파티션 수행 → 피벗이 최종적으로 위치할 인덱스를 반환
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분을 재귀적으로 정렬
        quick_sort_inplace(arr, low, pi - 1)

        # 피벗 오른쪽 부분을 재귀적으로 정렬
        quick_sort_inplace(arr, pi + 1, high)


def partition(arr, low, high):
    """
    파티션 과정:
    - 피벗을 구간의 마지막 요소(arr[high])로 잡는다.
    - left_idx는 피벗보다 작은 원소들을 모아두는 위치를 가리킨다.
    - 순회하면서 피벗보다 작은 원소를 발견하면 left_idx와 현재 인덱스를 교환한다.
    - 최종적으로 피벗을 left_idx 위치와 교환해 정렬을 완성한다.
    """
    # 피벗 값 선택 (구간의 마지막 요소)
    pivot = arr[high]

    # left_idx는 피벗보다 작거나 같은 원소를 저장할 위치
    left_idx = low - 1

    # low부터 high-1까지 순회하면서 피벗과 비교
    for i in range(low, high):
        # 현재 원소가 피벗보다 작거나 같으면 left_idx를 증가시키고 교환
        if arr[i] <= pivot:
            left_idx += 1
            arr[left_idx], arr[i] = arr[i], arr[left_idx]   # swap

    # 마지막으로 피벗을 left_idx+1 위치와 교환 → 피벗이 정확히 그 위치에 고정
    arr[left_idx + 1], arr[high] = arr[high], arr[left_idx + 1]

    # 피벗이 최종적으로 위치한 인덱스를 반환
    return left_idx + 1


# -------------------------------------------------
# 사용 예시
# -------------------------------------------------
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18]

    # 1) 새 리스트를 반환하는 퀵소트
    sorted_data = quick_sort(data)
    print("새 리스트 반환:", sorted_data)          # [3, 10, 18, 29, 33, 55, 71]

    # 2) 제자리 정렬(in‑place) 퀵소트
    data2 = data[:]               # 복사본을 만든 뒤
    quick_sort_inplace(data2)    # 제자리 정렬 호출
    print("제자리 정렬:", data2)               # [3, 10, 18, 29, 33, 55, 71]
```

### 코드 흐름 요약
| 단계 | 주요 동작 |
|------|-----------|
| **재귀 버전** | 피벗을 기준으로 `left`와 `right` 두 리스트로 분할 → 각각을 재귀 호출 → 결과를 합쳐 반환 |
| **제자리 버전** | `partition` 함수에서 피벗을 적절한 위치에 배치 → 피벗을 기준으로 좌·우 구간을 재귀 호출해 정렬 |
| **partition** | `low`~`high-1` 구간을 순회하며 피벗보다 작거나 같은 원소를 앞쪽으로 모으고, 마지막에 피벗을 중간에 삽입 |
