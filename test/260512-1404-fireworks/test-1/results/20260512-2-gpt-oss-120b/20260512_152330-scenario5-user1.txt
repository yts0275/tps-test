아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 한글 주석을 달아 동작을 설명했습니다. 필요에 따라 함수 호출 부분만 복사해 사용하시면 됩니다.

```python
def quick_sort(arr):                     # 정렬할 리스트를 인자로 받는 함수 정의
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                       # 그대로 반환하고 재귀를 종료

    pivot = arr[len(arr) // 2]           # 피벗(pivot)으로 리스트 중앙 요소 선택
    left = []                            # 피벗보다 작은 원소들을 담을 리스트 초기화
    middle = []                          # 피벗과 같은 원소들을 담을 리스트 초기화
    right = []                           # 피벗보다 큰 원소들을 담을 리스트 초기화

    for x in arr:                        # 원본 리스트의 모든 요소를 순회
        if x < pivot:                    # 현재 요소가 피벗보다 작으면
            left.append(x)               # left 리스트에 추가
        elif x == pivot:                 # 현재 요소가 피벗과 같으면
            middle.append(x)             # middle 리스트에 추가
        else:                            # 현재 요소가 피벗보다 크면
            right.append(x)              # right 리스트에 추가

    # left와 right 리스트에 대해 재귀적으로 quick_sort를 호출하여 정렬하고,
    # middle 리스트(피벗과 동일한 값)는 그대로 연결
    return quick_sort(left) + middle + quick_sort(right)  # 정렬된 리스트를 합쳐 반환
```

### 사용 예시
```python
unsorted = [33, 10, 55, 71, 29, 3, 18]
sorted_arr = quick_sort(unsorted)
print(sorted_arr)   # [3, 10, 18, 29, 33, 55, 71]
```

**주요 포인트**
- **피벗 선택**: 리스트 가운데 요소를 피벗으로 사용해 평균적인 경우 O(n log n)의 시간 복잡도를 기대합니다.
- **분할 단계**: 리스트를 `left`, `middle`, `right` 세 부분으로 나누어 재귀 호출합니다.
- **합병 단계**: 재귀 호출이 끝난 후 정렬된 `left`와 `right` 리스트를 `middle`과 함께 연결해 최종 결과를 반환합니다.  

필요에 따라 피벗 선택 전략(예: 랜덤 선택)이나 **in‑place** 버전을 구현해 성능을 조정할 수 있습니다.
