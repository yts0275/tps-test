아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 이해를 돕기 위해 **한글 주석**을 달아 두었습니다.  

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    """
    입력: 정렬하고 싶은 리스트 arr
    반환: 정렬된 새로운 리스트 (원본 리스트는 변경되지 않음)
    """
    # 리스트가 비어 있거나 원소가 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작거나 같은 원소들을 담을 리스트
    less = []
    # 피벗보다 큰 원소들을 담을 리스트
    greater = []

    # 피벗을 제외한 나머지 원소들을 순회하면서 두 리스트에 나눠 담는다
    for element in arr[:-1]:
        # 현재 원소가 피벗보다 작거나 같으면 less 리스트에 추가
        if element <= pivot:
            less.append(element)
        # 현재 원소가 피벗보다 크면 greater 리스트에 추가
        else:
            greater.append(element)

    # 재귀 호출: less와 greater 각각을 정렬하고,
    # 정렬된 less 리스트 + 피벗 + 정렬된 greater 리스트를 합쳐 반환
    return quick_sort(less) + [pivot] + quick_sort(greater)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬할 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("정렬 전:", unsorted_list)
    print("정렬 후:", sorted_list)
```

### 주요 포인트
1. **피벗 선택**  
   - 위 코드에서는 리스트의 마지막 원소를 피벗으로 선택했지만, `random.choice(arr)` 등으로 무작위 피벗을 골라도 된다.  
   - 피벗 선택 방법에 따라 최악/최선 수행 시간이 달라질 수 있다.

2. **분할 단계**  
   - `less`와 `greater` 두 개의 리스트에 원소를 나누어 담는다.  
   - 이 과정이 **O(n)** 의 추가 메모리를 사용한다는 점을 유의하라.  
   - **인플레이스(in‑place)** 퀵소트(값을 교환하면서 같은 배열 안에서 정렬) 구현도 가능하지만 코드가 다소 복잡해진다.

3. **재귀 호출**  
   - `quick_sort(less)`와 `quick_sort(greater)`가 각각 더 작은 문제(부분 리스트)로 재귀 호출된다.  
   - 재귀 깊이는 최악의 경우 O(n) (이미 정렬된 리스트를 피벗으로 선택했을 때) 이지만, 평균적으로는 O(log n) 이다.

4. **시간 복잡도**  
   - 평균: **O(n log n)**
   - 최악: **O(n²)** (피벗이 항상 최소/최대값일 때)

위 코드를 그대로 복사해 실행하면, 입력 리스트가 정렬된 모습을 확인할 수 있습니다. 필요에 따라 피벗 선택 방식을 바꾸거나, 인플레이스 버전으로 최적화해 사용할 수 있습니다. 🚀
