아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 한글 주석을 달아 코드 흐름을 자세히 설명했습니다.

```python
# 퀵소트 구현 --------------------------------------------------------------

def quick_sort(arr):
    """
    입력받은 리스트 arr를 정렬하고 반환한다.
    재귀 호출을 이용한 퀵소트 알고리즘이다.
    """
    # 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 잡는다.
    pivot = arr[-1]

    # 피벗보다 작은 원소들을 모아 놓을 리스트
    left = []
    # 피벗과 같은 값을 모아 놓을 리스트 (중복을 위해 필요)
    middle = []
    # 피벗보다 큰 원소들을 모아 놓을 리스트
    right = []

    # 전체 리스트를 순회하면서 원소들을 left, middle, right에 분류한다.
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x == pivot:       # 피벗과 같으면 middle에 추가
            middle.append(x)
        else:                  # 피벗보다 크면 right에 추가
            right.append(x)

    # left와 right는 아직 정렬되지 않았으므로 재귀적으로 quick_sort를 호출한다.
    # middle는 피벗과 같은 값들의 집합이므로 이미 정렬된 상태이다.
    return quick_sort(left) + middle + quick_sort(right)


# 사용 예시 --------------------------------------------------------------

if __name__ == "__main__":
    # 정렬되지 않은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90, 42]

    # quick_sort 함수를 호출하여 정렬된 리스트를 얻는다.
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("정렬 전:", unsorted_list)
    print("정렬 후:", sorted_list)
```

### 코드 설명 (줄별 요약)

| 줄 번호 | 내용 |
|--------|------|
| 1‑2    | 퀵소트 구현을 위한 함수 정의 시작 |
| 4‑7    | 입력 리스트가 비어 있거나 원소가 1개이면 바로 반환 (기저 사례) |
| 9‑10   | 피벗을 리스트 마지막 요소로 선택 |
| 12‑14  | 피벗보다 작은 값, 같은 값, 큰 값을 저장할 빈 리스트 3개 생성 |
| 16‑22  | 리스트 전체를 순회하면서 각 값들을 `left`, `middle`, `right`에 분류 |
| 24‑26  | `left`와 `right`는 아직 정렬되지 않았으므로 재귀 호출, `middle`는 그대로 사용 |
| 30‑31  | 메인 블록: 실행될 때만 동작하도록 `if __name__ == "__main__":` 사용 |
| 33‑34  | 정렬 전 예시 리스트 선언 |
| 36‑37  | `quick_sort` 호출 후 정렬된 리스트를 `sorted_list`에 저장 |
| 39‑40  | 정렬 전/후 리스트를 화면에 출력 |

이 구현은 **분할 정복(Divide and Conquer)** 방식을 사용하며,  
피벗 선택을 마지막 요소로 고정했지만 필요에 따라 임의 선택 등으로 바꿀 수 있습니다.  
시간 복잡도는 평균 `O(N log N)`, 최악의 경우(이미 정렬된 입력 등) `O(N²)`입니다.
