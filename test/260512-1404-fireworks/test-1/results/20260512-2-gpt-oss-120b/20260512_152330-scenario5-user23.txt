아래는 Python으로 구현한 **퀵소트(Quick Sort)** 알고리즘 예시입니다.  
각 줄마다 어떤 역할을 하는지 설명하는 주석을 달아두었으니, 코드 흐름을 따라가면서 이해하기 쉽도록 구성했습니다.

```python
def quick_sort(arr):
    """
    퀵소트를 재귀적으로 수행하는 함수
    - 입력: 정렬하고 싶은 리스트 arr
    - 반환: 정렬된 새로운 리스트
    """
    # 1) 리스트가 비어 있거나 원소가 하나만 있으면 이미 정렬된 상태 → 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2) 피벗(pivot) 선택
    #    여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 3) 피벗보다 작은 값들을 담을 리스트 (왼쪽 파티션)
    left = []

    # 4) 피벗보다 큰 값들을 담을 리스트 (오른쪽 파티션)
    right = []

    # 5) 피벗을 제외한 나머지 요소들을 순회하면서
    #    각각 left 혹은 right 리스트에 배치
    for element in arr[:-1]:                # 마지막 요소(pivot)를 제외하고 순회
        if element <= pivot:                # 피벗보다 작거나 같은 경우
            left.append(element)            # left 파티션에 추가
        else:                               # 피벗보다 큰 경우
            right.append(element)           # right 파티션에 추가

    # 6) 재귀 호출을 통해 left와 right 파티션을 각각 정렬
    #    - quick_sort(left) : left 파티션을 정렬
    #    - quick_sort(right): right 파티션을 정렬
    sorted_left = quick_sort(left)          # 정렬된 left 파티션
    sorted_right = quick_sort(right)        # 정렬된 right 파티션

    # 7) 최종 결과 반환
    #    left 파티션 + 피벗 + right 파티션 순서가 오름차순 정렬 결과
    return sorted_left + [pivot] + sorted_right


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [34, 7, 23, 32, 5, 62, 31, 4]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 그대로 반환합니다. (이미 정렬된 상태)
2. **피벗 선택** – 여기서는 마지막 요소를 피벗으로 사용했습니다. (다른 전략도 가능)
3. **분할 단계** – 피벗을 기준으로 `left`와 `right` 두 파티션을 만든 뒤, 각각에 원소를 배치합니다.
4. **재귀 호출** – `left`와 `right` 파티션에 대해 같은 과정을 반복해 완전히 정렬합니다.
5. **결합 단계** – 정렬된 `left`, 피벗, 정렬된 `right`를 차례대로 이어붙이면 전체 리스트가 정렬됩니다.

이 구현은 **안정적인(stable) 정렬**은 아니지만, 평균 시간 복잡도가 `O(N log N)`이며, 최악의 경우 `O(N²)`가 되는 퀵소트의 기본 원리를 잘 보여줍니다. 필요에 따라 피벗 선택 방식을 바꾸면 최악의 경우를 방지할 수도 있습니다. 😊
