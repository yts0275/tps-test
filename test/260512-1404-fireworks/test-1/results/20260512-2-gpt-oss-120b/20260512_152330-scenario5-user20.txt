아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 어떤 동작을 하는지 설명하는 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):
    """배열 arr를 제자리(in‑place) 퀵소트 알고리즘으로 정렬하고 정렬된 배열을 반환한다."""
    
    # 0. 내부에 재귀 호출을 담당할 헬퍼 함수를 정의한다.
    def _quick_sort(low, high):
        # 1. 재귀 종료 조건: 구간에 요소가 1개 이하이면 이미 정렬된 상태이므로 반환
        if low >= high:
            return
        
        # 2. 피벗(pivot) 선택: 여기서는 구간의 가장 오른쪽 요소를 피벗으로 사용
        pivot = arr[high]
        
        # 3. i는 피벗보다 작거나 같은 값이 배치될 최종 위치를 가리키는 인덱스
        i = low - 1
        
        # 4. low부터 high-1까지 순회하면서 피벗보다 작은(또는 같은) 값들을 앞쪽으로 모은다
        for j in range(low, high):
            # 현재 요소 arr[j]가 피벗보다 작거나 같은 경우
            if arr[j] <= pivot:
                i += 1                # i를 한 칸 오른쪽으로 옮기고
                arr[i], arr[j] = arr[j], arr[i]  # 그 위치와 현재 요소를 교환
                # 이제 arr[low..i] 구간은 피벗보다 작거나 같은 값들로 채워짐
        
        # 5. 피벗을 “작은 값들” 구간 바로 뒤에 배치한다.
        #    i+1 위치가 피벗의 최종 정렬 위치가 된다.
        arr[i + 1], arr[high] = arr[high], arr[i + 1]
        
        # 6. 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 재귀적으로 정렬한다.
        _quick_sort(low, i)          # 피벗 왼쪽(작은 값들) 정렬
        _quick_sort(i + 2, high)     # 피벗 오른쪽(큰 값들) 정렬
    
    # 7. 전체 배열에 대해 헬퍼 함수를 호출한다.
    _quick_sort(0, len(arr) - 1)
    
    # 8. 정렬이 끝난 배열을 반환한다(선택 사항: 함수 자체가 제자리 정렬이라 반환값이 없어도 된다)
    return arr


# ------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    sample = [34, 7, 23, 32, 5, 62]
    print("정렬 전 :", sample)
    quick_sort(sample)                # 제자리 정렬이므로 반환값을 받지 않아도 된다.
    print("정렬 후 :", sample)
```

### 코드 흐름 요약
1. `quick_sort`는 외부에서 한 번만 호출되는 진입점이다.  
2. 내부에 정의된 `_quick_sort(low, high)`가 실제 재귀 로직을 담당한다.  
3. 피벗을 마지막 요소로 정하고, `low`부터 `high‑1`까지 순회하면서 피벗보다 작은 값들을 왼쪽으로 몰아준다.  
4. 순회가 끝난 뒤 피벗을 그 바로 다음 위치(`i+1`)에 놓아, 피벗을 기준으로 **왼쪽**은 모두 피벗보다 작고 **오른쪽**은 모두 피벗보다 크도록 만든다.  
5. 피벗을 기준으로 두 구간을 각각 재귀 호출해 정렬을 진행한다.  
6. 재귀 깊이가 0(구간에 요소가 1개 이하)이라면 바로 반환한다.  

이렇게 하면 평균 시간 복잡도는 **O(N log N)**, 최악의 경우(이미 정렬된 배열에 대해 피벗을 한쪽 끝에서 선택) **O(N²)** 가 됩니다.  
피벗 선택 방식을 랜덤하게 바꾸면 최악의 경우 발생 확률을 크게 낮출 수 있습니다. 🌟
