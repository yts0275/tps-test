아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 동작을 설명하는 주석을 한국어로 달아 두었습니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행하는 함수 정의
    """
    Quick Sort 알고리즘을 이용해 리스트를 정렬하고,
    정렬된 새로운 리스트를 반환한다.
    """
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                        # 그대로 반환

    pivot = arr[len(arr) // 2]           # 피벗(pivot)값을 리스트 중간 요소로 선택
    left = []                             # 피벗보다 작은 요소를 담을 리스트
    middle = []                           # 피벗과 같은 요소를 담을 리스트
    right = []                            # 피벗보다 큰 요소를 담을 리스트

    for x in arr:                         # 원본 리스트의 모든 요소를 순회
        if x < pivot:                     # 현재 요소가 피벗보다 작다면
            left.append(x)                # left 리스트에 추가
        elif x == pivot:                  # 현재 요소가 피벗과 같다면
            middle.append(x)              # middle 리스트에 추가
        else:                             # 현재 요소가 피벗보다 크다면
            right.append(x)               # right 리스트에 추가

    # 재귀적으로 left와 right 부분을 정렬하고, middle (피벗)과 합쳐 반환
    return quick_sort(left) + middle + quick_sort(right)


# -------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 아래 코드 실행
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]  # 정렬되지 않은 예시 리스트
    print("정렬 전 :", unsorted)                # 정렬 전 리스트 출력
    sorted_arr = quick_sort(unsorted)           # 퀵소트 함수 호출
    print("정렬 후 :", sorted_arr)               # 정렬된 리스트 출력
```

**핵심 아이디어**  
- 피벗을 기준으로 리스트를 **left**, **middle**, **right** 세 파트로 나눈 뒤,  
- `left`와 `right`에 대해서 재귀적으로 같은 과정을 반복합니다.  
- `middle`은 피벗과 같은 값들을 그대로 유지하므로 병합 단계에서 그대로 연결하면 됩니다.

이 구현은 **안정적인** 정렬은 아니지만(같은 값들의 상대 순서를 보장하지 않음)  
평균 시간 복잡도 `O(N log N)`을 가지며, 최악의 경우 `O(N²)`가 될 수 있습니다.  
필요에 따라 피벗 선택 방법(예: 랜덤 피벗)이나 **in‑place** 버전을 구현하면
성능과 메모리 사용을 더 최적화할 수 있습니다.
