아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘이며, **각 줄마다 한글 주석**을 달아 두었습니다.  
코드 흐름을 이해하는 데 도움이 되길 바랍니다.

```python
# 퀵소트를 구현하기 위한 메인 함수
def quick_sort(arr):
    # 입력 배열이 비어있거나 원소가 하나뿐이면 이미 정렬된 상태 → 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 원소들을 저장할 리스트
    less = []
    # 피벗과 같은 값(중복)들을 저장할 리스트
    equal = []
    # 피벗보다 큰 원소들을 저장할 리스트
    greater = []

    # 배열의 각 원소를 순회하면서 삼분(less, equal, greater)한다
    for x in arr:
        # 현재 원소가 피벗보다 작으면 less 리스트에 추가
        if x < pivot:
            less.append(x)
        # 현재 원소가 피벗과 같으면 equal 리스트에 추가
        elif x == pivot:
            equal.append(x)
        # 현재 원소가 피벗보다 크면 greater 리스트에 추가
        else:
            greater.append(x)

    # 재귀적으로 less와 greater 부분을 정렬하고,
    # 정렬된 결과를 less + equal + greater 순서로 합쳐 반환
    return quick_sort(less) + equal + quick_sort(greater)


# ----------------------------------------------------------------------
# 아래는 위에서 만든 quick_sort 함수를 직접 실행해 보는 예시 코드입니다.
# ----------------------------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42, 9, 27]

    # 퀵소트 함수 호출 → 정렬된 리스트 반환
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트:", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 설명 (요약)

1. **기본 종료 조건**  
   `len(arr) <= 1` 일 때는 이미 정렬된 상태이므로 바로 반환합니다.

2. **피벗 선택**  
   간단히 배열의 마지막 요소(`arr[-1]`)를 피벗으로 잡았습니다.  
   (실제 구현에서는 무작위 선택 혹은 중간값 선택 등으로 최악의 경우를 회피할 수 있습니다.)

3. **분할 단계**  
   `less`, `equal`, `greater` 세 리스트에 각각 `피벗보다 작은`, `피벗과 같은`, `피벗보다 큰` 원소들을 나눠 담습니다.

4. **재귀 호출**  
   `less`와 `greater` 부분에 대해 다시 `quick_sort`를 호출해 정렬하고,
   `equal` 리스트(피벗 자체)와 합쳐 최종 정렬 결과를 반환합니다.

5. **메인 실행**  
   `__name__ == "__main__"` 블록에서 샘플 리스트를 정렬하고 결과를 출력합니다.
