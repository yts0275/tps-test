아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 줄마다 어떤 역할을 하는지 상세히 주석을 달아두었으니, 학습하거나 그대로 사용하셔도 됩니다.

```python
# -*- coding: utf-8 -*-          # 파일 최상단에 UTF-8 인코딩을 명시 (한글 주석을 위해)
# 퀵소트(Quick Sort) 구현 예시

def quick_sort(arr):
    """
    재귀적으로 배열을 정렬하는 퀵소트 함수.
    매개변수
        arr : 정렬하고자 하는 리스트(복사본을 반환)
    반환값
        정렬된 새로운 리스트
    """
    # 원본 리스트가 비었거나 원소가 하나이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                         # 기저 사례(base case)

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                        # 피벗은 현재 구간의 마지막 원소

    # 피벗보다 작은 원소들을 저장할 리스트
    left = []                              # 피벗보다 작거나 같은 값을 담을 리스트
    # 피벗보다 큰 원소들을 저장할 리스트
    right = []                             # 피벗보다 큰 값을 담을 리스트

    # 피벗을 제외한 나머지 원소들을 순회하면서 left와 right에 나눠 담는다
    for element in arr[:-1]:               # 마지막 원소(피벗)를 제외하고 순회
        if element <= pivot:               # 피벗보다 작거나 같은 경우
            left.append(element)           # left 리스트에 추가
        else:                              # 피벗보다 큰 경우
            right.append(element)          # right 리스트에 추가

    # 재귀 호출을 통해 left와 right 부분을 각각 정렬하고,
    # 정렬된 left + 피벗 + 정렬된 right 순으로 합쳐 최종 결과 반환
    return quick_sort(left) + [pivot] + quick_sort(right)
    # left 부분이 재귀적으로 정렬되고,
    # 피벗은 한 번만 삽입되며,
    # right 부분도 재귀적으로 정렬된 뒤 병합된다.

# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90]

    # 퀵소트 함수를 호출하여 정렬된 리스트를 얻는다
    sorted_list = quick_sort(unsorted_list)

    # 결과를 화면에 출력
    print("원본 리스트 :", unsorted_list)   # 원본 리스트는 변경되지 않음
    print("정렬된 리스트:", sorted_list)   # 퀵소트 결과가 출력됨
```

### 코드 설명
1. **기저 사례** – 리스트 길이가 0 또는 1이면 그대로 반환합니다. 재귀가 끝나는 조건입니다.  
2. **피벗 선택** – 가장 간단하게 마지막 요소를 피벗으로 잡았습니다. (다른 전략도 가능)  
3. **분할 과정** – 피벗을 기준으로 `left`와 `right` 두 리스트에 원소를 나눕니다.  
4. **재귀 호출** – `left`와 `right` 각각에 `quick_sort`를 다시 적용합니다.  
5. **병합** – 정렬된 `left` + 피벗 + 정렬된 `right` 순으로 연결해 최종 정렬 결과를 반환합니다.  

이 구현은 **새로운 리스트를 만들어 반환**하므로 원본 리스트(`unsorted_list`)는 그대로 유지됩니다.  
필요에 따라 **제자리(in‑place) 버전**이나 **피벗 선택 전략**을 바꾸어 성능을 최적화할 수도 있습니다.
