아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 코드입니다.  
각 줄마다 한국어 주석을 달아 동작 흐름을 상세히 설명했습니다.

```python
# 퀵소트를 수행하는 함수
def quick_sort(arr):
    # 배열이 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)으로 사용할 값을 배열의 마지막 요소로 선택
    pivot = arr[-1]

    # 피벗보다 작은 요소들을 저장할 리스트
    left = []
    # 피벗보다 큰 요소들을 저장할 리스트
    right = []
    # 피벗과 값이 같은(중복된) 요소들을 저장할 리스트
    equal = [pivot]   # 피벗 자체를 미리 equal 리스트에 넣어 둠

    # 배열의 마지막 요소(피벗)를 제외한 나머지 요소들을 순회
    for element in arr[:-1]:
        if element < pivot:        # 피벗보다 작으면 left 리스트에 추가
            left.append(element)
        elif element > pivot:      # 피벗보다 크면 right 리스트에 추가
            right.append(element)
        else:                      # 피벗과 값이 같으면(equal) 리스트에 추가
            equal.append(element)

    # 재귀적으로 left와 right 부분을 정렬한 뒤,
    # left + equal + right 순서로 합쳐 최종 정렬된 리스트를 반환
    return quick_sort(left) + equal + quick_sort(right)


# ----------------------------------------------------------------------
# ---------------------- 사용 예시 (테스트) ---------------------------
# ----------------------------------------------------------------------
if __name__ == "__main__":
    # 정렬할 샘플 리스트
    sample = [33, 10, 55, 71, 29, 3, 18, 90, 42, 33]

    # 퀵소트 함수 호출 및 결과 저장
    sorted_sample = quick_sort(sample)

    # 정렬 결과 출력
    print("원본 리스트 :", sample)
    print("정렬된 리스트 :", sorted_sample)
```

### 코드 설명
1. **기본 종료 조건**  
   `len(arr) <= 1` 일 때는 더 이상 분할할 필요가 없으므로 그대로 반환합니다.

2. **피벗 선택**  
   여기서는 편의상 배열의 마지막 요소를 피벗으로 사용했습니다.  
   (다른 전략—예: 무작위 선택—도 가능)

3. **분할 단계**  
   - `left` : 피벗보다 작은 값들  
   - `right`: 피벗보다 큰 값들  
   - `equal`: 피벗과 같은 값들 (중복을 처리)

4. **재귀 호출**  
   `quick_sort(left)`와 `quick_sort(right)`를 각각 정렬한 뒤,  
   `left + equal + right` 순서로 결합해 전체 정렬 결과를 만든다.

5. **시간 복잡도**  
   - 평균 O(N log N)  
   - 최악 O(N²) (피벗이 최솟값/최댓값일 때)  

6. **공간 복잡도**  
   재귀 호출과 리스트 복사 때문에 O(N) 정도의 추가 메모리를 사용합니다.

필요에 따라 피벗 선택 방식을 바꾸거나, 제자리(in‑place) 버전으로 구현하면 메모리 사용량을 줄일 수 있습니다. 즐거운 코딩 되세요!
