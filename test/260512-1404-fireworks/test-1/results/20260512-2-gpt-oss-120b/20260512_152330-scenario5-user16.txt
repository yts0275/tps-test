아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 어떤 역할을 하는지 이해하기 쉽도록 한글 주석을 달아두었습니다.  
필요에 따라 `list` 대신 `array` 혹은 다른 컬렉션에도 그대로 적용할 수 있습니다.

```python
# 퀵소트 구현 : 재귀 호출 버전
def quick_sort(arr):
    """입력된 리스트 arr 를 제자리(in‑place)에서 정렬하고, 정렬된 리스트를 반환한다."""
    
    # 0. 리스트가 비어 있거나 원소가 1개뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 1. 피벗(pivot) 선택 : 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                     # 피벗 값 저장
    
    # 2. 피벗보다 작은 요소들을 저장할 리스트와, 큰 요소들을 저장할 리스트를 만든다
    left = []   # 피벗보다 작은 값들을 모아둘 리스트
    right = []  # 피벗보다 큰 값들을 모아둘 리스트
    
    # 3. 피벗을 제외한 나머지 요소들을 순회하면서 left / right 리스트에 분배
    for element in arr[:-1]:            # 마지막 요소(피벗)를 제외하고 모두 검사
        if element <= pivot:            # 피벗보다 작거나 같으면 left 리스트에
            left.append(element)
        else:                           # 피벗보다 크면 right 리스트에
            right.append(element)
    
    # 4. left와 right 리스트에 대해 각각 재귀적으로 quick_sort 를 호출
    #    이렇게 하면 sub‑list 들도 같은 방식으로 정렬된다.
    sorted_left = quick_sort(left)      # 왼쪽 파티션 정렬
    sorted_right = quick_sort(right)    # 오른쪽 파티션 정렬
    
    # 5. 정렬된 left 파티션 + 피벗 + 정렬된 right 파티션을 합쳐서 최종 결과 반환
    return sorted_left + [pivot] + sorted_right


# ------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]
    print("정렬 전 :", unsorted)
    
    # quick_sort 함수는 새로운 리스트를 반환하므로 원본을 그대로 두고 사용 가능
    sorted_list = quick_sort(unsorted)
    print("정렬 후 :", sorted_list)

    # 원본 리스트를 제자리에서 바꾸고 싶다면 아래와 같이 구현할 수도 있음
    # (이 경우에는 추가적인 메모리를 거의 사용하지 않음)
    def quick_sort_inplace(arr, low, high):
        """in‑place 퀵소트: low~high 구간을 정렬한다."""
        if low < high:
            # 파티션 과정: 피벗을 기준으로 좌우를 분리하고 피벗의 최종 위치를 반환
            pivot_index = partition(arr, low, high)
            # 피벗 왼쪽 구간을 재귀 정렬
            quick_sort_inplace(arr, low, pivot_index - 1)
            # 피벗 오른쪽 구간을 재귀 정렬
            quick_sort_inplace(arr, pivot_index + 1, high)

    def partition(arr, low, high):
        """피벗을 배열의 마지막 요소로 잡고, 피벗보다 작은 요소를 앞쪽으로 이동한다."""
        pivot = arr[high]               # 피벗 선택
        i = low - 1                     # i는 피벗보다 작은 마지막 인덱스
        for j in range(low, high):      # 피벗을 제외한 구간을 순회
            if arr[j] <= pivot:         # 현재 요소가 피벗보다 작거나 같으면
                i += 1                  # i를 하나 늘리고
                arr[i], arr[j] = arr[j], arr[i]   # 그 요소를 앞쪽(i 위치)으로 스와핑
        # 모든 요소가 검사되면 피벗을 i+1 위치와 교환해 최종 정렬 위치 확보
        arr[i + 1], arr[high] = arr[high], arr[i + 1]
        return i + 1                    # 피벗이 최종적으로 자리 잡은 인덱스 반환

    # in‑place 버전 사용 예시
    data = [33, 10, 55, 71, 29, 3, 18, 42]
    print("\n[in‑place] 정렬 전 :", data)
    quick_sort_inplace(data, 0, len(data) - 1)
    print("[in‑place] 정렬 후 :", data)
```

### 코드 설명 요약
| 구분 | 핵심 아이디어 |
|------|----------------|
| **재귀 버전** | 피벗을 기준으로 리스트를 `left`(작음)와 `right`(큼)로 나누고, 각각을 다시 `quick_sort` 로 정렬 후 합친다. |
| **in‑place 버전** | 별도의 `left/right` 리스트를 만들지 않고, 배열 내부에서 인덱스 교환을 통해 피벗 위치를 찾아낸 뒤 재귀적으로 구간을 정렬한다. 메모리 사용량을 최소화한다. |
| **시간 복잡도** | 평균 O(N log N), 최악 O(N²) (피벗 선택이 좋지 않을 경우) |
| **공간 복잡도** | 재귀 호출 스택을 제외하면 O(1) (in‑place) / O(N) (리스트 복사 버전) |

필요에 따라 **피벗 선택 전략**을 `첫 번째`, `중간`, `무작위` 등으로 바꾸면 최악 상황을 어느 정도 완화할 수 있습니다. 원하는 형태에 맞게 코드를 수정해 사용해 보세요! 🚀
