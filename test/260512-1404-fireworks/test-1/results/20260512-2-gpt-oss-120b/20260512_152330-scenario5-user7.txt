아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 어떤 역할을 하는지 상세히 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 것입니다.

```python
# === 퀵소트 구현 (in‑place 버전) ===
# 배열(arr)을 직접 정렬하고, left와 right는 현재 정렬하고 있는 구간의 양 끝 인덱스를 의미합니다.
def quick_sort(arr, left, right):
    # 1️⃣ 기저 조건: 구간의 길이가 1 이하이면 (left >= right) 더 이상 정렬할 필요가 없습니다.
    if left >= right:
        return

    # 2️⃣ 피벗 선택: 여기서는 구간의 가장 오른쪽 요소를 피벗으로 삼습니다.
    pivot = arr[right]

    # 3️⃣ i는 피벗보다 작거나 같은 요소들을 모아두는 “경계” 인덱스 역할을 합니다.
    i = left - 1

    # 4️⃣ j는 left부터 right‑1까지 순회하면서 현재 요소와 피벗을 비교합니다.
    for j in range(left, right):
        # 현재 요소(arr[j])가 피벗보다 작거나 같으면,
        if arr[j] <= pivot:
            # i를 하나 증가시키고, arr[i]와 arr[j]를 교환해
            # 작은 값들을 왼쪽으로 모아 둡니다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 5️⃣ 모든 요소를 검사한 뒤, 피벗을 (i+1)번째 위치와 교환합니다.
    # 이제 피벗은 정확히 왼쪽에 작은 값들, 오른쪽에 큰 값들이 오도록 위치합니다.
    arr[i + 1], arr[right] = arr[right], arr[i + 1]

    # 6️⃣ 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 재귀적으로 정렬합니다.
    quick_sort(arr, left, i)        # 피벗 왼쪽 부분 (작은 값들)
    quick_sort(arr, i + 2, right)   # 피벗 오른쪽 부분 (큰 값들)


# === 사용 예시 ===
if __name__ == "__main__":
    # 정렬할 예시 리스트
    data = [33, 10, 55, 71, 29, 3, 18, 42]

    # 정렬 전 출력
    print("정렬 전:", data)

    # 전체 리스트를 정렬 (인덱스 0부터 len(data)-1까지)
    quick_sort(data, 0, len(data) - 1)

    # 정렬 후 출력
    print("정렬 후:", data)
```

### 코드 흐름 요약
1. **기저 조건**(`left >= right`)에 도달하면 재귀 호출을 멈추고 반환합니다.  
2. 피벗을 **가장 오른쪽 요소**로 잡고, `i`를 피벗보다 작은 값들의 마지막 위치로 사용합니다.  
3. `j`를 통해 구간을 순회하며, 피벗보다 작거나 같은 값이 나오면 `i`를 증가시키고 해당 값을 `arr[i]`와 교환합니다.  
4. 순회가 끝난 뒤 피벗을 `i+1` 위치와 교환해 피벗을 정확히 제자리(`partition`)에 놓습니다.  
5. 피벗을 기준으로 **좌·우 구간**을 각각 재귀 호출해 정렬을 진행합니다.  

이렇게 하면 **평균 시간 복잡도 O(N log N)**, **최악 시간 복잡도 O(N²)**(피벗 선택이 최악인 경우)인 퀵소트를 구현할 수 있습니다.
