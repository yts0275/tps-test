아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 무엇을 하는지 상세히 주석을 달아 두었으니, 흐름을 따라가며 이해하기 쉽도록 구성되었습니다.

```python
# -*- coding: utf-8 -*-

def quick_sort(arr):
    """
    퀵소트 알고리즘을 사용해 리스트 arr을 정렬하고 새 리스트를 반환한다.
    재귀 호출을 통해 원소를 작은 부분 문제로 나누어 정렬한다.
    """
    # 1️⃣ 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2️⃣ 피벗(pivot) 선택: 여기서는 리스트의 마지막 원소를 피벗으로 삼는다.
    pivot = arr[-1]                 # 피벗은 비교 기준이 되는 값
    
    # 3️⃣ 피벗보다 작은 원소들을 담을 리스트와
    #    피벗보다 크거나 같은 원소들을 담을 리스트를 각각 만든다.
    left = []   # 피벗보다 작은 원소들
    right = []  # 피벗보다 크거나 같은 원소들
    
    # 4️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left와 right에 분류한다.
    for element in arr[:-1]:        # 마지막 원소(피벗)를 제외하고 순회
        if element < pivot:
            left.append(element)    # 피벗보다 작으면 left에 추가
        else:
            right.append(element)   # 피벗보다 크거나 같으면 right에 추가
    
    # 5️⃣ 재귀적으로 left와 right를 각각 정렬한다.
    #    정렬된 left + 피벗 + 정렬된 right 순서로 합쳐 최종 결과를 만든다.
    return quick_sort(left) + [pivot] + quick_sort(right)


# ------------------------------
# 사용 예시 (테스트용)
if __name__ == "__main__":
    # 정렬되지 않은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90, 42]
    
    # 퀵소트를 이용해 정렬
    sorted_list = quick_sort(unsorted_list)
    
    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소(`arr[-1]`)를 피벗으로 사용.  
3. **분할** – 피벗을 기준으로 두 개의 서브 리스트(`left`, `right`)를 만든다.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 `quick_sort`를 재귀적으로 호출.  
5. **합치기** – 정렬된 `left` + 피벗 + 정렬된 `right`를 이어 최종 정렬 결과를 만든다.

이와 같이 퀵소트는 “분할‑정복(divide‑and‑conquer)” 전략을 활용해 평균 *O(n log n)* 시간 복잡도를 달성합니다. (최악의 경우 *O(n²)*이지만, 피벗 선택을 무작위화하거나 median‑of‑three와 같은 기법을 쓰면 실제 사용에서는 거의 *O(n log n)*에 가깝게 동작합니다.)
