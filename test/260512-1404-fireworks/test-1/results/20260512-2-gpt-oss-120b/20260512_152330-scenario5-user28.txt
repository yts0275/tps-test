아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시이며, 각 줄마다 한국어 주석을 달아 이해를 돕도록 했습니다.  
코드 자체는 `quick_sort(arr)` 함수 하나만 있으면 되며, 재귀 호출을 이용해 배열을 계속 분할하고 정렬합니다.

```python
# quick_sort 함수 정의: 정렬하고 싶은 리스트(arr)를 인자로 받음
def quick_sort(arr):
    # 리스트의 길이가 0이거나 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 첫 번째 요소를 피벗으로 사용
    pivot = arr[0]

    # 피벗보다 작은 요소들을 모아 놓을 리스트 (왼쪽 파티션)
    left = []

    # 피벗과 같은 값을 모아 놓을 리스트 (같은 값들을 모아 두면 중복 처리에 유리)
    middle = []

    # 피벗보다 큰 요소들을 모아 놓을 리스트 (오른쪽 파티션)
    right = []

    # 리스트 전체를 순회하면서 각각의 파티션에 요소들을 배분
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left 파티션에 추가
            left.append(x)
        elif x == pivot:       # 피벗과 같으면 middle 파티션에 추가
            middle.append(x)
        else:                  # 피벗보다 크면 right 파티션에 추가
            right.append(x)

    # 재귀적으로 left 파티션과 right 파티션을 정렬하고,
    # middle 파티션은 이미 정렬된 상태이므로 그대로 사용
    # 최종적으로 left + middle + right 순서로 이어붙여 반환
    return quick_sort(left) + middle + quick_sort(right)


# ------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 10, 42]

    # quick_sort 함수를 호출하여 정렬된 결과를 얻음
    sorted_arr = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트:", sorted_arr)
```

### 코드 흐름 요약
1. **기본 종료 조건** – 리스트 길이가 1 이하이면 그대로 반환 (이미 정렬된 상태).  
2. **피벗 선택** – 첫 번째 요소(`arr[0]`)를 기준값으로 삼아 분할.  
3. **분할 단계** – 리스트를 순회하면서 피벗보다 작은(`left`), 같은(`middle`), 큰(`right`) 요소들로 나눔.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 `quick_sort`를 다시 실행해 정렬.  
5. **병합 단계** – 정렬된 `left`, 원래 피벗과 같은 값들(`middle`), 정렬된 `right`를 차례대로 합쳐 최종 결과 반환.  

이렇게 구현된 퀵소트는 **평균 시간 복잡도 O(N log N)**, **최악 경우 O(N²)** (피벗 선택이 좋지 않을 때)이며, **추가 메모리 사용량이 O(N)** (새 리스트를 만들어 파티션을 저장)인 **비인플레이스(in‑place) 버전**입니다. 필요에 따라 피벗 선택 전략을 바꾸거나 **제자리(in‑place) 버전**으로 최적화할 수 있습니다.
