아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 어떤 역할을 하는지 상세히 주석을 달아두었으니, 공부하시거나 바로 사용하실 때 참고하시기 바랍니다.

```python
def quick_sort(arr):                     # quick_sort 함수 정의 (정렬할 리스트를 매개변수로 받음)
    """
    재귀적으로 퀵소트를 수행하여 정렬된 새로운 리스트를 반환한다.
    """
    if len(arr) <= 1:                    # 리스트의 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                        # 그대로 반환한다

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택 : 리스트 중간 요소를 선택
    left = []                            # 피벗보다 작은 요소들을 담을 리스트 초기화
    middle = []                          # 피벗과 같은 요소들을 담을 리스트 초기화
    right = []                           # 피벗보다 큰 요소들을 담을 리스트 초기화

    for x in arr:                        # 리스트의 모든 요소를 순회하면서
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x == pivot:                  # 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가
        else:                             # 피벗보다 크면
            right.append(x)               # right 리스트에 추가

    # 재귀 호출을 통해 left와 right 부분을 각각 정렬한 뒤,
    # 정렬된 left, middle(피벗), 정렬된 right 를 순서대로 이어 붙인다.
    return quick_sort(left) + middle + quick_sort(right)   # 결과 리스트 반환


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 아래 코드를 수행
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]   # 정렬되지 않은 예시 리스트
    sorted_arr = quick_sort(unsorted)               # quick_sort 함수를 호출하여 정렬
    print("정렬 전 :", unsorted)                     # 정렬 전 리스트 출력
    print("정렬 후 :", sorted_arr)                   # 정렬 후 리스트 출력
```

### 코드 설명 (주석 외 추가 설명)

1. **기본 구조**  
   - `quick_sort` 함수는 입력 리스트를 직접 수정하지 않고, 새로운 정렬된 리스트를 반환합니다.  
   - 재귀 호출을 이용해 `left`와 `right` 서브 리스트를 각각 정렬하고, `middle`(피벗)과 합쳐 최종 결과를 만든다.

2. **피벗 선택**  
   - 여기서는 리스트 중간 요소(`len(arr)//2`)를 피벗으로 사용했으며, 구현에 따라 첫 번째 요소, 랜덤 요소 등으로 바꿀 수 있습니다.

3. **시간 복잡도**  
   - 평균: **O(N log N)**  
   - 최악(이미 정렬된 경우 등): **O(N²)** (피벗 선택을 개선하면 최악 상황을 완화할 수 있음)

4. **특징**  
   - 파이썬 리스트 슬라이싱을 사용하지 않아 메모리 복사 비용을 최소화했습니다.  
   - `left`, `middle`, `right` 로 분리하고 재귀 호출을 하는 방식이 직관적이며, 학습용으로 적합합니다.

필요에 따라 피벗 선택 전략을 바꾸거나, 제자리(in‑place) 퀵소트 형태로 변형해서 사용할 수도 있습니다. 즐거운 코딩 되세요!
