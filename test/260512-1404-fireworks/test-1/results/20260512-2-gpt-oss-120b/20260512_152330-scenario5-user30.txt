아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘 예시입니다.  
각 코드 줄마다 한글 주석을 달아 동작 흐름을 상세히 설명했습니다.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    """
    입력: 정렬되지 않은 리스트 arr
    출력: 정렬된 리스트 (새로운 리스트를 반환)
    """
    # 리스트가 비었거나 원소가 하나만 있으면 이미 정렬된 상태이므로 바로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 원소를 피벗으로 사용
    pivot = arr[-1]                # 피벗은 현재 하위 리스트의 마지막 값
    left = []                      # 피벗보다 작은 원소들을 담을 리스트
    right = []                     # 피벗보다 큰 원소들을 담을 리스트
    middle = []                    # 피벗과 같은 값이 여러 개일 경우를 대비한 리스트

    # 피벗을 제외한 나머지 원소들을 순회하면서 left, middle, right에 분류
    for x in arr[:-1]:             # 마지막 원소(피벗)는 제외하고 탐색
        if x < pivot:              # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:            # 피벗보다 크면 right에 추가
            right.append(x)
        else:                      # 피벗과 같으면 middle에 추가 (중복 처리)
            middle.append(x)

    # 재귀적으로 left와 right 부분을 정렬하고,
    # middle 리스트와 피벗을 합쳐 최종 정렬된 리스트를 만든다
    return (
        quick_sort(left)           # left 부분을 정렬
        + middle + [pivot]         # 같은 값은 middle에 모아두고, 피벗은 마지막에 삽입
        + quick_sort(right)        # right 부분을 정렬
    )

# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 44, 55]   # 정렬되지 않은 리스트
    sorted_arr = quick_sort(unsorted)               # 퀵소트 함수 호출
    print("정렬 전:", unsorted)                     # 정렬 전 출력
    print("정렬 후:", sorted_arr)                   # 정렬 후 출력
```

### 코드 설명 (줄별 요약)

|줄 번호|설명|
|-------|----|
|1|`quick_sort` 함수를 정의합니다.|
|3‑9|함수 설명 문자열(Docstring) – 입력·출력에 대한 간단한 설명.|
|11‑12|리스트 길이가 0 또는 1이면 이미 정렬된 것이므로 그대로 반환합니다.|
|15|피벗을 리스트 마지막 원소(`arr[-1]`)로 선택합니다.|
|16‑18|피벗보다 작은(`left`), 큰(`right`), 같은(`middle`) 값을 각각 저장할 빈 리스트를 만든다.|
|21‑27|피벗을 제외한 모든 원소를 순회하면서 세 리스트에 분류합니다.|
|30‑32|`left`와 `right`에 대해 재귀적으로 `quick_sort`를 호출해 각각 정렬하고, `middle`과 피벗을 사이에 끼워 최종 리스트를 만든다.|
|38‑44|`__main__` 블록: 직접 실행할 때 테스트용 리스트를 만든 뒤 정렬 전·후를 출력합니다.|

### 핵심 아이디어
1. **분할(Divide)** – 피벗을 기준으로 리스트를 `left`, `middle`, `right`로 세 부분으로 나눈다.  
2. **정복(Conquer)** – `left`와 `right`에 대해 같은 과정을 재귀적으로 수행한다.  
3. **합병(Combine)** – 정렬된 `left`, `middle + [pivot]`, 정렬된 `right`를 차례대로 이어 붙인다.

이 구현은 **인-플레이스**(in‑place) 방식이 아니라 새로운 리스트를 반환하는 형태이지만, 가독성이 높고 각 단계별 동작을 쉽게 확인할 수 있어 학습용으로 적합합니다. 필요에 따라 `left`와 `right`를 인덱스로 직접 조작해 메모리 사용량을 줄이는 인‑플레이스 버전으로 변형할 수도 있습니다.
