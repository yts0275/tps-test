아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 한국어 주석을 달아 동작을 상세히 설명했습니다.  

```python
# quick_sort.py

def quick_sort(arr):
    """
    리스트 arr 를 제자리(in‑place) 퀵소트로 정렬하고,
    정렬된 리스트를 반환한다.
    """
    # 정렬을 수행할 헬퍼 함수 호출 (배열, 시작 인덱스, 끝 인덱스)
    _quick_sort(arr, 0, len(arr) - 1)
    return arr                     # 정렬이 끝난 뒤 arr 를 반환

def _quick_sort(arr, low, high):
    """
    low 에서 high 까지 범위에 대해 재귀적으로 퀵소트를 수행한다.
    """
    if low < high:                 # 범위가 하나 이하라면 이미 정렬된 것이므로 종료
        # 파티션을 수행하고 피벗이 최종 위치에 놓인 인덱스를 반환받는다.
        pivot_index = _partition(arr, low, high)
        # 피벗 왼쪽 부분(피벗보다 작은 값들)에 대해 재귀 호출
        _quick_sort(arr, low, pivot_index - 1)
        # 피벗 오른쪽 부분(피벗보다 큰 값들)에 대해 재귀 호출
        _quick_sort(arr, pivot_index + 1, high)

def _partition(arr, low, high):
    """
    피벗을 기준으로 배열을 두 구역으로 나눈다.
    - 피벗보다 작은 값들은 왼쪽에,
    - 피벗보다 큰 값들은 오른쪽에 배치한다.
    최종적으로 피벗은 정확히 자신의 정렬된 위치에 놓인다.
    """
    pivot = arr[high]              # 가장 오른쪽 요소를 피벗으로 선택
    i = low - 1                    # i 는 "피벗보다 작은 구역"의 마지막 인덱스

    # low 부터 high-1 까지 순회하면서 각 원소를 피벗과 비교
    for j in range(low, high):
        if arr[j] <= pivot:        # 현재 원소가 피벗보다 작거나 같다면
            i += 1                 # 작은 구역을 한 칸 확대하고
            arr[i], arr[j] = arr[j], arr[i]   # 해당 원소를 작은 구역 끝으로 이동

    # 모든 원소를 확인했으므로 피벗을 작은 구역 바로 다음 위치(i+1)와 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                   # 피벗이 최종적으로 들어간 인덱스를 반환

# ----------------------------------------------------------------------
# 아래 코드는 직접 실행해 볼 수 있는 간단한 테스트 예시입니다.
if __name__ == "__main__":
    sample = [33, 10, 55, 71, 29, 3, 18, 90]
    print("정렬 전:", sample)
    quick_sort(sample)             # 정렬 수행 (제자리 정렬이므로 반환값을 사용할 필요 없음)
    print("정렬 후:", sample)
```

### 코드 흐름 요약
1. `quick_sort` 함수가 호출되면 `_quick_sort` 를 통해 전체 배열을 재귀적으로 나눈다.  
2. `_partition` 함수는 현재 구간에서 피벗을 기준으로 **작은 값**과 **큰 값**을 분리하고, 피벗을 정확한 위치에 배치한다.  
3. 피벗을 기준으로 왼쪽·오른쪽 두 구간에 대해 다시 `_quick_sort` 를 호출하면서 전체 배열이 정렬될 때까지 반복한다.  

이 구현은 **제자리 정렬**이며, 평균 시간 복잡도는 `O(n log n)`, 최악의 경우(`이미 정렬된 배열` 등) `O(n²)` 가 됩니다. 필요에 따라 피벗 선택 전략(예: 무작위 피벗, median‑of‑three 등)으로 최악의 경우를 완화할 수 있습니다.
