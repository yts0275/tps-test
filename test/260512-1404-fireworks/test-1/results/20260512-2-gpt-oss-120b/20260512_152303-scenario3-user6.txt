아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 무슨 역할을 하는지 자세히 설명하는 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 것입니다.

```python
# 퀵소트를 구현하기 위한 파티션 함수
def partition(arr, low, high):
    pivot = arr[high]               # 마지막 원소를 피벗(pivot)으로 선택
    i = low - 1                     # i는 피벗보다 작은 원소들의 마지막 인덱스

    # low부터 high-1까지는 피벗보다 작거나 같은지를 검사
    for j in range(low, high):
        if arr[j] <= pivot:         # 현재 원소가 피벗 이하라면
            i += 1                  # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]   # 작은 원소를 앞쪽(i)으로 스와프
            # 이제 arr[low..i] 구역에 피벗 이하 원소들이 모여 있다

    # 피벗을 정렬된 위치에 배치 (i+1 위치가 피벗의 최종 위치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                    # 피벗의 최종 인덱스를 반환

# 재귀적으로 퀵소트를 수행하는 함수
def quick_sort(arr, low, high):
    if low < high:                  # 정렬할 구간이 하나 이상의 원소를 포함할 때
        pi = partition(arr, low, high)   # 파티션 수행 → 피벗 위치 pi 반환
        quick_sort(arr, low, pi - 1)      # 피벗 왼쪽 구간을 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)     # 피벗 오른쪽 구간을 재귀적으로 정렬
    # else: 구간이 비어 있거나 원소가 하나라면 정렬할 필요가 없음

# 사용 예시
if __name__ == "__main__":
    data = [34, 7, 23, 32, 5, 62]   # 정렬하고 싶은 리스트
    print("정렬 전:", data)         # 정렬 전 출력
    quick_sort(data, 0, len(data) - 1)   # 전체 리스트를 퀵소트
    print("정렬 후:", data)         # 정렬 후 출력
```

### 코드 흐름 요약
1. **partition**  
   - 피벗을 기준으로 작은 원소와 큰 원소를 구분해 배열을 두 부분으로 나눈다.  
   - 최종적으로 피벗을 정확한 위치에 놓고, 그 인덱스를 반환한다.

2. **quick_sort**  
   - `low < high` 조건을 만족하는 구간에 대해 `partition`을 수행한다.  
   - 피벗을 기준으로 왼쪽·오른쪽 구간을 각각 재귀 호출해 정렬한다.  

3. **실행**  
   - `if __name__ == "__main__":` 블록에서 예시 리스트를 정렬하고, 전후 결과를 출력한다.

이 구현은 **제자리(in‑place) 정렬**이며, 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(`정렬이 이미 되어 있거나 역순인 경우`) `O(N²)`이지만 피벗을 무작위로 선택하거나 ‘median‑of‑three’ 기법을 쓰면 최악 상황을 크게 완화할 수 있습니다.
