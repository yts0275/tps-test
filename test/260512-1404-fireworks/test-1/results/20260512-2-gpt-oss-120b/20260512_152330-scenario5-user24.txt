아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 한국어 주석을 달아 동작 방식을 단계별로 설명했습니다.  

```python
# quick_sort 함수 정의
def quick_sort(arr):
    # 배열이 비었거나 원소가 하나만 있으면 그대로 반환 (재귀 종료 조건)
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 원소들을 담을 리스트
    less = []
    # 피벗과 같은 원소들을 담을 리스트 (피벗 자체도 포함)
    equal = []
    # 피벗보다 큰 원소들을 담을 리스트
    greater = []

    # 배열의 모든 원소를 검사하여 세 개의 리스트에 분류
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 less에
            less.append(x)
        elif x == pivot:       # 피벗과 같으면 equal에
            equal.append(x)
        else:                  # 피벗보다 크면 greater에
            greater.append(x)

    # 재귀적으로 less와 greater 부분을 정렬하고,
    # 정렬된 결과를 less + equal + greater 순서로 합쳐 반환
    return quick_sort(less) + equal + quick_sort(greater)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 리스트 정의
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42]

    # quick_sort 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("정렬 전:", unsorted_list)
    print("정렬 후:", sorted_list)
```

### 코드 흐름 요약
1. **기본 상황 처리** – 리스트 길이가 0 또는 1이면 더 이상 정렬할 필요가 없으므로 바로 반환합니다.  
2. **피벗 선택** – 여기서는 편의상 마지막 요소를 피벗으로 잡았습니다. (다른 선택 방법도 가능)  
3. **분할 과정** – 리스트를 `less`, `equal`, `greater` 세 구역으로 나눕니다.  
4. **재귀 호출** – `less`와 `greater` 구역을 각각 다시 `quick_sort`에 넘겨 정렬합니다.  
5. **결합** – 정렬된 `less`, 피벗을 포함한 `equal`, 정렬된 `greater`를 차례대로 이어 붙여 최종 결과를 반환합니다.  

이와 같이 한 줄씩 주석을 달아 놓으면 퀵소트가 어떻게 동작하는지 이해하는 데 도움이 될 것입니다. 필요에 따라 피벗 선택 방식을 무작위(`random.choice`)로 바꾸거나, 제자리(in‑place) 방식으로 구현하는 등 다양한 변형을 시도해 볼 수 있습니다. Happy coding!
