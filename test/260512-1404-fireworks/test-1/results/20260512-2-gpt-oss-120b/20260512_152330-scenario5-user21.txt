아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 줄마다 한글 주석을 달아 동작 흐름을 상세히 설명했습니다.  

```python
def quick_sort(arr):                     # 퀵소트를 수행하는 함수 정의, 입력은 정렬할 리스트
    if len(arr) <= 1:                    # 리스트 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr                        # 그대로 반환한다
                                           
    pivot = arr[len(arr) // 2]           # 피벗(pivot) 값 선택 → 리스트 중간 원소를 사용
                                           
    left = []                            # 피벗보다 작은 원소를 담을 리스트
    middle = []                          # 피벗과 같은 값을 담을 리스트 (중복 허용)
    right = []                           # 피벗보다 큰 원소를 담을 리스트
                                           
    for x in arr:                        # 입력 리스트의 모든 원소를 순회하면서
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x > pivot:                   # 피벗보다 크면
            right.append(x)               # right 리스트에 추가
        else:                             # 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가 (중복된 피벗도 보존)
                                           
    # 재귀적으로 left와 right 부분을 정렬하고, middle(피벗)과 합쳐서 반환
    return quick_sort(left) + middle + quick_sort(right)


# -------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 이 파일이 직접 실행될 때만 아래 코드 실행
    unsorted = [33, 10, 55, 71, 29, 33, 2, 99, 1]  # 정렬되지 않은 샘플 리스트
    sorted_arr = quick_sort(unsorted)    # quick_sort 함수 호출
    print("정렬 전:", unsorted)           # 정렬 전 리스트 출력
    print("정렬 후:", sorted_arr)         # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 중간 인덱스의 값을 피벗으로 사용해 평균적인 성능을 기대.  
3. **분할 단계** – 리스트를 `left`, `middle`, `right` 세 구역으로 나눔.  
4. **재귀 호출** – `left`와 `right` 구역에 대해 같은 과정을 반복.  
5. **병합 단계** – 정렬된 `left`, `middle`, `right`를 순서대로 이어 최종 결과 반환.

이 구현은 **읽기 쉬운 구조**와 **중복 피벗 처리**를 중점으로 작성했으며, 각 줄마다 주석을 달아 초보자도 이해하기 쉽도록 구성했습니다. 🚀
