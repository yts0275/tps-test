아래는 **Python** 으로 구현한 퀵소트(Quick Sort)이며, 각 줄마다 어떤 역할을 하는지 주석을 달아 두었습니다.  
코드 전체가 한눈에 들어오도록 변수 이름도 직관적으로 정했으니, 공부하거나 그대로 복사해 사용할 때 도움이 될 거예요.

```python
# 퀵소트 구현 --------------------------------------------------------------
def quicksort(arr):
    """
    재귀적으로 배열을 정렬하고 정렬된 새로운 리스트를 반환한다.
    - arr : 정렬하고 싶은 리스트(또는 리스트와 같은 시퀀스)
    """
    # 1. 정렬 대상이 0개 혹은 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선택: 여기서는 리스트의 중간 값을 피벗으로 잡는다
    pivot = arr[len(arr) // 2]

    # 3. 피벗보다 작은 요소들을 모아 left 리스트에 담는다
    left = [x for x in arr if x < pivot]

    # 4. 피벗과 같은 값을 가진 요소들을 모아 middle 리스트에 담는다
    #    (피벗이 중복될 경우를 대비해 별도 리스트에 보관)
    middle = [x for x in arr if x == pivot]

    # 5. 피벗보다 큰 요소들을 모아 right 리스트에 담는다
    right = [x for x in arr if x > pivot]

    # 6. left와 right 부분을 각각 재귀적으로 정렬하고,
    #    middle(피벗)과 합쳐서 최종 정렬 결과를 만든다
    return quicksort(left) + middle + quicksort(right)


# -------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 원본 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트를 호출하여 정렬된 리스트를 얻는다
    sorted_list = quicksort(unsorted)

    # 결과를 화면에 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트:", sorted_list)
```

### 코드 설명 (주석 외에 추가 설명)
1. **기본 원리**  
   * 피벗(pivot)을 기준으로 리스트를 `left`, `middle`, `right` 세 파트로 나눈 뒤,  
     `left`와 `right`를 각각 재귀 호출해 다시 정렬합니다.  
   * 이렇게 나눈 뒤 합치면 전체가 정렬된 리스트가 됩니다.

2. **시간 복잡도**  
   * 평균 O(n log n) – 피벗이 리스트를 거의 반씩 나눌 때 가장 빠릅니다.  
   * 최악 O(n²) – 이미 정렬된 리스트에 대해 가장 작은(또는 가장 큰) 값을 피벗으로 선택하면 발생합니다.  
   * 여기서는 중간값을 피벗으로 잡아 일반적인 경우를 조금이라도 완화하려고 했습니다.

3. **공간 복잡도**  
   * 리스트를 새로 만들어서 반환하므로 **O(n)** (추가 메모리) 가 필요합니다.  
   * 제자리(in‑place) 퀵소트를 원한다면 인덱스를 직접 조작하는 버전을 구현해야 합니다.
