아래는 Python으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 동작을 설명하는 주석을 달아 두었으니, 흐름을 따라가며 이해하기 쉽습니다.

```python
# quick_sort 함수: 리스트와 정렬할 구간(start, end)을 인자로 받는다
def quick_sort(arr, start, end):
    # 구간이 하나 이하의 원소만 포함하면 이미 정렬된 상태이므로 바로 반환
    if start >= end:
        return

    # 피벗(pivot)으로 구간의 가장 오른쪽 원소를 선택한다
    pivot = arr[end]

    # i는 피벗보다 작거나 같은 원소들의 마지막 인덱스를 가리킨다
    i = start - 1

    # j는 시작 인덱스부터 피벗 바로 전까지 순회하며 원소들을 검사한다
    for j in range(start, end):
        # 현재 원소가 피벗보다 작거나 같으면 i를 하나 증가시키고,
        # 그 자리와 현재 원소를 교환한다 (작은 원소를 앞으로 모은다)
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 마지막으로 피벗을 i+1 위치와 교환한다.
    # 이제 피벗은 정확히 자신의 최종 위치에 있다.
    arr[i + 1], arr[end] = arr[end], arr[i + 1]

    # 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 재귀적으로 정렬한다
    quick_sort(arr, start, i)       # 피벗 왼쪽 부분
    quick_sort(arr, i + 2, end)     # 피벗 오른쪽 부분


# 예시 실행 코드: 사용자가 직접 리스트를 정렬해볼 수 있다
if __name__ == "__main__":
    # 정렬할 샘플 리스트
    sample = [33, 10, 55, 71, 29, 3, 18, 42]

    # 정렬 전 리스트 출력
    print("정렬 전:", sample)

    # quick_sort 함수를 전체 구간에 적용
    quick_sort(sample, 0, len(sample) - 1)

    # 정렬 후 리스트 출력
    print("정렬 후:", sample)
```

### 코드 흐름 요약
1. `quick_sort`는 재귀 함수이며, **피벗**을 선택해 **좌·우 구간**을 나눈다.  
2. `for` 루프를 돌면서 피벗보다 작거나 같은 원소들을 왼쪽으로 몰아준다.  
3. 피벗을 최종 위치(`i+1`)에 놓고, 그 왼쪽·오른쪽 구간을 각각 다시 `quick_sort` 호출해 정렬한다.  
4. 구간 크기가 1 이하가 되면(시작 인덱스 ≥ 끝 인덱스) 재귀 호출을 종료한다.  

이렇게 구현된 퀵소트는 평균 시간 복잡도 **O(N log N)**, 최악 경우 **O(N²)**(피벗 선택이 항상 최악일 때)이며, 제자리(in‑place) 정렬이므로 추가 메모리 사용이 거의 없습니다.
