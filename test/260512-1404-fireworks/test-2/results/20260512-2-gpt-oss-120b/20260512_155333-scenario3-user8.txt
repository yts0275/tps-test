아래는 **Python** 으로 구현한 퀵소트(Quick Sort)입니다.  
각 코드 라인마다 무엇을 하는지 상세히 주석을 달아 두었으니, 흐름을 따라가기에 도움이 될 것입니다.

```python
# quick_sort.py

def quick_sort(arr):
    """
    퀵소트를 이용해 리스트 arr를 정렬한 새로운 리스트를 반환합니다.
    원본 리스트는 변경되지 않으며, 재귀적으로 작동합니다.
    """
    # 1) 정렬이 필요 없는 경우(길이가 0 또는 1인 경우) 바로 반환
    if len(arr) <= 1:
        return arr

    # 2) 피벗(pivot) 선택
    #    여기서는 리스트의 가운데 원소를 피벗으로 사용합니다.
    #    (리스트 앞/뒤 원소를 사용해도 무방합니다.)
    pivot = arr[len(arr) // 2]

    # 3) 피벗보다 작은 원소들을 모아 left 리스트에 저장
    left = [x for x in arr if x < pivot]

    # 4) 피벗과 같은 값(중복값)을 모아 middle 리스트에 저장
    middle = [x for x in arr if x == pivot]

    # 5) 피벗보다 큰 원소들을 모아 right 리스트에 저장
    right = [x for x in arr if x > pivot]

    # 6) left와 right 부분을 각각 재귀적으로 정렬하고,
    #    정렬된 left + middle + 정렬된 right 를 합쳐 최종 결과 반환
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]

    # 퀵소트 함수를 호출해 정렬된 리스트를 얻음
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 이미 정렬된 상태이므로 그대로 반환합니다.  
2. **피벗 선택** – 현재 구현에서는 리스트의 가운데 원소를 피벗으로 잡았지만, 첫 번째 원소, 마지막 원소, 혹은 무작위 원소 등으로 바꿔도 됩니다.  
3. **분할 (Partition)** – 리스트를 `left`, `middle`, `right` 세 부분으로 나눕니다.  
   * `left` : 피벗보다 작은 원소  
   * `middle` : 피벗과 같은 원소(중복값 포함)  
   * `right` : 피벗보다 큰 원소  
4. **재귀 호출** – `left`와 `right` 부분을 각각 다시 `quick_sort`에 넘겨 정렬합니다.  
5. **합치기** – 정렬된 `left`, `middle`, 정렬된 `right`를 차례대로 이어붙여 최종 정렬 결과를 반환합니다.  

### 참고 사항
- **시간 복잡도**  
  * 평균·최선: **O(N log N)**  
  * 최악(이미 정렬된 리스트에 피벗을 첫/끝 원소로 선택) : **O(N²)**  
- **공간 복잡도**  
  * 리스트를 새로 만들어 반환하기 때문에 **O(N)** 의 추가 메모리를 사용합니다.  
  * 제자리(in‑place) 퀵소트를 구현하면 메모리 사용을 **O(log N)** (재귀 스택) 수준으로 줄일 수 있습니다.
