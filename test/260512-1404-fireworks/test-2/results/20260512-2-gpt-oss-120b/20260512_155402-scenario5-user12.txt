아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 무엇을 하는 코드인지 한국어 주석을 달아 두었습니다.

```python
# Quick Sort 함수 정의: arr는 정렬할 리스트, low는 시작 인덱스, high는 끝 인덱스
def quick_sort(arr, low, high):
    # 구간이 하나 이상의 원소를 포함할 때만 정렬 수행
    if low < high:
        # 파티션을 수행하고 피벗이 놓인 최종 인덱스를 반환
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, low, pi - 1)

        # 피벗 오른쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)


# 파티션 함수: 피벗을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽에 배치하고
# 피벗의 최종 위치 인덱스를 반환한다
def partition(arr, low, high):
    # 일반적으로 가장 오른쪽 원소를 피벗으로 선택
    pivot = arr[high]

    # i는 '피벗보다 작은 원소'들의 마지막 인덱스를 가리킴
    i = low - 1

    # low부터 high-1까지 순회하면서 피벗보다 작은 원소를 찾는다
    for j in range(low, high):
        # 현재 원소 arr[j]가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 한 칸 오른쪽으로 옮기고
            i += 1
            # 작은 원소와 현재 원소를 교환한다
            arr[i], arr[j] = arr[j], arr[i]

    # 마지막으로 피벗을 i+1 위치와 교환해 정렬을 완성한다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 최종적으로 위치한 인덱스를 반환
    return i + 1


# ==== 사용 예시 ====
if __name__ == "__main__":
    # 정렬할 샘플 리스트
    data = [34, 7, 23, 32, 5, 62]

    # quick_sort 함수 호출 (전체 리스트를 정렬)
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과 출력
    print("정렬된 결과:", data)
```

### 코드 흐름 요약
1. `quick_sort`는 재귀적으로 호출되어 현재 구간을 `partition`으로 나눈다.  
2. `partition`은 피벗을 기준으로 작은 값들을 좌측, 큰 값들을 우측에 배치하고 피벗의 최종 위치를 반환한다.  
3. 피벗을 기준으로 좌·우 서브 배열에 대해 다시 `quick_sort`를 수행한다.  
4. 구간이 하나 이하가 되면( `low >= high` ) 재귀 호출이 종료된다.  

이렇게 하면 **평균 시간 복잡도 O(N log N)**, **최악의 경우 O(N²)** 인 퀵소트가 완성됩니다. 😊
