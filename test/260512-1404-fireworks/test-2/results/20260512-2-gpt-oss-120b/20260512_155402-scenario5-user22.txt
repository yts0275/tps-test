아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 상세히 주석을 달아두었으니, 알고리즘 흐름을 그대로 따라가 보세요.

```python
def quicksort(arr, low, high):
    """퀵소트 메인 함수
    arr  : 정렬할 리스트
    low  : 현재 정렬 구간의 시작 인덱스
    high : 현재 정렬 구간의 끝 인덱스(포함)"""

    # -----------------------------------------------------------------
    # 1) 구간이 한 요소 이하이면 이미 정렬된 것이므로 바로 반환
    # -----------------------------------------------------------------
    if low < high:                       # 구간에 두 개 이상 요소가 있을 때만 진행
        # -----------------------------------------------------------------
        # 2) 파티션 단계: pivot(피벗) 기준으로 좌·우 파트로 나누고,
        #    피벗을 최종 위치로 옮긴 뒤 그 인덱스를 반환한다.
        # -----------------------------------------------------------------
        pi = partition(arr, low, high)  # 피벗이 최종적으로 자리 잡은 인덱스

        # -----------------------------------------------------------------
        # 3) 재귀 호출: 피벗 왼쪽(작은 값) 부분을 정렬
        # -----------------------------------------------------------------
        quicksort(arr, low, pi - 1)      # 피벗 바로 앞까지 정렬

        # -----------------------------------------------------------------
        # 4) 재귀 호출: 피벗 오른쪽(큰 값) 부분을 정렬
        # -----------------------------------------------------------------
        quicksort(arr, pi + 1, high)     # 피벗 바로 뒤부터 정렬


def partition(arr, low, high):
    """배열을 파티션하고 피벗이 최종 위치에 오도록 하는 함수"""

    # -----------------------------------------------------------------
    # 1) 피벗 선택: 여기서는 가장 오른쪽 요소를 피벗으로 사용한다.
    # -----------------------------------------------------------------
    pivot = arr[high]                     # 피벗 값 저장

    # -----------------------------------------------------------------
    # 2) i는 “피벗보다 작은 요소들의 마지막 인덱스” 역할을 한다.
    #    처음에는 피벗보다 작은 요소가 없으므로 low-1 로 초기화.
    # -----------------------------------------------------------------
    i = low - 1

    # -----------------------------------------------------------------
    # 3) low부터 high-1까지 순회하면서 피벗보다 작거나 같은 값을 앞쪽에 모아준다.
    # -----------------------------------------------------------------
    for j in range(low, high):
        if arr[j] <= pivot:               # 현재 요소가 피벗보다 작거나 같으면
            i += 1                         # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # 작은 값을 i 위치로 스와핑

    # -----------------------------------------------------------------
    # 4) 모든 비교가 끝난 뒤, 피벗을 “작은 값들” 뒤에 놓는다.
    #    즉, i+1 위치에 피벗을 옮겨 최종 정렬 위치를 만든다.
    # -----------------------------------------------------------------
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # -----------------------------------------------------------------
    # 5) 피벗이 최종적으로 자리 잡은 인덱스를 반환한다.
    # -----------------------------------------------------------------
    return i + 1


# --------------------------------------------------------------
# 사용 예시
# --------------------------------------------------------------
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18]   # 정렬하고 싶은 임의의 리스트
    print("정렬 전:", data)

    quicksort(data, 0, len(data) - 1)   # 전체 리스트에 대해 퀵소트 호출

    print("정렬 후:", data)
```

### 주요 포인트

1. **재귀(Recursive) 구조**  
   - `quicksort`는 현재 구간을 피벗 기준으로 두 부분으로 나눈 뒤, 각각을 다시 `quicksort`에 넘겨 재귀적으로 정렬합니다.

2. **피벗 선택**  
   - 여기서는 가장 오른쪽 요소(`arr[high]`)를 피벗으로 사용했지만, 랜덤 선택, 중앙값 선택 등 다양한 전략이 존재합니다. 피벗 선택 방식에 따라 최악·평균 성능이 달라집니다.

3. **시간 복잡도**  
   - 평균 O(N log N) / 최악 O(N²) (피벗 선택이 좋지 않을 때)  
   - 공간 복잡도는 재귀 호출 스택 때문에 평균 O(log N), 최악 O(N) 입니다.

4. **안정성**  
   - 퀵소트는 **불안정** 정렬 알고리즘입니다. 같은 값을 가진 요소들의 원래 순서는 보장되지 않습니다.

필요에 따라 `partition`을 **Hoare 파티션** 방식으로 바꾸거나, **인-플레이스(iterative) 퀵소트**를 구현하면 스택 사용을 최소화할 수 있습니다. 궁금한 점이 있으면 언제든 물어보세요! 🚀
