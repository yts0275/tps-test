아래는 **Python** 로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 줄마다 어떤 역할을 하는지 상세히 주석을 달아 두었습니다.  
필요에 따라 리스트가 아닌 다른 시퀀스에도 쉽게 적용할 수 있습니다.

```python
def quick_sort(arr):
    # 1️⃣ 입력 리스트가 비었거나 원소가 하나만 있을 때는 이미 정렬돼 있으므로 바로 반환
    if len(arr) <= 1:
        return arr

    # 2️⃣ 피벗(pivot) 선택 – 여기서는 리스트의 첫 번째 원소를 사용
    #    (다른 전략: 마지막 원소, 중간 원소, 랜덤 원소 등)
    pivot = arr[0]

    # 3️⃣ 피벗보다 작은 원소들을 left 리스트에 모음
    left = []          # 피벗보다 작은 값들을 저장할 리스트
    # 4️⃣ 피벗과 같은 원소들을 middle 리스트에 모음
    middle = []        # 피벗과 같은 값들을 저장할 리스트 (중복 처리용)
    # 5️⃣ 피벗보다 큰 원소들을 right 리스트에 모음
    right = []         # 피벗보다 큰 값들을 저장할 리스트

    # 6️⃣ 전체 리스트를 한 번 순회하면서 세 개의 리스트에 나눠 담음
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:        # 피벗보다 크면 right에 추가
            right.append(x)
        else:                  # 피벗과 같은 값이면 middle에 추가 (피벗 자체 포함)
            middle.append(x)

    # 7️⃣ 재귀 호출을 통해 left와 right 부분을 각각 정렬
    sorted_left = quick_sort(left)    # left 부분을 정렬
    sorted_right = quick_sort(right)  # right 부분을 정렬

    # 8️⃣ 정렬된 left, middle(피벗), right 를 순서대로 합쳐 최종 정렬된 리스트 반환
    return sorted_left + middle + sorted_right


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42, 57]
    print("정렬 전:", unsorted)
    sorted_arr = quick_sort(unsorted)
    print("정렬 후:", sorted_arr)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 그대로 반환.  
2. **피벗 선택** – 현재 예시에서는 첫 번째 원소를 피벗으로 사용.  
3. **분할(Partition)** – 리스트를 `left`, `middle`, `right` 세 부분으로 나눔.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 과정을 반복해 정렬.  
5. **합치기** – 정렬된 `left` + `middle`(피벗) + 정렬된 `right`를 연결해 최종 결과 반환.

이 구현은 **안정적인(stable) 정렬**은 아니지만, 평균 시간 복잡도 `O(N log N)`을 보장합니다  
(최악의 경우 `O(N²)`가 되며, 피벗 선택 전략을 개선하면 이를 완화할 수 있습니다).
