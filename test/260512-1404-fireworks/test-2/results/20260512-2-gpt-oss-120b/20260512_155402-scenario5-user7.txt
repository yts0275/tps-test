아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 한국어 주석을 달아 동작 방식을 자세히 설명했습니다.  

```python
def quick_sort(arr):                     # 배열을 받아 정렬된 새로운 리스트를 반환하는 함수
    # 길이가 0 또는 1인 경우는 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:                    # 기본 사례 (Base case)
        return arr                       

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                       # 피벗은 정렬 과정에서 기준이 되는 값

    # 피벗보다 작은 요소들을 담을 리스트
    left = []                             # left에는 pivot보다 작은 값들을 저장
    # 피벗보다 큰 요소들을 담을 리스트
    right = []                            # right에는 pivot보다 큰 값들을 저장
    # 피벗과 같은 값(중복값)들을 담을 리스트
    middle = []                           # middle에는 pivot과 같은 값들을 저장 (중복 처리)

    # 전체 배열을 한 번 순회하면서 left, middle, right에 요소를 분류
    for x in arr:                         # 각 요소 x에 대해
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x > pivot:                   # 피벗보다 크면
            right.append(x)               # right 리스트에 추가
        else:                             # 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가 (중복 포함)

    # 재귀적으로 left와 right를 정렬하고, middle은 그대로 유지해서 합친다
    # left와 right는 각각 독립적인 서브 문제이므로 다시 quick_sort 호출
    return quick_sort(left) + middle + quick_sort(right)  
    # 정렬된 left + 피벗(및 중복) + 정렬된 right 를 이어서 최종 정렬 결과 반환


# -------------------- 사용 예시 --------------------
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 아래 코드 실행
    unsorted = [33, 10, 55, 71, 29, 3, 18, 55, 2]  # 정렬되지 않은 예시 리스트
    print("원본 리스트 :", unsorted)               # 원본 출력
    sorted_list = quick_sort(unsorted)              # quick_sort 함수를 이용해 정렬
    print("정렬된 리스트 :", sorted_list)           # 정렬 결과 출력
```

### 코드 흐름 요약
1. **기본 사례 확인** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 삼음.  
3. **분할 단계** – 배열을 순회하며 피벗보다 작은(`left`), 같은(`middle`), 큰(`right`) 값으로 나눔.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 각각 정렬.  
5. **병합 단계** – 정렬된 `left`, `middle`, 정렬된 `right`를 차례대로 이어서 최종 정렬 리스트를 만든다.  

이처럼 퀵소트는 **분할‑정복(Divide‑Conquer)** 전략을 활용해 평균 \(O(n \log n)\) 시간 복잡도로 정렬을 수행합니다. (최악의 경우 \(O(n^2)\) 가 될 수 있지만, 피벗을 무작위로 선택하거나 평균적인 경우에는 효율적입니다.)
