아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 코드 줄마다 한국어로 상세히 주석을 달아 이해를 돕도록 작성했습니다.

```python
# Quick Sort 구현 예시 (Python)
# ------------------------------------------------------------
# 퀵소트는 '분할 정복(Divide and Conquer)' 전략을 이용한 정렬 알고리즘입니다.
# 1) 배열에서 피벗(pivot)이라는 기준값을 선택하고,
# 2) 피벗보다 작은 원소들은 왼쪽 파트, 큰 원소들은 오른쪽 파트로 나눕니다.
# 3) 나눠진 두 파트를 각각 재귀적으로 같은 과정을 반복하면
#    전체 배열이 정렬됩니다.
# ------------------------------------------------------------

def quick_sort(arr):
    """
    입력: 정렬하고 싶은 리스트 arr
    반환: 정렬된 새로운 리스트 (원본 리스트는 변경되지 않음)
    """
    
    # 1. 정렬이 필요 없는 경우(길이가 0 또는 1인 리스트) 바로 반환
    if len(arr) <= 1:
        # 리스트가 비었거나 한 개만 있으면 이미 정렬된 것이므로 그대로 반환
        return arr
    
    # 2. 피벗 선택
    # 여기서는 가장 오른쪽 요소를 피벗으로 삼는다.
    # (다른 선택 전략도 가능: 랜덤, 중간값 등)
    pivot = arr[-1]               # 피벗 값 저장
    
    # 3. 피벗을 기준으로 작은 원소와 큰 원소를 분리
    left = []   # 피벗보다 작은 원소들을 담을 리스트
    right = []  # 피벗보다 큰 원소들을 담을 리스트
    
    # 리스트 전체를 순회하면서 피벗과 비교
    for element in arr[:-1]:     # 마지막 피벗 자체는 제외하고 순회
        if element <= pivot:
            left.append(element)   # 피벗보다 작거나 같은 경우 left에 추가
        else:
            right.append(element)  # 피벗보다 큰 경우 right에 추가
    
    # 4. 재귀적으로 left와 right 파트를 정렬하고, 피벗을 가운데에 넣는다.
    #    정렬된 전체 리스트는 [정렬된 left] + [pivot] + [정렬된 right] 형태가 된다.
    sorted_left = quick_sort(left)    # 왼쪽 파트 재귀 정렬
    sorted_right = quick_sort(right)  # 오른쪽 파트 재귀 정렬
    
    # 5. 정렬 결과를 하나의 리스트로 합쳐 반환
    return sorted_left + [pivot] + sorted_right


# ------------------------------------------------------------
# 사용 예시
# ------------------------------------------------------------
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬되지 않은 임의의 리스트
    print("원본 리스트 :", unsorted)
    
    sorted_list = quick_sort(unsorted)          # 퀵소트 함수 호출
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 바로 반환 (이미 정렬된 상태).  
2. **피벗 선택** – 여기서는 마지막 요소를 피벗으로 사용.  
3. **분할** – 피벗보다 작거나 같은 값은 `left`에, 큰 값은 `right`에 저장.  
4. **재귀 호출** – `left`와 `right`를 각각 다시 `quick_sort`로 정렬.  
5. **결합** – `sorted_left + [pivot] + sorted_right` 형태로 하나의 정렬된 리스트를 만든 뒤 반환.

이 구현은 **제자리(in‑place) 정렬**이 아니라 새로운 리스트를 만들어 반환하므로 메모리 사용량이 다소 증가합니다.  
제자리 버전을 원한다면 리스트 슬라이스 대신 인덱스를 이용해 같은 리스트를 직접 교환하는 방식을 구현하면 됩니다.
