아래는 **파이썬**으로 작성한 퀵소트(Quick Sort) 구현 예시입니다.  
각 코드 라인마다 간단한 한글 주석을 달아 두었으니, 흐름을 따라가며 이해하기 쉬울 겁니다.

```python
def quick_sort(arr):                           # quick_sort 함수 정의 – 정렬할 리스트를 매개변수로 받는다
    """                                         # 함수 설명을 위한 docstring 시작
    퀵소트 알고리즘을 재귀적으로 구현한다.
    인자는 정렬하고 싶은 리스트이며, 정렬된 새로운 리스트를 반환한다.
    """                                         # docstring 종료

    if len(arr) <= 1:                         # 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로
        return arr[:]                         # 원본을 그대로 복사해서 반환한다 (복사본을 반환해 부수효과 방지)

    # 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 잡는다
    pivot = arr[-1]                            # 마지막 원소를 피벗으로 저장

    # 피벗보다 작은 값들을 담을 리스트
    less = []                                  # 피벗보다 작은 원소들을 저장할 빈 리스트
    # 피벗과 같은 값들을 담을 리스트 (피벗 자체도 포함)
    equal = []                                 # 피벗과 같은 값들을 저장할 빈 리스트
    # 피벗보다 큰 값들을 담을 리스트
    greater = []                               # 피벗보다 큰 원소들을 저장할 빈 리스트

    # 전체 리스트를 순회하면서 세 개의 파티션으로 나눈다
    for x in arr:                              # 리스트의 각 원소 x에 대해
        if x < pivot:                          # 피벗보다 작으면
            less.append(x)                     # less 리스트에 추가
        elif x == pivot:                       # 피벗과 같으면
            equal.append(x)                    # equal 리스트에 추가
        else:                                  # 피벗보다 크면
            greater.append(x)                  # greater 리스트에 추가

    # 재귀적으로 less와 greater 파티션을 정렬하고,
    # equal 파티션은 그대로 두어 최종 결과를 만든다
    sorted_less = quick_sort(less)             # less 파티션을 재귀 호출로 정렬
    sorted_greater = quick_sort(greater)       # greater 파티션을 재귀 호출로 정렬

    # 정렬된 three-part 리스트를 합쳐서 반환한다
    return sorted_less + equal + sorted_greater # 합쳐진 최종 정렬 리스트 반환


# ---------------------------------------------------------------
# 사용 예시 (테스트용)
if __name__ == "__main__":                     # 이 파일이 메인 프로그램으로 실행될 때만 아래 코드를 실행
    sample = [33, 10, 55, 71, 29, 3, 18]       # 정렬할 샘플 리스트
    print("원본 리스트 :", sample)            # 원본 리스트 출력
    result = quick_sort(sample)                # quick_sort 함수 호출
    print("정렬 결과 :", result)               # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 다른 전략(중간값, 랜덤 등)도 가능.  
3. **파티셔닝** – 리스트를 `less`, `equal`, `greater` 세 부분으로 나눔.  
4. **재귀 호출** – `less`와 `greater` 부분을 각각 다시 `quick_sort`로 정렬.  
5. **병합** – 정렬된 `less`, 원래 `equal`, 정렬된 `greater`를 차례대로 이어서 최종 정렬 리스트를 만든다.

이 구현은 **안정적(stable)하지 않지만** 이해하기 쉬운 형태이며, 파이썬 리스트 복사를 최소화하고 싶다면 **in‑place 퀵소트**(배열을 직접 수정) 구현을 선택할 수도 있습니다. 필요하면 알려 주세요!
