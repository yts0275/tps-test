아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘 예시입니다.  
각 줄마다 무엇을 하는지 주석을 달아 놓았으니 코드를 따라가며 이해해 보세요.

```python
# 퀵소트 함수: 리스트와 정렬할 구간(시작 인덱스, 끝 인덱스)을 인자로 받는다
def quick_sort(arr, low, high):
    # 구간의 시작이 끝보다 작을 때만 정렬을 진행한다
    if low < high:
        # 파티션 함수를 호출해 피벗(pivot)의 최종 위치를 구한다
        pi = partition(arr, low, high)

        # 피벗 왼쪽(피벗 이전) 구간을 재귀적으로 정렬한다
        quick_sort(arr, low, pi - 1)

        # 피벗 오른쪽(피벗 이후) 구간을 재귀적으로 정렬한다
        quick_sort(arr, pi + 1, high)


# 파티션 함수: 피벗을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽에 배치하고
# 피벗이 최종적으로 위치하는 인덱스를 반환한다
def partition(arr, low, high):
    # 여기서는 가장 오른쪽 원소를 피벗으로 선택한다
    pivot = arr[high]

    # i는 피벗보다 작거나 같은 원소들의 마지막 인덱스를 가리킨다
    i = low - 1

    # low부터 high-1까지 순회하면서 피벗보다 작거나 같은 원소를 찾는다
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같으면 i를 하나 증가시키고
        # 그 위치와 현재 원소를 교환한다
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]   # 스와핑

    # 마지막으로 피벗을 i+1 위치와 교환하면 피벗이 정확한 위치에 놓인다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 인덱스를 반환한다
    return i + 1


# ---------- 사용 예시 ----------
if __name__ == "__main__":
    # 정렬하고 싶은 리스트를 정의한다
    data = [34, 7, 23, 32, 5, 62]

    # 리스트 전체를 정렬하기 위해 low=0, high=len(data)-1 로 호출한다
    quick_sort(data, 0, len(data) - 1)

    # 정렬된 결과를 출력한다
    print("정렬 결과:", data)
```

### 코드 흐름 요약
1. `quick_sort`는 전체 리스트를 재귀적으로 **분할(divide)** 하고 **정복(conquer)** 한다.  
2. `partition` 함수가 피벗을 기준으로 리스트를 두 부분으로 나누고, 피벗을 최종 위치에 둔다.  
3. 피벗을 기준으로 왼쪽·오른쪽 구간에 대해 다시 `quick_sort`를 호출해 정렬을 반복한다.  

이 구현은 **in‑place**(제자리) 정렬이며, 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(`이미 정렬된 리스트` 등) `O(N^2)` 입니다. 필요에 따라 피벗 선택 방식을 랜덤하게 바꾸면 최악의 경우를 더 낮출 수 있습니다.
