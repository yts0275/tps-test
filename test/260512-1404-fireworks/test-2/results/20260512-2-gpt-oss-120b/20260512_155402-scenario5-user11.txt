아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 한글 주석을 달아 흐름을 상세히 설명했습니다.  

```python
# 퀵소트를 구현한 모듈 ---------------------------------------------------------

def quick_sort(arr: list, low: int, high: int) -> None:
    """ 
    배열 arr을 [low, high] 구간에서 제자리(in‑place) 정렬한다.
    low와 high는 인덱스이며, 재귀 호출을 통해 구간을 계속 나눈다.
    """
    if low < high:                               # 구간이 최소 2개 이상의 요소를 가질 때만 정렬
        pivot_index = partition(arr, low, high)  # 피벗을 기준으로 배열을 분할하고 피벗 위치 반환
        quick_sort(arr, low, pivot_index - 1)    # 피벗 왼쪽 부분을 재귀적으로 정렬
        quick_sort(arr, pivot_index + 1, high)   # 피벗 오른쪽 부분을 재귀적으로 정렬


def partition(arr: list, low: int, high: int) -> int:
    """
    Lomuto 파티션 방식을 사용한다.
    - 피벗: 현재 구간의 가장 오른쪽 요소 (arr[high])
    - i: 피벗보다 작은 요소들의 마지막 인덱스
    반환값: 피벗이 최종적으로 놓이게 되는 인덱스
    """
    pivot = arr[high]            # 피벗값 선택 (구간 끝 요소)
    i = low - 1                  # i는 아직 피벗보다 작은 요소가 없으므로 low-1로 초기화

    for j in range(low, high):   # low부터 high-1까지 순회하며 피벗보다 작은 요소를 찾는다
        if arr[j] <= pivot:      # 현재 요소가 피벗보다 작거나 같다면
            i += 1               # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]   # 작은 요소를 앞쪽(i 위치)으로 스와핑

    # 루프가 끝난 뒤, i+1 위치에 피벗을 넣어야 정렬이 완성된다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                 # 피벗이 최종적으로 자리 잡은 인덱스를 반환


# ---------------------------------------------------------------------------
# 사용 예시 (테스트) ---------------------------------------------------------

if __name__ == "__main__":
    # 정렬하고자 하는 샘플 리스트
    sample = [33, 10, 55, 71, 29, 3, 18, 42]

    print("정렬 전:", sample)                     # 정렬 전 원본 출력
    quick_sort(sample, 0, len(sample) - 1)        # 전체 구간에 대해 퀵소트 수행
    print("정렬 후:", sample)                     # 정렬이 완료된 리스트 출력
```

### 코드 설명
1. **`quick_sort`**  
   - 재귀 함수로, 현재 구간(`low ~ high`)을 피벗을 기준으로 두 부분으로 나눈 뒤 각각 다시 정렬합니다.  
2. **`partition`**  
   - Lomuto 파티션 방식을 사용해 피벗(`arr[high]`)을 적절한 위치에 배치하고, 피벗보다 작은 값들은 왼쪽, 큰 값들은 오른쪽에 모이도록 스와핑합니다.  
3. **`if __name__ == "__main__":`**  
   - 모듈이 직접 실행될 때 동작하는 테스트 코드이며, 정렬 전후를 출력해 결과를 확인할 수 있습니다.

이 구현은 **제자리 정렬**이므로 추가적인 메모리를 거의 사용하지 않으며, 평균 시간 복잡도는 `O(N log N)`, 최악 경우(`이미 정렬된 상태`)에는 `O(N²)`가 됩니다. 필요에 따라 피벗 선택 전략을 바꾸면 최악 경우를 완화할 수 있습니다.
