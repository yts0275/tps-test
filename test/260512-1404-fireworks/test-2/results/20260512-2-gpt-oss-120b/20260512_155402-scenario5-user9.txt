아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 한글로 달아두었습니다.  

```python
# -*- coding: utf-8 -*-                # 파일 인코딩 선언 (한글 주석을 위해)

def quick_sort(arr):
    """퀵소트를 수행하여 정렬된 새 리스트를 반환한다."""
    # 0 또는 1개의 원소만 있으면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                       # 기본(Basis) 케이스

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 원소를 피벗으로 사용
    pivot = arr[-1]                       # 피벗값 저장

    # 피벗보다 작은 원소들을 모아 left 리스트에 저장
    left = []                             # 피벗보다 작은 원소를 담을 리스트
    # 피벗보다 큰 원소들을 모아 right 리스트에 저장
    right = []                            # 피벗보다 큰 원소를 담을 리스트

    # 피벗을 제외한 나머지 요소들을 순회하면서 left / right에 분배
    for element in arr[:-1]:              # 마지막 요소(피벗)를 제외하고 순회
        if element <= pivot:              # 현재 요소가 피벗보다 작거나 같으면
            left.append(element)          # left 리스트에 추가
        else:                             # 현재 요소가 피벗보다 크면
            right.append(element)         # right 리스트에 추가

    # 재귀적으로 left와 right 부분을 각각 정렬하고, 피벗을 가운데에 끼워서 합침
    return quick_sort(left) + [pivot] + quick_sort(right)  # 정렬된 결과 반환


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트 정의
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90, 42]

    # 퀵소트 함수 호출하여 정렬된 리스트 얻기
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)   # 정렬 전 리스트
    print("정렬된 리스트:", sorted_list)   # 정렬 후 리스트
```

### 코드 설명
1. **기본 케이스** – 리스트 길이가 0 혹은 1이면 그대로 반환합니다.  
2. **피벗 선택** – 여기서는 가장 오른쪽 원소(`arr[-1]`)를 피벗으로 잡았습니다.  
3. **분할 단계** – 피벗보다 작거나 같은 원소는 `left`에, 큰 원소는 `right`에 모읍니다.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 다시 `quick_sort`를 호출해 정렬합니다.  
5. **병합** – 정렬된 `left`, 피벗, 정렬된 `right`를 차례대로 이어서 최종 정렬 결과를 반환합니다.  

각 줄마다 왜 그 코드가 필요한지 설명을 달아두었으니, 퀵소트의 흐름을 이해하는 데 도움이 될 것입니다. 🚀
