아래는 파이썬(Python)으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 자세히 설명하는 주석을 달아 두었습니다.

```python
def quick_sort(arr: list) -> list:                     # 정렬할 리스트를 인자로 받아 새 리스트를 반환하는 함수 정의
    # 기본 경우: 리스트가 비어 있거나 원소가 하나뿐이면 그대로 반환한다.
    if len(arr) <= 1:                                 # 리스트 길이가 1 이하인지 확인
        return arr                                     # 조건에 맞으면 현재 리스트를 그대로 반환

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용한다.
    pivot = arr[-1]                                    # 피벗을 리스트의 마지막 원소로 지정
    less = []                                          # 피벗보다 작은 원소들을 담을 리스트 초기화
    greater = []                                       # 피벗보다 큰 원소들을 담을 리스트 초기화

    # 피벗을 제외한 나머지 원소들을 순회하며 less와 greater에 분류한다.
    for element in arr[:-1]:                           # 피벗을 제외한 모든 원소를 차례대로 탐색
        if element <= pivot:                           # 현재 원소가 피벗보다 작거나 같은 경우
            less.append(element)                       # less 리스트에 추가
        else:                                          # 현재 원소가 피벗보다 큰 경우
            greater.append(element)                    # greater 리스트에 추가

    # 재귀적으로 less와 greater를 각각 정렬하고, 피벗을 중간에 끼워 최종 리스트를 만든다.
    sorted_less = quick_sort(less)                     # less 부분에 대해 재귀 호출해 정렬
    sorted_greater = quick_sort(greater)               # greater 부분에 대해 재귀 호출해 정렬

    # 정렬된 less, 피벗, 정렬된 greater를 차례대로 합쳐서 반환한다.
    return sorted_less + [pivot] + sorted_greater       # 최종 정렬된 리스트 반환


# -------------------------------------------------------------------------
# 사용 예시 (main 함수처럼 활용할 수 있습니다)
if __name__ == "__main__":                             # 이 파일이 직접 실행될 때만 아래 코드 실행
    sample = [34, 7, 23, 32, 5, 62]                   # 정렬하고 싶은 샘플 리스트 정의
    print("원본 리스트 :", sample)                   # 정렬 전 리스트 출력
    sorted_sample = quick_sort(sample)               # quick_sort 함수를 호출해 정렬
    print("정렬된 리스트 :", sorted_sample)           # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기본 경우** – 리스트가 비어 있거나 원소가 하나면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용.  
3. **분할 단계** – 피벗을 기준으로 `less`(작은 원소)와 `greater`(큰 원소) 두 리스트로 나눔.  
4. **재귀 호출** – `less`와 `greater` 각각에 대해 `quick_sort`를 재귀적으로 수행.  
5. **합치기** – 정렬된 `less`, 피벗, 정렬된 `greater`를 차례대로 이어 최종 정렬 리스트를 만든다.  

이 구현은 **리스트 복사를 많이** 하므로 메모리 사용량이 다소 높지만, 이해하기 쉽고 가독성이 좋은 전형적인 퀵소트 예시입니다. 필요에 따라 **인‑플레이스(in‑place)** 버전이나 **피벗 선택 전략**을 바꾸어 성능을 개선할 수 있습니다.
