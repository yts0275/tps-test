아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘 예시입니다.  
각 줄마다 무슨 일을 하는지 설명하는 주석을 달아 두었으니, 코드를 따라가며 이해하기 쉬울 거예요.

```python
# quick_sort.py
# 리스트(배열)를 정렬하는 퀵소트 구현
# 시간복잡도: 평균 O(N log N), 최악 O(N^2) (피벗 선택에 따라 달라짐)

def quick_sort(arr):
    """
    퀵소트를 수행하는 재귀 함수.
    입력: 정렬되지 않은 리스트 arr
    반환: 정렬된 새로운 리스트 (원본 리스트는 변하지 않음)
    """
    # 1. 정렬할 원소가 0개 혹은 1개이면 이미 정렬된 것이므로 바로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선택
    #    여기서는 가장 오른쪽 원소를 피벗으로 잡는다.
    #    (다른 전략: 무작위 선택, 중앙값 선택 등)
    pivot = arr[-1]

    # 3. 피벗보다 작은 원소들을 모을 리스트
    left = []
    # 4. 피벗보다 큰 원소들을 모을 리스트
    right = []

    # 5. 피벗을 제외한 나머지 원소들을 순회하며 left / right에 분류
    for element in arr[:-1]:          # arr[-1]은 피벗이므로 제외
        if element <= pivot:          # 피벗보다 작거나 같은 경우
            left.append(element)      # left 리스트에 추가
        else:                         # 피벗보다 큰 경우
            right.append(element)     # right 리스트에 추가

    # 6. left와 right 각각에 대해 재귀적으로 quick_sort 실행
    #    - 이렇게 하면 점점 리스트가 작아지면서 기본 사례(base case)인
    #      len(arr) <= 1에 도달하게 된다.
    sorted_left = quick_sort(left)    # 왼쪽 부분 정렬
    sorted_right = quick_sort(right)  # 오른쪽 부분 정렬

    # 7. 정렬된 결과를 합친다.
    #    [sorted_left] + [pivot] + [sorted_right] 순서가 오름차순 정렬을 보장한다.
    return sorted_left + [pivot] + sorted_right


# ----------------------------------------------------------------------
# 사용 예시 (스크립트가 직접 실행될 때만 동작하도록 함)
# ----------------------------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 40]

    # 퀵소트 함수를 호출해 정렬된 리스트를 얻는다.
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기본 사례(Base case)**  
   - 리스트 길이가 0 또는 1이면 이미 정렬돼 있으므로 그대로 반환합니다.
2. **피벗 선택**  
   - 여기서는 가장 오른쪽 원소를 피벗으로 잡았습니다. (다른 선택도 가능)
3. **분할(Partition)**  
   - 피벗을 기준으로 `left`(피벗 이하)와 `right`(피벗 초과) 리스트로 나눕니다.
4. **재귀 호출**  
   - `left`와 `right` 각각에 대해 같은 과정을 재귀적으로 수행합니다.
5. **결합(Combine)**  
   - 정렬된 `left`, 피벗, 정렬된 `right` 를 차례대로 이어 붙여 최종 정렬 결과를 얻습니다.

### 참고 사항
- **제자리(in‑place) 버전**도 존재합니다. 위 코드는 가독성을 위해 새 리스트를 만들어 반환하는 형태라 메모리를 더 사용합니다.
- **피벗 선택 전략**을 바꾸면 최악의 경우를 피하고 평균 성능을 높일 수 있습니다. 예를 들어 `random.choice(arr)` 로 무작위 피벗을 선택하거나, “median‑of‑three” 전략을 쓰면 좋습니다.
- **스택 깊이**가 너무 깊어지는 것을 방지하려면, 재귀 대신 명시적인 스택을 이용한 반복 구현도 가능합니다.
