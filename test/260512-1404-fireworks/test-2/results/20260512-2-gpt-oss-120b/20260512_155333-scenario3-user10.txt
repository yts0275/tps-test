아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 자세히 이해할 수 있도록 한국어 주석을 달았습니다.  

```python
def quick_sort(arr: list[int]) -> list[int]:          # 퀵소트를 수행하는 함수 정의 (입력: 정수 리스트, 반환: 정렬된 리스트)
    # ---------- 1. 기본 탈출 조건 ----------
    if len(arr) <= 1:                                 # 리스트 길이가 0 혹은 1이면 이미 정렬된 상태이므로
        return arr                                    # 바로 반환한다.

    # ---------- 2. 피벗(pivot) 선택 ----------
    pivot = arr[len(arr) // 2]                        # 가운데 요소를 피벗으로 잡는다(다른 선택 방식도 가능)

    # ---------- 3. 피벗을 기준으로 분할 ----------
    left  = [x for x in arr if x < pivot]              # 피벗보다 작은 값들만 모은 리스트 (왼쪽 부분)
    middle = [x for x in arr if x == pivot]           # 피벗과 값이 같은 요소들 (중앙 부분, 피벗 자체 포함)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 값들만 모은 리스트 (오른쪽 부분)

    # ---------- 4. 재귀 호출 ----------
    # 왼쪽 부분을 정렬하고, 중앙 부분은 그대로 두고, 오른쪽 부분을 정렬한다.
    # 각각 반환된 리스트를 이어 붙여 최종 정렬 결과를 만든다.
    return quick_sort(left) + middle + quick_sort(right)  # 재귀적으로 left, right 를 정렬하고 합친 결과 반환
```

### 사용 예시
```python
if __name__ == "__main__":                     # 스크립트를 직접 실행할 때만 동작하도록 하는 진입점
    unsorted = [34, 7, 23, 32, 5, 62]          # 정렬이 필요한 원본 리스트
    sorted_list = quick_sort(unsorted)         # quick_sort 함수 호출
    print("정렬 전:", unsorted)                # 정렬 전 리스트 출력
    print("정렬 후:", sorted_list)            # 정렬된 리스트 출력
```

---

#### 코드 흐름 요약
1. **기본 탈출 조건** – 리스트가 1개 이하이면 바로 반환.  
2. **피벗 선택** – 여기서는 리스트 중간 값을 피벗으로 사용하지만, 첫 번째/마지막/임의 선택도 가능.  
3. **분할** – 리스트를 `피벗보다 작은`, `피벗과 같은`, `피벗보다 큰` 세 부분으로 나눈다.  
4. **재귀 호출** – `left`와 `right` 부분을 각각 재귀적으로 정렬하고, `middle`은 그대로 두어 합친다.  

이 구현은 **가독성이 좋고** 이해하기 쉬우며, 파이썬 리스트 컴프리헨션을 활용해 간결하게 작성되었습니다.  
시간 복잡도는 평균 **O(N log N)**, 최악의 경우 **O(N²)** (피벗 선택이 불균형할 때)이며, 추가 공간 복잡도는 **O(N)** 입니다.
