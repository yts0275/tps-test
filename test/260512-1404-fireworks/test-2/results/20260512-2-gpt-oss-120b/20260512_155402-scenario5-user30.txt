아래는 **Python** 으로 구현한 퀵소트(quick sort) 알고리즘 예시입니다.  
각 코드 라인마다 무엇을 수행하는지 주석을 달아 두었으니, 흐름을 따라가면서 이해하시면 됩니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수를 정의한다. 입력은 정렬할 리스트 arr
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로
        return arr                       # 그대로 반환한다.

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 값으로 리스트 가운데 요소를 선택한다.
    left = []                            # 피벗보다 작은 요소를 담을 리스트 left 선언
    middle = []                          # 피벗과 같은 요소를 담을 리스트 middle 선언
    right = []                           # 피벗보다 큰 요소를 담을 리스트 right 선언

    for x in arr:                        # 원본 리스트의 모든 요소 x에 대해 반복
        if x < pivot:                    # x가 피벗보다 작으면
            left.append(x)               # left 리스트에 추가
        elif x > pivot:                  # x가 피벗보다 크면
            right.append(x)              # right 리스트에 추가
        else:                            # x가 피벗과 같으면
            middle.append(x)             # middle 리스트에 추가 (피벗 자체와 중복값)

    # 재귀적으로 left와 right 부분을 각각 정렬하고,
    # 정렬된 left + middle(피벗) + 정렬된 right 를 이어 붙여 반환한다.
    return quick_sort(left) + middle + quick_sort(right)


# ------------------------------
# 사용 예시
# ------------------------------
if __name__ == "__main__":               # 이 파일이 직접 실행될 때만 아래 코드를 수행
    unsorted = [33, 10, 55, 71, 29, 3, 44]   # 정렬되지 않은 샘플 리스트
    sorted_arr = quick_sort(unsorted)        # 퀵소트 함수 호출
    print("정렬 전:", unsorted)              # 정렬 전 리스트 출력
    print("정렬 후:", sorted_arr)            # 정렬 후 리스트 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트가 1개 이하이면 그대로 반환. (재귀 종료)
2. **피벗 선택** – 리스트 중간값을 피벗으로 잡음. (다른 선택 방법도 가능)
3. **분할** – 리스트를 `left`, `middle`, `right` 로 나눔.  
   - `left` : 피벗보다 작은 값들  
   - `middle` : 피벗과 같은 값들 (피벗 자체와 중복값)  
   - `right` : 피벗보다 큰 값들
4. **재귀 호출** – `left`와 `right` 부분을 각각 다시 `quick_sort` 로 정렬.
5. **병합** – 정렬된 `left` + `middle` + 정렬된 `right` 를 이어서 하나의 리스트로 만든다.

이제 이 코드를 실행하면 퀵소트 알고리즘에 의해 리스트가 오름차순으로 정렬됩니다. 필요에 따라 피벗 선택 방법이나 병합 방식 등을 바꿔볼 수도 있습니다! 🚀
