아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 동작을 설명하는 한국어 주석을 달아두었으니, 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):
    """퀵소트 함수: 배열을 받아 정렬된 새로운 리스트를 반환한다."""
    
    # 1️⃣ 베이스 케이스: 리스트가 비었거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # (len(arr) == 0 또는 1) 일 때 바로 리턴
    
    # 2️⃣ 피벗 선택: 여기서는 리스트의 첫 번째 요소를 피벗으로 잡는다
    pivot = arr[0]                     # 피벗값을 저장
    
    # 3️⃣ 피벗보다 작은 원소들을 left 리스트에 모은다
    left = []                          # 작은 원소를 담을 리스트 초기화
    # 4️⃣ 피벗과 같은 원소(피벗 자체 제외)를 middle 리스트에 모은다
    middle = []                        # 피벗과 같은 값을 담을 리스트 초기화
    # 5️⃣ 피벗보다 큰 원소들을 right 리스트에 모은다
    right = []                         # 큰 원소를 담을 리스트 초기화
    
    # 6️⃣ 전체 배열을 순회하면서 위 세 리스트에 원소를 분배
    for x in arr:
        if x < pivot:                  # 피벗보다 작으면
            left.append(x)             # left에 추가
        elif x == pivot:               # 피벗과 같으면
            middle.append(x)           # middle에 추가
        else:                          # 피벗보다 크면
            right.append(x)            # right에 추가
    
    # 7️⃣ 재귀 호출을 통해 left와 right 부분을 각각 정렬한다
    sorted_left = quick_sort(left)     # 왼쪽 부분을 재귀적으로 정렬
    sorted_right = quick_sort(right)   # 오른쪽 부분을 재귀적으로 정렬
    
    # 8️⃣ 정렬된 left + middle(피벗) + 정렬된 right 를 이어 붙여 최종 결과 반환
    return sorted_left + middle + sorted_right
```

### 사용 예시
```python
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18]
    print("정렬 전:", unsorted)
    print("정렬 후:", quick_sort(unsorted))
```

**설명 요약**

1. **베이스 케이스** – 길이가 0 또는 1인 리스트는 그대로 반환.  
2. **피벗 선택** – 여기서는 첫 번째 요소를 피벗으로 사용했지만, 랜덤 피벗이나 중앙값 피벗 등으로 바꿀 수 있다.  
3. **분할** – 배열을 피벗보다 작은(`left`), 같은(`middle`), 큰(`right`) 세 그룹으로 나눈 뒤, `left`와 `right`에 대해 재귀적으로 같은 작업을 수행한다.  
4. **합병** – 재귀 호출 결과를 순서대로 이어 붙이면 최종적으로 오름차순 정렬된 리스트가 만든다.
