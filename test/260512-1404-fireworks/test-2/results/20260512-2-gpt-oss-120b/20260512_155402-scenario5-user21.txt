아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하는지 주석을 달아 놓았으니, 흐름을 따라가면서 이해해 보세요.

```python
# 퀵소트를 수행하는 메인 함수
def quick_sort(arr):
    # 배열이 비어 있거나 한 개의 원소만 있으면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                                   # 정렬이 필요 없는 경우

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                                   # pivot = 마지막 원소

    # 피벗보다 작은 원소들만 모은 리스트 (왼쪽 부분 배열)
    left = []                                         # 피벗보다 작은 값들을 담을 리스트
    # 피벗과 같은 값을 모은 리스트 (중복된 피벗값을 처리하기 위해)
    middle = []                                       # 피벗과 같은 값들을 담을 리스트
    # 피벗보다 큰 원소들만 모은 리스트 (오른쪽 부분 배열)
    right = []                                        # 피벗보다 큰 값들을 담을 리스트

    # 배열의 모든 원소를 순회하면서 left, middle, right에 분류
    for x in arr:
        if x < pivot:                                 # 피벗보다 작으면
            left.append(x)                            # left 리스트에 추가
        elif x == pivot:                              # 피벗과 같으면
            middle.append(x)                          # middle 리스트에 추가
        else:                                         # 피벗보다 크면
            right.append(x)                           # right 리스트에 추가

    # 재귀적으로 left와 right 부분 배열을 정렬하고, middle(피벗)와 합쳐서 반환
    return quick_sort(left) + middle + quick_sort(right)   # 정렬된 결과 반환

# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 92, 44]   # 정렬되지 않은 예시 리스트
    sorted_arr = quick_sort(unsorted)                # 퀵소트 실행
    print("정렬 전:", unsorted)                      # 정렬 전 리스트 출력
    print("정렬 후:", sorted_arr)                    # 정렬 후 리스트 출력
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 0 혹은 1이면 그대로 반환.  
2. **피벗 선택** – 여기선 마지막 원소를 피벗으로 사용했지만, 임의 선택 등 다른 전략도 가능.  
3. **분할 단계** – 리스트를 `left`, `middle`, `right` 세 부분으로 나눔.  
4. **재귀 호출** – `left`와 `right` 부분에 대해 각각 다시 `quick_sort`를 호출해 정렬.  
5. **합병 단계** – 정렬된 `left` + `middle`(피벗) + 정렬된 `right` 를 이어서 최종 정렬 결과를 만든다.  

이렇게 한 줄 한 줄에 주석을 달아 두었으니, 퀵소트의 핵심 아이디어와 구현 방식을 이해하는 데 도움이 되길 바랍니다!
