아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 상세히 주석을 달아 두었으니, 흐름을 따라가면서 이해하시면 됩니다.

```python
# 퀵소트 함수: 주어진 리스트를 정렬하고 정렬된 리스트를 반환한다
def quick_sort(arr):
    # 1. 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # 기본 사례(base case)

    # 2. 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                    # 피벗은 분할 기준이 되는 값

    # 3. 피벗보다 작은 요소들을 담을 리스트와 큰 요소들을 담을 리스트 초기화
    left = []                          # 피벗보다 작은 값들을 모음
    right = []                         # 피벗보다 큰 값들을 모음
    middle = []                        # 피벗과 같은 값들이 들어갈 리스트 (중복 허용)

    # 4. 리스트를 순회하면서 각 요소를 피벗과 비교해 적절한 리스트에 삽입
    for x in arr:
        if x < pivot:                  # 피벗보다 작으면 left 리스트에
            left.append(x)
        elif x > pivot:                # 피벗보다 크면 right 리스트에
            right.append(x)
        else:                          # 피벗과 같으면 middle 리스트에(중복을 위해)
            middle.append(x)

    # 5. left와 right 부분에 대해 재귀적으로 quick_sort를 호출해 정렬하고
    #    left, middle, right를 순서대로 합쳐 최종 정렬 결과를 만든다
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90, 42, 33]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("정렬 전:", unsorted_list)
    print("정렬 후:", sorted_list)
```

### 코드 흐름 요약
1. **기본 사례** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 임의의 원소로도 바꿀 수 있다.  
3. **분할 단계** – 리스트를 피벗보다 작은(`left`), 같은(`middle`), 큰(`right`) 세 부분으로 나눈다.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 과정을 반복한다.  
5. **결합 단계** – 재귀 호출 결과와 `middle`을 순서대로 이어서 최종 정렬 리스트를 만든다.

이 구현은 **안정적인(stable)** 정렬은 아니지만, 퀵소트의 핵심 아이디어인 *분할‑정복* 방식을 명확하게 보여줍니다.  
필요에 따라 피벗 선택 방식을 개선하거나, 제자리(in‑place) 버전으로 변형할 수 있습니다.
