아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한글 주석을 달아 동작 과정을 자세히 설명했습니다.  

```python
def quicksort(arr):                     # 퀵소트를 수행할 함수를 정의합니다.
    """퀵소트 구현 (제자리 정렬)"""       # 함수 설명 (Docstring)

    def _quicksort(low: int, high: int):   # 내부 재귀 함수: 현재 정렬 구간을 low~high 인덱스로 지정
        if low < high:                     # 구간이 최소 두 원소 이상이면 정렬 진행
            pivot_index = partition(low, high)   # 피벗을 기준으로 배열을 분할하고 피벗 최종 위치 반환
            _quicksort(low, pivot_index - 1)      # 피벗 왼쪽(작은 값들) 부분을 재귀적으로 정렬
            _quicksort(pivot_index + 1, high)    # 피벗 오른쪽(큰 값들) 부분을 재귀적으로 정렬

    def partition(low: int, high: int) -> int:   # 구간을 분할하는 함수, 피벗 위치 반환
        pivot = arr[high]                # 마지막 원소를 피벗으로 선택 (단순 구현)
        i = low - 1                       # i는 "작은 값들"의 마지막 인덱스를 가리킴
        for j in range(low, high):        # 피벗을 제외한 구간을 왼쪽→오른쪽으로 순회
            if arr[j] <= pivot:           # 현재 원소가 피벗보다 작거나 같으면
                i += 1                     # 작은 값 구역의 끝을 하나 늘리고
                arr[i], arr[j] = arr[j], arr[i]   # 현재 원소와 작은 값 구역 끝 원소를 교환
        # 루프가 끝난 뒤 i는 마지막 작은 값의 인덱스가 된다.
        arr[i + 1], arr[high] = arr[high], arr[i + 1]   # 피벗을 작은 값 구역 바로 뒤 위치(i+1)로 이동
        return i + 1                     # 피벗의 최종 인덱스를 반환

    # ------------------- 메인 시작 -------------------
    _quicksort(0, len(arr) - 1)          # 전체 배열을 대상으로 재귀 정렬 시작
    # ------------------- 메인 종료 -------------------
    return arr                           # 정렬된 배열을 반환 (제자리 정렬이므로 원본도 바뀜)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":               # 스크립트가 직접 실행될 때만 아래 코드 실행
    data = [33, 10, 55, 71, 29, 3, 18]    # 정렬할 임의의 리스트
    print("정렬 전 :", data)              # 정렬 전 출력
    sorted_data = quicksort(data)         # 퀵소트 호출
    print("정렬 후 :", sorted_data)       # 정렬 후 출력
```

### 코드 설명
1. **`quicksort` 함수** – 배열을 인수로 받아 제자리(in‑place) 퀵소트를 실행하고 정렬된 배열을 반환합니다.  
2. **`_quicksort` (내부 재귀 함수)** – 실제 재귀 로직을 담당합니다. `low`와 `high` 인덱스로 현재 구간을 지정합니다.  
3. **`partition` 함수** – 현재 구간의 마지막 원소를 피벗으로 삼아, 피벗보다 작거나 같은 원소들을 왼쪽으로 몰고 피벗을 올바른 위치에 놓습니다. 피벗 최종 인덱스를 반환합니다.  
4. **재귀 호출** – 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 다시 정렬합니다.  
5. **메인 블록** – 파일을 직접 실행했을 때 테스트용으로 동작하도록 했습니다.

이 구현은 평균 시간 복잡도 **O(N log N)**, 최악 경우 **O(N²)** (피벗 선택이 최악일 때)이며, 추가적인 배열을 생성하지 않으므로 **O(1)** 的 추가 메모리만 사용합니다. 필요에 따라 피벗 선택 전략(예: 랜덤 피벗, Median‑of‑Three)이나 꼬리 재귀 최적화 등을 적용하면 성능을 더 향상시킬 수 있습니다.
