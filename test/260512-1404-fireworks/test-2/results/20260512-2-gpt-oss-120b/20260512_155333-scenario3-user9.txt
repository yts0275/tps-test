아래는 **Python**으로 구현한 퀵소트(Quick Sort) 알고리즘 예시입니다.  
각 코드 줄마다 무엇을 하는지 상세히 주석을 달아 두었으니, 공부하시거나 직접 수정하실 때 도움이 될 것입니다.

```python
# 퀵소트 함수 정의: 리스트와 정렬할 구간의 시작(start)과 끝(end) 인덱스를 매개변수로 받음
def quick_sort(arr, start, end):
    # 구간에 요소가 하나 이하이면 이미 정렬된 상태이므로 바로 반환
    if start >= end:
        return

    # 피벗(pivot) 선택: 여기서는 구간의 마지막 요소를 피벗으로 잡음
    pivot = arr[end]

    # i는 피벗보다 작거나 같은 요소들의 마지막 인덱스를 가리킴
    i = start - 1

    # j는 start부터 end-1까지 순회하며 현재 요소와 피벗을 비교
    for j in range(start, end):
        # 현재 요소가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            # i를 한 칸 오른쪽으로 이동
            i += 1
            # i와 j 위치의 요소를 서로 교환하여 작은 값을 앞쪽으로 모음
            arr[i], arr[j] = arr[j], arr[i]

    # 모든 요소를 검사한 뒤, 피벗을 i+1 위치로 옮겨서 정확한 정렬 위치 확보
    arr[i + 1], arr[end] = arr[end], arr[i + 1]

    # 피벗의 최종 위치를 기준으로 왼쪽 구간과 오른쪽 구간을 재귀적으로 정렬
    quick_sort(arr, start, i)       # 피벗 왼쪽 부분 정렬
    quick_sort(arr, i + 2, end)     # 피벗 오른쪽 부분 정렬


# ------------------------------
# 사용 예시
# ------------------------------
if __name__ == "__main__":
    # 정렬할 원본 리스트
    data = [33, 10, 55, 71, 29, 3, 18, 42]

    # quick_sort 함수 호출 (전체 리스트를 정렬)
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과 출력
    print("정렬된 리스트:", data)
```

### 코드 흐름 요약
1. **재귀 종료 조건** – 구간에 요소가 0 또는 1개이면 바로 반환합니다.  
2. **피벗 선정** – 여기서는 구간의 마지막 요소(`arr[end]`)를 피벗으로 사용했습니다.  
3. **분할 과정** – `i`를 기준으로 피벗보다 작은(또는 같은) 값들을 앞쪽에 모으고, 최종적으로 피벗을 정확한 위치(`i+1`)에 삽입합니다.  
4. **재귀 호출** – 피벗을 기준으로 왼쪽·오른쪽 구간을 각각 다시 퀵소트합니다.  

이 구현은 **in‑place**(추가 메모리 사용 최소)이며 평균‑시간 복잡도는 \(O(n \log n)\), 최악‑시간 복잡도는 \(O(n^2)\) (피벗 선택이 최악인 경우)임을 기억하세요. 필요에 따라 피벗 선택 전략(예: 무작위 선택 또는 median‑of‑three)을 바꾸면 최악 상황을 피할 확률을 높일 수 있습니다.
