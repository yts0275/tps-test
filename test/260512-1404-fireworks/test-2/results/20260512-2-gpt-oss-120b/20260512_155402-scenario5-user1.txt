아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 한국어 주석을 달아 이해를 돕도록 했습니다.

```python
# 퀵소트를 수행하는 함수 정의
def quick_sort(arr):
    # 1. 정렬 대상이 비어 있거나 원소가 하나뿐이면 그대로 반환한다.
    if len(arr) <= 1:
        return arr                                            # 이미 정렬된 상태

    # 2. 피벗(pivot)으로 사용할 원소를 선택한다.
    #    여기서는 리스트의 가운데 원소를 피벗으로 잡았다.
    pivot = arr[len(arr) // 2]                                 # 피벗값

    # 3. 피벗보다 작은 원소들을 담을 리스트
    left = []                                                   # 피벗보다 작은 집합

    # 4. 피벗과 같은 원소들을 담을 리스트 (피벗 자체도 포함)
    middle = []                                                 # 피벗과 같은 집합

    # 5. 피벗보다 큰 원소들을 담을 리스트
    right = []                                                  # 피벗보다 큰 집합

    # 6. 원본 리스트의 모든 원소를 순회하면서 위 세 개 리스트에 나눠 담는다.
    for element in arr:
        if element < pivot:                                    # 피벗보다 작으면
            left.append(element)                               # left에 추가
        elif element > pivot:                                  # 피벗보다 크면
            right.append(element)                              # right에 추가
        else:                                                   # 피벗과 같으면
            middle.append(element)                             # middle에 추가

    # 7. 재귀적으로 left와 right를 정렬하고, middle은 그대로 붙인다.
    #    left와 right가 빈 리스트일 경우 재귀 호출이 바로 return 되므로
    #    추가적인 종료 조건이 필요 없다.
    return quick_sort(left) + middle + quick_sort(right)      # 결합하여 반환


# ------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]                # 정렬되지 않은 리스트
    sorted_list = quick_sort(unsorted)                        # 퀵소트 실행
    print("정렬 전:", unsorted)                               # 원본 출력 (변경되지 않음)
    print("정렬 후:", sorted_list)                            # 정렬된 결과 출력
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 리스트 중간 원소를 피벗으로 사용(다른 선택 방법도 가능).  
3. **분할** – 전체 원소를 `left`, `middle`, `right` 세 그룹으로 나눈다.  
4. **재귀 호출** – `left`와 `right`에 대해 동일한 과정을 재귀적으로 수행.  
5. **합치기** – `left` 결과 + `middle` + `right` 결과를 이어 최종 정렬 리스트를 만든다.  

이 구현은 **새로운 리스트를 반환**하는 방식이며, 원본 리스트 `arr`은 변경되지 않습니다.  
필요에 따라 **제자리(in‑place) 퀵소트** 버전으로 변형할 수도 있습니다.
