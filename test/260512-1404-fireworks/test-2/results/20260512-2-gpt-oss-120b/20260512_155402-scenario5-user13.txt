아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘 예시입니다.  
각 코드 라인마다 한국어 주석을 달아 동작을 자세히 설명했습니다. 필요에 따라 `arr` 대신 다른 리스트를 넣어 사용하면 됩니다.

```python
def quick_sort(arr):
    """퀵소트 메인 함수: 리스트를 정렬하고 새 리스트를 반환합니다."""
    # 리스트가 비어 있거나 한 개의 원소만 있으면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                     # 피벗은 리스트의 마지막 원소

    # 피벗보다 작은 원소들을 모아 두는 리스트
    left = []                           # 피벗보다 작은 값들을 저장

    # 피벗보다 큰 원소들을 모아 두는 리스트
    right = []                          # 피벗보다 큰 값들을 저장

    # 피벗을 제외한 나머지 원소들을 순회하면서 left와 right에 분류
    for x in arr[:-1]:                  # 마지막 원소(피벗)를 제외하고 모두 검사
        if x <= pivot:                  # 현재 원소가 피벗보다 작거나 같으면
            left.append(x)              # left 리스트에 추가
        else:                           # 현재 원소가 피벗보다 크면
            right.append(x)             # right 리스트에 추가

    # 재귀적으로 left와 right 부분 리스트를 정렬하고,
    # 정렬된 left + 피벗 + 정렬된 right 순서로 이어서 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 샘플 리스트
    sorted_arr = quick_sort(unsorted)       # 퀵소트 호출
    print("정렬 전:", unsorted)             # 원본 리스트 출력 (변경되지 않음)
    print("정렬 후:", sorted_arr)           # 정렬된 결과 출력
```

### 코드 흐름 요약
1. **기본 조건** – 리스트 길이가 0 또는 1이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용. (다른 전략도 가능)  
3. **분할 단계** – 피벗을 기준으로 `left`와 `right` 두 리스트에 원소를 나눔.  
4. **재귀 호출** – `left`와 `right`를 각각 다시 `quick_sort`로 정렬.  
5. **결합** – 정렬된 `left` + 피벗 + 정렬된 `right`를 이어 최종 정렬 리스트를 만든다.

이러한 방식으로 퀵소트는 평균 **O(N log N)** 의 시간 복잡도를 가지며, 최악의 경우(이미 정렬된 배열에 대해 마지막 원소를 피벗으로 선택) **O(N²)** 가 될 수 있습니다. 피벗 선택 전략을 바꾸면 최악의 경우를 완화할 수 있습니다.
