아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 코드 라인마다 어떤 역할을 하는지 설명하는 주석을 달아두었으니, 코드를 읽으며 흐름을 따라가 보세요.

```python
def quick_sort(arr):                     # 퀵소트를 수행하는 함수 정의 (입력: 정렬할 리스트)
    """
    재귀적으로 퀵소트를 수행해 정렬된 새 리스트를 반환한다.
    원본 리스트는 변경되지 않는다.
    """
    if len(arr) <= 1:                    # 리스트가 비었거나 한 요소만 있으면 이미 정렬된 상태
        return arr.copy()                # 원본을 그대로 반환 (복사본을 만들어 부작용 방지)

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택: 가운데 요소를 기준값으로 사용
    left = []                            # 피벗보다 작은 요소들을 담을 리스트
    middle = []                          # 피벗과 같은 값들을 담을 리스트 (중복 허용)
    right = []                           # 피벗보다 큰 요소들을 담을 리스트

    for x in arr:                        # 입력 리스트의 모든 요소를 하나씩 검사
        if x < pivot:                    # 현재 요소가 피벗보다 작으면
            left.append(x)               # left 리스트에 추가
        elif x > pivot:                  # 현재 요소가 피벗보다 크면
            right.append(x)              # right 리스트에 추가
        else:                            # 현재 요소가 피벗과 같으면(중복 포함)
            middle.append(x)             # middle 리스트에 추가

    # 재귀 호출: left와 right 부분을 각각 다시 퀵소트하고,
    # middle은 피벗값 자체이므로 그대로 유지한다.
    sorted_left = quick_sort(left)       # left 부분을 정렬하고 결과를 저장
    sorted_right = quick_sort(right)     # right 부분을 정렬하고 결과를 저장

    # 정렬된 left + middle(피벗) + 정렬된 right 를 하나의 리스트로 합친다.
    return sorted_left + middle + sorted_right  # 최종 정렬된 리스트 반환


# --------------------------------------------------------------------
# 사용 예시 (테스트용)
if __name__ == "__main__":               # 이 파일이 직접 실행될 때만 아래 코드를 실행
    sample = [33, 10, 55, 71, 29, 3, 18, 40]  # 정렬할 임의의 리스트
    print("Original :", sample)                # 원본 리스트 출력
    print("Sorted   :", quick_sort(sample))    # 퀵소트 결과 출력
```

### 주요 포인트
1. **피벗 선택** – 여기서는 리스트 가운데 값을 피벗으로 사용했지만, 첫 요소, 마지막 요소, 혹은 랜덤 요소 등 다양한 선택 방법이 있다.  
2. **분할(Divide)** – 리스트를 `left`, `middle`, `right` 세 부분으로 나눈 뒤, 각각 재귀적으로 정렬한다.  
3. **합병(Conquer)** – 정렬이 끝난 `left`와 `right`에 `middle`(피벗)을 끼워 넣어 최종 결과를 만든다.  
4. **불변성 유지** – 입력 리스트 `arr`를 직접 수정하지 않고, 복사본을 반환하도록 설계했다.  

이 구현은 가독성이 좋고 이해하기 쉬우며, 작은/중간 규모 데이터에 충분히 빠르게 동작한다. 큰 데이터셋에서는 재귀 깊이 제한이나 피벗 선택 전략을 개선해 최적화할 수 있다.
