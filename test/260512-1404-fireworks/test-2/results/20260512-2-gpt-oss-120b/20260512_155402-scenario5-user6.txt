아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 어떤 역할을 하는지 설명하는 주석을 달아 두었으니, 학습이나 디버깅에 활용하시기 바랍니다.

```python
# quick_sort.py
# 리스트를 퀵소트 알고리즘으로 정렬하는 함수

def quick_sort(arr, low, high):
    """ 
    quick_sort 함수: 배열 arr의 인덱스 low ~ high 구간을 정렬한다.
    재귀 호출을 이용해 부분 배열을 계속 나누어 정렬한다.
    """
    if low < high:                     # 구간에 최소 두 개 이상의 원소가 있을 때만 정렬 진행
        pivot_index = partition(arr, low, high)   # 피벗을 기준으로 배열을 분할하고 피벗의 최종 위치 반환
        quick_sort(arr, low, pivot_index - 1)     # 피벗 왼쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, pivot_index + 1, high)    # 피벗 오른쪽 부분 배열을 재귀적으로 정렬


def partition(arr, low, high):
    """
    partition 함수: 현재 구간 [low, high] 에서 피벗을 정하고,
    피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽에 배치한다.
    최종적으로 피벗이 정확히 정렬된 위치에 놓이게 되고 그 인덱스를 반환한다.
    """
    pivot = arr[high]            # 가장 오른쪽 원소를 피벗으로 선택
    i = low - 1                  # i는 피벗보다 작은 값들의 마지막 인덱스를 가리킴

    # low부터 high-1까지 순회하면서 피벗보다 작은 값을 찾는다
    for j in range(low, high):
        if arr[j] <= pivot:      # 현재 원소가 피벗보다 작거나 같으면
            i += 1               # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]   # 작은 원소를 i 위치로 스와핑

    # 피벗을 i+1 위치에 놓아 정렬을 완성한다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                 # 피벗이 최종적으로 위치한 인덱스를 반환


# ----------------------------------------------------------------------
# 사용 예시 (직접 실행해볼 수 있는 간단한 테스트 코드)
if __name__ == "__main__":
    sample = [33, 10, 55, 71, 29, 3, 18]   # 정렬하고 싶은 임의의 리스트
    print("정렬 전 :", sample)

    quick_sort(sample, 0, len(sample) - 1)   # 전체 리스트에 대해 퀵소트 호출
    print("정렬 후 :", sample)
```

### 코드 흐름 요약
1. `quick_sort`는 **재귀** 함수이며, `low < high` 인 경우에만 작동한다.  
2. `partition` 함수가 피벗을 기준으로 배열을 두 부분으로 나누고 피벗의 최종 위치(`pivot_index`)를 반환한다.  
3. 피벗을 기준으로 좌·우 부분 배열에 대해 각각 다시 `quick_sort`를 호출한다.  
4. 재귀 호출이 끝나면 전체 배열이 오름차순으로 정렬된다.

이 코드는 **시간 복잡도 O(n log n)** (평균)와 **O(n²)** (최악) 를 가지며, **제자리(in‑place)** 로 정렬이 수행됩니다. 필요에 따라 피벗 선택 전략(예: 무작위 피벗)이나 꼬리 재귀 최적화를 추가하면 성능을 더욱 개선할 수 있습니다.
