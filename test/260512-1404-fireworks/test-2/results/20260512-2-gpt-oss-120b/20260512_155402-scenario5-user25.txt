아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 무슨 역할을 하는지 자세히 주석을 달아두었으니, 코드를 따라가며 이해해 보세요.

```python
def quick_sort(arr):
    """퀵소트를 재귀적으로 구현한 함수.
    입력 : 정렬하고 싶은 리스트(arr)
    반환 : 정렬된 새로운 리스트
    """
    # === 1. 베이스 케이스 : 리스트 길이가 0 또는 1이면 이미 정렬돼 있으므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # 반환값은 원본 리스트 자체(복사본이 아님)

    # === 2. 피벗 선택
    # 여기서는 리스트의 마지막 요소를 피벗으로 잡는다.
    # (다른 전략—예: 랜덤 피벗, 중간값 피벗—도 가능)
    pivot = arr[-1]

    # === 3. 피벗보다 작은 요소와 큰 요소를 구분해 두 개의 리스트에 저장
    less = []      # 피벗보다 작은 값들을 모을 리스트
    greater = []   # 피벗보다 큰 값들을 모을 리스트
    equal = []     # 피벗과 같은 값을 모을 리스트 (중복을 고려)

    # 리스트 전체를 순회하면서 분류
    for x in arr:
        if x < pivot:
            less.append(x)      # 피벗보다 작으면 less에 추가
        elif x > pivot:
            greater.append(x)   # 피벗보다 크면 greater에 추가
        else:
            equal.append(x)     # 피벗과 같으면 equal에 추가 (피벗 자체 포함)

    # === 4. 재귀 호출을 이용해 부분 리스트를 정렬
    # less와 greater 부분만 다시 퀵소트 적용
    sorted_less = quick_sort(less)          # 작은 값들 정렬
    sorted_greater = quick_sort(greater)    # 큰 값들 정렬

    # === 5. 정렬된 결과를 합쳐서 반환
    # 순서 : (정렬된 작은 값들) + (피벗과 동일한 값들) + (정렬된 큰 값들)
    return sorted_less + equal + sorted_greater


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 임의의 정수 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42, 5]

    # 퀵소트 실행
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬 결과 :", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트가 비었거나 하나의 원소만 있으면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용.  
3. **분할 단계** – 리스트를 `less`, `equal`, `greater` 세 그룹으로 나눈다.  
4. **재귀 호출** – `less`와 `greater`에 대해 각각 `quick_sort`를 다시 호출해 정렬한다.  
5. **합병 단계** – 정렬된 `less`, `equal`, `greater`를 순서대로 이어 붙여 최종 정렬된 리스트를 만든다.

이 구현은 **새로운 리스트를 반환**하므로 원본 리스트(`unsorted`)는 변하지 않으며, 메모리 사용이 비교적 많지만 가독성이 높은 형태입니다.  
인‑플레이스(in‑place) 버전이 필요하면 `partition` 함수와 인덱스 교환을 이용한 구현도 가능합니다. 필요하면 알려 주세요!
