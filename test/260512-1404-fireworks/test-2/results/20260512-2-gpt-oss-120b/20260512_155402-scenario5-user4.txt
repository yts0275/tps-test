아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 어떤 역할을 하는지 한국어 주석을 달아 두었으니, 코드 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):
    """퀵소트를 수행하고 정렬된 새로운 리스트를 반환한다."""
    
    # 0개 또는 1개의 원소만 있는 리스트는 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)으로 리스트의 마지막 원소를 선택한다.
    pivot = arr[-1]                # ← 기준이 되는 값
    
    # 피벗보다 작은 원소들을 모아 놓을 리스트
    less = []                      
    # 피벗보다 큰 원소들을 모아 놓을 리스트
    greater = []                   
    # 피벗과 같은 값이 여러 개 있을 경우를 대비해 따로 저장한다.
    equal = []                     
    
    # 원소들을 하나씩 검토하면서 세 개의 리스트에 적절히 배분한다.
    for x in arr:
        if x < pivot:              # 피벗보다 작으면 less에 추가
            less.append(x)
        elif x > pivot:            # 피벗보다 크면 greater에 추가
            greater.append(x)
        else:                      # 피벗과 같으면 equal에 추가
            equal.append(x)
    
    # 재귀적으로 less와 greater 부분을 정렬하고,
    # 정렬된 결과를 less + equal + greater 순서로 합쳐 반환한다.
    return quick_sort(less) + equal + quick_sort(greater)


# -----------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬되지 않은 리스트
    sorted_arr = quick_sort(unsorted)           # 퀵소트 호출
    print("정렬 전:", unsorted)                 # 원본 리스트 출력
    print("정렬 후:", sorted_arr)               # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기본 종료 조건** – 원소가 0개 혹은 1개이면 그대로 반환.  
2. **피벗 선택** – 여기서는 리스트의 마지막 원소를 피벗으로 사용.  
3. **분할(partition)** – 모든 원소를 피벗과 비교해 `less`, `equal`, `greater` 세 그룹으로 나눔.  
4. **재귀 호출** – `less`와 `greater` 부분에 대해 같은 과정을 반복(재귀).  
5. **병합(merge)** – 정렬된 `less` + `equal` + 정렬된 `greater`를 이어 최종 결과 반환.  

이렇게 구현된 퀵소트는 평균 O(n log n) 시간 복잡도를 가지며, 최악의 경우(이미 정렬된 배열에 대해 피벗을 끝 원소로 선택) O(n²)까지 떨어질 수 있습니다.  
필요에 따라 피벗 선택 방식을 “무작위 선택”이나 “중앙값 선택” 등으로 바꾸면 최악의 경우를 완화할 수 있습니다.
