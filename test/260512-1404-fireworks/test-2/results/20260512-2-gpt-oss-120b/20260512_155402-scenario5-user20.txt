아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 무슨 역할을 하는지 자세히 설명하는 주석을 달아두었으니, 코드를 따라가며 이해하시면 됩니다.

```python
# 퀵소트 함수: 리스트와 정렬을 할 구간의 시작 인덱스(start)와 끝 인덱스(end)를 매개변수로 받는다
def quick_sort(arr, start, end):
    # 구간이 하나 이하이면 이미 정렬된 상태이므로 바로 반환한다
    if start >= end:
        return

    # -------------------------------------------------
    # 1️⃣ 피벗 선택
    # -------------------------------------------------
    # 여기서는 구간의 가장 오른쪽 요소를 피벗(pivot)으로 잡는다
    pivot = arr[end]

    # -------------------------------------------------
    # 2️⃣ 파티션(partition) 수행
    # -------------------------------------------------
    # i는 피벗보다 작거나 같은 요소들을 모아두는 '경계' 역할을 한다
    i = start - 1

    # start부터 end-1까지 순회하면서 피벗보다 작거나 같은 요소를 찾아 앞쪽으로 옮긴다
    for j in range(start, end):
        # 현재 요소 arr[j]가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            # 경계 i를 하나 늘리고, 그 위치와 현재 요소를 교환한다
            i += 1
            arr[i], arr[j] = arr[j], arr[i]   # swap

    # -------------------------------------------------
    # 3️⃣ 피벗을 올바른 위치에 배치
    # -------------------------------------------------
    # 파티션이 끝난 뒤, 경계 i 바로 다음 위치가 피벗이 들어가야 할 최종 위치다
    # i+1 과 end(피벗)의 값을 교환한다
    arr[i + 1], arr[end] = arr[end], arr[i + 1]   # swap

    # 피벗이 최종적으로 자리 잡은 인덱스
    pivot_index = i + 1

    # -------------------------------------------------
    # 4️⃣ 재귀 호출: 피벗을 기준으로 좌·우 부분 배열을 각각 정렬
    # -------------------------------------------------
    # 피벗 왼쪽 구간 (start ~ pivot_index-1) 정렬
    quick_sort(arr, start, pivot_index - 1)

    # 피벗 오른쪽 구간 (pivot_index+1 ~ end) 정렬
    quick_sort(arr, pivot_index + 1, end)


# -------------------------------------------------
# 사용 예시
# -------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    data = [34, 7, 23, 32, 5, 62, 78, 1, 19]

    # quick_sort에 리스트와 정렬 구간(전체)을 전달한다
    quick_sort(data, 0, len(data) - 1)

    # 정렬이 끝난 리스트 출력
    print("정렬 결과:", data)
```

### 코드 흐름 요약
1. **피벗 선택** – 여기서는 가장 오른쪽 요소(`arr[end]`)를 피벗으로 사용합니다.  
2. **파티션** – `start`부터 `end-1`까지 순회하면서 피벗보다 작거나 같은 값을 앞쪽에 모읍니다.  
3. **피벗 삽입** – 파티션이 끝난 뒤 피벗을 올바른 위치(`i+1`)에 교환해 줍니다.  
4. **재귀 호출** – 피벗을 기준으로 좌·우 서브 배열을 각각 다시 퀵소트합니다.  

이렇게 하면 리스트 전체가 **O(n log n)** 평균 시간 복잡도로 정렬됩니다 (최악의 경우 O(n²)일 수 있지만, 피벗 선택 방식을 개선하면 완화할 수 있습니다).
