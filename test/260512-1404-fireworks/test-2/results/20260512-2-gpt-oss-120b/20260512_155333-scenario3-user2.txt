아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘이며, 각 줄마다 한국어 주석을 달아 두었습니다.  
코드를 그대로 복사해서 실행하면 동작합니다.

```python
# quick_sort 함수 정의: 리스트와 정렬할 구간(left, right)을 인자로 받는다
def quick_sort(arr, left, right):
    # 구간이 하나 이하일 경우(원소가 없거나 하나일 때) 재귀를 종료한다
    if left >= right:
        return

    # 피벗(pivot) 선택: 현재 구간의 가장 오른쪽 원소를 피벗으로 삼는다
    pivot = arr[right]

    # i는 피벗보다 작거나 같은 원소들을 모아 놓을 인덱스이다
    i = left - 1

    # j는 left부터 right-1까지 순회하면서 피벗보다 작은 원소를 찾는다
    for j in range(left, right):
        # 현재 원소가 피벗보다 작거나 같으면, i를 하나 늘리고 두 원소를 교환한다
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]   # 작은 원소를 왼쪽으로 이동

    # 마지막으로 피벗을 i+1 위치로 옮겨서 왼쪽은 모두 피벗보다 작고,
    # 오른쪽은 모두 피벗보다 크게 만든다
    arr[i + 1], arr[right] = arr[right], arr[i + 1]

    # 피벗이 최종적으로 위치한 인덱스
    pivot_index = i + 1

    # 피벗을 기준으로 왼쪽 구간을 재귀적으로 정렬한다
    quick_sort(arr, left, pivot_index - 1)

    # 피벗을 기준으로 오른쪽 구간을 재귀적으로 정렬한다
    quick_sort(arr, pivot_index + 1, right)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 리스트를 정의한다
    data = [34, 7, 23, 32, 5, 62, 78, 1, 9]

    # 원본 리스트를 출력한다
    print("정렬 전:", data)

    # quick_sort 함수를 호출해 전체 리스트를 정렬한다
    quick_sort(data, 0, len(data) - 1)

    # 정렬된 리스트를 출력한다
    print("정렬 후:", data)
```

#### 코드 흐름 요약
1. **재귀 종료 조건**(`left >= right`)에 도달하면 그 구간은 더 이상 정렬할 필요가 없으므로 반환한다.  
2. **피벗**을 현재 구간의 마지막 원소로 선택한다.  
3. `for` 루프를 돌면서 피벗보다 작거나 같은 원소를 앞쪽(`i` 인덱스)으로 옮긴다.  
4. 루프가 끝난 뒤 피벗을 `i+1` 위치에 삽입해 피벗을 기준으로 왼쪽·오른쪽이 구분되도록 만든다.  
5. 구분된 두 구간을 각각 **재귀 호출**해 정렬한다.  

이와 같이 퀵소트는 **분할 정복(Divide and Conquer)** 전략을 사용해 평균 `O(N log N)`의 시간 복잡도로 정렬을 수행합니다. (최악의 경우 `O(N²)`가 될 수 있지만, 피벗 선택을 랜덤하게 하는 등 개선 방법이 존재합니다.)
