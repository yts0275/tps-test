아래는 **Python**으로 구현한 퀵소트(quick sort) 예제입니다.  
각 코드 줄마다 한국어 주석을 달아 두었으니, 흐름을 따라가며 이해하시면 됩니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수를 정의한다.
    if len(arr) <= 1:                    # 배열 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr                        # 그대로 반환한다.

    pivot = arr[len(arr) // 2]           # 피벗(pivot)으로 중간값을 선택한다.
    left = []                            # 피벗보다 작은 원소들을 담을 리스트
    middle = []                          # 피벗과 같은 값들을 담을 리스트
    right = []                           # 피벗보다 큰 원소들을 담을 리스트

    for x in arr:                        # 배열의 모든 원소를 순회한다.
        if x < pivot:                    # 현재 원소가 피벗보다 작으면
            left.append(x)                # left 리스트에 추가한다.
        elif x > pivot:                  # 현재 원소가 피벗보다 크면
            right.append(x)               # right 리스트에 추가한다.
        else:                            # 현재 원소가 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가한다.

    # left와 right 부분을 재귀적으로 정렬하고,
    # 정렬된 left + middle + 정렬된 right 를 이어서 반환한다.
    return quick_sort(left) + middle + quick_sort(right)


# -----------------------------
# 사용 예시
# -----------------------------
if __name__ == "__main__":                # 해당 파일이 직접 실행될 때만 아래 코드를 실행한다.
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]   # 정렬되지 않은 샘플 리스트
    print("정렬 전 :", unsorted)                # 정렬 전 리스트 출력
    sorted_arr = quick_sort(unsorted)           # 퀵소트 함수 호출
    print("정렬 후 :", sorted_arr)              # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 리스트 중간값을 피벗으로 잡는다. (다른 선택 방법도 가능)  
3. **분할** – 원소들을 `left`, `middle`, `right` 세 그룹으로 나눈다.  
4. **재귀 호출** – `left`와 `right`를 각각 다시 `quick_sort`에 넣어 정렬한다.  
5. **결합** – 정렬된 `left` + `middle` + 정렬된 `right` 를 이어서 최종 결과를 만든다.  

주석이 한 줄씩 달려 있으니 코드를 따라가며 퀵소트의 동작 원리를 이해하는 데 도움이 되길 바랍니다!
