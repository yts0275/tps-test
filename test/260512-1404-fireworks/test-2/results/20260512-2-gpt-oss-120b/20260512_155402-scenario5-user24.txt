아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 코드 라인마다 무슨 역할을 하는지 이해하기 쉽게 한글 주석을 달았습니다.

```python
# 퀵소트를 수행하는 함수
def quick_sort(arr):
    # 리스트가 비었거나 원소가 하나만 있으면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                       # 기저 사례(base case)

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                       # 피벗은 정렬 과정에서 기준이 되는 값

    # 피벗보다 작은 요소들을 모아 둘 리스트
    left = []                             # 피벗보다 작은 값들을 저장
    # 피벗보다 큰 요소들을 모아 둘 리스트
    right = []                            # 피벗보다 큰 값들을 저장

    # 피벗을 제외한 나머지 요소들을 순회하면서 left와 right에 분배
    for element in arr[:-1]:              # 마지막 요소(피벗)를 제외한 모든 원소에 대해
        if element <= pivot:              # 현재 원소가 피벗보다 작거나 같으면
            left.append(element)          # left 리스트에 추가
        else:                             # 피벗보다 크면
            right.append(element)         # right 리스트에 추가

    # 재귀 호출을 사용해 left와 right 각각을 정렬하고,
    # 정렬된 left + 피벗 + 정렬된 right 순서로 합쳐 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# -------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted_list = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 임의의 리스트
    sorted_list = quick_sort(unsorted_list)      # 퀵소트 함수 호출
    print("정렬 전:", unsorted_list)             # 정렬 전 리스트 출력
    print("정렬 후:", sorted_list)               # 정렬 후 리스트 출력
```

### 코드 설명
1. **기저 사례** (`len(arr) <= 1`)  
   - 리스트가 비었거나 원소가 하나이면 더 이상 분할할 필요가 없으므로 그대로 반환합니다.
2. **피벗 선택**  
   - 여기서는 가장 마지막 원소를 피벗으로 삼았지만, 무작위 선택이나 중간값 선택 등 다른 전략도 가능합니다.
3. **분할 과정**  
   - 피벗을 기준으로 `left`(피벗 이하)와 `right`(피벗 초과) 두 리스트에 원소를 나눕니다.
4. **재귀 호출**  
   - `left`와 `right` 각각에 대해 같은 과정을 반복해 완전히 정렬된 리스트를 만든 뒤,  
     `left + [pivot] + right` 형태로 합쳐 최종 결과를 반환합니다.

이 구현은 **시간 복잡도**가 평균 `O(N log N)`, 최악 `O(N²)`이며, **추가 메모리**를 `O(N)` 사용합니다.  
입력 크기가 매우 크거나 메모리 사용을 최소화하고 싶다면 **in‑place 퀵소트**(배열을 직접 교환) 구현을 고려해보세요.
