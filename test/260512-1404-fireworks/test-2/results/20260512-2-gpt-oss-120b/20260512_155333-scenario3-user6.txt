아래는 **파이썬**으로 구현한 퀵소트(Quick Sort)입니다.  
각 줄마다 무엇을 하는지 자세히 설명하는 주석을 달았습니다.  
필요에 따라 함수 호출 부분만 복사해서 사용하거나, `arr` 리스트를 바꾸어 테스트해 보세요.

```python
def quick_sort(arr, low, high):                     # quick_sort 함수 정의: arr은 정렬할 리스트, low와 high는 현재 정렬 구간의 인덱스
    if low < high:                                 # 구간에 최소 두 개 이상의 원소가 있을 때만 정렬을 진행
        pi = partition(arr, low, high)             # 파티션 함수를 호출해 피벗을 기준으로 배열을 나누고 피벗의 최종 위치를 반환받음

        quick_sort(arr, low, pi - 1)               # 피벗 왼쪽 부분(피벗보다 작은 원소들) 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)              # 피벗 오른쪽 부분(피벗보다 큰 원소들) 재귀적으로 정렬


def partition(arr, low, high):                      # 파티션 함수: 피벗을 기준으로 원소들을 좌·우로 재배치하고 피벗의 최종 인덱스를 반환
    pivot = arr[high]                               # 일반적인 구현에서는 마지막 원소를 피벗으로 선택
    i = low - 1                                     # i는 "피벗보다 작거나 같은" 영역의 마지막 인덱스를 가리킴; 초기값은 low-1

    for j in range(low, high):                     # j는 현재 조사 중인 원소의 인덱스, low부터 high-1까지 순회
        if arr[j] <= pivot:                        # 현재 원소가 피벗보다 작거나 같으면
            i += 1                                 # i를 한 칸 오른쪽으로 이동(작은 영역 확대)
            arr[i], arr[j] = arr[j], arr[i]        # 작은 영역의 끝(i)과 현재 원소(j)를 교환해 작은 원소를 앞쪽에 배치

    # for 루프가 끝난 뒤 i는 피벗보다 작은 마지막 원소의 인덱스가 된다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]   # 피벗을 작은 영역 바로 뒤(i+1)로 이동시켜 최종 위치 확정
    return i + 1                                    # 피벗의 최종 인덱스를 반환, 이 인덱스를 기준으로 재귀 호출이 나뉨


# ------------------------------
# 사용 예시
# ------------------------------
if __name__ == "__main__":                          # 스크립트가 직접 실행될 때만 아래 코드를 실행
    sample = [34, 7, 23, 32, 5, 62]                # 정렬하고 싶은 임의의 리스트
    print("정렬 전:", sample)                      # 정렬 전 리스트 출력
    quick_sort(sample, 0, len(sample) - 1)         # quick_sort 함수를 호출해 전체 리스트를 정렬
    print("정렬 후:", sample)                      # 정렬된 리스트 출력
```

### 코드 흐름 간단 요약
1. **`quick_sort`**는 재귀적으로 구간을 나누면서 정렬을 수행합니다.  
2. **`partition`**은 마지막 원소를 피벗으로 삼아, 피벗보다 작은 원소들을 왼쪽에, 큰 원소들을 오른쪽에 모아 피벗을 제자리에 놓습니다.  
3. 피벗의 최종 위치(`pi`)를 기준으로 좌·우 구간을 다시 `quick_sort`에 넘겨 재귀 호출합니다.  

이 구현은 평균 시간복잡도 **O(N log N)**, 최악 경우 **O(N²)**(이미 정렬된 배열에 대해 피벗을 최악 선택)이며, **in‑place**(추가 메모리 사용이 거의 없음) 방식입니다. 필요에 따라 피벗 선택 전략(예: 무작위 피벗)이나 꼬리 재귀 최적화 등을 적용하면 최악 상황을 완화할 수 있습니다.
