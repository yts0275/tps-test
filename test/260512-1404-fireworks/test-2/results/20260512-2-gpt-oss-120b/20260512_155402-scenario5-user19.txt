아래는 **Python**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 어떤 역할을 하는지 상세히 주석을 달아 두었으니, 학습이나 참고용으로 활용하시면 됩니다.

```python
# quick_sort 함수: 리스트 전체를 정렬하고 정렬된 새 리스트를 반환합니다.
def quick_sort(arr):
    # 1. 리스트가 비었거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선택 – 여기서는 리스트의 마지막 원소를 피벗으로 사용
    pivot = arr[-1]

    # 3. 피벗보다 작거나 같은 원소들을 담을 left 리스트 초기화
    left = []
    # 4. 피벗보다 큰 원소들을 담을 right 리스트 초기화
    right = []

    # 5. 피벗을 제외한 나머지 원소들을 순회하면서 left와 right에 분배
    for element in arr[:-1]:
        if element <= pivot:          # 피벗보다 작거나 같은 경우
            left.append(element)      # left 리스트에 추가
        else:                         # 피벗보다 큰 경우
            right.append(element)     # right 리스트에 추가

    # 6. left와 right 리스트에 대해서 재귀적으로 quick_sort 호출
    #    (각 부분 리스트가 정렬된 상태가 될 때까지 반복)
    sorted_left = quick_sort(left)    # left 부분 정렬
    sorted_right = quick_sort(right)  # right 부분 정렬

    # 7. 정렬된 left, 피벗, 정렬된 right를 순서대로 합쳐 최종 정렬 결과 반환
    return sorted_left + [pivot] + sorted_right


# ----- 사용 예시 -----
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18]

    # quick_sort 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트 :", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 그대로 반환(이미 정렬된 상태).  
2. **피벗 선택** – 여기서는 가장 오른쪽 원소를 피벗으로 사용했지만, 다른 전략(예: 중앙 원소, 랜덤 원소)도 가능함.  
3. **분할** – 피벗을 기준으로 작은 원소와 큰 원소를 각각 `left`, `right` 리스트에 나눔.  
4. **재귀 호출** – `left`와 `right`에 대해 동일한 `quick_sort`를 수행해 각각 정렬.  
5. **병합** – 정렬된 `left`, 피벗, 정렬된 `right`를 순서대로 연결해 최종 정렬된 리스트를 만든다.

이 구현은 **제자리(in‑place) 정렬**이 아니라 새로운 리스트를 반환하는 형태이므로 메모리 사용량이 약간 더 늘어나지만, 이해하기 쉽고 디버깅하기에 편리합니다.  
필요에 따라 `left`와 `right`를 별도 리스트 대신 인덱스를 활용해 제자리 정렬 버전으로 변형할 수도 있습니다.
