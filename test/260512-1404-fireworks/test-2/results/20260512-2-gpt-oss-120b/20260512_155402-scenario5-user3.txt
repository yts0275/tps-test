아래는 **Python** 로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 무엇을 하는지 자세히 설명하는 주석을 달아두었습니다.  
코드와 주석을 그대로 복사해서 사용하면 바로 동작합니다.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    """
    입력 배열 arr을 정렬해서 새로운 리스트를 반환한다.
    원본 리스트는 변경하지 않는다(불변성 유지).
    """
    # 배열이 비었거나 원소가 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 가장 오른쪽 원소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 원소들을 모아 둘 리스트
    less = []
    # 피벗과 같은 값을 모아 둘 리스트 (중복된 피벗을 처리)
    equal = []
    # 피벗보다 큰 원소들을 모아 둘 리스트
    greater = []

    # 전체 배열을 한 번 순회하면서 세 개의 리스트에 원소를 분류
    for x in arr:
        if x < pivot:        # 피벗보다 작으면 less에 저장
            less.append(x)
        elif x == pivot:     # 피벗과 같으면 equal에 저장
            equal.append(x)
        else:                # 피벗보다 크면 greater에 저장
            greater.append(x)

    # 재귀적으로 less와 greater 리스트를 각각 정렬하고,
    # 정렬된 결과를 less + equal + greater 순서로 합쳐 반환
    return quick_sort(less) + equal + quick_sort(greater)


# ------------------- 사용 예시 -------------------
if __name__ == "__main__":
    # 정렬하고 싶은 예시 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42, 7]

    # 퀵소트 함수를 호출해 정렬된 리스트를 얻는다
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 간단 요약
1. **기본 종료 조건** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 다른 전략(첫 번째 원소, 무작위 선택 등)도 가능.  
3. **분할 과정** – `less`, `equal`, `greater` 세 리스트에 원소를 분류.  
4. **재귀 호출** – `less`와 `greater`에 대해 각각 다시 `quick_sort`를 호출해 정렬하고, 결과를 합쳐 최종 리스트를 만든다.  
5. **불변성 유지** – 입력 리스트 `arr`를 직접 수정하지 않고, 새로운 리스트를 반환한다.

필요에 따라 피벗 선택 방식이나 `in-place`(제자리) 버전으로 변형할 수 있습니다. 궁금한 점이 있으면 언제든 물어보세요!
