아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
코드의 **각 라인마다** 무슨 작업을 하는지 설명하는 주석을 달아두었으니, 이해하는 데 도움이 되길 바랍니다.

```python
def quicksort(arr):                     # 퀵소트를 수행할 함수를 정의하고, 정렬할 리스트(arr)를 매개변수로 받는다.
    if len(arr) <= 1:                   # 리스트의 길이가 0 또는 1이면 이미 정렬된 상태이므로
        return arr                      # 그대로 반환한다.

    pivot = arr[-1]                      # 피벗(pivot)을 리스트의 마지막 요소로 선택한다.
    less = []                            # 피벗보다 작은 값들을 담을 빈 리스트를 만든다.
    equal = []                           # 피벗과 같은 값들을 담을 빈 리스트를 만든다.
    greater = []                         # 피벗보다 큰 값들을 담을 빈 리스트를 만든다.

    for x in arr:                       # 원본 리스트를 하나씩 순회한다.
        if x < pivot:                    # 현재 원소가 피벗보다 작으면
            less.append(x)               # less 리스트에 추가한다.
        elif x == pivot:                 # 현재 원소가 피벗과 같으면
            equal.append(x)              # equal 리스트에 추가한다.
        else:                            # 현재 원소가 피벗보다 크면
            greater.append(x)            # greater 리스트에 추가한다.

    # 재귀적으로 less와 greater 부분을 각각 정렬하고,
    # 정렬된 less, 피벗(=equal), 정렬된 greater를 차례대로 이어서 반환한다.
    return quicksort(less) + equal + quicksort(greater)


# -------------------------------------------------------
# 사용 예시
if __name__ == "__main__":               # 이 파일을 직접 실행할 때만 아래 코드를 실행한다.
    sample = [33, 10, 55, 71, 29, 3, 18] # 정렬할 샘플 리스트
    sorted_sample = quicksort(sample)   # 퀵소트 함수를 호출해 정렬한다.
    print("원본 리스트 :", sample)       # 정렬 전 리스트를 출력한다.
    print("정렬 결과 :", sorted_sample) # 정렬 후 리스트를 출력한다.
```

**설명 요약**

1. **기본 종료 조건** – 리스트 길이가 1 이하이면 더 이상 분할할 필요가 없으므로 그대로 반환합니다.  
2. **피벗 선택** – 여기서는 간단히 마지막 요소를 피벗으로 잡았습니다. (다른 선택 전략도 가능)  
3. **분할(Partition)** – 리스트를 `less`, `equal`, `greater` 세 그룹으로 나눕니다.  
4. **재귀 호출** – `less`와 `greater`에 대해 다시 `quicksort`를 호출해 정렬하고, 세 그룹을 순서대로 합칩니다.  

이 구현은 **가독성이 높고** 각 단계가 명확히 드러나도록 작성되었습니다. 필요에 따라 피벗 선택 방식을 바꾸거나 제자리(in‑place) 버전으로 최적화할 수도 있습니다. Happy coding! 🚀
