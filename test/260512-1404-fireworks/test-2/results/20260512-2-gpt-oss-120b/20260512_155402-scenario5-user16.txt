아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 달아 두었으니, 알고리즘 흐름을 따라가면서 이해하기 쉬울 겁니다.  

```python
def quick_sort(arr):
    """리스트 arr을 정렬해서 새로운 리스트를 반환하는 퀵소트 구현"""

    # 1️⃣  정렬할 원소가 0개 또는 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                                 # ──> 베이스 케이스

    # 2️⃣  피벗(pivot) 선택: 여기서는 리스트의 가장 오른쪽 요소를 피벗으로 사용
    pivot = arr[-1]                                 # ──> 기준값

    # 3️⃣  피벗보다 작은 요소를 저장할 리스트와 큰 요소를 저장할 리스트를 초기화
    left = []                                       # ──> 피벗보다 작은 값들의 집합
    right = []                                      # ──> 피벗보다 큰 값들의 집합

    # 4️⃣  피벗을 제외한 나머지 요소들을 순회하면서 left / right에 분류
    for element in arr[:-1]:                        # ──> 피벗 제외 모든 원소
        if element <= pivot:                        # ──> 피벗보다 작거나 같은 경우
            left.append(element)                    #     ──> left 리스트에 추가
        else:                                       # ──> 피벗보다 큰 경우
            right.append(element)                   #     ──> right 리스트에 추가

    # 5️⃣  재귀 호출을 통해 left와 right 부분을 각각 정렬
    sorted_left = quick_sort(left)                  # ──> 좌측 파티션 정렬
    sorted_right = quick_sort(right)                # ──> 우측 파티션 정렬

    # 6️⃣  정렬된 left + 피벗 + 정렬된 right 를 이어 붙여 최종 결과 반환
    return sorted_left + [pivot] + sorted_right     # ──> 합병 단계 (concatenation)
```

---

### 코드 흐름 요약

| 단계 | 설명 |
|------|------|
| **베이스 케이스** | `len(arr) <= 1`이면 이미 정렬된 것이므로 바로 반환 |
| **피벗 선택** | 현재 구현에서는 마지막 요소(`arr[-1]`)를 피벗으로 사용 |
| **분할 (Partition)** | 피벗을 기준으로 작은 값은 `left`, 큰 값은 `right`에 분류 |
| **재귀 호출** | `left`와 `right`를 각각 다시 `quick_sort`에 넘겨 정렬 |
| **결합 (Combine)** | `sorted_left + [pivot] + sorted_right` 로 최종 정렬된 리스트 생성 |

---

### 실행 예시

```python
if __name__ == "__main__":
    unsorted = [34, 7, 23, 32, 5, 62]
    print("정렬 전 :", unsorted)
    print("정렬 후 :", quick_sort(unsorted))
```

**출력**

```
정렬 전 : [34, 7, 23, 32, 5, 62]
정렬 후 : [5, 7, 23, 32, 34, 62]
```

### 참고 사항

1. **시간 복잡도**  
   - 평균: `O(N log N)`  
   - 최악(이미 정렬된 배열 등): `O(N²)` (피벗 선택이 좋지 않을 경우)

2. **공간 복잡도**  
   - 재귀 호출 때문에 최악 `O(N)` 수준의 스택 메모리를 사용합니다.  
   - 위 구현은 **새로운 리스트**를 매번 만들어 반환하므로 **추가적인 O(N)** 메모리가 필요합니다.

3. **피벗 선택 전략 개선**  
   - 현재는 마지막 요소를 피벗으로 사용했지만,  
     - `random.choice(arr)` 로 랜덤 피벗을 고르거나  
     - “median‑of‑three” 전략 등으로 피벗을 고르면 최악 경우를 더 낮출 수 있습니다.
