아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 무슨 일을 하는지 상세히 주석을 달아두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):
    """
    리스트 arr 를 정렬된 새로운 리스트로 반환한다.
    (제자리(in‑place) 정렬이 아니라 새로운 리스트를 만든다.)
    """

    # 1. 리스트가 비어 있거나 원소가 한 개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                                 # ★ 기본(베이스) 경우

    # 2. 피벗(pivot) 선택
    #    여기선 리스트의 중간 값을 피벗으로 잡는다.
    #    (첫 번째 원소, 마지막 원소, 무작위 선택 등도 가능)
    pivot = arr[len(arr) // 2]

    # 3. 피벗보다 작은 원소들을 모아 left 리스트에 담는다.
    left = [x for x in arr if x < pivot]

    # 4. 피벗과 같은 값을 모아 middle 리스트에 담는다.
    #    (피벗이 중복될 경우를 대비)
    middle = [x for x in arr if x == pivot]

    # 5. 피벗보다 큰 원소들을 모아 right 리스트에 담는다.
    right = [x for x in arr if x > pivot]

    # 6. 왼쪽 부분(left)과 오른쪽 부분(right)을 각각 재귀적으로 정렬하고,
    #    정렬된 결과를 left, middle, right 순서로 합쳐서 반환한다.
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]
    print("정렬 전 :", unsorted)

    sorted_list = quick_sort(unsorted)
    print("정렬 후 :", sorted_list)
```

### 코드 흐름 요약
1. **기본 경우** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 여기선 중간값을 피벗으로 사용했지만, 다른 선택 방법도 가능.  
3. **분할** – 리스트를 피벗보다 작은 `left`, 같은 `middle`, 큰 `right` 세 부분으로 나눈다.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 정렬한다.  
5. **결합** – `left`(정렬된) + `middle` + `right`(정렬된) 순서대로 합쳐 최종 결과를 만든다.

### 참고 사항
- **시간 복잡도**  
  - 평균: **O(N log N)**  
  - 최악(이미 정렬된 경우 등): **O(N²)** (피벗 선택 전략을 바꾸면 완화 가능)
- **공간 복잡도**  
  - 리스트를 새로 만들어서 반환하므로 **O(N)** 이 추가로 필요합니다. 제자리(in‑place) 퀵소트를 원한다면 `partition` 과 `swap`을 활용한 구현으로 바꿀 수 있습니다.
