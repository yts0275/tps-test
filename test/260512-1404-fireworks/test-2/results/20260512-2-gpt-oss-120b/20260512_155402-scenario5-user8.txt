아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 달아 두었습니다.  
필요에 따라 `quick_sort` 함수만 호출하면 정렬된 리스트를 얻을 수 있습니다.

```python
def quick_sort(arr):
    """리스트 arr를 퀵소트를 이용해 정렬하고 반환한다."""
    
    # 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                              # O(1)

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 잡는다
    pivot = arr[-1]                            # O(1)

    # 피벗보다 작은 원소들을 담을 리스트
    less = []                                   # O(1)

    # 피벗과 같은 원소들을 담을 리스트 (피벗 자체도 포함)
    equal = []                                  # O(1)

    # 피벗보다 큰 원소들을 담을 리스트
    greater = []                                # O(1)

    # 리스트 전체를 순회하면서 세 개의 서브리스트에 원소를 분배
    for x in arr:
        if x < pivot:                           # 피벗보다 작다면
            less.append(x)                      # less 리스트에 추가
        elif x == pivot:                        # 피벗과 같다면
            equal.append(x)                     # equal 리스트에 추가
        else:                                   # 피벗보다 크다면
            greater.append(x)                   # greater 리스트에 추가

    # 재귀 호출을 통해 less와 greater를 각각 정렬하고,
    # 정렬된 결과와 equal 리스트를 이어 붙인다
    return quick_sort(less) + equal + quick_sort(greater)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬하고 싶은 임의의 리스트
    sorted_arr = quick_sort(unsorted)           # 퀵소트 실행
    print("정렬 전:", unsorted)                 # 정렬 전 리스트 출력
    print("정렬 후:", sorted_arr)               # 정렬된 리스트 출력
```

### 코드 설명 (주석 외)

1. **피벗 선택**  
   - 여기서는 가장 간단하게 마지막 원소를 피벗으로 잡았지만,  
     최악의 경우(`O(n²)`)를 최소화하려면 `random.choice` 로 무작위 피벗을 고르거나  
     “median‑of‑three” 전략을 사용할 수 있습니다.

2. **분할 단계**  
   - `less`, `equal`, `greater` 세 리스트에 각각 `pivot`보다 작은, 같은, 큰 원소를 저장합니다.  
   - 이 과정은 `O(n)` 시간 복잡도를 가집니다.

3. **재귀 호출**  
   - `less`와 `greater`에 대해 같은 작업을 반복하면서 리스트가 0·1개가 될 때까지 내려갑니다.  
   - 평균 시간 복잡도는 `O(n log n)`, 최악의 경우는 `O(n²)`입니다.

4. **합병 단계**  
   - 정렬된 `less`와 `greater` 리스트에 `equal` 리스트를 가운데에 끼워 최종 결과를 반환합니다.

이 구현은 **가독성이 높고 이해하기 쉬운** 형태이며, 교육용이나 작은 데이터셋에 적합합니다.  
대용량 데이터에 대해서는 제자리(in‑place) 퀵소트를 구현하거나, 파이썬 내장 `sorted()`(Timsort)를 사용하는 것이 더 효율적일 수 있습니다.
