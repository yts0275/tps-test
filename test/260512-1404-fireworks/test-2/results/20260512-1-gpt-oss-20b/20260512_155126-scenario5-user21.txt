아래는 **Python** 로 작성한 퀵소트(Quick Sort) 구현 예시입니다.  
각 줄마다 상세한 주석을 달아, 동작 흐름이 한눈에 이해되도록 하였습니다.

```python
def quick_sort(arr):                     # 1: 배열(리스트)를 인자로 받는 함수 정의
    if len(arr) <= 1:                    # 2: 배열의 길이가 0이나 1이면 이미 정렬된 상태
        return arr                       # 3: 그대로 반환 후 종료

    pivot = arr[len(arr) // 2]           # 4: 중간값을 피벗으로 선택 (실전에서는 다양한 전략이 존재)
    left = [x for x in arr if x < pivot] # 5: 피벗보다 작은 값들만 모음
    middle = [x for x in arr if x == pivot]  # 6: 피벗과 같은 값들(중복 처리용)
    right = [x for x in arr if x > pivot]  # 7: 피벗보다 큰 값들만 모음

    # 재귀적으로 좌우 부분 배열을 정렬하고, 각각을 병합
    return quick_sort(left) + middle + quick_sort(right)   # 8: 최종 정렬된 리스트 반환
```

## 사용 예시

```python
if __name__ == "__main__":          # 1: 스크립트 실행 시 바로 테스트
    sample = [3, 6, 8, 10, 1, 2, 1] # 2: 임의의 숫자 리스트
    sorted_list = quick_sort(sample)      # 3: 퀵소트 함수 호출
    print(sorted_list)             # 4: 결과 출력
```

### 결과
```
[1, 1, 2, 3, 6, 8, 10]
```

### 주의 사항
- 위 구현은 **피벗을 중간값으로 고정**한 단순 버전이므로, 불균형한 입력(예: 이미 정렬된 배열 등)에서는 성능이 최악이 될 수 있습니다.
- 실제 활용 시에는 **3중 선택**(중간값, 첫 번째 값, 마지막 값 중 평균)이나 **런덤 피벗** 등의 전략을 도입하면 평균 시간 복잡도가 거의 **O(n log n)** 으로 유지됩니다.
- 파이썬의 리스트 복사와 리스트 이해(list comprehension)은 편리하지만 메모리 사용량이 증가하므로, 대규모 데이터에는 인덱스 기반 제자리(in‑place) 버전이 권장됩니다.

필요에 따라 `quick_sort_inplace` 같은 제자리 구현을 도입할 수도 있으니, 구현 목적에 맞게 활용해 보세요!
