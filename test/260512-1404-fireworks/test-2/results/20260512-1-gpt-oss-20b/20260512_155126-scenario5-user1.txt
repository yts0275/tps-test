아래는 **Python** 으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
프로그램의 각 줄마다 `#` 뒤에 주석을 달아 동작을 설명했습니다.  

```python
# 퀵소트(QuickSort)를 재귀적으로 구현한 함수
def quicksort(arr):
    # 리스트가 0개 또는 1개일 때는 이미 정렬되어 있으므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # 정리: 바닐라 케이스

    # 첫 번째 원소를 피벗(pivot)으로 선택
    pivot = arr[0]                     # pivot 선정

    # 피벗보다 작거나 같은 원소를 담을 리스트
    less = []                          # left partition
    # 피벗보다 큰 원소를 담을 리스트
    greater = []                       # right partition

    # 피벗을 제외한 나머지 원소들을 순회하면서 두 리스트에 분리
    for x in arr[1:]:
        if x <= pivot:                 # 작은(또는 같은) 경우
            less.append(x)             # less에 저장
        else:                          # 큰 경우
            greater.append(x)          # greater에 저장

    # 재귀 호출로 left와 right를 각각 정렬하고
    # pivot을 가운데에 삽입해 최종 정렬된 리스트 반환
    return quicksort(less) + [pivot] + quicksort(greater)

# 사용 예시
if __name__ == "__main__":
    # 정렬되지 않은 예시 리스트
    data = [3, 6, 8, 10, 1, 2, 1]
    # 퀵소트를 수행하고 결과를 출력
    sorted_data = quicksort(data)
    print(sorted_data)      # 출력: [1, 1, 2, 3, 6, 8, 10]
```

### 코멘트 요약
- `quicksort` 함수는 재귀적으로 구현되었으며, 입력 리스트가 `0` 또는 `1`개의 원소를 가질 때 바로 반환합니다.  
- 피벗을 `arr[0]` 로 지정하고, `less` 와 `greater` 두 개의 리스트에 피벗보다 작은/큰 원소를 분리합니다.  
- 분리된 두 리스트를 재귀적으로 정렬한 뒤에 `pivot` 을 가운데에 넣어 최종 정렬된 리스트를 반환합니다.  
- `if __name__ == "__main__":` 블록에서는 예시 데이터를 정의하고, 함수 사용 예시를 보여줍니다.  

이 코드에는 한 줄마다 주석이 포함되어 있어, 각 단계가 무엇을 수행하는지 바로 알 수 있도록 하였습니다.
