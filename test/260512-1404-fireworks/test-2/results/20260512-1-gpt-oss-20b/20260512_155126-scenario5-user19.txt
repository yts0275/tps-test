아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 예시입니다.  
코드의 **모든 줄**에 한 줄씩 주석(한국어) 을 달아 이해가 쉽게 했습니다.

```python
def quicksort(arr):                    # 1. 정렬할 리스트를 받아 정렬이 완료된 리스트를 반환하는 함수 정의
    if len(arr) <= 1:                  # 2. 리스트가 0개 또는 1개라면 그대로 반환(기저 사례)
        return arr                     # 3. 정렬이 필요없는 경우 바로 반환
    pivot = arr[len(arr) // 2]         # 4. 리스트의 중간 값을 pivot(절정값) 으로 선정
    left = [x for x in arr if x < pivot]   # 5. pivot 보다 작은 값들만 모아 left 리스트 생성
    middle = [x for x in arr if x == pivot]# 6. pivot 와 같은 값들만 모아 middle 리스트 생성
    right = [x for x in arr if x > pivot]  # 7. pivot 보다 큰 값들만 모아 right 리스트 생성
    return quicksort(left) + middle + quicksort(right)   # 8. 재귀 호출로 left와 right를 정렬한 후 연결

# 아래 예시는 함수가 어떻게 동작하는지 보여줍니다.
if __name__ == "__main__":            # 9. 바로 실행될 때만 아래 코드가 평가되도록 함
    unsorted = [3, 6, 8, 10, 1, 2, 1]  # 10. 정렬할 예시 리스트 정의
    print("정렬 전:", unsorted)       # 11. 정렬 전 리스트 출력
    sorted_list = quicksort(unsorted)  # 12. quicksort 함수를 호출해 정렬 수행
    print("정렬 후:", sorted_list)    # 13. 정렬 결과 출력
```

**주요 포인트**

1. **기저 사례**(`if len(arr) <= 1`) – 재귀가 끝나는 조건입니다.  
2. **pivot 선택** – 중간 값을 사용했지만, 분할 전략에 따라 다양한 방법을 쓸 수 있습니다.  
3. **리스트 컴프리헨션**을 이용해 `left`, `middle`, `right`를 한 번에 생성했습니다.  
4. 최종적으로 재귀적으로 정렬한 `left`와 `right`를 `middle`과 연결해 반환합니다.  

이 코드는 **공간 복잡도**가 O(n) 만큼의 임시 리스트를 사용하지만, **시간 복잡도**는 평균적으로 O(n log n)입니다. 필요에 따라 인덱스 기반 구현으로 공간 사용을 줄일 수도 있습니다.
