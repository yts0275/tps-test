아래는 파이썬으로 작성한 **퀵소트(QuickSort)** 구현 예시입니다.  
코드의 각 문장마다 그 역할을 설명하는 주석을 추가했습니다.

```python
def quick_sort(arr):
    # 1. 정렬을 수행할 함수 정의
    
    if len(arr) <= 1:
        # 2. 배열에 0개 또는 1개의 원소가 있으면 이미 정렬된 상태이므로 그대로 반환
        return arr
    
    pivot = arr[-1]
    # 3. 피봈(Pivot) 선택 – 가장 간단하게 마지막 원소를 피봈으로 사용
    
    # 4. 피봈보다 작거나 같은 원소를 한 리스트에 모음(리스트 내포 사용)
    less = [x for x in arr[:-1] if x <= pivot]
    
    # 5. 피봈보다 큰 원소를 다른 리스트에 모음(리스트 내포 사용)
    greater = [x for x in arr[:-1] if x > pivot]
    
    # 6. 1단계와 2단계가 재귀적으로 반복된 뒤, 정렬된 'less'와 'greater' 리스트를
    #     피봇과 합쳐서 완전한 정렬 결과를 반환
    return quick_sort(less) + [pivot] + quick_sort(greater)

# ---------------------------------------------
# 아래 코드는 quick_sort 함수를 테스트하는 예시입니다.
if __name__ == "__main__":

    # 7. 정렬할 예제 배열 생성
    sample = [33, 10, 55, 71, 29, 5, 4, 99]
    
    # 8. quick_sort 함수 호출
    sorted_sample = quick_sort(sample)
    
    # 9. 결과 출력
    print("정렬 전:", sample)
    print("정렬 후:", sorted_sample)
```

> **출력 결과 예시**
> ```
> 정렬 전: [33, 10, 55, 71, 29, 5, 4, 99]
> 정렬 후: [4, 5, 10, 29, 33, 55, 71, 99]
> ```

- **주의**: 이 구현은 새로운 리스트를 매 단계마다 만들기 때문에 메모리 사용량이 많습니다.  
  인‑플레이스(배열을 직접 재정렬) 방식이 필요하면 `partition` 함수를 별도로 구현해서 재귀 호출 대신 반복문으로 수행하면 좋습니다.
