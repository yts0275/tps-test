아래는 **Python**으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
코드의 각 줄마다 한 줄씩 주석을 달았으니 읽어보시면 바로 이해가 가능합니다.

```python
# 리스트 (array)를 정렬하기 위한 함수, 반환값은 정렬된 리스트
def quick_sort(array):
    # 배열이 비었거나 원소가 한 개 이하이면 이미 정렬된 상태 -> 그대로 반환
    if len(array) <= 1:
        return array
    
    # 피벗으로 첫 번째 원소를 선택
    pivot = array[0]
    
    # 피벗보다 작은 값들을 모아 놓을 리스트
    less = []
    # 피벗보다 큰 값들을 모아 놓을 리스트
    greater = []
    
    # 나머지 원소들을 순회하면서 less 또는 greater에 넣는다
    for x in array[1:]:
        if x <= pivot:          # 피벗과 같거나 작으면 less에 추가
            less.append(x)
        else:                   # 그렇지 않으면 greater에 추가
            greater.append(x)
    
    # 재귀적으로 정렬을 수행하고 결과를 결합(피벗은 가운데 두고)
    return quick_sort(less) + [pivot] + quick_sort(greater)
```

#### 코드 해설

| 줄 | 코드 | 주석 (한글) |
|---|------|--------------|
| 1 | `def quick_sort(array):` | 정렬을 수행할 함수 정의 |
| 2 | `    if len(array) <= 1:` | 길이가 0 또는 1인 배열은 정렬 필요 없음 |
| 3 | `        return array` | 단일 배열 그대로 반환 |
| 4 | `    pivot = array[0]` | 피벗으로 첫 번째 원소를 선택 |
| 5 | `    less = []` | 피벗보다 작은 값을 모을 리스트 초기화 |
| 6 | `    greater = []` | 피벗보다 큰 값을 모을 리스트 초기화 |
| 7 | `    for x in array[1:]:` | 피벗을 제외한 나머지 원소 순회 |
| 8 | `        if x <= pivot:` | 피벗보다 작거나 같은 경우 |
| 9 | `            less.append(x)` | less 리스트에 추가 |
| 10 | `        else:` | 피벗보다 큰 경우 |
| 11 | `            greater.append(x)` | greater 리스트에 추가 |
| 12 | `    return quick_sort(less) + [pivot] + quick_sort(greater)` | 재귀 호출로 정렬 후 피벗과 결합 |

---

### 사용 예시

```python
if __name__ == "__main__":
    arr = [3, 6, 8, 10, 1, 2, 1]
    sorted_arr = quick_sort(arr)
    print("정렬 전:", arr)
    print("정렬 후:", sorted_arr)
```

위 예시를 실행하면

```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

포함됩니다. 퀵소트는 평균적으로 **O(n log n)**의 시간복잡도를 가지지만, 최악의 경우(이미 정렬된 입력 등)에서는 **O(n²)**가 될 수 있습니다.  
필요하다면 피벗 선택 방식을 랜덤화하거나 하이브리드(예: 삽입 정렬과 결합) 등으로 최적화할 수 있습니다.
