아래는 **Python** 으로 구현한 퀵소트(QuickSort) 예시입니다.  
각 줄마다 한글 주석을 달아, 코드가 무슨 일을 하는지 한눈에 이해할 수 있도록 했습니다.

```python
# 퀵소트(QuickSort) 알고리즘 (in‑place 방식)
#
# 1. quicksort 함수 : 주어진 배열의 low~high 구간을 재귀적으로 정렬
# 2. partition 함수 : 피봇(pivot)을 기준으로 왼쪽에는 <=, 오른쪽에는 > 를 배치
#    그리고 피봇이 올바른 위치에 놓이도록 반환값으로 인덱스를 리턴

# 파이썬 스크립트 실행 시 사용하기 위해 필요한 표준 입력/출력도 포함
# (필요 없는 경우 생략 가능)

# ---------------- 1) 퀵소트 함수 정의 ----------------
def quicksort(arr, low, high):
    """
    재귀적으로 주어진 범위(low~high)를 정렬한다.
    
    :param arr: 정렬할 리스트
    :param low: 정렬 시작 인덱스 (정수)
    :param high: 정렬 종료 인덱스 (정수)
    """
    # QuickSort의 종료 조건: 구간에 원소가 1개 이하일 때 (low >= high)
    if low < high:
        # partition 함수를 호출해 피봇의 최종 인덱스를 얻는다.
        pivot_index = partition(arr, low, high)
        # 피봇보다 왼쪽에 있는 구간을 재귀 정렬
        quicksort(arr, low, pivot_index - 1)
        # 피봇보다 오른쪽에 있는 구간을 재귀 정렬
        quicksort(arr, pivot_index + 1, high)

# ---------------- 2) 파티션 함수 정의 ----------------
def partition(arr, low, high):
    """
    피봇(마지막 원소)을 기준으로 배열을 두 부분으로 나눈다.
    
    :param arr: 정렬할 리스트
    :param low: 파티션 시작 인덱스
    :param high: 파티션 종료 인덱스 (피봇이 위치할 인덱스)
    :return: 피봇이 최종적으로 놓인 인덱스
    """
    # 피봇은 파티션 구간의 마지막 원소로 설정
    pivot = arr[high]
    # i는 피봇보다 작은 원소가 들어갈 최종 인덱스(지금은 아직 올바른 위치 안 됨)
    i = low - 1
    # j는 현재 검사 중인 원소를 가리키는 인덱스
    for j in range(low, high):
        # arr[j] 가 피봇보다 작거나 같으면, 그 위치에 i+1 인덱스를 넣는다.
        if arr[j] <= pivot:
            # i 를 1 증가시키고, i 와 j 기준 원소를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    # 마지막에 피봇을 i+1 인덱스로 옮겨서, 피봇을 순서에 맞게 놓는다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피봇이 놓인 최종 인덱스를 반환
    return i + 1

# ---------------- 3) 사용 예시 (필요 시에만) ----------------
if __name__ == "__main__":
    # 예시 입력 리스트
    data = [32, 10, 45, 3, 27, 9, 18, 4]
    print("정렬 전:", data)
    # quicksort 호출: 전체 범위를 지정 (index 0부터 마지막 원소까지)
    quicksort(data, 0, len(data) - 1)
    print("정렬 후 :", data)
```

### 코드 해설

| 라인 | 설명 |
|------|------|
| **1~3** | 퀵소트와 파티션 함수의 간략한 문서화 |
| **6** | 퀵소트의 종료 조건 `low < high`는 구간에 적어도 두 개의 원소가 있을 때만 재귀 호출 |
| **8** | 파티션 함수 호출로 피봇이 끝나는 인덱스 얻기 |
| **10-11** | 피봇을 기준으로 왼쪽과 오른쪽 부분을 재귀로 정렬 |
| **15** | 피봇을 `arr[high]`로 설정 |
| **16** | `i`는 피봇보다 작은 원소가 놓일 최선의 인덱스를 가리킴 |
| **18-20** | `j`를 이용해 모든 원소를 검사하며 `arr[j] ≤ pivot`이면 `i`를 증가시키고 교환 |
| **22** | 피봇을 `i+1` 위치에 놓음으로써 피봇보다 작은 값이 좌측에, 큰 값이 우측에 배치 |
| **24** | 피봇의 최종 인덱스를 반환해 재귀 호출에서 사용 |

이 스크립트를 그대로 복사해 실행하면, `data` 리스트가 퀵소트를 통해 오름차순으로 정렬됩니다.  
한 줄마다 주석을 달았으므로, 처음 퀵소트에 대해 배우는 사람도 코드를 따라가며 이해하기 쉬울 것입니다.
