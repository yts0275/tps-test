아래는 파이썬으로 구현한 **퀵소트(Quick Sort)**입니다.  
코드 아래에 있는 각 줄마다 **한 줄씩 주석**을 달아, 동작 과정을 명확히 설명했습니다.  
필요에 따라 리스트를 그대로 정렬하거나 새로운 리스트를 반환하도록 두 가지 버전을 예시로 넣어두었습니다.

```python
# ------------------------------------------------------------
# 1. 파이썬으로 퀵소트 구현 예시 (원본 리스트를 인_place 방식으로 정렬)
# ------------------------------------------------------------
def quick_sort_inplace(arr, low, high):
    """
    arr : 정렬할 리스트
    low : 현재 정렬 구간의 시작 인덱스
    high: 현재 정렬 구간의 끝 인덱스
    """
    if low < high:                                   # 2. 정렬구간이 유효한 경우에만 처리
        pivot_index = partition(arr, low, high)      # 3. 피벗을 포함하는 최종 위치 찾기
        quick_sort_inplace(arr, low, pivot_index-1)  # 4. 피벗 왼쪽 부분 재귀 호출
        quick_sort_inplace(arr, pivot_index+1, high) # 5. 피벗 오른쪽 부분 재귀 호출


def partition(arr, low, high):
    """
    피벗(보통 고른 마지막 원소)을 기준으로 정렬 구간을 두 부분으로 나누는 함수
    """
    pivot = arr[high]                                # 6. 피벗 값 저장 (보통 마지막 원소 사용)
    i = low - 1                                      # 7. 삽입 위치 인덱스 초기화
    for j in range(low, high):                        # 8. 총 구간(피벗 제외) 순회
        if arr[j] <= pivot:                          # 9. 현재 원소가 피벗보다 작거나 같은 경우
            i += 1                                   # 10. 삽입 위치를 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]         # 11. 현재 원소와 i 위치의 원소 교환
    arr[i+1], arr[high] = arr[high], arr[i+1]        # 12. 피벗을 정렬된 위치에 놓음
    return i + 1                                     # 13. 피벗 인덱스를 반환


# ------------------------------------------------------------
# 2. 포인터를 외부에서 지정하지 않고 도움 함수 제공
# ------------------------------------------------------------
def quick_sort(arr):
    """
    사용자에게는 이 함수만 호출하면 된다. 내부에서 재귀 호출을 시작한다.
    """
    if not arr:                                      # 14. 빈 리스트인 경우 바로 반환
        return arr
    quick_sort_inplace(arr, 0, len(arr)-1)           # 15. 전체 범위에서 재귀 호출
    return arr                                       # 16. 정렬 완료 후 리스트 반환


# ------------------------------------------------------------
# 3. 테스트 예시
# ------------------------------------------------------------
if __name__ == "__main__":
    sample = [33, 10, 55, 71, 2, 18, 39]
    print("정렬 전:", sample)
    quick_sort(sample)
    print("정렬 후 :", sample)
```

### 동작 흐름 요약
1. **`quick_sort`** 가 호출되면 내부에서 **`quick_sort_inplace`** 가 전체 범위를 아래와 같이 재귀적으로 호출한다.  
2. 재귀마다 **`partition`** 함수가 피벗을 기준으로 배열을 두 부분으로 나누고 피벗의 최종 인덱스를 반환한다.  
3. 피벗을 기준으로 다시 왼쪽/오른쪽 서브배열에 대해 같은 과정을 반복해 가면서 정렬된다.  
4. 힙(시간)복잡도는 평균 O(n log n), 최악의 경우 O(n²) 이지만, 보통 랜덤 혹은 중간값을 피벗으로 선택하면 평균 성능을 보장한다.
