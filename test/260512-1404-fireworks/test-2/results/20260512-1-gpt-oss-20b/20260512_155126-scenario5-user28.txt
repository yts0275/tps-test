아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 예시입니다.  
**각 줄마다** 주석을 달아 이해를 돕도록 했습니다.  

```python
# 1. 필요한 모듈을 가져옵니다. (순수 파이썬이므로 별도 모듈 필요 없음)
# from typing import List  # 필요 시 타입 힌트를 위해 임포트

# 2. 퀵소트 함수 정의: 입력 리스트를 정렬된 새 리스트로 반환합니다.
def quicksort(arr):
    # 3. 리스트가 0개 혹은 1개이면 이미 정렬된 상태이므로 그대로 반환합니다.
    if len(arr) <= 1:
        return arr

    # 4. 피벗(pivot)을 선택합니다. 여기서는 리스트의 마지막 원소를 사용합니다.
    pivot = arr[-1]

    # 5. 피벗보다 작은 값들(<= pivot)과 큰 값들(> pivot)을 각각 분리합니다.
    #    파이썬의 리스트 컴프리헨션(list comprehension)을 사용합니다.
    less = [x for x in arr[:-1] if x <= pivot]    # 피벗보다 작거나 같은 값들
    greater = [x for x in arr[:-1] if x > pivot]  # 피벗보다 큰 값들

    # 6. 재귀적으로 왼쪽(less)과 오른쪽(greater) 부분을 정렬합니다.
    #    그리고 정렬된 결과와 피벗을 연결해 최종 정렬된 리스트를 만들어 반환합니다.
    return quicksort(less) + [pivot] + quicksort(greater)

# 아래는 함수 사용 예시입니다. 테스트용으로 실행할 수 있습니다.
if __name__ == "__main__":
    # 7. 정렬할 예시 리스트를 정의합니다.
    unsorted_list = [33, 10, 55, 71, 29, 5, 12]
    
    # 8. 퀵소트 함수를 호출해 정렬된 리스트를 얻습니다.
    sorted_list = quicksort(unsorted_list)
    
    # 9. 결과를 출력해 확인합니다.
    print("정렬 전:", unsorted_list)
    print("정렬 후:", sorted_list)
```

### 주요 포인트
- `quicksort` 함수는 재귀적으로 **분할-정복(Divide & Conquer)** 전략을 적용합니다.
- 피벗을 마지막 요소로 선택했습니다. 다른 전략(중앙값, 랜덤 피벗 등)으로 바꿔도 무방합니다.
- `less`와 `greater`를 만들 때 `arr[:-1]`으로 피벗을 제외한 나머지 요소만 비교합니다.
- 재귀 종료 조건은 리스트 길이가 0 또는 1일 때입니다.

필요에 따라 **중간 변수**를 줄이거나 **in‑place(자리수) 버전**을 구현할 수도 있습니다. 하지만 이 예시는 가독성과 학습을 위해 간결하고 직관적인 구조를 유지했습니다.
