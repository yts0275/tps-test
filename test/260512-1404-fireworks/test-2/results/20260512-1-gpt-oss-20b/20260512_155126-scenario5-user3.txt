아래는 **파이썬**으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
코드의 **모든 줄**에 한 줄씩 한글 주석을 달아 이해를 돕도록 하였습니다.

```python
def quicksort(arr):                     # 1. 정렬할 리스트를 인자로 받는 함수 정의
    if len(arr) <= 1:                   # 2. 리스트 길이가 0 또는 1이면 이미 정렬 완료
        return arr[:]                   # 3. 원본 리스트를 변경하지 않도록 복사본 반환
    pivot = arr[0]                      # 4. 피벗(pivot) 값으로 첫 번째 요소 선택
    less = []                           # 5. 피벗보다 작은 요소를 담을 리스트 초기화
    greater = []                        # 6. 피벗보다 크거나 같은 요소를 담을 리스트 초기화
    for element in arr[1:]:             # 7. 피벗을 제외한 나머지 요소를 순회
        if element < pivot:             # 8. 현재 요소가 피벗보다 작으면
            less.append(element)        # 9. less 리스트에 추가
        else:                           #10. 그렇지 않으면
            greater.append(element)     #11. greater 리스트에 추가
    sorted_less = quicksort(less)       #12. less 리스트를 재귀적으로 정렬
    sorted_greater = quicksort(greater) #13. greater 리스트를 재귀적으로 정렬
    return sorted_less + [pivot] + sorted_greater  #14. 정렬된 리스트와 피벗 합치기

# 아래는 위 정의한 quicksort 함수를 테스트하는 예시
if __name__ == "__main__":           #15. 모듈이 직접 실행될 때만 아래 코드를 실행
    test_list = [3, 6, 8, 10, 1, 2, 1]  #16. 테스트에 사용할 정해진 리스트
    sorted_list = quicksort(test_list) #17. quicksort 함수를 호출해 정렬 결과 저장
    print(sorted_list)                #18. 정렬된 리스트를 화면에 출력
```

#### 코드 동작 요약
1. **기저 조건**: 리스트 길이가 `0` 또는 `1`이면 정렬이 끝나므로 복사본을 바로 반환합니다.  
2. **피벗 선택**: 첫 번째 요소를 피벗으로 사용합니다.  
3. **분할**: 나머지 요소를 피벗보다 작은 `less` 리스트와 크거나 같은 `greater` 리스트로 나눕니다.  
4. **재귀**: `less`와 `greater` 각각을 `quicksort`로 재귀 정렬합니다.  
5. **결합**: 정렬된 `less` 리스트, 피벗, 정렬된 `greater` 리스트를 순서대로 이어서 하나의 정렬된 리스트를 만듭니다.  

위 예시는 파이썬에서 가장 간단하면서도 직관적인 퀵소트 구현이며, 각 줄마다 한글 주석이 달려 이해하기 쉽도록 구성했습니다. 필요에 따라 피벗 선택 방식을 바꾸거나, 인-place 정렬 버전을 만들 수도 있습니다.
