아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드 안에 **각 줄마다** 주석을 달아 동작 방식을 한눈에 파악할 수 있도록 했습니다.

```python
def quicksort(arr):  # 재귀를 이용한 퀵소트 함수 (입력은 리스트)
    if len(arr) <= 1:  # 리스트에 0개 혹은 1개의 원소만 있으면 이미 정렬이 완료
        return arr  # 정렬된 리스트를 그대로 반환

    pivot = arr[len(arr)//2]  # 리스트 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]      # 피벗보다 작은 원소들을 모음
    middle = [x for x in arr if x == pivot]   # 피벗과 같은 원소들을 모음
    right = [x for x in arr if x > pivot]     # 피벗보다 큰 원소들을 모음

    # 왼쪽 부분, 같은 값, 오른쪽 부분을 각각 재귀적으로 정렬한 뒤 합침
    return quicksort(left) + middle + quicksort(right)

# 테스트용 코드
if __name__ == "__main__":
    sample = [9, 3, 1, 5, 13, 12, 15, 8]  # 예시 데이터
    print("정렬 전:", sample)             # 원본 리스트 출력
    sorted_list = quicksort(sample)        # 퀵소트 실행
    print("정렬 후:", sorted_list)        # 정렬된 결과 출력
```

### 주요 포인트 정리

1. **피벗 선택**: 중간 인덱스(`len(arr)//2`)를 피벗으로 사용하면 평균적인 성능이 안정적입니다.  
2. **분할**: 피벗 기준으로 `left`, `middle`, `right` 세 개의 리스트로 나누고, `middle`은 피벗 값과 같은 원소들을 모두 포함합니다.  
3. **재귀 호출**: `left`와 `right` 부분을 각각 재귀적으로 정렬한 뒤 연결(`+`)합니다.  
4. **복합 시간복잡도**: 평균 \(O(n \log n)\), 최악 \(O(n^2)\) (피벗이 항상 가장 작은/큰 값인 경우).  
5. **공간복잡도**: 재귀 호출 시 스택 사용과 리스트 복사 때문에 \(O(n)\) 정도가 됩니다.  

이 코드 스니펫을 그대로 복사해서 실행하면 퀵소트가 동작하고, 각 라인에 달린 주석을 통해 동작 원리를 한눈에 확인할 수 있습니다. 필요에 따라 피벗을 최댓값/최솟값으로 바꾸거나, 추가적인 최적화(예: 인덱스 기반 자르기)를 적용할 수 있으며, 그때마다 주석을 업데이트해 주시면 됩니다.
