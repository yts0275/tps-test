아래는 **Python**으로 작성한 퀵소트(QuickSort) 구현입니다.  
코드의 **각 줄**마다 한 줄 주석(`#`)을 달아 이해하기 쉽도록 정리해 두었습니다.

```python
# 퀵소트(QuickSort) 알고리즘 구현 (재귀적 방식)
def quicksort(arr):
    # arr(리스트)을 오름차순으로 정렬하는 함수
    # (원본 리스트를 직접 수정하고, 정렬된 리스트를 반환)

    # 내부 재귀 함수 정의: 왼쪽 인덱스와 오른쪽 인덱스 범위에 대해 정렬 수행
    def _quicksort(left, right):
        # 범위가 유효하지 않으면(왼쪽 > 오른쪽) 재귀 종료
        if left >= right:
            return

        # 피벗(pivot)을 가장 오른쪽 원소로 선택
        pivot = arr[right]

        # 피벗이 위치할 인덱스 i를 설정(초기값은 왼쪽보다 한칸 앞다음)
        i = left - 1

        # 피벗을 제외한 왼쪽부터 오른쪽-1까지 반복
        for j in range(left, right):
            # 현재 원소 arr[j]가 피벗보다 작거나 같으면, i를 한 칸 오른쪽으로 이동하고
            # arr[i]와 arr[j] 교환
            if arr[j] <= pivot:
                i += 1
                arr[i], arr[j] = arr[j], arr[i]

        # 최종적으로 피벗을 올바른 위치(이제 i+1번째)로 옮김
        arr[i + 1], arr[right] = arr[right], arr[i + 1]

        # 피벗보다 작은 부분(left)과 큰 부분(right)을 재귀적으로 정렬
        _quicksort(left, i)        # 피벗보다 작은 영역
        _quicksort(i + 2, right)   # 피벗보다 큰 영역

    # 입력 리스트가 비어 있지 않다면 정렬 시작 (0부터 끝까지)
    if arr:
        _quicksort(0, len(arr) - 1)

    # 정렬된 리스트 반환 (원본은 그대로 변경됨)
    return arr
```

### 사용 예시

```python
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", data)
    sorted_data = quicksort(data)
    print("정렬 후:", sorted_data)
```

실행 결과는 아래와 같습니다.

```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**주요 특징**

- 재귀적으로 분할 정복을 수행합니다.  
- 평균 시간복잡도는 `O(n log n)`이며, 최악의 경우 `O(n²)`이지만
  일반적인 입력에서는 빠른 성능을 보여 줍니다.  
- 피벗을 가장 오른쪽에 두는 전략이 가장 단순하고 직관적인 구현입니다.  

필요에 따라 피벗 선택 방식을 바꾸면(예: 중간값, 랜덤값 등) 최악의 경우 성능을 개선할 수 있습니다.
