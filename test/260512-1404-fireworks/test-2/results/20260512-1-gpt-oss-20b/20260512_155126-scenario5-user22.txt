아래는 각 줄에 주석을 달아 구현한 QuickSort 예시입니다.

```python
def quick_sort(arr):  # 1. quick_sort 함수 정의: 입력된 리스트 arr을 정렬해 반환합니다.
    if len(arr) <= 1:  # 2. 리스트 길이가 0 또는 1이면 이미 정렬된 상태여서 그대로 반환합니다.
        return arr     # 3. 정렬된 리스트(또는 길이 1 이하)를 반환합니다.
    pivot = arr[len(arr)//2]  # 4. 피벗을 리스트의 중간값으로 선택합니다.
    left = [x for x in arr if x < pivot]  # 5. 피벗보다 작은 원소들만 골라 새로운 리스트를 만듭니다.
    middle = [x for x in arr if x == pivot]  # 6. 피벗과 같은 값들만 골라 새로운 리스트를 만듭니다.
    right = [x for x in arr if x > pivot]  # 7. 피벗보다 큰 원소들만 골라 새로운 리스트를 만듭니다.
    return quick_sort(left) + middle + quick_sort(right)  # 8. 재귀적으로 왼쪽과 오른쪽 리스트를 정렬한 뒤 합칩니다.

if __name__ == "__main__":  # 9. 모듈이 직접 실행될 때만 아래 코드를 수행합니다.
    sample = [3, 6, 8, 10, 1, 2, 1]  # 10. 정렬 예시를 위한 샘플 리스트를 정의합니다.
    print("정렬 전:", sample)  # 11. 정렬 전의 리스트를 출력합니다.
    sorted_list = quick_sort(sample)  # 12. quick_sort 함수를 호출해 정렬된 리스트를 얻습니다.
    print("정렬 후:", sorted_list)  # 13. 정렬된 리스트를 출력합니다.
```
