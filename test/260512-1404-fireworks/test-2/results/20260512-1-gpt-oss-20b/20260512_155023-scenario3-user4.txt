아래는 **Python**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 “`#`” 뒤에 주석을 달아 이해를 돕겠습니다.

```python
def quicksort(arr):                                 # 배열을 정렬하기 위한 함수 정의
    """
    퀵소트를 사용해 arr을 오름차순으로 정렬합니다.
    (함수는 새 리스트를 반환하고, 원본 arr은 그대로 두고 리턴합니다)
    """
    if len(arr) <= 1:                              # 배열 길이가 0 또는 1이면 이미 정렬 완료
        return arr                                 # 그냥 원본(또는 복사본) 반환

    pivot = arr[len(arr) // 2]                     # 중간 인덱스의 값을 피벗으로 선정
    left = [x for x in arr if x < pivot]           # 피벗보다 작은 값들만 모은 리스트
    middle = [x for x in arr if x == pivot]        # 피벗과 같은 값들만 모은 리스트
    right = [x for x in arr if x > pivot]          # 피벗보다 큰 값들만 모은 리스트

    # 재귀 호출로 좌우 두 부분을 정렬한 뒤, 정렬된 리스트를 합칩니다.
    return quicksort(left) + middle + quicksort(right)   # 좌우 정렬 결과와 피벗을 합산해 반환
```

### 사용 예시

```python
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]
    sorted_sample = quicksort(sample)
    print("정렬 전:", sample)          # 원본은 그대로 (정렬되지 않음)
    print("정렬 후:", sorted_sample)   # 오름차순 정렬 결과
```

위 코드는 평균적으로 O(n log n)의 시간복잡도를 가지며, 피벗을 중간값으로 고정해서 수행하므로 입력이 정렬된 경우에도 최악의 경우를 방지하지 못하는 단점이 있습니다.  

필요에 따라 **볼륨(입력 값이 정렬된 경우 성능 저하)** 를 방지하기 위해 ‘선택형 피벗(임의의 인덱스 또는 랜덤)’을 사용하거나, 인‑플레이스(메모리 비중간 저장소) 구현을 고려할 수 있습니다.
