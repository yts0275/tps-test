아래는 **Python**으로 구현한 퀵소트(빠른 정렬) 알고리즘입니다.  
코드의 **각 줄마다** 한국어 주석이 달려 있으니,  
어떤 단계가 수행되는지 한눈에 파악할 수 있습니다.

```python
# --------------------------------------------------------------------
# 퀵소트(quick sort) 구현 예시 (Python)
# --------------------------------------------------------------------

def quicksort(arr, low, high):
    """
    재귀적으로 배열 arr의 일부분 [low, high]를 정렬하는 함수
    """
    # 낮은 인덱스가 높은 인덱스보다 크거나 같으면, 정렬할 부분이 없어 종료
    if low >= high:
        return

    # 배열의 범위 안에서 피벗(기준값)을 선택하고, 해당 피벗을 기준으로
    # 왼쪽에는 피벗보다 작은 값, 오른쪽에는 큰 값을 배치
    pivot_index = partition(arr, low, high)

    # 피벗이 놓인 최종 위치를 기준으로 왼쪽과 오른쪽 부분을 각각 재귀적으로 정렬
    quicksort(arr, low, pivot_index - 1)
    quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    """
    피벗을 이용해 배열을 분할하는 함수
    피벗은 보통 가장 오른쪽 원소를 사용
    """
    # 피벗 값(우측 끝 원소)을 저장
    pivot = arr[high]
    # 피벗보다 작은 원소를 저장할 위치를 초기화
    i = low - 1

    # low부터 high-1까지 각 원소를 순회
    for j in range(low, high):
        # 현재 원소가 피벗보다 작으면, 피벗보다 작은 부분에 포함
        if arr[j] < pivot:
            i += 1               # 피벗보다 작은 원소가 들어갈 위치를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # arr[i]와 arr[j]를 교환

    # 마지막으로 피벗을 그보다 큰 원소의 앞쪽, 즉 i+1 위치에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 위치한 인덱스를 반환 (이후 재귀 호출에 사용)
    return i + 1

# --------------------------------------------------------------------
# 사용 예시
# --------------------------------------------------------------------
if __name__ == "__main__":
    # 예시 데이터: 정렬이 필요한 배열
    data = [33, 10, 55, 71, 29, 3, 89, 12, 5, 42]
    # 배열의 인덱스 범위: 0부터 len(data)-1까지
    quicksort(data, 0, len(data) - 1)
    # 정렬 결과를 출력
    print("정렬된 배열:", data)
```

### 코드 설명
1. **`quicksort` 함수**  
   - 재귀적으로 전체 배열을 정렬합니다.  
   - `partition` 함수를 이용해 피벗을 기준으로 배열을 분할하고,  
     그 결과를 이용해 왼쪽·오른쪽 구간을 다시 정렬합니다.

2. **`partition` 함수**  
   - 현재 구간(`low~high`) 안에서 가장 오른쪽 원소를 피벗으로 삼습니다.  
   - `i`는 피벗보다 작은 원소를 모아두는 인덱스이며,  
     `j`를 이용해 배열을 순회하면서 작은 원소를 `i` 왼쪽에 모읍니다.  
   - 최종적으로 피벗을 `i+1` 위치에 두고, 그 인덱스를 반환합니다.

3. **`__main__` 블록**  
   - 예시 배열 `data`를 정의하고, `quicksort` 함수를 호출합니다.  
   - 정렬이 끝난 뒤 결과를 출력합니다.

이 예시 코드는 배열을 **제자리(인‑플레이스)** 정렬하므로,
추가 메모리 사용량이 적습니다.  
필요에 따라 다른 프로그래밍 언어(async, C/C++, Java 등)로도 비슷하게 구현할 수 있습니다.
