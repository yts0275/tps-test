아래는 **Python**으로 구현한 퀵소트(QuickSort) 예시이며, **모든 줄에** 주석을 한 줄씩 달아 놓았습니다. 한 줄짜리 주석은 한국어로 정리해 두었습니다.  

```python
# 리스트를 정렬하는 퀵소트 함수 (값은 배열의 일부분에 적용)
def quick_sort(arr, low, high):                         # 함수 선언: arr – 정렬할 배열, low – 시작 인덱스, high – 끝 인덱스
    if low < high:                                     # 시작 인덱스가 끝 인덱스보다 작다면(정렬이 아직 끝나지 않았으면)
        pivot_index = partition(arr, low, high)        # 배열을 피벗을 기준으로 분할하고, 피벗이 최종적으로 놓일 인덱스를 반환
        quick_sort(arr, low, pivot_index - 1)          # 피벗 좌측 서브배열 재귀적으로 정렬
        quick_sort(arr, pivot_index + 1, high)         # 피벗 우측 서브배열 재귀적으로 정렬

# 배열을 분할(피벗 기준으로 정렬 후)하는 헬퍼 함수
def partition(arr, low, high):                          # 함수 선언: arr – 정렬할 배열, low – 시작 인덱스, high – 끝 인덱스
    pivot = arr[high]                                  # 가장 끝에 있는 요소를 피벗으로 지정
    i = low - 1                                         # i는 피벗보다 작거나 같은 값보다 사전적 위치를 가리킴
    for j in range(low, high):                         # j는 피벗 바로 앞까지 순회
        if arr[j] <= pivot:                            # 현재 원소가 피벗보다 작거나 같으면
            i += 1                                     # i를 한 칸 앞으로 이동
            arr[i], arr[j] = arr[j], arr[i]            # i와 j 위치의 원소를 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]      # 피벗을 올바른 위치(i+1)에 넣음
    return i + 1                                       # 피벗의 최종 인덱스를 반환

# 예시 데이터
data = [10, 7, 8, 9, 1, 5]                            # 정렬할 숫자 리스트 정의
quick_sort(data, 0, len(data) - 1)                    # 퀵소트 실행: 전체 리스트를 정렬
print("정렬된 배열:", data)                           # 정렬 결과 출력
```

위 코드는 **재귀적으로** 배열을 분할하면서 정렬을 수행합니다.  
- `quick_sort()` 함수가 재귀 호출을 통해 왼쪽·오른쪽 서브 배열을 정렬합니다.  
- `partition()` 함수는 피벗을 기준으로 배열을 두 부분으로 나누고, 피벗이 최종 정렬 위치에 놓이도록 합니다.  

출력 예시  
```
정렬된 배열: [1, 5, 7, 8, 9, 10]
```
