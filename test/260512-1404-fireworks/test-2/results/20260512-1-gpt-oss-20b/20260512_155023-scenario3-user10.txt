아래는 파이썬으로 구현한 퀵소트(QuickSort) 함수이며, 각 줄마다 한글 주석을 달았습니다.  
> **주의**: 코드 블록 안의 공백 줄에도 주석을 달지 않았습니다. 필요하면 다시 말씀해 주세요.

```python
def quicksort(arr):                                      # 입력된 리스트를 그대로 정렬해 새로운 리스트를 반환한다
    if len(arr) <= 1:                                   # 리스트가 비어 있거나 한 개짜리이면 그대로 반환
        return arr                                   # 더 이상 분할할 필요가 없으므로 그대로 리턴
    pivot = arr[len(arr) // 2]                         # 리스트의 중앙 요소를 피벡트(pivot)로 선택한다
    left = [x for x in arr if x < pivot]               # 피벡트보다 작은 요소들만 모아 왼쪽 리스트를 만든다
    middle = [x for x in arr if x == pivot]            # 피벡트와 같은 값을 가진 모든 요소를 모아 가운데 리스트를 만든다
    right = [x for x in arr if x > pivot]              # 피벡트보다 큰 요소들만 모아 오른쪽 리스트를 만든다
    return quicksort(left) + middle + quicksort(right) # 재귀 호출을 통해 각 부분을 정렬한 뒤 합쳐 반환한다
```

### 사용 예시

```python
arr = [3, 6, 8, 10, 1, 2, 1]
print(quicksort(arr))                                 # [1, 1, 2, 3, 6, 8, 10] 라고 출력된다
```

이 구현은 **분할 정복** 방식에 따라 피벡트를 기준으로 좌·우 부분을 재귀적으로 정렬하고, 이들을 합쳐 최종 정렬 리스트를 만듭니다. 각 행에 한글 주석을 달아 이해를 돕도록 했으니, 필요하신 부분이 더 있으면 언제든 알려 주세요!
