아래는 파이썬으로 구현한 **퀵소트(Quick Sort)**입니다.  
코드의 **모든 줄에** 한국어 주석을 달아 이해하기 쉽게 구성했습니다.  

```python
def quick_sort(arr):
    # quick_sort 함수 정의: 주어진 리스트 arr 를 정렬합니다.
    def _quick_sort(items, low, high):
        # _quick_sort 내부 함수: 재귀를 통해 부분 배열을 정렬합니다.
        if low < high:
            # 파티션 과정으로 피벗(기준값)을 결정하고, 그 위치를 반환합니다.
            pivot_index = partition(items, low, high)
            # 피벗보다 작은 부분과 큰 부분을 각각 재귀 호출합니다.
            _quick_sort(items, low, pivot_index - 1)
            _quick_sort(items, pivot_index + 1, high)

    def partition(items, low, high):
        # partition 함수: items[low..high] 구간을 기준으로 피벗으로 분할합니다.
        pivot = items[high]          # 가장 오른쪽 원소를 피벗으로 선택
        i = low - 1                  # i는 "작은 값" 구간 끝의 인덱스
        for j in range(low, high):   # j는 현재 검사 중인 원소의 인덱스
            if items[j] <= pivot:    # 현재 원소가 피벗보다 작거나 같으면
                i += 1              # 작은 값 구간을 확장
                items[i], items[j] = items[j], items[i]
                # i와 j를 교환하여 작은 값 구간에 넣습니다.
        # 피벗을 적절한 위치에 두고 그 인덱스를 반환
        items[i + 1], items[high] = items[high], items[i + 1]
        return i + 1

    # 외부에서 전달받은 입력이 비어 있거나 한 원소만 있을 경우 종료
    if not arr or len(arr) <= 1:
        return arr

    # 재귀 정렬 시작: 전체 범위(0 ~ len(arr)-1)를 지정합니다.
    _quick_sort(arr, 0, len(arr) - 1)
    # 정렬된 리스트를 반환합니다.
    return arr


# 예시 사용법
if __name__ == "__main__":
    sample = [10, 7, 8, 9, 1, 5]
    print("원본 리스트:", sample)
    sorted_list = quick_sort(sample)
    print("정렬된 리스트:", sorted_list)
```

### 코드 설명
1. `quick_sort` 함수는 사용자 인터페이스이며, 내부에서 재귀 정렬을 호출합니다.  
2. `_quick_sort` 는 실제 재귀 로직을 수행합니다.  
3. `partition` 은 피벗을 기준으로 배열을 두 부분으로 나누고, 피벗이 올바른 위치에 오도록 조정합니다.  
4. `if not arr or len(arr) <= 1:` 는 사전 검사로, 정렬할 필요가 없을 때 바로 반환합니다.  

이 코드는 인-place (공간 복사 없이 원본 리스트를 바로 정렬) 동작하며, 평균적으로 **O(n log n)**, 최악의 경우 **O(n²)** 성능을 보입니다.
