아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘입니다.  
각 행마다 주석을 달아 왜 그 코드를 쓰는지 설명했습니다.  

```python
# --- 퀵소트 구현 (인플레이스) -------------------------------------
def quick_sort_inplace(arr, low, high):                               # 인플레이스 퀵소트 함수 정의
    if low < high:                                                     # 정렬이 필요하면(하위 범위가 하나 이상일 때)
        pi = partition(arr, low, high)                                 # 피벗(끝 원소)를 기준으로 partition 수행
        quick_sort_inplace(arr, low, pi - 1)                           # 피벗 왼쪽 구간 재귀 호출
        quick_sort_inplace(arr, pi + 1, high)                          # 피벗 오른쪽 구간 재귀 호출
    # 함수 종료 시, arr[low:high+1] 영역이 정렬된 상태가 됨

def partition(arr, low, high):                                          # 배열을 피벗 기준으로 재배열
    pivot = arr[high]                                                  # 피벗은 마지막 원소(고정된 기준)
    i = low - 1                                                        # i는 '작은 값' 구간 끝 인덱스
    for j in range(low, high):                                         # j는 '현재 검사 중인 원소' 인덱스
        if arr[j] <= pivot:                                            # 현재 원소가 피벗 이하이면
            i += 1                                                     # 작은값 구간 확장
            arr[i], arr[j] = arr[j], arr[i]                            # 작은값 구간과 현재 원소 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]                       # 피벗을 작은값 구간 끝후에 둠
    return i + 1                                                       # 피벗의 최종 위치 반환

# --- 사용자 사용 예시 ----------------------------------------------
if __name__ == "__main__":                                            # 스크립트가 직접 실행될 때만 실행
    arr = [3, 6, 8, 10, 1, 2, 1]                                      # 정렬할 리스트 예시
    print("정렬 전:", arr)                                            # 정렬 전 상태 출력
    quick_sort_inplace(arr, 0, len(arr) - 1)                           # 인플레이스 퀵소트 호출
    print("정렬 후 :", arr)                                            # 정렬 이후 상태 출력
``` 

**주요 포인트**

1. `quick_sort_inplace`는 리스트의 `low`~`high` 범위만을 대상으로 재귀적으로 정렬합니다.  
2. `partition`에서 피벗을 기준으로 크기가 작은 원소들을 왼쪽에, 큰 원소들을 오른쪽에 배치합니다.  
3. 피벗을 지정하는 위치(여기서는 마지막 원소)를 바꾸면 통계적 성능이 달라질 수 있으니, 실제 데이터에 맞는 전략을 선택하는 것이 좋습니다.  

이 코드를 그대로 복사해서 실행하면, `정렬 전:` 과 `정렬 후 :` 가 정상적으로 출력됩니다. 필요에 따라 다른 언어(자바, C++, 자바스크립트 등)로도 동일한 로직을 적용할 수 있습니다.
