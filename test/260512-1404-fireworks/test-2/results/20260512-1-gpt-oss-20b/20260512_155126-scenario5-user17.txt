아래는 **Python** 으로 구현한 퀵소트(QuickSort) 예제입니다.  
코드의 **각 줄**에 한 줄씩 주석을 달아 구현 흐름과 의미를 명확히 했습니다.  
필요에 따라 체계적으로 재귀 호출을 활용하여 정렬을 수행합니다.

```python
# 1. 재귀 정렬을 위한 함수 정의
def quicksort(arr):
    # 2. 리스트가 0개 혹은 1개일 때는 정렬이 끝난 상태이므로 그대로 반환
    if len(arr) < 2:
        return arr
    
    # 3. 첫 번째 원소를 피벗(pivot)으로 선정(가장 쉬운 선택 방식)
    pivot = arr[0]
    
    # 4. 피벗보다 작거나 같은 원소들을 담을 리스트 초기화
    less = []
    # 5. 피벗보다 큰 원소들을 담을 리스트 초기화
    greater = []
    
    # 6. 피벗 제외한 나머지 원소들을 순회
    for x in arr[1:]:
        # 7. 현재 원소가 피벗 이하라면 less 리스트에 추가
        if x <= pivot:
            less.append(x)
        # 8. 그 외(피벗 초과)는 greater 리스트에 추가
        else:
            greater.append(x)
    
    # 9. less 를 재귀적으로 정렬
    sorted_less = quicksort(less)
    # 10. greater 를 재귀적으로 정렬
    sorted_greater = quicksort(greater)
    
    # 11. 정렬 결과를 결합: less + 피벗 + greater
    return sorted_less + [pivot] + sorted_greater


# --------------------------- 사용 예시 ---------------------------

# 12. 정렬되지 않은 예시 리스트
sample = [7, 2, 5, 3, 9, 1, 8]

# 13. 퀵소트를 호출하여 정렬 수행
sorted_sample = quicksort(sample)

# 14. 결과 출력
print("정렬 전:", sample)      # 원본 리스트는 변하지 않음(순수함수)
print("정렬 후:", sorted_sample)
```

### 코드 흐름 정리

1. **재귀 종료 조건**: 리스트 길이가 0 또는 1이면 이미 정렬 완료이므로 그대로 반환합니다.  
2. **피벗 선택**: 가장 간단히 첫 번째 원소를 피벗으로 정하고, 나머지는 두 개의 리스트(`less`, `greater`)로 분리합니다.  
3. **분리**: 피벗보다 작거나 같은 항목은 `less`, 그보다 큰 항목은 `greater`에 저장합니다.  
4. **재귀 호출**: `less`와 `greater`를 각각 재귀적으로 정렬합니다.  
5. **결합**: 정렬된 `less`, 피벗, 정렬된 `greater`를 순서대로 이어 붙여 최종 정렬된 리스트를 반환합니다.

이 코드의 구조는 퀵소트의 핵심 아이디어인 "분할(Divide) → 정복(Conquer) → 결합(Combine)"을 그대로 따르고 있으며, 각 단계가 한 줄씩 주석으로 명시되어 있어 이해가 쉽습니다.
