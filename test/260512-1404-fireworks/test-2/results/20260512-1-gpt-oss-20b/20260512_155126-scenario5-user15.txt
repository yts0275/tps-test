아래는 **Python 3** 로 구현한 퀵소트(QuickSort) 예시입니다.  
코드의 각 줄마다 `#` 뒤에 주석을 달아 이해하기 쉽도록 했습니다.

```python
import sys                       # 시스템 모듈(필요 시 STL 기능 제공) 임포트

def quicksort(arr):             # 배열(리스트)을 인자로 받는 함수 정의
    if len(arr) <= 1:           # 리스트가 비어 있거나 원소가 하나일 경우
        return arr              # 이미 정렬되어 있으므로 그대로 반환

    pivot = arr[len(arr) // 2]  # 중간 인덱스의 값을 피벗으로 선택

    left = [x for x in arr if x < pivot]   # 피벗보다 작은 값들
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 값들 (중복 처리)
    right = [x for x in arr if x > pivot]    # 피벗보다 큰 값들

    # 재귀적으로 정렬한 결과를 합친 뒤 반환
    return quicksort(left) + middle + quicksort(right)

if __name__ == "__main__":                 # 직접 실행될 때만 아래 코드 실행
    test_list = [3, 6, 8, 10, 1, 2, 1]     # 예시 데이터
    print("원본 리스트:", test_list)        # 원본 리스트 출력
    sorted_list = quicksort(test_list)     # 퀵소트 수행
    print("정렬된 리스트:", sorted_list)  # 결과 리스트 출력
```

### 핵심 포인트
1. **피벗 선택** – 중간 인덱스 값을 사용해 평균적인 분할을 시도함 (선택은 자유).
2. **리스트 컴프리헨션** 으로 `left`, `middle`, `right` 세 리스트를 한 줄에 만들어 재귀 호출이 깔끔함.
3. **재귀** – `left`와 `right`에 대해 같은 함수를 호출하고, `middle`과 바로 연결해 결과를 만들기 때문에 코드가 간결함.

필요에 따라 피벗을 무작위로 선택하거나, 장황한 지시문 대신 `bisect` 모듈을 활용해 정렬할 수도 있습니다.  
이 예시는 명명과 주석이 풍부해 학습용으로도 좋습니다.
