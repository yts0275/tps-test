아래는 파이썬으로 구현한 퀵소트(QuickSort) 예제이며, **모든 코드 한 줄마다 주석**을 붙였습니다.  

```python
def quicksort(arr):  # 주어진 배열을 퀵소트로 정렬하는 함수
    # 배열이 0개 또는 1개라면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:  # 배열 길이가 1 이하일 경우
        return arr  # 그 배열을 그대로 반환

    # 마지막 원소를 피봇(pivot)으로 선택
    pivot = arr[-1]  # 피봇(분할 기준)가 되는 값

    # 피봇보다 작거나 같은 원소와 큰 원소를 각각 따로 모음
    less_or_equal = [x for x in arr[:-1] if x <= pivot]  # 피봇 이하의 원소
    greater = [x for x in arr[:-1] if x > pivot]  # 피봇보다 큰 원소

    # 재귀적으로 왼쪽, 오른쪽 부분을 정렬하고 피봇을 사이에 삽입
    return quicksort(less_or_equal) + [pivot] + quicksort(greater)  # 정렬된 결과 반환

# 아래 코드는 스크립트를 직접 실행했을 때만 실행되는 부분
if __name__ == "__main__":  # 메인 스크립트로 실행될 때만 아래 코드 실행
    # 예시 배열 (원취소)
    sample = [3, 6, 8, 10, 1, 2, 1]  # 정렬될 배열
    print("Original array:", sample)  # 원본 배열 출력
    sorted_arr = quicksort(sample)  # 퀵소트 실행
    print("Sorted array:", sorted_arr)  # 정렬된 배열 출력
```

### 코드 설명
1. **함수 정의**  
   `quicksort(arr)` 은 주어진 리스트 `arr` 를 재귀적으로 분할·정렬합니다.  

2. **기본 기준**  
   리스트 길이가 `0` 혹은 `1` 이면 더 이상 분할할 필요가 없으므로 그대로 반환합니다.  

3. **피봇 선택**  
   가장 오른쪽 원소를 피봇으로 삼아 분할합니다. 이 선택은 구현을 단순화하기 위한 표준 방식입니다.  

4. **분할**  
   피봇보다 작거나 같은 원소를 `less_or_equal` 에, 피봇보다 큰 원소를 `greater` 에 각각 모읍니다.  

5. **재귀 정렬 및 합치기**  
   `less_or_equal` 과 `greater` 를 각각 재귀적으로 `quicksort` 로 정렬한 뒤, 피봇을 가운데에 삽입해 최종 정렬 결과를 만듭니다.  

6. **메인 실행**  
   스크립트가 직접 실행될 때 예시 배열을 정렬하고 결과를 출력하도록 구성했습니다.

필요에 따라 피봇 선택 방식을 바꾸거나, 인플레이스(in-place) 버전을 적용해도 좋습니다. 그러나 위 예제는 **가독성**과 **주석 친절함**을 가장 중요시한 구현입니다.
