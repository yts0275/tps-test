아래는 파이썬으로 구현한 퀵소트 예제입니다. 각 코드 줄마다 한국어 주석을 달아두었습니다.

```python
def partition(arr, low, high):  # 배열과 파티션할 시작/끝 인덱스를 받아 파티션을 수행하는 함수 정의
    pivot = arr[high]  # 피벗으로 배열의 마지막 요소를 선택
    i = low - 1  # 작은 요소들의 경계 인덱스를 초기화(가장 왼쪽보다 한 칸 왼쪽)
    for j in range(low, high):  # low부터 high-1까지 순회하며 각 요소를 피벗과 비교
        if arr[j] <= pivot:  # 현재 요소가 피벗 이하이면
            i += 1  # 경계 인덱스를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # 현재 요소를 경계 위치로 이동시키기 위해 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 경계의 다음 위치로 놓기 위해 교환
    return i + 1  # 피벗의 최종 위치 인덱스를 반환


def quicksort(arr, low, high):  # 재귀적으로 퀵소트를 수행하는 함수 정의
    if low < high:  # 분할할 범위에 두 개 이상의 요소가 있는지 확인
        pi = partition(arr, low, high)  # 배열을 분할하고 피벗의 인덱스를 얻음
        quicksort(arr, low, pi - 1)  # 피벗 왼쪽 부분을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)  # 피벗 오른쪽 부분을 재귀적으로 정렬


def quicksort_inplace(arr):  # 사용자가 바로 호출하기 쉬운 래퍼 함수 정의
    quicksort(arr, 0, len(arr) - 1)  # 전체 배열 범위로 퀵소트 호출


if __name__ == "__main__":  # 이 파일이 직접 실행될 때만 아래 예제를 실행
    arr = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예제 배열 선언
    print("정렬 전:", arr)  # 정렬 전 배열 상태 출력
    quicksort_inplace(arr)  # 배열을 인플레이스 방식으로 정렬
    print("정렬 후:", arr)  # 정렬된 배열 상태 출력
```

원하시면 다른 분할 방식(Hoare partition), 무작위 피벗 선택, 또는 안정 정렬/비재귀 구현 예제도 제공해 드리겠습니다.
