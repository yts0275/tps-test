아래는 **파이썬( Python )**으로 구현한 퀵소트 예시입니다. **각 줄(또는 핵심 실행 줄)**마다 주석을 달았습니다.

```python
def quick_sort(arr):  # 퀵소트를 구현한 함수(정렬된 새 배열을 반환)
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬되어 있으므로 그대로 반환
        return arr  # 정렬된 배열(또는 같은 배열)을 반환

    pivot = arr[0]  # 기준 원소(pivot)를 첫 번째 값으로 선택
    left = []       # pivot보다 작은 값들을 담을 리스트
    right = []      # pivot보다 큰(또는 같지 않은) 값들을 담을 리스트
    equal = []      # pivot과 같은 값들을 담을 리스트(중복 처리용)

    for x in arr:  # 배열의 각 원소를 순회
        if x < pivot:  # 현재 값이 pivot보다 작으면
            left.append(x)  # left 리스트에 추가
        elif x > pivot:  # 현재 값이 pivot보다 크면
            right.append(x)  # right 리스트에 추가
        else:  # x == pivot 인 경우
            equal.append(x)  # equal 리스트에 추가

    return quick_sort(left) + equal + quick_sort(right)  # 왼쪽 정렬 + pivot(동일값) + 오른쪽 정렬 결과 결합
```
