아래는 **퀵소트(Quick Sort) 구현 예시**와 **각 줄마다 주석**을 단 버전입니다. (파이썬)

```python
def quick_sort(arr):  # 배열을 퀵소트로 정렬해주는 함수 정의
    if len(arr) <= 1:  # 배열 길이가 0 또는 1이면 이미 정렬된 상태이므로
        return arr  # 그대로 반환
    pivot = arr[len(arr) // 2]  # 가운데 원소를 피벗(pivot)으로 선택
    left = []  # 피벗보다 작은 값들을 담을 리스트
    middle = []  # 피벗과 같은 값들을 담을 리스트
    right = []  # 피벗보다 큰 값들을 담을 리스트
    for x in arr:  # 배열의 모든 원소 x를 하나씩 확인
        if x < pivot:  # x가 피벗보다 작다면
            left.append(x)  # left 리스트에 추가
        elif x > pivot:  # x가 피벗보다 크다면
            right.append(x)  # right 리스트에 추가
        else:  # x가 피벗과 같다면
            middle.append(x)  # middle 리스트에 추가
    return quick_sort(left) + middle + quick_sort(right)  # 재귀로 정렬한 결과를 합쳐 반환
```
