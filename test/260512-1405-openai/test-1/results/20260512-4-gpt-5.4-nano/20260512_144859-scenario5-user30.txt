아래는 **퀵소트(Quick Sort) 구현 예시**입니다. 요청하신 대로 **각 줄마다 주석**을 달았습니다. (파이썬)

```python
def quick_sort(arr):  # 주어진 리스트 arr을 퀵소트로 정렬하기 위한 함수 정의
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬되어 있으므로 그대로 반환
        return arr  # 정렬된 배열(원본)을 반환
    pivot = arr[0]  # 첫 번째 원소를 피벗(pivot)으로 선택
    left = []  # 피벗보다 작은 원소들을 담을 리스트
    right = []  # 피벗보다 큰 원소들을 담을 리스트
    for x in arr[1:]:  # 피벗을 제외한 나머지 원소들을 순회
        if x < pivot:  # 현재 원소 x가 피벗보다 작으면
            left.append(x)  # left에 추가
        else:  # 현재 원소 x가 피벗보다 크거나 같으면
            right.append(x)  # right에 추가
    return quick_sort(left) + [pivot] + quick_sort(right)  # 재귀적으로 정렬 후 합쳐서 반환
```

원하시면,  
1) **불변(새 배열 생성)** 방식 말고 **제자리(in-place) 퀵소트** 버전,  
2) **C/C++/Java** 등 다른 언어 버전,  
3) **중복값 처리 방식**(피벗과 같은 값 포함 방식)도 원하는 스타일로 맞춰드릴게요. 어떤 언어로 원하세요?
