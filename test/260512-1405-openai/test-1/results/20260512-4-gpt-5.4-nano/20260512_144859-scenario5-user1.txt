아래는 **파이썬(기본 퀵소트)** 구현 예시입니다. **각 줄마다 주석**을 달았습니다.

```python
def quicksort(arr):  # 퀵소트 함수를 정의합니다. (입력: arr, 출력: 정렬된 리스트)
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬된 상태이므로 그대로 반환합니다.
        return arr  # 정렬된 배열을 반환합니다.

    pivot = arr[len(arr) // 2]  # 피벗을 배열의 가운데 값으로 선택합니다.
    left = []  # 피벗보다 작은 값들을 담을 리스트를 준비합니다.
    mid = []  # 피벗과 같은 값들을 담을 리스트를 준비합니다.
    right = []  # 피벗보다 큰 값들을 담을 리스트를 준비합니다.

    for x in arr:  # 입력 배열의 각 원소 x를 순회합니다.
        if x < pivot:  # x가 피벗보다 작으면
            left.append(x)  # left 리스트에 추가합니다.
        elif x > pivot:  # x가 피벗보다 크면
            right.append(x)  # right 리스트에 추가합니다.
        else:  # x가 피벗과 같으면
            mid.append(x)  # mid 리스트에 추가합니다.

    return quicksort(left) + mid + quicksort(right)  # 왼쪽(정렬) + 가운데(피벗과 같은 값) + 오른쪽(정렬)을 합쳐 반환합니다.


# 사용 예시
data = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예시 데이터입니다.
print(quicksort(data))  # 퀵소트를 수행한 결과를 출력합니다.
```
