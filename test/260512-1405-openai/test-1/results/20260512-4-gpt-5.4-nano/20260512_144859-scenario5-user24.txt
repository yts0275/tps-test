아래는 **퀵소트(Quick Sort)**를 예시로 구현한 파이썬 코드입니다. **각 줄마다 주석**을 달았습니다.

```python
def quicksort(arr):  # 퀵소트 함수를 정의 (입력: arr, 출력: 정렬된 새 리스트)
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬되어 있으므로 그대로 반환
        return arr  # 입력 배열 그대로 반환

    pivot = arr[0]  # 피벗을 첫 번째 원소로 선택
    left = []  # 피벗보다 작은 원소들을 담을 리스트 생성
    right = []  # 피벗보다 크거나 같은 원소들을 담을 리스트 생성

    for i in range(1, len(arr)):  # 피벗 다음 인덱스부터 끝까지 반복
        if arr[i] < pivot:  # 현재 원소가 피벗보다 작은 경우
            left.append(arr[i])  # left 리스트에 추가
        else:  # 현재 원소가 피벗보다 크거나 같은 경우
            right.append(arr[i])  # right 리스트에 추가

    return quicksort(left) + [pivot] + quicksort(right)  # 왼쪽 정렬 + 피벗 + 오른쪽 정렬 결과를 이어서 반환
    # 재귀적으로 계속 분할하여 최종적으로 정렬된 배열을 만든다.


# 테스트 코드
data = [3, 6, 8, 10, 1, 2, 1]  # 예시 입력 배열
print(quicksort(data))  # 퀵소트 실행 후 정렬 결과 출력
```

2) **피벗 선택을 랜덤/중앙값으로 개선한 버전**
