아래는 **퀵소트(Quicksort)** 구현 예시와 **각 줄마다 주석**을 단 코드입니다. (파이썬)

```python
def quicksort(arr):  # 퀵소트 함수를 정의, 입력은 리스트 arr
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬된 상태이므로
        return arr  # 그대로 반환
    pivot = arr[-1]  # 마지막 원소를 피벗(pivot)으로 선택
    left = []  # 피벗보다 작은 값들을 담을 리스트 생성
    right = []  # 피벗보다 큰(또는 같지 않은) 값들을 담을 리스트 생성
    for x in arr[:-1]:  # 피벗을 제외한 나머지 원소를 하나씩 확인
        if x < pivot:  # 현재 값이 피벗보다 작으면
            left.append(x)  # left에 추가
        else:  # 현재 값이 피벗보다 크거나 같으면(여기서는 같은 값도 right로 보냄)
            right.append(x)  # right에 추가
    return quicksort(left) + [pivot] + quicksort(right)  # 재귀로 정렬한 결과를 합쳐 반환
# -----------------------------------------------

# 예시 실행
nums = [10, 7, 8, 9, 1, 5]  # 정렬할 예제 리스트
print(quicksort(nums))  # 퀵소트 결과 출력
```
