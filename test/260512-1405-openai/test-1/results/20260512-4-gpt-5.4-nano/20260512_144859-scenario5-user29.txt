아래는 **퀵소트(Quick Sort)**를 **파이썬**으로 구현한 예시이고, **각 줄마다 주석**을 달았습니다.

```python
def quicksort(arr):  # 주어진 리스트(arr)에 대해 퀵소트 정렬을 수행하는 함수 정의
    if len(arr) <= 1:  # 원소가 1개 이하이면 이미 정렬된 상태이므로 그대로 반환
        return arr  # 그대로 반환

    pivot = arr[len(arr) // 2]  # 피벗을 가운데 원소로 선택
    left = []  # 피벗보다 작은 원소들을 담을 리스트 생성
    middle = []  # 피벗과 같은 원소들을 담을 리스트 생성
    right = []  # 피벗보다 큰 원소들을 담을 리스트 생성

    for x in arr:  # 배열의 모든 원소를 순회
        if x < pivot:  # 현재 원소가 피벗보다 작으면
            left.append(x)  # left 리스트에 추가
        elif x > pivot:  # 현재 원소가 피벗보다 크면
            right.append(x)  # right 리스트에 추가
        else:  # 현재 원소가 피벗과 같으면
            middle.append(x)  # middle 리스트에 추가

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 정렬 + 가운데 + 오른쪽 정렬 결과를 합쳐 반환
```
