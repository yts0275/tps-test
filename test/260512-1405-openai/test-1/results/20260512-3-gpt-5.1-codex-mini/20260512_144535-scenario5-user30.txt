아래는 각 줄마다 주석을 단 퀵소트 구현 예시입니다:

```python
def quicksort(arr):  # 퀵소트를 수행할 함수 정의
    if len(arr) <= 1:  # 배열의 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr  # 원본 배열 그대로 반환
    pivot = arr[len(arr) // 2]  # 중앙값을 기준 피벗으로 선정
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 값들을 모아서 왼쪽 리스트 생성
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 값을 모아서 가운데 리스트 생성
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 값들을 모아서 오른쪽 리스트 생성
    return quicksort(left) + middle + quicksort(right)  # 왼쪽과 오른쪽을 재귀 정렬한 뒤 결합하여 반환
```
