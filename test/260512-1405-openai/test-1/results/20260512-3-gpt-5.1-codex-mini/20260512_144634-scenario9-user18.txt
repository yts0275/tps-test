이 Workflow의 흐름은 다음과 같습니다.

1. **시작(Start)**: 시작 노드에서 바로 `SoftwareEngineer` 노드로 흐릅니다. 즉, 개발자는 처음에 `SoftwareEngineer` 상태가 됩니다.

2. **SoftwareEngineer 노드**: `SoftwareEngineer`는 여러 방향으로 나뉘어지며, 각각의 흐름은 다음과 같으며, 화살표 방향과 레이블을 기준으로 흐름이 표현됩니다.
   - `analyze_code` 레이블로 `CodeAnalyzer`로 이어집니다. 이는 개발자가 코드 분석을 시작하기 위해 `CodeAnalyzer`로 이동한다는 의미입니다.
   - `edit_file` 레이블로 `Editor`로 이어집니다. 코드를 수정하기 위해 `Editor`로 전환합니다.
   - `continue` 레이블로 `swe_tool`을 거쳐 `end`로 이어지는 흐름이 존재합니다. 이는 개발자가 어떤 도구(swe_tool)를 이용하여 계속 진행하다가 종료하는 상황을 나타낼 수 있습니다.
   - `done` 레이블로 노드 자체로 되돌아오는 자가 루프도 있으며, `SoftwareEngineer`에서 직접 `CodeAnalyzer` 또는 `Editor`로 연결된 `done` 흐름도 보입니다. 즉, 어떤 작업을 마치면 다시 `SoftwareEngineer` 상태로 돌아오거나 다른 도구 흐름으로 전환됩니다.

3. **CodeAnalyzer 노드**:
   - `SoftwareEngineer`에서 `analyze_code`로 진입합니다.
   - 내부적으로 `code_analysis_tool`이라는 실행 도구 노드로 흐릅니다 (점선 흐름). 이는 `CodeAnalyzer`가 실제 분석 툴을 사용하여 작업함을 나타냅니다.
   - 또한, `continue` 레이블이 `CodeAnalyzer`에서 `Editor`로 이어지거나 또는 `SoftwareEngineer`로 다시 반환되는 흐름이 있어 분석을 마친 후 편집으로 넘어가거나 다시 개발자 상태로 되돌아감을 나타냅니다.
   - `CodeAnalyzer`에서 `done` 레이블이 `SoftwareEngineer`로 향해 있으므로 분석 완료 후 개발자로 복귀합니다.

4. **Editor 노드**:
   - `SoftwareEngineer`에서 `edit_file`로 진입합니다.
   - 내부적으로 `code_edit_tool`과 `test_tool`로 연결되어 있어 편집 도구와 테스트 도구를 활용하면서 작업하는 흐름을 보여줍니다.
   - `continue` 레이블이 `Editor`에서 다시 `SoftwareEngineer`로 되돌아가거나 (`done`, `continue` 모두 존재) `CodeAnalyzer` 또는 `swe_tool`로 이어질 수 있습니다. 특히 `continue` 흐름 중 하나는 다시 `CodeAnalyzer`로 가는 듯한 점선 연결이 있어, 편집 후 다시 분석을 수행하거나, `test_tool`을 통해 테스트한 후 계속 진행할 수 있습니다.
   - `done` 레이블이 `SoftwareEngineer`로 향하므로 편집 작업 완료 후 개발자 상태로 돌아갑니다.

5. **swe_tool 노드**:
   - `SoftwareEngineer`에서 `continue` 흐름을 통해 `swe_tool`로 이동합니다. 이 도구는 아마 실제 작업 처리 흐름의 마지막 단계로, 말 그대로 개발 도구나 배포 절차를 의미할 수 있습니다.
   - `swe_tool`에서 다시 `SoftwareEngineer`로 직접적인 연결은 없으며, `end`로 이어지는 흐름만 존재하여 이 도구를 거친 뒤 Workflow가 종료되는 구조입니다.

6. **종료(end)**:
   - `swe_tool`을 거쳐 `continue` 레이블을 통해 `end` 노드에 도달하면서 전체 Workflow가 종료됩니다.

**요약**:
- 개발자는 `SoftwareEngineer`로 시작해 분석(`CodeAnalyzer`), 수정(`Editor`), 추가 도구(`swe_tool`) 등 다양한 작업을 반복적으로 수행함.
- 각 작업은 `done` 또는 `continue`로 상태 전환되며, 필요한 곳에서 도구(`code_analysis_tool`, `code_edit_tool`, `test_tool`)를 호출함.
- 최종적으로 개발자는 `swe_tool`을 거쳐 Workflow를 종료(`end`)함.
