다음은 각 줄마다 주석을 달아 설명한 퀵소트 구현입니다:

```python
def quicksort(arr):  # 퀵소트 함수를 정의합니다.
    if len(arr) <= 1:  # 배열 길이가 1 이하이면 이미 정렬된 상태이므로,
        return arr  # 그대로 반환합니다.
    pivot = arr[len(arr) // 2]  # 피벗을 배열 중간값으로 선택합니다.
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 요소들을 모읍니다.
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 요소들을 모읍니다.
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들을 모읍니다.
    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 정렬한 후 합쳐서 반환합니다.
```
