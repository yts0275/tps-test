다음은 각 줄마다 주석이 달린 Python으로 구현한 퀵소트 예시입니다.

```python
def quicksort(arr):  # 함수를 정의하여 퀵소트 알고리즘을 초기화합니다.
    if len(arr) <= 1:  # 리스트 길이가 1 이하이면 이미 정렬된 상태이므로 그대로 반환합니다.
        return arr  # 입력 배열을 그대로 반환합니다.
    pivot = arr[len(arr) // 2]  # 리스트 중간 요소를 기준점(pivot)으로 선택합니다.
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 요소들을 모아 왼쪽 서브리스트를 만듭니다.
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 요소들을 모아 중간 리스트를 만듭니다.
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들을 모아 오른쪽 서브리스트를 만듭니다.
    return quicksort(left) + middle + quicksort(right)  # 왼쪽, 중간, 오른쪽을 재귀적으로 정렬하여 합칩니다.
```
