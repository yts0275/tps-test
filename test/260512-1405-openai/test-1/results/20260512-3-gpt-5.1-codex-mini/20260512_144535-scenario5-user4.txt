다음은 퀵소트 구현 예시입니다. 각 줄마다 주석을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr):  # 배열을 입력받아 정렬된 배열을 반환하는 함수 정의
    if len(arr) <= 1:  # 배열의 길이가 1 이하이면 이미 정렬되어 있는 상태이므로
        return arr  # 입력 배열을 그대로 반환한다
    pivot = arr[len(arr) // 2]  # 배열 가운데 요소를 기준값(pivot)으로 선택한다
    left = [x for x in arr if x < pivot]  # pivot보다 작은 요소들을 왼쪽 그룹으로 모은다
    middle = [x for x in arr if x == pivot]  # pivot과 같은 요소들은 가운데 그룹으로 모은다
    right = [x for x in arr if x > pivot]  # pivot보다 큰 요소들은 오른쪽 그룹으로 모은다
    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 왼쪽과 오른쪽 그룹을 정렬한 후 결합하여 반환
```
