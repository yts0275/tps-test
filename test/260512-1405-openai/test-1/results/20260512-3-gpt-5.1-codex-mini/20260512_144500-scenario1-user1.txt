다음은 각 줄마다 주석을 단 퀵소트 구현 예시입니다:
```python
def quick_sort(arr):  # 퀵소트 함수를 정의합니다.
    if len(arr) <= 1:  # 배열 길이가 1 이하이면 이미 정렬된 상태입니다.
        return arr  # 현재 배열을 그대로 반환합니다.
    pivot = arr[len(arr) // 2]  # 피벗으로 가운데 값을 선택합니다.
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 요소들로 왼쪽 부분 배열을 만듭니다.
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 요소들을 중앙 부분 배열로 만듭니다.
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들로 오른쪽 부분 배열을 만듭니다.
    return quick_sort(left) + middle + quick_sort(right)  # 왼쪽, 가운데, 오른쪽 배열을 결합해 정렬 결과를 반환합니다.
```
