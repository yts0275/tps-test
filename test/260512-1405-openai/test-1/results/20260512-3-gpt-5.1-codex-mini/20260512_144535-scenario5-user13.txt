다음은 각 줄마다 주석이 달린 파이썬 퀵소트 구현입니다:

```python
def quicksort(arr):  # 리스트를 입력받아 정렬된 결과를 반환하는 함수 정의
    if len(arr) <= 1:  # 리스트의 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr  # 그대로 반환
    pivot = arr[len(arr) // 2]  # 리스트의 중간값을 피벗으로 선정
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 요소들을 왼쪽 리스트로 수집
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 요소들은 가운데 리스트에 모음
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들은 오른쪽 리스트에 수집
    return quicksort(left) + middle + quicksort(right)  # 왼쪽과 오른쪽을 재귀적으로 정렬한 후 결합하여 반환
```
