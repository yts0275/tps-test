다음은 퀵소트 구현 예시이며, 각 줄마다 한국어로 주석을 달았습니다:

```python
def quicksort(arr):
    # 배열이 비어있거나 요소가 하나뿐이면 그대로 반환합니다.
    if len(arr) <= 1:
        # 기준이 되는 경우이므로 정렬된 배열을 반환합니다.
        return arr
    # 배열의 첫 번째 요소를 피벗으로 선택합니다.
    pivot = arr[0]
    # 피벗보다 작은 요소들을 모읍니다.
    left = [x for x in arr[1:] if x <= pivot]
    # 피벗보다 큰 요소들을 모읍니다.
    right = [x for x in arr[1:] if x > pivot]
    # 좌측과 우측을 재귀적으로 정렬한 후 피벗과 합쳐서 반환합니다.
    return quicksort(left) + [pivot] + quicksort(right)
```
