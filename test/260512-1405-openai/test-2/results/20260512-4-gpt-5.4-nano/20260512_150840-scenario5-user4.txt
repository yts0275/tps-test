아래는 **퀵소트(Quick Sort)** 구현 예시와 **각 줄마다 주석**을 단 버전입니다. (파이썬)

```python
def quicksort(arr, left, right):  # 퀵소트 함수를 정의한다. arr은 정렬할 리스트, left/right는 범위의 인덱스다.
    if left >= right:  # 구간 길이가 0 또는 1이면 더 이상 정렬할 필요가 없으므로 종료한다.
        return  # 재귀를 종료한다.

    pivot = arr[(left + right) // 2]  # 기준값(pivot)을 현재 구간의 가운데 값으로 잡는다.
    i = left  # i 포인터를 왼쪽 끝에 둔다.
    j = right  # j 포인터를 오른쪽 끝에 둔다.

    while i <= j:  # i가 j를 역전을 일으키기 전까지 파티션(분할)을 진행한다.
        while arr[i] < pivot:  # i가 pivot보다 작은 동안 i를 오른쪽으로 이동한다.
            i += 1  # i를 1 증가시킨다.
        while arr[j] > pivot:  # j가 pivot보다 큰 동안 j를 왼쪽으로 이동한다.
            j -= 1  # j를 1 감소시킨다.

        if i <= j:  # i와 j가 아직 교차하지 않았다면(또는 같다면) 교환이 필요할 수 있다.
            arr[i], arr[j] = arr[j], arr[i]  # i 위치 값과 j 위치 값을 서로 교환한다.
            i += 1  # 교환 후 i를 오른쪽으로 한 칸 이동한다.
            j -= 1  # 교환 후 j를 왼쪽으로 한 칸 이동한다.

    quicksort(arr, left, j)  # pivot 기준으로 왼쪽 파티션을 재귀적으로 정렬한다.
    quicksort(arr, i, right)  # pivot 기준으로 오른쪽 파티션을 재귀적으로 정렬한다.


# 사용 예시
data = [10, 7, 8, 9, 1, 5]  # 정렬할 초기 배열을 만든다.
quicksort(data, 0, len(data) - 1)  # 전체 범위를 대상으로 퀵소트를 수행한다.
print(data)  # 정렬 결과를 출력한다.
```
