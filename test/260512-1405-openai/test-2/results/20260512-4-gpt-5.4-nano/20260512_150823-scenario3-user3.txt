아래는 **퀵소트(Quick Sort)** 구현 예시입니다.  
요청하신 대로 **각 줄(또는 거의 모든 라인)** 마다 주석을 달았습니다. (가독성을 위해 한 줄에 여러 의미가 들어가지 않게 했어요.)

```python
def quicksort(arr):                       # 퀵소트를 수행할 함수 정의
    if len(arr) <= 1:                    # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                        # 그대로 반환

    pivot = arr[0]                       # 기준값(pivot)을 첫 번째 원소로 선택
    left = []                            # pivot보다 작은 값들을 담을 리스트
    right = []                           # pivot보다 큰(또는 같은 방식 처리) 값들을 담을 리스트

    for x in arr[1:]:                   # pivot을 제외한 나머지 원소들을 순회
        if x < pivot:                    # 현재 값이 pivot보다 작다면
            left.append(x)              # left 리스트에 추가
        else:                             # 현재 값이 pivot보다 크거나 같다면
            right.append(x)             # right 리스트에 추가

    return quicksort(left) + [pivot] + quicksort(right)  # 재귀로 정렬 후 결합
```

1) **자바/자바스크립트/C++** 버전으로도 바꿔드리거나,  
2) “각 줄마다”를 정말 **초정밀로**(빈 줄/괄호 라인까지 포함) 달아드리거나,  
3) **제자리(in-place) 퀵소트**(배열 자체를 수정하는 방식)로 구현도 가능해요.
