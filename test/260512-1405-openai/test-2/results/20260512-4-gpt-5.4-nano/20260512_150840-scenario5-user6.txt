아래는 **퀵소트(Quick Sort) 구현 예시**입니다. **각 줄마다 주석**을 달았습니다. (파이썬)

```python
def quicksort(arr):  # 퀵소트 함수를 정의한다. (입력: 배열 arr)
    if len(arr) <= 1:  # 배열의 길이가 0 또는 1이면 이미 정렬된 것이므로
        return arr  # 그대로 반환한다.
    
    pivot = arr[len(arr) // 2]  # 가운데 원소를 피벗(pivot)으로 선택한다.
    
    left = []  # 피벗보다 작은 값들을 담을 리스트를 만든다.
    middle = []  # 피벗과 같은 값들을 담을 리스트를 만든다.
    right = []  # 피벗보다 큰 값들을 담을 리스트를 만든다.
    
    for x in arr:  # 배열의 각 원소 x에 대해 반복한다.
        if x < pivot:  # x가 피벗보다 작다면
            left.append(x)  # left 리스트에 추가한다.
        elif x > pivot:  # x가 피벗보다 크다면
            right.append(x)  # right 리스트에 추가한다.
        else:  # x가 피벗과 같다면
            middle.append(x)  # middle 리스트에 추가한다.
    
    return quicksort(left) + middle + quicksort(right)  # 왼쪽(정렬) + 피벗(같은 값) + 오른쪽(정렬)을 합쳐 반환한다.
```
