아래는 **퀵소트(Quick Sort) 구현** 예시이며, **각 줄마다 주석**을 달아두었습니다. (파이썬 기준)

```python
def quicksort(arr):  # 퀵소트를 수행하는 함수(배열 arr를 받아서 정렬된 배열을 반환)
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬된 상태이므로
        return arr  # 그대로 반환

    pivot = arr[len(arr) // 2]  # 가운데 원소를 피벗(pivot)으로 선택
    left = []  # 피벗보다 작은 원소들을 담을 리스트
    right = []  # 피벗보다 큰 원소들을 담을 리스트
    equal = []  # 피벗과 같은 원소들을 담을 리스트

    for x in arr:  # 입력 배열의 각 원소 x에 대해 반복
        if x < pivot:  # x가 피벗보다 작으면
            left.append(x)  # left에 추가
        elif x > pivot:  # x가 피벗보다 크면
            right.append(x)  # right에 추가
        else:  # x가 피벗과 같으면
            equal.append(x)  # equal에 추가

    return quicksort(left) + equal + quicksort(right)  # 정렬된 left + 피벗과 같은 값들 + 정렬된 right 합쳐서 반환
```

2) C / Java / JavaScript 등 다른 언어 버전
