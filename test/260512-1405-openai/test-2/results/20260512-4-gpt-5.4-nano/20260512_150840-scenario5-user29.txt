아래는 **퀵소트(Quick Sort)** 예시 구현입니다.  
요청하신 대로 **각 줄마다 주석**을 달았습니다. (Python)

```python
def quicksort(arr):  # 퀵소트 함수를 정의한다. (입력: 리스트 arr)
    if len(arr) <= 1:  # 원소가 0개 또는 1개면 이미 정렬된 것이므로 그대로 반환한다.
        return arr  # 정렬된 리스트를 반환한다.

    pivot = arr[len(arr) // 2]  # 가운데 원소를 피벗(pivot)으로 선택한다.
    left = []  # 피벗보다 작은 값들을 담을 리스트를 만든다.
    right = []  # 피벗보다 큰 값들을 담을 리스트를 만든다.
    middle = []  # 피벗과 같은 값들을 담을 리스트를 만든다.

    for x in arr:  # 입력 배열의 각 원소 x를 순회한다.
        if x < pivot:  # x가 피벗보다 작으면
            left.append(x)  # left 리스트에 x를 추가한다.
        elif x > pivot:  # x가 피벗보다 크면
            right.append(x)  # right 리스트에 x를 추가한다.
        else:  # x가 피벗과 같으면
            middle.append(x)  # middle 리스트에 x를 추가한다.

    return quicksort(left) + middle + quicksort(right)  # 재귀로 left와 right를 정렬한 뒤 middle과 합쳐 반환한다.


# 테스트를 위한 코드 시작
if __name__ == "__main__":  # 이 파일이 직접 실행된 경우에만 아래 코드를 실행한다.
    data = [3, 6, 8, 10, 1, 2, 1]  # 예시 입력 배열을 만든다.
    print(quicksort(data))  # 퀵소트 결과를 출력한다.
```
