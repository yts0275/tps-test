아래는 **퀵소트(Quicksort)** 구현 예시(파이썬)와 **각 줄마다 주석**을 단 버전입니다.

```python
def quicksort(arr):  # 퀵소트 함수 정의 (배열 arr을 받아 정렬된 배열을 반환)
    if len(arr) <= 1:  # 배열 길이가 0 또는 1이면 이미 정렬되어 있으므로
        return arr  # 입력 그대로 반환

    pivot = arr[len(arr) // 2]  # 기준값(pivot)을 배열의 가운데 원소로 선택
    left = []  # pivot보다 작은 값들을 담을 리스트 생성
    middle = []  # pivot과 같은 값들을 담을 리스트 생성
    right = []  # pivot보다 큰 값들을 담을 리스트 생성

    for x in arr:  # 배열의 각 원소 x에 대해 반복
        if x < pivot:  # x가 pivot보다 작으면
            left.append(x)  # left 리스트에 추가
        elif x > pivot:  # x가 pivot보다 크면
            right.append(x)  # right 리스트에 추가
        else:  # x가 pivot과 같으면
            middle.append(x)  # middle 리스트에 추가

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 정렬 + pivot들 + 오른쪽 정렬 결과를 합쳐 반환
```
