다음은 퀵소트를 구현한 예시 코드이며, 각 줄마다 한국어 주석을 달았습니다.

```python
def quicksort(arr):  # 퀵소트 함수 정의, 입력은 정렬할 리스트
    if len(arr) <= 1:  # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr  # 그대로 반환
    pivot = arr[len(arr) // 2]  # 리스트 중앙 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 요소들을 모은 리스트
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 요소들을 모은 리스트
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들을 모은 리스트
    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 정렬한 뒤 합쳐서 반환
```
