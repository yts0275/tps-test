아래는 각 줄마다 주석을 단 퀵소트 구현입니다:

```python
def quicksort(arr):  # 퀵소트 함수 정의, 입력은 리스트
    if len(arr) <= 1:  # 리스트 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr  # 그대로 반환
    pivot = arr[len(arr) // 2]  # 리스트 중간값을 피벗으로 선택
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 요소들로 왼쪽 리스트 구성
    equal = [x for x in arr if x == pivot]  # 피벗과 같은 요소들로 가운데 리스트 구성
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들로 오른쪽 리스트 구성
    return quicksort(left) + equal + quicksort(right)  # 재귀적으로 정렬 후 합쳐서 반환
```
