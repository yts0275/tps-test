다음은 각 줄마다 주석을 단 퀵소트 구현 예시입니다.

```python
def 퀵소트(배열):                      # 퀵소트를 수행하는 함수를 정의합니다.
    if len(배열) <= 1:                # 배열의 길이가 1 이하이면 이미 정렬된 상태입니다.
        return 배열                    # 그대로 반환하여 정렬을 종료합니다.
    피봇 = 배열[len(배열) // 2]       # 배열의 가운데 요소를 피봇으로 선택합니다.
    작은_부분 = [x for x in 배열 if x < 피봇]    # 피봇보다 작은 요소들을 모읍니다.
    피봇_동일 = [x for x in 배열 if x == 피봇]  # 피봇과 같은 요소들을 모읍니다.
    큰_부분 = [x for x in 배열 if x > 피봇]     # 피봇보다 큰 요소들을 모읍니다.
    return 퀵소트(작은_부분) + 피봇_동일 + 퀵소트(큰_부분)  # 재귀적으로 정렬한 후 전체를 합쳐 반환합니다.
```
