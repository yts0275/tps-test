다음은 퀵소트 구현 예시입니다. 각 줄마다 주석을 달아 이해를 돕습니다.

```python
def quicksort(arr):  # 퀵소트 함수 정의
    if len(arr) <= 1:  # 배열 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr  # 입력 배열을 그대로 반환
    pivot = arr[len(arr) // 2]  # 피벗은 배열 중앙 요소로 설정
    left = [x for x in arr if x < pivot]  # 피벧보다 작은 요소들을 왼쪽 배열로
    middle = [x for x in arr if x == pivot]  # 피벧과 같은 요소들을 가운데 배열로
    right = [x for x in arr if x > pivot]  # 피벧보다 큰 요소들을 오른쪽 배열로
    return quicksort(left) + middle + quicksort(right)  # 왼쪽과 오른쪽을 재귀적으로 정렬한 뒤 합쳐 반환
```
