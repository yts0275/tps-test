다음은 퀵소트 구현 예시입니다. 각 줄마다 한국어로 주석을 달았습니다:

```python
def quicksort(arr):
    # 배열 길이가 1 이하이면 이미 정렬된 상태이므로 그대로 반환합니다.
    if len(arr) <= 1:
        return arr
    # 피벗을 배열의 가운데 원소로 설정합니다.
    pivot = arr[len(arr) // 2]
    # 피벗보다 작은 원소들을 모읍니다.
    left = [x for x in arr if x < pivot]
    # 피벗과 같은 원소들을 모읍니다.
    middle = [x for x in arr if x == pivot]
    # 피벧보다 큰 원소들을 모읍니다.
    right = [x for x in arr if x > pivot]
    # 왼쪽 부분, 중간, 오른쪽 부분을 각각 정렬한 뒤 하나로 합쳐서 반환합니다.
    return quicksort(left) + middle + quicksort(right)
```
