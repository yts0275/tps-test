다음은 파이썬으로 구현한 퀵소트입니다 — 각 코드 줄마다 한글 주석을 달아놓았습니다.

def quicksort(arr):  # 리스트를 제자리(in-place)로 정렬하는 퀵소트 함수 정의
    def partition(low, high):  # 배열의 일부를 피벗 기준으로 분할하는 보조 함수 정의
        pivot = arr[high]  # 피벗을 오른쪽 끝 요소로 선택하여 pivot 변수에 저장
        i = low - 1  # 작은(<= pivot) 요소들의 경계를 나타내는 인덱스 i 초기화
        for j in range(low, high):  # low부터 high-1까지 각 요소를 순회하며 검사
            if arr[j] <= pivot:  # 현재 요소가 피벗 이하이면 작은 그룹에 포함
                i += 1  # 작은 그룹의 경계를 한 칸 오른쪽으로 이동
                arr[i], arr[j] = arr[j], arr[i]  # 경계 위치와 현재 요소를 교환하여 작은 그룹 유지
        arr[i+1], arr[high] = arr[high], arr[i+1]  # 피벗을 작은 그룹 바로 다음 위치로 옮겨 제자리에 둠
        return i + 1  # 피벗의 최종 위치 인덱스를 반환
    def _quicksort(low, high):  # 실제 재귀 호출을 수행하는 내부 함수 정의
        if low < high:  # 구간에 두 개 이상의 요소가 있을 때만 정렬 수행
            pi = partition(low, high)  # 분할을 수행하여 피벗 위치(pi)를 얻음
            _quicksort(low, pi - 1)  # 피벗 왼쪽 부분 배열을 재귀적으로 정렬
            _quicksort(pi + 1, high)  # 피벗 오른쪽 부분 배열을 재귀적으로 정렬
    _quicksort(0, len(arr) - 1)  # 리스트 전체(0부터 len(arr)-1까지)에 대해 퀵소트 시작
    return arr  # 정렬된 리스트(같은 참조)를 반환

# 사용 예시
if __name__ == "__main__":  # 모듈을 직접 실행할 때만 아래 예시 코드 실행
    data = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 테스트용 리스트 정의
    print("정렬 전:", data)  # 정렬 전 상태 출력
    print("정렬 후:", quicksort(data))  # 퀵소트 호출 후 정렬 결과 출력
