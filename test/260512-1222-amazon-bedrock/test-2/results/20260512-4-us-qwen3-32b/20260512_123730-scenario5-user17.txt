---

### ✅ 퀵소트(Quick Sort) Python 구현

```python
# 퀵소트를 위한 메인 함수
def quicksort(arr):
    # 기저 조건: 배열의 길이가 1 이하면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot) 선택: 여기서는 리스트의 첫 번째 요소를 피벗으로 선택
    pivot = arr[0]
    
    # 피벗보다 작거나 같은 요소로 구성된 서브 배열 (왼쪽 그룹)
    left = [x for x in arr[1:] if x <= pivot]
    
    # 피벗보다 큰 요소로 구성된 서브 배열 (오른쪽 그룹)
    right = [x for x in arr[1:] if x > pivot]
    
    # 재귀적 호출을 통해 왼쪽과 오른쪽 서브 배열을 정렬한 후,
    # 피벗을 사이에 끼워 전체를 정렬된 형태로 반환
    return quicksort(left) + [pivot] + quicksort(right)
```

---

### 📝 주석 설명

1. `def quicksort(arr):`  
   - `quicksort`라는 이름의 함수 정의. 입력 배열 `arr`이 정렬됩니다.

2. `if len(arr) <= 1: return arr`  
   - 재귀의 **기저(Basis) 조건**: 요소가 하나 이하이면 이미 정렬된 배열로 간주하고 그대로 반환합니다.

3. `pivot = arr[0]`  
   - **피벗**을 선택합니다. 일반적으로 첫 번째 요소를 사용하며, 다른 요소를 선택할 수도 있습니다.

4. `left = [x for x in arr[1:] if x <= pivot]`  
   - 피벗보다 작거나 같은 요소들만 모아 `left` 리스트를 생성합니다.

5. `right = [x for x in arr[1:] if x > pivot]`  
   - 피벗보다 큰 요소들만 모아 `right` 리스트를 생성합니다.

6. `return quicksort(left) + [pivot] + quicksort(right)`  
   - `left`와 `right` 서브리스트를 재귀적으로 정렬하고,  
     정렬한 왼쪽 + 피벗 + 정렬한 오른쪽을 합쳐 최종 정렬 결과를 반환합니다.

---

### ✅ 예시 사용

```python
nums = [3, 6, 8, 10, 1, 2, 1]
sorted_nums = quicksort(nums)
print(sorted_nums)  # 출력: [1, 1, 2, 3, 6, 8, 10]
```
