다음은 **파이썬**으로 구현한 **퀵소팅**(Quick Sort) 알고리즘입니다. 각 줄마다 자세한 주석을 달았습니다.

### ✅ 퀵소트란?
- 퀵소트는 **분할 정복**(Divide and Conquer) 전략을 사용하는 **재귀적 정렬 알고리즘**입니다.
- 배열을 **피벗**(pivot)을 기준으로 두 부분으로 나누고, 각 부분을 재귀적으로 정렬합니다.

---

### 🧾 퀵소트 파이썬 구현

```python
def quick_sort(arr):
    # 1. 빈 배열일 경우 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗 선택: 여기서는 맨 처음 요소를 피벗으로 선택
    pivot = arr[0]

    # 3. 피벗보다 작은 원소를 포함하는 왼쪽 배열
    left = [x for x in arr[1:] if x < pivot]

    # 4. 피벗보다 큰 원소를 포함하는 오른쪽 배열
    right = [x for x in arr[1:] if x >= pivot]

    # 5. 재귀적으로 왼쪽, 오른쪽 배열을 정렬한 후,
    #     정렬된 왼쪽 배열 + 피벗 + 정렬된 오른쪽 배열 형태로 반환
    return quick_sort(left) + [pivot] + quick_sort(right)
```

---

### 🧪 예시 실행

```python
unsorted_array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quick_sort(unsorted_array)
print("정렬 결과:", sorted_array)
```

**결과:**

```
정렬 결과: [1, 1, 2, 3, 6, 8, 10]
```

---

### ✅ 시간 복잡도 (최선/평균: O(n log n) | 최악: O(n²))

- 퀵소트는 대부분의 데이터에서 매우 빠르게 동작합니다.
- 최악의 경우(예: 이미 정렬된 배열)는 **버블 소트와 비슷한 성능**을 보일 수 있습니다.
