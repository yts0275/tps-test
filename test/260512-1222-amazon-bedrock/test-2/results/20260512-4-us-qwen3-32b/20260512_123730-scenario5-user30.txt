### 🚀 퀵소트(Quick Sort) Python 구현

```python
# 퀵소트는 분할과 정복 기법을 사용하는 정렬 알고리즘입니다.
# 기본적으로 피벗(pivot)을 기준으로 왼쪽은 피벗보다 작은 수, 오른쪽은 큰 수로 분할 후 재귀적으로 정렬합니다.

def quicksort(arr):
    # 1. 만약 배열의 길이가 0이거나 1이면(빈 배열이나 하나만 있는 경우), 정렬할 필요가 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot)을 선택합니다. 여기서는 배열의 첫 번째 원소를 사용합니다.
    pivot = arr[0]

    # 3. 피벗보다 작은 수들을 저장할 리스트
    less_than_pivot = []
    # 4. 피벗보다 큰 수들을 저장할 리스트
    greater_than_pivot = []
    # 5. 피벗과 같은 수들을 저장할 리스트 (중복 원소가 있을 때 필요)
    equal_to_pivot = []

    # 6. 배열의 모든 요소를 순회하며 분류합니다.
    for num in arr:
        if num < pivot:
            less_than_pivot.append(num)      # 피벗보다 작은 수
        elif num > pivot:
            greater_than_pivot.append(num)   # 피벗보다 큰 수
        else:
            equal_to_pivot.append(num)       # 피벗과 같은 수는 여기 넣음

    # 7. 재귀적으로 왼쪽, 중간, 오른쪽 리스트를 정렬한 후 결합
    return quicksort(less_than_pivot) + equal_to_pivot + quicksort(greater_than_pivot)

# 테스트 코드
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quicksort(arr)

print("정렬 전:", arr)
print("정렬 후:", sorted_arr)
```

```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

### 💡 주석 설명 정리

- **Line 3-5**: 기본 종료 조건 설정 (재귀 종료)
- **Line 7~9**: 피벗보다 작고, 크고, 같은 요소들을 분리
- **Line 11**: 분할된 데이터를 재귀적으로 정렬
- **Line 13-14**: 테스트 코드
