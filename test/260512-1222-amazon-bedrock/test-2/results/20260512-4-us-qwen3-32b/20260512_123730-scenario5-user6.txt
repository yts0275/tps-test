---

### ✅ 퀵소트 (Quick Sort) in Python

```python
def quick_sort(arr):
    """ 주어진 배열을 퀵소트로 정렬합니다. """
    
    # 1. 빈 배열이면 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2. 피벗(pivot)을 선택합니다. (이 예제에서는 첫 번째 요소로 선택)
    pivot = arr[0]
    
    # 3. 피벗보다 작은 요소들을 저장할 리스트
    left = []
    
    # 4. 피벗보다 큰 요소들을 저장할 리스트
    right = []
    
    # 5. 피벗과 같은 값이 있는 경우, 따로 처리하지만 지금은 left/right에도 포함
    for num in arr[1:]:  # 6. 피벗을 제외한 나머지를 순회
        if num < pivot:  # 7. 피벗보다 오는 값
            left.append(num)
        else:            # 8. 피벗보다 크거나 같은 값
            right.append(num)

    # 9. 재귀적으로 왼쪽과 오른쪽 부분 리스트를 정렬
    return quick_sort(left) + [pivot] + quick_sort(right)
```

---

### 🔍 어떻게 동작하는지 예시

입력: `[5, 3, 8, 4, 2]`

1. 피벗 = 5  
   left: [3,4,2] (5보다 작은 수)  
   right: [8] (5보다 큰 수)

2. 왼쪽 [3,4,2] 퀵소트 재귀
3. 오른쪽 [8] 퀵소트 재귀
4. 정렬 후: [3,2,4] + [5] + [8] → [3,2,4,5,8] → [2,3,4,5,8]

---

### ✅ 출력 예제

```python
print(quick_sort([5, 3, 8, 4, 2]))
# 결과: [2, 3, 4, 5, 8]
```
