물론입니다! 아래는 파이썬에서 퀵소트(QuickSort)를 구현한 코드이며, 각 줄에 대해 친절하게 주석을 달아 설명하겠습니다.

```python
# 퀵소트를 위해 함수를 정의합니다.
def quicksort(arr):
    # 리스트에 항목이 없거나 1개만 있으면 이미 정렬된 상태이므로 바로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 리스트의 첫 번째 항목으로 선택합니다.
    pivot = arr[0]

    # 피벗보다 작거나 같은 수들을 모을 왼쪽 리스트
    left = []
    # 피벗보다 큰 수들을 모을 오른쪽 리스트
    right = []

    # 피벗을 제외한 나머지 엘리먼트를 순회합니다.
    for num in arr[1:]:
        # 해당 수가 피벗보다 작거나 같다면 왼쪽 리스트에 추가
        if num <= pivot:
            left.append(num)
        # 아니면 피벗보다 커서 오른쪽 리스트에 추가
        else:
            right.append(num)

    # 재귀적으로 왼쪽 리스트와 오른쪽 리스트를 각각 퀵소트합니다.
    # 그 후 왼쪽 리스트 + [피벗] + 오른쪽 리스트의 형태로 정렬된 리스트를 반환
    return quicksort(left) + [pivot] + quicksort(right)
```

### 예시:
```python
arr = [3, 6, 8, 10, 1, 2, 1]
print(quicksort(arr))
```

### 결과:
```
[1, 1, 2, 3, 6, 8, 10]
```

---

이 퀵소트는 **리스트 내비키(list comprehension) 없이** 기본적인 방식으로 구현된 것으로,
기초적인 이해를 위해 적합합니다. 추가적으로 공간 복잡도나 인플레이스 정렬(in-place) 버전도 존재하므로 필요하시면 소개해드릴 수 있어요!
