---

### 🚀 퀵소트(Quick Sort) - Python으로 구현

```python
def quick_sort(arr):
    """
    퀵소트 알고리즘을 사용하여 리스트를 정렬합니다.
    
    매개변수:
        arr (list): 정렬할 원본 리스트
    반환:
        list: 정렬된 리스트
    """
    # 1. 기저 조건: 리스트의 길이가 0이면 빈 리스트를 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot)을 선택합니다. 여기서는 첫 번째 요소를 피벗으로 선택
    pivot = arr[0]

    # 3. 피벗보다 작거나 같은 요소들은 left 리스트에 저장
    left = [x for x in arr[1:] if x <= pivot]

    # 3.1. 피벗보다 큰 요소들은 right 리스트에 저장
    right = [x for x in arr[1:] if x > pivot]

    # 4. 왼쪽 리스트를 퀵소트로 재귀호출하여 정렬
    sorted_left = quick_sort(left)

    # 5. 오른쪽 리스트를 퀵소트로 재귀호출하여 정렬
    sorted_right = quick_sort(right)

    # 6. 정렬된 왼쪽 + 피벗 + 정렬된 오른쪽을 합쳐 최종 정렬 결과를 반환
    return sorted_left + [pivot] + sorted_right
```

---

### 🧪 실행 예시

```python
# 예시 리스트
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵소트 호출
sorted_arr = quick_sort(arr)

# 결과 출력
print(sorted_arr)  # 출력: [1, 1, 2, 3, 6, 8, 10]
```

---

💡 **정리:**
- 퀵소트는 **분할 정복 알고리즘**입니다.
- 리스트에서 **피벗**을 선택하고, 피벗보다 작은 그룹과 큰 그룹으로 나눕니다.
- 각 그룹에 대해 재귀적으로 퀵소트를 적용한 후, 결과를 합쳤습니다.
- 시간복잡도는 평균적으로 **O(n log n)**, 최악의 경우 **O(n²)** 입니다.
