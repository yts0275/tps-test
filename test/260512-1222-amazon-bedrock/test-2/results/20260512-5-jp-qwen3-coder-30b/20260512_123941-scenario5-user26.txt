물론입니다! 아래는 **퀵정렬**(Quick Sort) 알고리즘의 Python 구현 코드입니다. 코드의 각 줄에 대해 상세한 주석을 달았습니다.

```python
def quicksort(arr, low, high):
    # 재귀적으로 퀵정렬을 수행하는 함수
    # arr: 정렬할 배열, low: 시작 인덱스, high: 끝 인덱스
    if low < high:
        # 파티션 함수를 호출하여 피벗 위치를 구함
        pi = partition(arr, low, high)

        # 피벗의 왼쪽 부분 배열에 대해 재귀적으로 퀵정렬 실행
        quicksort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분 배열에 대해 재귀적으로 퀵정렬 실행
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 배열을 피벗을 기준으로 두 부분으로 나누는 함수
    # 피벗은 배열의 마지막 원소로 잡음
    pivot = arr[high]

    # i는 작은 값을 가진 요소들의 마지막 인덱스
    i = low - 1

    # j는 현재 검사 중인 요소를 나타냄
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, i와 j의 요소를 교환함
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킴 (피벗의 왼쪽은 모두 작고, 오른쪽은 모두 큼)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 위치한 인덱스 반환
    return i + 1

# 예제 사용법
if __name__ == "__main__":
    arr = [10, 7, 8, 9, 1, 5]
    n = len(arr)
    print("정렬 전:", arr)
    quicksort(arr, 0, n - 1)  # 퀵정렬 호출
    print("정렬 후:", arr)
```

### 📘 설명

- `quicksort()` 함수: **재귀**적으로 배열을 정렬합니다.
- `partition()` 함수: **피벗을 이용해** 배열을 두 개로 분할하고, 피벗의 최종 위치를 반환합니다.
- `pivot`: 피벗은 마지막 요소로 선택되어 있습니다. (선택에 따라 조정 가능)
- 시간 복잡도: 평균 `O(n log n)`, 최악 `O(n²)`
- 공간 복잡도: `O(log n)` (재귀 스택)
