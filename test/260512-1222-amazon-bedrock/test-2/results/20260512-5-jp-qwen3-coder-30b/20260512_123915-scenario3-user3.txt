```python
# 퀵 정렬(Quick Sort) 알고리즘을 구현하는 함수입니다.
def quick_sort(arr):
    # 배열이 비어 있거나 길이가 1이라면 정렬할 필요가 없으므로 그대로 반환합니다.
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)은 배열의 중간에 있는 원소로 선택합니다.
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 원소들을 모은 리스트입니다.
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 원소들을 모은 리스트입니다.
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 원소들을 모은 리스트입니다.
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 좌측과 우측 배열을 정렬한 후, 중간 배열과 합칩니다.
    return quick_sort(left) + middle + quick_sort(right)

# 예제 배열을 정의합니다.
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵 정렬을 실행하고 결과를 출력합니다.
print("정렬 전:", arr)
sorted_arr = quick_sort(arr)
print("정렬 후:", sorted_arr)
```

위 코드는 퀵 정렬 알고리즘의 기본적인 구현 방식입니다.

- `quick_sort` 함수는 입력된 배열을 정렬하여 반환합니다.
- 피벗은 중간 원소로 선택되며, 각각의 원소들은 피벗과 비교하면서 세 가지 그룹으로 나뉩니다: 작은 값, 같은 값, 큰 값.
- 이후 재귀적으로 해당 부분을 정렬한 뒤 결과를 결합하여 전체 배열을 정렬합니다.
