물론입니다! 다음은 **퀵정렬(Quick Sort)** 알고리즘의 Python 구현 코드이며, 각 줄에 주석을 달았습니다.

```python
# 퀵정렬 함수: 배열을 정렬하는 메인 함수
def quicksort(arr, low, high):
    # base case: low가 high보다 크거나 같으면 더 이상 정렬할 필요 없음
    if low < high:
        # 피벗을 기준으로 배열을 분할하고, 피벗의 인덱스를 얻음
        pi = partition(arr, low, high)
        
        # 피벗의 왼쪽 부분 배열을 퀵정렬
        quicksort(arr, low, pi - 1)
        
        # 피벗의 오른쪽 부분 배열을 퀵정렬
        quicksort(arr, pi + 1, high)

# 분할 함수: 배열을 피벗을 기준으로 두 부분으로 나누는 함수
def partition(arr, low, high):
    # 배열의 마지막 원소를 피벗으로 설정
    pivot = arr[high]
    
    # i는 작은 요소들을 위한 인덱스 (초기값은 low-1)
    i = low - 1
    
    # j는 현재 검사 중인 요소를 나타내는 인덱스
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 요소와 arr[i]를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동: 피벗을 i+1 위치로 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 있는 위치를 반환
    return i + 1

# 예제 사용법
if __name__ == "__main__":
    # 정렬할 배열 생성
    arr = [10, 7, 8, 9, 1, 5]
    
    # 배열의 길이를 저장
    n = len(arr)
    
    # 퀵정렬 실행
    quicksort(arr, 0, n - 1)
    
    # 정렬된 배열 출력
    print("정렬된 배열:", arr)
```

### 설명:

- `quicksort(arr, low, high)` : 재귀적으로 호출되며, 배열을 정렬함.
- `partition(arr, low, high)` : 피벗을 기준으로 배열을 나누고, 피벗의 최종 위치를 반환함.
- `pivot` : 정렬 대상 배열의 마지막 원소를 피벗으로 사용.
- `i` : 왼쪽에 있는, 피벗보다 작거나 같은 요소들의 끝 인덱스.
- `j` : 현재 탐색 중인 인덱스.
- `arr[i+1], arr[high]` : 피벗을 올바른 위치로 이동시킴.
