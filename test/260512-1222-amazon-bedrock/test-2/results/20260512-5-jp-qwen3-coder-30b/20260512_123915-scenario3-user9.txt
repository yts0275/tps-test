아래는 퀵소트(Quick Sort) 알고리즘의 Python 구현 코드입니다. 각 줄에 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr, low, high):
    # 재귀적으로 퀵소트를 실행하는 함수이다.
    # arr: 정렬할 배열, low: 시작 인덱스, high: 끝 인덱스
    
    if low < high:
        # base case: low가 high보다 작을 때만 계속 분할한다.
        
        pi = partition(arr, low, high)
        # 파티션 함수를 호출하여 기준값(pivot)의 최종 위치를 얻는다.
        # pi는 피벗(기준값)이 위치한 인덱스이다.
        
        quicksort(arr, low, pi - 1)
        # 피벗 왼쪽 부분 배열을 재귀적으로 정렬한다.
        
        quicksort(arr, pi + 1, high)
        # 피벗 오른쪽 부분 배열을 재귀적으로 정렬한다.

def partition(arr, low, high):
    # 배열의 특정 범위 내에서 피벗을 기준으로 요소들을 나누는 함수
    
    pivot = arr[high]
    # 마지막 요소를 피벗으로 설정한다.
    
    i = low - 1
    # i는 작은 값들이 위치할 인덱스를 가리킨다. 먼저 -1로 초기화한다.
    
    for j in range(low, high):
        # j는 현재 탐색 중인 인덱스이며, low부터 high-1까지 이동한다.
        
        if arr[j] <= pivot:
            # 만약 현재 요소가 피벗보다 작거나 같다면,
            
            i += 1
            # i를 증가시켜 작은 값을 위한 위치를 확보한다.
            
            arr[i], arr[j] = arr[j], arr[i]
            # 현재 요소와 i 위치의 요소를 교환한다.
    
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗을 적절한 위치로 이동시킨다. 피벗은 i+1에 위치하게 된다.
    
    return i + 1
    # 피벗이 최종적으로 위치한 인덱스를 반환한다.

# 사용 예제
if __name__ == "__main__":
    arr = [10, 7, 8, 9, 1, 5]
    # 정렬할 배열을 정의한다.
    
    n = len(arr)
    # 배열의 길이를 저장한다.
    
    quicksort(arr, 0, n - 1)
    # 퀵소트를 실행한다. 처음에는 전체 배열을 대상으로 한다.
    
    print("정렬된 배열:", arr)
    # 정렬 후 결과를 출력한다.
```

### 간단 설명:

- `quicksort()` 함수는 배열을 재귀적으로 분할하며,
- `partition()` 함수는 피벗을 중심으로 작은 값과 큰 값을 나누는 역할을 합니다.
- 시간 복잡도는 평균적으로 O(n log n), 최악의 경우 O(n²)입니다.
