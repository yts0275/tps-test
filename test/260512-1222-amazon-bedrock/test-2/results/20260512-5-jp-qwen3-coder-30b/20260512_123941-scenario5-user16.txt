물론입니다! 아래에 퀵정렬(Quick Sort) 알고리즘의 코드를 구현하고, 각 줄마다 주석을 달아놓았습니다.

```python
# 피벗을 기준으로 배열을 분할하는 함수
def partition(arr, low, high):
    # 마지막 요소를 피벗으로 설정
    pivot = arr[high]
    
    # i는 작은 요소들의 인덱스를 가리킴
    i = low - 1

    # 배열의 모든 요소를 순회하면서
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 요소와 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 제대로된 위치로 이동시킴
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 있는 위치 반환
    return i + 1

# 퀵정렬 메인 함수
def quicksort(arr, low, high):
    # 재귀적 호출 종료 조건: 시작 인덱스가 끝 인덱스보다 크거나 같으면 종료
    if low < high:
        # 파티션 함수를 통해 피벗의 올바른 위치를 찾음
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분 배열에 대해 재귀적으로 퀵정렬 수행
        quicksort(arr, low, pi - 1)

        # 피벗 오른쪽 부분 배열에 대해 재귀적으로 퀵정렬 수행
        quicksort(arr, pi + 1, high)

# 사용 예제
if __name__ == "__main__":
    # 정렬할 배열 생성
    arr = [10, 7, 8, 9, 1, 5]
    
    # 배열의 길이
    n = len(arr)
    
    # 퀵정렬 실행 (시작 인덱스는 0, 끝 인덱스는 n-1)
    quicksort(arr, 0, n - 1)
    
    # 결과 출력
    print("정렬된 배열:", arr)
```

---

### 설명:

- `partition()` 함수는 배열을 **피벗**을 기준으로 두 부분으로 나누는 역할을 합니다.
- `quicksort()` 함수는 **재귀적으로** 배열을 분할하며, `partition` 함수를 통해 피벗의 위치를 찾아가며 정렬합니다.
- 이러한 방식으로 **평균적인 시간 복잡도는 O(n log n)** 이며, **최악의 경우 O(n²)** 이 될 수 있습니다.
