```python
# 퀵정렬(QucikSort) 함수 정의
def quicksort(arr):
    # 배열의 길이가 1 이하이면 그대로 반환 (기저 조건)
    if len(arr) <= 1:
        return arr
    
    # 피벗을 배열의 중간에 있는 요소로 선택
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들로 구성된 배열
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들로 구성된 배열
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들로 구성된 배열
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 배열을 정렬하고, 중간 배열과 함께 합침
    return quicksort(left) + middle + quicksort(right)

# 예제: 정렬할 배열
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵정렬 실행 및 결과 출력
sorted_arr = quicksort(arr)
print("정렬된 배열:", sorted_arr)
```

이 코드는 퀵정렬 알고리즘을 구현한 것으로, 다음과 같은 방식으로 작동합니다:

1. **기저 조건**: 배열의 길이가 1 이하라면 더 이상 정렬할 필요 없음.
2. **피벗 선택**: 배열의 중간 값으로 피벗을 설정.
3. **원소 분류**:
   - 피벗보다 작은 값: `left` 배열
   - 피벗과 같은 값: `middle` 배열
   - 피벗보다 큰 값: `right` 배열
4. **재귀 호출**: `left`, `middle`, `right`를 각각 정렬 후 결합.

예제 배열 `[3, 6, 8, 10, 1, 2, 1]`은 다음과 같이 정렬됩니다:
```
정렬된 배열: [1, 1, 2, 3, 6, 8, 10]
```
