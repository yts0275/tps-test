```python
# 퀵정렬(quick sort) 알고리즘을 구현하는 함수
def quicksort(arr):
    # 배열의 길이가 1 이하인 경우, 정렬할 필요 없음 -> 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)은 배열의 중간 인덱스에 있는 요소를 선택
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들로 이루어진 배열 (왼쪽 부분)
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들로 이루어진 배열 (중간 부분)
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들로 이루어진 배열 (오른쪽 부분)
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분을 정렬한 후, 중간 부분과 합침
    return quicksort(left) + middle + quicksort(right)

# 예제 실행: 정렬할 배열
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵정렬 수행 및 결과 출력
print("정렬 전:", arr)
sorted_arr = quicksort(arr)
print("정렬 후:", sorted_arr)
```

### 설명:
- 이 코드는 파이썬으로 **퀵정렬** 알고리즘을 구현한 것입니다.
- `quicksort` 함수는 재귀적으로 작동하며, 배열을 피벗을 기준으로 세 부분으로 나누고,
- 다시 그 부분들을 재귀적으로 정렬하여 최종적으로 전체 배열을 정렬합니다.
- 각 행에 해당하는 동작에 대해 주석을 달았습니다.
