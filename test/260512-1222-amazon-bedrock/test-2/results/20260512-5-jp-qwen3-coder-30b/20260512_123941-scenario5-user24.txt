물론입니다! 아래에 퀵정렬(QuickSort) 알고리즘을 파이썬으로 구현한 코드와 각 줄에 대한 주석을 설명해 드릴게요.

```python
# 피벗을 기준으로 배열을 분할하는 함수
def partition(arr, low, high):
    # 배열의 마지막 요소를 피벗으로 설정
    pivot = arr[high]
    
    # 작은 요소들을 배치할 인덱스를 초기화
    i = low - 1

    # 배열의 요소들을 순회하며 피벗과 비교함
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 요소를 i 위치로 이동시킴
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킴 (i+1 위치에 피벗을 놓음)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 위치한 인덱스를 반환
    return i + 1

# 퀵정렬 메인 함수
def quicksort(arr, low, high):
    # 재귀 호출의 기저 조건: low >= high이면 더 이상 정렬할 필요 없음
    if low < high:
        # 피벗을 기준으로 배열을 분할하고, 피벗의 인덱스를 얻음
        pi = partition(arr, low, high)

        # 피벗의 왼쪽 부분 배열에 대해 재귀적으로 퀵정렬 수행
        quicksort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분 배열에 대해 재귀적으로 퀵정렬 수행
        quicksort(arr, pi + 1, high)

# 정렬할 배열 예시
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)

# 퀵정렬 수행
quicksort(arr, 0, n - 1)

# 결과 출력
print("정렬된 배열:", arr)
```

### 간단한 설명:
- `partition()` 함수는 배열을 피벗을 기준으로 두 그룹으로 나누는 역할을 합니다.
- `quicksort()` 함수는 재귀적으로 배열을 분할하고 정렬합니다.
- 이 알고리즘은 평균적으로 O(n log n) 시간 복잡도를 가집니다.
