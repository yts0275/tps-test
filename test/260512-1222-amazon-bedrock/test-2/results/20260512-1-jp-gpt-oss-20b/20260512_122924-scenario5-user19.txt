아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 예제입니다.  
각 줄마다 Korean 주석을 달아 이해하기 쉽도록 했습니다.

```python
def quick_sort(arr):                               # 리스트에 0개 또는 1개 원소가 있으면 그대로 반환
    if len(arr) <= 1:                              # 리스트 길이가 1 이하이면 이미 정렬됨
        return arr                                  # 정렬된 리스트 반환
    _quick_sort_recursive(arr, 0, len(arr) - 1)    # 재귀적으로 정렬 시작

def _quick_sort_recursive(arr, low, high):         # 인덱스(low~high) 범위로 재귀 호출
    if low < high:                                 # low가 high보다 작을 때만 분할
        pivot_index = _partition(arr, low, high)   # 피벗 위치를 결정하고 배열 분할
        _quick_sort_recursive(arr, low, pivot_index - 1)   # 왼쪽 서브 배열 재귀 정렬
        _quick_sort_recursive(arr, pivot_index + 1, high)  # 오른쪽 서브 배열 재귀 정렬

def _partition(arr, low, high):                    # 피벗으로 배열을 분할
    pivot = arr[high]                              # 가장 오른쪽 원소를 피벗으로 고정
    i = low - 1                                    # 피벗보다 작은 요소를 저장할 위치(초기값은 low-1)
    for j in range(low, high):                     # i+1부터 high-1까지 순회
        if arr[j] <= pivot:                        # 현재 원소가 피벗 이하이면
            i += 1                                 # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]        # 현재 원소와 i번째 원소 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 정렬된 위치(i+1)로 옮김
    return i + 1                                    # 피벗의 최종 인덱스 반환

# ---- 사용 예시 -----------------------------------------------------------------
if __name__ == "__main__":                         # 직접 실행될 때만 실행
    data = [24, 2, 45, 20, 56, 75, 2]              # 정렬 대상 배열
    print("정렬 전:", data)                        # 정렬 전 상태 출력
    quick_sort(data)                               # 퀵소트 실행
    print("정렬 후:", data)                        # 정렬 후 상태 출력
```

#### 핵심 포인트
- `quick_sort()` 은 사용자가 호출하는 가장 외부 함수이며, 내부에서 재귀적으로   
`_quick_sort_recursive()` 를 호출합니다.
- `_partition()` 은 피벗을 기준으로 좌우 두 개의 부분 배열로 나누며, 계속해서   
피벗보다 작은 원소를 왼쪽에, 큰 원소를 오른쪽에 배치합니다.
- 재귀 호출이 완료되면 배열은 전부 정렬됩니다.
