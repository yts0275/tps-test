아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드의 각 줄마다 라인별로 한국어 주석을 달아 이해를 돕도록 했습니다.

```python
# 퀵소트 구현 예시
# 주어진 리스트를 오름차순으로 정렬합니다.
def quick_sort(arr, low, high):
    # 재귀 종료 조건: 배열이 2개 이하일 때
    if low < high:
        # 파티션 과정을 거쳐 피벗의 최종 위치를 찾습니다.
        pi = partition(arr, low, high)

        # 피벗 앞의 부분을 재귀적으로 정렬
        quick_sort(arr, low, pi - 1)
        # 피벗 뒤의 부분을 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high):
    # 가장 오른쪽 원소를 피벗으로 선택
    pivot = arr[high]
    # 'i'는 피벗보다 작은 원소가 존재할 인덱스를 추적
    i = low - 1

    # low ~ high-1까지 순회하면서
    for j in range(low, high):
        # 현재 원소가 피벗보다 작으면
        if arr[j] <= pivot:
            # i를 한 칸 이동시키고, j와 i+1 위치의 값을 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 마지막으로 피벗을 i+1 위치로 옮겨, 피벗 이전에는 모두 작거나 같음 보장
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗의 최종 인덱스를 반환
    return i + 1

# 사용 예시
if __name__ == "__main__":
    # 정렬할 리스트 정의
    numbers = [10, 7, 8, 9, 1, 5]
    # 퀵소트 함수 호출 (전체 범위 지정)
    quick_sort(numbers, 0, len(numbers) - 1)
    # 정렬된 리스트 출력
    print("정렬된 결과:", numbers)
```

**코드 설명**

1. `quick_sort` 함수는 재귀적으로 배열을 정렬합니다.  
2. `partition` 함수는 마지막 원소를 피벗으로 삼아 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽에 배치합니다.  
3. 피벗의 최종 인덱스를 반환받아, 그 구간을 두 개의 서브 구간(피벗 앞, 피벗 뒤)으로 나누어 다시 `quick_sort`를 호출합니다.  
4. `if __name__ == "__main__":` 블록을 통해 스크립트가 직접 실행될 때 예시 실행을 보여줍니다.

이 구현은 **in-place** 정렬이며 평균 시간복잡도는 O(n log n)입니다.  
필요에 맞게 리스트의 타입이나 정렬 방향(내림차순 등)을 조정할 수 있습니다.
