아래는 파이썬으로 구현한 **퀵소트**(QuickSort) 예제입니다.   
프로그램의 모든 줄에 한글 주석을 달아, 각 단계가 무엇을 하는지 쉽게 이해할 수 있도록 했습니다.  
(피벗을 배열의 가운데 원소로 고르고, 재귀적으로 정렬).  

```python
# ----------------------------- 1. 함수 정의 -----------------------------
def quick_sort(arr):                       # 1. 재귀적으로 호출되는 quick_sort 함수 정의
    if len(arr) <= 1:                     # 2. 배열 길이가 0 또는 1이면 이미 정렬 완료
        return arr                        # 3. 정렬된 배열(자기 자신)을 반환

    pivot = arr[len(arr)//2]              # 4. 피벗으로 중간 원소를 선택 (임의의 선택 가능)

    # 5. 피벗보다 작은 값들, 피벗과 같은 값들, 피벗보다 큰 값들로 3개의 하위 배열을 만든다
    left   = [x for x in arr if x < pivot]   # 6. 피벗보다 작은 값들을 수집
    middle = [x for x in arr if x == pivot]  # 7. 피벗과 같은 값들을 수집 (중복 허용)
    right  = [x for x in arr if x > pivot]   # 8. 피벗보다 큰 값들을 수집

    # 9. 재귀 호출로 정렬된 left, middle, right 를 합쳐서 최종 정렬된 배열 반환
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------------- 2. 실행 부분 -----------------------------
if __name__ == "__main__":               # 10. 모듈이 직접 실행될 때만 아래 코드 실행
    arr = [3, 6, 8, 10, 1, 2, 1]          # 11. 정렬 전 배열 정의
    print("원본 배열:", arr)            # 12. 원본 배열 출력
    sorted_arr = quick_sort(arr)          # 13. quick_sort 함수 호출
    print("정렬된 배열:", sorted_arr)    # 14. 정렬 후 배열 출력
```

### 해설
- **라인 1-3**: 재귀 함수의 기본 종료 조건. 길이가 1 이하인 배열은 이미 정렬이 완료된 상태이므로 그대로 반환합니다.  
- **라인 4**: 피벗을 배열의 가운데 요소로 고르며, 이는 평균적인 경우 좋은 선택이 됩니다(최악의 경우는 피벗이 가장 크거나 가장 작을 때).  
- **라인 6-8**: 리스트 컴프리헨션을 이용해 피벗보다 작거나 같은 세 그룹으로 나눕니다.  
- **라인 9**: `quick_sort`를 재귀적으로 호출하여 하위 배열을 정렬한 뒤, `+` 연산으로 다시 합칩니다.  
- **라인 10-14**: 함수가 직접 실행될 때 예시 배열을 정렬하고 결과를 출력합니다.

이 코드는 학습용으로 이해하기 쉽도록 구조를 단순화했으며, 실제 대용량 데이터 처리 시에는 매번 피벗을 중간값으로 고르는 대신 무작위 혹은 `median‑of‑3` 등의 전략을 적용해 최악의 경우를 방지할 수 있습니다.
