아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드의 **각 줄**마다 한국어 주석을 달아 이해를 돕겠습니다.  

```python
# 리스트를 제자리에서 오름차순 정렬하는 퀵소트 구현
# --------------------------------------------------------

def quick_sort(arr, low, high):
    # 재귀가 끝나는 조건: 정렬할 범위가 1개 이하이면 종료
    if low < high:
        # 배열을 두 파트(<= pivot, > pivot)로 분할하고, 파티션 인덱스를 반환
        pi = partition(arr, low, high)

        # 왼쪽 파트(해당 피벗보다 작은 부분) 정렬
        quick_sort(arr, low, pi - 1)

        # 오른쪽 파트(해당 피벗보다 큰 부분) 정렬
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high):
    # subarray arr[low..high] 에서 가장 오른쪽 원소를 피벗으로 선택
    pivot = arr[high]

    # i는 피벗보다 작거나 같은 원소가 있을 최종 위치를 추적
    i = low - 1

    # j는 low부터 high-1까지 순회하며 피벗보다 작거나 같은 요소를 찾아 i+1 위치에 넣음
    for j in range(low, high):
        if arr[j] <= pivot:      # 현재 원소가 피벗보다 작거나 같으면
            i += 1               # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # i와 j에 있는 원소를 스왑

    # i+1 위치에 피벗을 삽입 (i+1이 현재 피벗이 들어갈 최종 위치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 새로운 피벗 위치 반환
    return i + 1

# --------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬할 예시 리스트
    data = [29, 10, 14, 37, 13, 2, 43, 4, 5, 9]

    print("정렬 전:", data)

    # 퀵소트 호출 (전체 범위 지정)
    quick_sort(data, 0, len(data) - 1)

    print("정렬 후:", data)
```

### 코드 구성
1. **quick_sort**  
   재귀 함수로 리스트를 (피벗을 기준으로) 두 부분으로 분할하고 각각을 다시 정렬합니다.  
2. **partition**  
   피벗을 기준으로 배열을 두 파트(작음/큼) 로 나누며, 피벗이 최종적으로 올 위치를 찾습니다.  
3. **사용 예시**  
   `__main__` 부분에서 간단한 리스트를 정렬해 보여줍니다.  

각 줄에 있는 주석이 해당 줄의 기능을 한눈에 이해하도록 도와줍니다. 필요에 따라 매개변수 이름을 바꾸거나 중복 값을 허용/제한하는 등 변형이 가능합니다.
