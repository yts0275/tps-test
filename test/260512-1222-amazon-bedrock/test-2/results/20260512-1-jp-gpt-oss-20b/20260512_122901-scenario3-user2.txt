아래는 Python으로 구현한 **퀵소트(QuickSort)** 의 예시입니다.  
모든 코드 줄마다 한글 주석을 달아 동작을 단계별로 설명했습니다.  

```python
def quicksort(arr, low=0, high=None):  # quicksort 함수 정의(리스트 arr, 시작 인덱스 low, 끝 인덱스 high)
    if high is None:                  # high가 None이면 전체 배열의 마지막 인덱스를 설정
        high = len(arr) - 1           # 고유의 끝 인덱스를 계산
    if low < high:                    # low가 high보다 작을 때에만 정렬 수행
        pi = partition(arr, low, high)  # 배열을 피벗 기준으로 분할하고 피벗이 올바른 위치에 놓이는 인덱스 반환
        quicksort(arr, low, pi - 1)    # 피벗보다 작은 부분을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)   # 피벗보다 큰 부분을 재귀적으로 정렬

def partition(arr, low, high):       # partition 함수 정의(피벗을 기준으로 배열 재배치)
    pivot = arr[high]                # 피벗을 배열의 마지막 요소로 지정
    i = low - 1                      # i는 <= 피벗인 요소가 배치될 가장 오른쪽 인덱스를 가리킴
    for j in range(low, high):       # low부터 high-1까지 순회
        if arr[j] <= pivot:          # 요소가 피벗보다 작거나 같으면
            i += 1                   # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # i와 j에 있는 요소를 서로 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치에 삽입
    return i + 1                    # 피벗이 최종적으로 놓인 인덱스를 반환

if __name__ == "__main__":          # 스크립트가 직접 실행될 때만 아래 코드 실행
    arr = [10, 7, 8, 9, 1, 5]       # 정렬할 리스트 정의
    print("정렬 전 배열:", arr)     # 정렬 전 배열 출력
    quicksort(arr)                  # quicksort 함수를 호출해 배열 정렬
    print("정렬 후 배열:", arr)     # 정렬 후 배열 출력
```

위 코드가 동작하는 방식은 다음과 같습니다:  
1. `quicksort` 함수는 피벗을 기준으로 배열을 재배치한 뒤, 피벗보다 작은 부분과 큰 부분을 각각 재귀적으로 정렬합니다.  
2. `partition` 함수는 피벗을 마지막 원소로 잡고, 피벗보다 작은 값들을 왼쪽으로 모으고 피벗을 그 위치에 올려놓습니다.  
3. `if __name__ == "__main__":` 블록에서 테스트용 배열을 정렬하고 결과를 출력합니다.  

각 줄마다 한글 주석이 달려 있어, 초보자도 이해하기 쉽도록 구현되었습니다.
