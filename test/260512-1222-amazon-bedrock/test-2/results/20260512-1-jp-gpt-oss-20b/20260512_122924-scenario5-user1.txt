아래는 파이썬으로 구현한 **퀵소트(in‑place) 예시**입니다.  
코드의 각 줄마다 그 역할을 한 줄 주석으로 달아두었습니다.  

```python
# ------------------------------  퀵소트 구현  ------------------------------

def quicksort(arr):              # ① 정렬 함수 시작: 배열과 인덱스를 재귀적으로 정렬
    """
    배열 arr을 퀵소트로 정렬한 뒤, 정렬된 배열을 반환한다.
    내부에 재귀 순서와 partition(피벗 분할) 함수를 정의한다.
    """
    
    # ------------------------------ 내부 재귀 함수 ------------------------------
    def _quicksort(lo, hi):      # ② 재귀 함수 정의: 인덱스 lo~hi 범위를 정렬
        if lo < hi:               # ③ 범위가 1개 이하이면 더 정렬할 필요가 없음
            p = partition(arr, lo, hi)  # ④ 피벗(hi 위치) 기준으로 분할
            _quicksort(lo, p-1)         # ⑤ 피벗 왼쪽 부분을 재귀적으로 정렬
            _quicksort(p+1, hi)         # ⑥ 피벗 오른쪽 부분을 재귀적으로 정렬

    # ------------------------------ 파티션(피벗 분할) 함수 ------------------------------
    def partition(arr, lo, hi):   # ⑦ 파티션 함수 정의: 피벗 기준으로 요소 분할
        pivot = arr[hi]           # ⑧ 피벗을 가장 오른쪽 요소(hi)로 지정
        i = lo - 1                # ⑨ 작은 요소들을 모을 인덱스(i)는 범위 시작 전
        for j in range(lo, hi):   # ⑩ j = lo 부터 hi-1 까지 각각 검사
            if arr[j] <= pivot:   # ⑪ 현재 요소가 피벗보다 작거나 같으면
                i += 1            # ⑫ i 증가(작은 요소를 담을 위치 이동)
                arr[i], arr[j] = arr[j], arr[i]  # ⑬ 현재 요소와 i 위치의 값 스왑
        arr[i+1], arr[hi] = arr[hi], arr[i+1]  # ⑭ 피벗을 올바른 위치(i+1)로 이동
        return i+1                               # ⑮ 피벗 인덱스 반환

    # ------------------------------ 퀵소트 시작 ------------------------------
    _quicksort(0, len(arr)-1)                # ⑯ 전체 범위(0~len-1)를 정렬 시작
    return arr                                 # ⑰ 정렬된 배열 반환


# ------------------------------ 사용 예시 ------------------------------
if __name__ == "__main__":
    arr = [3, 6, 8, 10, 1, 2, 1]          # ① 테스트 배열
    print("정렬 전:", arr)               # ② 정렬 전 출력
    sorted_arr = quicksort(arr)           # ③ 퀵소트 함수 호출
    print("정렬 후:", sorted_arr)       # ④ 정렬 후 배열 출력
```

위 코드는 **임의의 배열**을 복사 없이 그대로 정렬합니다(**in-place**).  
각 줄마다 주석으로 코드가 수행하는 역할을 설명했으니 이해하시기에 도움이 되실 겁니다.  
필요에 따라 파이썬 출력을 실행해보면, `정렬 전`과 `정렬 후`가 차이 나는 것을 확인하실 수 있습니다.
