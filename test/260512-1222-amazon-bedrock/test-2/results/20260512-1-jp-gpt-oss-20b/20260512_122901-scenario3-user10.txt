```python
# 리스트를 재귀적으로 빠르게 정렬하는 퀵소트(Quick Sort) 구현
# (파이썬 표준 문법과 한 줄 주석을 포함한 예시)

def quick_sort(arr):
    # 리스트의 길이가 1 이하이면 이미 정렬이 끝난 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 가장 마지막 원소를 피벗(pivot)으로 선택
    pivot = arr[-1]

    # 피벗보다 작거나 같은 값들만 모아 새로운 리스트 형성 (left 서브 리스트)
    left = [x for x in arr[:-1] if x <= pivot]

    # 피벗보다 큰 값들만 모아 새로운 리스트 형성 (right 서브 리스트)
    right = [x for x in arr[:-1] if x > pivot]

    # 재귀적으로 정렬된 왼쪽 서브 리스트, 피벗, 정렬된 오른쪽 서브 리스트를 이어붙여 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# 사용 예시
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]
    print("원본 리스트:", sample)
    sorted_list = quick_sort(sample)
    print("정렬된 리스트:", sorted_list)
```

**주요 포인트 요약**

1. **피벗 선택** – 가장 끝 원소를 피벗으로 사용했지만, 다른 전략(중간값, 랜덤 값 등)도 가능하다.  
2. **리스트 컴프리헨션** – 피벗보다 작은/큰 값들을 한 줄에 걸쳐 분리한다.  
3. **재귀 호출** – 분할된 서브 리스트를 다시 `quick_sort` 로 정렬하며, 리스트 길이가 1 이하가 되면 재귀가 종료된다.  
4. **결합 단계** – 정렬된 `left`, `pivot`, `right` 를 **순서대로 붙여** 하나의 정렬된 리스트를 완성한다.  

이 구현은 **공간 복잡도**가 \(O(n)\) (새로운 리스트 생성)이며, 평균 **시간 복잡도**는 \(O(n \log n)\)이다. 인플레이스(in‑place) 버전에 대한 구현이 필요하면 알려주세요!
