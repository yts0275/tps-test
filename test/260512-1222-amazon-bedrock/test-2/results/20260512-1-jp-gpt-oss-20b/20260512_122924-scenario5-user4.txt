아래 예시는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄 끝에 한 줄 주석이 있습니다.  
원본 배열을 그대로 두고, 새로운 정렬된 배열을 반환하는 `quick_sort` 함수를 호출하면 됩니다.

```python
#!/usr/bin/env python3                     # 파이썬 실행 파일 경로 지정

def quick_sort(arr):                       # 정렬할 리스트를 인수로 받아 정렬된 리스트를 반환
    if len(arr) <= 1:                      # 리스트 길이가 0 또는 1이면 이미 정렬이 완료
        return arr                        # 정렬된 리스트(원본 그대로)를 반환
    pivot = arr[0]                        # 첫 번째 원소를 피봇(중앙값)으로 선택
    less = [x for x in arr[1:] if x <= pivot]     # 피봇보다 작거나 같은 값들 모음
    greater = [x for x in arr[1:] if x > pivot]   # 피봇보다 큰 값들 모음
    return quick_sort(less) + [pivot] + quick_sort(greater)   # 재귀 호출 후 결합

# ----------------- 사용 예시 -----------------
if __name__ == "__main__":               # 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [24, 2, 45, 20, 56, 75, 2]   # 예시 데이터 리스트
    print("정렬 전:", sample)            # 정렬 전 출력
    sorted_list = quick_sort(sample)       # 퀵소트 함수 호출
    print("정렬 후:", sorted_list)        # 정렬 후 출력
```

### 주요 설명
1. **기초 조건**  
   재귀 호출이 끝나도록 `len(arr) <= 1` 인 경우 바로 반환합니다.

2. **피봇 선택**  
   가장 간단히 배열의 첫 번째 원소를 피봇으로 사용합니다.  
   다른 알고리즘에서는 중간값이나 랜덤값을 선택하지만, 여기서는 구현 단순화를 위해 첫 번째 원소를 사용했습니다.

3. **분할**  
   리스트 컴프리헨션으로 피봇보다 작거나 같은 값들과 큰 값들을 두 개의 리스트 `less` 와 `greater` 로 분리합니다.  
   피봇 자체는 중간에 놓이게 됩니다.

4. **재귀 호출 & 결합**  
   `quick_sort` 를 각각 `less` 와 `greater` 에 재귀적으로 적용한 뒤,  
   정렬된 `less` 리스트 ⟶ `{pivot}` ⟶ 정렬된 `greater` 리스트 순서로 합칩니다.

5. **사용 예시**  
   `__name__ == "__main__"` 블록 안에 간단한 테스트 코드를 넣어 스크립트가 직접 실행될 때만 동작하도록 했습니다.

이 코드는 **O(n log n)** 평균 시간복잡도와 **O(log n)** 스택 공간복잡도를 가집니다(트리 구조는 균형을 이룰 때).  
피봇 선택을 개선하거나 데이터가 이미 정렬된 경우를 처리하려면 피봇을 중간값으로 바꾸거나 랜덤한 인덱스를 선택하면 좋습니다.
