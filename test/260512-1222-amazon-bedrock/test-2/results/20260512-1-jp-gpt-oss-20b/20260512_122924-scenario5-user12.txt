아래는 파이썬으로 구현한 퀵소트(QuickSort) 알고리즘이며, **각 코드 라인마다 주석**을 달아 이해가 쉽도록 구성했습니다.  

```python
def quicksort(arr):  # 정렬하고자 하는 리스트를 인자로 받는 함수 정의
    if len(arr) <= 1:  # 리스트의 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
        return arr  # 원본 리스트를 반환
    pivot = arr[len(arr) // 2]  # 리스트의 가운데 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 값들만 모은 리스트
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 값들만 모은 리스트
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 값들만 모은 리스트
    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 정렬한 결과를 합쳐서 반환

# 아래 코드는 예시를 보여주기 위한 것이며, 실제 환경에서는 필요에 따라 사용하면 됩니다.
if __name__ == "__main__":  # 이 스크립트가 직접 실행될 때만 아래 코드를 실행
    data = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예시 리스트
    sorted_data = quicksort(data)  # quicksort 함수 호출
    print(sorted_data)  # 정렬된 결과를 출력
```

**설명**  
- `quicksort` 함수는 재귀적으로 남은 부분을 다시 정렬합니다.  
- 피벗을 가운데 값으로 잡았기에 평균적인 경우 실행 시간은 **O(n log n)** 이지만 최악의 경우 **O(n²)** 가 됩니다.  
- `left`, `middle`, `right` 세 리스트를 만들어 재귀 호출을 통해 정렬을 수행하고, 마지막에 이들을 합쳐 최종 정렬 결과를 만듭니다.
