아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 예시입니다.  
코드의 각 줄마다 **주석**을 넣어 기능을 설명했습니다.  

```python
def quick_sort(arr, low, high):
    """
    In‑place Quick Sort

    Parameters
    ----------
    arr   : list[int]  # 정렬할 배열
    low   : int        # 배열의 시작 인덱스
    high  : int        # 배열의 끝 인덱스
    """
    # 1. base case: low == high 혹은 범위가 넓지 않을 때는 리턴
    if low >= high:
        return
    
    # 2. pivot 을 선택 (이 예시에서는 가장 마지막 원소를 pivot 으로 사용)
    pivot = arr[high]
    
    # 3. partition 과정을 실행하여 pivot 의 최종 위치 (pivot_index)를 구함
    pivot_index = partition(arr, low, high, pivot)
    
    # 4. pivot 앞과 뒤를 재귀적으로 정렬
    quick_sort(arr, low, pivot_index - 1)      # pivot 왼쪽 부분 정렬
    quick_sort(arr, pivot_index + 1, high)     # pivot 오른쪽 부분 정렬


def partition(arr, low, high, pivot):
    """
    주어진 pivot 을 기준으로 배열을 partition 하는 함수

    Returns
    -------
    pivot_index : int
        pivot 가 최종적으로 놓일 인덱스
    """
    # i 라는 인덱스를 pivot 보다 작은 값들 바로 다음 위치에 두고 시작
    i = low - 1  
    
    # j 를 low 부터 high-1 까지 돌면서 pivot 보다 작은 요소와 교환
    for j in range(low, high):
        if arr[j] <= pivot:          # 현재 원소가 pivot 보다 작거나 같으면
            i += 1                    # i 를 하나 올려 한 칸 남긴 뒤
            arr[i], arr[j] = arr[j], arr[i]   # 두 원소를 교환
    
    # 마지막에 pivot 을 올바른 위치 (i+1)에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                       # pivot 의 인덱스 반환


# ---------- 사용 예시 ----------
if __name__ == "__main__":
    # 예시 배열
    arr = [10, 7, 8, 9, 1, 5]
    print("정렬 전:", arr)
    
    # quick_sort 호출 (전체 배열 범위 지정)
    quick_sort(arr, 0, len(arr) - 1)
    
    print("정렬 후 :", arr)
```

### 코드 설명  
1. **`quick_sort` 함수**  
   - `low`와 `high`를 이용해 정렬 범위를 매개변수화.  
   - 재귀적 호출을 통해 배열을 정렬.  
2. **`partition` 함수**  
   - 현재 구간에서 pivot 이하의 원소를 왼쪽에, 그보다 큰 원소를 오른쪽에 두도록 배열을 재배치.  
   - 최종적으로 pivot이 오게 될 인덱스를 반환.  
3. **`if __name__ == "__main__":`**  
   - 스크립트가 독립 실행될 때만 동작하도록 하는 구문.  

이 구현은 **in‑place** 정렬이며 평균적으로 O(n log n)의 시간 복잡도를 가집니다. (최악의 경우 O(n²) – 예: 이미 정렬된 배열에서 가장 작은/가장 큰 원소를 pivot 으로 선택할 때).  필요하면 pivot 선택 방식을 랜덤화하거나 median‑of‑three 기법을 추가해 성능을 안정화할 수 있습니다.
