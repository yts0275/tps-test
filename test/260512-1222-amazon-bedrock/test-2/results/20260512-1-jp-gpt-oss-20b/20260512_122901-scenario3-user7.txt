아래는 **Python** 으로 구현한 퀵소트(QuickSort) 예제입니다.  
코드의 각 줄 옆에 그 줄이 수행하는 작업을 한글 주석으로 설명했습니다.

```python
def quicksort(arr):  # 1. 정렬을 수행할 함수 정의
    if len(arr) <= 1:  # 2. 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
        return arr  # 3. 정렬된 리스트(또는 바로 전달받은 리스트)를 반환

    pivot = arr[-1]  # 4. 피벗 값으로 배열의 마지막 원소를 선택
    left = []  # 5. 피벗보다 작은 값을 모을 리스트
    right = []  # 6. 피벗보다 큰 값을 모을 리스트

    for x in arr[:-1]:  # 7. 피벗을 제외한 모든 원소를 순회
        if x <= pivot:  # 8. 현재 원소가 피벗보다 작거나 같은 경우
            left.append(x)  # 9. left 리스트에 추가
        else:  # 10. 현재 원소가 피벗보다 큰 경우
            right.append(x)  # 11. right 리스트에 추가

    # 12. left 와 right 를 재귀적으로 정렬한 뒤 피벗을 가운데에 삽입해 반환
    return quicksort(left) + [pivot] + quicksort(right)

# 아래 부분은 직접 실행했을 때 사용할 예시 코드입니다
if __name__ == "__main__":  # 13. 스크립트가 직접 실행될 때만 아래 코드 실행
    data = [3, 6, 8, 10, 1, 2, 1]  # 14. 예시 입력 리스트
    sorted_data = quicksort(data)  # 15. 퀵소트 실행
    print(sorted_data)  # 16. 정렬 결과 출력
```

> **핵심 요약**  
> * 한 줄마다 주석을 달아 코드를 읽는 사람이 각 줄이 수행하는 역할을 바로 이해할 수 있도록 했습니다.  
> * `quicksort` 함수는 불변 방식을 사용하여 새 리스트를 만들어 반환합니다. (공간복잡도는 O(n) 입니다.)  
> * 재귀 호출을 통해 왼쪽, 오른쪽 부분 배열을 반복적으로 정렬합니다.  
> * `if __name__ == "__main__":` 블록은 모듈이 직접 실행될 때 테스트용 샘플을 실행하도록 합니다.  

필요에 따라 인-place(자리 내) 퀵소트 버전을 만들거나 피벗 선택 방식을 바꾸어 최적화할 수 있습니다. 즐거운 코딩 되세요!
