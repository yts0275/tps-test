아래는 파이썬으로 구현한 **퀵소트** 예제입니다.  
모든 코드 라인마다 주석을 달았습니다.

```python
def quicksort(arr):  # quicksort 함수 정의: 입력 배열을 인자로 받는다
    if len(arr) <= 1:  # 배열 길이가 1 이하이면 이미 정렬된 것이므로 그대로 반환한다
        return arr  # 정렬된 배열을 반환한다
    pivot = arr[len(arr) // 2]  # 배열의 중간값을 피벗으로 선택한다
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 원소들만 모은 리스트
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 값들을 모은 리스트
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들만 모은 리스트
    return quicksort(left) + middle + quicksort(right)  # 재귀 호출로 정렬 후 결합


if __name__ == "__main__":  # 실행 입구: 스크립트가 바로 실행될 때 아래 코드를 수행한다
    array = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 정수 배열 정의
    print("원본 배열:", array)  # 원본 배열 출력
    sorted_array = quicksort(array)  # quicksort 함수 호출로 정렬 수행
    print("정렬된 배열:", sorted_array)  # 정렬된 배열 출력
```

**출력 예시**

```
원본 배열: [3, 6, 8, 10, 1, 2, 1]
정렬된 배열: [1, 1, 2, 3, 6, 8, 10]
```
