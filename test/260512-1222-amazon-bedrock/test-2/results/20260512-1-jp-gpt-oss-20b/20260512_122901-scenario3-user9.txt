아래는 파이썬으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
**각 실행되는 줄마다** 한 줄의 주석을 달아, 코드가 무엇을 하고 있는지 자세히 설명했습니다.

```python
def quicksort(arr):                               # 1️⃣ 함수 정의: 입력 리스트 arr 을 정렬해 새 리스트를 반환
    if len(arr) <= 1:                              # 2️⃣ 기준: 리스트가 0개 혹은 1개이면 이미 정렬된 상태임
        return arr                                # 3️⃣ 정렬이 필요 없는 리스트를 그대로 반환

    pivot = arr[0]                                 # 4️⃣ 피벗 선택: 가장 간단히 첫 번째 원소를 피벗으로 사용
    less = [x for x in arr[1:] if x < pivot]       # 5️⃣ 피벗보다 작은 값들을 모은 리스트 생성
    greater = [x for x in arr[1:] if x >= pivot]   # 6️⃣ 피벗보다 크거나 같은 값들을 모은 리스트 생성

    return quicksort(less) + [pivot] + quicksort(greater)  # 7️⃣ 재귀 호출: less 와 greater 를 각각 정렬 후 
                                                             # 8️⃣ 피벗을 중간에 놓고 합친 결과를 반환

# 예시 사용법
if __name__ == "__main__":                        # 9️⃣ 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [38, 27, 43, 3, 9, 82, 10]           # 10️⃣ 테스트할 정수 리스트 생성
    sorted_sample = quicksort(sample)             # 11️⃣ 퀵소트 호출
    print("정렬 전:", sample)                    # 12️⃣ 원본 리스트 출력
    print("정렬 후:", sorted_sample)            # 13️⃣ 정렬된 리스트 출력
```

### 코드 설명

1. `quicksort` 함수는 재귀적으로 리스트를 정렬합니다.  
2. 리스트의 길이가 1 이하이면 정렬이 필요 없으므로 그대로 반환합니다.  
3. 피벗은 리스트의 첫 번째 요소를 선택했습니다(임의의 선택도 가능).  
4. 파이썬 리스트 컴프리헨션을 이용해 피벗보다 작은/큰 값들을 분리합니다.  
5. 이미 정렬된 두 리스트(less, greater)를 재귀적으로 정렬한 뒤, 피벗을 중간에 삽입해 최종 배열을 만듭니다.  
6. `if __name__ == "__main__":` 블록은 모듈로서 사용될 때는 실행되지 않고, 독립 실행 시 예시를 보여줍니다.
