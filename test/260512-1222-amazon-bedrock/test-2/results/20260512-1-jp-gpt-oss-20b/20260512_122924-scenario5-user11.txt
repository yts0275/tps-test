아래는 파이썬으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
코드의 **모든 줄**에 주석을 달아 이해를 돕겠습니다.

```python
def quicksort(arr):  # 퀵소트 함수 정의: 입력 리스트 arr을 정렬해서 반환
    if len(arr) <= 1:  # 리스트가 0개 또는 1개 원소만 있을 때는 이미 정렬 완료
        return arr  # 그대로 반환
    pivot = arr[-1]  # 가장 마지막 원소를 피벗(pivot)으로 선택
    left = [x for x in arr[:-1] if x <= pivot]  # 피벗 이하(<=)의 원소들을 모음
    right = [x for x in arr[:-1] if x > pivot]   # 피벗 초과(>)의 원소들을 모음
    return quicksort(left) + [pivot] + quicksort(right)  # 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":  # 직접 실행될 때만 동작하도록 메인 블록
    data = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예시 데이터
    sorted_data = quicksort(data)  # 퀵소트 실행
    print(sorted_data)  # 정렬 결과 출력
```

📝 **핵심 내용 정리**

1. **피벗 선택**  
   - 가장 간단히 마지막 원소를 피벗으로 사용했습니다. (다른 전략이 가능)

2. **분할**  
   - 리스트 컴프리헨션으로 피벗 보다 작거나 같은 요소(`left`)와 큰 요소(`right`)를 나눕니다.

3. **재귀**  
   - `left`와 `right` 각각을 재귀적으로 정렬하고,  
     `left + [pivot] + right` 형태로 합쳐 최종 정렬된 리스트를 반환합니다.

필요에 따라 피벗을 더 효율적인 위치(예: 중간값, 무작위 선택 등)로 바꾸거나, 인플레이스(공간복잡도 O(1)) 버전으로 구현할 수도 있습니다. 좋은 코딩 실습이 되었으면 좋겠습니다!
