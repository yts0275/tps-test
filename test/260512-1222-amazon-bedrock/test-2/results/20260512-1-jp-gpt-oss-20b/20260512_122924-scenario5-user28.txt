아래는 **Python**으로 구현한 퀵소트(QuickSort) 예제입니다.  
코드의 각 줄마다 “# …” 으로 주석을 달아 동작을 설명했습니다.

```python
# ① 딕셔너리 사용을 방지하고, 가독성을 위해 라이브러리 임포트 없음

def quicksort(arr):
    """
    ②   quicksort 함수는 주어진 리스트를 재귀적으로 정렬해 새로운 리스트를 반환한다.
    """
    # ③  리스트가 0개 또는 1개면 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:          # ④  리스트 길이 <= 1 (비교 연산)
        return arr              # ⑤  원본 리스트를 그대로 반환

    # ⑥  피벗(pivot)은 첫 번째 원소를 선택
    pivot = arr[0]              # ⑦  pivot 에는 파이썬 리스트 arr 의 0번째 값 저장

    # ⑧  피벗보다 작은 요소들을 모은 리스트 생성
    less = [x for x in arr[1:] if x < pivot]   # ⑨  리스트 컴프리헨션 + 조건문
    # ⑩ 피벗과 같은 값들을 모은 리스트 생성
    equal = [x for x in arr[1:] if x == pivot] # ⑪  피벗과 같은 값들
    # ⑫ 피벗보다 큰 요소들을 모은 리스트 생성
    greater = [x for x in arr[1:] if x > pivot]# ⑬  피벗보다 큰 값들

    # ⑭  재귀적으로 소 리스트들을 정렬하고,
    # ⑮  정렬된 `less` + `pivot` + `equal` + `greater` 순으로 합친 새로운 리스트 반환
    return quicksort(less) + [pivot] + equal + quicksort(greater)


# --------------------------------------------------------------------
# 아래 코드 블록은 예시 실행용이다. 
# 실제 프로그램에서 필요에 따라 주석처리하거나 삭제 가능.
# --------------------------------------------------------------------

if __name__ == "__main__":               # ⑯  스크립트가 직접 실행될 때만 아래 코드를 실행
    arr = [33, 10, 55, 71, 29, 3, 18]   # ⑰  정렬할 예시 리스트
    print("원본:", arr)                  # ⑱  원본 출력
    sorted_arr = quicksort(arr)          # ⑲  퀵소트 호출
    print("정렬 후:", sorted_arr)        # ⑳  정렬 결과 출력
```

### 동작 요약
1. 리스트 길이가 0 혹은 1이면 그대로 반환 (정렬 필요 없음).
2. 첫 번째 요소를 **피벗** 으로 선택.
3. 피벗보다 작은 값, 같은 값, 큰 값을 각각 다른 리스트에 모음.
4. `less` 와 `greater` 를 재귀적으로 정렬.
5. 정렬된 `less`, 피벗, `equal`, `greater` 를 순서대로 합쳐서 반환.

이 구현은 **배열 복사**가 필요하므로 추가 메모리 소비가 있지만, 코드를 이해하기 쉽습니다.  
필요하다면 인덱스를 그대로 사용해 **in‑place** 버전으로 바꿀 수도 있습니다.
