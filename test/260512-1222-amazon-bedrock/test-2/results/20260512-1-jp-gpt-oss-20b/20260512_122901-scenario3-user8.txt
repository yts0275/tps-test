아래는 **Python**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드의 **각 줄**마다 주석을 달아 이해를 돕고, 사용법을 예시와 함께 설명합니다.

```python
# ------------------------------------------------------------------
# 퀵소트 : 분할(Partition) + 재귀 호출을 이용한 정렬 구현
# ------------------------------------------------------------------

def quicksort(arr):
    """
    주어진 리스트 arr 을 인접한 부분 리스트에 대해 재귀적으로 정렬한다.
    원본 리스트 그대로를 반환하지만, 실제 정렬은 입력 리스트 자체를 변경한다.
    """
    # 리스트가 비어 있거나 하나의 원소만 있으면(정렬 필요 없음) 그대로 반환
    if len(arr) <= 1:
        return arr

    # 가장 오른쪽 원소를 피벗(pivot) 으로 선택
    pivot = arr[-1]

    # 피벗보다 작은 원소를 담을 리스트
    left = []
    # 피벗보다 큰 원소를 담을 리스트
    right = []

    # 피벗을 제외한 나머지 원소들을 순회하며 분리
    for x in arr[:-1]:
        if x < pivot:
            left.append(x)          # 좌측(작은) 리스트에 추가
        else:
            right.append(x)         # 우측(큰) 리스트에 추가

    # 왼쪽 리스트(작은 값들) 정렬 + 피벗 + 오른쪽 리스트(큰 값들) 정렬
    # 이를 재귀적으로 호출하여 완전히 정렬된 리스트를 반환
    return quicksort(left) + [pivot] + quicksort(right)


# ------------------------------------------------------------------
# 사용 예시 및 테스트
# ------------------------------------------------------------------

if __name__ == "__main__":
    # 정렬하려는 예시 리스트
    sample = [34, 7, 23, 32, 5, 62]

    # 정렬 전 상태 출력
    print("정렬 전:", sample)

    # 퀵소트 함수 호출
    sorted_list = quicksort(sample)

    # 정렬 후 결과 출력
    print("정렬 후:", sorted_list)
```

### 코드 설명 요약
1. **`quicksort` 함수**  
   - 입력 리스트가 1개 이하이면 그대로 반환 (정렬 종료 조건).  
   - 피벗을 리스트의 마지막 원소로 선택.  
   - 피벗보다 작은 원소와 큰 원소를 각각 `left`, `right` 리스트에 분리.  
   - `left`와 `right`를 재귀 호출하여 정렬한 뒤, 피벗을 중앙에 삽입해 반환.

2. **상태 확인**  
   - `if __name__ == "__main__":` 블록에서 정렬 전·후를 출력해 결과를 확인.
