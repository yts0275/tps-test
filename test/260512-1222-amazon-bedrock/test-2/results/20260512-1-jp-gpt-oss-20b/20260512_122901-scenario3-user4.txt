```python
def quicksort(arr):                                      # 1. 배열을 정렬하기 위한 재귀 함수 정의
    if len(arr) <= 1:                                    # 2. 배열이 0개 또는 1개라면 이미 정렬된 상태
        return arr                                      # 3. 정렬된 배열을 그대로 반환
    else:                                                # 4. 그렇지 않은 경우, 피벗을 선택하고 재귀 호출 수행
        pivot = arr[len(arr) // 2]                       # 5. 피벗을 배열의 중간 원소로 선택
        left = [x for x in arr if x < pivot]              # 6. 피벗보다 작은 원소들로 구성된 리스트 생성
        middle = [x for x in arr if x == pivot]           # 7. 피벗과 같은 원소들로 구성된 리스트 생성
        right = [x for x in arr if x > pivot]             # 8. 피벗보다 큰 원소들로 구성된 리스트 생성
        return quicksort(left) + middle + quicksort(right)  # 9. 재귀적으로 정렬된 리스트를 합쳐 반환
```

### 사용 예시
```python
unsorted = [23, 1, 45, 34, 7, 8, 12, 0, 99]          # 10. 정렬할 원본 배열 정의
sorted_arr = quicksort(unsorted)                      # 11. quicksort 함수 호출
print(sorted_arr)                                     # 12. 정렬 결과 출력
```

위 코드는 파이썬으로 구현한 퀵소트이며, 모든 비공백 행에 주석이 달려 있습니다. 필요에 따라 인덱스를 이용한 in‑place 버전을 추가로 작성할 수도 있습니다.
