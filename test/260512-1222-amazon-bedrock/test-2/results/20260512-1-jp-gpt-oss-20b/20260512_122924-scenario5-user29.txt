아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
주석은 **각 코드 라인마다** 달아 이해하기 쉽게 구성했습니다.  
(배열이 길어질수록 재귀 호출 깊이가 증가하므로, 필요하면 `sys.setrecursionlimit()` 로 제한을 늘려 주세요.)

```python
# ----- 퀵소트 구현 (파이썬) -----

def quick_sort(arr):
    """
    주어진 리스트 arr 을 부호 없이 오름차순으로 정렬해 반환합니다.
    원본 리스트는 그대로 두지 않으므로 Copy 를 사용해도 됩니다.
    """
    # 1. 길이가 0 또는 1인 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr          # 정렬할 필요가 없습니다.

    # 2. 기준값(pivot)을 리스트의 마지막 원소로 선택
    pivot = arr[-1]        # 마지막 원소를 pivot 으로 삼음

    # 3. pivot 보다 작은 원소들 (left), 큰 원소들 (right) 로 분리
    left = [x for x in arr[:-1] if x <= pivot]   # pivot <= 가 포함되서 안정적
    right = [x for x in arr[:-1] if x > pivot]   # pivot 보다 큰 것들

    # 4. 재귀적으로 왼쪽, 오른쪽 부분을 정렬 후 합치기
    #    정렬합니다. 마지막에 pivot 을 삽입하고, 오른쪽을 이어붙입니다.
    return quick_sort(left) + [pivot] + quick_sort(right)

# ----- 예시 사용 ---------------------------------------------------

if __name__ == "__main__":
    # 예시 배열
    sample = [10, 7, 8, 9, 1, 5]
    print("원본 배열:", sample)

    # 퀵소트 호출
    sorted_list = quick_sort(sample)
    print("정렬된 배열:", sorted_list)
```

### 코드 라인별 해석

| 라인 | 코드 | 주석 (설명) |
|------|------|-------------|
| `def quick_sort(arr):` | 함수 정의 | - |
| `if len(arr) <= 1:` | 길이 체크 | 작은 리스트는 이미 정렬 |
| `return arr` | 반환 | 정렬이 필요 없음 |
| `pivot = arr[-1]` | 피벗 선택 | 리스트 마지막 원소 사용 |
| `left = [x for x in arr[:-1] if x <= pivot]` | 파이프 분할 | 피벗 이하 요소 모음 |
| `right = [x for x in arr[:-1] if x > pivot]` | 파이프 분할 | 피벗 초과 요소 모음 |
| `return quick_sort(left) + [pivot] + quick_sort(right)` | 재귀 합치기 | 정렬된 결과 반환 |
| `if __name__ == "__main__":` | 테스트 용 | 스크립트 직접 실행 시 |
| `sample = [10, 7, 8, 9, 1, 5]` | 테스트 데이터 | 예제용 |
| `print("원본 배열:", sample)` | 출력 | 입력 확인 |
| `sorted_list = quick_sort(sample)` | 실행 | 함수 호출 |
| `print("정렬된 배열:", sorted_list)` | 출력 | 결과 확인 |

> **주의**  
> *파이썬 기본 재귀 깊이는 1000으로 제한됩니다.*  
> 큰 입력에 대해 재귀가 너무 깊어지는 경우 `sys.setrecursionlimit()` 로 깊이를 늘리거나, **분할 정복** 대신 **루프 기반** 구현을 고려하십시오.  

이어서 `quick_sort` 로 정렬을 할 때는 `sample.sort()` 대신 직접 작성한 함수를 호출해 테스트하면 좋습니다. 필요에 따라 **피벗**을 더 합리적으로 선택(예: 정렬된 리스트 중에서 `random.choice` 등)하면 평균 성능이 𝑂(n log n) 정도로 우수합니다.
