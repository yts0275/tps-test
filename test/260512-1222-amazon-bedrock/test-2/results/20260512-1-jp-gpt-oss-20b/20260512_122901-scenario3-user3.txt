아래는 **Python** 으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
코드의 **각 줄마다** 주석을 달아 이해하기 쉽도록 구성했습니다.  

```python
def quick_sort(arr, low, high):
    """
    재귀적으로 배열을 정렬하는 퀵소트 함수.
    :param arr: 정렬 대상 리스트
    :param low: 정렬할 구간의 시작 인덱스
    :param high: 정렬할 구간의 끝 인덱스
    """
    # 구간이 1 이하이면 이미 정렬된 상태이므로 바로 반환
    if low < high:
        # 피벗을 기준으로 배열을 나누는 파티션 함수 호출
        pivot_index = partition(arr, low, high)

        # 피벗보다 작은 부분과 큰 부분을 각각 재귀 호출
        quick_sort(arr, low, pivot_index - 1)   # 피벗 왼쪽 구간 정렬
        quick_sort(arr, pivot_index + 1, high)  # 피벗 오른쪽 구간 정렬


def partition(arr, low, high):
    """
    피벗을 기준으로 배열을 두 부분으로 분할하는 함수.
    피벗보다 작은 값은 왼쪽에, 큰 값은 오른쪽에 배치.
    :param arr: 정렬 대상 리스트
    :param low: 구간 시작 인덱스
    :param high: 구간 끝 인덱스
    :return: 피벗의 최종 인덱스
    """
    # 마지막 원소를 피벗으로 선택
    pivot = arr[high]

    # i는 피벗보다 작은 원소의 가장 오른쪽 인덱스를 가리키는 변수
    i = low - 1

    # low 부터 high-1 까지 순회하면서 피벗보다 작은 원소를 찾음
    for j in range(low, high):
        if arr[j] <= pivot:
            # 피벗보다 작은 원소가 발견되면 i를 한 칸 오른쪽으로 이동
            i += 1
            # i와 j 위치의 원소를 교환
            arr[i], arr[j] = arr[j], arr[i]

    # 마지막에 피벗을 올바른 위치(모든 작은 원소 뒤)로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 놓인 인덱스를 반환
    return i + 1


# -------------------- 사용 예시 --------------------
if __name__ == "__main__":
    # 예시 배열
    data = [10, 7, 8, 9, 1, 5]

    # 배열의 길이를 기준으로 전체 구간을 지정 (0부터 len-1)
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과 출력
    print("정렬된 배열:", data)
```

### 동작 원리 요약
1. **피벗 선택** – 현재 구간의 마지막 원소를 피벗으로 정한다.  
2. **파티션** – 피벗보다 작은 원소들은 오른쪽으로 모으고, 피벗을 적절한 위치로 옮긴다.  
3. **재귀 호출** – 피벗을 기준으로 생성된 두 개의 서브 배열에 대해 동일 과정을 재귀적으로 수행한다.  
4. **종료 조건** – 구간이 1 이하가 되면 재귀를 종료한다.  

위 코드를 그대로 실행하면 대부분의 경우 `quick_sort`가 정수 리스트를 **오름차순**으로 정렬해 줍니다. 필요에 따라 `partition`에서 피벗을 다른 위치(예: 평균값, 중앙 값 등)로 바꿔서 최적화할 수도 있습니다.
