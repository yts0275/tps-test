아래는 **Python** 으로 작성한 퀵소트(Quick Sort) 구현 예시입니다.  
각 줄마다 신중히 해석된 주석(한국어) 를 달아 이해가 쉽도록 했습니다.

```python
def quicksort(arr):                                       # 1. 재귀 함수 정의: 배열(리스트)를 정렬해 반환
    if len(arr) <= 1:                                     # 2. 리스트의 길이가 0 또는 1이면 이미 정렬 완료
        return arr                                      # 3. 원래 배열 그대로 반환

    pivot = arr[-1]                                      # 4. 기준값(피벗) 선택: 마지막 원소

    left = [x for x in arr[:-1] if x <= pivot]          # 5. 피벗보다 작거나 같은 값들만 모은 서브 리스트
    right = [x for x in arr[:-1] if x > pivot]           # 6. 피벗보다 큰 값들만 모은 서브 리스트

    return quicksort(left) + [pivot] + quicksort(right)  # 7. 재귀 호출로 정렬한 뒤, left, pivot, right 순으로 결합
```

### 사용 예시
```python
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", data)
    sorted_data = quicksort(data)
    print("정렬 후:", sorted_data)
```

위 예시를 실행하면  
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**주요 포인트**

- 퀵소트의 핵심은 `pivot`(피벗) 값을 기준으로 `left`/`right` 두 개의 서브리스트를 만들어 재귀적으로 정렬하는 것입니다.  
- 위 구현에서는 피벗이 마지막 원소이지만, 실제 알고리즘에서는 중간값, 랜덤값 등을 사용해 성능을 최적화할 수 있습니다.  
- 재귀 호출 시 리스트를 복사(`arr[:-1]`)하므로 공간 복잡도는 O(n^2) 의 최악이 발생할 수 있으니, 대규모 데이터에서는 인덱스 기반 구현이 더 효율적입니다.  

이제 원하는 배열을 `quicksort()`에 전달하면 바로 정렬 결과를 얻을 수 있습니다. Happy coding!
