아래는 파이썬으로 구현한 퀵소트(QuickSort) 예시이며, **각 줄마다** 주석을 달아 이해하기 쉽도록 설명했습니다.

```python
def quicksort(arr):                     # 정렬할 리스트를 인자로 받는다.
    if len(arr) <= 1:                   # 길이가 0이나 1인 경우에는 이미 정렬 완료
        return arr                     # 그대로 반환한다.
    
    pivot = arr[len(arr) // 2]          # 리스트의 중간 원소를 피벗(Pivot)으로 선택
    left = [x for x in arr if x < pivot]          # 피벗보다 작은 원소들로 새로운 리스트 생성
    middle = [x for x in arr if x == pivot]       # 피벗과 같은 원소들로 새로운 리스트 생성
    right = [x for x in arr if x > pivot]           # 피벗보다 큰 원소들로 새로운 리스트 생성
    
    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 정렬 후 합친다.

# ---------- 메인 프로그램 ----------
if __name__ == "__main__":          # 스크립트가 직접 실행될 때만 아래 코드를 실행
    sample = [3, 6, 8, 10, 1, 2, 1] # 테스트할 예시 리스트
    print("원본: ", sample)          # 원본 리스트 출력
    print("정렬: ", quicksort(sample))  # 퀵소트 실행 결과 출력
```

**주요 포인트 설명**

1. **피벗 선택**  
   - 보통 리스트의 중간 원소를 피벗으로 선택하면 평균/최신 상황에서 좋은 성능을 낼 수 있음.  
   - 다른 전략으로는 랜덤 피벗을 선택해 최악의 경우를 방지할 수 있음.

2. **분할**  
   - 피벗보다 작은 것(`left`), 같은 것(`middle`), 큰 것(`right`)으로 분리  
   - 파이썬의 리스트 컴프리헨션을 이용해 한 줄로 구현

3. **재귀**  
   - `left`와 `right`를 다시 `quicksort`에 전달해 재귀 호출  
   - Base Case는 `len(arr) <= 1` 이므로 재귀 깊이가 깊어지지 않음

4. **결합**  
   - 정렬된 `left`, `middle`, `right` 를 순서대로 합쳐 하나의 정렬된 리스트 반환

이 코드를 그대로 실행해 보시면 퀵소트가 제대로 동작하는 것을 확인하실 수 있습니다!
