아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘입니다.  
모든 코드 한 줄마다 한 줄의 주석(한국어)을 달아 이해하기 쉽도록 했습니다.  
이 코드는 입력 리스트를 **제자리(in‑place)**로 정렬합니다.

```python
def quicksort(arr):                     # 정렬을 수행할 함수 정의
    """
    arr 리스트를 퀵소트 알고리즘으로 오름차순 정렬합니다.
    정렬 결과는 arr 자체가 정렬된 상태가 됩니다.
    """
    def _quicksort(left, right):          # 재귀적으로 호출할 내부 함수
        if left >= right:                 # 하위 범위가 1개 이하이면 종료
            return

        # 피벗(pivot)을 선택(범위 중앙값 사용)
        pivot = arr[(left + right) // 2]  # 피벗 요소(참조값)
        i, j = left, right                # 두 포인터 초기화

        # 섹션 1: 피벗보다 작은 요소를 왼쪽에, 큰 요소를 오른쪽에 정돈
        while i <= j:
            while arr[i] < pivot:         # 피벗보다 작은 값일 때 i를 오른쪽으로 이동
                i += 1
            while arr[j] > pivot:         # 피벗보다 큰 값일 때 j를 왼쪽으로 이동
                j -= 1
            if i <= j:                    # i와 j가 교차하기 전이면 교환
                arr[i], arr[j] = arr[j], arr[i]
                i += 1
                j -= 1

        # 섹션 2: 재귀적으로 좌우 범위를 정렬
        _quicksort(left, j)               # 피벗보다 작은 구간 정렬
        _quicksort(i, right)              # 피벗보다 큰 구간 정렬

    # 재귀 시작: 리스트 전체 범위
    _quicksort(0, len(arr) - 1)

# ------------------------------------------------------------
# 사용 예시 (테스트용)
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]    # 정렬할 예시 리스트
    print("정렬 전 :", sample)          # 정렬 전 상태
    quicksort(sample)                   # 퀵소트 적용
    print("정렬 후 :", sample)          # 정렬 후 상태
```

### 코드 상세 설명
1. **`quicksort(arr)`**  
   - 외부에서 호출되는 함수. 리스트를 인자로 받고 결과를 반환하지 않으면서 바로 제자리 정렬합니다.

2. **`_quicksort(left, right)`**  
   - 재귀적 내부 함수로 `[left, right]` 범위의 하위 리스트를 정렬합니다.

3. **피벗 선택**  
   - 가운데 인덱스(`(left + right) // 2`)의 값을 피벗으로 사용합니다.  
   - 이 방식은 평균적인 경우 성능이 좋으며, 최악의 경우(이미 정렬된 입력)에서는 안쪽에 다시 정렬 기회를 줄 수 있으나 큰 영향은 없습니다.

4. **포인터 이동**  
   - `i`와 `j`를 이용해 피벗보다 작은 값들은 왼쪽에, 큰 값들은 오른쪽에 가도록 교환합니다.  
   - 두 포인터가 교차(`i > j`)하면 반복을 종료합니다.

5. **재귀 호출**  
   - 피벗 값을 기준으로 양쪽 구간(`left~j`, `i~right`)을 각각 재귀적으로 정렬합니다.

6. **테스트 코드**  
   - `__main__` 블록에서 예시 리스트를 만들어 `quicksort` 함수를 호출하고 결과를 출력합니다.

---

#### 시간 복잡도
- 평균: `O(n log n)`
- 최악: `O(n^2)` (피벗 선택이 최악의 경우일 때)

#### 공간 복잡도
- `O(log n)` (재귀 호출 스택 공간)  → 제자리 정렬
