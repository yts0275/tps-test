아래는 파이썬으로 작성한 **in‑place QuickSort** 알고리즘입니다.  
각 줄마다 한 줄씩 주석(`# 주석`)을 달아 이해를 돕도록 했습니다.

```python
# quicksort.py

def quicksort(arr, low, high):
    """
    힙프의 재귀적 방법으로 배열 arr[low:high+1]을 정렬합니다.
    """
    # base case : 부분 배열이 1개 이하이면 정렬이 끝난 것
    if low < high:
        # 파티션을 수행해 피벗의 올바른 위치를 찾음
        p = partition(arr, low, high)
        # 피벗이 있는 위치보다 왼쪽, 오른쪽 부분 배열을 각각 정렬
        quicksort(arr, low, p - 1)
        quicksort(arr, p + 1, high)

def partition(arr, low, high):
    """
    피벗(끝 원소)을 기준으로 배열을 재배치한 후
    피벗이 올바르게 놓인 인덱스를 반환합니다.
    """
    pivot = arr[high]          # 피벗 선택 (여기서는 가장 끝 원소를 사용)
    i = low - 1                # i는 작은 값이 모인 영역의 끝 인덱스

    # high-1까지 반복하면서 피벗보다 작은 원소를 앞으로 이동
    for j in range(low, high):
        if arr[j] <= pivot:    # 현재 원소가 피벗보다 작으면
            i += 1             # i++ 으로 작은 영역을 확장
            arr[i], arr[j] = arr[j], arr[i]  # i 와 j 위치 교환

    # 마지막으로 피벗을 작은 영역 뒤쪽에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1               # 피벗의 최종 인덱스 반환

# --------------------------- 테스트 예시 ---------------------------
if __name__ == "__main__":
    # 예시 배열
    arr = [34, 7, 23, 32, 5, 62, 78, 1, 10]
    print("정렬 전:", arr)  # 정렬 전 배열 출력

    # QuickSort 수행 (임의 배열이 비어 있거나 하나의 원소일 경우를 대비)
    if arr:  # 비어 있지 않다면 정렬 실행
        quicksort(arr, 0, len(arr) - 1)

    print("정렬 후 :", arr)  # 정렬된 배열 출력
```

---

### 코드 해설
1. **`quicksort` 함수**  
   - `low`와 `high`가 지시하는 범위가 1개 이하인 경우(`low >= high`) 정렬이 필요 없으므로 종료합니다.  
   - 파티션을 한 뒤 피벗 왼쪽과 오른쪽 서브필드에 대해 재귀적으로 같은 과정을 적용합니다.

2. **`partition` 함수**  
   - 피벗을 가장 오른쪽 원소로 잡습니다.  
   - `i`는 피벗보다 작은 원소가 모인 영역의 끝을 가리키며, `for` 루프를 통해 `j`가 가리키는 원소가 피벗보다 작을 때마다 `i`를 이동시키고 두 원소를 교환합니다.  
   - 루프 끝에서 피벗을 `i+1` 위치에 넣어, 피벗이 두 서브배열 사이에 놓이도록 합니다.  
   - 이때 반환되는 인덱스(`i+1`)가 피벗의 최종 위치가 됩니다.

3. **테스트 블록**  
   - 예시 배열을 만들고 `quicksort` 함수 호출로 정렬을 수행합니다.  
   - `if arr:` 조건문은 배열이 비어 있을 때 오류가 발생하지 않게 보호합니다.

---

#### 시간복잡도
- 평균: `O(n log n)`  
- 최악(이미 정렬된 배열 등): `O(n²)` (피벗을 항상 가장 작은/가장 큰 값으로 선택했을 때)

#### 공간복잡도
- 재귀 호출로 인한 스택 사용: 평균 `O(log n)`, 최악 `O(n)`

위 코드를 그대로 실행하면 파이썬 인터프리터에서 QuickSort 기능을 한눈에 확인하실 수 있습니다. 필요에 따라 피벗 선택 방식을 바꾸거나, 수치 범위가 매우 큰 경우 `sys.setrecursionlimit` 등으로 재귀 깊이 제한을 늘려 사용하시면 됩니다.
