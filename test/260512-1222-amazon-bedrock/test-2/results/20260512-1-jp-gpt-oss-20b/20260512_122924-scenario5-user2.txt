아래는 **Python** 로 구현한 재귀적 인‑플레이스(인덱스 기준) 퀵소트 예시입니다.  
각 줄마다 한 줄 주석을 달아 두었으니, 한 줄씩 읽어가며 이해해 보세요.

```python
# 전체 리스트를 인덱스(low~high) 범위 안에서 정렬하는 함수
def quick_sort(arr, low, high):
    # 재귀 종료 조건: 하위 구간이 1개 이하라면 정렬 완료
    if low < high:
        # 현재 구간을 기준으로 partition 수행
        pivot_index = partition(arr, low, high)

        # 피벗을 기준으로 왼쪽 구간 정렬
        quick_sort(arr, low, pivot_index - 1)

        # 피벗을 기준으로 오른쪽 구간 정렬
        quick_sort(arr, pivot_index + 1, high)

# arr[low]~arr[high] 범위에서 피벗(마지막 원소)을 기준으로 partition
def partition(arr, low, high):
    # 피벗을 마지막 원소로 선택
    pivot = arr[high]
    # 작은 원소가 모여 있을 인덱스(초기값은 low-1)
    i = low - 1

    # low~high-1까지 순회하며 피벗보다 작은 원소를 앞쪽으로 이동
    for j in range(low, high):
        if arr[j] < pivot:
            i += 1               # i를 한 칸 앞으로
            arr[i], arr[j] = arr[j], arr[i]  # i번과 j번 자리를 교환

    # 최종적으로 피벗을 i+1 위치로 옮김
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 놓인 인덱스 반환
    return i + 1

# --------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬되지 않은 배열
    data = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전 :", data)

    # 전체 범위인 0번 인덱스부터 len-1 인덱스까지 정렬
    quick_sort(data, 0, len(data) - 1)
    print("정렬 후 :", data)
```

===> **설명**  
1. `quick_sort` 가 리스트의 한 구간을 재귀적으로 **피벗** 기준으로 나눠 정렬합니다.  
2. `partition` 은 피벗보다 작은 값들을 왼쪽으로 모으고, 피벗을 최종 위치에 두어 그 좌우로 다시 재귀 호출합니다.  
3. `quick_sort`·`partition` 은 모두 **in‑place** 방식으로 동작하므로 추가적인 배열 복사 없이 공간 복잡도 \(O(1)\) 에 정렬이 됩니다.  

위 예시를 실행하면 다음과 같이 출력됩니다.

```
정렬 전 : [3, 6, 8, 10, 1, 2, 1]
정렬 후 : [1, 1, 2, 3, 6, 8, 10]
```

필요에 따라 피벗 선택 전략(가장 앞선 원소, 무작위 원소 등)을 바꾸면 최악의 경우 성능을 개선할 수 있습니다.
