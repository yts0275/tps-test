아래는 **Python** 으로 구현한 퀵소트(QuickSort) 예시입니다.  
코드의 각 줄마다 그 줄이 수행하는 일을 한글로 주석 처리했습니다.  
주석은 코드와 같은 라인에 `#` 뒤에 붙여서 제공했습니다.

```python
def quick_sort(arr, low, high):
    # 만약 정렬할 범위가 0개 이하이면(끝이 맞음) 바로 종료
    if low < high:
        # 파티션(분할) 함수 호출: pivot(고정 기준값) 기준으로 작은/큰 값으로 배열 분리
        pivot_index = partition(arr, low, high)

        # pivot보다 작은 부분에 대해 재귀 호출(같은 함수 실행)
        quick_sort(arr, low, pivot_index - 1)

        # pivot보다 큰 부분에 대해 재귀 호출(같은 함수 실행)
        quick_sort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    # 가장 오른쪽 요소를 pivot 으로 선택
    pivot = arr[high]
    # 작은(또는 같은) 값이 저장될 인덱스 초기화
    i = low - 1

    # low ~ high-1 영역을 순회하면서 pivot보다 작은 값과 큰 값을 구분
    for j in range(low, high):
        # 만약 arr[j] 가 pivot보다 작으면
        if arr[j] < pivot:
            # i를 한 칸 오른쪽으로 이동
            i += 1
            # arr[i] 와 arr[j] 를 교환
            arr[i], arr[j] = arr[j], arr[i]

    # pivot을 올바른 위치(모두 작거나 같은 왼쪽, 크거나 같은 오른쪽)로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # pivot의 최종 위치를 반환
    return i + 1

# 테스트 코드: 원하는 배열과 호출 예시
if __name__ == "__main__":
    # 정렬되지 않은 예시 배열
    data = [33, 10, 55, 71, 29, 3, 12, 86]
    # 배열의 처음 인덱스와 끝 인덱스 지정
    quick_sort(data, 0, len(data) - 1)
    # 정렬 결과 출력
    print("정렬된 결과:", data)
```

이 코드는 재귀적으로 배열을 두 부분으로 나누어 정렬합니다.  
- **pivot**: 가장 오른쪽 원소를 기준값으로 사용합니다.  
- **partition**: pivot 보다 작은 값들을 왼쪽에, 큰 값들을 오른쪽에 위치하도록 배열을 재배치합니다.  
- **quick_sort**: 재귀적으로 좌우 부분을 다시 정렬합니다.

위 예시를 실행하면 `정렬된 결과: [3, 10, 12, 29, 33, 55, 71, 86]` 가 출력됩니다.  
필요에 따라 pivot 선택 방식을 변경하거나, 반복문(Iterative) 버전으로 바꿀 수도 있습니다.
