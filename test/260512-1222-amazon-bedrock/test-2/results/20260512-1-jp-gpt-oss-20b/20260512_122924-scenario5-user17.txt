아래는 Python으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 `#` 뒤에 설명을 넣어 주석을 달았습니다.

```python
def quicksort(arr, low, high):
    # 배열과 정렬 범위(인덱스)를 인수로 받는다
    if low < high:                         # 정렬 범위가 한 개 이하이면 더이상 분할이 필요없다
        pivot_index = partition(arr, low, high)  # 피벗을 정하고 그 위치를 반환한다
        quicksort(arr, low, pivot_index - 1)     # 피벗보다 작은 부분에 대해 재귀 호출
        quicksort(arr, pivot_index + 1, high)    # 피벗보다 큰 부분에 대해 재귀 호출

def partition(arr, low, high):
    # 하위 범위 중 마지막 원소를 피벗으로 선택한다
    pivot = arr[high]                    # 피벗 값 저장
    i = low - 1                          # i는 피벗보다 작은 원소가 쌓일 위치
    for j in range(low, high):           # 범위 내 모든 원소를 순회
        if arr[j] <= pivot:              # 현재 원소가 피벗보다 작거나 같으면
            i += 1                       # i를 한 칸 이동
            arr[i], arr[j] = arr[j], arr[i]  # i와 j의 원소를 교환
    # 피벗을 적절한 위치에 놓는다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # i+1에 피벗을 넣고 원소 교환
    return i + 1                         # 피벗이 놓인 인덱스를 반환

# 예제 사용법
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]         # 정렬하고자 하는 배열
    quicksort(data, 0, len(data) - 1)     # 퀵소트 호출 (전체 범위)
    print("정렬된 배열:", data)          # 결과 출력
```

이 코드는 재귀적으로 동작하며, 평균 시간 복잡도는 **O(n log n)**, 최악의 경우는 **O(n²)** 입니다.  
각 코드 줄마다 자세한 주석이 달려 있으니, 읽으면서 이해를 돕기 좋습니다.
