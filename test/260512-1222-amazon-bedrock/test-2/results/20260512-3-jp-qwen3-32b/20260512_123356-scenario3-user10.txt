---

### ✅ 퀵소트 (Quick Sort) Python 구현

```python
def quick_sort(arr):
    # 배열이 비어 있거나 원소가 하나만 있다면, 이미 정렬되어 있으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 선택합니다. 여기서는 첫 번째 요소를 사용
    pivot = arr[0]

    # 피벗보다 작은 요소들을 담을 왼쪽 리스트
    left = [x for x in arr[1:] if x <= pivot]

    # 피벗보다 큰 요소들을 담을 오른쪽 리스트
    right = [x for x in arr[1:] if x > pivot]

    # 재귀적으로 왼쪽과 오른쪽을 각각 정렬한 후, 왼쪽 + [피벗] + 오른쪽을 반환
    return quick_sort(left) + [pivot] + quick_sort(right)
```

---

### 💡 예시 실행

```python
unsorted_list = [5, 2, 9, 1, 5, 6]
sorted_list = quick_sort(unsorted_list)
print(sorted_list)  # 출력: [1, 2, 5, 5, 6, 9]
```

---

### 📌 참고

- 퀵소트는 **분할 정복 알고리즘**(Divide and Conquer)의 한 종류입니다.
- 평균 시간 복잡도는 **O(n log n)**, 최악의 경우 **O(n²)**.
- 최악의 성능을 피하기 위해 피벗 선택 전략을 바꾸는 것도 고려할 수 있습니다.

추가로 원하시면, **인플레이스(in-place)** 버전의 퀵소트도 구현해 드릴 수 있어요. 😊
