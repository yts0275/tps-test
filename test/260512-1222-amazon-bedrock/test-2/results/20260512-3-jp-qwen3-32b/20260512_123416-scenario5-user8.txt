---

### ✅ 퀵소트(Quick Sort)란?
빠른 정렬 알고리즘으로, **분할 정복**(divide and conquer) 전략을 사용합니다. 배열을 하나의 기준(피벗)으로 나누고, 피벗보다 작고 큰 요소들을 각각의 쪽으로 분류한 후, 재귀적으로 정렬합니다.

---

```python
def quick_sort(arr):
    # 리스트에 요소가 하나라도 있다면
    if len(arr) <= 1:
        # 재귀 종료 조건: 요소가 1개이면 그대로 반환
        return arr

    # 피벗(pivot)을 리스트의 첫 번째 요소로 설정
    pivot = arr[0]

    # 피벗보다 작은 요소들을 담을 왼쪽 리스트
    left = [x for x in arr[1:] if x < pivot]

    # 피벗보다 큰 요소들을 담을 오른쪽 리스트
    right = [x for x in arr[1:] if x >= pivot]

    # 재귀적으로 왼쪽과 오른쪽을 정렬 후, 피벗과 결합
    return quick_sort(left) + [pivot] + quick_sort(right)
```

---

### ✅ 예제 사용법:

```python
# 테스트용 배열
unsorted_list = [5, 3, 8, 4, 2]

# 퀵소트 실행
sorted_list = quick_sort(unsorted_list)

# 정렬된 리스트 출력
print("정렬된 리스트:", sorted_list)
```

---

### 🔍 설명 요약

- `quick_sort()` 함수는 자기 자신을 재귀적으로 호출합니다.
- 피벗은 항상 배열의 첫 번째 요소로 선택되며, 실제 구현에서는 다양한 피벗 선택 전략이 존재합니다.
- 재귀가 종료되는 조건은 배열의 길이가 `1` 이하일 때입니다.
