---

### ✅ 퀵소트(Quick Sort) – Python 구현 (재귀 방식)

```python
def quick_sort(arr):
    # 리스트가 비어있거나 요소가 하나라면, 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(Pivot) 선택: 여기서는 리스트의 첫 번째 요소로 선택
    pivot = arr[0]

    # 피벗보다 작거나 같은 요소들을 모을 왼쪽 리스트
    left = [x for x in arr[1:] if x <= pivot]

    # 피벗보다 큰 요소들을 모을 오른쪽 리스트
    right = [x for x in arr[1:] if x > pivot]

    # 재귀적으로 왼쪽과 오른쪽을 정렬한 후, [왼쪽] + [피벗] + [오른쪽] 형태로 결합
    return quick_sort(left) + [pivot] + quick_sort(right)
```

---

### 📌 예시 실행

```python
# 정렬할 데이터
data = [5, 3, 8, 4, 2, 7, 1, 10]

# 퀵소트 실행
sorted_data = quick_sort(data)

print("정렬된 리스트:", sorted_data)
```

```
정렬된 리스트: [1, 2, 3, 4, 5, 7, 8, 10]
```

---

### 📌 퀵소트의 핵심 아이디어

- **분할**(Divide): 리스트를 "작은 값", "피벗", "큰 값" 세 그룹으로 나눔.
- **정복**(Conquer): 각 그룹을 재귀적으로 정렬.
- **합병**(Combine): 정렬된 두 리스트와 피벗으로 완성된 리스트를 연결.
