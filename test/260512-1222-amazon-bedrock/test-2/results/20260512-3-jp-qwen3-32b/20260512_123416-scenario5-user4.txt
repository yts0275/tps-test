---

### ✅ 퀵소트(Quick Sort) Python 구현

```python
def quick_sort(arr):
    # 종료 조건: 배열 길이가 1 이하이면, 이미 정렬된 상태
    if len(arr) <= 1:
        return arr

    # 피벗(Pivot) 선택: 여기서는 첫 번째 원소를 피벗으로 사용
    pivot = arr[0]

    # 피벗보다 작은 원소들을 모을 리스트
    less_than_pivot = []

    # 피벗보다 큰 원소들을 모을 리스트
    greater_than_pivot = []

    # 피벗을 제외한 나머지 원소를 기준에 따라 분류
    for num in arr[1:]:
        if num <= pivot:
            less_than_pivot.append(num)  # 피벗보다 작거나 같으면 왼족
        else:
            greater_than_pivot.append(num)  # 피벗보다 크면 오른쪽

    # 재귀적으로 왼쪽/오른쪽 리스트 정렬 후, 피벗과 함께 결합
    return quick_sort(less_than_pivot) + [pivot] + quick_sort(greater_than_pivot)
```

---

### 🔧 예시 사용법

```python
# 예시 배열
unsorted_list = [3, 6, 8, 10, 1, 2, 1]
sorted_list = quick_sort(unsorted_list)
print(sorted_list)  # [1, 1, 2, 3, 6, 8, 10]
```

---

### 📌 퀵소트 설명

- **분할 정복 알고리즘**입니다.
- **피벗(Pivot)**을 기준으로 작은 그룹과 큰 그룹으로 나누고, **재귀적**으로 정렬합니다.
- 평균 시간 복잡도는 **O(n log n)** 입니다.
- 최악의 경우(배열이 이미 정렬되어 있을 때)는 **O(n²)**이 됩니다. 이를 개선하려면 피벗 선택 전략을 바꾸는 것이 좋습니다 (예: 난수 선택, 중간 값 선택).
