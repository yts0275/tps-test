```python
# 퀵정렬(Quick Sort) 알고리즘을 구현하는 함수입니다.
def quicksort(arr):
    # 배열의 길이가 1보다 작거나 같으면 이미 정렬된 것으로 간주하여 바로 반환합니다.
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)은 배열의 중간 요소를 선택합니다. (여러 방법이 있지만 여기서는 중간 인덱스를 사용)
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들을 모으는 리스트
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들을 모으는 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들을 모으는 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬하고, 중간 부분과 결합합니다.
    return quicksort(left) + middle + quicksort(right)

# 예제 실행: 정렬할 배열을 정의합니다.
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵정렬 함수를 호출하고 결과를 출력합니다.
print("정렬된 배열:", quicksort(arr))
```

### 설명:

- `quicksort`: 퀵정렬 알고리즘을 구현하는 함수입니다.
- `pivot`: 기준값으로 사용될 요소입니다. 이 예제에서는 배열의 중간 값으로 설정됩니다.
- `left`, `middle`, `right`: 피벗을 기준으로 나누어진 세 개의 하위 배열입니다.
- 재귀적으로 각각의 배열을 정렬하여 합치면 전체 배열이 정렬됩니다.

### 시간 복잡도:

- 평균 경우: $ O(n \log n) $
- 최악의 경우: $ O(n^2) $ (피벗이 항상 가장 작거나 큰 수일 때)

### 공간 복잡도:

- $ O(\log n) $ (재귀 호출 스택에 따라 다름)
