물론입니다! 아래는 퀵소트(Quick Sort) 알고리즘의 Python 구현 코드이며, **각 줄에 주석**을 달아 설명해드렸습니다:

```python
def quicksort(arr, low, high):
    # 재귀적으로 호출하여 정렬 수행 (기저 조건)
    if low < high:
        # 파티션 함수를 호출하여 피벗 위치를 반환받음
        pi = partition(arr, low, high)

        # 피벗의 왼쪽 부분 배열을 재귀적으로 정렬
        quicksort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분 배열을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 마지막 원소를 피벗으로 설정
    pivot = arr[high]

    # i는 작은 요소들을 배치할 위치를 나타냄
    i = low - 1

    # j는 현재 검사 중인 요소를 가리킴
    for j in range(low, high):
        # 만약 j번째 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, i와 j의 값을 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킴 (i+1 위치에 배치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 위치 인덱스를 반환
    return i + 1

# 예제 사용법:
if __name__ == "__main__":
    # 정렬할 배열을 정의
    arr = [10, 7, 8, 9, 1, 5]
    n = len(arr)

    # 퀵소트 실행
    quicksort(arr, 0, n - 1)

    # 정렬된 결과 출력
    print("정렬된 배열:", arr)
```

### 📌 주요 설명:

- `quicksort` 함수: 배열의 특정 구간을 정렬하는 재귀 함수입니다.
- `partition` 함수: 피벗을 기준으로 배열을 분할하고, 피벗의 위치를 반환합니다.
- 위 코드는 **인-place 정렬** 방식으로 이루어져 있어 공간 복잡도가 `O(log n)`입니다.
