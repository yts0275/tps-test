```python
def quicksort(arr, low, high):
    # 재귀 호출의 기본 경우: 만약 low가 high보다 크거나 같다면, 정렬할 요소가 없으므로 종료
    if low < high:
        # 피벗을 기준으로 배열을 분할하고, 피벗의 올바른 위치를 반환받음
        pi = partition(arr, low, high)
        
        # 피벗 왼쪽 부분 배열에 대해 퀵소트 재귀 호출 (피벗 이전 요소들)
        quicksort(arr, low, pi - 1)
        
        # 피벗 오른쪽 부분 배열에 대해 퀵소트 재귀 호출 (피벗 이후 요소들)
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피벗을 배열의 마지막 요소로 설정 (기본적으로 가장 우측 요소 사용)
    pivot = arr[high]
    
    # i는 작은 요소들을 추적하기 위한 인덱스 (초기값은 low-1)
    i = low - 1
    
    # j는 현재 검토 중인 요소를 나타냄
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 요소와 arr[i]를 교환하여 작은 요소들을 앞으로 이동
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동시킴 (작은 요소들 뒤에 배치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 위치한 인덱스를 반환
    return i + 1

# 예제 사용법:
# arr = [10, 7, 8, 9, 1, 5]
# n = len(arr)
# quicksort(arr, 0, n - 1)
# print("정렬된 배열:", arr)
```

위 코드는 퀵소트(Quick Sort) 알고리즘을 구현한 것입니다.  
`quicksort()` 함수는 배열 전체를 정렬하는 메인 함수이고,  
`partition()` 함수는 배열을 피벗 기준으로 분할하는 역할을 합니다.  

### 각 줄 설명:

- `def quicksort(arr, low, high):`  
  퀵소트를 수행하는 함수이며, 배열과 시작, 끝 인덱스를 받습니다.

- `if low < high:`  
  재귀적으로 정렬하는 조건. `low`가 `high`보다 작아야 정렬할 요소가 있음을 의미합니다.

- `pi = partition(arr, low, high)`  
  분할 작업을 수행하고, 피벗의 올바른 위치를 반환합니다.

- `quicksort(arr, low, pi - 1)`  
  피벗 이전 부분에 대해 재귀 호출하여 정렬합니다.

- `quicksort(arr, pi + 1, high)`  
  피벗 이후 부분에 대해 재귀 호출하여 정렬합니다.

- `def partition(arr, low, high):`  
  배열을 두 부분으로 분할하면서 피벗을 정렬된 위치로 이동시킵니다.

- `pivot = arr[high]`  
  마지막 요소를 피벗으로 선택합니다.

- `i = low - 1`  
  작은 요소들을 추적할 인덱스를 초기화합니다.

- `for j in range(low, high):`  
  배열을 순회하면서 피벗과 비교합니다.

- `if arr[j] <= pivot:`  
  현재 요소가 피벗보다 작거나 같으면, 해당 요소를 "작은 그룹"에 추가합니다.

- `i += 1`  
  작은 요소들이 저장될 위치를 업데이트합니다.

- `arr[i], arr[j] = arr[j], arr[i]`  
  현재 요소를 적절한 위치로 이동시킵니다.

- `arr[i + 1], arr[high] = arr[high], arr[i + 1]`  
  피벗을 최종적으로 정렬된 위치로 이동시킵니다.

- `return i + 1`  
  피벗이 위치한 인덱스를 반환합니다.

### 사용 예시:
```python
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)
quicksort(arr, 0, n - 1)
print("정렬된 배열:", arr)
```
