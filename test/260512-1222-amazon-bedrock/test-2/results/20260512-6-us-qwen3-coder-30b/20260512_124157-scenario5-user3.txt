아래는 퀵소트(Quick Sort) 알고리즘의 Python 구현 코드입니다.
각 줄에 해당하는 주석을 추가하여 설명을 드렸습니다.

```python
def quicksort(arr, low, high):
    # 재귀적으로 호출되어야 하는 기저 조건: low가 high보다 크거나 같으면 정렬할 원소가 없음
    if low < high:
        # partition 함수를 호출하여 피벗의 올바른 위치를 찾고,
        # 그 위치를 pivot_index에 저장합니다.
        pivot_index = partition(arr, low, high)

        # 피벗의 왼쪽 부분(피벗보다 작은 값들)에 대해 재귀적으로 퀵소트를 호출합니다.
        quicksort(arr, low, pivot_index - 1)

        # 피벗의 오른쪽 부분(피벗보다 큰 값들)에 대해 재귀적으로 퀵소트를 호출합니다.
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    # 배열의 마지막 원소를 피벗으로 설정합니다.
    pivot = arr[high]

    # i는 작은 값을 저장할 인덱스를 나타냅니다.
    i = low - 1

    # low부터 high-1까지 반복하면서 원소들을 비교합니다.
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 증가시킨 후, i와 j의 원소를 교환합니다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킵니다.
    # 피벗은 이제 i+1 위치에 있습니다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 들어갈 위치인 i+1를 반환합니다.
    return i + 1


# 예시 사용법
if __name__ == "__main__":
    # 퀵소트를 적용할 배열
    arr = [10, 7, 8, 9, 1, 5]
    
    # 배열의 길이를 구합니다.
    n = len(arr)
    
    # 퀵소트 함수를 호출합니다. 처음에는 전체 배열에 대해 정렬을 시작합니다.
    quicksort(arr, 0, n - 1)
    
    # 정렬된 결과 출력
    print("정렬된 배열:", arr)
```

이 코드는 다음과 같은 절차로 동작합니다:

1. **quicksort**: 
   - 재귀적으로 배열을 분할하고, 분할된 배열 각각에 대해 퀵소트를 수행합니다.
   - 기저조건은 `low >= high`일 때입니다.

2. **partition**: 
   - 배열의 일부분을 피벗을 기준으로 두 파트로 나누어주는 함수입니다.
   - 피벗보다 작은 원소들은 왼쪽으로, 큰 원소들은 오른쪽으로 보내고, 
     피벗은 자신이 있어야 할 위치에 배치됩니다.

3. **메인 실행부분**:
   - 예제 배열을 정의하고, `quicksort`를 호출해 순서대로 정렬합니다.

이러한 방식으로 퀵소트는 평균적으로 O(n log n) 시간 복잡도를 가지며, 공간 복잡도는 O(log n)입니다.
