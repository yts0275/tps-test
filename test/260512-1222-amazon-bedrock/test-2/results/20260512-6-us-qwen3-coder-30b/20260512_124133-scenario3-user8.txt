```python
# 퀵 정렬(Quick Sort) 알고리즘 구현
def quicksort(arr):
    # 리스트의 길이가 1개 이하인 경우, 정렬이 필요 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)을 리스트의 첫 번째 요소로 설정
    pivot = arr[0]
    
    # 피벗보다 작은 요소들을 담는 리스트
    left = [x for x in arr[1:] if x < pivot]
    
    # 피벗과 같은 요소들을 담는 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들을 담는 리스트
    right = [x for x in arr[1:] if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분 리스트를 정렬하고, 중간 부분과 합침
    return quicksort(left) + middle + quicksort(right)

# 예제 사용법
if __name__ == "__main__":
    # 정렬할 배열을 정의
    example_array = [64, 34, 25, 12, 22, 11, 90]
    
    # 퀵 정렬 수행
    sorted_array = quicksort(example_array)
    
    # 결과 출력
    print("정렬된 배열:", sorted_array)
```

### 설명:

- **`quicksort(arr)`**: 퀵 정렬 함수로, 입력받은 배열을 정렬하여 반환합니다.
- **기저 조건 (`if len(arr) <= 1`)**: 배열 길이가 1 이하이면 이미 정렬되어 있으므로 그대로 반환합니다.
- **피벗 선택**: 첫 번째 원소를 피벗으로 합니다 (단순화된 방법).
- **분할 과정**:
  - `left`: 피벗보다 작은 원소들.
  - `middle`: 피벗과 같은 원소들.
  - `right`: 피벗보다 큰 원소들.
- **재귀 호출**: 왼쪽과 오른쪽 부분 리스트를 다시 분할하고 정렬합니다.
- **결합**: 재귀 호출 후 결과를 합쳐서 최종 정렬된 배열을 만듭니다.

이 코드는 파이썬 기반으로 작성되었으며, 간단하고 이해하기 쉬운 버전입니다. 실제 라이브러리나 고성능 요구사항에서는 다른 최적화 방식(예: 인-place 정렬)을 사용할 수 있습니다.
