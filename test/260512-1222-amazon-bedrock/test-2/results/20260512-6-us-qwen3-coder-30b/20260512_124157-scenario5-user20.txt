```python
# 퀵정렬(Quick Sort) 알고리즘 구현
def quicksort(arr, low, high):
    # 재귀적으로 호출되며, low가 high보다 크거나 같으면 종료
    if low < high:
        # 파티션 함수를 호출하여 기준점(pivot)의 올바른 위치를 찾음
        pivot_index = partition(arr, low, high)
        
        # 기준점 왼쪽 부분 배열에 대해 재귀 호출 (퀵정렬 수행)
        quicksort(arr, low, pivot_index - 1)
        
        # 기준점 오른쪽 부분 배열에 대해 재귀 호출 (퀵정렬 수행)
        quicksort(arr, pivot_index + 1, high)

# 배열을 파티션하여 기준점을 올바른 위치로 이동시키는 함수
def partition(arr, low, high):
    # 배열의 마지막 요소를 기준점으로 선택
    pivot = arr[high]
    
    # i는 작은 요소들을 가리키는 인덱스 (초기값은 low-1로 설정)
    i = low - 1
    
    # j는 현재 검사 중인 요소를 가리키는 인덱스
    for j in range(low, high):
        # 만약 현재 요소가 기준점보다 작거나 같다면,
        if arr[j] <= pivot:
            # i를 증가시켜 작은 요소들의 경계를 이동시키고,
            i += 1
            # 현재 요소와 i 위치의 요소를 교환
            arr[i], arr[j] = arr[j], arr[i]
    
    # 기준점을 올바른 위치로 이동시키기 위해, 마지막 요소와 i+1 위치의 요소를 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 기준점이 올바른 위치에 도달했으므로, 그 위치를 반환
    return i + 1

# 예시: 정렬할 배열
arr = [64, 34, 25, 12, 22, 11, 90]

# 퀵정렬을 실행하기 전 배열 상태 출력
print("정렬 전:", arr)

# 퀵정렬 실행
quicksort(arr, 0, len(arr) - 1)

# 퀵정렬 이후의 배열 상태 출력
print("정렬 후:", arr)
```

### 주석 설명:

1. **`quicksort(arr, low, high)`** 함수는 원소들이 있는 범위를 인자로 받아, 퀵정렬 알고리즘을 수행합니다.
2. **기저조건**: `if low < high` 조건은 하위 배열이 최소 하나 이상의 원소를 포함하도록 함.
3. **기준점 찾기**: `partition()` 함수는 현재 배열에서 기준 점을 결정하고 해당 원소가 최종적으로 위치해야 할 인덱스를 반환합니다.
4. **재귀 호출**: 기준점 기준으로 왼쪽과 오른쪽의 부분 배열에 대해 퀵정렬을 다시 반복합니다.
5. **`partition()` 함수**: 
   - 가장 오른쪽 원소를 기준으로 선택한다.
   - 작은 원소들끼리는 왼쪽으로 모으고 크거나 같은 원소들은 오른쪽으로 둔다.
   - `i` 역할은 왼쪽에 있는 작은 원소들의 끝 위치이다.
6. **최종 위치 조정**: 모든 원소 탐색 후 기준 점을 제자리로 이동시킨다.

이 코드는 평균 시간 복잡도는 O(n log n)이며, 공간 복잡도는 O(log n)입니다.
