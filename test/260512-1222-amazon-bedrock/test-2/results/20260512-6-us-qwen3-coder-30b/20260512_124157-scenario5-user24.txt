```python
# 퀵소트(Quick Sort) 알고리즘을 구현합니다.
def quicksort(arr):
    # 배열이 1개 이하의 요소를 가진 경우, 정렬이 필요 없으므로 그대로 반환합니다.
    if len(arr) <= 1:
        return arr
    
    # 배열의 중간 인덱스를 기준으로 피벗(pivot)을 선택합니다.
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들만 모은 리스트를 생성합니다.
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들만 모은 리스트를 생성합니다.
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들만 모은 리스트를 생성합니다.
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽 부분과 오른쪽 부분을 정렬하고, 중간 부분과 합칩니다.
    return quicksort(left) + middle + quicksort(right)

# 테스트용 입력 배열
test_array = [3, 6, 8, 10, 1, 2, 1]

# 퀵소트를 적용한 결과를 출력합니다.
print("정렬 전:", test_array)
print("정렬 후:", quicksort(test_array))
```

### 설명:
- **함수 `quicksort(arr)`**: 주어진 배열을 퀵소트로 정렬합니다.
- **기저 조건**: 배열의 길이가 1 또는 0이면 정렬할 필요가 없으므로 그대로 반환됩니다.
- **피벗 선택**: 배열의 중간 값을 피벗으로 사용합니다 (이는 간단한 구현을 위한 방법이며, 실제 구현에서는 더 복잡한 방법으로 피벗을 선택할 수 있습니다).
- **분할 (Partitioning)**: 배열을 피벗을 기준으로 세 부분으로 나눕니다.
  - 왼쪽: 피벗보다 작은 값들
  - 중간: 피벗과 같은 값들
  - 오른쪽: 피벗보다 큰 값들
- **재귀 호출**: 왼쪽과 오른쪽 부분을 다시 퀵소트로 정렬하고, 최종 결과를 합쳐 반환합니다.

이 코드는 파이썬으로 작성된 **퀵소트의 간단한 버전**입니다. 이 방식은 이해하기 쉽지만, 추가 메모리를 필요로 하며 시간복잡도는 평균적으로 O(n log n)입니다.
