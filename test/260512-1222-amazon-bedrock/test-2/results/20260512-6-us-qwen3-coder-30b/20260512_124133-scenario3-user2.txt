물론입니다! 아래는 **퀵정렬**(Quick Sort) 알고리즘의 Python 구현 코드이며, 각 줄에 설명하는 **주석**이 달려 있습니다.

```python
def quicksort(arr, low, high):
    # 만약 하위 인덱스가 상위 인덱스보다 작거나 같다면 정렬할 필요 없음
    if low < high:
        # 파티션 함수를 호출하여 피벗의 최종 위치를 구함
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분 배열에 대해 재귀적으로 퀵소트 실행
        quicksort(arr, low, pi - 1)

        # 피벗 오른쪽 부분 배열에 대해 재귀적으로 퀵소트 실행
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 마지막 요소를 피벗으로 설정
    pivot = arr[high]

    # i는 작은 요소들의 인덱스를 나타냄 (초기값은 low-1)
    i = low - 1

    # j는 현재 검사 중인 요소의 인덱스
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시킨 후, arr[i]와 arr[j]를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동 (피벗의 왼쪽은 작은 값들, 오른쪽은 큰 값들)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 위치 반환
    return i + 1

# 테스트 예제
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)

# 퀵소트 실행
quicksort(arr, 0, n - 1)

# 결과 출력
print("정렬된 배열:", arr)
```

### 설명

- `quicksort()` : 재귀적으로 배열을 분할하고 정렬하는 메서드.
- `partition()` : 피벗을 기준으로 배열을 두 부분으로 나누는 함수.
- 피벗은 배열의 마지막 원소로 설정되며, 피벗보다 작은 값들은 왼쪽, 큰 값들은 오른쪽으로 배치됩니다.

```
정렬된 배열: [1, 5, 7, 8, 9, 10]
```
