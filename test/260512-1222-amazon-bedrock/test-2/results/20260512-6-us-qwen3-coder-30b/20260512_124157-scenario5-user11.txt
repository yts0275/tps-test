아래는 퀵소트(Quick Sort) 알고리즘의 Python 구현 코드입니다. 각 줄에 주석을 달아 설명을 제공했습니다.

```python
def quicksort(arr, low, high):
    # 재귀적으로 퀵소트를 호출하는 함수
    # arr: 정렬할 배열, low: 시작 인덱스, high: 끝 인덱스

    if low < high:
        # 만약 시작 인덱스가 끝 인덱스보다 작다면, 정렬을 진행함
        
        pi = partition(arr, low, high)
        # 파티션 함수를 호출하여 피벗의 올바른 위치를 찾고, 그 위치를 pi에 저장

        quicksort(arr, low, pi - 1)
        # 피벗보다 왼쪽 부분 배열에 대해 재귀적으로 퀵소트를 호출

        quicksort(arr, pi + 1, high)
        # 피벗보다 오른쪽 부분 배열에 대해 재귀적으로 퀵소트를 호출


def partition(arr, low, high):
    # 배열을 피벗을 기준으로 두 부분으로 나누는 함수
    # 피벗은 배열의 마지막 요소로 선택

    pivot = arr[high]
    # 피벗은 배열의 가장 오른쪽 값으로 설정

    i = low - 1
    # i는 작은 요소들을 배치할 위치를 나타냄 (초기값은 low-1)

    for j in range(low, high):
        # j는 현재 탐색 중인 인덱스이며, 피벗과 비교하는 역할

        if arr[j] <= pivot:
            # 현재 요소가 피벗보다 작거나 같으면

            i += 1
            # i를 증가시켜 작은 요소들이 배치될 위치를 이동

            arr[i], arr[j] = arr[j], arr[i]
            # i와 j 위치의 요소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗을 올바른 위치로 이동시키기 위해, 피벗과 i+1 위치의 요소를 교환

    return i + 1
    # 피벗이 최종적으로 위치할 인덱스를 반환


# 예시 실행 코드
if __name__ == "__main__":
    arr = [10, 7, 8, 9, 1, 5]
    # 정렬할 배열

    n = len(arr)
    # 배열의 길이

    quicksort(arr, 0, n - 1)
    # 퀵소트 실행: 전체 배열을 정렬

    print("정렬된 배열:")
    print(arr)
    # 정렬 후 배열 출력
```

### 설명:

- **`quicksort`** 함수는 재귀적으로 분할 정복 기법을 사용합니다.
- **`partition`** 함수는 배열을 피벗을 기준으로 나누어, 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 배치합니다.
- 이 알고리즘은 평균적으로 O(n log n) 시간 복잡도를 가지며, 공간 복잡도는 O(log n)입니다.
