```python
# 퀵 정렬(Quick Sort) 알고리즘을 구현한 함수입니다.
# 리스트를 분할하고, 피벗을 기준으로 작은 값과 큰 값을 나누며 재귀적으로 정렬합니다.

def quicksort(arr):
    # 베이스 케이스: 배열의 길이가 1개 이하인 경우, 그대로 반환합니다.
    if len(arr) <= 1:
        return arr
    
    # 피벗을 배열의 중간 위치에 있는 요소로 설정합니다.
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 값을 모은 리스트
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 값을 모은 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 값을 모은 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분을 정렬하고, 중간 부분과 합칩니다.
    return quicksort(left) + middle + quicksort(right)

# 예제 사용법
if __name__ == "__main__":
    # 정렬할 배열을 정의합니다.
    example_array = [3, 6, 8, 10, 1, 2, 1]
    
    # 퀵 정렬로 배열을 정렬합니다.
    sorted_array = quicksort(example_array)
    
    # 결과를 출력합니다.
    print("정렬된 배열:", sorted_array)
```

### 설명:

- `quicksort` 함수는 입력된 배열을 재귀적으로 정렬합니다.
- 피벗은 배열의 중간 요소로 선택되며, 이를 기준으로 세 부분으로 나눕니다:
  - `left`: 피벗보다 작은 원소들
  - `middle`: 피벗과 같은 원소들
  - `right`: 피벗보다 큰 원소들
- 그런 다음 각각의 부분을 다시 정렬한 후 병합합니다.

이러한 방식으로 모든 요소가 적절히 정렬됩니다.
