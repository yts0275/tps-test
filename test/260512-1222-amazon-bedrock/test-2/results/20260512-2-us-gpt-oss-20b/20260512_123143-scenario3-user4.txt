아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘입니다.  
코드의 각 줄마다 반드시 주석을 달아 이해를 돕도록 했습니다.  

```python
# Quicksort 함수 정의
def quicksort(arr):                                 # 1. 함수 호출 시 arr(정렬할 리스트)를 인자로 받음
    if len(arr) <= 1:                               # 2. 리스트의 길이가 1 이하라면 이미 정렬되어 있으니 그대로 반환
        return arr                                 # 3. return statement
    pivot = arr[len(arr)//2]                        # 4. 중앙값을 피벗으로 선택 (배열 길이의 중간 인덱스)
    less = [x for x in arr if x < pivot]            # 5. 피벗보다 작은 값들을 모음 (리스트 컴프리헨션 사용)
    equal = [x for x in arr if x == pivot]          # 6. 피벗과 같은 값들만 모음 (중복값 처리)
    greater = [x for x in arr if x > pivot]         # 7. 피벗보다 큰 값들을 모음
    return quicksort(less) + equal + quicksort(greater)  # 8. 재귀적으로 정렬된 결과를 합쳐 최종 반환

# 프로그램 실행 예시
if __name__ == "__main__":                          # 9. 스크립트가 메인 모듈로 실행될 때만 아래 코드를 실행
    data = [19, 7, 1, 75, 4, 3, 3]                  # 10. 정렬할 원본 리스트
    sorted_data = quicksort(data)                   # 11. quicksort 함수 호출 및 결과 저장
    print(sorted_data)                              # 12. 정렬된 결과를 콘솔에 출력
```

**주요 포인트**

- **피벗 선택** : 중앙값을 선택했지만, 상황에 따라 시작/끝/무작위(랜덤) 피벗을 선택해 최악(완전한 정렬·역정렬)의 발생 가능성을 줄일 수 있습니다.  
- **재귀 호출** : 리스트가 더 이상 분할되지 않으면 재귀 종료되고, 각 단계에서 정렬된 부분이 다시 합쳐지며 전체가 정렬됩니다.  
- **복사본 사용** : 위 구현은 리스트를 slice(분할)하고 새로운 리스트(`less`, `equal`, `greater`)를 생성하기 때문에, 원본 `arr`은 그대로 남아 있습니다. 메모리 사용량이 늘어나지만 코드가 직관적입니다.  
- **시간 복잡도** : 평균적으로 **O(n log n)**, 최악(피벗이 항상 최솟값/최댓값일 때)은 **O(n²)** 이지만, 피벗을 무작위로 고르면 최악을 거의 피할 수 있습니다.
