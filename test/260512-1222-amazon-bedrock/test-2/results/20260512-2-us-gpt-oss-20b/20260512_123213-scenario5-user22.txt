아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
모든 줄마다 설명 주석을 달아 이해하기 쉽도록 했습니다.

```python
def quicksort(arr):                                 # 정렬하려는 리스트를 입력받는다
    if len(arr) <= 1:                               # 리스트가 0개 또는 1개이면 이미 정렬 완료
        return arr                                 # 그대로 반환한다
    pivot = arr[len(arr)//2]                       # 중앙값을 피벗(pivot)으로 선택한다
    left = [x for x in arr if x < pivot]           # 피벗보다 작은 원소들을 모은 리스트
    middle = [x for x in arr if x == pivot]        # 피벗과 같은 값들을 모은 리스트
    right = [x for x in arr if x > pivot]          # 피벗보다 큰 원소들을 모은 리스트
    # 재귀적으로 정렬된 왼쪽과 오른쪽 부분을 합쳐 최종 정렬 결과를 반환
    return quicksort(left) + middle + quicksort(right)


# 사용 예시
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", sample)
    sorted_list = quicksort(sample)
    print("정렬 후:", sorted_list)
```

**주요 포인트**

1. **피벗 선택** – 리스트 중앙값을 피벗으로 사용해 구현을 단순화했습니다.  
2. **재귀 호출** – 피벗을 기준으로 왼쪽, 중간(같은값), 오른쪽 리스트를 나누고 각각 재귀적으로 정렬합니다.  
3. **합치기** – 왼쪽 정렬 결과, 피벗(중간), 오른쪽 정렬 결과를 차례로 이어서 최종 정렬된 리스트를 반환합니다.  
4. **시간 복잡도** – 평균적으로 O(n log n), 최악의 경우 O(n²)입니다.  
5. **공간 복잡도** – 재귀 호출과 리스트 생성으로 평균적으로 O(log n), 최악의 경우 O(n)입니다.  

이 코드는 파이썬에서 쉽게 실행할 수 있으며, 각 줄마다 무슨 일을 하는지 한눈에 확인할 수 있도록 주석을 달았습니다.
