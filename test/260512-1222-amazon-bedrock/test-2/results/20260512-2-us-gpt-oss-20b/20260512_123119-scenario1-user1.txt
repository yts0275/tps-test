아래는 **Python** 으로 구현한 퀵소트(QuickSort) 예제입니다.  
코드의 각 줄마다 한 줄 주석을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr):  # 입력 배열을 정렬하기 위한 외부 함수
    def _quicksort(lst, low, high):  # 재귀 정렬을 수행하는 내부 함수
        if low < high:  # 정렬 범위가 의미가 있을 때만 재귀 수행
            pi = partition(lst, low, high)  # 피벗 위치를 결정하고 배열을 분할
            _quicksort(lst, low, pi - 1)  # 피벗 왼쪽에 대해 재귀 호출
            _quicksort(lst, pi + 1, high)  # 피벗 오른쪽에 대해 재귀 호출

    def partition(lst, low, high):  # 파티션 함수를 정의, 피벗 기준으로 배열 재배치
        pivot = lst[high]  # 가장 오른쪽 요소를 피벗으로 선택
        i = low - 1  # i는 피벗보다 작은 요소가 놓일 마지막 위치 포인터
        for j in range(low, high):  # 배열의 왼쪽부터 피벗 직전까지 순회
            if lst[j] <= pivot:  # 현재 요소가 피벗보다 작거나 같으면
                i += 1  # i를 한 칸 앞으로 이동
                lst[i], lst[j] = lst[j], lst[i]  # i와 j 위치의 요소를 교환
        lst[i + 1], lst[high] = lst[high], lst[i + 1]  # 피벗을 올바른 위치( i+1 )에 이동
        return i + 1  # 피벗의 최종 위치를 반환

    _quicksort(arr, 0, len(arr) - 1)  # 바깥쪽 배열을 정렬 시작
    return arr  # 정렬된 배열을 반환

if __name__ == "__main__":  # 스크립트가 메인으로 실행될 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]  # 예시 배열 정의
    print("원본 배열:", sample)  # 원본 배열 출력
    sorted_arr = quicksort(sample)  # 퀵소트를 실행
    print("정렬된 배열:", sorted_arr)  # 정렬 결과 출력
```

코드의 각 줄에 한 줄씩 주석을 달아 구현 흐름과 로직을 자세히 정리했습니다. 필요에 따라 언어를 바꾸거나 다른 버전(예: 비재귀적 배치)으로 확장해 사용하실 수 있습니다.
