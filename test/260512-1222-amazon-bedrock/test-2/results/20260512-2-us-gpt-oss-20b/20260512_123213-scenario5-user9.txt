아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
주석은 **각 작업이 무슨 일을 하는지 한 줄씩** 설명하도록 해두었습니다.

```python
# 리스트를 정렬하는 재귀 함수
def quick_sort(arr, low, high):
    # 기저 조건: 1개 이하의 요소는 이미 정렬된 상태
    if low < high:
        # 1) 파티셔닝(분할) 함수 호출 → 피벗 기준으로 좌·우 분할
        pivot_index = partition(arr, low, high)
        # 2) 왼쪽 부분(피벗보다 작은 요소들) 정렬
        quick_sort(arr, low, pivot_index - 1)
        # 3) 오른쪽 부분(피벗보다 큰 요소들) 정렬
        quick_sort(arr, pivot_index + 1, high)

# 파티셔닝 함수: 피벗을 기준으로 좌·우를 교환
def partition(arr, low, high):
    # 피벗은 보통 가장 오른쪽에 있는 값
    pivot = arr[high]
    # i는 피벗보다 작은 요소가 놓일 위치를 가리킴
    i = low - 1
    # low부터 high-1까지 순회
    for j in range(low, high):
        # 현재 값이 피벗보다 작으면 i를 한 칸 앞으로 이동시키고 교환
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    # 최종적으로 피벗을 올바른 위치(i+1)에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗 인덱스를 반환
    return i + 1

# 테스트용 메인 코드
if __name__ == "__main__":
    # 정렬할 예시 배열
    sample = [33, 10, 55, 71, 29, 1, 13]
    print("정렬 전:", sample)          # 정렬 전 배열 출력
    quick_sort(sample, 0, len(sample) - 1)  # quick_sort 호출
    print("정렬 후:", sample)           # 정렬 후 배열 출력
```

**해설**  
1. `quick_sort`: 재귀 함수로, 주어진 구간(`low` ~ `high`)을 정렬  
2. `partition`: 피벗(오른쪽 끝 값)을 기준으로 배열을 좌·우로 나누고, 피벗의 최종 위치를 반환  
3. `if low < high` 조건은 재귀가 더 이상 분할할 수 없을 때 종료하도록 함  

이 코드를 그대로 실행하면, `sample` 배열이 오름차순으로 정렬된 것을 확인할 수 있습니다.
