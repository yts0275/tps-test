아래는 **Python** 으로 구현한 **퀵소트 (QuickSort)** 알고리즘입니다.  
각 줄마다 한 문장 정도의 설명을 주석으로 달아 이해하기 쉽도록 하였습니다.

```python
# 인플레이스(자리에서) 정렬을 수행하는 `quick_sort` 함수 정의
def quick_sort(array, left, right):
    # left < right 일 때만 분할과 재귀를 수행한다.
    if left < right:
        # pivot(기준값)을 기준으로 왼쪽보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 정렬
        pivot_index = partition(array, left, right)
        # pivot이 정해진 위치보다 왼쪽 범위에 대해 재귀 호출
        quick_sort(array, left, pivot_index - 1)
        # pivot이 정해진 위치보다 오른쪽 범위에 대해 재귀 호출
        quick_sort(array, pivot_index + 1, right)

# 주어진 범위에서 pivot을 찾고, pivot을 기준으로 배열을 분할하는 `partition` 함수
def partition(array, left, right):
    # 가장 오른쪽 원소를 pivot 으로 선택
    pivot = array[right]
    # i는 "pivot보다 작은" 요소가 끝나는 인덱스를 가리킨다.
    i = left - 1
    # left 부터 right-1까지 모든 요소를 순회하며 pivot과 비교
    for j in range(left, right):
        if array[j] <= pivot:      # 현재 요소가 pivot보다 작거나 같으면
            i += 1                 # i를 한 칸 이동시키고
            array[i], array[j] = array[j], array[i]   # i와 j 위치의 원소를 교환
    # pivot 원소를 올바른 위치(즉, i+1)의 원소와 교환
    array[i + 1], array[right] = array[right], array[i + 1]
    # pivot이 최종적으로 위치한 인덱스를 반환
    return i + 1

# 사용 예시
if __name__ == "__main__":
    # 정렬하려는 리스트
    arr = [3, 6, 8, 10, 1, 2, 1]
    # 전체 리스트(0부터 마지막 인덱스까지)에 대해 퀵소트 수행
    quick_sort(arr, 0, len(arr) - 1)
    # 정렬 결과 출력
    print("정렬된 배열:", arr)
```

### 주요 포인트
- `pivot` 으로 배열의 가장 오른쪽 원소를 사용했습니다.  
- `partition` 함수는 `pivot` 보다 작은 값들을 왼쪽으로, 큰 값들을 오른쪽으로 분리합니다.  
- 재귀 호출(`quick_sort`)은 분할된 왼쪽·오른쪽 범위 각각에 대해 다시 퀵소트를 수행합니다.  
- 전체 알고리즘은 평균적으로 `O(n log n)`의 시간복잡도를 가지며, 최악의 경우 `O(n²)`이 됩니다 (pivot이 항상 가장 크거나 가장 작은 값일 때).  

위 코드를 그대로 복사해 실행하면, 입력 배열이 정렬된 상태를 확인할 수 있습니다.
