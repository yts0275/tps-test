아래는 Python으로 구현한 퀵소트(Quicksort) 함수입니다.  
**주석은 각 줄마다 달아두었으며, 한 줄이라도 주석이 빠지는 경우가 없도록** 주의했습니다.  

```python
def quick_sort(arr):                                                      # 함수 정의: quick_sort(배열)
    if len(arr) <= 1:                                                     # 배열이 0개 혹은 1개일 때
        return arr                                                       # 이미 정렬돼 있으므로 그대로 반환
    pivot = arr[-1]                                                       # 피벗은 마지막 원소로 선택
    left = []                                                             # 피벗보다 작은 수를 넣는 리스트
    right = []                                                            # 피벗보다 크거나 같은 수를 넣는 리스트
    for x in arr:                                                         # 배열의 모든 원소 순회
        if x < pivot:                                                     # 피벗보다 작은 경우
            left.append(x)                                                # left에 추가
        else:                                                             # 피벗보다 크거나 같은 경우
            right.append(x)                                               # right에 추가
    return quick_sort(left) + [pivot] + quick_sort(right)                 # 재귀 호출 후 합쳐서 반환
```

### 사용 예시

```python
if __name__ == "__main__":                                               # 스크립트가 직접 실행될 때
    data = [3, 6, 8, 10, 1, 2, 1]                                       # 예시 배열
    print("정렬 전:", data)                                             # 원본 배열 출력
    sorted_data = quick_sort(data)                                      # 퀵소트 호출
    print("정렬 후:", sorted_data)                                     # 정렬된 배열 출력
```

### 결과 (내용 그대로)

```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

---

#### 참고 사항
- **시간 복잡도**: 평균 \(O(n \log n)\), 최악의 경우 \(O(n^2)\) (피벗 선택이 안 좋은 경우)
- **공간 복잡도**: 재귀 호출 깊이에 따라 \(O(\log n)\) (최소), 최악의 경우 \(O(n)\)  
- `left`와 `right`가 새 리스트를 만들기 때문에 **비용이 다소 커질 수** 있으나, 구현이 간단해 대부분의 교육용, 작은 규모 데이터에서는 크게 문제되지 않습니다.  
- `in-place` 버전을 원하시면 대체로 `partition` 함수를 써서 인덱스만 이동시키는 방식을 사용합니다. 

필요에 따라 추가적인 기능(예: 반복 버전, 비교 함수 지정 등)을 더할 수도 있답니다!
