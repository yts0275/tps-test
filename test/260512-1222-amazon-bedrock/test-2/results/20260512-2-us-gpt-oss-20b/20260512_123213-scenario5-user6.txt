아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 *필수* 주석을 넣어 이해를 돕도록 하였습니다.

```python
# 퀵소트(Quick Sort) 구현
# --------------------------------------------------------------------

def quicksort(arr, low, high):
    """
    재귀적으로 배열 arr을 정렬하는 함수.
    - low: 현재 정렬 영역의 시작 인덱스
    - high: 현재 정렬 영역의 끝 인덱스
    """
    # 정렬할 영역이 하나 이상의 원소를 포함하면
    if low < high:
        # 피벗을 기준으로 파티션(분할) 수행
        pivot_index = partition(arr, low, high)
        # 피벗보다 작은 부분 배열을 재귀적으로 정렬
        quicksort(arr, low, pivot_index - 1)
        # 피벗보다 큰 부분 배열을 재귀적으로 정렬
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    """
    배열 arr의 [low, high] 범위를 기준으로 파티션(분할)한다.
    - 가장 오른쪽 원소를 피벗(pivot)으로 사용.
    - 피벗보다 작은 원소는 왼쪽으로, 큰 원소는 오른쪽으로 배치.
    - 마지막에 피벗을 올바른 위치에 놓는다.
    """
    # 가장 오른쪽 원소를 피벗으로 선택
    pivot = arr[high]
    # i는 피벗보다 작은 원소를 넣을 위치(초기값은 low-1)
    i = low - 1

    # low부터 high-1까지를 순회하면서 피벗보다 작은 경우
    for j in range(low, high):
        if arr[j] <= pivot:
            # i를 한 칸 앞으로 이동
            i += 1
            # arr[i]와 arr[j]를 교환(작은 값이 왼쪽에 정렬)
            arr[i], arr[j] = arr[j], arr[i]

    # 마지막으로 피벗을 정렬 위치에 끼워넣음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 놓인 인덱스를 반환
    return i + 1

# --------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 예시 배열 (임의의 정수 목록)
    data = [64, 25, 12, 22, 11]
    print("정렬 전:", data)

    # 퀵소트 호출 (배열 전체를 정렬)
    quicksort(data, 0, len(data) - 1)

    print("정렬 후 :", data)
```

### 핵심 포인트 요약
- `quicksort` 함수는 재귀 호출을 통해 정렬 영역을 점점 줄여가면서 정렬합니다.
- `partition` 함수는 피벗을 기준으로 배열을 두 부분으로 나누고, 피벗이 최종 위치에 놓이도록 합니다.
- 가장 오른쪽 원소를 피벗으로 선택하는 방식은 구현이 가장 간단하며, 중복되는 값이 있을 때도 안정적으로 동작합니다.  
- 정리된 코드는 파이썬 3.8(또는 그 이상)에서 바로 실행할 수 있습니다.
