아래는 파이썬으로 구현한 퀵소트(QuickSort) 예시입니다.  
코드의 **모든 줄**에 각 줄이 어떤 역할을 하는지 주석(`#`)으로 설명을 달았습니다.  
이 예시는 재귀적으로 동작하며, 파이썬 리스트 컴프리헨션을 이용해 피벗보다 작은/같은/큰 값들을 분리하고 다시 정렬을 진행합니다.  

```python
import sys  # 파이썬 표준 라이브러리 로드(필요한 경우, 여기서는 사용하지 않음)

def quicksort(arr):  # 주어진 배열을 정렬하고 정렬된 배열을 반환하는 퀵소트 함수 정의
    if len(arr) <= 1:  # 배열이 비었거나 하나의 원소만 있으면 이미 정렬된 것이므로 그대로 반환
        return arr  # 정렬 완료된 배열을 반환
    pivot = arr[len(arr)//2]  # 배열의 중간 원소를 피벗으로 선택
    less = [x for x in arr if x < pivot]  # 피벗보다 작은 원소들을 모음
    equal = [x for x in arr if x == pivot]  # 피벗과 같은 원소들을 모음
    greater = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 모음
    return quicksort(less) + equal + quicksort(greater)  # 재귀적으로 정렬된 부분 배열을 합쳐 반환

if __name__ == "__main__":  # 스크립트가 직접 실행될 때 아래 코드를 수행
    data = [3, 6, 8, 10, 1, 2, 1]  # 테스트용 배열(정렬 전에 미리 정의)
    print("원본 배열:", data)  # 원본 배열 출력
    sorted_data = quicksort(data)  # 퀵소트 함수 호출
    print("정렬된 배열:", sorted_data)  # 정렬된 배열 출력
```  

**작동 방식 요약**

1. 배열이 0개 혹은 1개의 원소를 가질 때는 그대로 반환합니다.  
2. 중간 원소를 피벗으로 고르고, 피벗보다 작은/같은/큰 원소들을 각각 리스트에 분리합니다.  
3. `less`와 `greater` 리스트에 대해 재귀적으로 `quicksort`를 호출하고,  
   ```python
   quicksort(less) + equal + quicksort(greater)
   ```  
   로 최종 정렬된 배열을 반환합니다.  

필요에 따라 피벗 선택 방식을 바꾸거나, 원본 배열을 제자리에서 정렬하도록 변경할 수 있습니다. 사용 방법은 예제에서처럼 `quicksort` 함수를 호출하면 됩니다.
