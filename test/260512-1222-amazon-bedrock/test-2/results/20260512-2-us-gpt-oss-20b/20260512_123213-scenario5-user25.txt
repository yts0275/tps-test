아래는 Python으로 구현한 퀵소트(quick sort)입니다.  
코드의 각 줄마다 한 줄씩 주석을 달아 설명했습니다.

```python
# 퀵소트(Quick Sort) 구현
# --------------------------------------------

def quick_sort(arr):
    """주어진 리스트 arr을 오름차순으로 정렬한다.  
    (재귀 호출을 이용한 퀵소트 구현)"""
    
    # 1. 리스트가 0개 또는 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2. 피벗(pivot) 값을 선택한다. 여기서는 끝 원소를 선택
    pivot = arr[-1]
    
    # 3. 피벗보다 작은 값들(left)과 피벗보다 큰 값들(right)으로 구분한다
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
    
    # 4. 왼쪽, 피벗, 오른쪽을 재귀적으로 정렬해 반환
    return quick_sort(left) + [pivot] + quick_sort(right)

# --------------------------------------------
# 예시 사용
if __name__ == "__main__":
    # 테스트용 데이터
    data = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", data)
    sorted_data = quick_sort(data)
    print("정렬 후:", sorted_data)
```

- `quick_sort` 함수는 리스트를 그대로 바꾸지 않고 새 리스트를 반환하도록 설계했습니다.  
- 피벗을 끝 원소로 고정했지만, 다른 색인이나 무작위 선택으로 바꿔도 됩니다.  
- 리스트 컴프리헨션을 이용해 좌우 부분을 한 줄로 구분해 재귀 호출이 깔끔하게 이루어집니다.  

필요에 따라 인-place(제자리) 퀵소트 버전을 구현해도 좋습니다.
