아래 예시는 파이썬으로 구현한 **퀵소트** 예시입니다.  
코드의 *각 줄*에 해당 줄이 수행하는 일을 한 줄 주석으로 달았습니다.  

```python
# QuickSort (퀵소트) 구현 예시
# ------------------------------------------

def quicksort(a):  # 재귀적으로 배열 a 를 정렬하는 함수 정의
    if len(a) <= 1:  # 배열이 비었거나 한 원소뿐인 경우 이미 정렬 완료
        return a  # 정렬된 배열 그대로 반환
    pivot = a[len(a) // 2]  # 배열의 중간 원소를 피벗으로 선택
    left = [x for x in a if x < pivot]  # 피벗보다 작은 원소들만 모은 새 배열
    middle = [x for x in a if x == pivot]  # 피벗과 동일한 값들만 모은 새 배열
    right = [x for x in a if x > pivot]  # 피벗보다 큰 원소들만 모은 새 배열
    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐 반환

# 테스트용 입력 배열
arr = [3, 6, 8, 10, 1, 2, 1]  # 정렬이 필요한 원소들

print(quicksort(arr))  # 호출 결과 출력: [1, 1, 2, 3, 6, 8, 10]
```

> **주요 포인트 요약**  
> * `pivot` 은 중간 원소를 사용했습니다. (다른 전략(랜덤, 첫/마지막 원소 등)도 가능)  
> * 재귀 호출에서 `left` 와 `right` 를 다시 정렬하면서 전체 배열을 정렬합니다.  
> * O(n log n) 평균 시간 복잡도를 갖습니다.  
> * 최악의 경우(O(n²))를 방지하려면 피벗을 무작위로 선택하면 좋습니다.  
> * 이 구현은 부정확한 경우(같은 값이 많을 때)에도 중간값과 연산이 정상적으로 동작합니다.
