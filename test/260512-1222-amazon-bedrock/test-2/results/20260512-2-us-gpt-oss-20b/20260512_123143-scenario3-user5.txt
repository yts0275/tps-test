아래는 **파이썬으로 구현한 퀵소트** 예제입니다.  
각 줄마다 한글 주석을 달아 단계별로 어떤 일이 일어나는지 설명했습니다.  

```python
# quicksort.py

# ----------------------------
# 재귀적인 퀵소트 구현
# ----------------------------
def quicksort(arr, low, high):
    """
    주어진 배열 arr[l..r]을 오름차순으로 정렬하는 재귀 함수
    :param arr: 정렬 대상 배열
    :param low: 시작 인덱스
    :param high: 끝 인덱스
    """
    # low < high 인 경우에만 정렬 진행
    if low < high:
        # 배열을 파티션하여 피벗의 정해진 위치를 반환
        pivot_index = partition(arr, low, high)

        # 피벗 이전 요소들을 정렬
        quicksort(arr, low, pivot_index - 1)

        # 피벗 이후 요소들을 정렬
        quicksort(arr, pivot_index + 1, high)


# ----------------------------
# 파티션 함수
# ----------------------------
def partition(arr, low, high):
    """
    피벗을 기준으로 요소들을 재배열하고
    피벗이 정해진 위치에 들어갈 인덱스를 반환
    :param arr: 정렬 대상 배열
    :param low: 시작 인덱스
    :param high: 끝 인덱스
    """
    # 고른 피벗 (여기서는 고른 가장 왼쪽 요소를 피벗으로 사용)
    pivot = arr[high]          # 기준값(피벗)을 선택

    # i는 "arr[low..i]는 < pivot, arr[i+1..j]는 >= pivot" 구조를 유지
    i = low - 1                # 피벗보다 작은 값이 비워둘 위치

    # j는 실제 요소를 탐색하기 위해 사용
    for j in range(low, high):
        # 현재 j의 값이 피벗보다 작으면 i를 한 칸 앞으로 이동
        if arr[j] <= pivot:
            i += 1             # i 증가
            arr[i], arr[j] = arr[j], arr[i]  # i와 j를 교환

    # 마지막으로 피벗을 올바른 위치에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 위치한 인덱스를 반환
    return i + 1


# ----------------------------
# 사용 예시
# ----------------------------
if __name__ == "__main__":
    # 정렬할 예시 배열
    data = [33, 10, 55, 71, 29, 5, 18, 80, 2]

    print("정렬 전:", data)            # 정렬 전 배열 출력

    # quicksort 실행: 전체 배열 범위 지정
    quicksort(data, 0, len(data) - 1)

    print("정렬 후:", data)            # 정렬 후 배열 출력
```

**주요 포인트**  
1. `quicksort`는 재귀적으로 왼쪽과 오른쪽 부분을 정렬합니다.  
2. `partition`은 피벗(여기서는 가장 오른쪽 원소)을 기준으로 작은 값은 앞에, 큰 값은 뒤에 배치합니다.  
3. `partition`이 반환한 인덱스를 기준으로 재귀 호출이 진행됩니다.  

이 코드를 그대로 실행하면 다음과 같은 출력이 나타납니다.  

```
정렬 전: [33, 10, 55, 71, 29, 5, 18, 80, 2]
정렬 후: [2, 5, 10, 18, 29, 33, 55, 71, 80]
```
