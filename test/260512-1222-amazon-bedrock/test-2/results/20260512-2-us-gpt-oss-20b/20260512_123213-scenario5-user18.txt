아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
코드의 **각 줄**마다 한 줄 한 줄 주석을 달아 동작을 자세히 설명했습니다.  
주석은 모두 한국어로 작성되어 있으니 이해하기 쉽습니다.

```python
# 퀵소트 알고리즘 함수 (arr: 정렬할 리스트, low: 시작 인덱스, high: 끝 인덱스)
def quicksort(arr, low, high):                     # 전달받은 배열과 범위로 재귀 호출
    if low < high:                                 # low가 high보다 작으면 아직 정렬이 필요한 경우
        pi = partition(arr, low, high)             # 피벗 위치 결정 및 배열 분할
        quicksort(arr, low, pi - 1)                # 피벗 좌측 서브어레이 정렬
        quicksort(arr, pi + 1, high)               # 피벗 우측 서브어레이 정렬

# 파티션 함수 (배열을 피벗을 기준으로 나눕니다)
def partition(arr, low, high):                     # 전달받은 배열과 범위로 파티션 수행
    pivot = arr[high]                              # high 인덱스의 원소를 피벗으로 선택
    i = low - 1                                     # 피벗보다 작은 요소를 모을 인덱스
    for j in range(low, high):                      # low부터 high-1까지 순회
        if arr[j] <= pivot:                        # 현재 원소가 피벗 이하이면
            i += 1                                 # i 를 하나 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]       # i와 j 위치를 교환해 피벗보다 작은 구역에 넣음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 정렬된 위치(인덱스 i+1)로 이동
    return i + 1                                   # 피벗이 최종적으로 위치한 인덱스를 반환

# 프로그램 실행 부분 (테스트용)
if __name__ == "__main__":                        # 스크립트가 직접 실행될 때만 아래 코드 실행
    arr = [10, 7, 8, 9, 1, 5]                    # 정렬할 원본 배열
    n = len(arr)                                  # 배열 길이
    quicksort(arr, 0, n - 1)                      # 퀵소트 호출 (전체 범위)
    print("정렬된 배열:", arr)                    # 결과 출력
```

**설명 요약**  
1. **Partition** 함수는 피벗(여기서는 가장 오른쪽 원소)을 기준으로 왼쪽에 `<= 피벗`, 오른쪽에 `> 피벗`인 요소들을 배치하고, 피벗이 정렬된 위치를 반환합니다.  
2. **Quicksort** 함수는 재귀적으로 파티션을 통해 배열을 분할하며, 피벗이 기준이 되어 좌우 서브어레이를 재귀적으로 정렬합니다.  
3. 테스트 코드에서는 `[10, 7, 8, 9, 1, 5]` 의 배열을 퀵소트를 통해 정렬한 뒤 결과를 출력합니다.
