아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
모든 줄마다 자세한 주석을 달았으니, 알고리즘 흐름을 한눈에 파악하실 수 있습니다.  

```python
def quick_sort(arr):  # 정렬할 리스트를 인자로 받는 함수 정의
    # 리스트가 비어 있거나 원소가 하나 이하이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:                     # 리스트의 길이가 0 또는 1일 때
        return arr                         # 원본 리스트를 그대로 리턴
    # 피벗(pivot)을 리스트의 첫 번째 원소로 선택
    pivot = arr[0]                         # 첫 번째 요소를 피벗으로 사용
    # 피벗보다 작거나 같은 원소들을 모은 리스트(왼쪽 부분 배열)
    less = [x for x in arr[1:] if x <= pivot]   # 피벗보다 작은 값들
    # 피벗보다 큰 원소들을 모은 리스트(오른쪽 부분 배열)
    greater = [x for x in arr[1:] if x > pivot] # 피벗보다 큰 값들
    # 재귀 호출을 통해 왼쪽·오른쪽 부분 배열을 정렬하고, 피벗을 가운데에 두어 최종 리스트 반환
    return quick_sort(less) + [pivot] + quick_sort(greater)  # 정렬 완료

# 예시 실행
if __name__ == "__main__":
    unsorted_list = [3, 6, 8, 10, 1, 2, 1]
    sorted_list = quick_sort(unsorted_list)  # 정렬 수행
    print("정렬 전 :", unsorted_list)        # 원래 리스트 출력
    print("정렬 후 :", sorted_list)          # 정렬된 리스트 출력
```

위 코드에서는 `quick_sort` 함수가 재귀적으로 실행되면서 리스트를 왼쪽·오른쪽으로 분할하고,  
최종적으로 피벗을 중심으로 정렬된 리스트를 반환합니다.  
주석을 따라가며 한 줄씩 기능을 이해해 보시길 바랍니다!
