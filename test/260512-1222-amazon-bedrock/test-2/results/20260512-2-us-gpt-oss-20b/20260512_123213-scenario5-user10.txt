아래는 **Python**으로 구현한 퀵소트(QuickSort) 예시입니다.  
코드의 **각 줄마다** 한 줄 주석(`#`)을 달아, 왜 그 줄이 필요한지 설명했습니다.

```python
def quicksort(arr):                     # 정렬하고 싶은 리스트를 인자로 받는다
    if len(arr) <= 1:                   # 리스트가 0개 혹은 1개이면 이미 정렬된 상태
        return arr                     # 그대로 반환하고 종료한다

    pivot = arr[-1]                     # 피벗(분할 기준)으로 마지막 원소를 선택한다
    less = []                           # 피벗보다 작은(또는 같은) 원소를 모을 리스트
    greater = []                        # 피벗보다 큰 원소를 모을 리스트

    for x in arr[:-1]:                  # 피벗을 제외한 모든 원소에 대해 반복
        if x <= pivot:                  # 피벗보다 작거나 같으면 less 리스트에 추가
            less.append(x)
        else:                           # 피벗보다 크면 greater 리스트에 추가
            greater.append(x)

    # less와 greater를 각각 재귀적으로 정렬하고, 피벗을 중간에 삽입한 새로운 리스트를 반환
    return quicksort(less) + [pivot] + quicksort(greater)
```

#### 사용 예시

```python
if __name__ == "__main__":             # 스크립트가 직접 실행될 때만 아래 코드가 동작
    unsorted = [5, 2, 9, 1, 5, 6]      # 정렬되지 않은 리스트
    sorted_list = quicksort(unsorted)  # 퀵소트 실행
    print(sorted_list)                 # 출력: [1, 2, 5, 5, 6, 9]
```

### 주석에 대한 짧은 요약

1. **함수 정의** – `quicksort`는 정렬할 리스트 `arr`를 입력받는다.  
2. **기저 사례** – 리스트가 0개·1개이면 이미 정렬된 상태이므로 그대로 반환한다.  
3. **피벗 선택** – 가장 간단한 방식으로 마지막 원소를 피벗으로 잡는다.  
4. **저장용 리스트** – 피벗보다 작은/큰 원소를 두 개의 별도 리스트에 분리한다.  
5. **반복** – 피벗을 제외한 각 원소를 분할 기준에 따라 두 리스트에 넣는다.  
6. **재귀 호출 + 합치기** – 분리된 리스트들을 재귀적으로 정렬하고,  
   정렬된 `less` + `pivot` + 정렬된 `greater` 를 순서대로 연결해 최종 결과를 만든다.  

필요에 따라 피벗 선택 방식을 바꾸거나 (예: median‑of‑three),  
분할 기준을 더 빠르게 하기 위해 인-플레이스(원본 배열 자체를 재배열) 버전을 만들 수도 있습니다.
