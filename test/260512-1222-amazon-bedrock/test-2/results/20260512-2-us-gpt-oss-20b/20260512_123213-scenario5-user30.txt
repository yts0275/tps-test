아래는 파이썬으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
**각 코드 행 뒤에 한 줄씩 주석을 달아 동작 방식을 자세히 설명했습니다.**

```python
# --------------------------------------------
# 파이썬으로 구현한 퀵소트(QuickSort) 함수
# --------------------------------------------

def quicksort(arr, left, right):
    """
    먼저 인덱스 범위가 1개 이하이면 소팅이 끝난 것이므로 반환한다.
    이 함수는 재귀적으로 자신을 호출하면서 분할 정복을 수행한다.
    """
    # 1. 종료 조건: left가 right보다 크거나 같으면 더 이상 분할할 필요 없음
    if left >= right:                # 종료 조건: 구간이 유효하지 않음
        return

    # 2. 피봇 선택: 보통 가장 오른쪽(혹은 가운데) 원소를 선택
    pivot = arr[right]                # 피봇 값 저장

    # 3. 피봇보다 작은 값과 큰 값을 나누는 인덱스 초기화
    i = left - 1                      # i는 "작은 값" 구간의 마지막 인덱스를 가리킴

    # 4. array[left] ~ array[right-1] 까지 순회
    for j in range(left, right):      # j는 현재 검사 중인 인덱스
        # 5. 현재 원소가 피봇보다 작으면
        if arr[j] <= pivot:           # 작은 값이면 i를 증가시키고 i와 j 위치 교환
            i += 1                    # i를 다음 작은 값 위치로 이동
            arr[i], arr[j] = arr[j], arr[i]  # i 와 j 사이의 원소 교환

    # 6. 마지막에 피봇을 적절한 위치에 삽입
    arr[i+1], arr[right] = arr[right], arr[i+1]  # i+1이 피봇이 들어갈 위치

    # 7. 피봇이 놓인 인덱스를 반환(재귀 호출 시 기준점)
    pivot_index = i + 1

    # 8. 피봇을 기준으로 왼쪽과 오른쪽 구간에 대해 재귀적으로 퀵소트 호출
    quicksort(arr, left, pivot_index - 1)   # 피봇 왼쪽 구간 정렬
    quicksort(arr, pivot_index + 1, right)  # 피봇 오른쪽 구간 정렬

# --------------------------------------------
# 사용 예시
# --------------------------------------------
if __name__ == "__main__":
    # 예제 배열
    sample = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", sample)

    # 퀵소트 호출 (전체 범위: 0 ~ len-1)
    quicksort(sample, 0, len(sample) - 1)

    print("정렬 후 :", sample)
```

### 주요 포인트
1. **피봇(pivot) 선택**  
   - 가장 오른쪽 원소를 피봇으로 사용합니다(`arr[right]`).  
   - 다른 전략(가운데, 랜덤 등)도 가능하지만, 가장 단순한 구현은 바로 이와 같습니다.

2. **분할 단계**  
   - `i` 는 피봇보다 작거나 같은 값을 모두 왼쪽에 모으는 인덱스입니다.  
   - `j` 를 순회하면서 `arr[j] <= pivot` 이면 `i` 를 한 칸씩 앞당겨 교환합니다.

3. **피봇 위치 지정**  
   - 통상적인 구현에서는 피봇을 `i+1` 위치에 두어 정렬된 배열을 만듭니다.

4. **재귀 호출**  
   - 피봇을 기준으로 왼쪽과 오른쪽 구간을 각각 재귀적으로 소팅합니다.  
   - 재귀 종료 조건(`left >= right`)이 포함되어 있기 때문에 무한 루프가 발생하지 않습니다.

5. **정합성 확인**  
   - 주어진 예시에서 `sample` 배열을 정렬하면 `[1, 1, 2, 3, 6, 8, 10]` 이 됩니다.

위 코드에서 각 줄마다 설명이 달려 있으므로 로직 이해가 어려운 부분 없이 빠르게 따라오실 수 있을 것입니다. 필요에 따라 피봇 선택 전략이나 인덱스 처리 방식을 변형해 보태면, 다양한 퀵소트 변형을 손쉽게 익힐 수 있습니다.
