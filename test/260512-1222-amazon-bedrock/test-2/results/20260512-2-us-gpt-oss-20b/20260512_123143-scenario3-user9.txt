아래는 **Python**으로 작성한 QuickSort(퀵소트) 구현입니다.  
코드의 각 줄마다 한국어 주석을 달아 이해를 돕도록 했습니다.

```python
# quicksort.py
# -----------------------------------------------------------

def quick_sort(arr, low, high):
    """
    QuickSort(퀵소트)를 재귀적으로 수행하는 함수
    :param arr: 정렬하고자 하는 리스트
    :param low: 현재 서브리스트의 시작 인덱스
    :param high: 현재 서브리스트의 끝 인덱스
    """
    if low < high:                     # 1. 기준: 시작 인덱스가 끝 인덱스보다 작다면
        pivot_index = partition(arr, low, high)  # 2. 두 번째: 파티션 함수 호출, 피벗 인덱스 반환
        quick_sort(arr, low, pivot_index - 1)    # 3. 두 번째(재귀): 피벗 왼쪽 부분 재정렬
        quick_sort(arr, pivot_index + 1, high)   # 4. 두 번째(재귀): 피벗 오른쪽 부분 재정렬

def partition(arr, low, high):
    """
    파티션(분할) 단계: 피벗을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽으로 나누는 함수
    :param arr: 정렬하고자 하는 리스트
    :param low: 파티션 시작 인덱스
    :param high: 파티션 끝 인덱스
    :return: 피벗이 위치한 인덱스
    """
    pivot = arr[high]                   # 5. 피벗 선택(마지막 요소를 사용)
    i = low - 1                         # 6. i는 작은 값이 모여있는 영역의 끝 인덱스

    for j in range(low, high):          # 7. j는 현재 검사하고 있는 인덱스
        if arr[j] <= pivot:             # 8. 현재 값이 피벗보다 작거나 같다면
            i += 1                     #    9. 작은 영역의 끝 인덱스를 한 칸 앞당김
            arr[i], arr[j] = arr[j], arr[i]  # 10. 작은 영역과 현재 값을 스왑

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 11. 마지막으로 피벗을 적절한 위치에 스왑
    return i + 1                                    # 12. 피벗 인덱스를 반환

# -----------------------------------------
# 힌트: 아래 코드를 사용하여 QuickSort를 직접 실행해 볼 수 있습니다.
# -----------------------------------------
if __name__ == "__main__":
    sample = [10, 7, 8, 9, 1, 5]     # 13. 예시 리스트
    n = len(sample)                  # 14. 리스트 길이
    quick_sort(sample, 0, n - 1)    # 15. QuickSort 호출
    print("정렬된 리스트:", sample) # 16. 결과 출력
```

> **설명**  
> 1. `quick_sort` 함수는 재귀적으로 피벗을 기준으로 왼쪽·오른쪽 서브리스트를 정렬한다.  
> 2. `partition` 함수는 피벗을 기준으로 리스트를 두 부분으로 나누며, 피벗이 최종 위치에 오도록 한다.  
> 3. 도입부의 `if __name__ == "__main__":` 블럭은 모듈로서 직접 실행될 때 예시 리스트를 정렬해 보여준다.  

이 코드를 그대로 실행하면 다음과 같이 정렬된 결과를 얻을 수 있다.

```
정렬된 리스트: [1, 5, 7, 8, 9, 10]
```
