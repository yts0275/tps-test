아래는 파이썬으로 작성한 퀵소트(Quick Sort) 구현 예시입니다.  
각 코드 라인마다 **주석을 달아 상세히 설명**합니다.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

# ----------------------------------------------
# 퀵소트(Quick Sort) 구현
# ----------------------------------------------

def quicksort(arr, low, high):
    """
    리스트 arr의 subarray arr[low:high+1]을 오름차순으로 정렬합니다.
    재귀적으로 호출됩니다.
    """
    # 1. low가 high보다 크면 (인덱스 범위가 비어 있으면) 종료
    if low < high:
        # 2. 피벗 분할: 배열의 한 항을 피벗으로 선택하고
        #    피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽에 배치
        pivot_index = partition(arr, low, high)
        # 3. 피벗 앞부분과 뒷부분 각각 재귀적으로 정렬
        quicksort(arr, low, pivot_index - 1)
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    """
    피벗(여기서는 가장 오른쪽 항)을 기준으로 subarray을 나누어
    피벗보다 작은 값들은 왼쪽, 큰 값들은 오른쪽에 배치합니다.
    최종적으로 피벗이 정렬된 위치(index)를 반환합니다.
    """
    # 4. 피벗은 가장 오른쪽 원소
    pivot = arr[high]
    # 5. 작은 원소를 저장할 인덱스: 처음은 low-1 (아직 작은 원소 없음)
    i = low - 1

    # 6. low부터 high-1까지 반복하며 피벗보다 작은 원소가 나오면
    #    i를 증가시키고 arr[i]와 현재 원소를 교환
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1              # 작은 원소 저장 위치 이동
            arr[i], arr[j] = arr[j], arr[i]  # swap

    # 7. 피벗을 잘못된 부분이 아닌 정렬된 위치에 넣음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 8. 피벗의 최종 위치 반환
    return i + 1

def main():
    """
    표준 입력으로부터 배열을 받아 퀵소트를 수행하고
    정렬된 결과를 표준 출력에 출력합니다.
    입력 포맷:
        첫 줄: 배열의 길이 N
        둘째 줄: N개의 정수 (공백으로 구분)
    """
    import sys

    # 9. 표준 입력에서 모든 줄 읽어 들이기
    data = sys.stdin.read().strip().split()
    if not data:
        return

    # 10. 첫 번째 값은 배열 길이 N (필수는 아님)
    n = int(data[0])
    # 11. 나머지 값들을 정수 리스트로 변환
    arr = list(map(int, data[1:n+1]))

    # 12. 배열 정렬 (인덱스 범위 low=0, high=len(arr)-1)
    quicksort(arr, 0, len(arr) - 1)

    # 13. 정렬된 배열을 공백으로 구분해 출력
    print(' '.join(map(str, arr)))

if __name__ == "__main__":
    # 14. 스크립트 실행 시 main() 호출
    main()
```

### 사용 예시

```
$ echo -e "7\n3 7 8 5 2 1 9" | python3 quicksort.py
1 2 3 5 7 8 9
```

위 코드처럼 **모든 줄에 주석**을 달아 구현해 두었으니,  
가독성 뿐 아니라 각 단계가 무슨 일을 하는지 명확히 확인할 수 있습니다.
