```python
def quick_sort(arr):
    # 입력 배열의 길이가 0이거나 1이면 이미 정렬돼 있으므로 그대로 반환한다.
    if len(arr) <= 1:
        return arr    # 정렬이 끝난 배열을 돌려준다.

    # 배열의 중간 원소를 피벗(pivot)으로 선택한다.
    pivot = arr[len(arr) // 2]      # 중간 인덱스의 값

    # 피벗보다 작은 값을 모아 새로운 리스트 left 생성
    left = [x for x in arr if x < pivot]
    # 피벗과 같은 값을 모아 새로운 리스트 middle 생성
    middle = [x for x in arr if x == pivot]
    # 피벗보다 큰 값을 모아 새로운 리스트 right 생성
    right = [x for x in arr if x > pivot]

    # left, right 를 재귀적으로 정렬한 뒤, left + middle + right 를 합쳐 반환한다.
    return quick_sort(left) + middle + quick_sort(right)   # 재귀 정렬 결과를 연결
```

이 코드는 매줄마다 주석을 달아서 각 단계가 어떤 역할을 하는지 명확히 보여줍니다.  
사용 예시:

```python
if __name__ == "__main__":
    nums = [24, 5, 3, 99, 10, 6, 18, 45]
    sorted_nums = quick_sort(nums)
    print("정렬된 결과:", sorted_nums)
```
