아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
코드의 **각 줄마다** 주석을 달아 이해하기 쉽게 설명했습니다.  

```python
# 파이썬으로 키워드 즉, 인덱스 기반 재귀 퀵소트 구현
# (배열을 바로 치환하며 정렬합니다)
def quicksort(arr, low, high):            # 1. 재귀 정렬 함수 정의(배열, 시작 인덱스, 끝 인덱스)
    if low < high:                        # 2. 시작 인덱스가 끝 인덱스보다 작아야 재귀 진행
        pivot_index = partition(arr, low, high)   # 3. 파티션 함수 호출: 피벗 위치 반환
        quicksort(arr, low, pivot_index - 1)   # 4. 왼쪽 부분 배열 재귀 정렬
        quicksort(arr, pivot_index + 1, high)   # 5. 오른쪽 부분 배열 재귀 정렬

def partition(arr, low, high):            # 6. 파티션 함수 정의(배열, 시작 인덱스, 끝 인덱스)
    pivot = arr[high]                    # 7. 마지막 원소를 피벗으로 지정
    i = low - 1                          # 8. 피벗보다 작은 값들의 마지막 위치를 가리키는 인덱스 초기화
    for j in range(low, high):           # 9. 시작 인덱스부터 끝 인덱스 전까지 반복
        if arr[j] <= pivot:              #10. 현재 원소가 피벗 이하일 경우
            i += 1                     #11. i를 한 칸 오른쪽으로 이동시켜 새로운 위치 확보
            arr[i], arr[j] = arr[j], arr[i]  #12. i와 j 위치의 원소 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  #13. 피벗을 올바른 위치( i+1 )에 삽입
    return i + 1                     #14. 피벗이 최종 배치된 인덱스를 반환

def quicksort_wrapper(arr):            #15. 사용자가 바로 호출할 래퍼 함수 정의
    quicksort(arr, 0, len(arr) - 1)   #16. 재귀 정렬 시작: 전체 배열 범위 지정
    return arr                        #17. 정렬된 배열 반환

# 사용 예시(테스트용)
if __name__ == "__main__":           #18. 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]  #19. 테스트용 데이터 배열 생성
    print("정렬 전:", sample)         #20. 정렬 전 배열 출력
    quicksort_wrapper(sample)         #21. 퀵소트 함수 호출
    print("정렬 후:", sample)         #22. 정렬 후 배열 출력
```

### 핵심 포인트
- **피벗 선택**: 가장 오른쪽 원소를 피벗으로 사용합니다.  
- **in-place**: 배열을 직접 치환하기 때문에 별도의 메모리 사용이 최소화됩니다.  
- **재귀**: 피벗을 기준으로 왼쪽·오른쪽 부분 배열을 각각 정렬합니다.  
- **로직**: `partition` 함수가 피벗 위치를 정해주면, 그 위치를 기준으로 정렬이 진행됩니다.  

이 코드 블럭을 그대로 복사해서 실행하면, `sample` 배열이 정렬되는 것을 확인할 수 있습니다. 파이썬의 `range`와 튜플 스왑(`arr[i], arr[j] = arr[j], arr[i]`)을 이용해 간결하게 작성했습니다. 필요하면 다른 피벗 전략(예: 중앙값)으로 바꾸어 성능을 조절할 수도 있습니다.
