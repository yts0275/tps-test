아래는 파이썬으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
모든 줄에 한글 주석을 달아, 러닝 항목(각 줄이 수행하는 일)을 명확히 했습니다.

```python
def quicksort(arr):                                          # arr 배열을 입력받는 재귀 함수 정의
    if len(arr) <= 1:                                        # 배열 길이가 1 이하이면 정렬이 끝난 상태
        return arr                                            # 그대로 반환하고 재귀 종료

    pivot = arr[len(arr) // 2]                               # 가운데 요소를 피벗으로 선택 (안정된 평균 위치)
    
    left = [x for x in arr if x < pivot]                     # 피벗보다 작은 값들만 모음
    middle = [x for x in arr if x == pivot]                  # 피벗과 같은 값들만 모음
    right = [x for x in arr if x > pivot]                    # 피벗보다 큰 값들만 모음
    
    return quicksort(left) + middle + quicksort(right)       # 재귀 호출로 정렬된 리스트를 합쳐 반환

# ----------------- 사용 예시 -----------------
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                          # 예시 배열
    sorted_list = quicksort(sample)                          # 퀵소트 호출
    print("정렬 전: ", sample)                               # 원본 배열 출력
    print("정렬 후: ", sorted_list)                          # 정렬된 배열 출력
```

**설명**  

1. `quicksort` 함수는 입력 배열 `arr`을 인수로 받고 재귀적으로 동작합니다.  
2. 배열 길이가 0 또는 1인 경우에는 이미 정렬이 끝났으므로 그대로 반환합니다.  
3. 피벗을 배열의 바로 가운데 요소(`len(arr)//2`) 로 선택합니다. 이는 평균적인 분할을 목표로 합니다.  
4. 리스트 내포를 이용해 피벗보다 작은 값(`left`), 피벗과 같은 값(`middle`), 피벗보다 큰 값(`right`)을 각각 새로운 리스트에 모읍니다.  
5. `left`와 `right`에 대해 같은 과정을 재귀 호출해 재귀 트리의 깊이를 채운 뒤,  
   `quicksort(left) + middle + quicksort(right)` 형태로 결합하여 정렬된 배열을 반환합니다.  

이 구현은 불변성을 유지하며, 파이썬 표준 리스트 복사와 가중치가 적은 리스트내포를 사용해 가독성이 좋습니다.  
필요에 따라 인덱스를 직접 조작해 원본 배열을 원자적으로 정렬하도록 변형할 수 있지만, 이 예시는 가장 단순하고 이해하기 쉬운 형태로 제공됩니다.
