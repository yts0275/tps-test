```python
def quicksort(arr):                      # ① 함수 정의 : 정렬할 리스트를 인자로 받는다
    if len(arr) <= 1:                    # ② 기저 조건 : 리스트가 비었거나 원소가 하나이면 이미 정렬된 상태
        return arr                       # ③ 리스트 그대로 반환 (방문 후 재귀 종료)
    pivot = arr[-1]                      # ④ 피벗 선택 : 리스트의 마지막 원소를 기준값으로 정한다
    left = []                            # ⑤ 피벗보다 작은 원소를 담을 리스트 초기화
    right = []                           # ⑥ 피벗보다 큰 원소를 담을 리스트 초기화
    for num in arr[:-1]:                 # ⑦ 피벗을 제외한 나머지 원소를 순회
        if num <= pivot:                 # ⑧ 피벗보다 작거나 같은 경우
            left.append(num)             # ⑨ 왼쪽 리스트에 추가
        else:                            # ⑩ 피벗보다 큰 경우
            right.append(num)            # ⑪ 오른쪽 리스트에 추가
    return quicksort(left) + [pivot] + quicksort(right)  # ⑫ 재귀 호출로 왼쪽·오른쪽을 정렬한 뒤 피벗을 삽입해 합친다
```

> 각 줄에 한글 주석을 달아 QuickSort 로직을 한눈에 파악할 수 있습니다.  
> 사용 예시: `sorted_list = quicksort([3, 6, 8, 10, 1, 2, 1])`  
> 이렇게 하면 `sorted_list` 가 `[1, 1, 2, 3, 6, 8, 10]` 으로 정렬됩니다.
