아래는 **Python** 으로 구현한 퀵소트(QuickSort) 예제입니다.  
코드의 각 줄마다 한 줄씩 주석을 달아 구현 흐름을 이해하기 쉽게 했습니다.

```python
# ----------------------------------------------
# 1. 퀵소트 알고리즘 구현 (in‑place, 재귀적 구현)
# ----------------------------------------------

def quicksort(arr, low, high):
    """
    2. 재귀적으로 정렬을 수행하는 퀵소트 함수.
       - arr: 정렬 대상 리스트
       - low: 현재 서브 배열의 시작 인덱스
       - high: 현재 서브 배열의 끝 인덱스
    """
    if low < high:  # 3. 서브 배열이 1개 이하일 때 재귀 종료 조건
        pivot_index = partition(arr, low, high)  # 4. 피벗 위치 찾기
        # 5. 피벗을 기준으로 왼쪽 부분과 오른쪽 부분을 다시 정렬
        quicksort(arr, low, pivot_index - 1)     # 6. 피벗 왼쪽 구간 재귀 정렬
        quicksort(arr, pivot_index + 1, high)    # 7. 피벗 오른쪽 구간 재귀 정렬

def partition(arr, low, high):
    """
    8. 피벗을 기준으로 구간을 분할하는 함수.
       - pivot: 보통 고정한 인덱스(여기서는 가장 오른쪽)를 선택
       - i: 작은 값이 모여갈 위치 인덱스
    """
    pivot = arr[high]          # 9. 가장 오른쪽 요소를 피벗으로 선택
    i = low - 1                # 10. i를 low-1 로 초기화 (작은 값 들어갈 위치)
    
    for j in range(low, high):  # 11. low 부터 high-1 까지 순회
        if arr[j] <= pivot:     # 12. 피벗보다 작거나 같은 값이면
            i += 1              # 13. 작은 값 들어갈 위치 증가
            arr[i], arr[j] = arr[j], arr[i]  # 14. 값 교환 (i와 j)

    # 15. 마지막으로 피벗을 올바른 위치에 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 16. 피벗 교환
    return i + 1          # 17. 피벗의 최종 인덱스 반환

# ----------------------------------------------
# 18. 사용 예
# ----------------------------------------------
if __name__ == "__main__":
    sample = [10, 7, 8, 9, 1, 5]  # 19. 정렬할 리스트 생성
    quicksort(sample, 0, len(sample) - 1)  # 20. 퀵소트 실행
    print("정렬된 결과:", sample)  # 21. 결과 출력
```

### 코드 흐름 요약
1. `quicksort` 함수는 `low`와 `high` 인덱스로 정해진 구간을 재귀적으로 분할합니다.  
2. `partition` 함수는 가장 오른쪽 요소를 피벗으로 하여, 그보다 작은 값은 앞쪽에 모이도록 배열을 섞고 피벗을 올바른 위치에 옮깁니다.  
3. 피벗을 기준으로 왼쪽과 오른쪽 구간을 다시 정렬하면서 전체 배열이 정렬됩니다.  

제공한 예시를 그대로 실행하면 `정렬된 결과: [1, 5, 7, 8, 9, 10]` 가 출력됩니다. 필요에 따라 피벗 선택 방식을 바꾸거나 입력에 대해 루프 기반 구현으로 바꿀 수도 있습니다.
