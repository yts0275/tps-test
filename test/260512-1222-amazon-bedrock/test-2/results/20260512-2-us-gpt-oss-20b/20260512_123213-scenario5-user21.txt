아래는 파이썬으로 구현한 퀵소트(Quick Sort) 예시입니다.  
**각 줄 끝에 한국어 주석이 달려 있으니, 코드 한 줄마다 무엇을 하는지 바로 확인하실 수 있습니다**.

```python
def quicksort(arr):                                   # 1. quicksort 함수 정의(정렬하려는 리스트를 인자 받음)
    if len(arr) <= 1:                                 # 2. 리스트 길이가 1 이하이면 이미 정렬됨(기저 사례)
        return arr                                   # 3. 리스트 그대로 반환
    pivot = arr[len(arr) // 2]                        # 4. 리스트의 중간 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 5. 피벗보다 작은 원소들만 모아 새 리스트 생성
    middle = [x for x in arr if x == pivot]           # 6. 피벗과 같은 원소들만 모아 새 리스트 생성
    right = [x for x in arr if x > pivot]             # 7. 피벗보다 큰 원소들만 모아 새 리스트 생성
    return quicksort(left) + middle + quicksort(right)  # 8. 재귀적으로 왼쪽과 오른쪽을 정렬하고 합쳐 반환
```

### 사용 예시
```python
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]
    sorted_list = quicksort(sample)   # 9. quicksort 호출
    print(sorted_list)                # 10. 정렬 결과 출력
```

이 구현은 재귀 호출을 이용해 입력 리스트를 분할하고, 각 분할을 다시 정렬한 뒤 합치는 방식으로 동작합니다.  
시간 복잡도는 평균적으로 `O(n log n)`이며, 최악의 경우(이미 정렬된 입력)에 `O(n²)`이 될 수 있습니다.  
`pivot`을 중간 인덱스(또는 무작위 인덱스)로 선택하면 이러한 최악의 경우를 피하는데 도움이 됩니다.
