아래는 파이썬으로 작성한 **퀵소트(Quick Sort)** 예시입니다.  
코드의 **모든 줄**에 한 줄씩 주석(한국어)을 달아, 각 줄이 어떤 일을 하는지 명확히 설명했습니다.  

```python
def quicksort(arr): 
    # 배열이 0개 또는 1개이면 이미 정렬이 완료된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 가장 마지막 원소를 피벗(pivot)으로 선택
    pivot = arr[-1]

    # 피벗보다 작거나 같은 원소들만 모아 'left' 리스트를 만든다
    left = [x for x in arr[:-1] if x <= pivot]

    # 피벗보다 큰 원소들만 모아 'right' 리스트를 만든다
    right = [x for x in arr[:-1] if x > pivot]

    # 재귀적으로 left와 right를 정렬한 뒤, 피벗을 끼워서 합친다
    return quicksort(left) + [pivot] + quicksort(right)

# --------------------------------------------------------------------
# 아래 코드는 퀵소트 함수를 실제로 호출해 동작을 확인하기 위한 예시입니다.

sample = [34, 7, 23, 32, 5, 62]      # 정렬되지 않은 예시 리스트
print("원본 리스트:", sample)          # 원본 리스트 출력

sorted_list = quicksort(sample)      # 퀵소트로 정렬
print("정렬된 리스트:", sorted_list)   # 정렬 결과 출력
```

### 코드 설명
1. **`quicksort` 함수**  
   - 재귀적으로 배열을 작은 부분 배열로 나누어 정렬합니다.  
   - 피벗으로 배열의 마지막 원소를 사용했고, 그 기준으로 `left`와 `right` 두 부분 배열을 생성합니다.  
   - 각 부분 배열은 다시 `quicksort`를 호출해 정렬된 뒤, 피벗 원소와 함께 재조합됩니다.  

2. **예시 실행**  
   - `sample` 리스트를 그대로 사용해 정렬 전후를 비교합니다.  
   - `print` 문을 통해 결과를 시각적으로 확인할 수 있습니다.  

이제 각 줄마다 무엇을 하는지 한눈에 들어오며, 퀵소트의 기본 원리는 쉽게 이해할 수 있을 것입니다.
