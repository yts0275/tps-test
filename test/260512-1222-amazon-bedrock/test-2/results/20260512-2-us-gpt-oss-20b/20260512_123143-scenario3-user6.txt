아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
**각 줄 끝에 한글 주석을 달아 동작을 설명**했습니다.  

```python
def quicksort(arr):
    # 퀵소트 함수: 주어진 리스트 arr을 정렬된 형태로 반환합니다.
    
    if len(arr) <= 1:
        # 기저 조건: 리스트가 0개 또는 1개 원소일 경우 이미 정렬되어 있으므로 그대로 반환합니다.
        return arr
    
    pivot = arr[-1]
    # 피벗을 리스트의 마지막 원소로 선택합니다.
    
    lower = [x for x in arr[:-1] if x <= pivot]
    # 피벗보다 작거나 같은 원소들을 모아 lower 리스트에 저장합니다.
    
    higher = [x for x in arr[:-1] if x > pivot]
    # 피벗보다 큰 원소들을 모아 higher 리스트에 저장합니다.
    
    # lower 리스트와 higher 리스트에 재귀적으로 퀵소트를 수행한 뒤, pivot을 중간에 삽입해 최종 정렬 결과를 반환합니다.
    return quicksort(lower) + [pivot] + quicksort(higher)

# 예시 실행
data = [3, 6, 8, 10, 1, 2, 1]
sorted_data = quicksort(data)
print(sorted_data)   # 출력: [1, 1, 2, 3, 6, 8, 10]
```

### 코드 흐름 요약  
1. **기저 조건**: 길이가 ≤ 1인 리스트는 정렬 필요 없음.  
2. **피벗 선택**: 마지막 원소를 피벗으로 사용.  
3. **분할**: 피벗 이하와 초과 두 리스트(`lower`, `higher`) 분리.  
4. **재귀 호출**: `lower`와 `higher`에 각각 퀵소트 적용.  
5. **결합**: 정렬된 `lower` + `[pivot]` + 정렬된 `higher`를 합쳐 최종 리스트 반환.  

필요에 따라 피벗 선택 방식을 바꾸거나 인‑플레이스(in‑place) 변형(메모리 절약형)으로 구현할 수도 있습니다.
