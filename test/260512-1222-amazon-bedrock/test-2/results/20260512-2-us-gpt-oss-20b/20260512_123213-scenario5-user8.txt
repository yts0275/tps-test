아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘입니다.  
각 줄마다 한 줄씩 주석을 달아 이해를 돕도록 했습니다.  

```python
# ------------------------------------------------------------
# 퀵소트(QuickSort) 구현 예시 (in‑place)
# low : 배열의 시작 인덱스
# high: 배열의 끝 인덱스
# ------------------------------------------------------------
def quick_sort(arr, low, high):
    # 종속조건(리턴 조건): 범위가 1개 이하이면 바로 리턴
    if low < high:
        # 피벗(구분자)를 기준으로 파티션 처리 후 인덱스 반환
        pi = partition(arr, low, high)
        # 피벗 왼쪽 부분에 대해 재귀적으로 퀵소트 수행
        quick_sort(arr, low, pi - 1)
        # 피벗 오른쪽 부분에 대해 재귀적으로 퀵소트 수행
        quick_sort(arr, pi + 1, high)


# ------------------------------------------------------------
# 파티션 함수: 피벗보다 작은 원소는 왼쪽, 큰 원소는 오른쪽에 배치
# ------------------------------------------------------------
def partition(arr, low, high):
    # 배열의 끝 원소를 피벗으로 사용
    pivot = arr[high]
    # i는 피벗보다 작은 원소가 끝나는 인덱스
    i = low - 1
    # j는 현재 검사 중인 인덱스
    for j in range(low, high):
        # 현재 원소가 피벗보다 작으면 i를 한 칸 옮기고 스왑
        if arr[j] < pivot:
            i += 1            # i가 한 칸 앞으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # i번째와 j번째 원소 교환
    # 마지막으로 피벗을 올바른 위치( i+1 )에 넣음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 그려진 인덱스를 반환
    return i + 1


# ------------------------------------------------------------
# 테스트용 예시
# ------------------------------------------------------------
if __name__ == "__main__":
    # 정렬할 배열 예제
    sample = [10, 7, 8, 9, 1, 5]
    # 배열 길이를 기준으로 high 인덱스 지정
    n = len(sample)
    # 퀵소트 호출 (인덱스 범위 : 0 ~ n-1)
    quick_sort(sample, 0, n - 1)
    # 정렬 결과 출력
    print("정렬된 배열:", sample)
```

**주요 포인트**  
1. `quick_sort` 함수는 재귀적으로 호출되며, 각 호출마다 파티션을 통해 배열을 두 부분으로 나눈다.  
2. `partition` 함수는 피벗을 기준으로 왼쪽(작은 값)과 오른쪽(큰 값)으로 분리하고, 피벗이 올바른 위치에 오도록 스왑한다.  
3. 인덱스 `low`와 `high`를 명시적으로 전달해 in‑place(공간 효율적) 정렬을 수행한다.  

위 예제를 그대로 실행하면 `정렬된 배열: [1, 5, 7, 8, 9, 10]`가 출력됩니다. 필요에 맞게 파티션 전략(피벗 선택 방식 등)을 바꾸면 추가적인 최적화가 가능하니, 원하는 대로 실험해 보세요!
