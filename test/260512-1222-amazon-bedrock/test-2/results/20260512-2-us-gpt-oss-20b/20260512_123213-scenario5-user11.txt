아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 로, 코드의 각 줄마다 한 줄씩 주석을 달아 이해를 돕도록 했습니다.  
(인덱스 기반으로 불변의 원래 리스트를 **in‑place** 방식으로 정렬합니다.)

```python
# 정렬하고자 하는 리스트에 대해 외부에서 호출할 함수
def quicksort(arr):                                                       # 1. 정렬 기능을 캡슐화한 외부 호출 함수 정의
    _quicksort(arr, 0, len(arr) - 1)                                      # 2. 내부 재귀 함수에 전체 범위(0~len-1)를 전달하여 정렬 시작

# 실제 재귀적인 정렬을 수행하는 내부 함수
def _quicksort(arr, left, right):                                         # 3. 왼쪽과 오른쪽 인덱스를 받아 재귀 정렬을 구현
    if left < right:                                                      # 4. 왼쪽 인덱스가 오른쪽 인덱스보다 작을 때만 정렬 진행
        pivot_index = _partition(arr, left, right)                        # 5. 파티션을 수행하고 피벗의 최종 인덱스를 반환받음
        _quicksort(arr, left, pivot_index - 1)                            # 6. 피벗 왼쪽 서브어레이를 재귀 정렬
        _quicksort(arr, pivot_index + 1, right)                           # 7. 피벗 오른쪽 서브어레이를 재귀 정렬

# 배열을 파티션(분할)시켜 피벗을 기준으로 왼쪽은 <= 피벗, 오른쪽은 > 피벗이 되도록 정렬
def _partition(arr, left, right):                                          # 8. 파티션 기능을 담당하는 내부 함수 정의
    pivot = arr[right]                                                    # 9. 가장 오른쪽 원소를 피벗으로 선택
    i = left - 1                                                          # 10. i는 <= 피벗을 가진 원소의 마지막 인덱스를 가리킴
    for j in range(left, right):                                          # 11. 왼쪽부터 오른쪽 바로 전까지 순회
        if arr[j] <= pivot:                                               # 12. 현재 원소가 피벗보다 작거나 같으면
            i += 1                                                       # 13. i를 한 칸 우측으로 이동
            arr[i], arr[j] = arr[j], arr[i]                              # 14. arr[i]와 arr[j]를 교환해 <= 피벗 인덱스 앞에 위치
    arr[i + 1], arr[right] = arr[right], arr[i + 1]                       # 15. 피벗을 i+1 위치(정렬 된 < 피벗 영역 바로 뒤)에 위치시켜 교환
    return i + 1                                                          # 16. 피벗이 최종적으로 위치한 인덱스를 반환
```

#### 사용 예시
```python
if __name__ == "__main__":
    data = [34, 2, 78, 1, 56, 99, 73, 5]                # 17. 정렬하고자 하는 예시 리스트
    print("정렬 전:", data)                            # 18. 원본 리스트 출력
    quicksort(data)                                    # 19. quicksort 함수 호출
    print("정렬 후:", data)                            # 20. 정렬이 완료된 리스트 출력
```

*주석은 모두 한 줄씩 덧붙여서 **각 줄**이 어떤 역할을 수행하는지 명확히 해두었습니다.*  
필요에 따라 다른 프로그래밍 언어나 비공식적 방식을 적용하려면 알려 주시면 그에 맞게 재구성해 드리겠습니다.
