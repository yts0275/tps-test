아래는 **Python** 으로 작성한 퀵소트(QuickSort) 구현입니다.  
각 코드 줄마다 주석을 달아 무엇을 하는 지 한눈에 이해할 수 있도록 했습니다.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
퀵소트 구현 예제
- 배열이 비어 있거나 한 개의 원소만 있을 때: 이미 정렬이 끝난 것으로 가정
- 피벗(pivot)을 배열 마지막 원소로 선택
- 피벗을 기준으로 왼쪽(작은값) / 오른쪽(큰값)으로 분할
- 재귀적으로 왼쪽·오른쪽 부분 리스트를 정렬
"""

def quicksort(arr):
    """
    주어진 리스트를 퀵소트(quick sort) 알고리즘으로 정렬한다.
    :param arr: 정렬 대상 리스트(수정됨)
    :return: 정렬된 리스트 (arr 와 동일 객체)
    """
    # 배열의 길이가 0 또는 1이면 이미 정렬이 끝난 것이므로 그대로 리턴
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 배열 마지막 원소
    pivot = arr[-1]

    # 피벗보다 작은 원소들(왼쪽)과 큰 원소들(오른쪽)을 저장할 리스트
    left = []   # 왼쪽(작은 값)
    right = []  # 오른쪽(큰 값)

    # 피벗을 제외한 모든 원소에 대해 비교
    for x in arr[:-1]:
        if x <= pivot:           # 현재 원소가 피벗보다 작거나 같으면 left에 넣음
            left.append(x)
        else:                    # 그렇지 않으면 right에 넣음
            right.append(x)

    # 왼쪽, 피벗, 오른쪽을 순서대로 재조합하고, left와 right를 재귀적으로 정렬
    # 재귀 호출로 left와 right를 각각 정렬한 뒤, 결과 리스트를 합침
    return quicksort(left) + [pivot] + quicksort(right)

# ---------------- 예시 실행 ----------------
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", sample)
    sorted_list = quicksort(sample.copy())  # 해당 함수는 입력 리스트를 그대로 수정하지 않음
    print("정렬 후 :", sorted_list)
```

### 코드 설명
- **`quicksort(arr)`**:  
  `arr`이 0개 또는 1개의 요소를 가질 때 바로 반환하고,  
  그렇지 않으면 가장 끝 원소를 피벗으로 사용해 `left`와 `right` 두 리스트로 분할합니다.  
  재귀적으로 `left`와 `right`를 정렬한 뒤, `pivot`과 함께 합쳐서 반환합니다.

- **`if __name__ == "__main__":`**:  
  스크립트가 직접 실행될 때 예시 배열을 정렬해 출력합니다.  
  `sample.copy()`를 사용해 원본 배열은 그대로 두고 정렬 결과를 확인합니다.

이 구현은 재귀 호출에 기반해 엘리먼트 수가 많아지면 스택 오버플로우가 발생할 수 있으므로,  
실제 대규모 데이터 처리에는 삽입-선택 및 반복 버전 또는 `itertools`와 같은 최적화가 필요할 수 있습니다.
