아래는 Python으로 구현한 **퀵소트(Quick Sort)** 예시입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 달아두었으니, 코드를 읽으며 알고리즘 흐름을 따라가 보세요.

```python
def quick_sort(arr):
    """퀵소트 함수: 주어진 리스트 arr를 정렬해서 새 리스트로 반환한다."""
    
    # 1️⃣ 기본 탈출 조건: 리스트 길이가 1 이하이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                                 # 리스트가 비었거나 원소가 하나이면 그대로 반환
    
    # 2️⃣ 피벗 선택: 여기서는 리스트의 마지막 요소를 피벗으로 잡는다
    pivot = arr[-1]                                 # 피벗은 정렬 기준이 되는 원소
    
    # 3️⃣ 피벗보다 작은(또는 같은) 원소들을 모을 리스트
    left = []                                       # 피벗보다 작거나 같은 값들을 저장할 리스트
    # 4️⃣ 피벗보다 큰 원소들을 모을 리스트
    right = []                                      # 피벗보다 큰 값들을 저장할 리스트
    
    # 5️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left / right에 분류한다
    for element in arr[:-1]:                        # 마지막 원소(피벗)를 제외한 모든 원소에 대해
        if element <= pivot:                        # 현재 원소가 피벗보다 작거나 같으면
            left.append(element)                    # left 리스트에 추가
        else:                                       # 현재 원소가 피벗보다 크면
            right.append(element)                   # right 리스트에 추가
    
    # 6️⃣ 재귀 호출: left와 right 부분을 각각 다시 퀵소트한다
    sorted_left = quick_sort(left)                 # left 부분을 정렬
    sorted_right = quick_sort(right)               # right 부분을 정렬
    
    # 7️⃣ 정렬된 결과 합치기: left + 피벗 + right 순서대로 연결한다
    return sorted_left + [pivot] + sorted_right     # 최종 정렬된 리스트 반환
```

### 코드 흐름 요약
1. **탈출 조건** – 리스트가 0·1개이면 그대로 반환.  
2. **피벗 선택** – 여기서는 가장 마지막 원소를 피벗으로 잡는다(다른 선택도 가능).  
3. **분할** – 피벗보다 작거나 같은 원소는 `left`, 큰 원소는 `right`에 각각 모은다.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 과정을 반복해 정렬한다.  
5. **결합** – 정렬된 `left`, 피벗, 정렬된 `right`를 순서대로 이어서 최종 결과를 만든다.

이 구현은 **O(N log N)** 평균 시간 복잡도를 가지지만, 최악의 경우(이미 정렬된 배열 등) **O(N²)** 가 될 수 있습니다.  
피벗을 무작위로 선택하거나 “median‑of‑three” 전략을 쓰면 최악의 경우를 피할 확률을 높일 수 있습니다.
