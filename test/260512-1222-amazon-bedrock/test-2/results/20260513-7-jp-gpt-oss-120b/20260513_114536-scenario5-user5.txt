아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 무엇을 하는지 설명하는 주석을 달아 두었으니, 코드를 보면서 알고리즘 흐름을 쉽게 따라올 수 있을 것입니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수 정의, 입력은 정렬하고 싶은 리스트 arr
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                       # 그대로 반환하고 재귀 호출을 종료

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택 → 중간 원소를 기준으로 삼음
    left = []                            # 피벗보다 작은 원소들을 담을 리스트
    middle = []                          # 피벗과 같은 원소들을 담을 리스트
    right = []                           # 피벗보다 큰 원소들을 담을 리스트

    for x in arr:                        # 입력 리스트의 모든 원소를 순회
        if x < pivot:                    # 현재 원소가 피벗보다 작으면
            left.append(x)               # left 리스트에 추가
        elif x == pivot:                 # 현재 원소가 피벗과 같으면
            middle.append(x)             # middle 리스트에 추가
        else:                            # 현재 원소가 피벗보다 크면
            right.append(x)              # right 리스트에 추가

    # 재귀적으로 left와 right 부분을 정렬하고, middle(피벗들)과 합쳐서 반환
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 동작하도록 조건
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]   # 정렬되지 않은 샘플 리스트
    sorted_arr = quick_sort(unsorted)            # 퀵소트 함수 호출
    print("정렬 전 :", unsorted)                 # 정렬 전 리스트 출력
    print("정렬 후 :", sorted_arr)               # 정렬 후 리스트 출력
```

### 코드 흐름 간단 요약
1. **베이스 케이스** – 리스트 길이가 1 이하이면 바로 반환.  
2. **피벗 선택** – 여기서는 리스트 중앙값을 피벗으로 사용(다른 전략도 가능).  
3. **분할** – 리스트를 `left`, `middle`, `right` 세 부분으로 나눔.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 정렬.  
5. **결합** – 정렬된 `left` + `middle` + 정렬된 `right` 순서로 합쳐 최종 결과 반환.

이렇게 한 줄 한 줄에 주석을 달아 두었으니, 퀵소트가 어떻게 “분할–정복” 방식으로 동작하는지 이해하는 데 도움이 되길 바랍니다! 🚀
