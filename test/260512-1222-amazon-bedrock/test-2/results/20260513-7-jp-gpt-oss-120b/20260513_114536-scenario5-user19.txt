아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 상세히 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 것입니다.

```python
# 퀵소트 알고리즘 구현
# 입력 : 정수 리스트 arr, 정렬할 구간의 시작 인덱스 low, 끝 인덱스 high
# 출력 : 같은 리스트가 제자리에서(in‑place) 정렬됩니다.

def quick_sort(arr, low, high):
    # 구간이 하나의 원소 이하일 때는 이미 정렬된 것이므로 바로 반환
    if low >= high:
        return

    # ----------------------------------------------------------------------
    # 1) 피벗(pivot) 선택
    # 여기서는 구간의 가장 오른쪽 원소를 피벗으로 사용한다.
    # (다른 선택 방법도 가능하지만 구현이 간단하다)
    # ----------------------------------------------------------------------
    pivot = arr[high]

    # ----------------------------------------------------------------------
    # 2) 파티션(partition) 수행
    # i : 피벗보다 작거나 같은 원소들의 마지막 위치를 가리키는 인덱스
    # 처음에는 low - 1 로 초기화해서 아직 아무 원소도 검사하지 않은 상태를 만든다.
    # ----------------------------------------------------------------------
    i = low - 1

    # 현재 구간의 low ~ high-1까지 순회하면서 피벗보다 작은 원소를 앞쪽으로 모은다.
    for j in range(low, high):
        # arr[j] 가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            # i 를 하나 증가시킨 뒤, arr[i] 와 arr[j] 를 교환한다.
            # 이렇게 하면 i 이전 구간( low ~ i )은 모두 피벗 이하의 값이 된다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # ----------------------------------------------------------------------
    # 3) 피벗을 자신의 최종 위치에 배치
    # 파티션이 끝난 뒤 i+1 위치에 피벗을 넣으면,
    # 왼쪽( low ~ i )은 피벗보다 작거나 같고,
    # 오른쪽( i+2 ~ high )은 피벗보다 큰 구간이 된다.
    # ----------------------------------------------------------------------
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 최종적으로 위치한 인덱스
    pivot_index = i + 1

    # ----------------------------------------------------------------------
    # 4) 재귀 호출
    # 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 독립적으로 정렬한다.
    # ----------------------------------------------------------------------
    quick_sort(arr, low, pivot_index - 1)   # 왼쪽 부분 배열 정렬
    quick_sort(arr, pivot_index + 1, high) # 오른쪽 부분 배열 정렬


# --------------------------------------------------------------------------
# 사용 예시
# --------------------------------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 숫자 리스트
    data = [34, 7, 23, 32, 5, 62, 78, 1, 0, 19]

    print("정렬 전:", data)

    # quick_sort 함수를 호출할 때는 리스트와 전체 구간(0 ~ len-1)을 넘겨준다.
    quick_sort(data, 0, len(data) - 1)

    print("정렬 후:", data)
```

### 코드 흐름 요약
1. **기저 조건** – `low >= high`이면 재귀 호출을 멈춘다.  
2. **피벗 선택** – 현재 구간의 마지막 원소를 피벗으로 잡는다.  
3. **파티션** – `i`를 기준으로 피벗보다 작은 원소들을 앞쪽에 모은다.  
4. **피벗 배치** – 파티션이 끝난 뒤 피벗을 `i+1` 위치에 놓아 두 부분을 나눈다.  
5. **재귀 호출** – 피벗을 기준으로 좌·우 구간을 각각 다시 퀵소트한다.

이렇게 하면 **제자리(in‑place) 정렬**이 이루어지며, 평균 시간 복잡도는 `O(N log N)`이고, 최악의 경우(`이미 정렬된 배열` 등) `O(N²)`이 됩니다.  
피벗 선택 방법을 랜덤하게 바꾸면 최악 상황을 회피할 확률을 크게 높일 수 있습니다. 필요에 따라 `pivot = random.choice(arr[low:high+1])` 와 같이 수정해 보세요!
