아래는 Python으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 줄마다 어떤 역할을 하는지 자세히 설명하는 주석을 달아 두었으니, 코드 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):
    """
    퀵소트 함수
    - 입력: 정렬하고 싶은 리스트(arr)
    - 반환값: 정렬이 완료된 새로운 리스트
    """
    
    # 1️⃣ 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 바로 반환한다.
    if len(arr) <= 1:
        return arr                                      # (base case)

    # 2️⃣ 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 잡는다.
    pivot = arr[-1]                                      # (pivot = 마지막 원소)

    # 3️⃣ 피벗보다 작은 원소들을 담을 리스트와 피벗보다 큰 원소들을 담을 리스트를 각각 초기화한다.
    left = []                                            # 피벗보다 작은 원소들
    right = []                                           # 피벗보다 큰 원소들
    middle = []                                          # 피벗과 값이 같은 원소들(중복을 위해)

    # 4️⃣ 전체 리스트를 순회하면서 각 원소를 피벗과 비교한다.
    for element in arr:
        if element < pivot:                              # 피벗보다 작으면 left에 추가
            left.append(element)
        elif element > pivot:                            # 피벗보다 크면 right에 추가
            right.append(element)
        else:                                            # 피벗과 같으면 middle에 추가 (중복 허용)
            middle.append(element)

    # 5️⃣ 재귀 호출을 이용해 left와 right 부분을 각각 정렬한다.
    #    - left와 right는 아직 정렬되지 않은 부분 리스트이다.
    sorted_left = quick_sort(left)                       # 왼쪽(작은 값) 부분 정렬
    sorted_right = quick_sort(right)                     # 오른쪽(큰 값) 부분 정렬

    # 6️⃣ 정렬된 left, middle(피벗 자체와 중복), sorted_right를 순서대로 이어서 반환한다.
    #    이렇게 하면 전체 리스트가 오름차순으로 정렬된다.
    return sorted_left + middle + sorted_right
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 임의의 원소를 골라도 된다.  
3. **분할 과정** – 리스트를 피벗 기준으로 `<`, `=`, `>` 세 그룹으로 나눈다.  
4. **재귀 호출** – 두 개의 부분 리스트(`left`, `right`)에 대해 각각 `quick_sort`를 다시 실행한다.  
5. **결합** – 정렬된 왼쪽, 피벗(및 중복), 정렬된 오른쪽을 차례대로 이어서 최종 결과를 만든다.

---

#### 사용 예시
```python
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 33]
    print("정렬 전 :", unsorted)
    print("정렬 후 :", quick_sort(unsorted))
```

출력:
```
정렬 전 : [33, 10, 55, 71, 29, 3, 18, 33]
정렬 후 : [3, 10, 18, 29, 33, 33, 55, 71]
```

이와 같이 구현한 퀵소트는 **분할 정복(Divide‑and‑Conquer)** 전략을 사용하여 평균적으로 *O(n log n)* 의 시간복잡도를 가집니다. (최악의 경우는 피벗 선택이 나쁘면 *O(n²)* 가 될 수 있지만, 무작위 피벗이나 삼중 피벗 전략을 쓰면 그 확률을 크게 낮출 수 있습니다.)
