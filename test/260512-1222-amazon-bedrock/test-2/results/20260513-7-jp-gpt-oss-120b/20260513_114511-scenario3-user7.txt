아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 한글 주석을 달아 두었으니, 흐름을 따라가며 이해하시기 좋을 것입니다.

```python
# -------------------------------------------------
# 퀵소트(Quick Sort) 구현 - Python
# -------------------------------------------------
# 퀵소트는 ‘분할 정복(Divide and Conquer)’ 알고리즘의 대표격.
# 1) 리스트(배열) 안에서 피벗(pivot)이라는 기준값을 하나 잡는다.
# 2) 피벗보다 작은 값들은 왼쪽, 큰 값들은 오른쪽으로 나눠서
#    두 개의 서브 리스트를 만든다.
# 3) 각각의 서브 리스트에 대해 위 과정을 재귀적으로 수행한다.
# 4) 더 이상 나눌 것이 없을 때(리스트 길이가 0 혹은 1) 정렬이 끝난다.
# -------------------------------------------------

def quick_sort(arr):
    """
    입력:  정렬하고 싶은 리스트(arr)
    반환:  정렬된 새로운 리스트
    """
    
    # 1️⃣ 리스트의 길이가 0 또는 1이면 이미 정렬된 상태 → 바로 반환
    if len(arr) <= 1:
        return arr
    
    # 2️⃣ 피벗 선택
    # -------------------------------------------------
    # 여기서는 가장 간단하게 '마지막 원소'를 피벗으로 잡는다.
    # (성능을 높이고 싶다면 무작위 선택 혹은 중간값 선택을 고려)
    # -------------------------------------------------
    pivot = arr[-1]
    
    # 3️⃣ 피벗을 기준으로 두 개의 리스트를 만든다
    #    - left: 피벗보다 작거나 같은 원소들
    #    - right: 피벗보다 큰 원소들
    left = []   # 피벗보다 작은(또는 같은) 원소들을 담을 리스트
    right = []  # 피벗보다 큰 원소들을 담을 리스트
    
    # 4️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left / right에 분배
    for element in arr[:-1]:          # 마지막 원소(pivot) 제외하고 순회
        if element <= pivot:          # 피벗보다 작거나 같으면 left에
            left.append(element)
        else:                         # 피벗보다 크면 right에
            right.append(element)
    
    # 5️⃣ 재귀 호출: left와 right 각각을 다시 퀵소트
    #    - 이렇게 하면 서브 리스트가 점점 작아지면서
    #      결국 길이가 0 또는 1이 되는 기저 조건에 도달한다.
    sorted_left = quick_sort(left)    # 왼쪽 부분 정렬
    sorted_right = quick_sort(right)  # 오른쪽 부분 정렬
    
    # 6️⃣ 정렬된 결과를 합친다
    #    - left 서브 리스트 + 피벗 + right 서브 리스트 순서가
    #      최종 정렬된 리스트가 된다.
    return sorted_left + [pivot] + sorted_right


# ------------------------------------------------------------------
# 사용 예시
# ------------------------------------------------------------------
if __name__ == "__main__":
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90]
    print("정렬 전 :", unsorted_list)
    
    sorted_list = quick_sort(unsorted_list)
    print("정렬 후 :", sorted_list)

```

### 코드 흐름 정리
1. **기저 조건** – 리스트 길이가 1 이하이면 바로 반환.  
2. **피벗 선택** – 여기선 마지막 원소(`arr[-1]`).  
3. **분할** – 피벗을 기준으로 `left`와 `right` 두 리스트에 원소를 나눔.  
4. **재귀** – `left`와 `right` 각각에 `quick_sort`를 다시 호출.  
5. **합치기** – `sorted_left + [pivot] + sorted_right` 로 최종 정렬 리스트 완성.

### 팁
- **피벗 선택 전략**을 바꾸면 최악의 경우(O(n²))를 피하고 평균 성능(O(n log n))을 더 안정적으로 유지할 수 있습니다.  
  - 예: 무작위 원소 선택 `pivot = random.choice(arr)`  
  - 예: “median‑of‑three” (첫 번째·중간·마지막 원소 중 중앙값)  
- **제자리(인‑플레이스) 퀵소트**도 가능하지만 구현이 약간 복잡해집니다. 위 예시는 가독성을 위해 새 리스트를 만들어 반환합니다.
