아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 달아 두었으니, 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):                       # 퀵소트를 수행할 함수를 정의 (입력: 정렬할 리스트)
    if len(arr) <= 1:                     # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                         # 그대로 반환

    pivot = arr[len(arr) // 2]             # 피벗(pivot) 선정 → 리스트 중간 요소를 선택
    left = []                              # 피벗보다 작은 요소들을 담을 리스트 초기화
    middle = []                            # 피벗과 같은 요소들을 담을 리스트 초기화
    right = []                             # 피벗보다 큰 요소들을 담을 리스트 초기화

    for x in arr:                          # 원본 리스트의 각 요소를 하나씩 검사
        if x < pivot:                      # 현재 요소가 피벗보다 작다면
            left.append(x)                 # left 리스트에 추가
        elif x > pivot:                    # 현재 요소가 피벗보다 크다면
            right.append(x)                # right 리스트에 추가
        else:                              # 현재 요소가 피벗과 같다면 (중복을 위해)
            middle.append(x)               # middle 리스트에 추가

    # 재귀 호출을 이용해 left와 right 부분을 각각 정렬하고,
    # middle(피벗)와 결합하여 최종 정렬된 리스트를 만든다.
    return quick_sort(left) + middle + quick_sort(right)   # 정렬된 left + 피벗(중복) + 정렬된 right 반환
```

### 사용 예시
```python
if __name__ == "__main__":                 # 스크립트가 직접 실행될 때만 아래 코드 실행
    unsorted = [33, 10, 55, 71, 29, 3, 18] # 정렬되지 않은 샘플 리스트
    sorted_list = quick_sort(unsorted)    # 퀵소트를 호출해 정렬
    print("정렬 전:", unsorted)           # 정렬 전 리스트 출력
    print("정렬 후:", sorted_list)        # 정렬 후 리스트 출력
```

#### 핵심 아이디어
1. **피벗 선택** – 여기서는 리스트 중간 값을 피벗으로 사용했지만, 첫 번째/마지막 요소를 쓰거나 무작위 선택해도 됩니다.  
2. **분할(Divide)** – 피벗을 기준으로 리스트를 `<피벗`, `=피벗`, `>피벗` 세 부분으로 나눕니다.  
3. **정복(Conquer)** – `left`와 `right` 부분을 각각 재귀적으로 퀵소트하고, `middle`(피벗)와 합쳐 최종 결과를 얻습니다.  
4. **기본 사례(Base case)** – 리스트 길이가 0 혹은 1이면 더이상 분할할 필요가 없으므로 바로 반환합니다.

이 구현은 **안정적(stable)하지는 않지만** 이해하기 쉽고, 파이썬 리스트를 그대로 활용해 간결하게 작성되었습니다. 필요에 따라 피벗 선택 전략이나 인-플레이스(in-place) 버전 등으로 변형할 수 있습니다. 🚀
