아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 한글로 달아두었으니, 알고리즘 흐름을 따라가기에 도움이 될 거예요.

```python
# 퀵소트 함수 정의: 리스트 lst와 정렬할 구간의 시작 인덱스 left, 끝 인덱스 right를 받는다
def quick_sort(lst, left, right):
    # 구간이 하나의 원소 이하로 축소되면(정렬할 대상이 없으면) 재귀를 종료한다
    if left >= right:
        return

    # 피벗(pivot) 선택: 여기서는 구간의 가장 오른쪽 요소를 피벗으로 잡는다
    pivot = lst[right]

    # i는 피벗보다 작거나 같은 값을 모아두는 구역의 끝 인덱스를 나타낸다
    i = left - 1

    # j는 현재 검사 중인 요소의 인덱스이다
    for j in range(left, right):
        # 현재 요소 lst[j]가 피벗보다 작거나 같다면
        if lst[j] <= pivot:
            # i를 하나 늘리고, lst[i]와 lst[j]를 교환해서 작은 값들을 앞쪽에 모은다
            i += 1
            lst[i], lst[j] = lst[j], lst[i]

    # 현재 i는 피벗보다 작은 값들의 마지막 인덱스이므로,
    # 피벗을 i+1 위치에 넣어 피벗보다 작은 값과 큰 값을 정확히 구분한다
    lst[i + 1], lst[right] = lst[right], lst[i + 1]

    # 피벗이 최종적으로 자리 잡은 인덱스
    pivot_index = i + 1

    # 피벗을 기준으로 왼쪽 부분(피벗보다 작은 구간)을 재귀적으로 정렬한다
    quick_sort(lst, left, pivot_index - 1)

    # 피벗을 기준으로 오른쪽 부분(피벗보다 큰 구간)을 재귀적으로 정렬한다
    quick_sort(lst, pivot_index + 1, right)


# ----- 사용 예시 -------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    data = [33, 10, 55, 71, 29, 3, 18, 90, 42]

    # 리스트와 전체 구간을 넘겨서 퀵소트를 수행한다
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과 출력
    print("정렬된 리스트:", data)
```

### 코드 흐름 요약
1. **기저 조건** – `left >= right`이면 이미 정렬된 구간이므로 바로 반환.  
2. **피벗 선택** – 여기서는 가장 오른쪽 요소(`lst[right]`)를 피벗으로 사용.  
3. **분할 단계** – `for` 루프에서 피벗보다 작은(또는 같은) 값들을 앞쪽에 모아 두고, 마지막에 피벗을 그 바로 다음 자리(`i+1`)에 놓는다. 이렇게 하면 피벗을 기준으로 좌·우 구간이 완전히 구분된다.  
4. **재귀 호출** – 피벗을 중심으로 좌·우 구간을 각각 다시 퀵소트한다.  

이 구현은 **제자리(in‑place) 정렬**이며, 평균 시간 복잡도는 `O(N log N)`, 최악 경우(`이미 정렬된 경우 등`)에는 `O(N²)`가 됩니다. 피벗을 무작위로 고르거나 “median‑of‑three” 전략을 쓰면 최악 경우를 현저히 감소시킬 수 있습니다.
