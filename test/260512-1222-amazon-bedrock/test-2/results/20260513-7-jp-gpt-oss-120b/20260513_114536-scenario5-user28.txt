아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 상세히 주석을 달아 두었으니, 코드를 읽으며 정렬 흐름을 쉽게 따라가실 수 있을 겁니다.

```python
# 퀵소트 함수: 리스트와 정렬 구간을 지정하는 left, right 인덱스를 입력받는다
def quick_sort(arr, left, right):
    # 구간이 하나 이하일 때는 이미 정렬된 것이므로 바로 반환한다
    if left >= right:
        return

    # 피벗(pivot)으로 사용할 값을 구간의 중간값으로 잡는다
    pivot = arr[(left + right) // 2]

    # i와 j는 각각 현재 구간의 왼쪽 끝, 오른쪽 끝을 가리킨다
    i, j = left, right

    # i와 j가 교차할 때까지 반복한다
    while i <= j:
        # 피벗보다 작은 값을 찾을 때까지 i를 오른쪽으로 이동한다
        while arr[i] < pivot:
            i += 1
        # 피벗보다 큰 값을 찾을 때까지 j를 왼쪽으로 이동한다
        while arr[j] > pivot:
            j -= 1
        # i와 j가 아직 교차하지 않았다면, 두 값을 서로 교환한다
        if i <= j:
            arr[i], arr[j] = arr[j], arr[i]   # swap
            i += 1   # 교환 후 i를 한 칸 오른쪽으로 이동
            j -= 1   # 교환 후 j를 한 칸 왼쪽으로 이동

    # 왼쪽 하위 구간에 대해 재귀 호출한다 (left ~ j)
    quick_sort(arr, left, j)
    # 오른쪽 하위 구간에 대해 재귀 호출한다 (i ~ right)
    quick_sort(arr, i, right)


# --------------------------------------------------------------
# 사용 예시 : 직접 실행해볼 수 있는 간단한 테스트 코드
if __name__ == "__main__":
    # 정렬할 무작위 리스트를 만든다
    sample = [33, 10, 55, 71, 29, 3, 18, 92, 44]

    print("정렬 전 :", sample)          # 정렬 전 원본 출력
    quick_sort(sample, 0, len(sample)-1)  # 전체 리스트를 정렬
    print("정렬 후 :", sample)          # 정렬된 결과 출력
```

### 코드 흐름 요약
1. **기본 종료 조건** – `left >= right`이면 구간이 0·1개 원소뿐이므로 정렬이 필요 없으므로 반환.  
2. **피벗 선택** – 여기서는 구간 중앙값을 피벗으로 사용했지만, 첫 원소/마지막 원소 등 다른 전략도 가능.  
3. **분할 과정** – 두 포인터 `i`, `j`를 이용해 피벗을 기준으로 작은 원소와 큰 원소를 교환하며 구간을 두 부분으로 나눈다.  
4. **재귀 호출** – 피벗을 기준으로 나뉜 왼쪽(`left ~ j`)과 오른쪽(`i ~ right`) 구간에 대해 각각 같은 과정을 반복한다.  

이 구현은 **제자리(in‑place)** 정렬이므로 추가 메모리를 거의 사용하지 않으며, 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(`이미 정렬된 배열에 피벗을 가장 큰/작은 값으로 잡는 경우`)는 `O(N²)`입니다.
