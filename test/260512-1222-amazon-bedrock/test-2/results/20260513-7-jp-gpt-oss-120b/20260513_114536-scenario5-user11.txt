아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 한글 주석을 달아 동작 흐름을 자세히 설명했습니다.  

```python
def quick_sort(arr):
    """퀵소트 함수 - 입력 리스트를 정렬하고 새 리스트를 반환"""

    # 1️⃣ 베이스케이스: 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                                   # ← 정렬이 필요 없는 경우

    # 2️⃣ 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                                   # ← 피벗 값 저장

    # 3️⃣ 피벗보다 작은 원소들을 담을 리스트와 큰 원소들을 담을 리스트 초기화
    left = []                                         # ← 피벗보다 작은 원소들
    right = []                                        # ← 피벗보다 큰 원소들
    equal = [pivot]                                   # ← 피벗과 같은 값(중복된 피벗)

    # 4️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left, right, equal에 분류
    for x in arr[:-1]:                                # ← 마지막 피벗 제외
        if x < pivot:                                 # ← 피벗보다 작으면
            left.append(x)                            #   left 리스트에 추가
        elif x > pivot:                               # ← 피벗보다 크면
            right.append(x)                           #   right 리스트에 추가
        else:                                         # ← 피벗과 값이 같으면(중복)
            equal.append(x)                           #   equal 리스트에 추가

    # 5️⃣ 재귀적으로 left와 right를 각각 정렬
    sorted_left = quick_sort(left)                    # ← left 부분 정렬
    sorted_right = quick_sort(right)                  # ← right 부분 정렬

    # 6️⃣ 정렬된 left + equal(pivot) + 정렬된 right 를 이어붙여 반환
    return sorted_left + equal + sorted_right         # ← 최종 정렬 결과
```

### 사용 예시
```python
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 44, 33]
    print("정렬 전 :", unsorted)
    print("정렬 후 :", quick_sort(unsorted))
```

**핵심 흐름 요약**

1. **베이스 케이스** → 리스트가 0·1개면 그대로 반환.  
2. **피벗 선택** → 여기서는 마지막 원소 사용(다른 선택도 가능).  
3. **분할** → 피벗보다 작은 `left`, 같은 값은 `equal`, 큰 값은 `right`에 저장.  
4. **재귀 호출** → `left`와 `right`를 각각 다시 퀵소트.  
5. **병합** → `sorted_left + equal + sorted_right` 로 하나의 정렬된 리스트 완성.

이 구현은 **원본 리스트를 변형하지 않고** 새로운 정렬 리스트를 반환합니다.  
리스트 복사가 필요 없는 **in‑place 퀵소트**를 원한다면 `partition` 함수를 이용한 버전을 구현하면 됩니다.
