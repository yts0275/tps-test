아래는 **Python** 으로 구현한 퀵소트(quick sort) 예제입니다.  
각 코드 라인마다 어떤 동작을 하는지 상세히 주석을 달아두었으니, **한 줄씩 읽어보면서 알고리즘 흐름을 이해**하는 데 도움이 될 겁니다.

```python
# 퀵소트 구현
# ------------------------------------------------------------
# quick_sort 함수는 리스트와 정렬할 구간의 시작 인덱스(start)와
# 끝 인덱스(end)를 받아서 해당 구간을 재귀적으로 정렬합니다.
# ------------------------------------------------------------
def quick_sort(arr, start, end):
    # 1. 구간의 크기가 1 이하이면(시작이 끝보다 크거나 같으면) 정렬이 필요 없으므로 바로 반환
    if start >= end:
        return

    # 2. 피벗(pivot) 선택: 여기서는 구간의 마지막 원소를 피벗으로 사용
    pivot = arr[end]

    # 3. i는 피벗보다 작은 원소들을 저장할 위치를 가리키는 인덱스
    #    처음에는 구간의 시작 인덱스로 잡는다.
    i = start

    # 4. j는 현재 검사 중인 원소의 인덱스. start부터 end-1까지 순회한다.
    for j in range(start, end):
        # 4-1. 현재 원소가 피벗보다 작거나 같으면,
        #      그 원소를 i번째 위치와 교환하고 i를 오른쪽으로 한 칸 이동시킨다.
        if arr[j] <= pivot:
            # 교환 (이미 i와 j가 같은 경우도 안전하게 동작)
            arr[i], arr[j] = arr[j], arr[i]
            i += 1   # i를 다음 빈칸으로 옮긴다.

    # 5. 모든 원소를 검사하고 나면, i 위치에 피벗보다 큰 원소가 남아 있다.
    #    피벗을 i 위치와 교환해 정렬된 상태(피벗은 왼쪽보다 크고 오른쪽보다 작음)로 만든다.
    arr[i], arr[end] = arr[end], arr[i]

    # 6. 이제 피벗을 기준으로 좌·우 서브배열이 각각 정렬되지 않은 상태이므로,
    #    재귀적으로 각각을 정렬한다.
    #    왼쪽 서브배열: start ~ i-1
    quick_sort(arr, start, i - 1)
    #    오른쪽 서브배열: i+1 ~ end
    quick_sort(arr, i + 1, end)


# ------------------------------------------------------------
# 사용 예시
# ------------------------------------------------------------
if __name__ == "__main__":
    # 정렬할 리스트 정의
    data = [33, 10, 55, 71, 29, 3, 18, 42]

    # 정렬 전 출력
    print("정렬 전:", data)

    # quick_sort 함수 호출 (전체 리스트를 정렬)
    quick_sort(data, 0, len(data) - 1)

    # 정렬 후 출력
    print("정렬 후:", data)
```

### 코드 흐름 요약
1. **기저 조건** – 구간에 원소가 0개 또는 1개이면 바로 반환.  
2. **피벗 선택** – 여기서는 가장 오른쪽 원소(`arr[end]`)를 사용했지만, 무작위 선택이나 중간값 선택 등으로 바꿀 수 있다.  
3. **파티셔닝(partition)** – 피벗보다 작거나 같은 원소들을 왼쪽으로 모아두고, `i`를 피벗이 들어갈 최종 위치로 지정한다.  
4. **피벗 교환** – 피벗을 `i` 위치와 교환해, 피벗이 정확히 정렬된 위치에 오도록 한다.  
5. **재귀 호출** – 피벗을 기준으로 왼쪽·오른쪽 서브배열을 각각 다시 퀵소트한다.
