아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 줄마다 어떤 역할을 하는지 한글 주석을 달아 두었으니, 공부하거나 활용할 때 참고하세요.

```python
def quick_sort(arr):                     # quick_sort 함수 정의, 정렬할 리스트를 매개변수로 받는다
    if len(arr) <= 1:                    # 리스트 길이가 1 이하라면 (빈 리스트·한 원소 리스트) 바로 반환
        return arr                        # 정렬이 필요 없는 경우 그대로 반환

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택 – 여기서는 중간 요소를 사용
    left = []                            # 피벗보다 작은 값들을 담을 리스트 초기화
    middle = []                          # 피벗과 같은 값들을 담을 리스트 초기화
    right = []                           # 피벗보다 큰 값들을 담을 리스트 초기화

    for x in arr:                        # 입력 리스트의 모든 요소를 하나씩 검사
        if x < pivot:                     # 현재 값이 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x == pivot:                  # 현재 값이 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가
        else:                             # 현재 값이 피벗보다 크면
            right.append(x)               # right 리스트에 추가

    # 재귀 호출을 통해 left와 right 부분을 각각 정렬하고,
    # 정렬된 left, middle(피벗), 정렬된 right 를 차례대로 이어서 반환
    return quick_sort(left) + middle + quick_sort(right)   # 정렬 결과를 합쳐서 반환


# ---------------------- 사용 예시 ----------------------
if __name__ == "__main__":               # 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [33, 10, 55, 71, 29, 3, 18, 92, 44]  # 정렬하고 싶은 임의의 리스트
    print("정렬 전:", sample)           # 정렬 전 리스트 출력
    sorted_sample = quick_sort(sample)   # quick_sort 함수 호출
    print("정렬 후:", sorted_sample)     # 정렬된 리스트 출력
```

### 코드 설명 (요약)

| 구분 | 내용 |
|------|------|
| **피벗 선택** | 리스트 중앙값(`arr[len(arr)//2]`)을 피벗으로 삼아 평균적인 성능을 확보 |
| **분할 단계** | `left`, `middle`, `right` 세 리스트에 각각 `< pivot`, `== pivot`, `> pivot`인 원소를 분류 |
| **재귀 호출** | `left`와 `right` 리스트에 대해 같은 과정을 재귀적으로 수행해 완전 정렬 |
| **병합** | 정렬된 `left` + `middle` + 정렬된 `right` 를 이어 최종 결과 반환 |
| **시간 복잡도** | 평균 O(N log N), 최악 O(N²) (피벗 선택이 최악인 경우) |
| **공간 복잡도** | 추가 리스트(`left`, `middle`, `right`)와 재귀 호출 스택 때문에 O(N) |

필요에 따라 **피벗 선택 전략**(예: 랜덤 선택, 첫 번째/마지막 요소 선택)이나 **인-플레이스(in‑place) 구현**으로 변형할 수도 있습니다.  
위 코드는 가독성을 위해 리스트를 새로 만들어 사용하는 **비인-플레이스** 버전이며, 초보자에게 이해하기 쉬운 형태로 작성했습니다.
