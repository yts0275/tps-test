아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하는지 상세히 주석을 달아 두었으니, 꼼꼼히 살펴보시면 이해가 쉬우실 거예요.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수 정의, 입력은 정렬할 리스트 arr
    if len(arr) <= 1:                    # 리스트의 길이가 1 이하이면 이미 정렬된 상태
        return arr                        # 그대로 반환 (재귀 종료 조건)

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                       # 피벗은 마지막 원소
    left = []                             # 피벗보다 작은 원소들을 담을 리스트
    right = []                            # 피벗보다 큰 원소들을 담을 리스트
    middle = []                           # 피벗과 같은 값(중복값)들을 담을 리스트

    # 리스트 전체를 순회하면서 원소들을 세 개의 그룹으로 나눔
    for x in arr:                         # arr의 모든 원소 x에 대해
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x > pivot:                   # 피벗보다 크면
            right.append(x)               # right 리스트에 추가
        else:                             # 피벗과 같으면 (중복값)
            middle.append(x)              # middle 리스트에 추가

    # 재귀적으로 left와 right 부분을 각각 정렬하고,
    # 정렬된 left + middle(피벗) + 정렬된 right 순서로 합침
    return quick_sort(left) + middle + quick_sort(right)   # 최종 정렬 결과 반환
```

### 코드 흐름 요약
1. **기저(case) 처리** – 리스트가 0·1개이면 그대로 반환한다.  
2. **피벗 선택** – 여기선 가장 오른쪽 원소를 피벗으로 잡는다.  
3. **분할** – 원소들을 `< pivot`, `== pivot`, `> pivot` 세 그룹으로 나눈다.  
4. **재귀 호출** – `< pivot`와 `> pivot` 그룹을 각각 다시 퀵소트한다.  
5. **병합** – 정렬된 왼쪽, 피벗(중복 포함), 정렬된 오른쪽을 차례대로 이어서 반환한다.
