아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 상세히 주석을 달아두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr: list) -> list:                     # 퀵소트를 수행할 함수를 정의한다. 입력은 정수(또는 비교 가능한 값) 리스트
    """                                              # 함수 설명 문자열 (docstring)
    퀵소트 알고리즘을 사용해 리스트를 오름차순 정렬한다.
    재귀 호출을 이용해 부분 배열을 계속 나누어 정렬한다.
    """
    if len(arr) <= 1:                                 # 리스트가 비었거나 원소가 하나이면 이미 정렬된 상태이므로
        return arr                                     # 그대로 반환한다.

    # 피벗(pivot) 선택: 여기서는 가장 오른쪽 원소를 피벗으로 잡는다.
    pivot = arr[-1]                                    # 피벗은 리스트의 마지막 요소

    # 피벗보다 작은 원소들을 저장할 리스트
    left = []                                          # 피벗보다 작은 값들을 담을 빈 리스트
    # 피벗보다 큰 원소들을 저장할 리스트
    right = []                                         # 피벗보다 큰 값들을 담을 빈 리스트
    # 피벗과 같은 값이 여러 개 있을 경우를 위한 리스트
    middle = []                                        # 피벗과 값이 같은 원소들을 담을 리스트

    # 리스트의 마지막 원소(피벗)를 제외하고 모든 원소를 검사한다.
    for x in arr[:-1]:                                 # 피벗을 제외한 모든 요소에 대해 반복
        if x < pivot:                                  # 현재 원소가 피벗보다 작다면
            left.append(x)                             # left 리스트에 추가
        elif x > pivot:                                # 현재 원소가 피벗보다 크다면
            right.append(x)                            # right 리스트에 추가
        else:                                          # 현재 원소가 피벗과 같다면
            middle.append(x)                           # middle 리스트에 추가 (중복 값 처리)

    # 재귀적으로 left와 right 부분을 정렬하고,
    # middle에 피벗 자체와 같은 값들을 추가한 뒤 모두 합친다.
    return quick_sort(left) + middle + [pivot] + quick_sort(right)
    # left 부분을 정렬 → middle(피벗과 동일한 값) → 피벗 자체 하나 → right 부분을 정렬
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 무작위 원소나 중앙값을 선택해도 된다.  
3. **분할 단계** – 리스트를 `left`, `middle`, `right` 세 개의 서브리스트로 나눈다.  
4. **재귀 호출** – `left`와 `right` 서브리스트에 대해 같은 과정을 반복해 정렬한다.  
5. **결과 합치기** – 정렬된 `left` + `middle` + 피벗 + 정렬된 `right`를 순서대로 이어 최종 정렬된 리스트를 만든다.  

이와 같이 퀵소트는 **분할‑정복(Divide‑and‑Conquer)** 전략을 이용해 평균 `O(n log n)` 시간 복잡도를 가지며, 구현도 비교적 간단합니다. 필요에 따라 피벗 선택 전략을 바꾸면 최악의 경우(`O(n²)`)를 줄이는 최적화도 가능합니다. 🎉
