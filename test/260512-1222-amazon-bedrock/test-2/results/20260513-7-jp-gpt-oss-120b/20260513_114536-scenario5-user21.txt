아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한글 주석을 달아 흐름을 이해하기 쉽게 만들었습니다.  

```python
# 퀵소트 함수 정의: 정렬하고 싶은 리스트와 시작·끝 인덱스를 매개변수로 받는다
def quick_sort(arr, low, high):
    # 현재 구간에 정렬할 요소가 두 개 이상인지 확인한다
    if low < high:
        # 파티션 함수를 호출해 기준값(pivot)을 기준으로
        # 왼쪽은 pivot보다 작고 오른쪽은 크게 배치된 새로운 인덱스를 반환받는다
        pi = partition(arr, low, high)

        # 피벗 기준 왼쪽 구간을 재귀적으로 정렬한다
        quick_sort(arr, low, pi - 1)

        # 피벗 기준 오른쪽 구간을 재귀적으로 정렬한다
        quick_sort(arr, pi + 1, high)

# 파티션 함수 정의: 리스트를 두 파트로 나누고 pivot(기준값)의 최종 위치를 반환한다
def partition(arr, low, high):
    # 가장 오른쪽 요소를 pivot(기준값)으로 선택한다
    pivot = arr[high]

    # i는 "작은 값들"이 모여 있는 구역의 마지막 인덱스를 가리킨다.
    # 초기값은 low - 1 (아직 작은 값이 없으므로 한 칸 앞을 가리킴)
    i = low - 1

    # low 부터 high-1까지 순회하면서 현재 요소와 pivot을 비교한다
    for j in range(low, high):
        # 현재 요소가 pivot보다 작거나 같으면
        if arr[j] <= pivot:
            # 작은 구역의 끝을 한 칸 늘리고, 현재 요소와 교환한다
            i += 1
            arr[i], arr[j] = arr[j], arr[i]   # swap

    # 모든 요소를 검사한 뒤, 작은 구역 바로 다음 위치(i+1)와 pivot을 교환한다
    # 이렇게 하면 pivot은 정확히 정렬된 위치에 놓인다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # pivot이 최종적으로 위치한 인덱스를 반환한다
    return i + 1

# ------------------- 사용 예시 -------------------
if __name__ == "__main__":
    # 정렬하고 싶은 샘플 리스트
    data = [34, 7, 23, 32, 5, 62]

    # quick_sort 함수 호출: 전체 리스트(0 부터 len-1까지)를 정렬한다
    quick_sort(data, 0, len(data) - 1)

    # 정렬이 완료된 리스트 출력
    print("정렬 결과:", data)
```

### 코드 흐름 요약
1. `quick_sort`가 전체 구간을 받아 **재귀**적으로 호출된다.  
2. `partition`이 현재 구간을 **pivot** 기준으로 두 파트로 나눈 뒤, pivot의 최종 위치(`pi`)를 반환한다.  
3. `quick_sort`는 `pi`를 기준으로 왼쪽·오른쪽 서브 구간을 각각 다시 정렬한다.  
4. 구간이 더 이상 두 개 이상 요소를 포함하지 않을 때(`low >= high`) 재귀가 종료되고, 리스트는 완전히 정렬된다.  

필요에 따라 `pivot`을 **임의 선택**하거나 **무작위 섞기** 등으로 바꾸면 최악의 경우를 줄일 수 있습니다. :)
