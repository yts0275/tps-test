아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
코드 한 줄마다 한글 주석을 달아 두었으니, 흐름을 따라가면서 이해하기 쉬울 거예요.

```python
# 퀵소트 구현 (재귀 방식)
def quick_sort(arr):
    # 1. 입력 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선택 – 여기서는 리스트의 첫 번째 요소를 피벗으로 사용
    pivot = arr[0]

    # 3. 피벗보다 작은 원소들만 모아 새로운 리스트 left에 저장
    left = [x for x in arr[1:] if x < pivot]

    # 4. 피벗과 같은 값(중복된 피벗)은 중간 리스트 middle에 저장
    middle = [x for x in arr[1:] if x == pivot]

    # 5. 피벗보다 큰 원소들만 모아 새로운 리스트 right에 저장
    right = [x for x in arr[1:] if x > pivot]

    # 6. left와 middle(피벗 자체)와 right를 재귀적으로 정렬 후 합쳐 반환
    #    - left와 right는 각각 다시 quick_sort()에 넘겨 정렬
    #    - middle은 피벗과 같은 값이 여러 개 있을 경우를 대비해 그대로 붙임
    return quick_sort(left) + [pivot] + middle + quick_sort(right)


# ------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 원본 리스트
    unsorted = [33, 10, 55, 71, 29, 10, 4, 90, 23]

    # quick_sort 함수 호출 → 정렬된 리스트 반환
    sorted_arr = quick_sort(unsorted)

    # 결과 출력
    print("정렬 전:", unsorted)
    print("정렬 후:", sorted_arr)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 가장 간단하게 첫 요소를 피벗으로 잡음. (다른 전략도 가능)  
3. **분할(partition)** – 피벗보다 작은(`left`), 같은(`middle`), 큰(`right`) 원소들을 각각 별도 리스트에 저장.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 과정을 다시 수행하여 정렬된 부분 리스트를 얻음.  
5. **병합(merge)** – 정렬된 `left` + 피벗 + `middle` + 정렬된 `right` 순서로 합쳐 최종 정렬 결과를 만든다.

### 참고사항
- **시간 복잡도**  
  - 평균 : \(O(n \log n)\)  
  - 최악 : \(O(n^2)\) (이미 정렬된 리스트에 첫 요소를 피벗으로 선택했을 경우)  
- **안정성** – 퀵소트는 기본적으로 **불안정** 정렬이지만, 위 구현에서는 `middle` 리스트를 따로 두어 같은 값들의 상대 순서를 유지하므로 어느 정도 안정성을 확보할 수 있다.  
- **피벗 선택 전략**을 다르게 하면(예: 무작위 선택, 중앙값 선택) 최악 상황을 피할 확률이 높아진다.

필요에 따라 피벗 선택을 바꾸거나, 리스트 슬라이스 대신 인덱스를 이용한 **in‑place** 버전으로 구현하면 메모리 사용량을 줄일 수 있습니다. 즐겁게 코딩하세요! 🚀
