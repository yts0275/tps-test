아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드줄마다 한글 주석을 달아 두었으니, 알고리즘 흐름을 따라가며 이해하시면 됩니다.

```python
# 퀵소트 구현 (Python)
# ----------------------------------------------------------------------
def quick_sort(arr):
    """
    리스트 arr을 제자리(in‑place) 정렬하고 정렬된 리스트를 반환한다.
    """
    # 정렬을 수행할 헬퍼 함수 정의
    def _quick_sort(left, right):
        # left 인덱스가 right 인덱스보다 작을 때만 구분(분할)한다.
        if left < right:
            # 피벗을 기준으로 배열을 분할하고 피벗의 최종 위치를 반환
            pivot_index = partition(left, right)
            # 피벗 왼쪽 부분에 대해 재귀 호출
            _quick_sort(left, pivot_index - 1)
            # 피벗 오른쪽 부분에 대해 재귀 호출
            _quick_sort(pivot_index + 1, right)

    # ------------------------------------------------------------------
    def partition(left, right):
        """
        배열의 오른쪽 끝 요소를 피벗으로 삼아,
        피벗보다 작거나 같은 값들은 왼쪽에, 큰 값들은 오른쪽에 배치한다.
        최종적으로 피벗을 올바른 위치에 놓고 그 인덱스를 반환한다.
        """
        # 피벗 선택 (여기서는 가장 오른쪽 요소)
        pivot = arr[right]               # 피벗 값
        i = left - 1                      # i는 "작거나 같은" 구역의 마지막 인덱스

        # left ~ right-1까지 순회하면서 피벗보다 작은 요소들을 앞쪽으로 모은다.
        for j in range(left, right):
            # 현재 요소 arr[j]가 피벗보다 작거나 같으면
            if arr[j] <= pivot:
                i += 1                    # 작은 구역의 끝을 한 칸 확장
                arr[i], arr[j] = arr[j], arr[i]   # 작은 요소와 현재 요소 교환
                # 이제 arr[left..i] 구역은 모두 피벗 이하 값들이다.

        # 모든 요소를 검사한 뒤, 피벗을 작은 구역 바로 뒤(i+1) 위치에 놓는다.
        arr[i + 1], arr[right] = arr[right], arr[i + 1]
        # i+1이 피벗의 최종 인덱스가 된다.
        return i + 1

    # ------------------------------------------------------------------
    # 정렬 시작: 전체 리스트 범위(0 ~ len(arr)-1)를 넘겨준다.
    _quick_sort(0, len(arr) - 1)

    # 정렬이 끝난 리스트를 반환 (선택 사항)
    return arr


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18]   # 정렬하고 싶은 리스트
    print("정렬 전 :", data)
    sorted_data = quick_sort(data)      # 퀵소트 호출
    print("정렬 후 :", sorted_data)
```

### 코드 흐름 요약

1. `quick_sort` 함수가 호출되면 내부 헬퍼 `_quick_sort`에 전체 인덱스(`0` ~ `len-1`)를 넘겨준다.  
2. `_quick_sort`는 `partition` 함수를 이용해 피벗을 가운데로 이동시킨 뒤, 피벗을 기준으로 **좌·우** 두 부분을 각각 다시 `_quick_sort`로 정렬한다.  
3. `partition`은 **Lomuto** 파티션 방식을 사용한다.  
   - 피벗은 오른쪽 끝 요소(`arr[right]`)를 선택하고, `i`를 `left-1` 로 초기화한다.  
   - `j`가 `left`부터 `right-1`까지 움직이며, `arr[j] <= pivot` 이면 `i`를 늘리고 `arr[i]`와 `arr[j]`를 교환한다.  
   - 루프가 끝난 뒤 피벗을 `i+1` 위치와 바꾸어 피벗이 정확히 정렬된 위치에 오도록 한다.  
4. 재귀 호출이 끝나면 전체 배열이 오름차순으로 정렬된다.

---

#### 📌 팁
- 피벗을 **무작위**로 선택하거나 **중앙값**(median‑of‑three)으로 고르면 최악의 경우(O(N²))를 피할 확률이 높아집니다.  
- 위 코드는 **제자리 정렬**(in‑place)이므로 추가적인 메모리를 거의 사용하지 않으며, 평균 시간복잡도는 **O(N log N)** 입니다.
