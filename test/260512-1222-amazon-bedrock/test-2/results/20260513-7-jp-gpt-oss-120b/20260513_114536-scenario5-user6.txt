아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 줄마다 상세히 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):
    """퀵소트를 재귀적으로 호출하여 정렬된 새 리스트를 반환한다."""
    
    # 1️⃣ 기본 사례: 배열의 길이가 1 이하이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # 길이가 0 또는 1인 경우 바로 반환

    # 2️⃣ 피벗 선택: 배열의 마지막 요소를 피벗(pivot)으로 잡는다.
    #    (다른 전략—예: 무작위 선택—도 가능하지만 여기서는 가장 단순하게 마지막 요소 사용)
    pivot = arr[-1]

    # 3️⃣ 피벗보다 작은 원소들을 모은 리스트(left)와
    #    피벗보다 큰 원소들을 모은 리스트(right)를 만든다.
    left = []   # 피벗보다 작거나 같은 원소들을 저장할 리스트
    right = []  # 피벗보다 큰 원소들을 저장할 리스트

    # 4️⃣ 배열의 첫 번째부터 마지막 전까지(피벗 제외) 순회하면서 분할 수행
    for element in arr[:-1]:           # 피벗을 제외하고 모든 원소에 대해
        if element <= pivot:           # 피벗보다 작거나 같으면
            left.append(element)      # left 리스트에 추가
        else:                          # 피벗보다 크면
            right.append(element)     # right 리스트에 추가

    # 5️⃣ 재귀 호출을 통해 left와 right 부분을 각각 정렬한다.
    #    정렬된 left + [pivot] + 정렬된 right 를 이어 붙여 최종 결과 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# ---------------------- 사용 예시 ----------------------
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬되지 않은 임의의 리스트
    sorted_arr = quick_sort(unsorted)           # 퀵소트 함수 호출
    print("정렬 전:", unsorted)                 # 원본 리스트 출력 (변경되지 않음)
    print("정렬 후:", sorted_arr)               # 정렬된 결과 출력
```

### 코드 흐름 요약
1. **기본 사례** – 리스트가 비어 있거나 원소가 1개이면 그대로 반환합니다.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 잡았습니다.  
3. **분할** – 피벗보다 작거나 같은 원소와 큰 원소를 두 개의 리스트(`left`, `right`)에 나눕니다.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 과정을 다시 수행해 완전 정렬된 리스트를 얻습니다.  
5. **결합** – 정렬된 `left`, 피벗, 정렬된 `right`를 순서대로 이어 붙여 최종 결과를 반환합니다.

#### 📌 참고 사항
- **시간 복잡도**  
  - 평균 : \(O(n \log n)\)  
  - 최악 : \(O(n^2)\) (피벗 선택이 최악의 경우, 예: 이미 정렬된 리스트에 마지막 요소를 피벗으로 잡을 때)  
- **공간 복잡도**  
  - 재귀 호출에 따른 호출 스택 + 각 단계에서 만드는 `left`, `right` 리스트 때문에 **\(O(n)\)** 정도의 추가 메모리를 사용합니다.  
- **피벗 선택을 개선**하면 최악 상황을 거의 피할 수 있습니다. 예) 무작위 피벗, median‑of‑three 등.
