아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한글 주석을 달아 어떤 역할을 하는지 상세히 설명했습니다.  

```python
# 퀵소트를 구현하는 함수
def quick_sort(arr):
    """
    입력:  정렬하고 싶은 리스트(arr)
    출력:  정렬된 새로운 리스트를 반환한다.
    """
    # 리스트가 비었거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 값들을 담을 리스트
    less = []
    # 피벗과 같은 값들을 담을 리스트 (피벗 자체도 여기 포함)
    equal = []
    # 피벗보다 큰 값들을 담을 리스트
    greater = []

    # 전체 리스트를 한 번 순회하면서 세 개의 리스트로 분류한다
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 less에 추가
            less.append(x)
        elif x == pivot:       # 피벗과 같으면 equal에 추가
            equal.append(x)
        else:                  # 피벗보다 크면 greater에 추가
            greater.append(x)

    # 재귀 호출을 통해 less와 greater 부분을 각각 정렬한다
    # 그리고 정렬된 less, equal, greater 를 순서대로 이어 붙여 최종 결과를 만든다
    return quick_sort(less) + equal + quick_sort(greater)


# -------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트를 실행하여 정렬된 리스트를 얻는다
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트 :", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환 (재귀 종료).  
2. **피벗 선택** – 마지막 원소를 피벗으로 삼는다 (다른 전략도 가능).  
3. **분할 단계** – 전체 리스트를 순회하면서 `less`, `equal`, `greater` 세 부분으로 나눈다.  
4. **재귀 호출** – `less`와 `greater` 부분에 대해 각각 `quick_sort`를 다시 호출한다.  
5. **합치기** – 정렬된 `less`, 피벗이 포함된 `equal`, 정렬된 `greater`를 차례대로 이어 붙여 결과를 만든다.  

이와 같이 퀵소트는 **분할‑정복(Divide and Conquer)** 전략을 이용해 평균 O(N log N)의 시간 복잡도를 달성합니다. (최악의 경우 O(N²)지만, 피벗 선택 방식을 개선하면 그 빈도를 크게 줄일 수 있습니다.)
