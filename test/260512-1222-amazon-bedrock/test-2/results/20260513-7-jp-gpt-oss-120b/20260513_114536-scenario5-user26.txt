아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 상세한 주석을 달아 두었으니, 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):
    """퀵소트 함수: 입력 리스트 arr를 정렬해서 반환한다."""
    
    # 1. 리스트가 비었거나 원소가 1개만 있으면 이미 정렬돼 있으므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2. 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                     # 피벗은 비교 기준이 되는 값
    
    # 3. 피벗보다 작은(또는 같은) 요소들을 저장할 리스트
    left = []                           
    # 4. 피벗보다 큰 요소들을 저장할 리스트
    right = []                          
    
    # 5. 피벗을 제외한 나머지 요소들을 순회하면서 left / right에 분리
    for element in arr[:-1]:            # 마지막 요소는 피벗이므로 제외
        if element <= pivot:            # 피벗보다 작거나 같은 경우
            left.append(element)        # left 리스트에 추가
        else:                           # 피벗보다 큰 경우
            right.append(element)       # right 리스트에 추가
    
    # 6. left와 right 리스트에 대해 각각 재귀적으로 퀵소트를 수행하고,
    #    피벗을 중간에 끼워서 정렬된 리스트를 만든다.
    #    (left가 먼저, 그 다음 피벗, 마지막에 right)
    return quick_sort(left) + [pivot] + quick_sort(right)

# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 임의의 리스트
    sorted_list = quick_sort(unsorted)      # 퀵소트를 호출해 정렬
    print("정렬 전 :", unsorted)            # 정렬 전 리스트 출력
    print("정렬 후 :", sorted_list)         # 정렬 후 리스트 출력
```

### 코드 흐름 정리
1. **기저 조건** – 리스트 길이가 0 또는 1이면 그대로 반환합니다.  
2. **피벗 선택** – 간단히 마지막 요소를 피벗으로 잡았습니다. (다른 전략도 가능)  
3. **분할 작업** – 피벗을 기준으로 `left`와 `right` 두 그룹으로 나눕니다.  
4. **재귀 호출** – 나눠진 두 그룹에 대해 각각 퀵소트를 다시 수행합니다.  
5. **결합** – `left`(정렬된) + `pivot` + `right`(정렬된) 순서로 합쳐 최종 정렬 결과를 얻습니다.

이 구현은 **직관적**이지만, 매 호출마다 새로운 리스트를 생성하므로 메모리 사용이 다소 비효율적일 수 있습니다.  
실제 대용량 데이터에 적용할 때는 **제자리(in‑place) 퀵소트**를 구현하거나, 피벗 선택 방식을 개선(예: 랜덤 피벗)하여 최악의 경우 시간을 줄이는 것이 좋습니다.
