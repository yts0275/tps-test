아래는 파이썬으로 작성한 **인‑플레이스 퀵소트(Quick Sort)** 구현 예시입니다.  
각 코드 라인마다 한글 주석을 달아 어떤 역할을 하는지 쉽게 이해할 수 있도록 설명했습니다.  

```python
def quick_sort(arr, low, high):
    """배열 arr을 low~high 구간까지 퀵소트로 정렬한다."""
    
    # 1. 구간이 1개 이하인 경우(이미 정렬된 경우) 바로 반환
    if low < high:
        
        # 2. 파티션 함수를 호출해 피벗(pivot)이 최종 위치하는 인덱스를 얻는다.
        pi = partition(arr, low, high)
        
        # 3. 피벗을 기준으로 왼쪽 구간을 재귀적으로 정렬
        quick_sort(arr, low, pi - 1)
        
        # 4. 피벗을 기준으로 오른쪽 구간을 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)


def partition(arr, low, high):
    """arr[low..high] 구간을 파티션하고, 피벗이 최종 위치한 인덱스를 반환한다."""
    
    # 5. 피벗으로 사용할 값을 오른쪽 끝 원소로 잡는다.
    pivot = arr[high]
    
    # 6. i는 피벗보다 작거나 같은 원소들의 마지막 위치를 가리킨다.
    i = low - 1
    
    # 7. low부터 high-1까지 순회하면서 피벗보다 작은 원소들을 앞쪽으로 모은다.
    for j in range(low, high):
        # 8. 현재 원소 arr[j]가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            # 9. i를 한 칸 오른쪽으로 이동시키고
            i += 1
            # 10. 현재 원소와 i 위치에 있는 원소를 교환한다.
            arr[i], arr[j] = arr[j], arr[i]
    
    # 11. 피벗을 i+1 위치와 교환해 피벗을 정확한 정렬 위치에 놓는다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 12. 피벗이 최종적으로 위치한 인덱스를 반환한다.
    return i + 1


# -------------------- 사용 예시 --------------------
if __name__ == "__main__":
    # 13. 정렬하고 싶은 배열을 정의한다.
    sample = [34, 7, 23, 32, 5, 62, 31, 4, 12]
    
    # 14. 배열 전체를 대상으로 quick_sort 함수를 호출한다.
    quick_sort(sample, 0, len(sample) - 1)
    
    # 15. 정렬 결과를 출력한다.
    print("정렬된 배열:", sample)
```

### 코드 흐름 요약
1. `quick_sort` 함수는 재귀적으로 호출되면서 배열을 작은 구간으로 나눕니다.  
2. `partition` 함수는 지정된 구간(`low`‑`high`) 안에서 피벗을 선택하고, 피벗보다 작은 값들을 앞쪽에, 큰 값들을 뒤쪽에 배치해 피벗을 **정렬된 최종 위치**에 둡니다.  
3. 파티션이 끝난 뒤 피벗을 기준으로 좌·우 구간을 다시 `quick_sort`에 넘겨 재귀적으로 정렬합니다.  
4. 구간 크기가 1 이하이면(즉, `low >= high`) 재귀 호출을 멈추어 정렬이 종료됩니다.

이 구현은 **제자리(in‑place)** 정렬이므로 추가적인 큰 메모리 공간을 요구하지 않으며, 평균 시간 복잡도는 `O(N log N)`이고 최악의 경우(`이미 정렬된 배열` 등) `O(N^2)`가 될 수 있습니다. 필요에 따라 피벗 선택 전략(예: 무작위 피벗)이나 꼬리 재귀 최적화 등을 적용하면 최악의 경우를 완화할 수 있습니다.
