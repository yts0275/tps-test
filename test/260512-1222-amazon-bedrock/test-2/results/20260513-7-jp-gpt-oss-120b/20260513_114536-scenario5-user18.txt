아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 한국어 주석을 달아 코드 흐름을 쉽게 이해할 수 있도록 했어요.

```python
# quick_sort.py

def quick_sort(arr):
    """리스트 arr를 제자리(in‑place) 퀵소트로 정렬하고 같은 리스트를 반환한다."""
    
    # 내부 함수: 파티션을 수행한다.
    def partition(low, high):
        # 피벗은 현재 구간의 가장 오른쪽 요소로 선택한다.
        pivot = arr[high]                  # 피벗 값 저장
        i = low - 1                        # i는 피벗보다 작거나 같은 요소들의 마지막 인덱스

        # low부터 high-1까지 순회하면서 피벗보다 작은(또는 같은) 요소를 앞쪽으로 모은다.
        for j in range(low, high):
            if arr[j] <= pivot:            # 현재 요소가 피벗보다 작거나 같다면
                i += 1                     # i를 한 칸 오른쪽으로 이동
                arr[i], arr[j] = arr[j], arr[i]   # i 위치와 j 위치의 값을 교환
                # 이제 arr[low..i] 범위에 피벗보다 작거나 같은 값들이 있다.

        # 마지막으로 피벗을 i+1 위치에 놓아, 피벗보다 작은 값과 큰 값 사이를 구분한다.
        arr[i + 1], arr[high] = arr[high], arr[i + 1]
        # 파티션이 끝난 후 피벗은 정확히 정렬된 위치에 있다.
        return i + 1                       # 피벗(또는 파티션 경계)의 인덱스를 반환

    # 재귀적으로 구간을 정렬하는 함수
    def quick_sort_recursive(low, high):
        if low < high:                     # 구간이 2개 이상인 경우에만 정렬 진행
            pi = partition(low, high)      # 파티션 수행 → 피벗 위치 pi 반환
            # 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 재귀 호출
            quick_sort_recursive(low, pi - 1)   # 피벗 왼쪽 부분 정렬
            quick_sort_recursive(pi + 1, high)  # 피벗 오른쪽 부분 정렬
        # low >= high이면 구간에 요소가 0개 또는 1개이므로 이미 정렬된 상태다.

    # 정렬 시작: 전체 리스트 범위(0부터 len-1)에서 재귀 호출
    quick_sort_recursive(0, len(arr) - 1)
    return arr        # 정렬된 리스트를 반환 (원본 리스트가 직접 변형됨)


# -------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [34, 7, 23, 32, 5, 62]
    print("정렬 전:", unsorted)

    sorted_arr = quick_sort(unsorted)     # quick_sort 호출
    print("정렬 후:", sorted_arr)
```

#### 📌 핵심 포인트
- **제자리 정렬(in‑place)**: 별도의 보조 배열을 만들지 않고 `arr` 자체를 바꾼다.  
- **피벗 선택**: 여기서는 가장 오른쪽 요소를 피벗으로 잡았지만, 랜덤 선택 등으로 바꾸면 최악의 경우를 피할 수 있다.  
- **시간 복잡도**  
  - 평균: **O(N log N)**  
  - 최악(이미 정렬된 경우 등): **O(N²)** (피벗 선택을 개선하면 완화 가능)  
- **재귀 깊이**: 파이썬 기본 재귀 제한(≈1000)보다 큰 배열을 정렬할 경우 `sys.setrecursionlimit`을 조정하거나 반복 버전(스택 사용)으로 구현한다.
