아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 무엇을 하는지 자세히 설명하는 주석을 넣어 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 1️⃣ 베이스 케이스: 리스트가 비어있거나 요소가 1개이면 정렬이 필요 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2️⃣ 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 3️⃣ 피벗보다 작은 요소들을 담을 리스트
    less = []

    # 4️⃣ 피벗과 같은 요소들을 담을 리스트 (중복된 값들을 그대로 유지)
    equal = []

    # 5️⃣ 피벗보다 큰 요소들을 담을 리스트
    greater = []

    # 6️⃣ 전체 리스트를 순회하면서 각 요소를 적절한 리스트에 배분
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 less에
            less.append(x)
        elif x == pivot:       # 피벗과 같으면 equal에
            equal.append(x)
        else:                  # 피벗보다 크면 greater에
            greater.append(x)

    # 7️⃣ 재귀 호출: less와 greater 부분 리스트를 각각 다시 퀵소트
    #    (베이스 케이스에 도달할 때까지 계속 분할·정렬)
    sorted_less = quick_sort(less)
    sorted_greater = quick_sort(greater)

    # 8️⃣ 정렬된 결과를 합쳐서 반환
    #    less(정렬) + equal(피벗 그룹) + greater(정렬)
    return sorted_less + equal + sorted_greater


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 42, 16]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("정렬 전 :", unsorted_list)
    print("정렬 후 :", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 크기가 0 또는 1이면 더 이상 분할할 필요가 없으므로 바로 반환.  
2. **피벗 선택** – 여기서는 가장 오른쪽 요소를 피벗으로 잡지만, 임의 선택, 중앙 선택 등 다른 전략도 가능.  
3. **분할 단계** – 리스트를 `less`, `equal`, `greater` 세 구간으로 나눔.  
4. **재귀 호출** – `less`와 `greater`를 각각 다시 퀵소트.  
5. **합치기** – 정렬된 `less`, 피벗(= `equal`), 정렬된 `greater` 를 차례대로 연결해서 최종 결과를 만든다.
