아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 줄마다 무슨 역할을 하는지 상세히 주석을 달아 두었으니, 코드를 읽어가며 알고리즘 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):
    """
    입력:  정렬되지 않은 리스트 arr
    반환:  정렬된 새로운 리스트
    """
    # 리스트 길이가 0이거나 1이면 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:
        return arr                         # 기본 사례 (Base case)

    # 피벗(pivot) 선정: 현재 리스트의 마지막 요소를 피벗으로 잡는다.
    pivot = arr[-1]                        # 피벗은 리스트의 마지막 원소

    # 피벗보다 작은 요소들을 담을 리스트
    less = []                              # left side
    # 피벗보다 큰 요소들을 담을 리스트
    greater = []                           # right side

    # 피벗을 제외한 나머지 요소들을 순회하면서
    # 각각 less 혹은 greater 리스트에 넣는다.
    for x in arr[:-1]:                     # 피벗을 제외한 모든 원소
        if x <= pivot:                     # 피벗보다 작거나 같은 경우
            less.append(x)                 # less 리스트에 추가
        else:                              # 피벗보다 큰 경우
            greater.append(x)              # greater 리스트에 추가

    # 재귀적으로 less와 greater 리스트를 정렬한다.
    # 정렬된 less 리스트 + 피벗 + 정렬된 greater 리스트를 이어 붙여 반환한다.
    return quick_sort(less) + [pivot] + quick_sort(greater)


# ----------------------------------------------
# 사용 예시
# ----------------------------------------------
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]
    print("정렬 전 :", unsorted)

    sorted_arr = quick_sort(unsorted)
    print("정렬 후 :", sorted_arr)
```

### 코드 흐름 요약
1. **기본 사례** – 리스트 길이가 1 이하이면 즉시 반환한다.  
2. **피벗 선택** – 여기서는 편의를 위해 마지막 원소를 피벗으로 잡는다. (다른 선택 전략도 가능)  
3. **분할(Partition)** – 피벗을 기준으로 작은 원소와 큰 원소를 각각 `less`, `greater` 리스트에 나눈다.  
4. **재귀 호출** – `less`와 `greater`에 대해 각각 `quick_sort`를 다시 실행한다.  
5. **결합** – 정렬된 `less` + 피벗 + 정렬된 `greater`를 이어서 최종 결과를 만든다.

### 주의 사항
- 위 구현은 **새로운 리스트를 만들어 반환**하므로 원본 리스트 `arr`는 변경되지 않습니다.  
- 메모리 사용량이 O(n log n) 정도로, 제자리(in‑place) 버전에 비해 다소 비효율적일 수 있습니다.  
- 피벗 선택을 무작위(`random.choice`)나 “median‑of‑three” 방식으로 바꾸면 최악의 경우(O(n²))를 더 희박하게 만들 수 있습니다.
