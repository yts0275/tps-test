아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 한국어 주석을 달아 동작 흐름을 자세히 설명했으니, 코드를 따라가면서 이해해 보세요.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    """
    arr: 정렬할 리스트(배열)
    반환값: 정렬이 완료된 새로운 리스트
    """
    # 리스트가 비어있거나 원소가 1개이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                 # 피벗은 정렬 과정에서 기준이 되는 값
    # 피벗보다 작은 원소들을 담을 리스트
    left = []                      
    # 피벗보다 큰 원소들을 담을 리스트
    right = []                     

    # 피벗을 제외한 나머지 원소들을 순회하면서 left와 right에 배분
    for x in arr[:-1]:              # arr[:-1] 은 마지막(피벗) 요소를 제외한 슬라이스
        if x <= pivot:              # 피벗보다 작거나 같으면 left에
            left.append(x)
        else:                       # 피벗보다 크면 right에
            right.append(x)

    # 재귀적으로 left와 right 부분을 정렬하고,
    # 정렬된 left + 피벗 + 정렬된 right 를 합쳐서 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬할 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 바로 반환(분할 더 이상 불필요).  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 임의 선택 혹은 중앙값 등으로 바꿀 수 있음.  
3. **분할 단계** – 피벗을 기준으로 `left`(작거나 같은 원소)와 `right`(큰 원소) 두 리스트로 나눔.  
4. **재귀 호출** – `left`와 `right` 각각에 `quick_sort`를 다시 적용해 정렬하고,  
5. **병합** – `left` 정렬 결과 + 피벗 + `right` 정렬 결과를 이어 붙여 최종 정렬된 리스트를 만든다.

이 구현은 **새로운 리스트를 반환**하는 방식이며, **제자리(in‑place) 정렬**이 아니라 메모리를 추가로 사용합니다.  
제자리 구현이 필요하면 리스트를 직접 슬라이스하지 않고 인덱스를 활용한 버전을 별도로 작성할 수도 있습니다.
