아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 코드입니다.  
요구에 맞춰 **한 줄마다 주석을 달아** 이해하기 쉽도록 설명했습니다.

```python
def quick_sort(arr):                     # 함수 정의: 정렬하고자 하는 리스트를 매개변수로 받는다
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로
        return arr                        # 그대로 반환한다
                                          # (재귀 호출의 종료 조건)
                                          
    pivot = arr[len(arr) // 2]           # 피벗 선택: 리스트 중간 요소를 피벗으로 잡는다
                                          # (중간값을 골라 평균적인 경우 성능을 기대)
                                          
    left = []                            # 피벗보다 작은 요소를 담을 리스트 초기화
    middle = []                          # 피벗과 같은 요소를 담을 리스트 초기화
    right = []                           # 피벗보다 큰 요소를 담을 리스트 초기화
                                          
    for x in arr:                        # 원본 리스트의 모든 요소를 하나씩 확인한다
        if x < pivot:                    # 현재 요소가 피벗보다 작으면
            left.append(x)               # left 리스트에 추가한다
        elif x == pivot:                 # 현재 요소가 피벗과 같으면
            middle.append(x)             # middle 리스트에 추가한다
        else:                            # 현재 요소가 피벗보다 크면
            right.append(x)              # right 리스트에 추가한다
                                          
    # 재귀적으로 left와 right 부분을 정렬하고, middle은 그대로 두어 합친다
    return quick_sort(left) + middle + quick_sort(right)  
    # left와 right는 재귀 호출을 통해 정렬되고, middle은 피벗값들의 모음이다
    # 세 부분을 이어 붙여 최종 정렬된 리스트를 반환한다
                                          
# ---------------------- 사용 예시 ----------------------
if __name__ == "__main__":                # 스크립트를 직접 실행했을 때만 아래 코드를 실행한다
    unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 샘플 리스트
    print("원본 리스트:", unsorted)          # 원본 리스트 출력
    sorted_list = quick_sort(unsorted)      # quick_sort 함수를 호출해 정렬 수행
    print("정렬된 리스트:", sorted_list)    # 정렬 결과 출력
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 리스트 중간 요소를 피벗으로 잡음.  
3. **분할** – 피벗보다 작은 요소, 같은 요소, 큰 요소를 각각 `left`, `middle`, `right`에 저장.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 각각 정렬.  
5. **합치기** – 정렬된 `left`, `middle`, 정렬된 `right`를 순서대로 이어 붙여 최종 결과 반환.

이 구현은 **안정적인** 정렬은 아니지만(같은 값의 상대 순서가 보장되지 않음)  
**간단하고 직관적인** 퀵소트 알고리즘을 보여줍니다. 필요에 따라 피벗 선택 전략이나
`in‑place` 방식 등으로 성능을 더 개선할 수 있습니다.
