아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 한글 주석을 달아 코드 흐름을 자세히 설명했으니, 이해하는 데 도움이 될 거예요.

```python
# ------------------------------
# 퀵소트(Quick Sort) 구현
# ------------------------------

def quick_sort(arr):
    """
    재귀적으로 배열을 정렬하고 정렬된 새로운 리스트를 반환한다.
    입력:  arr  -> 정렬하고자 하는 리스트(또는 배열)
    반환: 정렬된 리스트
    """
    
    # 1️⃣ 베이스 케이스: 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 바로 반환한다.
    if len(arr) <= 1:
        return arr                       # 리스트 자체를 그대로 반환
    
    # 2️⃣ 피벗 선택
    #    여기서는 리스트의 첫 번째 원소를 피벗(pivot)으로 잡는다.
    #    (다른 전략: 마지막 원소, 중앙 원소, 무작위 원소 등)
    pivot = arr[0]
    
    # 3️⃣ 피벗을 기준으로 좌·우 리스트를 만든다.
    #    - left: 피벗보다 작거나 같은 원소들
    #    - right: 피벗보다 큰 원소들
    left = []      # 피벗보다 작거나 같은 원소들을 담을 리스트
    right = []     # 피벗보다 큰 원소들을 담을 리스트
    
    # 4️⃣ 원본 리스트의 두 번째 원소부터 끝까지 순회하며 left / right에 분배한다.
    for element in arr[1:]:
        if element <= pivot:            # 피벗 이하이면 left에
            left.append(element)
        else:                           # 피벗 초과이면 right에
            right.append(element)
    
    # 5️⃣ 재귀 호출
    #    left와 right는 각각 독립된 부분 문제이므로 다시 quick_sort를 적용한다.
    sorted_left = quick_sort(left)      # left 부분 정렬
    sorted_right = quick_sort(right)    # right 부분 정렬
    
    # 6️⃣ 결과 결합
    #    정렬된 left + 피벗 + 정렬된 right 를 하나의 리스트로 합친다.
    return sorted_left + [pivot] + sorted_right


# ------------------------------
# 사용 예시
# ------------------------------
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 92, 44]
    print("정렬 전 :", unsorted)
    
    # quick_sort 함수 호출 → 정렬된 새로운 리스트 반환
    sorted_arr = quick_sort(unsorted)
    
    print("정렬 후 :", sorted_arr)
```

### 코드 흐름 요약

| 단계 | 설명 |
|------|------|
| 1️⃣  | **베이스 케이스** – 리스트 길이가 0 또는 1이면 그대로 반환 |
| 2️⃣  | **피벗 선택** – 여기선 첫 번째 원소를 피벗으로 사용 |
| 3️⃣  | **분할** – 피벗보다 작거나 같은 원소를 `left`, 큰 원소를 `right`에 저장 |
| 4️⃣  | **재귀 호출** – `left`와 `right` 각각에 `quick_sort`를 다시 적용 |
| 5️⃣  | **합치기** – `sorted_left + [pivot] + sorted_right` 로 하나의 배열로 결합 |

---

#### 📌 주요 포인트

- **시간 복잡도**  
  - 평균: **O(N log N)**  
  - 최악(피벗이 항상 최솟값/최댓값인 경우): **O(N²)** → 피벗 선택을 무작위로 하면 최악 상황을 회피할 수 있다.
- **공간 복잡도**  
  - 재귀 호출에 따른 스택 사용량이 **O(log N)** (평균) 혹은 **O(N)** (최악) 정도.
- **안정성**  
  - 퀵소트는 **안정 정렬**이 아니다. 같은 값의 상대 순서가 바뀔 수 있다.
