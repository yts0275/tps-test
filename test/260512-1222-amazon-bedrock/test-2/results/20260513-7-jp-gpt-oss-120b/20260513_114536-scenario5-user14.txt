아래는 **Python** 으로 구현한 퀵소트 알고리즘입니다.  
각 줄마다 무엇을 하는 코드인지 설명하는 주석을 한글로 달아 두었으니, 코드를 읽으며 흐름을 이해하기에 도움이 될 거예요.  

```python
def quick_sort(arr):
    """
    퀵소트 함수
    입력 : 정렬하고 싶은 리스트(arr)
    반환 : 정렬이 완료된 새로운 리스트
    """
    
    # 1. 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태 → 그대로 반환
    if len(arr) <= 1:
        return arr                     # 기저 조건 (Base case)

    # 2. 피벗(pivot) 선택 → 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                    # 피벗은 정렬 기준이 되는 값

    # 3. 피벗보다 작은 원소들을 담을 리스트와, 큰 원소들을 담을 리스트를 초기화
    left = []                          # 피벗보다 작은 값들을 저장
    right = []                         # 피벗보다 큰 값들을 저장
    middle = []                        # 피벗과 같은 값을 저장 (중복 처리)

    # 4. 리스트의 모든 요소를 순회하면서 세 개의 리스트에 분류
    for x in arr:
        if x < pivot:                  # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:                # 피벗보다 크면 right에 추가
            right.append(x)
        else:                          # 피벗과 같으면 middle에 추가
            middle.append(x)

    # 5. 재귀적으로 left와 right 부분을 정렬하고,
    #    정렬된 left, middle(피벗), 정렬된 right 를 차례대로 이어 붙인다.
    #    → 전체 리스트가 정렬된 형태가 된다.
    return quick_sort(left) + middle + quick_sort(right)


# --------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]
    print("정렬 전 :", unsorted)

    sorted_arr = quick_sort(unsorted)
    print("정렬 후 :", sorted_arr)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 요소를 피벗으로 삼음(다른 전략도 가능).  
3. **분할** – 리스트를 `left(피벗보다 작음)`, `middle(피벗과 동일)`, `right(피벗보다 큼)` 세 부분으로 나눔.  
4. **재귀 호출** – `left`와 `right` 부분에 대해 각각 다시 `quick_sort`를 호출해 정렬.  
5. **합치기** – 정렬된 `left`, `middle`, `right`를 차례대로 붙여 최종 정렬 결과를 만들고 반환.  

이렇게 한 줄 한 줄에 주석을 달아 두었으니, 퀵소트가 “분할‑정복(Divide‑Conquer)” 방식을 어떻게 구현하는지 쉽게 파악할 수 있을 거예요! 🚀
