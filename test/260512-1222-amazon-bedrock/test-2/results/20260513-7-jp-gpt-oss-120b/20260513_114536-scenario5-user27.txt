아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 동작을 설명하는 주석을 달아 두었으니, 알고리즘 흐름을 바로 확인할 수 있을 거예요.

```python
# -*- coding: utf-8 -*-

def quick_sort(arr):
    """퀵소트를 수행하고 정렬된 새로운 리스트를 반환한다."""
    
    # -------------------------------
    # 1️⃣ 기저 조건 : 리스트가 비었거나 원소가 1개이면 이미 정렬된 것이므로 그대로 반환
    # -------------------------------
    if len(arr) <= 1:                     # 리스트 길이가 1 이하인지 검사
        return arr                         # 정렬이 필요 없으니 그대로 반환
    
    # -------------------------------
    # 2️⃣ 피벗 선택 : 여기서는 가장 오른쪽 원소를 피벗으로 잡는다
    # -------------------------------
    pivot = arr[-1]                        # 마지막 원소를 피벗으로 저장
    
    # -------------------------------
    # 3️⃣ 파티셔닝 : 피벗보다 작거나 같은 원소와 큰 원소를 각각 두 서브리스트에 담는다
    # -------------------------------
    left = []   # 피벗보다 작거나 같은 원소들을 모을 리스트
    right = []  # 피벗보다 큰 원소들을 모을 리스트
    
    for x in arr[:-1]:                     # 피벗을 제외한 모든 원소를 순회
        if x <= pivot:                     # 현재 원소가 피벗 이하이면
            left.append(x)                 # left 리스트에 추가
        else:                              # 현재 원소가 피벗보다 크면
            right.append(x)                # right 리스트에 추가
    
    # -------------------------------
    # 4️⃣ 재귀 호출 : left와 right 부분 리스트에 대해 각각 퀵소트를 다시 수행
    # -------------------------------
    sorted_left = quick_sort(left)         # left 부분을 재귀적으로 정렬
    sorted_right = quick_sort(right)       # right 부분을 재귀적으로 정렬
    
    # -------------------------------
    # 5️⃣ 결과 합치기 : 정렬된 left + 피벗 + 정렬된 right 순서로 새 리스트를 만든다
    # -------------------------------
    return sorted_left + [pivot] + sorted_right  # 최종 정렬된 리스트 반환


# -------------------------------------------------------------
# 사용 예시
# -------------------------------------------------------------
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 임의의 리스트
    print("정렬 전 :", unsorted)            # 정렬 전 리스트 출력
    sorted_arr = quick_sort(unsorted)       # 퀵소트 실행
    print("정렬 후 :", sorted_arr)          # 정렬된 결과 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트가 0·1개이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용.  
3. **파티셔닝** – 피벗을 기준으로 두 서브리스트(`left`, `right`)를 만든다.  
4. **재귀 호출** – 두 서브리스트에 대해 각각 `quick_sort`를 다시 호출한다.  
5. **합치기** – 정렬된 `left` + `pivot` + 정렬된 `right` 를 이어서 최종 리스트를 만든다.  

이 구현은 **리스트를 새로 만들어** 반환하기 때문에 원본 리스트를 그대로 두고 싶을 때 유용합니다.  
인‑플레이스(in‑place) 버전을 원한다면 `partition` 함수를 따로 구현하고, 배열을 직접 교환하도록 수정하면 됩니다. 필요하시다면 그 버전도 알려드릴게요! 🚀
