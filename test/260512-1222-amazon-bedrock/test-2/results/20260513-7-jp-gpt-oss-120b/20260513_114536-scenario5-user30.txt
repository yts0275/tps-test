아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 라인마다 무엇을 하는지 설명하는 주석을 한국어로 달아 두었습니다.  

```python
# 퀵소트 함수 정의 : 리스트와 정렬할 구간의 시작 인덱스(low), 끝 인덱스(high)를 매개변수로 받는다
def quick_sort(arr, low, high):
    # 구간이 하나의 원소 이하가 되면 이미 정렬된 것이므로 재귀를 종료한다
    if low < high:
        # 파티션 과정을 통해 피벗(pivot) 위치(index)를 구한다
        pivot_index = partition(arr, low, high)
        # 피벗 왼쪽 부분(피벗보다 작은 값들)을 재귀적으로 정렬한다
        quick_sort(arr, low, pivot_index - 1)
        # 피벗 오른쪽 부분(피벗보다 큰 값들)을 재귀적으로 정렬한다
        quick_sort(arr, pivot_index + 1, high)

# 파티션 함수 정의 : 피벗을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽에 배치하고
# 최종 피벗의 인덱스를 반환한다
def partition(arr, low, high):
    # 가장 오른쪽 원소를 피벗(pivot)으로 선택한다
    pivot = arr[high]
    # i는 "피벗보다 작거나 같은" 원소들의 마지막 인덱스를 가리킨다
    i = low - 1

    # low부터 high-1까지 순회하면서 원소들을 피벗과 비교한다
    for j in range(low, high):
        # 현재 원소(arr[j])가 피벗보다 작거나 같다면,
        if arr[j] <= pivot:
            # i를 한 칸 오른쪽으로 옮기고,
            i += 1
            # i 위치와 j 위치의 원소를 교환한다
            arr[i], arr[j] = arr[j], arr[i]

    # 모든 원소를 검사한 뒤, 피벗을 i+1 위치와 교환해 최종 위치를 확정한다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 놓인 최종 인덱스를 반환한다
    return i + 1


# ---------- 사용 예시 ----------
if __name__ == "__main__":
    # 정렬할 리스트 선언
    data = [33, 10, 55, 71, 29, 3, 18, 42]

    # 정렬 전 출력
    print("정렬 전:", data)

    # quick_sort 호출 : 전체 구간을 0 ~ len(data)-1 로 지정
    quick_sort(data, 0, len(data) - 1)

    # 정렬 후 출력
    print("정렬 후:", data)
```

### 코드 흐름 간단 정리
1. `quick_sort`가 전체 리스트 구간을 받아 재귀적으로 호출된다.  
2. 각 호출마다 `partition`이 실행되어 피벗을 기준으로 리스트를 두 파트로 나눈다.  
3. 피벗이 최종 위치에 고정되면, 피벗 왼쪽·오른쪽 구간을 다시 `quick_sort`로 정렬한다.  
4. 구간 크기가 1 이하가 되면 재귀가 멈추고, 최종적으로 전체 리스트가 오름차순 정렬된다.

> **Tip**  
> - 피벗을 항상 마지막 원소가 아니라 무작위로 선택하면 최악의 경우(O(n²))를 피할 확률이 높아집니다.  
> - `low < high` 조건을 `low >= high` 로 바꾸어도 동일한 효과를 얻을 수 있습니다.
