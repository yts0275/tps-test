아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인에 한국어 주석을 달아 동작을 자세히 설명했으니, 참고하시면서 직접 실행해 보세요!

```python
def quick_sort(arr):
    """퀵소트를 수행해서 정렬된 새로운 리스트를 반환한다."""
    
    # 1️⃣ 기저 사례: 리스트 길이가 0 이거나 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                      # 리스트를 그대로 반환
    
    # 2️⃣ 피벗 선택: 보통 마지막 요소를 피벗으로 잡는다
    pivot = arr[-1]                      # 피벗은 리스트의 마지막 원소
    
    # 3️⃣ 피벗보다 작은 원소들을 담을 리스트와 큰 원소들을 담을 리스트 준비
    left = []    # 피벗보다 작은 원소들을 저장
    right = []   # 피벗보다 큰 원소들을 저장
    
    # 4️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left / right에 분류
    for x in arr[:-1]:                   # 마지막 피벗을 제외하고 전부 검사
        if x <= pivot:                   # 피벗보다 작거나 같으면 left에
            left.append(x)
        else:                            # 피벗보다 크면 right에
            right.append(x)
    
    # 5️⃣ 재귀 호출: left와 right 각각을 다시 퀵소트
    sorted_left = quick_sort(left)       # left 부분을 정렬
    sorted_right = quick_sort(right)     # right 부분을 정렬
    
    # 6️⃣ 정렬된 left + 피벗 + 정렬된 right 를 하나의 리스트로 합쳐 반환
    return sorted_left + [pivot] + sorted_right


# ------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬되지 않은 샘플 리스트
    print("정렬 전 :", unsorted)                # 정렬 전 출력
    sorted_list = quick_sort(unsorted)          # 퀵소트 실행
    print("정렬 후 :", sorted_list)             # 정렬 후 출력
```

### 코드 흐름 간단히 정리
1. **기저 사례** – 리스트 길이가 1 이하이면 이미 정렬된 것이므로 바로 반환.  
2. **피벗 선택** – 여기서는 가장 마지막 원소를 피벗으로 사용.  
3. **분할(Partition)** – 피벗을 기준으로 작은 원소(`left`)와 큰 원소(`right`) 로 나눈다.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 다시 `quick_sort`를 호출해 정렬한다.  
5. **합치기** – 정렬된 `left`, 피벗, 정렬된 `right` 순서대로 연결해 최종 결과를 만든다.

### 참고 사항
- **시간 복잡도**: 평균 O(n log n), 최악 O(n²) (피벗 선택이 좋지 않을 경우).  
- **제자리(in‑place) 구현**도 가능하지만, 위 예시는 가독성을 위해 새 리스트를 반환하는 형태로 작성했습니다.  
- 파이썬 표준 라이브러리의 `list.sort()` 혹은 `sorted()`보다 느릴 수 있으니, 실무에서 성능이 중요한 경우 C/C++ 구현이나 파이썬 내부 정렬을 이용하는 것이 좋습니다.
