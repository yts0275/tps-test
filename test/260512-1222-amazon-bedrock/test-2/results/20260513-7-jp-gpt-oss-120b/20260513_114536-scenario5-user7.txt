아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 줄마다 왜 그런 코드를 쓰는지 설명하는 주석을 한글로 달아 두었으니, 코드 흐름을 따라가며 이해하기 쉽습니다.

```python
def quick_sort(arr):
    """
    재귀 호출을 이용한 퀵소트 함수
    - 입력: 정렬하고 싶은 리스트 arr
    - 반환: 정렬된 새로운 리스트
    """
    
    # 1. 리스트 길이가 0 혹은 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2. 피벗(pivot) 선택
    #    여기서는 리스트의 중간 값을 피벗으로 잡는다.
    #    (첫 번째 원소, 마지막 원소 등으로 잡아도 무방)
    pivot = arr[len(arr) // 2]
    
    # 3. 피벗보다 작은 원소들을 모아 left 리스트에 저장
    left = [x for x in arr if x < pivot]
    
    # 4. 피벗과 같은 원소들을 모아 middle 리스트에 저장
    #    피벗 자체도 여기 포함된다.
    middle = [x for x in arr if x == pivot]
    
    # 5. 피벗보다 큰 원소들을 모아 right 리스트에 저장
    right = [x for x in arr if x > pivot]
    
    # 6. left와 right 부분은 각각 다시 퀵소트를 수행하여 정렬한다.
    #    이렇게 재귀적으로 호출하면서 리스트를 점점 작은 조각으로 나눈다.
    sorted_left = quick_sort(left)      # 왼쪽 부분 정렬
    sorted_right = quick_sort(right)    # 오른쪽 부분 정렬
    
    # 7. 정렬된 left, middle(피벗), right 를 순서대로 이어 붙여 최종 정렬 결과 반환
    return sorted_left + middle + sorted_right


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]
    print("정렬 전 :", unsorted)
    sorted_arr = quick_sort(unsorted)
    print("정렬 후 :", sorted_arr)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트가 비었거나 원소가 하나면 그대로 반환한다.  
2. **피벗 선택** – 리스트 중앙 값을 피벗으로 잡아 분할 기준을 만든다.  
3. **분할** – 리스트를 `left(피벗보다 작은)`, `middle(피벗과 같은)`, `right(피벗보다 큰)` 세 그룹으로 나눈다.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 같은 과정을 반복한다.  
5. **결합** – 정렬된 `left`, `middle`, `right`를 차례대로 이어 붙여 최종 정렬 리스트를 만든다.

이와 같이 퀵소트는 **분할‑정복(Divide‑and‑Conquer)** 전략을 사용해 평균 \(O(n \log n)\) 시간 복잡도로 정렬을 수행합니다. (최악의 경우 \(O(n^2)\) 가 될 수 있지만, 피벗을 무작위로 고르면 거의 발생하지 않음)
