아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한글 주석을 달아 동작 흐름을 자세히 설명했습니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수를 정의한다. (입력: 정렬할 리스트)
    if len(arr) <= 1:                    # 리스트 길이가 0 혹은 1이면 이미 정렬된 상태이므로
        return arr                        # 그대로 반환한다.

    pivot = arr[len(arr) // 2]           # 피벗(pivot)으로 리스트 중간 값을 선택한다.
    left = []                            # 피벗보다 작은 원소를 담을 리스트
    middle = []                          # 피벗과 같은 값을 담을 리스트(중복 처리용)
    right = []                           # 피벗보다 큰 원소를 담을 리스트

    for x in arr:                        # 원본 리스트의 모든 원소를 순회한다.
        if x < pivot:                    # 피벗보다 작으면
            left.append(x)               # left 리스트에 추가한다.
        elif x > pivot:                  # 피벗보다 크면
            right.append(x)              # right 리스트에 추가한다.
        else:                            # 피벗과 같으면(중복값)
            middle.append(x)             # middle 리스트에 추가한다.

    # 재귀 호출을 통해 left와 right 부분을 각각 정렬한다.
    sorted_left = quick_sort(left)       # left 부분을 정렬하고 결과를 저장한다.
    sorted_right = quick_sort(right)     # right 부분을 정렬하고 결과를 저장한다.

    # 정렬된 left + pivot(중복 포함) + 정렬된 right 를 이어 붙여 최종 결과를 만든다.
    return sorted_left + middle + sorted_right   # 완전 정렬된 리스트를 반환한다.


# -----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 아래 코드를 수행한다.
    unsorted = [33, 10, 55, 71, 29, 3, 18, 33]   # 정렬되지 않은 임의의 리스트
    print("원본 리스트 :", unsorted)            # 원본 리스트 출력
    sorted_list = quick_sort(unsorted)          # 퀵소트 함수 호출
    print("정렬된 리스트:", sorted_list)       # 정렬 결과 출력
```

**코드 흐름 요약**

1. 리스트가 1개 이하이면 바로 반환 → 재귀 종료 조건.  
2. 가운데 원소를 피벗으로 선택하고, 세 개의 서브 리스트(`left`, `middle`, `right`)에 분류.  
3. `left`와 `right`에 대해 재귀적으로 `quick_sort`를 호출해 각각 정렬.  
4. 정렬된 `left`, 피벗(및 중복값)인 `middle`, 정렬된 `right`를 차례대로 이어 붙여 최종 정렬 배열을 만든다.  

이 구현은 **안정적(stable) 하지 않으며**, 평균·최악의 시간 복잡도는 각각 `O(n log n)`·`O(n²)`입니다.  
피벗 선택 전략(예: 무작위 선택)이나 원소 교환 방식으로 최적화를 할 수 있습니다.
