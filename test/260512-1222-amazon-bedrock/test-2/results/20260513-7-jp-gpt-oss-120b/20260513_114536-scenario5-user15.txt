아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하는지 자세히 설명하는 주석을 달아 두었으니, 이해하는 데 도움이 되실 거예요.

```python
# 퀵소트를 실행하는 메인 함수
def quick_sort(arr):
    # 입력으로 받은 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 바로 반환
    if len(arr) <= 1:
        return arr                     # 정렬이 필요 없는 경우 그대로 반환

    # 피벗(pivot) 선택: 여기서는 가장 오른쪽 원소를 피벗으로 사용
    pivot = arr[-1]                    # 피벗은 리스트의 마지막 요소

    # 피벗보다 작은 값들을 저장할 리스트
    less = []                          # 피벗보다 작은 값들을 모을 곳
    # 피벗보다 큰 값들을 저장할 리스트
    greater = []                       # 피벗보다 큰 값들을 모을 곳
    # 피벗과 같은 값을 저장할 리스트 (중복된 피벗을 처리하기 위해)
    equal = []                         # 피벗과 같은 값을 모을 곳

    # 원본 리스트의 모든 원소를 순회하면서 세 개의 리스트에 분류
    for x in arr:
        if x < pivot:                  # 피벗보다 작으면
            less.append(x)             # less 리스트에 추가
        elif x > pivot:                # 피벗보다 크면
            greater.append(x)          # greater 리스트에 추가
        else:                          # 피벗과 같으면 (중복인 경우)
            equal.append(x)            # equal 리스트에 추가

    # 재귀적으로 less와 greater 리스트를 정렬하고,
    # 정렬된 결과를 순서대로 이어 붙여 최종 정렬 리스트를 만든다.
    #   - less 리스트는 피벗보다 작으므로 가장 앞에 위치
    #   - equal 리스트는 피벗 자체(및 중복)이므로 그 다음에 위치
    #   - greater 리스트는 피벗보다 크므로 가장 뒤에 위치
    return quick_sort(less) + equal + quick_sort(greater)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]   # 정렬되지 않은 임의의 리스트
    print("원본 리스트 :", unsorted)                # 정렬 전 출력
    sorted_lst = quick_sort(unsorted)               # 퀵소트 호출
    print("정렬된 리스트:", sorted_lst)             # 정렬 후 출력
```

### 코드 설명 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 이미 정렬된 것이므로 그대로 반환합니다.  
2. **피벗 선택** – 여기서는 가장 오른쪽 원소를 피벗으로 잡았습니다. (다른 전략도 가능)  
3. **분할** – 리스트를 `less`, `equal`, `greater` 세 부분으로 나눕니다.  
4. **재귀 호출** – `less`와 `greater` 부분에 대해 각각 다시 `quick_sort`를 호출해 정렬합니다.  
5. **합치기** – 정렬된 `less` + `equal` + 정렬된 `greater` 순서대로 이어 붙여 최종 결과를 반환합니다.

이 구현은 **안정적인(stable) 퀵소트**는 아니지만, 이해하기 쉽고 교육용으로 많이 사용됩니다.  
피벗을 무작위로 골라서 최악의 경우(O(n²))를 방지하거나, 인‑플레이스(in‑place) 버전으로 메모리를 절약하는 등 다양한 변형도 존재합니다. 필요에 따라 응용해 보세요!
