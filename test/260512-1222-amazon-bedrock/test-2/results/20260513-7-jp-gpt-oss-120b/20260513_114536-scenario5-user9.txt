아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 코드 라인마다 이해를 돕기 위한 한국어 주석을 달아두었으니, 그대로 복사해서 실행하거나 공부에 활용해 보세요.

```python
def quick_sort(arr):
    """퀵소트 함수: 입력 리스트를 정렬하고 새로운 리스트를 반환한다."""
    
    # 리스트가 비었거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:
        return arr                           # ✅ 기본 종료 조건

    # 피벗(pivot)을 선택한다. 여기서는 리스트의 첫 번째 원소를 피벗으로 잡는다.
    pivot = arr[0]                           # 🎯 피벗 선택

    # 피벗보다 작은 원소들을 모아 left 리스트에 담는다.
    left = [x for x in arr[1:] if x <= pivot]   # 📦 left 서브리스트 생성
    # 피벗보다 큰 원소들을 모아 right 리스트에 담는다.
    right = [x for x in arr[1:] if x > pivot]   # 📦 right 서브리스트 생성

    # 재귀적으로 left와 right를 정렬하고,
    # 정렬된 left + 피벗 + 정렬된 right 순서로 합쳐서 반환한다.
    return quick_sort(left) + [pivot] + quick_sort(right)  # 🔁 재귀 호출 및 병합
```

### 사용 예시
```python
if __name__ == "__main__":
    unsorted = [34, 7, 23, 32, 5, 62]
    sorted_list = quick_sort(unsorted)
    print("정렬 전:", unsorted)
    print("정렬 후:", sorted_list)
```

**핵심 포인트**
- `pivot`을 기준으로 리스트를 두 개의 서브리스트(`left`, `right`)로 분할하고,
- 각각을 다시 퀵소트로 정렬한 뒤, **left + pivot + right** 순서로 합쳐 최종 결과를 만든다.
- 평균 시간 복잡도는 **O(N log N)**, 최악 경우(이미 정렬된 리스트에 대해 첫 번째 원소를 피벗으로 선택)에는 **O(N²)** 가 된다.  
  이를 방지하려면 무작위 피벗 선택이나 “median‑of‑three” 전략을 사용할 수 있다.
