아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 한글 주석을 달아 어떤 작업을 하는지 쉽게 이해할 수 있도록 했어요.

```python
def quick_sort(arr: list) -> list:          # 퀵소트를 수행할 함수를 정의하고, 입력은 리스트, 반환값도 리스트
    # 기저 조건 : 리스트가 비어 있거나 원소가 1개이면 이미 정렬된 것이므로 그대로 반환
    if len(arr) <= 1:                       
        return arr                          # 정렬이 필요 없으니 입력 리스트 자체를 반환

    # 피벗 선택 : 여기서는 리스트의 첫 번째 원소를 피벗(pivot)으로 사용
    pivot = arr[0]                           # 피벗은 현재 구간을 나누는 기준값

    # 피벗보다 작은 원소들을 모은 리스트(왼쪽 부분)
    left = [x for x in arr[1:] if x <= pivot]   # 피벗을 제외한 나머지 중 피벗 이하인 원소들을 left에 저장

    # 피벗보다 큰 원소들을 모은 리스트(오른쪽 부분)
    right = [x for x in arr[1:] if x > pivot]   # 피벗을 제외한 나머지 중 피벗 초과인 원소들을 right에 저장

    # 재귀 호출을 통해 left와 right 부분을 각각 정렬하고,
    # 정렬된 left, 피벗, 정렬된 right를 차례대로 이어 붙여 반환
    return quick_sort(left) + [pivot] + quick_sort(right)   # 재귀적으로 정렬 후 결합
```

### 코드 흐름 요약
1. **기저 조건**에서 리스트 길이가 1 이하면 바로 반환한다. → 재귀 호출이 무한히 진행되는 것을 방지.  
2. **피벗**을 선택한다. 여기선 첫 번째 원소를 선택했지만, 무작위 선택이나 중앙값 선택 등으로 바꿀 수 있다.  
3. 피벗을 기준으로 **좌측(left)**, **우측(right)** 두 부분 리스트를 만든다.  
4. **재귀 호출**을 통해 좌·우측 리스트를 각각 정렬한다.  
5. 정렬된 좌측, 피벗, 정렬된 우측을 **연결**해 최종 정렬된 리스트를 만든다.

### 사용 예시
```python
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 리스트
    sorted_list = quick_sort(unsorted)      # 퀵소트 함수를 호출해 정렬
    print(sorted_list)                      # 결과 출력 → [3, 10, 18, 29, 33, 55, 71]
```
