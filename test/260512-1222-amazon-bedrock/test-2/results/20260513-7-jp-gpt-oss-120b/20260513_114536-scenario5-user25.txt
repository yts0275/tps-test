아래는 파이썬으로 구현한 **인‑플레이스 퀵소트** 예시입니다.  
각 코드 라인마다 기능을 설명하는 주석을 한글로 달아 두었습니다.  
필요에 따라 `quicksort(arr, 0, len(arr)-1)` 와 같이 호출하면 됩니다.

```python
def quicksort(arr, low, high):                     # quicksort 함수 정의: 배열과 정렬 구간을 인자로 받는다
    if low < high:                                 # 구간이 한 개 이상일 때만 정렬을 진행한다
        i = low                                     # i는 현재 탐색 중인 왼쪽 포인터
        j = high                                    # j는 현재 탐색 중인 오른쪽 포인터
        pivot = arr[low]                            # 피벗은 구간의 가장 왼쪽 원소로 잡는다
        # 피벗을 기준으로 작은 원소는 왼쪽, 큰 원소는 오른쪽에 배치한다
        while i < j:                                # i와 j가 만나기 전까지 반복
            while i < j and arr[j] >= pivot:       # 오른쪽에서 피벗보다 작은 값을 찾을 때까지 이동
                j -= 1                              # j를 왼쪽으로 한 칸 이동
            if i < j:                               # 아직 i와 j가 만나지 않았으면
                arr[i] = arr[j]                     # 오른쪽 원소를 왼쪽 빈칸에 복사
                i += 1                              # i를 오른쪽으로 한 칸 이동
            while i < j and arr[i] <= pivot:       # 왼쪽에서 피벗보다 큰 값을 찾을 때까지 이동
                i += 1                              # i를 오른쪽으로 한 칸 이동
            if i < j:                               # 아직 i와 j가 만나지 않았으면
                arr[j] = arr[i]                     # 왼쪽 원소를 오른쪽 빈칸에 복사
                j -= 1                              # j를 왼쪽으로 한 칸 이동
        arr[i] = pivot                               # i(또는 j) 위치에 피벗을 최종 배치
        # 피벗을 기준으로 왼쪽·오른쪽 부분 배열에 대해 재귀 호출
        quicksort(arr, low, i - 1)                  # 피벗 왼쪽 부분을 정렬
        quicksort(arr, i + 1, high)                 # 피벗 오른쪽 부분을 정렬
```

### 사용 예시
```python
if __name__ == "__main__":               # 스크립트가 직접 실행될 때만 동작하도록 구분
    data = [33, 10, 55, 71, 29, 3, 18]   # 정렬할 예시 리스트
    print("정렬 전:", data)              # 정렬 전 리스트 출력
    quicksort(data, 0, len(data) - 1)    # 퀵소트 호출
    print("정렬 후:", data)              # 정렬 후 리스트 출력
```

### 설명 (요약)
1. **피벗 선택** – 여기서는 구간 가장 왼쪽 원소를 피벗으로 사용합니다.  
2. **분할 과정** – 두 포인터 `i`, `j`를 활용해 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 이동시킵니다.  
3. **재귀 호출** – 피벗이 최종적으로 제자리에 놓인 뒤, 피벗을 기준으로 좌·우 부분 배열을 다시 퀵소트합니다.
