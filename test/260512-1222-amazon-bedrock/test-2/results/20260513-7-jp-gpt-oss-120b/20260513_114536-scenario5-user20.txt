아래는 **파이썬** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 역할을 설명하는 주석을 달아 두었으니, 코드 흐름을 이해하는 데 도움이 될 거예요.  

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 배열이 비어 있거나 원소가 하나만 있으면 이미 정렬된 상태이므로 바로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 원소를 사용
    pivot = arr[-1]

    # 피벗보다 작은 원소를 모아 둘 리스트 (왼쪽 파티션)
    left = []
    # 피벗보다 큰 원소를 모아 둘 리스트 (오른쪽 파티션)
    right = []
    # 피벗과 같은 값이 여러 개 있을 때 따로 모아 둘 리스트
    middle = []

    # 배열의 모든 원소를 순회하며 세 파티션에 나눠 담는다
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:        # 피벗보다 크면 right에 추가
            right.append(x)
        else:                  # 피벗과 같으면 middle에 추가 (pivot 자체 포함)
            middle.append(x)

    # 재귀적으로 left와 right 파티션을 정렬하고,
    # 정렬된 left + middle(피벗들) + 정렬된 right 순서로 합쳐 반환
    return quick_sort(left) + middle + quick_sort(right)


# ------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬할 샘플 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]

    # 퀵소트 함수를 호출하여 정렬된 리스트 얻기
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 0 또는 1이면 그대로 반환합니다.  
2. **피벗 선택** – 여기서는 마지막 요소(`arr[-1]`)를 피벗으로 잡았습니다.  
3. **분할(partition)** – `left`, `middle`, `right` 세 개 리스트에 원소를 나눕니다.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 각각 정렬합니다.  
5. **병합** – `left`(정렬) + `middle`(피벗들) + `right`(정렬) 순서로 결합해 최종 결과를 반환합니다.  

이와 같이 퀵소트는 **분할‑정복** 전략을 이용해 평균 O(n log n)의 시간 복잡도를 갖는 효율적인 정렬 알고리즘이에요. 필요에 따라 피벗 선택 방식을 바꾸면 최악의 경우(O(n²))를 더욱 회피할 수 있습니다. 🎉
