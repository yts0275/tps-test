아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 라인마다 무엇을 하는지 주석을 달아 두었으니, 흐름을 따라가며 이해하기 쉽도록 작성했습니다.

```python
def quick_sort(arr):
    """리스트 arr를 제자리(in‑place) 정렬하고 정렬된 리스트를 반환한다."""
    
    # 내부 함수: 실제 재귀 정렬 로직을 담당한다.
    def _quick_sort(lo, hi):
        # 베이스 케이스: 구간에 원소가 0개 또는 1개이면 이미 정렬된 상태.
        if lo >= hi:
            return
        
        # ------------------------------------------------------------------
        # 1) 피벗 선택
        # 여기서는 구간의 가장 오른쪽 요소를 피벗으로 잡는다.
        # (다른 선택 방법도 가능: 첫 번째, 중앙, 무작위 등)
        # ------------------------------------------------------------------
        pivot = arr[hi]
        
        # ------------------------------------------------------------------
        # 2) 파티셔닝(partition) 수행
        # i는 피벗보다 작은(또는 같은) 원소들의 마지막 인덱스를 가리킨다.
        # 처음에는 lo-1 로 시작해 빈 구간을 의미한다.
        # ------------------------------------------------------------------
        i = lo - 1
        
        # lo부터 hi-1까지 순회하며 피벗보다 작거나 같은 원소를 앞쪽으로 이동한다.
        for j in range(lo, hi):
            if arr[j] <= pivot:          # 현재 원소가 피벗 이하인가?
                i += 1                    # i를 한 칸 오른쪽으로 이동
                arr[i], arr[j] = arr[j], arr[i]   # 작은 원소와 i번째 원소 교환
        
        # ------------------------------------------------------------------
        # 3) 피벗을 올바른 위치에 배치
        # 파티션이 끝난 후 i+1 위치가 피벗보다 큰 첫 번째 인덱스이므로,
        # 피벗을 그 자리에 옮겨 주면 피벗의 왼쪽은 모두 <= 피벗,
        # 오른쪽은 모두 > 피벗이 된다.
        # ------------------------------------------------------------------
        pivot_index = i + 1
        arr[pivot_index], arr[hi] = arr[hi], arr[pivot_index]
        
        # ------------------------------------------------------------------
        # 4) 재귀적으로 좌·우 부분을 정렬
        # - 왼쪽 구간: lo ~ pivot_index-1
        # - 오른쪽 구간: pivot_index+1 ~ hi
        # ------------------------------------------------------------------
        _quick_sort(lo, pivot_index - 1)   # 왼쪽 서브 배열 정렬
        _quick_sort(pivot_index + 1, hi)   # 오른쪽 서브 배열 정렬
    
    # ----------------------------------------------------------------------
    # 메인 호출: 전체 리스트를 0번째 인덱스부터 마지막 인덱스까지 정렬한다.
    # ----------------------------------------------------------------------
    _quick_sort(0, len(arr) - 1)
    return arr   # 정렬이 끝난 동일 리스트를 반환 (선택 사항)


# --------------------------------------------------------------
# 사용 예시
# --------------------------------------------------------------
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18, 90]
    print("정렬 전:", data)
    sorted_data = quick_sort(data)   # 제자리 정렬이므로 data 자체가 변한다.
    print("정렬 후:", sorted_data)
```

### 핵심 포인트 정리
| 단계 | 내용 | 시간 복잡도 |
|------|------|--------------|
| 피벗 선택 | 구간의 마지막 요소를 피벗으로 사용 | – |
| 파티셔닝 | `i`와 `j` 포인터를 이용해 피벗보다 작거나 같은 원소를 왼쪽으로 모음 | O(n) (구간 길이 n) |
| 재귀 호출 | 피벗을 기준으로 좌·우 서브배열을 각각 정렬 | – |
| 전체 복잡도 | 평균 O(n log n), 최악 O(n²) (피벗 선택이 최악인 경우) | – |

이 구현은 **제자리 정렬**이므로 별도의 추가 메모리를 거의 사용하지 않습니다(재귀 호출 스택 제외).  
피벗을 무작위로 선택하거나 “median‑of‑three” 전략을 쓰면 최악의 경우 발생 확률을 크게 낮출 수 있습니다. 필요에 따라 피벗 선택 부분만 교체하면 됩니다.
