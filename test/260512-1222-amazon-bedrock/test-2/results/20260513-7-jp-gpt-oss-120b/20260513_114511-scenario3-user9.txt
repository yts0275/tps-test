아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드는 이해를 돕기 위해 한 줄씩 상세히 주석을 달아 두었으니, 그대로 복사‑붙여넣기 하면 바로 실행해볼 수 있습니다.

```python
# -------------------------------
#  퀵소트(Quick Sort) 구현
# -------------------------------

def quick_sort(arr):
    """
    주어진 리스트를 정렬한 새 리스트를 반환한다.
    (in‑place 버전이 아니라, 새로운 리스트를 만드는 형태)
    """
    # 1️⃣ 기본 탈출 조건: 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # 정렬이 필요 없는 경우 바로 반환

    # 2️⃣ 피벗 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                    # 피벗은 현재 부분 리스트의 마지막 원소

    # 3️⃣ 피벗보다 작은 요소와 큰 요소를 담을 임시 리스트 준비
    less = []      # 피벗보다 작은 값들을 저장
    greater = []   # 피벗보다 큰 값들을 저장

    # 4️⃣ 피벗을 제외한 나머지 요소들을 순회하면서 두 리스트에 분배
    for element in arr[:-1]:           # 마지막 요소(피벗)를 제외하고 반복
        if element <= pivot:           # 피벗보다 작거나 같은 경우
            less.append(element)       # less 리스트에 삽입
        else:                          # 피벗보다 큰 경우
            greater.append(element)    # greater 리스트에 삽입

    # 5️⃣ 재귀 호출: 분할된 두 리스트 각각을 다시 퀵소트
    sorted_less = quick_sort(less)     # 작은 값들의 정렬 결과
    sorted_greater = quick_sort(greater)  # 큰 값들의 정렬 결과

    # 6️⃣ 정렬된 결과 병합: (작은값 정렬) + 피벗 + (큰값 정렬)
    return sorted_less + [pivot] + sorted_greater


# -------------------------------
#  사용 예시
# -------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
| 순서 | 설명 |
|------|------|
| 1️⃣  | 리스트 길이가 0·1이면 바로 반환 (재귀 종료 조건) |
| 2️⃣  | 피벗(pivot) 선정 – 여기선 마지막 원소 |
| 3️⃣  | `less`와 `greater` 두 개의 임시 리스트 준비 |
| 4️⃣  | 피벗을 제외한 모든 원소를 순회하며 `less`·`greater`에 분배 |
| 5️⃣  | `less`와 `greater` 각각에 대해 재귀적으로 `quick_sort` 호출 |
| 6️⃣  | 정렬된 `less` + 피벗 + 정렬된 `greater` 를 합쳐 최종 결과 반환 |

### 참고 사항
- **시간 복잡도**  
  - 평균 O(N log N) – 피벗을 잘 고르면 빠르게 동작  
  - 최악 O(N²) – 이미 정렬된 리스트에 대해 마지막 원소를 피벗으로 선택하면 발생  
- **안정성**  
  - 퀵소트는 **불안정** 정렬(같은 값의 순서가 보존되지 않을 수 있음)  
- **in‑place 구현**도 가능하지만, 위 예시는 가독성을 위해 새 리스트를 만들어 반환하는 형태로 작성했습니다.

필요에 따라 피벗 선택 방식을 `"중앙값"`, `"무작위 선택"` 등으로 바꾸면 최악 상황을 줄일 수 있습니다. 즐거운 코딩 되세요! 🚀
