아래는 **Python** 으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
코드의 각 줄마다 `#` 뒤에 한국어 주석을 달아 이해를 돕겠습니다.

```python
def quicksort(arr, low, high):
    # 기본 케이스: low >= high 이면 더 이상 정렬할 필요가 없음
    if low < high:
        # 전반부와 후반부를 나눌 파티션 인덱스를 얻음
        pi = partition(arr, low, high)

        # 파티션 인덱스 앞 부분 정렬
        quicksort(arr, low, pi - 1)

        # 파티션 인덱스 뒤 부분 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 가장 오른쪽 값을 피벗(pivot)으로 선택
    pivot = arr[high]
    
    # i : 피벗보다 작은 값이 들어갈 위치(중간 지점)
    i = low - 1
    
    # low 부터 high-1 까지 순회
    for j in range(low, high):
        # 현재 원소가 피벗보다 작으면, i를 한 칸 이동하고 swap
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동 (i+1 에 놓음)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗의 최종 인덱스를 반환
    return i + 1

# --------------------------- 사용 예시 ----------------------------
if __name__ == "__main__":
    sample = [10, 7, 8, 9, 1, 5]
    quicksort(sample, 0, len(sample) - 1)
    print("정렬된 배열:", sample)
```

### 코드 설명
1. **`quicksort` 함수**  
   * `low` 와 `high` 를 인덱스로 받아 재귀적으로 배열을 정렬합니다.  
   * 파티션(`partition`)을 호출해 피벗 위치(`pi`)를 구하고, 그 앞뒤를 각각 재귀 정렬합니다.

2. **`partition` 함수**  
   * 가장 오른쪽 원소를 피벗으로 삼아, 피벗보다 작은 값들은 왼쪽으로, 큰 값들은 오른쪽으로 모읍니다.  
   * `i` 는 피벗보다 작은 값들이 모일 마지막 인덱스를 가리키고, `j` 는 현재 검사 중인 인덱스입니다.  
   * 최종적으로 피벗을 `i+1` 위치로 이동시키며, 그 인덱스를 반환합니다.

3. **사용 예시**  
   * `sample` 배열을 퀵소트로 정렬하고 결과를 출력합니다.  
   * 프로그램이 직접 실행될 때만 `if __name__ == "__main__":` 블록이 실행됩니다.

이 구현은 평균적으로 **O(n log n)**, 최악의 경우 **O(n²)**(같은 피벗이 매번 가장 끝/시작에 있을 때) 시간복잡도를 가집니다. 힙 정렬 같은 다른 정렬 알고리즘을 사용하면 최악의 경우를 방지할 수 있지만, 퀵소트는 평균 성능이 좋고 구현이 간단하기 때문에 많은 경우에 사용됩니다.
