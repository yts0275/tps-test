아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 입니다.  
코드의 **각 줄마다** 한 줄 주석을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr: list[int]) -> None:
    """
    주어진 배열을 원소들을 오름차순으로 정렬합니다.
    인자로 전달된 리스트 자체를 재귀적으로 정렬하므로 반환값은 없습니다.
    """
    # 재귀 기반의 퀵소트 실행
    _quicksort_inplace(arr, 0, len(arr) - 1)

def _quicksort_inplace(arr: list[int], low: int, high: int) -> None:
    """
    배열 arr[low … high] 를 정렬합니다.
    """
    if low < high:                                # 정렬이 필요한 구간이 하나 이상의 원소를 가질 때
        pivot_idx = _partition(arr, low, high)     # 피벗을 기준으로 나누고 피벗의 최종 위치 찾기
        _quicksort_inplace(arr, low, pivot_idx - 1) # 피벗의 왼쪽 부분 재귀 정렬
        _quicksort_inplace(arr, pivot_idx + 1, high) # 피벗의 오른쪽 부분 재귀 정렬

def _partition(arr: list[int], low: int, high: int) -> int:
    """
    피벗(마지막 원소)을 기준으로 요소들을 정렬한 뒤 피벗이 놓일 최종 위치를 반환합니다.
    """
    pivot = arr[high]               # 피벗 선택 (배열의 마지막 원소)
    i = low - 1                     # i는 작은 값 그룹의 가장 오른쪽 인덱스

    for j in range(low, high):      # j는 현재 비교할 인덱스
        if arr[j] <= pivot:         # 현재 원소가 피벗 이하이면
            i += 1                  # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]   # j와 i의 원소를 교환

    # 피벗을 그보다 큰 요소 바로 직전, 즉 i+1 위치에 넣음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1                    # 피벗의 최종 인덱스 반환

# 사용 예시
if __name__ == "__main__":
    data = [34, 7, 23, 32, 5, 62]           # 정렬할 예시 리스트
    print("정렬 전:", data)                 # 정렬 전 데이터 출력
    quicksort(data)                         # 퀵소트 호출로 정렬 수행
    print("정렬 후:", data)                 # 정렬 후 데이터 출력
```

### 코드 동작 흐름
1. **`quicksort`** 함수가 최상위 호출자로 배열을 인자로 받고 `_quicksort_inplace` 재귀 함수를 호출.
2. **`_quicksort_inplace`** 은 현재 구간(`low ~ high`)이 한 개 이상의 원소를 포함하면  `partition` 으로 피벗 위치를 찾고, 그 피벗을 기준으로 좌·우 부분을 재귀적으로 정렬.
3. **`_partition`** 은 피벗(마지막 원소)을 기준으로 배열을 재배치하고 피벗이 최종적으로 위치할 인덱스를 반환.
4. 재귀 종료 조건(`low >= high`)에 이르면 최종 정렬이 완료.

이 구현은 **in‑place** 로 동작하므로 메모리 사용량이 적으며, 평균 시간 복잡도는 **O(n log n)** 입니다. 단, 최악의 경우(이미 정렬된 입력 등)에는 **O(n²)** 가 될 수 있습니다.
