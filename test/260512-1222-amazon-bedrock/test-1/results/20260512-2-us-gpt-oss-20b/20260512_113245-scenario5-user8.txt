아래는 파이썬으로 구현한 퀵소트(quick sort) 알고리즘입니다.  
**각 줄 뒤에 한 줄씩 주석을 달아 구현 원리를 설명했습니다.**

```python
def quicksort(arr):  # 퀵소트 함수 정의. 입력은 리스트(배열)이고 정렬된 리스트를 반환
    if len(arr) <= 1:  # 리스트 길이가 0 또는 1이면 이미 정렬된 상태임
        return arr  # 그대로 반환해 재귀 종료 조건
    pivot = arr[0]  # 첫 번째 요소를 피봇(pivot) 으로 선택
    less = [x for x in arr[1:] if x <= pivot]  # 피봇보다 작거나 같은 값들로 구성된 서브리스트
    greater = [x for x in arr[1:] if x > pivot]  # 피봇보다 큰 값들로 구성된 서브리스트
    # 재귀적으로 left와 right 서브리스트를 정렬하고 피봇과 합쳐서 전체 정렬 결과 반환
    return quicksort(less) + [pivot] + quicksort(greater)
```

### 사용 예시

```python
arr = [3, 6, 8, 10, 1, 2, 1]  # 정렬 전 리스트
sorted_arr = quicksort(arr)  # 퀵소트 호출
print(sorted_arr)  # 출력: [1, 1, 2, 3, 6, 8, 10]
```

**설명**  
1. **기반 조건**: 요소가 0개 또는 1개인 리스트는 이미 정렬 상태이므로 그대로 반환합니다.  
2. **피봇 선택**: 가장 흔한 구현은 첫 번째 요소를 피봇으로 삼는 것이지만, 퍼포먼스에 따라 최적의 피봇을 선택할 수도 있습니다.  
3. **분할**: 피봇보다 작은/큰 두 개의 서브리스트를 만들어 분할합니다.  
4. **재귀 및 결합**: 각각의 서브리스트를 재귀적으로 정렬한 뒤 피봇을 가운데에 삽입해서 최종 정렬된 리스트를 만듭니다.  

이 구현은 가독성이 좋고, 파이썬의 리스트 컴프리헨션을 활용해 간결하게 작성되었습니다. 필요에 따라 피봇 선택 방식을 바꾸거나, 인덱스를 직접 사용해 메모리 사용량을 줄이도록 수정할 수도 있습니다.
