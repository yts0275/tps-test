아래는 파이썬으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
코드의 **모든 줄에 주석을 달아** 이해가 쉽도록 해두었으니 참고해 주세요.

```python
def quicksort(arr):  # QuickSort 함수. arr(정렬할 리스트)를 인자로 받는다
    if len(arr) <= 1:  # 리스트의 길이가 0 또는 1이면 이미 정렬이 완료된 상태
        return arr  # 그대로 반환해 재귀 종료
    pivot = arr[len(arr) // 2]  # 리스트의 가운데 요소를 피벗(pivot)으로 선택
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 값들만 모은 리스트
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 값들을 모은 리스트
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 값들만 모은 리스트
    # 재귀적으로 각각의 리스트를 정렬하고, left, middle, right 순서대로 합쳐서 반환
    return quicksort(left) + middle + quicksort(right)
```

#### 활용 예시
```python
if __name__ == "__main__":  # 스크립트가 직접 실행될 때만 아래 코드 실행
    unsorted = [3, 6, 8, 10, 1, 2, 1]  # 예시 데이터
    print("정렬 전:", unsorted)  # 출력 전
    sorted_list = quicksort(unsorted)  # QuickSort 호출
    print("정렬 후:", sorted_list)  # 출력 후
```

위 예를 실행하면 다음과 같은 결과가 나옵니다.

```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
