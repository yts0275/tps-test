아래는 파이썬으로 작성한 **퀵소트(Quick Sort)** 구현 예시입니다.  
프로그램의 **각 줄마다** 주석을 달아, 동작 방식을 한눈에 이해할 수 있도록 하였습니다.

```python
def quicksort(arr):  # quicksort 함수 정의: 입력으로 받은 리스트를 정렬하여 반환
    if len(arr) <= 1:  # 리스트의 길이가 0 혹은 1인 경우(이미 정렬된 상태)
        return arr  # 그대로 반환
    pivot = arr[len(arr) // 2]  # 리스트의 중간 인덱스 값을 피벗(pivot) 으로 선택
    less = [x for x in arr if x < pivot]  # 피벗보다 작은 원소들만 모은 리스트
    equal = [x for x in arr if x == pivot]  # 피벗과 같은 원소들만 모은 리스트
    greater = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들만 모은 리스트
    return quicksort(less) + equal + quicksort(greater)  # 작은 부분, 피벗, 큰 부분을 재귀적으로 정렬 후 합쳐 반환
```

#### 간단한 테스트

```python
if __name__ == "__main__":
    unsorted_list = [3, 6, 8, 10, 1, 2, 1]
    sorted_list = quicksort(unsorted_list)  # Quick Sort 호출
    print("정렬 전:", unsorted_list)      # 정렬 전 리스트 출력
    print("정렬 후:", sorted_list)        # 정렬 후 리스트 출력
```

`quicksort` 함수는 *재귀* 방식으로 동작합니다.  
- **피벗(pivot)**: 리스트 중간 인덱스의 값을 사용했지만, 필요에 따라
  첫 번째, 마지막, 혹은 무작위 원소를 선택해도 무방합니다.  
- 피벗을 기준으로 **왼쪽(less)**, **같음(equal)**, **오른쪽(greater)** 세 개의 서브리스트를 만들고,
  **재귀 호출**을 통해 각 서브리스트를 다시 정렬한 뒤 최종적으로 합칩니다.  

이 구현은 대개 평균적으로 **O(n log n)**의 시간 복잡도를 갖지만,
똑같은 값이 많거나 이미 정렬된 경우 최악의 **O(n²)** 복잡도가 발생할 수 있음을 기억하세요.
