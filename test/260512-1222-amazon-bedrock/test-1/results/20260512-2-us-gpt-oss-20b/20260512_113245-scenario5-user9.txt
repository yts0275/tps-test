아래는 **Python**으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
각 줄마다 그 역할을 간단히 설명하는 주석을 넣어 두었으니, 한 눈에 이해하기 쉽습니다.

```python
def quicksort(arr):  # arr(리스트)를 매개변수로 받아 정렬된 리스트를 반환하는 함수 정의
    # 리스트의 길이가 0번이나 1번이면 이미 정렬이 완료된 상태라 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗 선택: 여기서는 가장 간단히 첫 번째 원소를 피벗으로 사용
    pivot = arr[0]  
    
    # 피벗보다 작거나 같은 원소들을 모은 리스트
    less = [x for x in arr[1:] if x <= pivot]  
    # 피벗보다 큰 원소들을 모은 리스트
    greater = [x for x in arr[1:] if x > pivot]  
    
    # 재귀적으로 left와 right를 정렬한 뒤, pivot을 가운데에 붙여 완전한 정렬 결과 반환
    return quicksort(less) + [pivot] + quicksort(greater)  

# --- 아래 코드는 사용 예시 --------------------------------------------------
if __name__ == "__main__":  # 스크립트가 직접 실행될 때만 아래 코드가 실행되도록 함
    unsorted = [34, 7, 23, 32, 5, 62]  # 정렬되지 않은 리스트 예시
    print("정렬 전:", unsorted)  
    sorted_list = quicksort(unsorted)  # quicksort 함수를 호출해 정렬 수행
    print("정렬 후 :", sorted_list)  
```

#### 주요 포인트
- **피벗 선택**: 첫 번째 원소를 사용했지만, 성능을 높이려면 중간값 혹은 랜덤 선택을 고려할 수 있습니다.  
- **재귀**: `less`와 `greater`를 `quicksort`에 다시 전달해 재귀 호출하면서 분할정복을 수행합니다.  
- **분할**: 리스트 컴프리헨션을 이용해 피벗을 기준으로 색인 없이 바로 두 개의 서브리스트를 만들었습니다.  

이렇게 하면 입력 리스트가 재귀적으로 분할·정렬되어 최종적으로 정렬된 리스트가 반환됩니다.
