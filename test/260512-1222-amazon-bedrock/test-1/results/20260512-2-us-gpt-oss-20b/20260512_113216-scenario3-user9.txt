**퀵소트 구현 (Python)**  
각 코드 줄마다 한국어 주석을 달아 이해하기 쉽도록 정리했습니다.

```python
def quicksort(arr):  # 정렬할 목록을 인수로 받는 재귀 함수 정의
    if len(arr) <= 1:  # 정해진 배열이 0개 또는 1개일 때
        return arr  # 이미 정렬된 상태이므로 그대로 반환
    pivot = arr[0]  # 첫 번째 원소를 피벗으로 선택
    less = [x for x in arr[1:] if x < pivot]  # 피벗보다 작은 값들을 모음
    greater = [x for x in arr[1:] if x >= pivot]  # 피벗보다 크거나 같은 값들을 모음
    return quicksort(less) + [pivot] + quicksort(greater)  # 재귀 호출 후 합쳐서 반환
```

위 함수를 호출하면 입력 리스트가 오름차순으로 정렬됩니다.  
예시:
```python
print(quicksort([3, 6, 8, 10, 1, 2, 1]))  # -> [1, 1, 2, 3, 6, 8, 10]
```
