아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드의 **각 줄마다** 설명이 들어간 주석을 달았습니다.

```python
def quick_sort(arr):                         # 1️⃣ 입력 받은 리스트를 정렬해서 반환하는 함수
    if len(arr) <= 1:                        # 2️⃣ 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                           # 3️⃣ 정렬된 리스트 그대로 반환

    pivot = arr[len(arr) // 2]               # 4️⃣ 중앙 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]     # 5️⃣ 피벗보다 작은 값들만 모음
    right = [x for x in arr if x > pivot]    # 6️⃣ 피벗보다 큰 값들만 모음
    equal = [x for x in arr if x == pivot]   # 7️⃣ 피벗과 같은 값들(중복 처리)

    # 8️⃣ 왼쪽 정렬 + 피벗(동일값) + 오른쪽 정렬을 재귀적으로 결합
    return quick_sort(left) + equal + quick_sort(right)

# -------------------------------
# 사용 예시
if __name__ == "__main__":               # 9️⃣ 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]       # 10️⃣ 정렬하고자 하는 예시 리스트
    sorted_list = quick_sort(sample)      # 11️⃣ 퀵소트 함수 호출
    print("정렬 전 : ", sample)           # 12️⃣ 원본 리스트 출력
    print("정렬 후 : ", sorted_list)     # 13️⃣ 정렬된 리스트 출력
```

### 주석 해설
- **1**~**7**: 퀵소트의 핵심 부품(피벗 선택, 분할)과 반환 조건을 한 줄씩 설명했습니다.  
- **8**: 재귀 호출로 왼쪽과 오른쪽을 다시 정렬한 뒤, `equal` 리스트(피벗과 같은 값)을 중간에 넣어 최종 정렬된 리스트를 만듭니다.  
- **9**~**13**: 실제 프로그램 실행 시 어떻게 동작하는지 한눈에 확인할 수 있는 테스트 코드와 주석이 붙어 있습니다.  

이 코드를 그대로 복사해서 실행하면, 주어진 `sample` 리스트가 오름차순으로 정렬되는 과정을 확인할 수 있습니다.
