아래는 **Python**으로 작성한 퀵소트(Quick Sort) 구현입니다.  
각 줄마다 해설 주석(`#`)을 달아 비슷한 단계가 무엇을 하는지 이해하기 쉽도록 하였습니다.

```python
# 퀵소트(Quick Sort) 함수 정의
def quicksort(arr):
    # 입력 배열이 0개 또는 1개일 때는 이미 정렬이 끝난 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 값을 배열의 가운데 원소로 선택
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 원소들로 이루어진 배열
    left = [x for x in arr if x < pivot]
    # 피벗과 같은 값(중복값)으로 이루어진 배열
    middle = [x for x in arr if x == pivot]
    # 피벗보다 큰 원소들로 이루어진 배열
    right = [x for x in arr if x > pivot]

    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬한 뒤,
    # 다시 합쳐서 완전한 정렬 결과를 반환
    return quicksort(left) + middle + quicksort(right)

# 사용 예시
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]
    print("원본:", data)
    sorted_data = quicksort(data)
    print("정렬된 결과:", sorted_data)
```

---

### 주요 포인트

| 단계 | 내용 | 시간복잡도 |
|------|------|-----------|
| 1 | 파이프라인 사이클(피벗 선정, 분할, 재귀 호출) | 평균 `O(n log n)` |
| 2 | 최악의 경우(이미 정렬돼 있거나 피벗이 가장 크거나 작음) | 최악 `O(n²)` |
| 3 | 메모리 사용 | 새 배열을 매번 만들어 `O(n)` |

- **분할 전략**: 피벗을 기준으로 ≤, =, ≥ 세 개 그룹으로 나누어 재귀 호출합니다.  
- **재귀 종료 조건**: 배열 길이가 `0` 또는 `1`이면 그 자체가 이미 정렬된 상태.  
- **피벗 선택**: 이 예시에서는 가운데 원소를 사용했습니다. 실제 구현에서는 일반적으로 가운데, 첫 번째, 마지막 또는 랜덤 중 하나를 고르곤 합니다.

필요에 따라 인덱스를 기준으로 **제자리(원본 배열을 바로 바꾸는)** 퀵소트도 구현할 수 있지만, 위 예시는 가독성이 가장 좋고 빠르게 테스트하기 좋습니다.
