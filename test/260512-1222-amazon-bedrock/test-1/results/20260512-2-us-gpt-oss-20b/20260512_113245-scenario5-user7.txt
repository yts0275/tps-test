아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
코드의 **각 줄**마다 한 줄 주석을 넣어 이해를 돕겠습니다.

```python
def quick_sort(arr, low, high):
    # 배열과 정렬 범위가 유효한지 확인합니다.
    if low < high:
        # partition 함수를 사용해 왼쪽(<= pivot)과 오른쪽(> pivot)으로 나누고
        # 파티션 지점인 pivot의 인덱스를 반환합니다.
        pivot_index = partition(arr, low, high)

        # 파티션 지점을 기준으로 왼쪽 부분( low ~ pivot_index-1 ) 정렬
        quick_sort(arr, low, pivot_index - 1)

        # 파티션 지점을 기준으로 오른쪽 부분( pivot_index+1 ~ high ) 정렬
        quick_sort(arr, pivot_index + 1, high)


def partition(arr, low, high):
    # high 번째 원소를 pivot 으로 잡습니다.
    pivot = arr[high]
    # i는 "pivot 보다 작거나 같은 원소"가 배치될 마지막 인덱스를 가리킵니다.
    i = low - 1

    # low 에서 high-1 까지 순회하며 pivot 보다 작은 원소를 찾습니다.
    for j in range(low, high):
        if arr[j] <= pivot:
            # i 를 한 칸 앞으로 이동시킵니다.
            i += 1
            # arr[i] 와 arr[j] 를 교환합니다.
            arr[i], arr[j] = arr[j], arr[i]

    # i+1 의 위치에 pivot 을 넣어서, 왼쪽은 <= pivot, 오른쪽은 > pivot 가 되게 합니다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 파티션 지점인 pivot이 올바른 위치(인덱스)를 반환합니다.
    return i + 1


if __name__ == "__main__":
    # 예시 배열
    arr = [33, 10, 55, 71, 29, 1, 84, 57, 5, 23]
    print("원본 배열:", arr)

    # quick_sort 호출: 전체 배열을 정렬합니다. 인덱스 범위는 0부터 len(arr)-1까지 입니다.
    quick_sort(arr, 0, len(arr) - 1)
    print("정렬 완료:", arr)
```

### 코드 요약

1. **quick_sort**  
   - 재귀적으로 배열을 정렬합니다.  
   - `partition` 을 이용해 기준값(피봇)을 정하고, 그 기준에 따라 왼쪽 방과 오른쪽 방을 재귀로 정렬합니다.

2. **partition**  
   - 피봇(`arr[high]`)을 기준으로 배열을 두 부분으로 나눕니다.  
   - 피봇보다 작은 값은 왼쪽에, 커서는 오른쪽에 위치하도록 교환합니다.  
   - 최종적으로 피봇의 올바른 인덱스를 반환합니다.

3. **main**  
   - 예시 배열을 정의하고, `quick_sort` 로 정렬한 뒤 결과를 출력합니다.

이 코드는 **in‑place** 방식으로 동작하며, 평균적으로 O(n log n)의 시간복잡도와 O(log n)의 재귀 스택 공간을 필요로 합니다. 필요에 따라 다른 프로그래밍 언어나 자료구조를 사용해도 전반적인 로직은 비슷합니다.
