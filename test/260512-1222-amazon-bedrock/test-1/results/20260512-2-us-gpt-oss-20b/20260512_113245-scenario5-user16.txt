아래는 **정수 배열**에 대해 퀵소트(quick sort)를 구현한 Java 예제입니다.  
코드의 모든 줄에 한 줄씩 주석을 달아, 해당 줄이 수행하는 역할을 자세히 설명했습니다. 

```java
// QuickSort.java
public class QuickSort {

    /* 
     * 배열 전체를 정렬하는 헬퍼 메서드입니다.  
     * 정렬 범위 (left ~ right)를 지정해주는 인자를 사용합니다.
     */
    public static void quickSort(int[] arr, int left, int right) {
        // 왼쪽 끝이 오른쪽 끝보다 크거나 같으면 정렬할 필요 없이 종료
        if (left >= right) return;

        // 배열을 기준값을 중심으로 파티션(분할)합니다.
        int pivotIndex = partition(arr, left, right);

        // 기준값보다 작은 부분 배열 재귀 정렬
        quickSort(arr, left, pivotIndex - 1);

        // 기준값보다 큰 부분 배열 재귀 정렬
        quickSort(arr, pivotIndex + 1, right);
    }

    /* 
     * 파티션 함수: 
     *   - 가장 오른쪽 원소를 pivot(기준값)으로 사용
     *   - pivot보다 작은 모든 원소를 왼쪽에, 큰 원소를 오른쪽에 배치
     *   - 최종 pivot의 위치를 반환해서 재귀 호출에서 사용
     */
    private static int partition(int[] arr, int left, int right) {
        // 가장 오른쪽 원소를 기준값으로 지정
        int pivot = arr[right];
        // 피벗보다 작은 원소의 최종 위치를 가리키는 인덱스
        int i = left - 1;

        // left부터 right-1까지 순회
        for (int j = left; j < right; j++) {
            // 현재 원소가 피벗 이하이면
            if (arr[j] <= pivot) {
                i++;                    // i를 한 칸 오른쪽으로 이동
                swap(arr, i, j);        // arr[i]와 arr[j]를 교환
            }
        }
        // 피벗을 기준값보다 큰 원소들 뒤에 위치시키기
        swap(arr, i + 1, right);
        // 피벗이 정렬된 위치 반환
        return i + 1;
    }

    /*
     * 두 인덱스에 해당하는 배열 원소를 교환(스왑)합니다.
     */
    private static void swap(int[] arr, int i, int j) {
        int temp = arr[i];  // 일시적으로 저장
        arr[i] = arr[j];    // 두 원소 교환
        arr[j] = temp;
    }

    // 메인 메서드: 예시 배열을 정렬해 보자.
    public static void main(String[] args) {
        int[] data = { 9, 3, 5, 1, 6, 8, 2, 7, 4 };

        System.out.println("정렬 전: ");
        for (int v : data) System.out.print(v + " ");
        System.out.println();

        // 전체 배열을 정렬 (left = 0, right = length-1)
        quickSort(data, 0, data.length - 1);

        System.out.println("정렬 후: ");
        for (int v : data) System.out.print(v + " ");
        System.out.println();
    }
}
```

### 코드 흐름 요약
1. **`quickSort`**: 재귀적으로 파티션 후 좌우 부분을 정렬합니다.  
2. **`partition`**: 가장 오른쪽 원소를 기준값으로 잡아, 그보다 작은 값은 왼쪽에, 큰 값은 오른쪽에 배치합니다.  
3. **`swap`**: 배열 원소 두 개를 교환하는 헬퍼입니다.  
4. **`main`**: 예시 배열을 만들어 정렬 전후를 출력합니다.

이 예제는 한 줄마다 한 번에 하나의 동작을 수행하도록 구조화되어 있어, 퀵소트 알고리즘의 핵심 개념을 따라가면서 이해하기 쉽습니다.
