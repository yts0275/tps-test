아래는 **Python**으로 구현한 퀵소트(Quick Sort)입니다.  
각 줄마다 한 줄씩 주석을 달아 코드를 이해하기 쉽도록 해두었어요.

```python
# 1  : 리스트를 인수로 받아 정렬된 새로운 리스트를 반환하는 퀵소트 함수
def quicksort(arr):
    # 2  : 원본 리스트의 길이가 0 또는 1이라면 이미 정렬 완료이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    # 3  : 리스트의 중간값을 피벗(pivot)으로 선택 (여기서는 첫 번째 원소 사용)
    pivot = arr[0]
    # 4  : 피벗보다 작거나 같은 원소로 이루어진 왼쪽 부분 리스트 (<= 를 사용해 중복 허용)
    less = [x for x in arr[1:] if x <= pivot]
    # 5  : 피벗보다 큰 원소로 이루어진 오른쪽 부분 리스트
    greater = [x for x in arr[1:] if x > pivot]
    # 6  : 재귀적으로 왼쪽 부분을 정렬하고, 피벗을 중간에 넣고 오른쪽 부분을 정렬해 결합
    return quicksort(less) + [pivot] + quicksort(greater)

# 예시 실행
if __name__ == "__main__":
    # 7  : 예시로 사용할 정수 리스트
    arr = [9, 2, 6, 4, 8, 3, 5, 1, 7]
    # 8  : 퀵소트 함수 호출 후 결과를 변수에 저장
    sorted_arr = quicksort(arr)
    # 9  : 정렬된 결과를 출력
    print("정렬 전:", arr)
    print("정렬 후:", sorted_arr)
```

**설명**  
- **줄 1–6** : 재귀적 방식으로 퀵소트를 수행합니다.  
- 피벗을 첫 번째 원소로 고정했지만, 중간값이나 무작위 값을 사용해 성능을 조금 더 개선할 수도 있습니다.  
- **줄 7–9** : 간단한 테스트 코드를 추가해 실행 결과를 확인할 수 있도록 했습니다.  

이 코드를 그대로 복사해서 실행하면, 리스트가 정렬된 결과를 터미널에서 바로 볼 수 있어요! 🚀
