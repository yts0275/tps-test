아래는 파이썬으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
모든 코드 라인에 **한국어 주석**을 달아, 각 줄이 수행하는 역할을 한눈에 알 수 있도록 했습니다.

```python
def quicksort(arr, low, high):  # quicksort 함수 정의: arr은 배열, low~high는 현재 서브배열의 인덱스 범위
    if low < high:  # 재귀 종료 조건: 서브배열에 2개 이상의 원소가 있을 때만 진행
        pi = partition(arr, low, high)  # 피벗 위치를 결정하고 배열을 파티션
        quicksort(arr, low, pi - 1)  # 피벗 왼쪽 부분 재귀 정렬
        quicksort(arr, pi + 1, high)  # 피벗 오른쪽 부분 재귀 정렬

def partition(arr, low, high):  # 파티션 함수 정의: 피벗(마지막 원소)을 기준으로 정렬
    pivot = arr[high]           # 고정 피벗 선택
    i = low - 1                 # i는 "작은 값"이 들어갈 위치를 가리킴
    for j in range(low, high):  # 서브배열 전체를 순회
        if arr[j] <= pivot:     # 현재 원소가 피벗보다 작거나 같으면 왼쪽으로 이동
            i += 1              # 작은 원소가 들어갈 위치를 한 칸 옮김
            arr[i], arr[j] = arr[j], arr[i]  # i와 j의 원소 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 정렬된 위치(i+1)에 삽입
    return i + 1                  # 피벗이 정렬된 최종 인덱스를 반환

def main():                      # 메인 함수: 예시 배열을 정렬해 보기
    arr = [10, 7, 8, 9, 1, 5]    # 정렬 전 배열
    print("원래 배열:", arr)     # 원본 배열 출력
    quicksort(arr, 0, len(arr) - 1)  # quicksort 호출
    print("정렬된 배열:", arr)  # 정렬 결과 출력

if __name__ == "__main__":       # 스크립트가 직접 실행될 때만 main 호출
    main()                       # 프로그램 실행
```

### 주요 포인트
- **재귀**를 이용해 파티션을 반복하며 전체 배열을 정렬합니다.  
- 피벗은 **배열의 마지막 원소**로 선택했으며, `partition`에서 이 피벗을 기준으로 작은 값과 큰 값으로 나눕니다.  
- 파티션이 끝나면 피벗은 최종 올바른 위치에 놓이므로, 그 왼쪽·오른쪽 부분에 대해 동일한 과정을 재귀적으로 진행합니다.  
- 평균/최악 시간 복잡도는 각각 **O(n log n)**, **O(n²)**이며, 공간 복잡도는 재귀 호출 스택을 제외하고는 **O(1)**입니다.  

코드에 표시된 주석이 각 단계의 동작을 명확히 설명해 주므로, 퀵소트가 어떻게 동작하는지 한눈에 파악할 수 있을 것입니다.
