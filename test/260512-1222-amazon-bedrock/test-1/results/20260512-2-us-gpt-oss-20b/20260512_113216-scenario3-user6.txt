아래는 **Python**으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
코드의 **모든 줄**에 한글 주석을 달았으니, 무엇을 하는지 바로 이해하실 수 있습니다.  

```python
# ---------------------  퀵소트 기본 구현  ---------------------

def quicksort(arr):
    # 1. 재귀 종료 조건: 길이가 0 또는 1인 배열은 이미 정렬되어 있으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗 요소 선택(마지막 요소를 피벗으로 사용)
    pivot = arr[-1]

    # 3. 피벗보다 작은 값들(≤ pivot)와 큰 값들(> pivot)으로 분리하기
    #    - arr[:-1] : 마지막 요소를 제외한 나머지 원소들
    #    - list comprehensions 를 이용해 분리
    less = [x for x in arr[:-1] if x <= pivot]      # 피벗보다 작거나 같은 값들
    greater = [x for x in arr[:-1] if x > pivot]    # 피벗보다 큰 값들

    # 4. 재귀적으로 정렬한 결과를 이어붙여 하나의 정렬된 리스트 반환
    #    - less를 정렬하고, 피벗을 추가하고, greater를 정렬한 뒤 합침
    return quicksort(less) + [pivot] + quicksort(greater)

# ---------------------  테스트용 예시  ---------------------

if __name__ == "__main__":
    # 테스트 배열 정의
    test_arr = [34, 7, 23, 32, 5, 62, 1, 9, 15, 26]

    # 퀵소트 실행
    sorted_arr = quicksort(test_arr)

    # 결과 출력
    print("원본 배열 :", test_arr)
    print("정렬 후 :", sorted_arr)
```

> **가장 핵심적인 아이디어**  
> 1. 피벗을 기준으로 두 그룹(작은/큰)으로 분리  
> 2. 재귀적으로 두 그룹을 정렬  
> 3. 정리된 두 그룹과 피벗을 합쳐 최종 정렬 결과 반환  

이 구현은 **시간 복잡도**가 평균적으로 **O(n log n)**이며, 최악의 경우(이미 정렬된 배열 등) **O(n²)**이 될 수 있습니다.  
필요에 따라 랜덤 피벗 선택, 인덱스 기반 in‑place 버전 등으로 성능이나 메모리 사용을 개선할 수 있습니다.
