아래는 파이썬으로 구현한 **퀵소트**(QuickSort) 예시입니다.  
코드의 각 줄마다 한국어 주석을 달아 이해하기 쉽게 만들었습니다.  

```python
# 1️⃣ 빠른 정렬(퀵소트) 함수 정의
def quicksort(arr):
    # 2️⃣ 리스트가 0 또는 1개의 원소만 있으면 이미 정렬되어 있으므로 그대로 반환
    if len(arr) <= 1:
        # 3️⃣ 반환: 정렬이 완료된 리스트
        return arr

    # 4️⃣ 피벗(pivot) 전략: 리스트 중간값을 선택하여 균형 잡힌 분할을 시도
    pivot = arr[len(arr) // 2]

    # 5️⃣ 피벗보다 작은 값들만 모은 서브리스트 생성
    lesser = [x for x in arr if x < pivot]
    # 6️⃣ 피벗과 같은 값들만 모은 서브리스트 생성
    equal = [x for x in arr if x == pivot]
    # 7️⃣ 피벗보다 큰 값들만 모은 서브리스트 생성
    greater = [x for x in arr if x > pivot]

    # 8️⃣ 재귀적으로 왼쪽(lesser)과 오른쪽(greater) 부분에 퀵소트 적용 후 연결
    return quicksort(lesser) + equal + quicksort(greater)


# ========================
# 아래는 호출 예시
# ========================
if __name__ == "__main__":
    # 9️⃣ 테스트용 정렬할 리스트
    unsorted = [34, 7, 23, 32, 5, 62, 32]
    print("정렬 전:", unsorted)          # 사전 상태 출력

    # 10️⃣ quicksort 함수 호출
    sorted_list = quicksort(unsorted)
    print("정렬 후 :", sorted_list)      # 정렬 결과 출력
```

### 코드 설명  
1. `quicksort` 함수는 입력 리스트를 정렬된 새 리스트로 반환합니다.  
2. 리스트가 비었거나 하나의 원소만 있을 때 재귀 종료 조건으로 사용합니다.  
3. `pivot`은 현재 리스트의 중간값으로 선택해 분할을 수행합니다.  
4–7. `lesser`, `equal`, `greater` 세 개의 리스트를 만들어 피벗을 기준으로 분리합니다.  
8. `lesser`와 `greater`에 대해 재귀 호출을 수행하고, `equal`은 그대로 합쳐 최종 정렬된 리스트를 반환합니다.  

위 예시를 실행하면 다음과 같은 출력이 나타납니다.  
```
정렬 전: [34, 7, 23, 32, 5, 62, 32]
정렬 후 : [5, 7, 23, 32, 32, 34, 62]
```

필요에 따라 피벗 선택 전략을 바꾸거나(예: 첫 번째 원소, 랜덤 등) **인‑포‑플레이스** 버전으로 바꾸어 볼 수도 있지만, 본 예시처럼 *가독성이 좋은* 형태로 주석을 달아 두면 학습과 디버깅에 큰 도움이 됩니다. 🚀
