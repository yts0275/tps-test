아래는 **Python**으로 구현한 퀵소트(QuickSort) 예시입니다.  
각 줄마다 주석을 달아 구현 과정을 자세하게 설명했습니다.

```python
# 배열을 인자로 받아 퀵소트를 수행하는 함수
def quick_sort(arr):
    # 배열이 비어 있거나 원소가 1개인 경우 그대로 반환
    if len(arr) <= 1:          # 1 : 조건문(배열 길이 <= 1 인 경우)
        return arr            # 2 : 그 배열 자체를 반환

    # 피봇(pivot)은 배열의 마지막 원소를 선택
    pivot = arr[-1]            # 3 : 피봇 값 저장

    # 피봇보다 작은 원소와 큰(혹은 같은) 원소를 각각 담을 리스트
    left = []                  # 4 : 피봇보다 작은 값들을 저장할 리스트
    right = []                 # 5 : 피봇보다 큰 값들을 저장할 리스트

    # 배열의 모든 원소(피봇 제외)에 대해 반복
    for x in arr[:-1]:        # 6 : 피봇을 제외한 원소들 순회
        if x < pivot:        # 7 : 피봇보다 작을 때
            left.append(x)   # 8 : left 리스트에 추가
        else:                # 9 : 피봇보다 크거나 같은 경우
            right.append(x)  # 10 : right 리스트에 추가

    # 재귀적으로 왼쪽과 오른쪽 부분을 정렬 후, 피봇을 중간에 삽입
    return quick_sort(left) + [pivot] + quick_sort(right)
    # 11 : 재귀 호출(왼쪽), 피봇, 재귀 호출(오른쪽) 합치기

# 사용 예시
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]   # 12 : 정렬할 데이터
    sorted_data = quick_sort(data) # 13 : 퀵소트 함수 호출
    print(sorted_data)             # 14 : 정렬 결과 출력
```

**설명**  
1. `quick_sort` 함수가 재귀적으로 호출되어 하위 문제를 해결합니다.  
2. 피봇을 기준으로 `left`와 `right` 두 리스트에 원소를 분리합니다.  
3. 재귀 호출을 통해 각 부분을 다시 정렬하고, 피봇이 가운데 오도록 합칩니다.  
4. 최종적으로 정렬된 리스트를 반환합니다.  

위 코드는 작은 배열에도 잘 동작하며, 루프와 재귀를 통한 분할 정복(분할정복법) 전략을 명확히 보여줍니다.
