아래는 Python으로 구현한 퀵소트(QuickSort) 알고리즘입니다.  
**각 줄에 한국어 주석을 달아 이해하기 쉽도록 하였습니다.**

```python
def quick_sort(arr):                  # 정렬하고자 하는 배열(arr)을 인자로 받는 함수 정의
    if len(arr) <= 1:                # 배열의 길이가 0 또는 1이면 정렬이 필요 없음
        return arr                    # 원본 배열 그대로 반환
    pivot = arr[len(arr) // 2]       # 배열의 중앙값을 피벗으로 선택 (pivot)
    
    left = [x for x in arr if x < pivot]     # 피벗보다 작은 원소들만 모음
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 원소들만 모음
    right = [x for x in arr if x > pivot]    # 피벗보다 큰 원소들만 모음
    
    return quick_sort(left) + middle + quick_sort(right)   # 재귀적으로 정렬한 왼쪽 + 중간 + 오른쪽을 합쳐 반환
    

# ===================== 사용 예시 =====================
if __name__ == "__main__":          # 스크립트가 주요 프로그램으로 실행될 때만 아래 코드 실행
    arr = [3, 6, 8, 10, 1, 2, 1]    # 정렬이 필요한 임의의 배열
    print("원본 배열:", arr)        # 원본 배열 출력
    sorted_arr = quick_sort(arr)    # quick_sort 함수 호출
    print("정렬된 배열:", sorted_arr)  # 정렬 후 결과 출력
```

### 코드 설명
1. **테이스터**: `if len(arr) <= 1`에서 배열의 길이가 1 이하이면 재귀 호출이 더 이상 필요 없으므로 그대로 반환합니다.  
2. **피벗 선택**: `pivot = arr[len(arr) // 2]` 가 배열의 중간값을 피벗으로 사용합니다.  
3. **분할**: 리스트 컴프리헨션을 이용해 피벗보다 작은 `left`, 같은 `middle`, 큰 `right` 세 부분으로 나눕니다.  
4. **재귀 정렬**: `quick_sort`를 `left`와 `right`에 재귀적으로 적용하고, `middle`과 결합해 최종 정렬된 리스트를 반환합니다.  
5. **실행 예시**: `if __name__ == "__main__":` 블록에서 예시 배열을 만들고 정렬 결과를 출력합니다.  

이 코드는 Python 3.6 이상에서 바로 실행 가능하며, 주석이 각각의 줄에 달려 있으므로 이해하기 쉽습니다. 필요하면 피벗 선택 방식을 변경하거나, 인플레이스(배열을 제자리에서 정렬) 버전으로 바꾸어 활용할 수 있습니다.
