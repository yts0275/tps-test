아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘 예시입니다.  
각 줄마다 주석을 달아 이해를 돕도록 했습니다.  

```python
def quick_sort(arr, low, high):
    # 인덱스 범위가 유효하면(정렬할 부분이 남아있으면) 재귀 진행
    if low < high:
        # partition() 함수를 호출해 피벗 위치(최종 정렬된 인덱스)를 찾는다.
        pi = partition(arr, low, high)
        # 피벗 바로 왼쪽에 있는 부분을 재귀로 정렬
        quick_sort(arr, low, pi - 1)
        # 피벗 바로 오른쪽에 있는 부분을 재귀로 정렬
        quick_sort(arr, pi + 1, high)


def partition(arr, low, high):
    # 고른 피벗 값(리스트 마지막 원소)
    pivot = arr[high]  
    # 피벗보다 작은 값이 있을 때 그 위치를 기억할 인덱스
    i = low - 1  
    # low 부터 high-1 까지 반복
    for j in range(low, high):
        # j번째 원소가 피벗보다 작다면, i를 한 칸 옮기고 교환
        if arr[j] <= pivot:
            i += 1
            # arr[i]와 arr[j] 위치 교환
            arr[i], arr[j] = arr[j], arr[i]
    # 마지막으로 피벗과 i+1번째 위치를 교환해 피벗을 정렬된 위치에 배치
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 최종적으로 자리 잡은 인덱스를 반환
    return i + 1


# 사용 예시
if __name__ == "__main__":
    # 정렬하고자 하는 배열
    data = [35, 12, 43, 8, 51, 7, 29, 16]
    print("정렬 전:", data)

    # quick_sort() 호출: low와 high 인덱스는 0과 len-1
    quick_sort(data, 0, len(data) - 1)

    print("정렬 후 :", data)
```

이 코드는 **인-플레이스(공간 효율성 O(1))** 인 바깥쪽을 재귀로 호출할 뿐 내부에서는 `partition()` 함수에서 배열을 조금씩 재배치하며 정렬합니다.  
주석이 한 줄마다 포함되어 있으니, 파이썬 초보자라도 순서대로 읽어가며 이해하기 쉽습니다.
