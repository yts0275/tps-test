아래는 파이썬으로 구현한 **퀵소트**(Quick Sort) 예시입니다.  
각 코드 줄 뒤에 해당 줄이 수행하는 동작을 한글 주석으로 설명해 두었습니다.

```python
# 퀵소트(Quick Sort) 구현 (재귀적 인-플레이스 버전)
# 배열을 순서대로 정렬하며, 원본 리스트를 그대로 바꿉니다.

def quick_sort(arr):
    # 정수형 리스트가 비어 있거나 하나밖에 없으면 정렬이 필요 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 보통 마지막 원소를 선택합니다.
    pivot = arr[-1]

    # 피벗보다 작은 값들로 구성된 서브리스트
    left = []
    # 피벗보다 큰 값들로 구성된 서브리스트
    right = []

    # 피벗 이외의 모든 원소에 대해 반복
    for x in arr[:-1]:
        # 현재 원소가 피벗보다 작거나 같으면 왼쪽 서브리스트에 추가
        if x <= pivot:
            left.append(x)
        # 그 외(피벗보다 큰) 경우는 오른쪽 서브리스트에 추가
        else:
            right.append(x)

    # 왼쪽 서브리스트를 재귀적으로 정렬한 결과
    sorted_left = quick_sort(left)
    # 오른쪽 서브리스트를 재귀적으로 정렬한 결과
    sorted_right = quick_sort(right)

    # 왼쪽 정렬본 + 피벗 + 오른쪽 정렬본을 합쳐서 정렬 완료
    return sorted_left + [pivot] + sorted_right


# 예시: 사용 방법
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 44, 12, 90]
    print("원본:", data)
    sorted_data = quick_sort(data)
    print("정렬된 결과:", sorted_data)
```

**설명**

- `if len(arr) <= 1:`  
  리스트가 비어나 하나의 원소만 있는 경우는 이미 정렬된 상태이므로 그대로 반환합니다.

- `pivot = arr[-1]`  
  가장 마지막 원소를 피벗으로 선택합니다. 피벗은 리스트를 두 개의 하위 리스트(`left`, `right`)로 분할할 기준이 됩니다.

- `for x in arr[:-1]:`  
  피벗을 제외한 모든 원소를 순회하면서, 피벗보다 작거나 같은 값은 `left`에, 나머지는 `right`에 추가합니다.

- `sorted_left = quick_sort(left)`  
  `left` 서브리스트를 재귀적으로 정렬합니다. 이때도 같은 방식(`피벗`, `left`, `right`)으로 나눠서 정렬합니다.

- `sorted_right = quick_sort(right)`  
  `right` 서브리스트를 재귀적으로 정렬합니다.

- `return sorted_left + [pivot] + sorted_right`  
  재귀 호출이 리턴한 정렬 결과와 피벗을 합쳐서 완전한 정렬된 리스트를 반환합니다.

이 구현은 **오버헤드가 적은** 재귀적 분할-정복 알고리즘으로, 평균 시간복잡도는 O(n log n)이며, 최악의 경우(O(n^2))도 발생할 수 있으나 피벗 선택 전략(예: 무작위 피벗, 중간값 피벗)을 바꾸면 이를 완화할 수 있습니다.
