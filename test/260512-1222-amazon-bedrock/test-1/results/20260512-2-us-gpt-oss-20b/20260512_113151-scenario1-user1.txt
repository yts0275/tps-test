아래는 **Python** 언어로 작성한 퀵소트(quick sort) 구현입니다.  
코드의 각 줄마다 `#` 뒤에 *해당 줄이 수행하는 의미*를 주석으로 적어 두었습니다.

```python
def quicksort(arr):                           # 정렬할 배열을 인자로 받는다.
    """퀵소트 알고리즘으로 배열을 오름차순 정렬한다."""
    
    # 1) 배열이 비어 있거나 하나의 원소만 있을 때는 이미 정렬이 끝난 상태이므로 그대로 반환
    if len(arr) <= 1:                                 # 배열 길이가 1 이하이면
        return arr                                     # 그대로 반환

    # 2) 피벗(절정값) 선택 – 여기서는 배열의 마지막 원소를 피벗으로 사용
    pivot = arr[-1]                                   # 피벗을 배열의 마지막 원소로 정수

    # 3) 피벗보다 작은 원소들과 같은/큰 원소들을 나눔
    less = []                                         # 피벗보다 작은 원소들을 담을 리스트
    greater = []                                      # 피벗보다 큰 원소들을 담을 리스트

    # 4) 피벗을 제외한 모든 원소를 순회하면서 분류
    for x in arr[:-1]:                                 # 피벗 제외 배열의 모든 원소 반복
        if x <= pivot:                                # 원소가 피벗보다 작거나 같으면
            less.append(x)                            # ㅍ["더 작음/같음" 리스트에 추가
        else:                                         # 원소가 피벗보다 크면
            greater.append(x)                         # ㅍ["크음"] 리스트에 추가

    # 5) 재귀 호출: 작은 따로 정렬 + 피벗 + 큰 따로 정렬
    #    이렇게 병합하면 전체 배열이 정렬된다.
    left_sorted = quicksort(less)                    # 왼쪽(작은) 부분 재귀 정렬
    right_sorted = quicksort(greater)                # 오른쪽(큰) 부분 재귀 정렬

    # 6) 정렬된 부분과 피벗을 합쳐서 반환
    return left_sorted + [pivot] + right_sorted     # 작은 리스트 + 피벗 + 큰 리스트 결합
```

### 사용 예시
```python
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", data)
    sorted_data = quicksort(data)
    print("정렬 후:", sorted_data)
```

결과:
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

> **주요 포인트**  
> 1. **피벗 선택**: 간단히 마지막 원소를 피벗으로 사용했지만 다른 전략(중앙값, 랜덤 등)도 가능하다.  
> 2. **재귀 호출**: 좌우 부분을 다시 퀵소트로 정렬하고, 그 결과를 합쳐서 전체를 정렬한다.  
> 3. **시간 복잡도**: 평균적으로 \(O(n \log n)\), 최악은 \(O(n^2)\) (피벗이 항상 최솟값 또는 최댓값일 경우).  
> 4. **공간 복잡도**: 재귀 호출 때문에 스택 공간이 필요하며, 별도 배열을 만들기 때문에 \(O(n)\)의 추가 공간을 사용한다.
