아래는 파이썬으로 구현한 **퀵소트**(QuickSort) 예시입니다.  
각 줄마다 주석을 달아 이해를 쉽게 도와드릴게요.

```python
# 깔끔한 재귀 호출을 위해 인덱스를 직접 전달
def quicksort(arr, low, high):
    # 두 인덱스가 서로 교차하지 않으면(요소가 한 개 이하인 경우) 정렬이 끝난다.
    if low < high:
        # 배열을 피벗을 기준으로 분할하고, 피벗이 위치한 인덱스를 반환
        pi = partition(arr, low, high)
        # 피벗보다 작은 부분 배열 정렬
        quicksort(arr, low, pi - 1)
        # 피벗보다 큰 부분 배열 정렬
        quicksort(arr, pi + 1, high)

# 피벗을 기준으로 배열을 분할하고, 피벗의 최종 인덱스를 반환
def partition(arr, low, high):
    # 가장 오른쪽 원소를 피벗으로 고정
    pivot = arr[high]
    # i는 "피벗보다 작거나 같은" 원소가 있어야 할 가장 오른쪽 인덱스를 가리킨다
    i = low - 1
    # low부터 high-1까지 반복하며 피벗보다 작으면 왼쪽으로 이동
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 한 칸 오른쪽으로
            i += 1
            # i와 j에 있는 원소를 서로 교환
            arr[i], arr[j] = arr[j], arr[i]
    # 마지막으로 피벗을 i+1 위치에 놓아 두면, i+1이 피벗의 정해진 위치가 된다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗이 배열에서 차지한 최종 인덱스를 반환
    return i + 1

# ----------------- 사용 예시 -----------------

# 정렬할 숫자 리스트
arr = [10, 7, 8, 9, 1, 5]
# 전체 범위(0부터 len-1)를 인덱스로 지정
quicksort(arr, 0, len(arr) - 1)

# 결과 출력
print("Sorted array is:", arr)
```

**주요 포인트**

1. **피벗 선택**: 가장 오른쪽 원소를 피벗으로 사용했습니다.  
2. **재귀 종료 조건**: `low < high` 가 만족하지 않으면 더 이상 분할할 수 없으므로 함수를 빠져나옵니다.  
3. **배열 분할**: `partition` 함수에서 피벗보다 작은 원소를 왼쪽으로 모으고, 피벗을 그 사이에 넣습니다.  
4. **인덱스 기반 정렬**: 인덱스(`low`와 `high`)를 직접 전달해 재귀를 수행함으로써 공간 효율성을 유지합니다.

필요에 따라 피벗 전략(예: 랜덤 피벗)이나 버전(외부 정렬을 위해 새 리스트 반환)을 손쉽게 바꿔서 활용할 수 있어요! 궁금한 점이 있으면 언제든 물어보세요. 😊
