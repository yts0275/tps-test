아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 행마다 **한 줄 주석**을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr):
    # 리턴값이 없어도 상관없이 파이썬에서는 1개 이상의 값이 반환될 때만 사용
    # 1. 입력 배열이 한 개 이하라면 이미 정렬이 완료된 것
    if len(arr) <= 1:
        return arr          # 정렬된 배열 자체를 그대로 반환

    # 2. 피벗을 배열의 마지막 원소로 정하기
    pivot = arr[-1]

    # 3. 피벗보다 작은 값들을 담을 리스트
    left = []
    # 4. 피벗보다 큰 혹은 같은 값을 담을 리스트
    right = []

    # 5. 피벗을 제외한 원소들을 순회하며 두 리스트에 분류
    for x in arr[:-1]:
        if x < pivot:       # 6. 피벗보다 작은 경우 left에 추가
            left.append(x)
        else:               # 7. 피벗보다 크거나 같은 경우 right에 추가
            right.append(x)

    # 8. 재귀적으로 왼쪽과 오른쪽 서브배열을 정렬
    # 9. 정렬된 왼쪽 서브배열 + 피벗 + 정렬된 오른쪽 서브배열을 합쳐 반환
    return quicksort(left) + [pivot] + quicksort(right)


# 사용 예시
if __name__ == "__main__":
    # 10. 임의의 정수를 포함한 배열 선언
    sample = [8, 3, 9, 1, 5, 6, 7, 2, 4]

    # 11. 퀵소트 함수를 호출해 정렬된 결과를 받음
    sorted_array = quicksort(sample)

    # 12. 결과 출력
    print("정렬 전 :", sample)
    print("정렬 후 :", sorted_array)
```

### 주요 포인트

- `if len(arr) <= 1: return arr`  
  재귀 종료 조건. 원소가 0개 또는 1개이면 이미 정렬이 되어 있음을 의미합니다.

- 피벗(`pivot`)을 마지막 원소로 잡았지만, 다른 위치나 랜덤 값으로 바꾸어도 무방합니다.

- 재귀 호출을 통해 `left`와 `right`를 각각 정렬한 뒤 합치는 방법(`+`)은 파이썬에서 리스트 합친 결과를 반환합니다. 다른 언어(예: C, Java 등)에서는 다른 합치기(배열 복사)를 구현해야 합니다.

- 이 구현은 **불변성**을 유지하지 않으며, 입력 배열 자체는 변경하지 않습니다.  
  원본 배열을 바로 정렬하고 싶다면 `arr[:len(arr)//2]`처럼 슬라이스를 직접 변형하거나, 내장 함수 `list.sort()`를 활용할 수 있습니다.
