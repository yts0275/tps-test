아래는 파이썬으로 구현한 **퀵소트(quick sort)** 알고리즘입니다.  
각 줄마다 문장 끝에 `#` 뒤로 한 줄 주석을 달아 이해하기 쉽도록 설명했습니다.

```python
def quick_sort(arr):                     # 1. 재귀 함수를 이용해 배열을 정렬하는 함수 정의
    if len(arr) <= 1:                    # 2. 배열 길이가 0 또는 1이면 이미 정렬되어 있으므로 그대로 반환
        return arr                       # 3. 정렬된 배열을 반환
    pivot = arr[-1]                      # 4. 피벗으로 배열의 마지막 원소를 선택
    # 5-6. 피벗보다 작거나 같은 원소와 큰 원소를 새 리스트에 분리
    less = [x for x in arr[:-1] if x <= pivot]   # 5. 피벗 이하 원소들을 모은 리스트
    greater = [x for x in arr[:-1] if x > pivot] # 6. 피벗 초과 원소들을 모은 리스트
    # 7. 재귀 호출로 앞쪽과 뒤쪽 부분을 정렬한 후 합쳐서 반환
    return quick_sort(less) + [pivot] + quick_sort(greater)  # 7. 정렬이 완료된 부분을 결합

# ---------------------------- 테스트 예시 ----------------------------
if __name__ == "__main__":                 # 8. 직접 실행할 때만 아래 코드가 실행
    arr = [3, 6, 8, 10, 1, 2, 1]           # 9. 테스트용 배열 정의
    print("정렬 전:", arr)                 # 10. 정렬 전 배열 출력
    sorted_arr = quick_sort(arr)           # 11. 정렬 함수 호출
    print("정렬 후:", sorted_arr)          # 12. 정렬 후 배열 출력
```

주요 포인트  
- **피벗 선택**: 구현에서는 마지막 원소를 피벗으로 사용했습니다.  
- **분할**: 피벗보다 작은/같은 값과 큰 값을 각각 `less`, `greater` 리스트에 분리합니다.  
- **재귀**: `less`와 `greater` 각각에 대해 `quick_sort`를 재귀적으로 호출한 뒤, 피벗을 중간에 두고 합칩니다.  
- **기본 사례**: 배열이 0개 혹은 1개이면 바로 반환합니다.  

이렇게 하면 `O(n log n)` 평균 복잡도를 가지면서도 구현이 간단한 퀵소트를 얻을 수 있습니다. 🚀
