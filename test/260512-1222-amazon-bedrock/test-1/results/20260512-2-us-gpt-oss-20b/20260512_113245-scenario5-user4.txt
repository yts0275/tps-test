아래는 **Python**으로 구현한 퀵소트(QuickSort) 예제입니다.  
코드의 각 줄마다 주석을 달아 동작을 한눈에 파악할 수 있도록 했습니다.

```python
# 퀵소트 구현 예시 (Python)

def quick_sort(arr, low, high):
    """
    재귀적으로 사전순으로 정렬하기 위한 퀵소트 함수
    - arr : 정렬할 리스트
    - low : 현재 탐색 구간의 시작 인덱스
    - high: 현재 탐색 구간의 끝 인덱스
    """
    if low < high:                            # 1. 재귀 종료 조건: 구간이 1개 이하라면 더 이상 분할할 필요 없음
        pivot_index = partition(arr, low, high)  # 2. 피벗을 기준으로 좌우 구간 분할
        quick_sort(arr, low, pivot_index - 1)    # 3. 피벗보다 작은 구간 재귀 호출
        quick_sort(arr, pivot_index + 1, high)   # 4. 피벗보다 큰 구간 재귀 호출


def partition(arr, low, high):
    """
    피벗 선택 후 좌우 교환 순수 분할 처리
    - 반환값 : 피벗이 최종 도착한 인덱스
    """
    pivot = arr[high]           # 5. 가장 끝 원소를 피벗으로 선정
    i = low - 1                 # 6. i를 low-1로 초기화 (이미 올바른 위치에 있는 값 앞을 가리키는 인덱스)
    for j in range(low, high):  # 7. low부터 high-1까지 반복
        if arr[j] <= pivot:     # 8. 현재 원소가 피벗보다 작거나 같으면
            i += 1              # 9. i를 한 칸 앞으로 이동 (작은 값이 있는 위치)
            arr[i], arr[j] = arr[j], arr[i]  # 10. arr[i]와 arr[j] 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 11. 피벗을 올바른 위치에 놓음
    return i + 1               # 12. 피벗의 최종 인덱스 반환


# 예시 실행
if __name__ == "__main__":
    data = [9, 4, 7, 3, 8, 5, 1, 6, 2]  # 13. 정렬할 데이터
    quick_sort(data, 0, len(data) - 1)  # 14. 퀵소트 호출
    print("정렬된 결과:", data)          # 15. 정렬 완료 후 결과 출력
```

### 코드 해설

1. **재귀 종료 조건**  
   `low < high` 가 거짓이면 구간이 1개 이하이므로 재귀를 중단합니다.

2. **피벗 분할**  
   `partition` 함수는 피벗(`arr[high]`)을 기준으로 좌우 구간을 나누며,  
   피벗보다 작은 값은 모두 왼쪽에, 큰 값은 오른쪽에 정렬합니다.

3. **재귀 호출**  
   분할이 끝난 뒤 `partition`이 돌려준 `pivot_index`를 기준으로  
   피벗 앞과 뒤 구간을 각각 다시 퀵소트합니다.

4. **Partition 과정**  
   - `i`는 이미 올바른 위치에 놓인 값의 가장 오른쪽 인덱스를 가리킵니다.  
   - `j`는 아직 검사되지 않은 원소를 가리킵니다.  
   - `arr[j] <= pivot` 인 경우 `i`를 한 칸 이동시키고 `arr[i]` 와 `arr[j]` 를 교환합니다.  
   - 마지막에 피벗을 `i+1` 위치에 올려두어, 좌우가 정렬된 상태가 됩니다.

5. **예시 실행**  
   리스트 `data` 를 정의하고, `quick_sort` 를 호출한 뒤 결과를 출력합니다.

필요에 따라 `partition` 함수를 다른 피벗 전략(중간값, 랜덤 등)으로 바꾸면 성능에 차이가 생길 수 있습니다.  
이 예제에서는 가장 단순히 끝 원소를 피벗으로 사용했습니다.
