아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 자세히 설명하는 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 것입니다.

```python
def quick_sort(arr):                     # 1️⃣ 정렬할 리스트(arr)를 매개변수로 받는 함수 정의
    """                                    # 2️⃣ 함수에 대한 간단한 docstring
    퀵소트 알고리즘을 이용해 arr를 제자리(in‑place) 정렬합니다.
    반환값은 정렬된 리스트 자체이며, 입력 리스트가 변경됩니다.
    """                                    # 3️⃣ docstring 종료
    _quick_sort(arr, 0, len(arr) - 1)    # 4️⃣ 내부 재귀 함수를 호출, 정렬 구간을 전체 인덱스로 지정

def _quick_sort(arr, low, high):         # 5️⃣ 실제 재귀 작업을 수행하는 헬퍼 함수 정의
    """                                    # 6️⃣ 헬퍼 함수에 대한 docstring
    low와 high는 현재 정렬하고 있는 구간의 시작·끝 인덱스입니다.
    """                                    # 7️⃣ docstring 종료
    if low < high:                       # 8️⃣ 구간이 하나 이상의 원소를 포함하는 경우에만 재귀 수행
        pivot_index = _partition(arr, low, high)  # 9️⃣ 피벗을 기준으로 분할하고, 피벗이 최종 위치한 인덱스를 반환
        _quick_sort(arr, low, pivot_index - 1)    # 🔟 피벗 왼쪽(작은 값들) 구간에 대해 재귀 호출
        _quick_sort(arr, pivot_index + 1, high)   # 1️⃣1️⃣ 피벗 오른쪽(큰 값들) 구간에 대해 재귀 호출
    # 1️⃣2️⃣ low >= high이면 구간 길이가 0 또는 1이므로 정렬이 필요 없고 바로 반환

def _partition(arr, low, high):           # 1️⃣3️⃣ 피벗을 선택하고 배열을 재배치하는 함수 정의
    """                                    # 1️⃣4️⃣ docstring
    가장 오른쪽 원소를 피벗으로 삼아,
    피벗보다 작은 원소들을 왼쪽에, 큰 원소들을 오른쪽에 배치합니다.
    최종적으로 피벗이 들어갈 위치(index)를 반환합니다.
    """                                    # 1️⃣5️⃣ docstring 종료
    pivot = arr[high]                     # 1️⃣6️⃣ 피벗을 현재 구간의 가장 마지막 원소로 지정
    i = low - 1                           # 1️⃣7️⃣ i는 “작은 원소들의 마지막 인덱스” 역할, 초기값은 low‑1
    for j in range(low, high):            # 1️⃣8️⃣ 현재 구간을 순회하며 피벗보다 작은 원소를 찾음
        if arr[j] <= pivot:               # 1️⃣9️⃣ 현재 원소가 피벗보다 작거나 같으면
            i += 1                         # 2️⃣0️⃣ 작은 원소들의 경계(i)를 오른쪽으로 한 칸 이동
            arr[i], arr[j] = arr[j], arr[i]  # 2️⃣1️⃣ 작은 원소를 경계 바로 뒤(i)로 스와핑
            # 이렇게 하면 low~i 구간은 모두 피벗보다 작거나 같은 값이 됩니다.
    # for 루프 종료 후, i는 피벗보다 작은 원소들의 마지막 인덱스를 가리킴
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 2️⃣2️⃣ 피벗을 작은 원소들 뒤(i+1)로 이동시켜 최종 위치 지정
    return i + 1                         # 2️⃣3️⃣ 피벗이 최종적으로 자리 잡은 인덱스를 반환

# ------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":               # 2️⃣4️⃣ 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [33, 10, 55, 71, 29, 3, 18] # 2️⃣5️⃣ 정렬 대상 리스트
    print("정렬 전 :", sample)          # 2️⃣6️⃣ 정렬 전 리스트 출력
    quick_sort(sample)                  # 2️⃣7️⃣ 퀵소트 함수 호출 (리스트가 제자리에서 정렬됨)
    print("정렬 후 :", sample)          # 2️⃣8️⃣ 정렬 후 리스트 출력
```

### 코드 흐름 요약
1. **`quick_sort`** : 외부 인터페이스. 입력 리스트 전체를 정렬하도록 `_quick_sort`를 호출합니다.  
2. **`_quick_sort`** : 재귀 함수. `low < high`인 경우에만 **분할(`_partition`) → 좌·우 구간 재귀** 를 수행합니다.  
3. **`_partition`** : 피벗(`arr[high]`)을 기준으로 원소들을 재배치하고, 피벗이 최종으로 위치할 인덱스를 반환합니다.  
4. 재귀가 끝나면 전체 리스트가 오름차순으로 정렬됩니다.

이렇게 각 라인마다 상세 주석을 달아 두면, 초보자도 퀵소트가 어떤 단계로 동작하는지 쉽게 따라가며 이해할 수 있습니다. 🎉
