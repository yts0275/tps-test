아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 한글 주석을 달아 코드의 흐름을 자세히 설명했으니, 직접 실행해 보면서 이해해 보세요!

```python
# quick_sort 함수는 정렬이 필요한 리스트와 정렬 구간의 시작, 끝 인덱스를 매개변수로 받는다.
def quick_sort(arr, low, high):
    # 구간이 하나의 원소만 포함하거나 빈 구간이면 이미 정렬된 것이므로 바로 반환한다.
    if low < high:
        # 파티션 함수를 호출해 피벗(pivot)의 최종 위치를 구한다.
        # pivot_index는 피벗이 최종적으로 놓인 인덱스를 의미한다.
        pivot_index = partition(arr, low, high)

        # 피벗 왼쪽 부분 배열을 재귀적으로 정렬한다.
        quick_sort(arr, low, pivot_index - 1)

        # 피벗 오른쪽 부분 배열을 재귀적으로 정렬한다.
        quick_sort(arr, pivot_index + 1, high)


# partition 함수는 현재 구간 [low, high] 안에서 피벗을 기준으로
# 피벗보다 작은 원소는 왼쪽에, 큰 원소는 오른쪽에 배치하고,
# 피벗을 올바른 위치에 놓은 뒤 그 인덱스를 반환한다.
def partition(arr, low, high):
    # 여기서는 가장 오른쪽 원소를 피벗으로 선택한다.
    pivot = arr[high]

    # i는 "피벗보다 작은 원소들의 마지막 인덱스"를 가리킨다.
    # 초기값은 low - 1 (즉, 아직 작은 원소가 없음을 의미)
    i = low - 1

    # low부터 high-1까지 순회하면서 현재 원소와 피벗을 비교한다.
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 하나 증가시키고, 그 위치와 현재 원소를 교환한다.
            # 이렇게 하면 i까지의 구간은 모두 피벗보다 작은(또는 같은) 값이 된다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 모든 원소를 검사한 뒤, 피벗을 i+1 위치와 교환한다.
    # 이제 피벗은 정확히 “왼쪽은 피벗보다 작고, 오른쪽은 피벗보다 큰” 위치에 놓인다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 인덱스를 반환한다.
    return i + 1


# -------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬할 예시 리스트
    data = [34, 7, 23, 32, 5, 62, 19, 4]

    print("정렬 전:", data)

    # quick_sort 호출 (전체 구간을 지정)
    quick_sort(data, 0, len(data) - 1)

    print("정렬 후:", data)
```

### 코드 흐름 요약
1. **quick_sort**는 재귀적으로 구간을 나누며 정렬한다.  
2. **partition**은 피벗을 기준으로 원소들을 두 그룹(작은/큰)으로 나누고, 피벗을 올바른 위치에 둔다.  
3. 피벗을 기준으로 좌·우 구간을 다시 quick_sort에 넘겨 전체 리스트가 정렬될 때까지 반복한다.

이렇게 구현된 퀵소트는 평균 \(O(n \log n)\) 시간 복잡도를 가지며, 제자리(in‑place) 정렬이기 때문에 추가 메모리 사용이 거의 없습니다. 필요에 따라 피벗 선택 전략(예: 랜덤 피벗, 중앙값 피벗)만 바꾸면 더욱 최악 상황을 방지할 수 있습니다. 🚀
