아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 한글 주석을 달아 흐름을 상세히 설명했으니, 코드와 주석을 같이 보시면 이해가 쉬울 거예요.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 배열이 비었거나 원소가 하나뿐이면 이미 정렬된 상태 → 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 가운데 원소를 피벗으로 사용
    # (다른 전략을 써도 무방하지만, 평균적인 성능을 위해 중간값을 선택)
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 원소들을 모아 놓을 리스트
    left = []
    # 피벗과 같은 원소들을 모아 놓을 리스트
    middle = []
    # 피벗보다 큰 원소들을 모아 놓을 리스트
    right = []

    # 현재 배열의 모든 원소를 순회하면서 위 세 리스트에 분류
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:        # 피벗보다 크면 right에 추가
            right.append(x)
        else:                  # 피벗과 같으면 middle에 추가 (중복된 피벗을 보존)
            middle.append(x)

    # 재귀적으로 left와 right 부분을 정렬하고,
    # 정렬된 결과와 middle(피벗)들을 이어붙여 최종 정렬된 리스트 반환
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------------------------------------------------------
# 사용 예시 (테스트)
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90, 42, 7]

    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 혹은 1이면 바로 반환 (이미 정렬된 상태).  
2. **피벗 선택** – 여기서는 리스트 중간 원소를 피벗으로 잡아 평균적인 성능을 기대.  
3. **분할 단계** – 리스트를 `left(피벗보다 작음)`, `middle(피벗과 동일)`, `right(피벗보다 큼)` 세 그룹으로 나눔.  
4. **재귀 호출** – `left`와 `right` 그룹을 각각 다시 `quick_sort` 로 정렬.  
5. **병합 단계** – 정렬된 `left` + `middle` + 정렬된 `right` 를 이어 붙여 최종 결과 반환.

### 참고 사항
- **시간 복잡도**  
  - 평균‑O(n log n)  
  - 최악‑O(n²) (피벗 선택이 최적이 아닐 때)  
- **공간 복잡도** – 재귀 호출 스택과 새 리스트(`left`, `middle`, `right`) 때문에 O(n) 정도 추가 메모리를 사용합니다.  
- **피벗 선택 전략**을 바꾸면 최악 케이스를 회피할 수 있습니다. (예: 무작위 피벗, Median‑of‑Three 등)

필요에 따라 리스트를 직접 복사하지 않고 **in‑place** 로 구현하거나, 피벗 선택 방식을 바꾸어 성능을 튜닝할 수 있어요. 궁금한 점이 있으면 언제든 물어보세요! 🚀
