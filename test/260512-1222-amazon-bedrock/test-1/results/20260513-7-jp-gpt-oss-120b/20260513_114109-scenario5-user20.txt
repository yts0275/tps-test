아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 줄마다 한글 주석을 달아 동작을 상세히 설명했습니다.  
필요에 따라 `quick_sort()` 함수를 직접 호출해 정렬된 리스트를 얻을 수 있습니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행하는 메인 함수 정의
    """                                 # 함수 설명 문자열 (docstring)
    입력받은 리스트 arr를 재귀적으로 정렬하여 새로운 리스트 반환
    """                                 # docstring 종료

    # 리스트가 비어있거나 원소가 하나만 있으면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:                    # 정렬이 필요 없는 경우 검사
        return arr                        # 그대로 반환

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 원소를 피벗으로 사용
    pivot = arr[-1]                       # 마지막 원소를 피벗으로 지정

    # 피벗보다 작은 원소들을 모은 리스트와
    # 피벗보다 큰(또는 같은) 원소들을 모은 리스트를 각각 생성
    left = [x for x in arr[:-1] if x < pivot]   # 피벗보다 작은 원소들만 모음
    right = [x for x in arr[:-1] if x >= pivot] # 피벗보다 크거나 같은 원소들 모음

    # 재귀적으로 left와 right 부분을 정렬하고,
    # 피벗을 가운데에 두어 최종 정렬된 리스트를 만든다
    return quick_sort(left) + [pivot] + quick_sort(right)  # 재귀 호출 및 병합
```

### 사용 예시

```python
if __name__ == "__main__":               # 이 파일이 직접 실행될 때만 동작하도록
    unsorted = [33, 10, 55, 71, 29, 3]   # 정렬되지 않은 예시 리스트
    sorted_list = quick_sort(unsorted)   # 퀵소트 함수 호출하여 정렬
    print("정렬 전 :", unsorted)         # 정렬 전 리스트 출력
    print("정렬 후 :", sorted_list)      # 정렬 후 리스트 출력
```

---  

#### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용(다른 선택도 가능).  
3. **분할** – 피벗보다 작은 원소(`left`)와 피벗보다 크거나 같은 원소(`right`)로 리스트를 나눔.  
4. **재귀 정렬** – `left`와 `right`에 대해 각각 `quick_sort`를 다시 호출.  
5. **병합** – 정렬된 `left` + 피벗 + 정렬된 `right` 순서로 하나의 리스트로 합침.  

이 구현은 **새로운 리스트**를 반환하므로 원본 리스트는 변하지 않으며,  
시간 복잡도는 평균 *O(N log N)*, 최악 *O(N²)* (피벗 선택이 최악인 경우) 입니다.  
필요에 따라 제자리(in‑place) 버전을 구현하거나, 피벗을 무작위로 선택해 최악 상황을 완화할 수 있습니다.
