아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 무슨 역할을 하는지 상세히 설명하는 주석을 한글로 달아 두었으니, 코드를 따라가면서 이해하면 도움이 될 거예요.

```python
# ---------- 퀵소트 구현 (Python) ----------
# 퀵소트는 “분할 정복(Divide & Conquer)” 전략을 이용한 정렬 알고리즘입니다.
# 1) 배열(리스트) 중 하나의 요소를 기준값(pivot)으로 선택합니다.
# 2) 기준값보다 작은 원소와 큰 원소를 각각 별도 리스트에 나눕니다.
# 3) 나눠진 두 리스트에 대해 재귀적으로 같은 과정을 반복합니다.
# 4) 재귀가 끝난 뒤, (작은 리스트) + (기준값) + (큰 리스트) 순으로 합치면 정렬이 완성됩니다.

def quick_sort(arr):
    """
    입력:  정렬되지 않은 리스트 arr
    반환값: 정렬된 새로운 리스트 (원본 리스트는 변경되지 않음)
    """
    
    # ① 베이스 케이스: 리스트가 비었거나 원소가 하나이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                     # 리스트를 그대로 반환하고 재귀 호출을 종료
    
    # ② 피벗(pivot) 선택
    # 여기서는 가장 첫 번째 원소를 피벗으로 잡았습니다.
    # (다른 전략: 무작위 선택, 중간값 선택 등)
    pivot = arr[0]                     # 피벗 변수에 첫 번째 원소 저장
    
    # ③ 피벗을 기준으로 두 개의 서브리스트 만들기
    #    * left  : 피벗보다 작은 원소들
    #    * right : 피벗보다 큰(또는 같은) 원소들
    left = []                          # 피벗보다 작은 원소들을 담을 리스트 초기화
    right = []                         # 피벗보다 크거나 같은 원소들을 담을 리스트 초기화
    
    # ④ 원본 리스트의 두 번째 원소부터 끝까지 순회하면서 left / right에 분류
    for element in arr[1:]:            # 슬라이스를 이용해 첫 번째 원소(pivot)를 제외하고 순회
        if element < pivot:            # 현재 원소가 피벗보다 작으면
            left.append(element)       # left 리스트에 추가
        else:                          # 피벗보다 크거나 같으면
            right.append(element)      # right 리스트에 추가
    
    # ⑤ 재귀 호출: left와 right 각각 다시 퀵소트를 적용
    #    * quick_sort(left)  → left 리스트가 정렬된 결과를 반환
    #    * quick_sort(right) → right 리스트가 정렬된 결과를 반환
    sorted_left = quick_sort(left)     # 왼쪽 서브리스트 정렬
    sorted_right = quick_sort(right)   # 오른쪽 서브리스트 정렬
    
    # ⑥ 정렬된 결과 합치기
    #    왼쪽 정렬 결과 + 피벗 + 오른쪽 정렬 결과 순서대로 이어붙이면 전체가 정렬됩니다.
    return sorted_left + [pivot] + sorted_right   # 최종 정렬된 리스트 반환


# --------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬되지 않은 임의의 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]
    
    # 퀵소트 함수 호출
    sorted_list = quick_sort(unsorted)
    
    # 결과 출력
    print("원본 리스트 :", unsorted)      # 원본 리스트는 변하지 않음
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름을 한눈에 정리하면

| 단계 | 내용 | 주요 동작 |
|------|------|-----------|
| 1️⃣   | 베이스 케이스 체크 | 리스트 길이가 0 또는 1이면 그대로 반환 |
| 2️⃣   | 피벗 선택 | 여기선 `arr[0]` (첫 번째 원소) |
| 3️⃣   | 분할 | 피벗보다 작은 원소 → `left`, 나머지 → `right` |
| 4️⃣   | 재귀 호출 | `quick_sort(left)`, `quick_sort(right)` |
| 5️⃣   | 합치기 | `sorted_left + [pivot] + sorted_right` |

### 참고사항
- **시간 복잡도**  
  *평균*: `O(N log N)` <br>
  *최악* (이미 정렬된 상태 등): `O(N²)` → 피벗 선택 전략을 개선(예: 랜덤 피벗)하면 최악 상황을 줄일 수 있습니다.
- **공간 복잡도**  
  재귀 호출과 새로운 리스트(`left`, `right`)를 만들기 때문에 `O(N)` 정도의 추가 메모리를 사용합니다.
- **원본 리스트 보존**  
  이 구현은 입력 리스트를 그대로 두고, 정렬된 새 리스트를 반환합니다. 원본을 직접 변경하고 싶다면 `in‑place` 버전을 구현해야 합니다.

필요에 따라 **피벗 선택**을 무작위(`random.choice(arr)`)로 바꾸거나, **in‑place** 버전으로 변형하면 성능을 더 최적화할 수 있습니다. 🎯
