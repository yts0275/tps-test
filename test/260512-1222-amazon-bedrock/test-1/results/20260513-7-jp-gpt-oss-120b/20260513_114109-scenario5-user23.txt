아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하고 있는지 상세히 설명하는 주석을 한글로 달아두었으니, 직접 실행해 보면서 이해에 도움이 되길 바랍니다.

```python
def quick_sort(arr: list) -> list:                     # quick_sort 함수를 정의한다. 입력은 리스트, 반환값도 리스트
    """                                                  # 함수의 동작을 간단히 설명하는 docstring
    퀵소트 알고리즘을 재귀적으로 구현한다.
    """
    # 1) 길이가 0 또는 1인 경우는 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:                                 # 기본 사례(base case) 확인
        return arr                                     # 정렬이 필요 없는 경우 바로 반환

    # 2) 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 잡는다.
    pivot = arr[-1]                                    # 피벗은 리스트의 마지막 원소

    # 3) 피벗보다 작은 원소들을 저장할 리스트와 피벗보다 큰(또는 같은) 원소들을 저장할 리스트를 만든다.
    less = []                                          # 피벗보다 작은 값들을 담을 리스트
    greater = []                                       # 피벗보다 크거나 같은 값들을 담을 리스트

    # 4) 피벗을 제외한 나머지 원소들을 순회하면서 두 리스트에 나눠 담는다.
    for x in arr[:-1]:                                 # 피벗을 제외한 모든 원소에 대해 반복
        if x < pivot:                                  # 현재 원소가 피벗보다 작으면
            less.append(x)                             # less 리스트에 추가
        else:                                          # 현재 원소가 피벗보다 크거나 같으면
            greater.append(x)                          # greater 리스트에 추가

    # 5) 재귀 호출을 이용해 부분 리스트들을 각각 정렬한다.
    sorted_less = quick_sort(less)                     # less 리스트를 다시 quick_sort 로 정렬
    sorted_greater = quick_sort(greater)               # greater 리스트도 동일하게 정렬

    # 6) 정렬된 결과를 합쳐서 최종 정렬 리스트를 만든다.
    #    (정렬된 less) + (피벗) + (정렬된 greater) 순서가 바로 오름차순 정렬된 리스트가 된다.
    return sorted_less + [pivot] + sorted_greater      # 최종 결과 반환


# ----------------------------------------------------------------------
# 사용 예시 (직접 실행해 보세요)
if __name__ == "__main__":                             # 스크립트가 직접 실행될 때만 아래 코드를 수행
    sample = [34, 7, 23, 32, 5, 62]                    # 임의의 정수 리스트
    print("원본 리스트 :", sample)                     # 정렬 전 리스트 출력
    sorted_sample = quick_sort(sample)                # quick_sort 함수 호출
    print("정렬된 리스트 :", sorted_sample)           # 정렬 후 리스트 출력
```

### 코드 흐름 요약
1. **기본 사례** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용.  
3. **분할** – 피벗보다 작은 원소와 큰(또는 같은) 원소를 두 개의 서브 리스트로 나눈다.  
4. **재귀 호출** – 각각의 서브 리스트에 대해 `quick_sort`를 다시 실행하여 정렬한다.  
5. **합치기** – `sorted_less + [pivot] + sorted_greater` 형태로 최종 정렬 리스트를 만든다.

---

#### 🎯 팁
- **피벗 선택 전략**을 바꾸면 최악의 경우(`O(n²)`)를 회피하고 평균 `O(n log n)` 성능을 더 안정적으로 확보할 수 있다.  
  예: 무작위 원소 선택, 중간값(median‑of‑three) 선택 등.  
- 파이썬의 **리스트 슬라이싱**(`arr[:-1]`)은 새로운 리스트를 만들기 때문에 메모리 사용량이 늘어날 수 있다.  
  메모리를 절약하고 싶다면 **인덱스와 구간을 이용한 제자리(in‑place) 구현**을 고려해 보세요.
