아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 한국어 주석을 달아 두었으니, 동작 흐름을 쉽게 이해하실 수 있을 거예요.  

```python
def quick_sort(arr):                      # 퀵소트 함수를 정의합니다. 정렬할 리스트 arr를 매개변수로 받음
    # 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:                     # 기저 사례: 정렬할 필요가 없는 경우
        return arr                        

    # 피벗(pivot) 선택 – 여기서는 리스트의 첫 번째 요소를 사용
    pivot = arr[0]                         # 피벗은 기준이 되는 원소

    # 피벗보다 작은 원소들을 모아 left 리스트에 저장
    left = [x for x in arr[1:] if x < pivot]   # 피벗보다 작은 값들
    # 피벗과 같은 원소들을 모아 middle 리스트에 저장 (피벗 자체도 포함)
    middle = [x for x in arr if x == pivot]   # 피벗과 같은 값들 (중복 허용)
    # 피벗보다 큰 원소들을 모아 right 리스트에 저장
    right = [x for x in arr[1:] if x > pivot]  # 피벗보다 큰 값들

    # 재귀적으로 left와 right 리스트를 정렬하고,
    # 정렬된 left + middle + 정렬된 right 를 합쳐 반환
    return quick_sort(left) + middle + quick_sort(right)  # 재귀 호출로 부분 리스트를 정렬하고 결합
```

### 사용 예시
```python
unsorted = [33, 10, 55, 71, 29, 3, 18]   # 정렬되지 않은 리스트
sorted_list = quick_sort(unsorted)       # 퀵소트 함수 호출
print(sorted_list)                       # 결과 출력 → [3, 10, 18, 29, 33, 55, 71]
```

---

#### 코드 설명 (한 줄 요약)

| 라인 | 설명 |
|------|------|
| 1 | 퀵소트 함수 정의 |
| 2‑3 | 리스트 길이가 0·1이면 바로 반환 (재귀 종료 조건) |
| 5 | 피벗을 첫 원소로 선택 |
| 7 | 피벗보다 작은 원소들을 `left`에 저장 |
| 9 | 피벗과 같은 원소들을 `middle`에 저장 (중복 허용) |
| 11 | 피벗보다 큰 원소들을 `right`에 저장 |
| 13‑14 | `left`와 `right`를 재귀적으로 정렬하고, `middle`과 합쳐 최종 결과 반환 |

이렇게 하면 **분할 정복(Divide and Conquer)** 전략을 이용해 리스트를 효율적으로 정렬할 수 있습니다.  
시간 복잡도는 평균 `O(N log N)`, 최악(이미 정렬된 경우)에는 `O(N²)`이지만 피벗을 무작위로 선택하거나 median‑of‑three 방식을 적용하면 최악 상황을 크게 완화할 수 있습니다.
