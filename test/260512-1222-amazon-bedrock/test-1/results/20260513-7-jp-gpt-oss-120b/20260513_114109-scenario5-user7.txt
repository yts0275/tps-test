아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 한국어 주석을 달아 두었으니, 흐름을 따라가며 이해해 보세요.

```python
def quick_sort(arr):
    """퀵소트 함수: 리스트 arr를 정렬해서 새 리스트로 반환한다."""
    
    # 1️⃣ 기본 사례: 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2️⃣ 피벗(pivot) 선택 – 여기서는 리스트의 가장 마지막 요소를 사용
    pivot = arr[-1]                     # 피벗은 정렬 기준이 되는 값
    
    # 3️⃣ 피벗보다 작은 값들을 담을 리스트
    left = []                           # left에는 피벗보다 작은 원소들
    
    # 4️⃣ 피벗보다 큰 혹은 같은 값들을 담을 리스트
    right = []                          # right에는 피벗보다 크거나 같은 원소들
    
    # 5️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left / right에 분배
    for x in arr[:-1]:                  # 마지막 요소(피벗)를 제외하고 순회
        if x < pivot:                   # 피벗보다 작으면 left에
            left.append(x)
        else:                           # 피벗보다 크거나 같으면 right에
            right.append(x)
    
    # 6️⃣ 재귀 호출을 통해 left와 right 부분을 각각 정렬하고,
    #    정렬된 left + 피벗 + 정렬된 right 를 이어붙여 결과 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# ------------------------------
# 사용 예시
# ------------------------------
if __name__ == "__main__":
    unsorted = [34, 7, 23, 32, 5, 62]   # 정렬되지 않은 예시 리스트
    sorted_list = quick_sort(unsorted) # 퀵소트 호출
    print("정렬 전 :", unsorted)
    print("정렬 후 :", sorted_list)
```

### 코드 흐름 요약
1. **기본 사례** – 리스트가 0·1개이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 잡음(다른 방법도 가능).  
3. **분할** – 피벗을 기준으로 작은 값은 `left`, 큰 값은 `right`에 저장.  
4. **재귀** – `left`와 `right`에 대해 같은 과정을 다시 수행(재귀 호출).  
5. **합치기** – 정렬된 `left` + 피벗 + 정렬된 `right`를 이어서 최종 결과를 만든다.  

이 구현은 **제자리(in‑place) 퀵소트**가 아니라 **새 리스트를 반환**하는 형태이며,  
가독성을 위해 라인마다 주석을 달았습니다. 필요에 따라 피벗 선택 전략이나  
제자리 구현으로 바꾸어 사용할 수 있습니다.
