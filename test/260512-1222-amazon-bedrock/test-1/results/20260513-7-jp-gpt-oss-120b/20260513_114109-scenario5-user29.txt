아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 무엇을 하는지 상세히 설명하는 주석을 달아두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):
    """리스트 arr 를 제자리(in‑place) 퀵소트로 정렬하고 정렬된 리스트를 반환한다."""
    
    # 정렬 대상이 되는 구간을 지정하는 재귀 함수
    def _quick_sort(start, end):
        # 구간에 원소가 1개 이하이면(시작 인덱스 >= 끝 인덱스) 정렬할 필요 없음
        if start >= end:
            return
        
        # 피벗(pivot) 선택: 여기서는 구간의 가장 오른쪽 원소를 피벗으로 사용
        pivot = arr[end]                     # 피벗값 저장
        
        # i는 피벗보다 작거나 같은 원소들의 마지막 위치를 가리킴
        i = start - 1                        # i 를 구간 시작 이전으로 초기화
        
        # j는 start 부터 end‑1 까지 순회하면서 현재 원소와 피벗을 비교
        for j in range(start, end):
            # 현재 원소가 피벗보다 작거나 같다면, i 를 한 칸 늘리고 두 원소를 교환
            if arr[j] <= pivot:
                i += 1                       # i 를 오른쪽으로 이동
                arr[i], arr[j] = arr[j], arr[i]  # 작은 원소들을 왼쪽으로 몰기
        
        # 모든 원소를 검사한 뒤, 피벗을 i+1 위치에 놓아 왼쪽은 피벗보다 작고, 오른쪽은 크도록 함
        arr[i + 1], arr[end] = arr[end], arr[i + 1]
        pivot_index = i + 1                 # 피벗이 최종적으로 자리 잡은 인덱스
        
        # 피벗을 기준으로 왼쪽 구간을 재귀적으로 정렬
        _quick_sort(start, pivot_index - 1)
        # 피벗을 기준으로 오른쪽 구간을 재귀적으로 정렬
        _quick_sort(pivot_index + 1, end)
    
    # 전체 리스트에 대해 재귀 정렬 시작
    _quick_sort(0, len(arr) - 1)
    # 정렬이 끝난 리스트를 반환 (리스트 자체가 변형됐으므로 반환은 선택 사항)
    return arr


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬되지 않은 샘플 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]
    print("정렬 전:", unsorted)

    # quick_sort 함수를 호출해 정렬 수행
    sorted_list = quick_sort(unsorted)

    print("정렬 후:", sorted_list)
```

### 코드 흐름 요약
1. `quick_sort` 함수가 호출되면, 내부에 정의된 `_quick_sort` 재귀 함수를 이용해 **시작 인덱스(start)**와 **끝 인덱스(end)**를 지정한다.  
2. 재귀 함수는 현재 구간이 1개 이하면 바로 반환하고, 아니라면  
   - 구간의 마지막 원소를 **피벗**으로 선택한다.  
   - `i`와 `j` 포인터를 이용해 피벗보다 작거나 같은 원소들을 왼쪽으로 몰아 놓는다.  
   - 마지막에 피벗을 `i+1` 위치와 교환해 피벗이 정확한 최종 위치에 오도록 한다.  
3. 피벗을 기준으로 좌·우 구간을 각각 재귀 호출해 정렬한다.  
4. 모든 재귀 호출이 끝나면 원본 리스트 `arr` 가 정렬된 상태가 된다.

이렇게 구현된 퀵소트는 **제자리(in‑place)** 정렬이며, 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(이미 정렬된 배열 등) `O(N²)` 입니다. 필요에 따라 피벗 선택 전략을 바꾸면 최악의 경우 발생 확률을 낮출 수 있습니다.
