아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 무슨 동작을 하는지 상세히 주석을 달아 두었으니, 코드 흐름을 이해하는 데 도움이 될 거예요.

```python
# quick_sort.py
# ------------------------------
# 퀵소트(Quick Sort) 구현 예시
# 평균 시간 복잡도 : O(N log N)
# 최악 시간 복잡도 : O(N^2) (피벗 선택이 최악일 경우)
# 공간 복잡도      : O(log N) (재귀 호출 스택)
# ------------------------------

def quick_sort(arr):
    """
    입력받은 리스트를 정렬한 새 리스트를 반환한다.
    - 원본 리스트는 그대로 두고 새로운 리스트를 만든다(불변성 유지).
    - 파이썬의 리스트 슬라이싱을 활용해 간결하게 구현한다.
    """
    # 1. 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선정
    #    여기서는 리스트의 중간 요소를 피벗으로 잡는다.
    #    (첫 번째 요소나 마지막 요소를 잡아도 무방하지만,
    #    중간을 잡으면 평균적인 경우에 성능이 조금 더 안정적이다.)
    mid_index = len(arr) // 2
    pivot = arr[mid_index]

    # 3. 피벗을 제외한 나머지 요소들을 세 개의 그룹으로 분류한다.
    #    - left  : 피벗보다 작은 요소들
    #    - middle: 피벗과 같은 요소들 (피벗 자체를 포함)
    #    - right : 피벗보다 큰 요소들
    left = []      # 피벗보다 작은 값들을 담을 리스트
    middle = []    # 피벗과 같은 값들을 담을 리스트
    right = []     # 피벗보다 큰 값들을 담을 리스트

    # 4. 리스트를 한 번 순회하면서 각 요소를 적절한 그룹에 넣는다.
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left 그룹
            left.append(x)
        elif x > pivot:        # 피벳보다 크면 right 그룹
            right.append(x)
        else:                  # 피벗과 같으면 middle 그룹
            middle.append(x)

    # 5. 재귀적으로 left와 right 그룹을 정렬한다.
    #    - left와 right가 비어있지 않을 경우에만 재귀 호출이 일어난다.
    sorted_left = quick_sort(left)     # 왼쪽 부분 정렬
    sorted_right = quick_sort(right)   # 오른쪽 부분 정렬

    # 6. 정렬된 결과를 하나의 리스트로 합친다.
    #    순서 : 정렬된 left + middle(피벗) + 정렬된 right
    return sorted_left + middle + sorted_right


# -------------------------------------------------
# 아래 코드는 직접 실행해볼 수 있도록 만든 간단한 테스트 코드이다.
# -------------------------------------------------
if __name__ == "__main__":
    # 예제 리스트 (무작위 순서)
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 90, 42, 5]

    # 퀵소트를 이용해 정렬
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트 길이가 0 혹은 1이면 그대로 반환.  
2. **피벗 선택** – 중간 요소를 피벗으로 잡아 평균적인 성능을 기대.  
3. **분할 단계** – 리스트를 `left`, `middle`, `right` 세 그룹으로 나눔.  
4. **재귀 호출** – `left`와 `right` 그룹을 각각 다시 `quick_sort`로 정렬.  
5. **합병 단계** – 정렬된 `left`, `middle`, `right`를 순서대로 이어서 최종 결과 생성.

이제 이 파일을 `python quick_sort.py` 로 실행하면, 콘솔에 원본 리스트와 정렬된 리스트가 출력됩니다. 🎉

*(주석은 모두 한국어로 작성했으며, 각 라인의 역할을 최대한 자세히 설명했습니다.)*
