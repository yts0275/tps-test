아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 무슨 일을 하는지 설명하는 주석을 달았습니다.  

```python
# --------------------------------------------------------------
# 퀵소트(Quick Sort) 구현
# --------------------------------------------------------------

def quick_sort(arr: list[int]) -> list[int]:
    """입력받은 리스트를 정렬한 새로운 리스트를 반환한다."""
    
    # 1️⃣ 기저조건 : 리스트가 비어있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환한다.
    if len(arr) <= 1:
        return arr                     # ← 정렬이 필요 없는 경우

    # 2️⃣ 피벗(pivot) 선택 : 여기서는 리스트의 첫 번째 원소를 피벗으로 잡는다.
    pivot = arr[0]                     # ← 기준이 될 원소

    # 3️⃣ 피벗보다 작은 원소들을 left 리스트에 모은다.
    left = []                          # ← 피벗보다 작은 원소들의 집합
    # 4️⃣ 피벗보다 큰 원소들을 right 리스트에 모은다.
    right = []                         # ← 피벗보다 큰 원소들의 집합

    # 5️⃣ 피벗을 제외한 나머지 원소들을 순회하면서 left / right에 분류한다.
    for element in arr[1:]:            # ← 피벗을 제외한 모든 원소
        if element < pivot:            # ← 피벗보다 작으면
            left.append(element)       #   left 리스트에 추가
        else:                          # ← 피벗보다 크거나 같으면
            right.append(element)      #   right 리스트에 추가

    # 6️⃣ left와 right 리스트에 대해 재귀적으로 quick_sort를 호출한다.
    #    재귀 호출을 통해 부분 리스트가 더 이상 분할되지 않을 때까지 정렬한다.
    sorted_left = quick_sort(left)     # ← 왼쪽 부분 리스트 정렬
    sorted_right = quick_sort(right)   # ← 오른쪽 부분 리스트 정렬

    # 7️⃣ 최종 결과를 결합한다.
    #    (정렬된 왼쪽 리스트) + (피벗) + (정렬된 오른쪽 리스트)
    return sorted_left + [pivot] + sorted_right   # ← 완전 정렬된 리스트 반환


# --------------------------------------------------------------
# 사용 예시
# --------------------------------------------------------------
if __name__ == "__main__":                     # ← 스크립트가 직접 실행될 때만 실행
    # 1️⃣ 정렬할 원본 리스트 정의
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # 2️⃣ quick_sort 함수 호출
    sorted_list = quick_sort(unsorted)

    # 3️⃣ 결과 출력
    print("원본 리스트 :", unsorted)           # ← 정렬 전 리스트
    print("정렬된 리스트 :", sorted_list)      # ← 정렬 후 리스트
```

### 코드 흐름 요약
1. **기저조건** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 첫 번째 원소를 기준으로 사용. (다른 선택도 가능)  
3. **분할** – 피벗보다 작은 원소를 `left`, 큰 원소를 `right`에 넣음.  
4. **재귀 호출** – `left`와 `right` 각각을 다시 `quick_sort` 로 정렬.  
5. **결합** – `sorted_left + [pivot] + sorted_right` 로 최종 정렬 결과를 만든다.  

이 구현은 **제자리(In‑place) 정렬**이 아니고, 새로운 리스트를 만들어 반환하는 형태이지만 가독성이 높아 교육용이나 작은 데이터셋에 적합합니다.  
제자리 버전을 원한다면 리스트 슬라이스 대신 인덱스를 활용해 직접 교환하는 방식으로 구현할 수 있습니다.
