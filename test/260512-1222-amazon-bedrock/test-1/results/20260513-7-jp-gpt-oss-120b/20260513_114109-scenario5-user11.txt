아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드는 한 줄씩 주석을 달아 이해하기 쉽도록 설명했어요.  

```python
def quick_sort(arr, low, high):
    # -------------------------------------------------
    # quick_sort 함수 : 배열(arr) 을 low ~ high 인덱스 구간까지 정렬한다.
    # -------------------------------------------------
    
    if low < high:                     # 구간에 두 개 이상의 원소가 있으면 정렬 진행
        # -------------------------------------------------
        # 1) 피벗(pivot) 선택 및 파티션 수행
        # -------------------------------------------------
        pi = partition(arr, low, high) # 파티션 후 피벗이 최종 위치에 놓인 인덱스 반환
        
        # -------------------------------------------------
        # 2) 피벗을 기준으로 좌·우 부분 배열을 재귀적으로 정렬
        # -------------------------------------------------
        quick_sort(arr, low, pi - 1)   # 피벗 왼쪽(작은 값) 부분 정렬
        quick_sort(arr, pi + 1, high)  # 피벗 오른쪽(큰 값) 부분 정렬


def partition(arr, low, high):
    # -------------------------------------------------
    # partition 함수 : 피벗을 기준으로 배열을 재배열하고
    #                  피벗이 최종 위치에 놓인 인덱스를 반환한다.
    # -------------------------------------------------
    
    pivot = arr[high]          # 마지막 원소를 피벗으로 선택
    i = low - 1                # i는 피벗보다 작은 요소들의 마지막 인덱스
    
    for j in range(low, high):  # 피벗을 제외한 구간을 순회
        if arr[j] <= pivot:     # 현재 원소가 피벗 이하이면
            i += 1              # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # 작은 원소와 교환
            # 이제 arr[low..i] 구간은 모두 피벗 이하의 값
    
    # -------------------------------------------------
    # 루프가 끝난 뒤, i+1 위치에 피벗을 놓아야 함
    # -------------------------------------------------
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 정렬된 위치로 이동
    return i + 1               # 피벗이 최종적으로 위치한 인덱스 반환


# -------------------------------------------------
# 사용 예시
# -------------------------------------------------
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18]   # 정렬하고 싶은 리스트
    print("정렬 전:", data)
    
    quick_sort(data, 0, len(data) - 1)   # 전체 리스트에 대해 퀵소트 호출
    print("정렬 후:", data)
```

### 코드 흐름 정리
1. **`quick_sort`** : 구간이 1개 이하일 때는 바로 반환하고, 그렇지 않으면  
   `partition` 으로 피벗을 중앙에 배치한다.
2. **`partition`** : 마지막 원소를 피벗으로 잡아, 피벗보다 작거나 같은 원소들을
   좌측에 모은 뒤 피벗을 그 바로 다음 위치(`i+1`)에 놓는다.  
   반환값은 피벗의 최종 인덱스다.
3. 피벗을 기준으로 좌·우 두 부분을 **재귀** 호출해 각각 정렬한다.
4. 최종적으로 전체 배열이 오름차순으로 정렬된다.

이 구현은 **in‑place**(추가 메모리 사용 최소) 방식이며 평균 시간복잡도는 `O(N log N)`,  
최악의 경우(`이미 정렬된 배열` 등) `O(N²)` 이지만, 피벗을 무작위로 선택하거나
`median‑of‑three` 같은 전략을 쓰면 최악 상황을 줄일 수 있어요.
