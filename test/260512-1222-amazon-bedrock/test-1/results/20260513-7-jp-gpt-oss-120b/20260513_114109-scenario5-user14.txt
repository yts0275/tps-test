아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드 한 줄마다 무슨 일을 하는지 설명하는 주석을 달아 두었으니, 이해하는 데 도움이 될 거예요.

```python
def quick_sort(arr):
    """
    퀵소트 함수
    :param arr: 정렬하고 싶은 리스트(또는 배열)
    :return: 정렬된 새로운 리스트
    """
    # 1️⃣ 리스트가 비었거나 요소가 하나이면 이미 정렬된 상태 → 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2️⃣ 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 3️⃣ 피벗보다 작거나 같은 요소들을 담을 리스트
    less = []
    # 4️⃣ 피벗보다 큰 요소들을 담을 리스트
    greater = []

    # 5️⃣ 피벗을 제외한 모든 요소를 순회하면서 두 리스트에 나눠 담는다
    for element in arr[:-1]:               # 마지막 요소(피벗)는 제외하고 순회
        if element <= pivot:               # 피벗보다 작거나 같으면
            less.append(element)           # less 리스트에 추가
        else:                              # 피벗보다 크면
            greater.append(element)        # greater 리스트에 추가

    # 6️⃣ 재귀 호출을 통해 less와 greater 리스트를 각각 정렬한다
    sorted_less = quick_sort(less)          # less 부분을 재귀적으로 정렬
    sorted_greater = quick_sort(greater)    # greater 부분을 재귀적으로 정렬

    # 7️⃣ 정렬된 결과를 합친다: (정렬된 less) + [pivot] + (정렬된 greater)
    return sorted_less + [pivot] + sorted_greater
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 그대로 반환합니다.  
2. **피벗 선택** – 가장 간단하게 마지막 원소를 피벗으로 잡았습니다. (다른 전략도 가능)  
3. **분할** – 피벗보다 작거나 같은 원소와 큰 원소를 두 개의 리스트(`less`, `greater`)에 나눕니다.  
4. **재귀 호출** – `less`와 `greater` 리스트에 대해 같은 과정을 다시 수행해 정렬합니다.  
5. **합치기** – 정렬된 `less` + 피벗 + 정렬된 `greater` 순서대로 이어서 최종 정렬 결과를 반환합니다.

### 사용 예시
```python
unsorted = [33, 10, 55, 71, 29, 3, 18]
sorted_arr = quick_sort(unsorted)
print(sorted_arr)   # 출력: [3, 10, 18, 29, 33, 55, 71]
```

### 주의할 점
- **제자리(in‑place) 정렬이 아닙니다.**  
  새로운 리스트를 만들어 반환하기 때문에 메모리를 추가로 사용합니다.  
- **피벗 선택에 따라 최악의 시간 복잡도 O(n²)** 가 발생할 수 있습니다.  
  최악 상황을 피하려면 무작위 피벗, 중앙값 피벗 등 다른 방법을 고려하세요.
