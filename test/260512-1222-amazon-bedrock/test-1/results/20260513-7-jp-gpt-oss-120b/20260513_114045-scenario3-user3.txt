아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 무슨 역할을 하는지 상세히 주석을 달아두었으니, 코드 흐름을 따라가면서 이해하기 쉬울 겁니다.  

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    """
    입력받은 리스트 arr를 제자리(in‑place)에서 정렬하고,
    정렬된 리스트를 반환한다.
    """
    # 내부에서 실제 재귀 정렬을 수행할 함수
    def _quick_sort(lst, low, high):
        # low >= high이면 이미 한 요소 이하이므로 정렬이 필요없다
        if low >= high:
            return

        # -----------------------------------------------------------------
        # 1) 피벗(pivot) 선택: 여기서는 현재 구간의 가장 오른쪽 요소를 사용
        # -----------------------------------------------------------------
        pivot = lst[high]

        # -----------------------------------------------------------------
        # 2) 파티셔닝(partition) 과정
        #    - i는 피벗보다 작은 원소들의 마지막 인덱스를 가리킨다.
        #    - j는 현재 검사 중인 인덱스이다.
        # -----------------------------------------------------------------
        i = low - 1                     # 아직 작은 원소가 없으므로 low-1로 초기화
        for j in range(low, high):      # 피벗을 제외한 구간을 스캔
            if lst[j] <= pivot:         # 현재 원소가 피벗보다 작거나 같으면
                i += 1                  # 작은 원소 영역을 하나 확장하고
                lst[i], lst[j] = lst[j], lst[i]  # 그 원소를 앞으로 이동시킨다

        # -----------------------------------------------------------------
        # 3) 피벗을 자신의 최종 위치에 삽입
        #    - i+1 위치가 피벗보다 큰 첫 번째 자리이므로 이곳에 피벗을 놓는다.
        # -----------------------------------------------------------------
        pivot_index = i + 1
        lst[pivot_index], lst[high] = lst[high], lst[pivot_index]

        # -----------------------------------------------------------------
        # 4) 재귀 호출: 피벗을 기준으로 왼쪽과 오른쪽 서브 배열을 각각 정렬
        # -----------------------------------------------------------------
        _quick_sort(lst, low, pivot_index - 1)   # 피벗 왼쪽 부분
        _quick_sort(lst, pivot_index + 1, high)  # 피벗 오른쪽 부분

    # 외부에서 받은 리스트를 직접 정렬하기 위해 내부 재귀 함수를 호출
    _quick_sort(arr, 0, len(arr) - 1)
    return arr   # 정렬이 끝난 리스트를 반환(선택적)


# -----------------------------------------------------------------
# 사용 예시
# -----------------------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트를 실행하고 결과를 출력
    sorted_list = quick_sort(unsorted.copy())   # 원본을 보존하고 싶다면 copy() 사용
    print("정렬 전:", unsorted)
    print("정렬 후:", sorted_list)
```

### 코드 흐름 요약
1. **피벗 선택** – 현재 구간의 가장 오른쪽 요소(`high` 인덱스)를 피벗으로 잡는다.  
2. **파티셔닝** – `low`부터 `high-1`까지 순회하면서 피벗보다 작거나 같은 원소를 왼쪽으로 몰아준다.  
3. **피벗 삽입** – 작은 원소들이 모여 있는 영역 바로 뒤(`i+1`)에 피벗을 넣어, 피벗이 최종 위치를 갖게 한다.  
4. **재귀 호출** – 피벗을 기준으로 좌·우 서브 배열을 각각 다시 퀵소트한다.  

이 구현은 **제자리 정렬(in‑place)** 이므로 추가적인 메모리를 거의 사용하지 않으며, 평균 시간복잡도는 `O(N log N)` 입니다. (최악의 경우 `O(N²)`가 되지만, 피벗을 무작위로 선택하면 거의 `O(N log N)`에 가깝게 유지됩니다.)  

필요에 따라 피벗 선택 전략을 바꾸거나, 재귀 대신 스택을 사용한 반복형 구현으로 바꾸면 더 안정적인 성능을 얻을 수 있습니다. 🎉
