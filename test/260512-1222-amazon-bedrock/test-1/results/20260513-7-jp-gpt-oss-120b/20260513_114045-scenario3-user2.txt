아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 한국어 주석을 달아 놓았으니, 알고리즘 흐름을 따라가며 이해하기 쉬울 거예요.  

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 1️⃣ 기본 경우: 리스트가 비어있거나 원소가 하나뿐이면 정렬이 필요 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2️⃣ 피벗(pivot) 선택 – 여기서는 리스트의 마지막 원소를 피벳으로 사용
    pivot = arr[-1]

    # 3️⃣ 피벗보다 작은 원소들을 담을 left 리스트, 
    #    피벗보다 큰 원소들을 담을 right 리스트를 초기화
    left = []   # 피벗보다 작은 값들
    right = []  # 피벗보다 큰 값들
    middle = [] # 피벗과 값이 같은 원소들 (중복값 처리용)

    # 4️⃣ 리스트를 순회하면서 원소들을 left / middle / right에 나눠 담는다
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에
            left.append(x)
        elif x > pivot:        # 피벗보다 크면 right에
            right.append(x)
        else:                  # 피벗과 값이 같으면 middle에 (피벗 자체도 포함)
            middle.append(x)

    # 5️⃣ 재귀적으로 left와 right 부분을 정렬하고,
    #    정렬된 left + middle + 정렬된 right 순서로 이어 붙인다
    #    → left와 right가 다시 quick_sort에 의해 정렬된다
    return quick_sort(left) + middle + quick_sort(right)


# --------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 임의의 정수 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42, 10]

    # 퀵소트를 실행해 정렬된 리스트를 얻는다
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기본 사례** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소(`arr[-1]`)를 피벗으로 사용했지만, 임의 선택, 중앙 선택 등으로 바꿀 수 있어요.  
3. **분할(partition)** – 피벗을 기준으로 작은 원소(`left`)와 큰 원소(`right`), 그리고 피벗과 같은 값(`middle`)을 구분해 각각 별도 리스트에 저장합니다.  
4. **재귀 호출** – `left`와 `right`에 대해 같은 과정을 다시 수행(재귀)하고, 정렬된 결과를 `middle`과 합쳐 최종 리스트를 만든다.  

### 참고 사항
- **시간 복잡도**: 평균 O(n log n), 최악의 경우 O(n²) (피벗이 최악의 선택일 때).  
- **공간 복잡도**: 리스트를 새로 만들기 때문에 O(n) 추가 메모리를 사용합니다. 제자리(in‑place) 퀵소트를 원한다면 `partition` 함수를 직접 구현해 배열을 직접 교환하는 방식으로 바꿀 수 있어요.  
- **중복 원소**가 많을 경우 `middle` 리스트에 모두 모아두어 같은 값의 순서를 유지하면서도 효율적으로 처리합니다.
