아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 한글 주석을 달아 동작을 상세히 설명했습니다.  

```python
# 퀵소트 구현: 리스트를 제자리(in‑place)에서 정렬합니다.
def quick_sort(arr, low, high):
    """
    arr  : 정렬할 리스트
    low  : 현재 정렬 구간의 시작 인덱스
    high : 현재 정렬 구간의 끝 인덱스
    """
    # 구간이 하나 이하의 원소만 가지고 있으면 정렬할 필요가 없으므로 종료
    if low < high:
        # 파티션을 수행하고 피벗이 최종 위치에 놓인 인덱스를 반환
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분(피벗보다 작은 값들) 재귀 정렬
        quick_sort(arr, low, pi - 1)

        # 피벗 오른쪽 부분(피벗보다 큰 값들) 재귀 정렬
        quick_sort(arr, pi + 1, high)


def partition(arr, low, high):
    """
    파티션 과정:
    - 마지막 원소를 피벗(pivot)으로 선택한다.
    - 피벗보다 작거나 같은 원소들을 배열의 앞쪽에 모아두고,
    - 마지막에 피벗을 그 구역의 경계 바로 뒤에 놓는다.
    - 반환값은 피벗이 최종적으로 위치한 인덱스이다.
    """
    # 피벗은 현재 구간의 가장 마지막 원소
    pivot = arr[high]

    # i는 피벗보다 작은 원소들의 마지막 인덱스를 가리킴.
    # 처음에는 구간 시작 이전을 의미하도록 low-1 로 초기화한다.
    i = low - 1

    # low 부터 high-1 까지 순회하며 피벗보다 작은(또는 같은) 원소를 찾는다.
    for j in range(low, high):
        # 현재 원소 arr[j] 가 피벗 이하이면
        if arr[j] <= pivot:
            # i 를 하나 증가시켜 다음 빈 자리로 만든다.
            i += 1
            # 작은 원소와 현재 원소를 교환한다.
            arr[i], arr[j] = arr[j], arr[i]

    # 모든 원소를 검사한 뒤, 피벗을 i+1 위치에 넣어
    # 피벗보다 작은 원소들(0~i)과 피벗을 구분한다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 최종적으로 위치한 인덱스를 반환한다.
    return i + 1


# ---------------------- 사용 예시 ----------------------
if __name__ == "__main__":
    # 정렬할 샘플 리스트
    data = [34, 7, 23, 32, 5, 62, 78, 1, 19]

    print("정렬 전 :", data)

    # quick_sort 를 호출할 때는 리스트 전체를 가리키도록 low=0, high=len-1 로 넘긴다.
    quick_sort(data, 0, len(data) - 1)

    print("정렬 후 :", data)
```

### 코드 흐름 요약
1. `quick_sort` 함수가 호출되면 현재 구간(`low ~ high`)이 **두 개 이상의 원소**인지 검사한다.  
2. `partition` 함수가 피벗을 기준으로 구간을 **작은 부분**과 **큰 부분**으로 나눈 뒤, 피벗이 최종 위치한 인덱스를 반환한다.  
3. 반환된 인덱스(`pi`)를 기준으로 피벗 왼쪽과 오른쪽에 대해 각각 **재귀적으로** `quick_sort` 를 호출한다.  
4. 구간이 하나 이하가 될 때까지 재귀가 진행되면 전체 리스트가 오름차순으로 정렬된다.

이 구현은 **제자리 정렬**이며, 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(`이미 정렬된 경우` 등) `O(N^2)`이다.  
피벗 선택을 임의값으로 바꾸면 최악의 경우 발생 확률을 낮출 수 있습니다.
