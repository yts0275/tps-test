아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 줄마다 한국어 주석을 달아 코드 흐름을 쉽게 이해할 수 있도록 했습니다.

```python
# 퀵소트 함수 정의: 리스트와 정렬할 구간의 시작 인덱스, 끝 인덱스를 매개변수로 받는다
def quick_sort(arr, low, high):
    # 구간이 하나 이하의 원소만 포함하면 이미 정렬된 것이므로 바로 반환
    if low < high:
        # 파티션 함수를 호출해 피벗(pivot)의 최종 위치를 구한다
        pi = partition(arr, low, high)

        # 피벗 왼쪽(작은 값들) 부분에 대해 재귀적으로 퀵소트를 수행
        quick_sort(arr, low, pi - 1)

        # 피벗 오른쪽(큰 값들) 부분에 대해 재귀적으로 퀵소트를 수행
        quick_sort(arr, pi + 1, high)

# 파티션 함수 정의: 배열을 피벗 기준으로 재배치하고 피벗의 최종 인덱스를 반환한다
def partition(arr, low, high):
    # 가장 오른쪽 원소를 피벗으로 선택한다
    pivot = arr[high]

    # i는 피벗보다 작은 원소들의 마지막 인덱스를 가리킨다
    i = low - 1

    # low부터 high‑1까지 순회하면서 피벗보다 작은 원소를 앞쪽으로 이동시킨다
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            # i를 한 칸 오른쪽으로 옮겨 작은 원소를 차곡차곡 모은다
            i += 1
            # i와 j 위치의 원소를 교환한다
            arr[i], arr[j] = arr[j], arr[i]

    # 모든 작은 원소를 다 모은 뒤, 피벗을 그 바로 다음 위치(i+1)와 교환한다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 인덱스를 반환한다
    return i + 1

# -------------------- 사용 예시 --------------------
if __name__ == "__main__":
    # 정렬하고 싶은 리스트를 정의한다
    data = [34, 7, 23, 32, 5, 62, 78, 1, 19]

    # 리스트 전체를 정렬하기 위해 low=0, high=len(data)-1 로 호출
    quick_sort(data, 0, len(data) - 1)

    # 정렬이 끝난 리스트를 출력한다
    print("정렬 결과:", data)
```

### 코드 흐름 요약
1. `quick_sort`는 재귀 함수이며, 현재 구간이 하나 이하일 때( `low >= high` )는 바로 반환한다.  
2. `partition` 함수는 오른쪽 끝 원소를 피벗으로 삼아, 피벗보다 작은 원소들을 왼쪽에, 큰 원소들을 오른쪽에 모아 피벗을 정확한 위치에 놓는다.  
3. `partition`이 반환한 피벗 인덱스를 기준으로 `quick_sort`를 좌·우 구간에 각각 재귀 호출한다.  
4. 전체 구간에 대해 재귀가 끝나면 리스트가 오름차순으로 정렬된다.  

이 구현은 **In‑Place**(추가 메모리 없이)이며 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(`이미 정렬된 상태` 등)에는 `O(N^2)`가 됩니다. 필요에 따라 피벗 선택 전략(무작위 피벗, 중앙값 피벗 등)을 바꾸면 최악 경우를 완화할 수 있습니다.
