아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한글 주석을 달아 동작 과정을 살펴볼 수 있도록 했습니다.  

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 배열이 비어 있거나 요소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 요소를 사용
    pivot = arr[-1]                 # 피벗은 현재 정렬할 구간의 마지막 원소
    left = []                       # 피벗보다 작은 원소들을 담을 리스트
    right = []                      # 피벗보다 큰 원소들을 담을 리스트
    middle = []                     # 피벗과 같은 값이 여러 개일 경우를 위한 리스트

    # 배열의 모든 원소를 피벗과 비교하여 left, middle, right에 배분
    for x in arr:
        if x < pivot:               # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:             # 피벗보다 크면 right에 추가
            right.append(x)
        else:                       # 피벗과 같으면 middle에 추가 (중복 처리)
            middle.append(x)

    # left와 right는 각각 재귀적으로 다시 퀵소트를 수행
    # 정렬된 left + 중복 피벗(middle) + 정렬된 right 순서로 합쳐 최종 결과 반환
    return quick_sort(left) + middle + quick_sort(right)


# --------------------------------------------------------------
# 함수 사용 예시
if __name__ == "__main__":          # 모듈이 직접 실행될 때만 아래 코드를 수행
    sample = [33, 10, 55, 71, 29, 3, 18, 90, 42, 3]  # 정렬할 예시 리스트
    print("정렬 전:", sample)      # 정렬 전 원본 출력
    sorted_list = quick_sort(sample)  # 퀵소트 호출
    print("정렬 후:", sorted_list)   # 정렬된 결과 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 또는 1이면 이미 정렬된 것이므로 그대로 반환.  
2. **피벗 선택** – 현재 구간의 마지막 원소를 피벗으로 잡는다. (다른 선택 전략도 가능)  
3. **분할** – 전체 리스트를 피벗보다 작은(`left`), 같은(`middle`), 큰(`right`) 세 그룹으로 나눈다.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 `quick_sort`를 다시 실행한다.  
5. **합치기** – 정렬된 `left` + `middle` + 정렬된 `right`를 이어붙여 최종 정렬 리스트를 만든다.  

이 구현은 **안정 정렬(stable sort)** 은 아니지만, 간단하고 이해하기 쉬운 퀵소트의 기본 형태를 보여줍니다.  
피벗을 무작위로 고른다든가, **인플레이스(in‑place)** 로 구현한다든가 하면 성능을 더 최적화할 수 있습니다. 필요에 따라 변형해 보세요!
