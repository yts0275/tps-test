아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하는지 자세히 주석을 달아두었으니, 이해하는 데 도움이 되길 바랍니다.  

```python
# ──────────────────────────────────────────────────────────────
#  퀵소트(Quick Sort) 구현
#  - 평균 시간 복잡도 : O(N log N)
#  - 최악 시간 복잡도 : O(N^2) (피벗 선택이 안 좋을 때)
#  - 제자리 정렬 (in‑place) 방식
#  - 재귀 호출을 사용해 구현
# ──────────────────────────────────────────────────────────────

def quick_sort(arr, left, right):
    """
    arr   : 정렬할 리스트
    left  : 현재 정렬 구간의 시작 인덱스
    right : 현재 정렬 구간의 끝 인덱스
    """
    # 1) 구간이 하나 이상의 원소를 가지고 있는지 확인
    if left < right:
        # 2) 파티션 과정을 통해 피벗을 올바른 위치에 배치하고,
        #    그 위치를 반환받는다.
        pivot_index = partition(arr, left, right)

        # 3) 피벗을 기준으로 왼쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, left, pivot_index - 1)

        # 4) 피벗을 기준으로 오른쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, pivot_index + 1, right)


def partition(arr, left, right):
    """
    파티션 함수
    - 피벗을 선택하고, 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽에 배치한다.
    - 최종적으로 피벗이 정확히 자신의 정렬된 위치에 오게 된다.
    - 반환값 : 피벗이 최종적으로 위치한 인덱스
    """
    # 1) 피벗 선택: 여기서는 가장 오른쪽 원소를 피벗으로 잡는다.
    pivot = arr[right]

    # 2) i : 피벗보다 작은 원소들을 모아놓을 구역의 끝 인덱스
    #    초기값은 left - 1 (아직 아무 원소도 없는 상태)
    i = left - 1

    # 3) j : left ~ right-1 범위의 원소들을 하나씩 검사한다.
    for j in range(left, right):
        # 현재 원소가 피벗보다 작거나 같다면,
        # i 를 하나 증가시키고 (새로운 작은 원소 구역 확장),
        # 그 구역 끝에 현재 원소를 위치시킨다.
        if arr[j] <= pivot:
            i += 1                # 작은 구역을 확장
            arr[i], arr[j] = arr[j], arr[i]   # 위치 교환

    # 4) 마지막으로 피벗을 작은 구역 바로 다음 위치(i+1)와 교환한다.
    #    이렇게 하면 피벗 왼쪽에는 피벗보다 작은 값들,
    #    오른쪽에는 피벗보다 큰 값들이 정렬된 상태가 된다.
    arr[i + 1], arr[right] = arr[right], arr[i + 1]

    # 5) 피벗이 최종적으로 위치한 인덱스를 반환한다.
    return i + 1


# ──────────────────────────────────────────────────────────────
# 사용 예시
# ──────────────────────────────────────────────────────────────
if __name__ == "__main__":
    # 정렬하고 싶은 리스트를 정의한다.
    data = [34, 7, 23, 32, 5, 62, 78, 1, 19]

    # quick_sort 함수를 호출한다.
    # 전체 리스트를 대상으로 하므로 left=0, right=len(data)-1 로 전달한다.
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과를 출력한다.
    print("정렬된 결과 :", data)
```

### 코드 흐름 요약
1. `quick_sort`가 **재귀적으로** 호출되면서 리스트를 점점 작은 구간으로 나눕니다.  
2. `partition` 함수가 현재 구간에서 피벗을 정하고, 피벗보다 작은 값과 큰 값을 **제자리(in‑place)** 로 구분합니다.  
3. 피벗이 정확한 위치에 놓이면, 그 좌·우 구간을 각각 다시 `quick_sort` 로 정렬합니다.  
4. 구간이 더 이상 분할되지 않을 때(`left >= right`) 재귀 호출이 종료되고 전체 정렬이 끝납니다.
