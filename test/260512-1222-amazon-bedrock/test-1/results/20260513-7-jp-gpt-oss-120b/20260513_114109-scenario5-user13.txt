아래는 **파이썬** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한글 주석을 달아 동작을 자세히 설명했으니, 그대로 복사‑붙여넣기해서 실행해 보세요.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수를 정의합니다. 입력은 정렬할 리스트 arr
    if len(arr) <= 1:                    # 리스트 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr                       # 바로 그대로 반환합니다.

    pivot = arr[len(arr) // 2]           # 피벗(pivot)으로 리스트 중앙값을 선택합니다.
    left = []                            # 피벗보다 작은 원소들을 담을 리스트 left 초기화
    middle = []                          # 피벗과 같은 원소들을 담을 리스트 middle 초기화
    right = []                           # 피벗보다 큰 원소들을 담을 리스트 right 초기화

    for x in arr:                        # 리스트의 모든 원소를 순회하면서
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)               # left 리스트에 추가합니다.
        elif x == pivot:                  # 피벗과 같으면
            middle.append(x)             # middle 리스트에 추가합니다.
        else:                             # 피벗보다 크면
            right.append(x)              # right 리스트에 추가합니다.

    # 재귀적으로 left와 right 부분을 정렬하고,
    # middle은 이미 정렬된 상태이므로 그대로 두어
    # left + middle + right 를 합쳐 반환합니다.
    return quick_sort(left) + middle + quick_sort(right)


# ----------------------- 사용 예시 -----------------------
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 아래 코드를 실행합니다.
    sample = [33, 10, 55, 71, 29, 3, 8]   # 정렬하고 싶은 임의의 리스트
    print("정렬 전:", sample)            # 정렬 전 리스트를 출력합니다.
    sorted_sample = quick_sort(sample)   # 퀵소트를 호출해 정렬된 리스트를 얻습니다.
    print("정렬 후:", sorted_sample)     # 정렬된 결과를 출력합니다.
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 중앙값을 피벗으로 잡아 평균적인 성능을 기대.  
3. **세 파트로 분할** – `left`, `middle`, `right`에 각각 `< 피벗`, `== 피벗`, `> 피벗` 원소를 저장.  
4. **재귀 호출** – `left`와 `right` 부분에 대해 다시 `quick_sort`를 호출.  
5. **결과 결합** – 정렬된 `left`, `middle`, `right`를 순서대로 이어 붙여 반환.

이 구현은 **안정 정렬(stable sort)** 은 아니지만, 코드가 직관적이고 이해하기 쉬워 학습용으로 많이 사용됩니다.  
필요에 따라 피벗 선택 전략(예: 랜덤 피벗)이나 **제자리(in‑place) 버전**으로 변형할 수도 있습니다. 🚀
