아래는 **Python**으로 구현한 퀵소트(Quick Sort) 알고리즘 예시입니다.  
각 코드 라인마다 한글 주석을 달아 동작 흐름을 자세히 설명했습니다.  
필요에 따라 `list` 대신 `numpy.ndarray` 등 다른 시퀀스 타입에도 그대로 적용할 수 있습니다.

```python
# quick_sort.py
# 퀵소트 알고리즘 구현 (인-플레이스, 재귀 사용)

def quick_sort(arr, low, high):
    """
    arr  : 정렬할 리스트
    low  : 현재 정렬 구간의 시작 인덱스
    high : 현재 정렬 구간의 끝 인덱스
    """
    # 구간이 하나 이상의 원소를 포함할 때만 정렬 작업을 수행
    if low < high:
        # 파티션 과정을 통해 pivot(피벗) 요소를 최종 위치로 이동시키고
        # 그 위치를 반환한다.
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, low, pi - 1)

        # 피벗 오른쪽 부분 배열을 재귀적으로 정렬
        quick_sort(arr, pi + 1, high)


def partition(arr, low, high):
    """
    파티션 함수: 배열을 두 구역으로 나눈다.
    - 피벗보다 작거나 같은 값은 왼쪽, 큰 값은 오른쪽에 배치한다.
    - 최종적으로 피벗은 정확히 그 값이 정렬된 위치에 놓인다.
    반환값: 피벗이 최종적으로 위치한 인덱스
    """
    # 1) 피벗 선택: 여기서는 가장 오른쪽 요소를 피벗으로 사용한다.
    pivot = arr[high]

    # 2) i는 '피벗보다 작거나 같은' 요소들의 마지막 인덱스를 가리킨다.
    i = low - 1   # 아직 아무 요소도 탐색되지 않았으므로 low-1 로 초기화

    # 3) low 에서 high-1 까지 순회하면서 피벗과 비교한다.
    for j in range(low, high):
        # 현재 요소 arr[j] 가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i 를 한 칸 오른쪽으로 옮긴 뒤, arr[i] 와 arr[j] 를 교환한다.
            # 이렇게 하면 지금까지 본 작은(또는 같은) 요소들을 모두
            # 배열 앞쪽에 모아 놓을 수 있다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]   # swap

    # 4) 현재 i 위치 바로 다음(=i+1)에 피벗을 놓는다.
    #    이렇게 하면 피벗보다 작은 값들은 왼쪽, 큰 값들은 오른쪽에 정렬된다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]   # 피벗을 제자리로 이동

    # 5) 피벗이 최종적으로 위치한 인덱스를 반환한다.
    return i + 1


# -------------------- 사용 예시 --------------------
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    data = [34, 7, 23, 32, 5, 62, 78, 1, 0, -4, 3]

    # quick_sort 함수에 전체 구간을 전달한다.
    quick_sort(data, 0, len(data) - 1)

    # 정렬 결과 출력
    print("정렬된 결과:", data)
```

### 코드 흐름 요약
1. `quick_sort` 함수는 현재 정렬 구간(`[low, high]`)이 하나 이상의 원소를 갖는 경우에만 실행한다.  
2. `partition` 함수에서 피벗을 기준으로 구간을 **두 개의 서브구간**으로 나눈다. 피벗은 최종적으로 정렬된 위치에 놓이게 된다.  
3. 피벗을 기준으로 나뉜 왼쪽·오른쪽 서브구간에 대해 **재귀적으로** `quick_sort` 를 호출한다.  
4. 재귀 호출이 종료될 때까지 위 과정을 반복하면 전체 리스트가 정렬된다.

### 주요 포인트
- **시간 복잡도**: 평균 O(N log N), 최악 O(N²) (피벗 선택이 좋지 않을 때)  
- **공간 복잡도**: 인‑플레이스이므로 O(log N) (재귀 호출 스택)  
- **피벗 선택 전략**을 `arr[high]` 대신 `random.choice`, `median-of-three` 등으로 바꾸면 최악 상황 발생 확률을 낮출 수 있다.
