아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 예시입니다.  
각 코드 라인마다 한국어 주석을 달아 두었으니, 동작 흐름을 이해하는 데 도움이 될 거예요.

```python
# 퀵소트를 구현하는 함수
def quick_sort(arr):
    # 배열이 비었거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 가장 오른쪽 원소를 피벗으로 잡는다
    pivot = arr[-1]

    # 피벗보다 작은 원소들을 모아 놓는 리스트
    less = []
    # 피벗과 같은 원소들을 모아 놓는 리스트 (피벗 자체도 포함)
    equal = []
    # 피벗보다 큰 원소들을 모아 놓는 리스트
    greater = []

    # 배열의 모든 원소를 하나씩 살펴보며 위 세 리스트에 분류한다
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 less 리스트에 추가
            less.append(x)
        elif x == pivot:       # 피벗과 같으면 equal 리스트에 추가
            equal.append(x)
        else:                  # 피벗보다 크면 greater 리스트에 추가
            greater.append(x)

    # 재귀적으로 less와 greater 부분을 정렬하고,
    # 정렬된 부분들을 순서대로 이어 붙여 최종 결과를 만든다
    return quick_sort(less) + equal + quick_sort(greater)


# --------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 92, 42]

    # 퀵소트 함수를 호출해 정렬 수행
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬 후 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 사례(Base case)** – 리스트 길이가 0 또는 1이면 바로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 랜덤 선택 등 다른 전략도 가능합니다.  
3. **분할(Partition)** – 리스트를 `less`, `equal`, `greater` 세 부분으로 나눕니다.  
4. **재귀 호출** – `less`와 `greater`에 대해 다시 `quick_sort`를 호출해 각각 정렬합니다.  
5. **병합(Concatenation)** – 정렬된 `less`, `equal`, `greater`를 차례대로 이어 붙여 최종 정렬된 리스트를 반환합니다.

이렇게 구현된 퀵소트는 **분할 정복(Divide and Conquer)** 전략을 사용해 평균 시간 복잡도가 `O(N log N)`이며, 최악의 경우(이미 정렬된 배열을 피벗으로 선택했을 때) `O(N^2)`이 될 수 있다는 점을 기억해 주세요.  

필요에 따라 피벗 선택 방식을 바꾸면 최악 상황을 좀 더 방지할 수 있습니다. 예를 들어 **무작위 피벗** 혹은 **중앙값( Median-of-three)** 방식을 사용해 보세요! 🚀
