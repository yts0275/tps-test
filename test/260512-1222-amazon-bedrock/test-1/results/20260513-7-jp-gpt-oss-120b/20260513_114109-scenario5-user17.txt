아래는 파이썬(Python)으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 코드 라인마다 한글 주석을 달아 로직이 어떻게 동작하는지 상세히 설명했습니다.  

```python
# quick_sort 함수를 정의합니다.
# arr: 정렬하고 싶은 리스트, left: 현재 구간의 시작 인덱스, right: 현재 구간의 끝 인덱스
def quick_sort(arr, left, right):
    # 구간이 한 개 이하의 원소라면(left >= right) 이미 정렬된 상태이므로 바로 반환
    if left >= right:
        return

    # 피벗(pivot)으로 사용할 원소를 선택합니다.
    # 여기서는 구간의 가장 오른쪽 원소를 피벗으로 잡았습니다.
    pivot = arr[right]

    # i는 피벗보다 작은(또는 같은) 원소들을 모아두는 위치를 가리킵니다.
    # 초기값은 구간의 시작 인덱스보다 하나 앞인 left - 1 로 설정합니다.
    i = left - 1

    # j는 현재 검사하고 있는 원소를 가리키는 인덱스입니다.
    # left부터 right - 1까지 순회하면서 피벗보다 작은 원소를 찾습니다.
    for j in range(left, right):
        # 현재 원소 arr[j]가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 한 칸 앞으로 이동시키고
            i += 1
            # i와 j 위치의 원소를 서로 교환합니다.
            # 이렇게 하면 피벗보다 작은 원소들은 모두 배열 앞쪽에 모이게 됩니다.
            arr[i], arr[j] = arr[j], arr[i]

    # 현재 i는 피벗보다 작은 원소들의 마지막 위치를 가리킵니다.
    # 피벗을 i+1 위치와 교환해 피벗이 정확한 정렬 위치에 오도록 합니다.
    arr[i + 1], arr[right] = arr[right], arr[i + 1]

    # 피벗이 최종적으로 위치한 인덱스는 i + 1 입니다.
    # 좌측 구간(left ~ i)과 우측 구간(i+2 ~ right)을 각각 재귀적으로 정렬합니다.
    quick_sort(arr, left, i)          # 피벗 왼쪽 부분 정렬
    quick_sort(arr, i + 2, right)     # 피벗 오른쪽 부분 정렬


# ---------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬할 예시 리스트
    data = [34, 7, 23, 32, 5, 62, 31, 4]

    # quick_sort 함수 호출 (전체 리스트를 정렬)
    quick_sort(data, 0, len(data) - 1)

    # 정렬이 끝난 리스트 출력
    print("정렬 결과:", data)
```

### 코드 흐름 요약
1. **기본 종료 조건** – 구간에 원소가 하나 이하이면 재귀를 멈춥니다.  
2. **피벗 선택** – 현재 구간의 가장 오른쪽 원소를 피벗으로 잡습니다.  
3. **분할(partition)** – 피벗보다 작거나 같은 원소들을 왼쪽에 몰고, 피벗을 올바른 위치에 놓습니다.  
4. **재귀 호출** – 피벗을 기준으로 좌·우 구간을 각각 다시 퀵소트합니다.  

이 구현은 **in‑place** 방식으로 별도의 추가 배열을 만들지 않으며, 평균 시간 복잡도는 `O(N log N)`, 최악 경우(`이미 정렬된 배열` 등)에는 `O(N²)`이 됩니다. 최악 경우를 방지하고 싶다면 피벗을 무작위로 선택하거나 “median‑of‑three” 기법을 쓰는 것이 일반적입니다.
