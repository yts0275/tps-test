아래는 **Python** 로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 무엇을 하는지 설명하는 주석을 한글로 달아 두었습니다.  
※ 파이썬에서는 리스트 자체를 그대로 정렬하도록 **in‑place** 방식으로 구현했습니다.

```python
def quick_sort(arr, left, right):
    """ arr[left..right] 구간을 퀵소트로 정렬한다 """   # 함수 헤더 및 설명
    if left >= right:                                   # 구간이 비었거나 원소가 하나이면 정렬이 필요 없음
        return                                          # 재귀 종료

    pivot = arr[(left + right) // 2]                    # 피벗(pivot)값을 구간 중간 요소로 선택
    i, j = left, right                                 # i는 왼쪽 인덱스, j는 오른쪽 인덱스 초기화

    while i <= j:                                      # i와 j가 교차하기 전까지 반복
        while arr[i] < pivot:                          # 피벗보다 작은 값을 찾을 때까지 i를 오른쪽으로 이동
            i += 1
        while arr[j] > pivot:                          # 피벗보다 큰 값을 찾을 때까지 j를 왼쪽으로 이동
            j -= 1
        if i <= j:                                     # i와 j가 아직 교차하지 않았다면
            arr[i], arr[j] = arr[j], arr[i]            # 두 원소를 교환(스와핑)
            i += 1                                    # i를 한 칸 오른쪽으로 이동
            j -= 1                                    # j를 한 칸 왼쪽으로 이동

    # 이제 피벗을 기준으로 왼쪽은 전부 피벗보다 작고, 오른쪽은 전부 피벗보다 크게 구분됨
    quick_sort(arr, left, j)       # 피벗 왼쪽 부분(arr[left..j])을 재귀적으로 정렬
    quick_sort(arr, i, right)      # 피벗 오른쪽 부분(arr[i..right])을 재귀적으로 정렬


# -----------------------------------------------
# 사용 예시
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18, 42]  # 정렬하고 싶은 임의의 리스트
    print("정렬 전 :", data)               # 정렬 전 출력
    quick_sort(data, 0, len(data) - 1)     # 전체 리스트를 정렬 (인덱스 0부터 마지막까지)
    print("정렬 후 :", data)               # 정렬 후 출력
```

### 코드 흐름 요약
1. **기본 조건** – `left >= right`이면 구간이 비었거나 원소가 하나라 바로 반환합니다.  
2. **피벗 선택** – 중간 인덱스의 값을 피벗으로 잡아 평균적인 경우에 좋은 성능을 기대합니다.  
3. **두 포인터 탐색** – `i`는 왼쪽에서 오른쪽으로, `j`는 오른쪽에서 왼쪽으로 이동하면서 피벗보다 **큰** 값과 **작은** 값을 찾아 교환합니다.  
4. **구역 분할** – `while` 루프가 끝나면 피벗을 기준으로 좌·우 두 구역이 나뉘고, 각각을 재귀 호출해 정렬합니다.  

이 구현은 **시간 복잡도**가 평균 `O(n log n)`, 최악 `O(n²)`이며, **추가 메모리**는 재귀 호출 스택만 사용해 `O(log n)` 정도입니다. 필요에 따라 피벗 선택 전략(랜덤 선택 등)을 바꾸면 최악 상황을 조금 더 완화시킬 수 있습니다.
