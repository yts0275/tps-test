아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예제입니다.  
각 코드 라인마다 어떤 역할을 하는지 상세히 주석을 달아 두었으니, 구현 흐름을 파악하는 데 도움이 될 거예요.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    """리스트 arr를 제자리(in‑place) 정렬하고 정렬된 리스트를 반환한다."""
    
    # 내부에서 재귀적으로 사용할 헬퍼 함수 정의
    def _quick_sort(start, end):
        # 구간이 1개 이하의 원소만 포함하면 이미 정렬된 상태이므로 바로 반환
        if start >= end:
            return
        
        # 피벗(pivot) 선택: 여기서는 구간의 마지막 원소를 피벗으로 사용
        pivot = arr[end]
        
        # i는 피벗보다 작은(또는 같은) 원소가 모여있는 영역의 오른쪽 끝 인덱스
        i = start - 1
        
        # j는 현재 검사 중인 원소의 인덱스 (start부터 end‑1까지 순회)
        for j in range(start, end):
            # 현재 원소가 피벗보다 작거나 같다면
            if arr[j] <= pivot:
                # i를 한 칸 오른쪽으로 이동하고
                i += 1
                # i와 j 위치의 원소를 교환한다
                arr[i], arr[j] = arr[j], arr[i]
        
        # 마지막에 피벗을 i+1 위치로 이동시켜 피벗이 정확히 정렬된 위치에 오게 함
        arr[i + 1], arr[end] = arr[end], arr[i + 1]
        
        # 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 재귀 호출
        _quick_sort(start, i)        # 피벗 왼쪽 부분 (start ~ i)
        _quick_sort(i + 2, end)      # 피벗 오른쪽 부분 (i+2 ~ end)

    # 전체 리스트에 대해 헬퍼 함수 실행
    _quick_sort(0, len(arr) - 1)
    
    # 정렬된 리스트 반환 (필요에 따라 사용)
    return arr


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬되지 않은 샘플 리스트
    sample = [33, 10, 55, 71, 29, 3, 18, 42]
    
    # 퀵소트 호출
    sorted_sample = quick_sort(sample)
    
    # 결과 출력
    print("정렬 결과 :", sorted_sample)
```

### 코드 흐름 요약
1. **quick_sort**: 외부 인터페이스. 입력 리스트 `arr`를 직접 정렬하고 반환한다.  
2. **_quick_sort(start, end)**: 실제 재귀 로직을 담당하는 내부 함수.  
   - 구간이 하나 이하이면(시작 인덱스 ≥ 종료 인덱스) 바로 반환.  
   - 마지막 원소를 피벗으로 잡고, `i`와 `j` 포인터를 이용해 피벗보다 작은 원소들을 앞쪽에 몰아넣는다.  
   - `i+1` 위치에 피벗을 넣어 피벗이 최종 정렬 위치에 있게 만든 뒤, 피벗을 기준으로 좌·우 구간을 재귀 호출한다.  
3. **메인 블록**: 예시 데이터를 정렬하고 결과를 출력한다.

이 구현은 **제자리 정렬**(in‑place)이며, 평균 시간 복잡도는 `O(N log N)`, 최악의 경우(이미 정렬된 배열 등) `O(N²)`이지만, 일반적인 경우에 매우 빠르게 동작합니다. 필요에 따라 피벗 선택 방식을 (예: 무작위 피벗) 바꾸면 최악 상황을 완화할 수 있습니다.
