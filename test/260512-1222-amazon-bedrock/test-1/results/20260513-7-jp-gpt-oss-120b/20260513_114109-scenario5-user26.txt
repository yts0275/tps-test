아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 뭐를 하는지 자세히 설명하는 주석을 달아두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
# 퀵소트를 수행하는 함수
def quick_sort(arr):
    # 1️⃣: 입력 리스트가 비어 있거나 원소가 하나뿐이면 이미 정렬된 것이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2️⃣: 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 3️⃣: 피벗보다 작은 요소들을 담을 리스트 (왼쪽 파티션)
    left = []
    # 4️⃣: 피벗과 같은 요소들을 담을 리스트 (중앙 파티션)
    middle = []
    # 5️⃣: 피벗보다 큰 요소들을 담을 리스트 (오른쪽 파티션)
    right = []

    # 6️⃣: 전체 리스트를 순회하면서 요소를 세 파트 중 하나에 넣는다
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에
            left.append(x)
        elif x == pivot:       # 피벗과 같으면 middle에 (중복된 피벗을 처리)
            middle.append(x)
        else:                  # 피벗보다 크면 right에
            right.append(x)

    # 7️⃣: left와 right 파티션에 대해 재귀적으로 퀵소트를 수행
    #    (이미 정렬된 middle은 그대로 두어도 된다)
    sorted_left = quick_sort(left)     # 왼쪽 파티션 정렬
    sorted_right = quick_sort(right)   # 오른쪽 파티션 정렬

    # 8️⃣: 정렬된 left, middle, right를 순서대로 이어 붙여 최종 결과 반환
    return sorted_left + middle + sorted_right


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90, 42]
    print("정렬 전 :", unsorted)
    sorted_arr = quick_sort(unsorted)
    print("정렬 후 :", sorted_arr)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 0 혹은 1이면 그대로 반환.  
2. **피벗 선정** – 가장 마지막 요소를 피벗으로 잡음(다른 전략도 가능).  
3. **분할 단계** – 리스트를 `left`, `middle`, `right` 세 부분으로 나눔.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 정렬.  
5. **결합 단계** – 정렬된 `left` + `middle` + 정렬된 `right`를 이어 최종 리스트를 만든다.

---

#### 📌 팁
- **피벗 선택**을 무작위(`random.choice`) 혹은 중앙값(`median-of-three`) 등으로 바꾸면 최악의 경우(O(N²)) 발생 확률을 줄일 수 있어요.  
- 위 구현은 **새 리스트를 만든다**(불변 방식)므로 메모리 사용량이 약간 늘어나지만, 코드가 직관적이라 학습용에 적합합니다.  
- **제자리(in‑place) 퀵소트**를 원한다면 `partition` 과 `low/high` 포인터를 이용해 배열 자체를 직접 교환하는 방식으로 구현할 수 있습니다. 필요하면 알려 주세요!
