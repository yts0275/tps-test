아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 예시입니다.  
각 코드 라인마다 한글 주석을 달아 두었으니, 흐름을 따라가며 이해하기 쉬울 거예요.

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 배열이 비었거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 배열의 가운데 요소를 사용
    # (피벗을 무작위로 골라도 무방하지만, 예시를 위해 가운데로 고정)
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 값들을 담을 리스트
    left = []
    # 피벗과 같은 값들을 담을 리스트 (피벗 자체도 포함)
    middle = []
    # 피벗보다 큰 값들을 담을 리스트
    right = []

    # 배열의 모든 원소를 순회하며 세 개의 리스트에 분류
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 left에 추가
            left.append(x)
        elif x > pivot:        # 피벗보다 크면 right에 추가
            right.append(x)
        else:                  # 피벗과 같으면 middle에 추가 (중복을 위해)
            middle.append(x)

    # 재귀적으로 left와 right를 정렬하고, middle은 그대로 연결
    # 정렬된 left + middle(피벗) + 정렬된 right 순서로 합쳐 최종 결과 반환
    return quick_sort(left) + middle + quick_sort(right)


# ------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted_list = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트를 적용하여 정렬
    sorted_list = quick_sort(unsorted_list)

    # 결과 출력
    print("원본 리스트 :", unsorted_list)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 배열 길이가 1 이하이면 그대로 반환합니다.  
2. **피벗 선택** – 배열 중앙값을 피벗으로 잡아 분할 기준을 정합니다.  
3. **분할 단계** – 모든 원소를 순회하며 피벗보다 작은 `left`, 같은 `middle`, 큰 `right` 로 나눕니다.  
4. **재귀 호출** – `left`와 `right`에 대해 다시 `quick_sort`를 호출해 각각 정렬합니다.  
5. **병합** – 정렬된 `left`, `middle`, 정렬된 `right`를 차례대로 이어 최종 정렬 배열을 반환합니다.

이렇게 하면 평균 시간 복잡도 **O(N log N)**, 최악 경우 **O(N²)**(피벗 선택이 불리할 때)인 퀵소트를 구현할 수 있습니다.
