아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘 예시입니다.  
각 줄마다 한글 주석을 달아 동작을 상세히 설명했으니, 코드를 읽으며 이해하기 쉬울 거예요.  

```python
def quick_sort(arr):
    """
    리스트 arr를 제자리(in‑place) 정렬해서 반환한다.
    반환값이 필요 없으면 함수 호출만 해도 arr 자체가 정렬된다.
    """
    
    # 1. 정렬이 필요한 구간을 지정하기 위해 재귀 함수 정의
    def _quick_sort(start, end):
        # 구간에 원소가 하나 이하이면 이미 정렬된 상태 → 재귀 종료
        if start >= end:
            return

        # 2. 피벗(pivot) 선정 → 여기서는 구간의 가장 오른쪽 원소 사용
        pivot = arr[end]

        # 3. i는 피벗보다 작은(또는 같은) 원소들의 마지막 인덱스를 가리킴
        i = start - 1

        # 4. j는 시작부터 피벗 직전까지 차례대로 검사
        for j in range(start, end):
            # 현재 원소가 피벗보다 작거나 같다면
            if arr[j] <= pivot:
                # i를 한 칸 오른쪽으로 이동하고(다음 자리 확보)
                i += 1
                # 현재 원소와 i 위치에 있는 원소를 교환
                arr[i], arr[j] = arr[j], arr[i]

        # 5. 피벗을 “작은 원소들” 뒤에 정확한 위치(i+1)로 이동
        #    이렇게 하면 피벗의 왼쪽은 모두 <= 피벗, 오른쪽은 > 피벗
        arr[i + 1], arr[end] = arr[end], arr[i + 1]

        # 6. 피벗을 기준으로 좌·우 서브 배열을 각각 재귀 호출
        _quick_sort(start, i)        # 피벗 왼쪽 구간
        _quick_sort(i + 2, end)      # 피벗 오른쪽 구간

    # 전체 리스트에 대해 _quick_sort 시작
    _quick_sort(0, len(arr) - 1)

    # 정렬된 리스트 반환 (선택 사항)
    return arr


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 92]
    print("정렬 전:", unsorted)

    sorted_list = quick_sort(unsorted)   # 함수는 직접 리스트를 정렬한다
    print("정렬 후:", sorted_list)
```

### 코드 흐름 요약
1. **재귀 함수 `_quick_sort(start, end)`** : 현재 정렬하고자 하는 구간을 `start`와 `end` 인덱스로 지정합니다.  
2. **피벗 선택** : 여기서는 구간의 마지막 원소(`arr[end]`)를 피벗으로 잡았습니다. (다른 전략도 가능)  
3. **분할(partition)** : 두 포인터 `i`와 `j`를 이용해 피벗보다 작거나 같은 원소들을 왼쪽으로 모아줍니다.  
4. **피벗 위치 확정** : `i+1` 위치에 피벗을 놓아, 피벗을 기준으로 좌·우가 완벽히 구분되게 합니다.  
5. **재귀 호출** : 피벗을 기준으로 좌·우 서브 배열을 각각 정렬합니다.  
6. **전체 호출** : `quick_sort` 함수 내부에서 전체 리스트에 대해 첫 번째 재귀를 시작합니다.

이렇게 구현된 퀵소트는 평균 시간 복잡도가 **O(N log N)** 이며, 최악 상황(이미 정렬된 리스트에 대해 마지막 원소를 피벗으로 선택)에서는 **O(N²)** 가 될 수 있습니다.  
피벗 선택 전략(무작위 피벗, 중앙값 등)을 바꾸면 최악 상황을 회피할 수 있습니다.  

필요에 따라 **in‑place** 정렬 대신 새로운 리스트를 반환하는 버전이나, **반복문 기반** 구현도 만들 수 있으니, 언제든 질문 주세요! 🚀
