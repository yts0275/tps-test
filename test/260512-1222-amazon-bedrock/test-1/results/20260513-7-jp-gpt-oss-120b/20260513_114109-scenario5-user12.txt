아래는 **파이썬(Python)** 으로 구현한 **퀵소트(Quick Sort)** 입니다.  
각 줄마다 한국어 주석을 달아 코드 흐름을 상세히 설명했습니다.  
필요에 따라 리스트를 복사하지 않고 제자리(in‑place) 정렬을 수행하도록 구현했어요.

```python
def quick_sort(arr, low=0, high=None):
    """
    퀵소트 메인 함수
    :param arr: 정렬할 리스트 (제자리 정렬)
    :param low: 현재 정렬 구간의 시작 인덱스
    :param high: 현재 정렬 구간의 끝 인덱스 (포함)
    """
    # 처음 호출일 때만 high 값을 리스트 끝으로 설정
    if high is None:
        high = len(arr) - 1

    # 구간이 1개 이하이면 이미 정렬된 것이므로 재귀 종료
    if low < high:
        # 파티션 과정을 통해 피벗(pivot)을 올바른 위치로 이동하고,
        # 그 위치를 반환받는다.
        pivot_index = partition(arr, low, high)

        # 피벗 왼쪽(작은 값들) 구간을 재귀적으로 정렬
        quick_sort(arr, low, pivot_index - 1)

        # 피벗 오른쪽(큰 값들) 구간을 재귀적으로 정렬
        quick_sort(arr, pivot_index + 1, high)


def partition(arr, low, high):
    """
    파티션 함수
    :param arr: 정렬 대상 리스트
    :param low: 파티션 시작 인덱스
    :param high: 파티션 끝 인덱스 (피벗으로 사용할 요소)
    :return: 피벗이 최종적으로 자리잡은 인덱스
    """
    # 가장 오른쪽 요소를 피벗으로 선택
    pivot = arr[high]

    # i는 "피벗보다 작거나 같은 값"들의 마지막 인덱스를 가리킴
    i = low - 1

    # low부터 high-1까지 순회하면서 피벗보다 작은 원소를 앞쪽으로 모은다
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같다면
        if arr[j] <= pivot:
            i += 1                 # i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]   # 작은 값과 현재 값을 교환

    # 루프가 끝난 뒤 i+1 위치에 피벗을 놓아야 정렬이 완성된다
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 최종적으로 자리잡은 인덱스를 반환 (재귀 호출에 사용)
    return i + 1


# ----------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    data = [33, 10, 55, 71, 29, 3, 18, 42]
    print("정렬 전 :", data)

    quick_sort(data)               # 제자리 정렬 수행
    print("정렬 후 :", data)
```

### 코드 흐름 요약
1. `quick_sort`가 호출되면 현재 정렬 구간이 `low < high`인지 확인한다.  
2. `partition` 함수가 피벗을 기준으로 작은 값·큰 값 두 그룹으로 나누고, 피벗을 **정확히 정렬된 위치**에 둔다.  
3. 피벗을 기준으로 좌·우 구간을 각각 재귀 호출해 다시 같은 과정을 반복한다.  
4. 구간이 더 이상 나눠질 수 없을 때(길이가 1이 되면) 재귀가 종료되고, 전체 리스트가 정렬된다.

### 시간·공간 복잡도 (참고)
- **평균/최선 시간복잡도**: \(O(n \log n)\)  
- **최악 시간복잡도**: \(O(n^2)\) (피벗이 매번 최솟값/최댓값일 때)  
- **추가 메모리**: 재귀 호출 스택만 사용하므로 평균 \(O(\log n)\), 최악 \(O(n)\)

필요에 따라 피벗 선택 방식을 “무작위 선택” 혹은 “중앙값” 등으로 바꾸면 최악 상황을 완화할 수 있습니다. 🚀
