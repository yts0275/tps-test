아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘이며, **각 줄마다 한국어 주석**을 달아 놓았습니다.  
코드 자체만 복사해서 실행하면 바로 동작합니다.

```python
def quick_sort(arr):                      # quick_sort 함수 정의, 정렬할 리스트 arr 를 인자로 받는다
    if len(arr) <= 1:                     # 리스트 길이가 1 이하이면(빈 리스트 혹은 원소 하나) 정렬이 필요 없으므로
        return arr                        # 그대로 반환한다

    pivot = arr[len(arr) // 2]            # 피벗(pivot) 선택: 리스트 중간 값을 기준으로 잡는다
    left = []                             # 피벗보다 작은 원소들을 담을 리스트 left 초기화
    middle = []                           # 피벗과 같은 원소들을 담을 리스트 middle 초기화
    right = []                            # 피벗보다 큰 원소들을 담을 리스트 right 초기화

    for x in arr:                         # 입력 리스트의 모든 원소 x 에 대해
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x == pivot:                  # 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가
        else:                             # 피벗보다 크면
            right.append(x)               # right 리스트에 추가

    # 재귀 호출을 통해 left와 right 부분을 각각 정렬하고,
    # 정렬된 left + middle(피벗) + 정렬된 right 를 이어 붙여 반환한다
    return quick_sort(left) + middle + quick_sort(right)


# ---------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 이 파일을 직접 실행했을 때만 아래 코드를 수행한다
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬되지 않은 예시 리스트
    print("정렬 전 :", unsorted)               # 정렬 전 리스트 출력
    sorted_arr = quick_sort(unsorted)           # quick_sort 함수 호출
    print("정렬 후 :", sorted_arr)              # 정렬된 리스트 출력
```

### 코드 흐름 간단히 정리
1. **기저 조건**  
   - 리스트 길이가 1 이하이면 그대로 반환 (재귀 종료).

2. **피벗 선택**  
   - 여기서는 리스트 중간 값(`len(arr)//2`)을 피벗으로 사용했지만,  
     첫 번째, 마지막, 랜덤 등 다른 전략도 가능하다.

3. **분할(Partition)**  
   - `left`, `middle`, `right` 세 개의 리스트에 원소를 각각 분류한다.

4. **재귀 정렬**  
   - `left`와 `right`에 대해 같은 `quick_sort` 함수를 다시 호출한다.

5. **합치기**  
   - 정렬된 `left` + `middle`(피벗) + 정렬된 `right`를 이어서 최종 결과를 만든다.

---

#### ✨ 팁
- **시간 복잡도**: 평균 O(N log N), 최악 O(N²) (피벗 선택이 안 좋을 때).  
- **메모리 사용**: 위 구현은 **추가 리스트**(`left`, `middle`, `right`)를 만들기 때문에 **O(N)**의 추가 메모리를 사용한다.  
  제자리(in‑place) 퀵소트를 원한다면 **두 포인터** 방식을 구현하면 된다.
