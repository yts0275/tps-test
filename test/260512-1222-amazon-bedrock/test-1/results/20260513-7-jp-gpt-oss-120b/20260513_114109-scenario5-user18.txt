아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘 예시입니다.  
각 코드 라인마다 한국어 주석을 달아 이해를 돕도록 했어요.

```python
def quick_sort(arr):                     # 정렬할 리스트를 매개변수로 받는 함수 정의
    """
    퀵소트 알고리즘을 재귀적으로 적용해 리스트를 오름차순 정렬한다.
    입력:  arr  – 정렬하고 싶은 리스트(또는 리스트 부분)
    반환: 정렬된 새로운 리스트
    """
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                        # 그대로 반환한다

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택 → 리스트 중간 원소 활용
    left = []                            # 피벗보다 작은 원소들을 담을 리스트
    middle = []                          # 피벗과 같은 원소들을 담을 리스트
    right = []                           # 피벗보다 큰 원소들을 담을 리스트

    for x in arr:                        # 원본 리스트의 모든 원소를 순회
        if x < pivot:                    # 피벗보다 작으면
            left.append(x)               # left 리스트에 추가
        elif x == pivot:                 # 피벗과 같으면
            middle.append(x)             # middle 리스트에 추가(중복 처리)
        else:                            # 피벗보다 크면
            right.append(x)              # right 리스트에 추가

    # 재귀 호출: left와 right 부분을 각각 퀵소트로 정렬하고,
    # middle(피벗)은 이미 정렬된 상태이므로 그대로 두어 세 리스트를 합친다.
    return quick_sort(left) + middle + quick_sort(right)


# ---------- 사용 예시 ----------
if __name__ == "__main__":                # 이 파일이 메인 프로그램으로 실행될 때만 동작
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]  # 정렬되지 않은 예시 리스트
    print("정렬 전:", unsorted)               # 정렬 전 리스트 출력
    sorted_list = quick_sort(unsorted)        # 퀵소트 함수 호출
    print("정렬 후:", sorted_list)            # 정렬된 리스트 출력
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 중간 원소를 피벗으로 잡아 평균적인 성능을 기대.  
3. **분할(Partition)** – 리스트를 `< 피벗`, `= 피벗`, `> 피벗` 세 구역으로 나눈다.  
4. **재귀 호출** – 작은 구역(`left`)과 큰 구역(`right`)에 대해 다시 퀵소트를 수행한다.  
5. **합치기** – 정렬된 `left`, 그대로인 `middle`, 정렬된 `right`를 순서대로 이어 최종 결과를 만든다.

이렇게 하면 평균 시간 복잡도 **O(N log N)**, 최악의 경우 **O(N²)**(피벗 선택이 좋지 않을 때) 를 가집니다.
