아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 코드입니다.  
각 줄마다 상세히 주석을 달아두었으니, 흐름을 따라가며 이해하기 쉬울 겁니다.

```python
# 퀵소트 구현
# 입력 리스트 lst와 정렬을 수행할 구간을 나타내는 left(시작 인덱스)와 right(끝 인덱스)를 받아 정렬한다.
def quick_sort(lst, left, right):
    # 구간이 하나의 원소 이하일 때는 이미 정렬된 상태이므로 바로 반환한다.
    if left >= right:
        return

    # -------------------------
    # 1) 피벗(pivot) 선택
    # -------------------------
    # 여기서는 구간의 중간 값을 피벗으로 선택한다.
    # (다른 전략: 첫 번째, 마지막, 무작위 등)
    mid = (left + right) // 2
    pivot = lst[mid]

    # 피벗을 구간의 끝(right)으로 옮겨서 partition 절차를 간단하게 만든다.
    lst[mid], lst[right] = lst[right], lst[mid]

    # -------------------------
    # 2) Partition 과정
    # -------------------------
    # i : 피벗보다 작은 값들을 모아두는 영역의 마지막 인덱스
    i = left - 1          # 아직 아무것도 없으니 left-1 로 초기화

    # j : 현재 검사 중인 원소의 인덱스
    for j in range(left, right):      # 피벗은 right에 있으므로 right-1까지 순회
        if lst[j] <= pivot:           # 현재 원소가 피벗보다 작거나 같으면
            i += 1                    # i 를 한 칸 오른쪽으로 이동
            lst[i], lst[j] = lst[j], lst[i]   # 작은 원소를 i 위치로 스와핑

    # for 문이 끝나면 i+1 위치가 피벗보다 큰 첫 영역이 된다.
    # 피벗을 (i+1) 위치에 두어 정확한 최종 위치를 잡아준다.
    pivot_index = i + 1
    lst[pivot_index], lst[right] = lst[right], lst[pivot_index]

    # -------------------------
    # 3) 재귀 호출
    # -------------------------
    # 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 정렬한다.
    quick_sort(lst, left, pivot_index - 1)   # 피벗 왼쪽 부분 정렬
    quick_sort(lst, pivot_index + 1, right)  # 피벗 오른쪽 부분 정렬


# ---------------------------------------------------------
# 사용 예시
# ---------------------------------------------------------
if __name__ == "__main__":
    # 정렬하고 싶은 리스트 선언
    data = [33, 10, 55, 71, 29, 3, 18, 90, 42]

    print("정렬 전 :", data)

    # quick_sort 함수 호출 (전체 구간을 정렬)
    quick_sort(data, 0, len(data) - 1)

    print("정렬 후 :", data)
```

### 코드 흐름 요약
1. **피벗 선택** – 구간 중간값을 피벗으로 잡고, 편의를 위해 구간 끝(`right`)으로 이동한다.  
2. **Partition** – `i`를 이용해 피벗보다 작거나 같은 원소를 왼쪽에 모으고, 마지막에 피벗을 정확한 위치(`pivot_index`)에 넣는다.  
3. **재귀 호출** – 피벗을 기준으로 왼쪽 구간과 오른쪽 구간을 각각 다시 `quick_sort` 호출한다.  
4. **기저 사례** – 구간이 크기 0 혹은 1이면 정렬이 필요 없으므로 바로 반환한다.

이렇게 구현된 퀵소트는 평균 시간 복잡도 `O(N log N)`이며, 최악의 경우(`이미 정렬된 경우` 등) `O(N²)`가 될 수 있습니다. 피벗 선택 방식을 무작위(`random`)로 바꾸면 최악의 경우 발생 확률을 크게 낮출 수 있습니다. 필요에 따라 `pivot = random.choice(lst[left:right+1])` 와 같이 수정해 보세요.
