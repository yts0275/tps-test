아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하는지 상세히 설명하는 주석을 한글로 달아 두었습니다.  
필요에 따라 `list` 대신 `numpy.ndarray` 등 다른 시퀀스 타입에도 그대로 적용할 수 있습니다.

```python
# quick_sort.py
# 퀵소트(Quick Sort) 구현 예시
# 시간 복잡도 평균 O(N log N), 최악 O(N^2) (피벗 선택에 따라 달라짐)

def quick_sort(arr):
    """
    주어진 리스트 arr 를 제자리(in‑place)로 정렬하고,
    정렬된 리스트를 반환한다.
    """
    # 재귀 호출에 사용할 내부 함수 정의
    def _quick_sort(low, high):
        # low 가 high 보다 작을 때만 정렬을 시도한다.
        # (원소가 1개 이하이면 이미 정렬된 상태)
        if low < high:
            # 파티션 과정을 수행해 피벗(pivot)의 최종 위치를 찾는다.
            pivot_index = partition(low, high)
            # 피벗 왼쪽 부분을 재귀적으로 정렬한다.
            _quick_sort(low, pivot_index - 1)
            # 피벗 오른쪽 부분을 재귀적으로 정렬한다.
            _quick_sort(pivot_index + 1, high)

    def partition(low, high):
        """
        low~high 구간을 파티션한다.
        기준값(pivot)은 구간의 가장 오른쪽 요소(arr[high])를 사용한다.
        반환값 : 피벗이 최종적으로 놓인 인덱스
        """
        # 1) 피벗 값 저장
        pivot = arr[high]

        # 2) i 는 "피벗보다 작거나 같은 값"들의 마지막 인덱스를 가리킨다.
        #    초기값은 low-1 (즉 아직 아무것도 찾지 못한 상태)
        i = low - 1

        # 3) j 를 low 부터 high-1까지 순회하면서
        #    현재 요소가 피벗보다 작거나 같으면 i 를 증가시키고
        #    그 요소와 i 위치의 요소를 교환한다.
        for j in range(low, high):
            if arr[j] <= pivot:        # 피벗보다 작거나 같은 경우
                i += 1                 # i 를 오른쪽으로 한 칸 이동
                arr[i], arr[j] = arr[j], arr[i]   # 두 원소 교환

        # 4) 마지막으로 피벗을 i+1 위치와 교환한다.
        #    이제 피벗은 정확히 "왼쪽에는 피벗보다 작거나 같은 값,
        #    오른쪽에는 피벗보다 큰 값"이 배치된 상태가 된다.
        arr[i + 1], arr[high] = arr[high], arr[i + 1]

        # 5) 피벗이 최종적으로 놓인 인덱스를 반환한다.
        return i + 1

    # -------------------------------------------------
    # 실제 정렬을 시작한다. (전체 리스트는 0 부터 len-1까지)
    _quick_sort(0, len(arr) - 1)

    # 정렬이 끝난 리스트를 반환 (선택사항)
    return arr


# ---------------------- 사용 예시 ----------------------
if __name__ == "__main__":
    # 정렬하고 싶은 리스트 예시
    data = [33, 10, 55, 71, 29, 3, 18, 42]

    print("정렬 전 :", data)

    # quick_sort 함수 호출 (제자리 정렬이므로 원본 리스트가 바뀐다)
    sorted_data = quick_sort(data)

    print("정렬 후 :", sorted_data)
```

### 코드 흐름 요약
1. `quick_sort` 를 호출하면 내부에 정의된 `_quick_sort` 가 재귀적으로 동작한다.  
2. `_quick_sort` 은 `partition` 함수를 이용해 피벗을 적절한 위치에 배치하고, 피벗을 기준으로 좌·우 서브 배열을 각각 다시 정렬한다.  
3. `partition` 은 **Lomuto 파티션 방법**을 사용했으며, 피벗은 현재 구간의 가장 오른쪽 요소로 잡았다.  
4. 모든 재귀 호출이 끝나면 원본 리스트 `arr` 가 오름차순으로 정렬된다.

---

#### 📌 팁
- **피벗 선택을 랜덤화**하면 최악의 경우(O(N²))가 발생할 확률을 크게 낮출 수 있다.  
  ```python
  import random
  pivot_idx = random.randint(low, high)
  arr[pivot_idx], arr[high] = arr[high], arr[pivot_idx]   # 피벗을 끝으로 이동
  ```
- **데이터가 거의 정렬된 경우**에는 `Insertion Sort` 로 작은 구간(예: 10 이하) 을 처리하면 실전 성능이 향상된다.
