아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 프로그램입니다.  
각 코드 줄마다 어떤 역할을 하는지 상세히 주석을 달아 두었으니, 알고리즘 흐름을 따라가면서 이해하기 쉬울 거예요.  

---

```python
# ------------------------------
# 1️⃣  퀵소트 함수 정의
# ------------------------------
def quick_sort(arr):
    """
    배열 arr을 정렬해서 새로운 리스트로 반환한다.
    (제자리(in‑place) 정렬이 아니라, 정렬된 복사본을 만든다)
    """
    # 2️⃣ 베이스 케이스: 리스트가 비었거나 원소가 하나만 있으면 이미 정렬된 상태
    if len(arr) <= 1:
        return arr                         # 그대로 반환

    # 3️⃣ 피벗(pivot) 선택 – 여기서는 리스트의 마지막 요소를 피벗으로 잡는다
    pivot = arr[-1]                        # 마지막 원소를 피벗으로 지정

    # 4️⃣ 피벗보다 작은 원소들을 담을 리스트
    left = []                              # 피벗보다 작은 값들
    # 5️⃣ 피벗보다 큰 원소들을 담을 리스트
    right = []                             # 피벗보다 큰 값들
    # 6️⃣ 피벗과 같은 값(중복)들을 담을 리스트 (중복 허용을 위해 별도 관리)
    middle = []                            # 피벗과 같은 값들

    # 7️⃣ 전체 리스트를 순회하면서 세 개의 파티션으로 나눈다
    for x in arr:
        if x < pivot:                      # 피벗보다 작으면 left에
            left.append(x)
        elif x > pivot:                    # 피벗보다 크면 right에
            right.append(x)
        else:                              # x == pivot인 경우
            middle.append(x)               # 중복된 피벗을 middle에 저장

    # 8️⃣ 재귀 호출: left와 right 부분을 각각 정렬한다
    sorted_left = quick_sort(left)         # 왼쪽 파티션 정렬
    sorted_right = quick_sort(right)       # 오른쪽 파티션 정렬

    # 9️⃣ 정렬된 결과를 합친다 → left + middle + right 순서가 정렬된 전체 리스트
    return sorted_left + middle + sorted_right
```

### 코드 흐름을 한눈에 정리하면

| 단계 | 수행 내용 | 설명 |
|------|-----------|------|
| 1️⃣ | `def quick_sort(arr):` | 퀵소트 함수를 정의합니다. |
| 2️⃣ | `if len(arr) <= 1:` | 리스트 길이가 0 혹은 1이면 이미 정렬된 상태이므로 바로 반환합니다. |
| 3️⃣ | `pivot = arr[-1]` | 피벗을 리스트의 마지막 원소로 선택합니다. (다른 전략도 가능) |
| 4️⃣~6️⃣ | `left, right, middle` 초기화 | 피벗을 기준으로 나눌 세 개의 임시 리스트를 만든다. |
| 7️⃣ | `for x in arr:` | 전체 원소를 순회하면서 피벗과 비교해 적절한 파티션에 배분한다. |
| 8️⃣ | `sorted_left = quick_sort(left)`<br>`sorted_right = quick_sort(right)` | 왼쪽·오른쪽 파티션을 재귀적으로 정렬한다. |
| 9️⃣ | `return sorted_left + middle + sorted_right` | 정렬된 왼쪽, 피벗(중복 포함), 정렬된 오른쪽을 차례대로 이어 최종 결과를 만든다. |

## 📌 사용 예시

```python
if __name__ == "__main__":
    sample = [33, 10, 55, 71, 29, 3, 18, 55, 10]
    print("원본 리스트 :", sample)
    print("정렬 결과   :", quick_sort(sample))
```

**출력**

```
원본 리스트 : [33, 10, 55, 71, 29, 3, 18, 55, 10]
정렬 결과   : [3, 10, 10, 18, 29, 33, 55, 55, 71]
```

### 🎓 퀵소트 핵심 포인트

1. **분할 정복(Divide‑and‑Conquer)**  
   - 리스트를 피벗을 기준으로 `작음/같음/큼` 세 파티션으로 나눈 뒤, 두 파티션(`left`, `right`)을 각각 다시 같은 방식으로 정렬합니다.

2. **시간 복잡도**  
   - 평균: **O(N log N)**  
   - 최악(이미 정렬된 경우 등 피벗 선택이 최악일 때): **O(N²)**  
   → 피벗을 무작위로 선택하거나 `median‑of‑three` 기법을 쓰면 최악 상황을 크게 완화할 수 있습니다.

3. **공간 복잡도**  
   - 위 구현은 **새 리스트**를 만들어 반환하므로 **O(N)** 정도의 추가 메모리를 사용합니다.  
   - 제자리(in‑place) 버전은 `swap`을 이용해 동일 배열 내에서 정렬하도록 구현하면 메모리 사용을 **O(1)** 로 줄일 수 있습니다.
