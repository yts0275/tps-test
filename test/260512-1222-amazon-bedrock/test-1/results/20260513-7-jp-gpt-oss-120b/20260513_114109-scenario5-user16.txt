아래는 파이썬으로 구현한 **퀵소트(Quick Sort)** 예시입니다.  
각 코드 라인마다 어떤 역할을 하는지 설명을 **주석** 형태로 달아두었으니, 코드를 읽으면서 바로 이해하실 수 있을 거예요.  

```python
# 퀵소트 함수 정의
def quick_sort(arr):
    # 리스트가 비어있거나 원소가 한 개만 있으면 정렬할 필요가 없으니 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 요소들을 담을 리스트
    less = []       
    # 피벗과 같은 요소들을 담을 리스트 (피벗 자체도 여기 포함)
    equal = []      
    # 피벗보다 큰 요소들을 담을 리스트
    greater = []    

    # 전체 리스트를 순회하면서 세 개의 리스트에 각각 분류
    for x in arr:
        if x < pivot:          # 피벗보다 작으면 less에 추가
            less.append(x)
        elif x == pivot:       # 피벗과 같으면 equal에 추가
            equal.append(x)
        else:                  # 피벗보다 크면 greater에 추가
            greater.append(x)

    # 재귀 호출을 이용해 less와 greater 부분을 각각 정렬하고,
    # 정렬된 결과를 less + equal + greater 순서로 합쳐 반환
    return quick_sort(less) + equal + quick_sort(greater)


# ----------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":
    # 정렬하고 싶은 임의의 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트 실행
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **기저 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 여기서는 가장 오른쪽 원소(`arr[-1]`).  
3. **분할** – 피벗을 기준으로 `less`, `equal`, `greater` 세 리스트로 나눔.  
4. **재귀 호출** – `less`와 `greater`에 대해 다시 `quick_sort`를 호출해 정렬.  
5. **합치기** – `less`(정렬된) + `equal` + `greater`(정렬된) 순서로 연결해 최종 정렬 결과 반환.

이렇게 하면 **분할 정복(Divide & Conquer)** 방식으로 평균 O(n log n)의 시간 복잡도를 갖는 퀵소트를 구현할 수 있습니다. 필요에 따라 피벗 선택 전략(예: 랜덤 피벗, 중앙값 피벗)이나 제자리(in‑place) 구현으로 최적화할 수도 있어요. 즐겁게 코딩하시길 바랍니다! 🚀
