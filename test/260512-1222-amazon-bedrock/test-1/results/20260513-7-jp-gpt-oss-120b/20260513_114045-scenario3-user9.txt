아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 줄마다 한국어 주석을 달아 코드 흐름을 쉽게 이해할 수 있도록 했습니다.

```python
# quick_sort.py
# 퀵소트(Quick Sort) 구현 예시

def quick_sort(arr):
    """
    재귀적으로 퀵소트를 수행하는 함수.
    입력: 정렬하고 싶은 리스트 arr
    반환값: 정렬된 새 리스트 (원본은 변하지 않음)
    """
    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 바로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은(또는 같은) 요소들을 담을 left 리스트
    left = []
    # 피벗보다 큰 요소들을 담을 right 리스트
    right = []

    # 피벗을 제외한 나머지 요소들을 순회하며 left / right에 분류
    for element in arr[:-1]:
        if element <= pivot:          # 피벗보다 작거나 같으면 left에
            left.append(element)
        else:                         # 피벗보다 크면 right에
            right.append(element)

    # left와 right 부분을 각각 재귀적으로 정렬하고,
    # 피벗을 가운데에 놓아 하나의 리스트로 합친 뒤 반환
    return quick_sort(left) + [pivot] + quick_sort(right)


# -----------------------------------------
# 사용 예시 (직접 실행해볼 수 있습니다)
if __name__ == "__main__":
    # 정렬할 원본 리스트
    unsorted = [33, 10, 55, 71, 29, 3, 18, 42]

    # 퀵소트를 호출하여 정렬된 리스트를 얻음
    sorted_list = quick_sort(unsorted)

    # 결과 출력
    print("원본 리스트 :", unsorted)
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 길이가 0 또는 1인 리스트는 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 임의 선택하거나 중간값 등을 사용할 수 있습니다.  
3. **분할(Partition)** – 피벗을 기준으로 `left`와 `right` 두 리스트에 원소를 나눕니다.  
4. **재귀 호출** – `left`와 `right` 부분을 각각 다시 `quick_sort`로 정렬합니다.  
5. **병합** – 정렬된 `left`, 피벗, 정렬된 `right`를 순서대로 이어서 하나의 리스트로 만듭니다.

이 구현은 **추가 메모리를 O(n)** 사용합니다(새 리스트를 계속 만들어 반환).  
인‑플레이스(in‑place) 버전을 원한다면 `partition` 함수를 이용해 리스트 내부에서 원소를 교환하는 방식으로 구현할 수도 있습니다. 필요하면 그 버전도 알려드릴게요!
