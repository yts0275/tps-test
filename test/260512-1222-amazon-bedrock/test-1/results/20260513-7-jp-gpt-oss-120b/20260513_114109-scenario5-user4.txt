아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 무슨 일을 하는지 설명하는 주석을 달아 두었으니, 알고리즘 흐름을 이해하는 데 도움이 될 거예요.

```python
# 퀵소트를 수행하는 함수 정의
def quick_sort(arr):
    # 배열이 비어 있거나 원소가 하나뿐이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr                         # 기본 사례 (Base case)

    # 피벗(pivot) 선택: 여기서는 배열의 마지막 원소를 피벗으로 사용
    pivot = arr[-1]                        # 피벗은 정렬 기준이 되는 값

    # 피벗보다 작은 원소들을 저장할 리스트
    less = []                              # 피벗보다 작은 값들을 모음
    # 피벗과 같은 값을 저장할 리스트 (피벗 자체도 여기 포함)
    equal = [pivot]                        # 피벗과 같은 값(중복 포함)
    # 피벗보다 큰 원소들을 저장할 리스트
    greater = []                           # 피벗보다 큰 값들을 모음

    # 배열의 첫 번째부터 마지막 전까지(피벗 제외) 순회하면서 분할
    for x in arr[:-1]:                     # 피벗을 제외한 나머지 원소들
        if x < pivot:                      # 피벗보다 작다면
            less.append(x)                 # less 리스트에 추가
        elif x == pivot:                   # 피벗과 같다면
            equal.append(x)                # equal 리스트에 추가 (중복 처리)
        else:                              # 피벗보다 크다면
            greater.append(x)              # greater 리스트에 추가

    # 재귀적으로 less와 greater 부분을 정렬하고, 세 리스트를 합쳐 최종 결과 반환
    #     1) less 부분을 정렬
    #     2) 피벗과 같은 값들(equal) 그대로
    #     3) greater 부분을 정렬
    return quick_sort(less) + equal + quick_sort(greater)


# ------------------------------
# 예시로 사용할 테스트 배열
arr = [33, 10, 55, 71, 29, 3, 18, 90, 42]

# 퀵소트를 실행하고 결과를 출력
sorted_arr = quick_sort(arr)
print("정렬 전 :", arr)          # 정렬 전 원본 배열 출력
print("정렬 후 :", sorted_arr)   # 정렬된 배열 출력
```

### 코드 흐름 요약
1. **기본 사례** – 배열 길이가 1 이하이면 그대로 반환한다.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 삼았다. (다른 전략도 가능)  
3. **분할 단계** – 피벗을 기준으로 `less`, `equal`, `greater` 세 리스트로 원소를 나눈다.  
4. **재귀 호출** – `less`와 `greater`에 대해 다시 `quick_sort`를 호출해 정렬한다.  
5. **결과 합치기** – 정렬된 `less`, `equal`, 정렬된 `greater`를 차례대로 이어 최종 정렬 배열을 만든다.
