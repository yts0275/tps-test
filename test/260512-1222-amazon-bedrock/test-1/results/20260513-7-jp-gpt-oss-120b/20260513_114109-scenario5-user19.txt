아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 예시입니다.  
각 코드 라인마다 한국어 주석을 달아 동작을 상세히 설명했습니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수 정의, 입력은 정렬할 리스트 arr
    if len(arr) <= 1:                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                        # 그대로 반환한다

    pivot = arr[len(arr) // 2]           # 피벗(pivot) 선택 – 여기서는 중간 요소를 사용
    left = []                            # 피벗보다 작은 요소들을 담을 리스트
    middle = []                          # 피벗과 같은 값들을 담을 리스트 (중복을 위한)
    right = []                           # 피벗보다 큰 요소들을 담을 리스트

    for x in arr:                        # 입력 리스트의 각 요소를 하나씩 검사
        if x < pivot:                     # 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x == pivot:                  # 피벗과 같으면
            middle.append(x)              # middle 리스트에 추가 (중복값 보존)
        else:                             # 피벗보다 크면
            right.append(x)               # right 리스트에 추가

    # 재귀적으로 left와 right 부분을 정렬하고,
    # middle (피벗)와 합쳐서 최종 정렬된 리스트를 만든다
    return quick_sort(left) + middle + quick_sort(right)  # 정렬된 left + 피벗 + 정렬된 right 반환


# -------------------------------------------------------------------------
# 사용 예시
if __name__ == "__main__":                # 스크립트가 직접 실행될 때만 아래 코드 실행
    sample = [33, 10, 55, 71, 29, 3, 18, 42]   # 정렬하고 싶은 임의의 리스트
    print("원본 리스트 :", sample)            # 원본 출력
    sorted_list = quick_sort(sample)          # 퀵소트 함수 호출
    print("정렬된 리스트:", sorted_list)      # 정렬 결과 출력
```

### 코드 흐름 요약
1. **기본 종료 조건** – 리스트 길이가 1 이하이면 그대로 반환.  
2. **피벗 선택** – 중간값(`arr[len(arr)//2]`)을 피벗으로 사용.  
3. **분할 단계** – 모든 원소를 `left`, `middle`, `right` 세 그룹으로 나눈다.  
4. **재귀 호출** – `left`와 `right` 그룹을 각각 다시 `quick_sort`로 정렬한다.  
5. **결합 단계** – 정렬된 `left` + `middle`(피벗) + 정렬된 `right`를 이어 최종 리스트를 만든다.  

이와 같이 퀵소트는 **분할‑정복(Divide‑Conquer)** 전략을 이용해 평균 *O(N log N)* 의 시간복잡도를 보이며, 최악의 경우(이미 정렬된 리스트 등) *O(N²)* 가 될 수 있습니다.  
추가적인 최적화(예: 무작위 피벗 선택, 삽입 정렬 전환 등)도 상황에 따라 적용할 수 있습니다.
