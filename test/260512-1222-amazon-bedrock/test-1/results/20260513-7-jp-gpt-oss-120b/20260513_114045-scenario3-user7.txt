아래는 **Python** 으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 줄마다 무슨 역할을 하는지 이해하기 쉽도록 한글 주석을 달아두었습니다.  

```python
# quick_sort.py
# 리스트(배열)를 받아서 정렬된 새 리스트를 반환하는 퀵소트 구현

def quick_sort(arr):
    """
    퀵소트 메인 함수
    :param arr: 정렬하고 싶은 리스트
    :return: 정렬된 새로운 리스트
    """
    # 1️⃣ 베이스 케이스: 리스트 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2️⃣ 피벗 선택: 여기서는 리스트의 마지막 요소를 피벗으로 잡는다
    pivot = arr[-1]               # 피벗은 마지막 원소

    # 3️⃣ 피벗보다 작은 원소들을 모아 left 리스트에, 큰 원소들을 right 리스트에 넣는다
    left = []                     # 피벗보다 작은 값들을 저장할 리스트
    right = []                    # 피벗보다 큰 값들을 저장할 리스트
    for x in arr[:-1]:            # 피벗을 제외한 모든 원소를 순회
        if x <= pivot:            # 피벗보다 작거나 같으면
            left.append(x)        # left 리스트에 추가
        else:                     # 피벗보다 크면
            right.append(x)       # right 리스트에 추가

    # 4️⃣ 재귀 호출: left와 right 부분 배열을 각각 다시 퀵소트
    sorted_left = quick_sort(left)    # left 부분을 정렬
    sorted_right = quick_sort(right)  # right 부분을 정렬

    # 5️⃣ 결과 결합: left 정렬 결과 + 피벗 + right 정렬 결과 순서대로 이어 붙인다
    return sorted_left + [pivot] + sorted_right


# ------------------------------------------------------------------
# 아래는 구현된 함수를 직접 테스트해 보는 간단한 예시입니다.
if __name__ == "__main__":
    unsorted = [33, 10, 55, 71, 29, 3, 18, 90]   # 정렬되지 않은 샘플 리스트
    print("원본 리스트 :", unsorted)
    sorted_list = quick_sort(unsorted)           # 퀵소트 실행
    print("정렬된 리스트:", sorted_list)
```

### 코드 흐름 요약
1. **베이스 케이스** – 리스트가 비었거나 요소가 1개뿐이면 그대로 반환.  
2. **피벗 선택** – 여기서는 마지막 원소를 피벗으로 사용했지만, 임의 선택이나 중간값 선택 등 다른 전략도 가능.  
3. **분할** – 피벗보다 작거나 같은 값은 `left`, 큰 값은 `right`에 나눠 담음.  
4. **재귀 호출** – `left`와 `right`에 대해 각각 같은 과정을 다시 수행.  
5. **결합** – 정렬된 `left` + 피벗 + 정렬된 `right`를 순서대로 이어서 최종 정렬 결과를 만든다.  

이 구현은 **O(n log n)** 평균 시간 복잡도를 가지며, 최악의 경우(이미 정렬된 리스트에 피벗을 마지막 원소로 선택했을 때) **O(n²)** 가 될 수 있습니다.  
피벗 선택 방식을 개선하거나 원소를 제자리(in‑place)에서 교환하도록 구현하면 메모리 사용량을 줄일 수 있습니다. 필요하면 그런 버전도 알려드릴게요!
