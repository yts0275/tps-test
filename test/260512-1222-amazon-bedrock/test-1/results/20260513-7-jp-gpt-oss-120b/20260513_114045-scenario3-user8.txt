아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
각 코드 라인마다 무엇을 하는지 자세히 설명하는 주석을 달아 두었으니, 코드를 읽으면서 흐름을 바로 이해하실 수 있을 겁니다.

```python
def quick_sort(arr):                     # 퀵소트를 수행할 함수 정의 (입력: 정렬할 리스트)
    if len(arr) <= 1:                    # 리스트 길이가 0 혹은 1이면 이미 정렬된 상태
        return arr                        # 그대로 반환 (재귀 호출 종료 조건)

    # 피벗(pivot) 선택: 여기서는 리스트의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]                       # 피벗 값 저장
    left = []      # 피벗보다 작은 값들을 모을 리스트
    right = []     # 피벗보다 큰 값들을 모을 리스트
    middle = []    # 피벗과 같은 값(중복된 경우)을 모을 리스트

    for x in arr:                         # 입력 리스트의 모든 원소를 순회
        if x < pivot:                     # 현재 원소가 피벗보다 작으면
            left.append(x)                # left 리스트에 추가
        elif x > pivot:                   # 현재 원소가 피벗보다 크면
            right.append(x)               # right 리스트에 추가
        else:                             # 현재 원소가 피벗과 같으면(중복)
            middle.append(x)              # middle 리스트에 추가 (피벗 자체 포함)

    # 재귀적으로 left와 right 부분을 정렬하고, middle(피벗)와 합쳐서 반환
    return quick_sort(left) + middle + quick_sort(right)
    # left ⟶ 재귀 정렬 → 피벗(중복 포함) → right ⟶ 재귀 정렬 순으로 연결

# -------------------------------------------------------------------------
# 사용 예시 (테스트용)
if __name__ == "__main__":                # 이 파일이 직접 실행될 때만 아래 코드 실행
    unsorted = [33, 10, 55, 71, 29, 33, 2, 18]   # 정렬되지 않은 예시 리스트
    print("원본 리스트 :", unsorted)           # 원본 리스트 출력
    sorted_list = quick_sort(unsorted)         # 퀵소트 호출
    print("정렬 결과 :", sorted_list)          # 정렬된 리스트 출력
```

### 주요 포인트
1. **피벗 선택**  
   - 여기서는 가장 오른쪽 요소를 피벗으로 사용했지만, `random.choice(arr)` 로 무작위 선택하거나, `arr[0]`(첫 번째) 등을 사용할 수도 있습니다. 피벗 선택 방식에 따라 평균 성능이 달라질 수 있습니다.

2. **분할 단계 (Partition)**  
   - 리스트를 `left`, `middle`, `right` 세 부분으로 나누어, 재귀 호출을 통해 각각을 독립적으로 정렬합니다.  
   - `middle`은 피벗과 같은 값을 모아 두어, 중복값이 있을 때도 올바르게 동작합니다.

3. **재귀 종료 조건**  
   - `len(arr) <= 1` 인 경우 더 이상 나눌 필요가 없으므로 바로 반환합니다. 이 조건이 없으면 무한 재귀에 빠지게 됩니다.

4. **시간 복잡도**  
   - 평균: **O(N log N)**  
   - 최악(이미 정렬된 경우 등): **O(N²)** (피벗 선택이 좋지 않을 때)  
   - 공간 복잡도: **O(N)** (새 리스트 `left`, `right`, `middle`을 만들기 때문에)

필요에 따라 피벗 선택 방식을 바꾸거나, **in‑place**(제자리) 구현으로 메모리 사용량을 줄일 수도 있습니다. 궁금한 점이 있으면 언제든 물어보세요! 🚀
