---

### 🚀 퀵소트(Quick Sort) Python 구현 (재귀, 파이썬 3)

```python
def quick_sort(arr):
    """
    퀵소트 재귀 함수
    배열을 피벗을 기준으로 분할하여 정렬
    """
    # 배열이 비거나 원소가 하나라면, 정렬할 필요가 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 배열의 첫 번째 요소로 선택
    pivot = arr[0]

    # 피벗보다 작은 요소들로 구성된 배열 (왼쪽 그룹)
    left = [x for x in arr[1:] if x <= pivot]

    # 피벗보다 큰 요소들로 구성된 배열 (오른쪽 그룹)
    right = [x for x in arr[1:] if x > pivot]

    # 재귀 호출로 왼쪽과 오른쪽 그룹을 정렬한 후,
    # [작은 것들] + [피벗] + [큰 것들] 순서로 결합하여 반환
    return quick_sort(left) + [pivot] + quick_sort(right)
```

---

### 📌 예시 사용법:

```python
unsorted_list = [3, 6, 8, 10, 1, 2, 1]
sorted_list = quick_sort(unsorted_list)

print("정렬 전:", unsorted_list)
print("정렬 후:", sorted_list)
```

### ✅ 결과 예시:

```
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

---

### 💡 설명 요약:

- **퀵소트**는 **피벗 기준 분할과 정복**(divide and conquer) 전략을 사용.
- 시간 복잡도는 평균적으로 **O(n log n)**, 최악의 경우 **O(n²)** (이미 정렬된 데이터).
- 이 구현은 **재귀 방식**이며, **불안정 정렬**(Unstable sort)입니다.
- 파이썬에서는 슬라이싱과 리스트 내포 표현(list comprehension)을 활용해 간단히 구현 가능.

필요하다면 이 알고리즘을 **인플레이스(in-place)** 방식으로 다시 구현도 도와드릴 수 있어요!
