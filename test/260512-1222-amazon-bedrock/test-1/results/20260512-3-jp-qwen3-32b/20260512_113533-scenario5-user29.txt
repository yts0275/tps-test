---

### 📌 퀵소트(Quick Sort)

**작동 원리**:
- 하나의 요소를 **基准値 (피벗)**으로 삼습니다.
- 피벗보다 작거나 같은 수는 왼쪽 배열, 큰 수는 오른쪽 배열에 배치합니다.
- 그런 다음, 왼쪽/오른쪽 배열에 대해서도 퀵소트를 재귀적으로 적용합니다.

---

### ✅ 파이썬 퀵소트 소스 (재귀적)

```python
def quicksort(arr):
    # 1. 배열이 비어 있거나 요소가 하나만 있을 경우, 그대로 반환 (재귀 종료 조건)
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선택 (예: 가장 첫 번째 요소)
    pivot = arr[0]

    # 3. 피벗보다 작은 요소들을 모아서 왼쪽 배열 생성
    left = [x for x in arr[1:] if x <= pivot]

    # 4. 피벗보다 큰 요소들을 모아서 오른쪽 배열 생성
    right = [x for x in arr[1:] if x > pivot]

    # 5. 재귀적으로 왼쪽과 오른쪽을 정렬한 후, 왼쪽 + [피벗] + 오른쪽을 반환
    return quicksort(left) + [pivot] + quicksort(right)
```

---

### 🎯 예시 사용

```python
# 예시 리스트
arr = [7, 2, 1, 6, 8, 5, 3]

# 퀵소트 실행
sorted_arr = quicksort(arr)

# 결과 출력
print(sorted_arr)
```

---

### 📝 예상 출력

```
[1, 2, 3, 5, 6, 7, 8]
```
