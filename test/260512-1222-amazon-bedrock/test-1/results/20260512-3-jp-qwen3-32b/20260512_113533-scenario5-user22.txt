---

### 🔍 퀵소트(QuickSort) 개요

퀵소트는 분할 정복 방식의 정렬 알고리즘입니다.  
하나의 '피벗(Pivot)'을 기준으로 데이터를 두 부분으로 분할한 후, 각 부분에 대해 재귀적으로 정렬하는 방식입니다.

---

### ✅ 파이썬 퀵소트 구현 (함수 스타일)

```python
def quick_sort(arr):
    # 종료 조건: 배열의 길이가 1 이하이면 정렬이 완료된 것으로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(Pivot) 선택: 여기서는 배열의 중간 값 선택
    pivot = arr[len(arr) // 2]

    # 피벗 기준으로 왼쪽, 오른쪽, 중간(피벗) 배열 생성
    left = [x for x in arr if x < pivot]      # 피벗보다 작은 값들
    middle = [x for x in arr if x == pivot]   # 피벗과 같은 값들
    right = [x for x in arr if x > pivot]     # 피벗보다 큰 값들

    # 재귀적으로 왼쪽과 오른쪽을 정렬한 후, middle과 합침
    return quick_sort(left) + middle + quick_sort(right)
```

---

### 📌 예시 사용법

```python
# 예시 리스트
nums = [3, 6, 8, 10, 1, 2, 1]

# 퀵소트 수행
sorted_nums = quick_sort(nums)

# 결과 출력
print("정렬 결과:", sorted_nums)
```

---

### ✍️ 주석 요약

- `if len(arr) <= 1`: 재귀 종료 조건. 더 이상 정렬할 필요 없음.
- `pivot = arr[len(arr) // 2]`: 피벗을 배열 중간 인덱스의 값으로 선택.
- `left`, `middle`, `right`: 리스트를 세 부분으로 분할.
- `return quick_sort(left) + middle + quick_sort(right)`: 재귀적으로 정렬 후 결과를 합침.
