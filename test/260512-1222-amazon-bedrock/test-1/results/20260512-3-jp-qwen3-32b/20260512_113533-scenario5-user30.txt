물론입니다! 아래는 Python으로 작성된 **퀵소트(Quick Sort)**의 예제 코드입니다. 각 줄마다 주석을 달아 설명을 넣었습니다.

---

```python
# 퀵소트를 위한 partition 함수 정의
def partition(arr, low, high):
    # pivot을 배열의 끝값 (high)로 선택
    pivot = arr[high]
    
    # i는 pivot보다 작은 수들의 마지막 인덱스를 가리킵니다.
    i = low - 1

    # low부터 high-1까지 반복하며 pivot보다 작은 수를 왼쪽으로 이동
    for j in range(low, high):
        if arr[j] <= pivot:  # 현재 요소가 pivot보다 작거나 같다면
            i += 1           # 왼쪽 인덱스 증가
            arr[i], arr[j] = arr[j], arr[i]  # 요소 교환

    # pivot을 올바른 위치로 놓음
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # pivot 인덱스 반환 (정렬 완료된 위치)
    return i + 1


# 퀵소트 재귀 함수
def quick_sort(arr, low, high):
    if low < high:
        # partition을 호출해서 pivot 인덱스 얻음
        pi = partition(arr, low, high)

        # pivot 기준으로 좌측 부분 정렬
        quick_sort(arr, low, pi - 1)

        # pivot 기준으로 우측 부분 정렬
        quick_sort(arr, pi + 1, high)


# 테스트용 배열 정의
arr = [10, 7, 8, 9, 1, 5]

# 배열의 처음, 끝 인덱스 설정
n = len(arr)

# quick_sort 함수 실행
quick_sort(arr, 0, n - 1)

# 정렬된 배열 출력
print("정렬된 배열:", arr)
```

---

### 📌 설명 요약:
- `partition`: 기준(pivot)을 기준으로 배열을 두 부분으로 나누는 함수.
- `quick_sort`: 재귀적으로 좌우 부분을 같은 방식으로 정렬.
- 시간복잡도: 평균 O(n log n), 최악 O(n²) (배열이 거의 정렬된 경우).
