---

### ✅ 퀵소트란?

퀵소트는 **분할 정복 전략**을 사용하는 정렬 알고리즘입니다.  
데이터를 **기준값(pivot)**을 기준으로 두 개의 그룹으로 나누고, 그 그룹을 재귀적으로 정렬합니다.

---

### 📌 Python 퀵소트 구현 (재귀적 버전)

```python
def quicksort(arr):
    # 1. 종료 조건: 리스트 길이가 0이거나 1이면 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 2. pivot 선택 (여기서는 맨 첫 번째 요소로 선택)
    pivot = arr[0]
    
    # 3. pivot보다 작은 요소들을 모은 리스트
    less = [x for x in arr[1:] if x <= pivot]
    
    # 4. pivot보다 큰 요소들을 모은 리스트
    greater = [x for x in arr[1:] if x > pivot]
    
    # 5. 재귀적으로 정렬 후, less + pivot + greater를 결합하여 반환
    return quicksort(less) + [pivot] + quicksort(greater)
```

---

### 🔎 정렬 예시

```python
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quicksort(arr)
print("정렬 결과:", sorted_arr)
```

**출력:**

```
정렬 결과: [1, 1, 2, 3, 6, 8, 10]
```

---

### 📚 주석 정리

- **줄 2~4:** 재귀 종료 조건을 설정합니다. (리스트 길이가 1 이하이면 더 이상 정렬할 필요가 없음)
- **줄 6:** 기준값(pivot)을 선택합니다. 여기서는 리스트의 첫 번째 요소를 사용.
- **줄 8:** pivot 이하인 요소들로 구성된 새로운 리스트를 만듭니다.
- **줄 10:** pivot 초과인 요소들로 구성된 새로운 리스트를 만듭니다.
- **줄 12:** less 리스트, pivot, greater 리스트를 합쳐서 반환합니다.
