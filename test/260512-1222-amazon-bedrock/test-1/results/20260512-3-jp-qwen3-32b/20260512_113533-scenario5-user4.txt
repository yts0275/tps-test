### 🧠 퀵소트(Quick Sort)란?
퀵소트는 분할 정복 기법을 사용하는 **정렬 알고리즘**입니다.  
배열 하나를 피벗(pivot)으로 나누어, 크기 비교를 통해 재귀적으로 구간을 나누어 정렬합니다. 대부분 효율적인 성능을 보이지만 최악의 경우 느릴 수 있습니다.

---

### ✅ 파이썬 퀵소트 구현 (재귀 방식)

```python
def quick_sort(arr):
    # 재귀의 기저 조건: 배열의 크기가 1 이하이면 정렬할 필요 없음
    if len(arr) <= 1:
        return arr
    
    # 리스트의 첫 번째 요소를 피벗(pivot)으로 설정
    pivot = arr[0]
    
    # 피벗보다 작은 요소를 담을 리스트
    less_than_pivot = []
    
    # 피벗과 같은 요소를 담을 리스트
    equal_to_pivot = []
    
    # 피벗보다 큰 요소를 담을 리스트
    greater_than_pivot = []
    
    # 배열의 모든 요소에 대해 분류
    for num in arr:
        if num < pivot:
            less_than_pivot.append(num)  # 피벗보다 작으면 왼쪽 그룹
        elif num == pivot:
            equal_to_pivot.append(num)  # 피벗과 같으면 중간 그룹
        else:
            greater_than_pivot.append(num)  # 피벗보다 크면 오른쪽 그룹
    
    # 재귀적으로 왼쪽, 오른쪽 그룹 정렬 후, 전체를 연결
    return quick_sort(less_than_pivot) + equal_to_pivot + quick_sort(greater_than_pivot)
```

---

### 🔍 예시 사용법

```python
unsorted_list = [5, 2, 9, 1, 7, 3, 6]
sorted_list = quick_sort(unsorted_list)
print(sorted_list)
```

### ❗ 결과
```
[1, 2, 3, 5, 6, 7, 9]
```
