### ✅ 퀵소트(Quick Sort)란?

퀵소트는 **분할 정복**(Divide and Conquer) 방식의 정렬 알고리즘입니다.  
가운데 원소를 **pivot**으로 설정하고, 이 값을 기준으로 배열을 두 부분으로 나눈 후 재귀적으로 정렬합니다.

---

### ✅ 파이썬 코드: 퀵소트 구현 (with 주석)

```python
def quick_sort(arr):
    # 1. 기저 조건: 배열의 길이가 1 이하이면 정렬할 필요가 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot) 선택: 중간 값을 선택합니다. (첫 번째 값일 수도 있어요)
    pivot = arr[len(arr) // 2]

    # 3. 피벗보다 작거나 같은 요소 -> left
    left = [x for x in arr if x < pivot]

    # 4. 피벗과 같은 요소 -> middle
    middle = [x for x in arr if x == pivot]

    # 5. 피벗보다 큰 요소 -> right
    right = [x for x in arr if x > pivot]

    # 6. 재귀적으로 left, right 부분 정렬 후, 결합
    return quick_sort(left) + middle + quick_sort(right)

# 🧪 테스트 코드
arr = [3, 6, 8, 10, 1, 2, 1]
print("원본 배열:", arr)
sorted_arr = quick_sort(arr)
print("정렬된 배열:", sorted_arr)
```

---

### ✅ 실행 예시

```plaintext
원본 배열: [3, 6, 8, 10, 1, 2, 1]
정렬된 배열: [1, 1, 2, 3, 6, 8, 10]
```

---

### 💡 설명 정리

- `quick_sort` 함수는 재귀적으로 작동합니다.
- `left`, `middle`, `right`는 각각 피벗 기준으로 작은 값, 같은 값, 큰 값을 분류합니다.
- 재귀로 다시 `quick_sort(left)`와 `quick_sort(right)`를 수행하여 분할 정복합니다.
- `left + middle + right`로 최종적으로 정렬된 배열이 구성됩니다.
