### 🔹 퀵소트(Quick Sort) 구현 (Python)

```python
def quicksort(arr):
    """
    입력된 리스트를 퀵소트로 정렬하는 함수
    """
    # 1-1. 재귀를 종료시킬 기저 조건: 리스트의 길이가 1 이하이면 이미 정렬된 것으로 본다.
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot)을 선택합니다.
    # 여기서는 리스트의 첫 번째 요소를 피벗으로 선택
    pivot = arr[0]

    # 3. 피벗보다 작은 요소를 담을 왼쪽 리스트
    less = []
    # 피벗보다 큰 요소를 담을 오른쪽 리스트
    greater = []

    # 4. 리스트를 순회하며 피벗과 비교
    for i in range(1, len(arr)):  # 리스트의 두 번째 요소부터 순회
        if arr[i] < pivot:
            less.append(arr[i])   # 피벗보다 작은 경우 less 리스트에 추가
        else:
            greater.append(arr[i])  # 피벗보다 같거나 큰 경우 greater 리스트에 추가

    # 5. 재귀적으로 왼쪽, 오른쪽 리스트를 정렬하고, 전체를 결합
    return quicksort(less) + [pivot] + quicksort(greater)


# 테스트
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quicksort(arr)
print("정렬된 배열:", sorted_arr)
```

---

### 🔸 주석 설명 요약

1. **기저 조건**: 리스트가 공백이나 1개 요소뿐일 때는 더 이상 정렬할 필요가 없으므로 직접 반환.
2. **피벗 선택**: 리스트의 첫 번째 요소를 피벗으로 선택.
3. **파티셔닝 과정**: 피벗보다 작거나 큰 요소를 별도의 리스트에 저장.
4. **재귀 호출**: 왼쪽 리스트와 오른쪽 리스트를 퀵소트 함수로 재귀적 호출.
5. **최종 구성**: 정렬된 왼쪽 + 피벗 + 정렬된 오른쪽을 합쳐 최종 정렬된 리스트로 반환.
