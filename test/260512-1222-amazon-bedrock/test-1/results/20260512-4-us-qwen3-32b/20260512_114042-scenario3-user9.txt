---

### ✅ Python 퀵소트 (Quick Sort) 구현 + 줄별 주석

```python
def quick_sort(arr):
    # 배열이 비어 있거나 하나의 요소만 있는 경우, 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 배열의 중간 요소로 선택 (보통 첫 번째 요소, 중간, 마지막 중 선택 가능)
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 요소들을 모은 배열
    left = [x for x in arr if x < pivot]

    # 피벗과 같은 요소들을 모은 배열
    middle = [x for x in arr if x == pivot]

    # 피벗보다 큰 요소들을 모은 배열
    right = [x for x in arr if x > pivot]

    # 왼쪽 배열을 퀵소트한 결과 + 중간 배열 + 오른쪽 배열을 퀵소트한 결과를 반환
    return quick_sort(left) + middle + quick_sort(right)
```

---

### 📌 설명 정리

- **기저 조건**: 배열 길이가 1 이하이면 더 정렬할 필요가 없으므로 그대로 반환.
- **피벗 선택**: 일반적으로 중간값, 첫 번째 값, 마지막 값 중 선택. 여기서는 중간 값을 선택.
- **분할**: 피벗 기준으로 **작은 값**, **같은 값**, **큰 값** 세 그룹으로 나눔.
- **재귀 호출**: 왼쪽과 오른쪽 배열에 다시 `quick_sort` 호출. 즉, 분할 정복 방식.

---

### ✅ 예시 실행

```python
print(quick_sort([5, 3, 8, 4, 1, 9, 2]))
# [1, 2, 3, 4, 5, 8, 9] 가 출력 됩니다.
```
