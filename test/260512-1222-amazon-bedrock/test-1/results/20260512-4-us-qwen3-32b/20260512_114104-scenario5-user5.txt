---

### ✅ 퀵소트(Quick Sort) – 파이썬 구현 (재귀 버전)
```python
def quick_sort(arr):
    """
    퀵소트 함수: 리스트를 오름차순으로 정렬합니다.
    재귀 알고리즘을 사용하여 작동합니다.
    """

    # 1. 리스트가 비어 있거나 요소가 하나뿐이면 정렬할 필요가 없으므로, 그대로 반환
    if len(arr) <= 1:
        return arr

    # 2. 피벗(pivot)을 선택 – 여기서는 첫 번째 요소를 피벗으로 선택
    pivot = arr[0]

    # 3. 피벗보다 작은 요소들을 담을 리스트
    less = []

    # 4. 피벗보다 큰 요소들을 담을 리스트
    greater = []

    # 5. 피벗과 같은 값을 담을 리스트 (필요 시, 여기선 생략해도 됨)
    # equal = []

    # 6. 배열의 나머지 요소들을 순회하며 분할
    for x in arr[1:]:
        if x < pivot:
            less.append(x)  # 피벗보다 작으면 'less' 리스트에 추가
        else:
            greater.append(x)  # 피벗보다 크거나 같으면 'greater' 리스트에 추가
        # equal.append(x) if x == pivot else (less if x < pivot else greater)

    # 7. 재귀호출을 통해 'less'와 'greater' 부분을 각각 정렬하고,
    #    'less' + [pivot] + 'greater' 형태로 합치면 최종 정렬 완성
    return quick_sort(less) + [pivot] + quick_sort(greater)
```

---

### 📌 예시
```python
unsorted_list = [3, 6, 8, 10, 1, 2, 1]
sorted_list = quick_sort(unsorted_list)
print(sorted_list)
```

**출력:**
```
[1, 1, 2, 3, 6, 8, 10]
```

---

### 📌 주의사항
- 위 구현은 **재귀**를 사용한 **파이썬 스타일의 퀵소트**입니다.
- **인플레이스(in-place)** 버전(공간복잡도 감소)도 있지만, 여기서는 이해하기 쉽게 재귀 + 리스트 재구성 방식을 사용했습니다.

필요하시면 인플레이스 퀵소트도 같이 설명해드릴 수 있어요!
