```python
# 퀵 정렬(Quick Sort) 알고리즘을 구현합니다.
def quicksort(arr, low, high):
    # 재귀적으로 호출되며, 기저 조건은 low가 high보다 크거나 같을 때입니다.
    if low < high:
        # 파티션 함수를 호출하여 피벗을 올바른 위치로 이동시키고, 피벗의 인덱스를 반환받습니다.
        pi = partition(arr, low, high)
        
        # 피벗의 왼쪽 부분에 대해 재귀적으로 퀵정렬을 수행합니다.
        quicksort(arr, low, pi - 1)
        
        # 피벗의 오른쪽 부분에 대해 재귀적으로 퀵정렬을 수행합니다.
        quicksort(arr, pi + 1, high)

# 파티션 함수는 배열을 피벗을 기준으로 두 부분으로 나눕니다.
def partition(arr, low, high):
    # 배열의 마지막 요소를 피벗으로 선택합니다.
    pivot = arr[high]
    
    # i는 작은 요소들의 인덱스를 나타냅니다. 처음에는 -1로 초기화합니다.
    i = low - 1
    
    # j는 배열의 현재 요소를 나타내며, low에서 high-1까지 반복합니다.
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같다면,
        if arr[j] <= pivot:
            # i를 증가시킨 후, i와 j의 위치를 교환합니다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동시키기 위해, 피벗과 i+1 위치의 요소를 교환합니다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 위치한 인덱스를 반환합니다.
    return i + 1

# 테스트를 위한 예제 배열
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)

# 퀵정렬 실행
quicksort(arr, 0, n - 1)

# 정렬된 결과 출력
print("정렬된 배열:", arr)
```

### 🔍 설명:

#### `quicksort` 함수:
- **목적**: 주어진 배열을 정렬합니다.
- **매개변수**:
  - `arr`: 정렬할 배열입니다.
  - `low`: 배열의 시작 인덱스입니다.
  - `high`: 배열의 끝 인덱스입니다.

#### `partition` 함수:
- **목적**: 피벗을 기준으로 배열을 나누고, 피벗이 올바른 위치에 있는 인덱스를 반환합니다.
- **매개변수**:
  - `arr`: 분할될 배열입니다.
  - `low`: 분할 범위의 시작 인덱스입니다.
  - `high`: 분할 범위의 끝 인덱스입니다.
  
#### 전체 로직:
1. 배열의 일부분에 대해 `partition`을 호출해 피벗을 적절한 위치로 이동시킵니다.
2. 피벗을 기준으로 왼쪽과 오른쪽 서브배열로 재귀적으로 퀵정렬을 진행합니다.
