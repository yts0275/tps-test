물론입니다! 다음은 **퀵정렬**(Quick Sort)의 Python 구현 코드이며, 각 줄에 주석을 달아 설명드리겠습니다.

```python
def quicksort(arr, low, high):
    # 재귀적으로 퀵정렬을 진행하는 함수
    # arr: 정렬할 배열, low: 시작 인덱스, high: 끝 인덱스

    if low < high:
        # 배열의 범위가 유효하면, 파티션 작업 수행
        pi = partition(arr, low, high)
        # 파티션 함수를 호출하여 기준값(피벗)의 최종 위치를 얻음

        # 피벗의 왼쪽 부분 정렬
        quicksort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 배열을 피벗을 기준으로 두 부분으로 나누는 함수
    # 피벗은 마지막 원소로 정함 (여기서는 arr[high])

    pivot = arr[high]  # 피벗 설정
    i = low - 1  # 작은 요소들을 나타낼 인덱스 초기화

    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            i += 1  # 작은 요소들의 인덱스를 증가시킴
            arr[i], arr[j] = arr[j], arr[i]  # 교환

    # 피벗을 올바른 위치로 이동 (작은 값들 뒤에 위치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1  # 피벗이 위치한 인덱스 반환


# 사용 예제
if __name__ == "__main__":
    # 정렬할 배열 생성
    arr = [10, 7, 8, 9, 1, 5]
    n = len(arr)
    
    print("정렬 전 배열:", arr)
    
    # 퀵정렬 함수 호출
    quicksort(arr, 0, n - 1)
    
    print("정렬 후 배열:", arr)
```

### 💡 설명

- `quicksort`: 재귀적으로 배열을 정렬하는 메인 함수.
- `partition`: 피벗을 기준으로 배열을 분할하며, 피벗의 최종 위치를 반환.
- `pivot`: 기준값으로 사용되며, 여기서는 배열의 마지막 원소를 선택.
- `i`, `j`: 인덱스 변수로, 배열을 순회하면서 요소들을 분류.
