물론입니다! 아래는 퀵소트(QuickSort) 알고리즘의 Python 구현 코드에 각 줄에 대한 주석을 달아놓은 것입니다:

```python
# 퀵소트 함수 정의: 배열을 정렬하는 재귀 함수
def quicksort(arr, low, high):
    # 기저 조건: 시작 인덱스가 끝 인덱스보다 크거나 같으면 종료
    if low < high:
        # 피벗을 기준으로 배열을 분할하고, 피벗이 존재할 인덱스를 반환
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분 정렬 (재귀 호출)
        quicksort(arr, low, pi - 1)

        # 피벗 오른쪽 부분 정렬 (재귀 호출)
        quicksort(arr, pi + 1, high)

# 파티션 함수 정의: 피벗을 기준으로 배열을 나누는 함수
def partition(arr, low, high):
    # 마지막 원소를 피벗으로 설정
    pivot = arr[high]

    # i는 작은 요소들을 가리키는 인덱스 (초기값은 low-1)
    i = low - 1

    # j는 현재 검사 중인 요소를 가리키는 인덱스
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, 배열의 i와 j 위치 요소를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킴 (i+1 위치에 배치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 위치 반환
    return i + 1

# 예제 사용법
if __name__ == "__main__":
    # 정렬할 배열 선언
    arr = [10, 7, 8, 9, 1, 5]
    
    # 배열의 길이 저장
    n = len(arr)
    
    # 퀵소트 실행 (시작 인덱스 0, 끝 인덱스 n-1)
    quicksort(arr, 0, n - 1)
    
    # 정렬된 배열 출력
    print("정렬된 배열:", arr)
```

### 설명:
- `quicksort`: 재귀적으로 배열을 분할하여 정렬합니다.
- `partition`: 피벗을 기준으로 배열을 두 부분으로 나누고, 피벗의 최종 위치를 반환합니다.
- 위 코드는 배열의 마지막 원소를 피벗으로 사용합니다.
