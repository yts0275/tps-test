QuickSort(퀵정렬)은 분할 정복 알고리즘을 사용하는 정렬 알고리즘이다. 다음은 QuickSort의 Python 구현과 각 줄에 대한 주석 설명이다:

```python
def quicksort(arr, low, high):
    # 재귀적으로 호출될 때, low가 high보다 크거나 같으면 더 이상 정렬할 필요가 없음
    if low < high:
        # 피벗을 기준으로 배열을 분할하고, 피벗의 최종 위치를 pivot_index에 저장
        pivot_index = partition(arr, low, high)

        # 피벗의 왼쪽 부분 배열에 대해 재귀적으로 퀵정렬 실행
        quicksort(arr, low, pivot_index - 1)

        # 피벗의 오른쪽 부분 배열에 대해 재귀적으로 퀵정렬 실행
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    # 마지막 원소를 피벗으로 설정
    pivot = arr[high]
    
    # i는 작은 값들이 올 위치를 추적하는 인덱스
    i = low - 1

    # low부터 high-1까지의 범위에서 반복
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같으면,
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 원소와 i 위치의 원소를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동 (피벗의 왼쪽에는 모두 작은 값, 오른쪽에는 큰 값)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 위치한 인덱스 반환
    return i + 1

# 예제 사용법
arr = [10, 7, 8, 9, 1, 5]
quicksort(arr, 0, len(arr) - 1)
print("정렬된 배열:", arr)
```

### 코드 설명 요약:

1. `quicksort` 함수는 배열의 하위 범위 (`low`부터 `high`)를 퀵정렬한다.
2. `partition` 함수는 배열을 피벗을 기준으로 두 개의 부분 배열로 분할한다.
3. 피벗을 중심으로 왼쪽은 피벗보다 작거나 같은 값, 오른쪽은 큰 값이 오도록 배치한다.
4. 재귀적으로 각 부분 배열을 정렬함으로써 전체 배열을 정렬한다.

이 방법은 평균적으로 O(n log n)의 시간 복잡도를 가지며, 공간 복잡도는 O(log n)이다.
