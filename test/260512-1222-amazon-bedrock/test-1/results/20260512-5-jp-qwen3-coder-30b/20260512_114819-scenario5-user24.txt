```python
# 퀵정렬(Quiicksort) 알고리즘을 구현하는 함수
def quicksort(arr):
    # 배열의 길이가 1개 이하인 경우, 그대로 반환 (기저조건)
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)은 배열의 중간 인덱스에 있는 요소로 선택
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작거나 같은 요소들을 저장할 리스트
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들을 저장할 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들을 저장할 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬하고 병합
    return quicksort(left) + middle + quicksort(right)

# 예제 사용법
if __name__ == "__main__":
    # 정렬할 배열
    test_array = [3, 6, 8, 10, 1, 2, 1]
    
    # 퀵정렬 수행
    sorted_array = quicksort(test_array)
    
    # 결과 출력
    print("정렬된 배열:", sorted_array)
```

이 코드는 퀵정렬 알고리즘을 구현한 것으로, 다음과 같은 방식으로 동작합니다:

1. **기저조건**: 배열의 크기가 1 이하이면 정렬할 필요가 없으므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 중간값을 피벗으로 선택합니다.
3. **분할 단계**: 피벗을 기준으로 세 개의 배열로 분할합니다:
   - 피벗보다 작은 요소들
   - 피벗과 같은 요소들
   - 피벗보다 큰 요소들
4. **재귀 호출**: 왼쪽과 오른쪽 배열을 재귀적으로 정렬하고, 결과를 결합합니다.
