물론입니다! 아래는 **퀵정렬**(Quick Sort)의 Python 구현 코드이며, 각 줄에 주석을 추가하여 설명했습니다.

```python
# 퀵정렬 함수 정의: 배열을 정렬하는 함수 (시작 인덱스와 끝 인덱스를 전달받음)
def quick_sort(arr, low, high):
    # 재귀적으로 호출되는 조건: 시작 인덱스가 끝 인덱스보다 작아야함
    if low < high:
        # 파티셔닝 함수를 호출하여 피벗 위치를 구함
        pi = partition(arr, low, high)

        # 피벗의 왼쪽 부분을 정렬
        quick_sort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분을 정렬
        quick_sort(arr, pi + 1, high)

# 파티셔닝 함수 정의: 피벗을 기준으로 배열을 분할
def partition(arr, low, high):
    # 피벗을 배열의 마지막 요소로 설정
    pivot = arr[high]

    # i는 작은 요소들의 인덱스를 가리킴 (초기값은 low-1)
    i = low - 1

    # j는 현재 탐색 중인 요소 인덱스
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 요소와 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시켜서, 피벗 왼쪽은 작은 값들, 오른쪽은 큰 값들이 오도록 함
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 있는 위치 반환
    return i + 1

# 예제 배열 생성
arr = [10, 7, 8, 9, 1, 5]

# 정렬 전 배열 출력
print("정렬 전:", arr)

# 퀵정렬 실행
quick_sort(arr, 0, len(arr) - 1)

# 정렬 후 배열 출력
print("정렬 후:", arr)
```

### 설명
- `quick_sort()` : 재귀적으로 전체 배열을 분할하여 정렬합니다.
- `partition()` : 피벗을 기준으로 배열을 나누며, 피벗 위쪽과 아래쪽으로 작은 값과 큰 값을 배치합니다.
- 피벗은 항상 배열의 끝에서 선택됩니다.
- 이 알고리즘은 시간복잡도는 평균적으로 $ O(n \log n) $이고, 최악의 경우 $ O(n^2) $입니다.
