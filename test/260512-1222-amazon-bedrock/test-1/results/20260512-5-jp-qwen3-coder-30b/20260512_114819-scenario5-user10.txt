```python
# 퀵정렬(Quiick Sort) 알고리즘을 구현하는 함수
def quicksort(arr):
    # Base case: 배열의 길이가 1 이하이면 이미 정렬된 것으로 간주하고 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # pivot을 배열의 중간 인덱스에 있는 원소로 선택
    pivot = arr[len(arr) // 2]
    
    # pivot보다 작은 값을 저장할 리스트
    left = [x for x in arr if x < pivot]
    
    # pivot과 같은 값을 저장할 리스트
    middle = [x for x in arr if x == pivot]
    
    # pivot보다 큰 값을 저장할 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽 부분과 오른쪽 부분을 정렬한 후, 결과를 합쳐서 반환
    return quicksort(left) + middle + quicksort(right)

# 사용 예제
if __name__ == "__main__":
    # 정렬할 배열을 정의
    test_array = [3, 6, 8, 10, 1, 2, 1]
    
    # 퀵정렬 함수를 호출하여 정렬된 결과를 출력
    sorted_array = quicksort(test_array)
    
    # 정렬된 배열을 출력
    print("정렬된 배열:", sorted_array)
```

### 설명:
- **quicksort 함수**: 배열을 받아 퀵정렬을 수행합니다.
- **Base Case**: 배열의 길이가 1 또는 0인 경우, 더 이상 정렬할 필요 없음.
- **Pivot 선택**: 배열의 중간값을 피벗으로 선택하여 균형 잡힌 분할을 시도.
- **분할 과정**: 피벗을 기준으로 작은 값(왼쪽), 같은 값(중간), 큰 값(오른쪽)을 나누어 처리.
- **재귀 호출**: 왼쪽과 오른쪽 서브 배열들을 재귀적으로 정렬한 후 병합.

이 방식은 평균 시간 복잡도 O(n log n)을 가지며, 공간 복잡도는 O(log n) 입니다.
