다음은 퀵소트(QuickSort) 알고리즘의 파이썬 구현 코드입니다. 각 줄에 주석을 달아 설명을 해드리겠습니다.

```python
def quicksort(arr, low, high):
    # 배열의 시작 인덱스와 끝 인덱스를 전달받습니다.
    if low < high:
        # 파티션 함수를 호출하여 피벗을 위치시키고, 피벗의 인덱스를 받습니다.
        pi = partition(arr, low, high)
        
        # 피벗 왼쪽 부분 배열에 대해 재귀적으로 퀵소트를 실행합니다.
        quicksort(arr, low, pi - 1)
        
        # 피벗 오른쪽 부분 배열에 대해 재귀적으로 퀵소트를 실행합니다.
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 마지막 요소를 피벗으로 선택합니다.
    pivot = arr[high]
    
    # 작은 요소들의 인덱스를 초기화합니다.
    i = low - 1
    
    # 배열의 모든 요소를 순회하면서 비교합니다.
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같으면,
        if arr[j] <= pivot:
            # i를 증가시키고, 작은 요소들을 왼쪽으로 이동시킵니다.
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # 교환합니다.
    
    # 피벗을 올바른 위치로 이동시킵니다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗이 위치한 인덱스를 반환합니다.
    return i + 1

# 사용 예제
if __name__ == "__main__":
    # 정렬할 배열을 정의합니다.
    arr = [10, 7, 8, 9, 1, 5]
    
    # 배열의 길이를 구합니다.
    n = len(arr)
    
    # 퀵소트를 호출합니다. 시작 인덱스는 0, 끝 인덱스는 n-1입니다.
    quicksort(arr, 0, n - 1)
    
    # 정렬된 배열을 출력합니다.
    print("정렬된 배열:", arr)
```

### 주석 설명 요약:

- `quicksort`: 재귀적으로 배열을 정렬하는 함수입니다.
- `partition`: 배열을 피벗을 기준으로 분할하고 피벗의 최종 위치를 반환합니다.
- `pivot`: 분할 작업에서 기준이 되는 값입니다.
- `i`, `j`: 인덱스 변수로, 위치를 추적합니다.
- `arr[i], arr[j] = arr[j], arr[i]`: 두 요소를 교환하는 코드입니다.
