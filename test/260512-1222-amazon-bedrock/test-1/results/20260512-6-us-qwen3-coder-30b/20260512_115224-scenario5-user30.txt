```python
# 퀵 정렬(Quick Sort) 알고리즘을 구현하는 함수
def quicksort(arr):
    # 기저 조건: 배열이 1개 이하의 요소를 갖는 경우, 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)을 배열의 중간에 위치한 요소로 설정
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들로 구성된 리스트 (왼쪽 부분)
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들로 구성된 리스트 (중간 부분)
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들로 구성된 리스트 (오른쪽 부분)
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분을 정렬하고, 중간 부분과 합쳐서 반환
    return quicksort(left) + middle + quicksort(right)

# 테스트를 위한 예제 배열
arr = [64, 34, 25, 12, 22, 11, 90]

# 퀵 정렬을 적용한 결과를 출력
print("정렬 전:", arr)
print("정렬 후:", quicksort(arr))
```

### 설명:
- 이 코드는 파이썬으로 구현된 **퀵 정렬** 알고리즘입니다.
- `quicksort` 함수는 배열을 분할하여 정렬하는 **분할 정복(Divide and Conquer)** 방식을 사용합니다.
- 피벗을 기준으로 배열을 세 부분으로 나누고, 재귀적으로 각 부분을 정렬합니다.
- 마지막에 모든 부분을 합치면서 최종 정렬된 배열을 얻습니다.
  
#### 예제 출력:
```
정렬 전: [64, 34, 25, 12, 22, 11, 90]
정렬 후: [11, 12, 22, 25, 34, 64, 90]
```
