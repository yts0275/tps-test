quick sort(퀵 정렬)은 분할 정복 알고리즘을 사용하여 배열을 정렬하는 방법입니다. 아래 코드는 퀵 정렬의 구현 예시이며, 각 줄에 주석을 달아 설명을 드렸습니다.

```python
# 피벗을 선택하고, 피벗보다 작은 원소들은 왼쪽, 큰 원소들은 오른쪽으로 나누는 함수
def partition(arr, low, high):
    # 배열의 마지막 원소를 피벗으로 설정
    pivot = arr[high]
    # i는 피벗보다 작은 원소들의 인덱스를 나타냄
    i = low - 1

    # 배열을 순회하면서 피벗과 비교
    for j in range(low, high):
        # 현재 원소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 원소와 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킴 (피벗보다 작은 요소들 왼쪽, 큰 요소들 오른쪽)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # 피벗의 최종 위치를 반환
    return i + 1

# 퀵 정렬 메인 함수
def quick_sort(arr, low, high):
    # 재귀 호출 종료 조건: 하한선이 상한선을 넘지 않도록 함
    if low < high:
        # 파티션 함수를 호출하여 피벗의 위치를 찾음
        pi = partition(arr, low, high)

        # 피벗의 왼쪽 부분 배열에 대해 재귀 호출
        quick_sort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분 배열에 대해 재귀 호출
        quick_sort(arr, pi + 1, high)

# 사용 예시
if __name__ == "__main__":
    # 정렬할 배열
    arr = [10, 7, 8, 9, 1, 5]
    n = len(arr)

    # 퀵 정렬 실행 (시작 인덱스 0, 끝 인덱스 n-1)
    quick_sort(arr, 0, n - 1)

    # 결과 출력
    print("정렬된 배열:", arr)
```

### 설명:
- `partition()` 함수는 배열을 피벗 기준으로 두 부분으로 나누는 역할을 합니다.
- `quick_sort()` 함수는 분할 정복 방식으로 배열을 정렬합니다.
- 피벗을 선택하고, 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 배치합니다.
- 이 과정을 반복해 전체 배열을 정렬합니다.

### 실행 결과 (예시):
```
정렬된 배열: [1, 5, 7, 8, 9, 10]
```
