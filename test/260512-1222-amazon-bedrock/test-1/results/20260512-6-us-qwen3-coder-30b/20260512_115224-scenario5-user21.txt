물론입니다! 아래는 **퀵정렬**(Quick Sort) 알고리즘의 Python 구현 코드입니다. 각 줄에 대해 주석을 추가하여 설명드렸습니다.

```python
# 퀵정렬 함수 정의: 배열을 정렬하는 재귀함수
def quicksort(arr, low, high):
    # 기저 조건: low가 high보다 크거나 같으면 더 이상 정렬할 필요 없음
    if low < high:
        # 파티션 함수를 호출하여 피벗의 올바른 위치 인덱스를 얻음
        pi = partition(arr, low, high)

        # 피벗 왼쪽 부분 배열에 대해 재귀적으로 퀵정렬 호출
        quicksort(arr, low, pi - 1)

        # 피벗 오른쪽 부분 배열에 대해 재귀적으로 퀵정렬 호출
        quicksort(arr, pi + 1, high)

# 파티션 함수 정의: 배열을 피벗을 기준으로 두 개의 부분 배열로 나눔
def partition(arr, low, high):
    # 가장 오른쪽 요소를 피벗으로 설정
    pivot = arr[high]

    # i는 작은 요소들이 위치할 위치를 추적함 (초기값은 low-1)
    i = low - 1

    # low에서 high-1까지 반복하며 요소들을 비교함
    for j in range(low, high):
        # 만약 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, i와 j의 요소를 교환함
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # swap

    # 피벗을 올바른 위치로 이동시킴 (i+1 위치에 배치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # swap

    # 피벗이 위치할 인덱스 반환
    return i + 1

# 예제 사용법
if __name__ == "__main__":
    # 정렬할 배열 정의
    arr = [10, 7, 8, 9, 1, 5]
    n = len(arr)  # 배열 길이

    print("정렬 전:", arr)

    # 퀵정렬 실행
    quicksort(arr, 0, n - 1)

    print("정렬 후:", arr)
```

### 🔍 코멘트 요약:

- `quicksort`: 재귀적으로 배열을 분할하고 정렬하는 메인 함수.
- `partition`: 배열을 피벗 기준으로 두 부분으로 나누는 과정.
- 피벗으로는 배열의 마지막 원소를 선택.
- `i` 변수는 작은 값들이 위치할 인덱스를 추적.
- `j` 변수는 배열 순회하면서 피벗과 비교할 인덱스.
- 시간 복잡도: 평균 O(n log n), 최악 O(n²)
