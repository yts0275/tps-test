QuickSort(퀵소트)는 분할 정복 알고리즘을 이용하여 배열을 정렬하는 방법입니다. 아래는 Python으로 구현한 퀵소트 코드에 각 줄마다 주석을 달은 것입니다:

```python
# 퀵소트 함수 정의. arr은 정렬할 배열, low는 시작 인덱스, high는 끝 인덱스
def quicksort(arr, low, high):
    # 재귀 호출 종료 조건: 시작 인덱스가 끝 인덱스보다 크거나 같으면 더 이상 정렬할 필요 없음
    if low < high:
        # 파티션 함수를 호출하여 피벗의 올바른 위치를 찾고, 그 위치를 pivot_index 변수에 저장
        pivot_index = partition(arr, low, high)

        # 피벗의 왼쪽 부분 배열에 대해 퀵소트 재귀 호출
        quicksort(arr, low, pivot_index - 1)

        # 피벗의 오른쪽 부분 배열에 대해 퀵소트 재귀 호출
        quicksort(arr, pivot_index + 1, high)


# 파티션 함수 정의. 배열을 피벗 기준으로 두 부분으로 나눔
def partition(arr, low, high):
    # 가장 오른쪽 요소를 피벗으로 선택
    pivot = arr[high]

    # i는 작은 요소들은 왼쪽에 배치하기 위한 인덱스. 초기값은 시작 인덱스 - 1
    i = low - 1

    # j는 현재 검토 중인 요소를 나타냄 (low부터 high-1까지)
    for j in range(low, high):
        # 만약 현재 요소(arr[j])가 피벗보다 작거나 같다면,
        if arr[j] <= pivot:
            # i를 증가시킨 후, i와 j의 요소들을 교환하여 작은 요소들을 왼쪽으로 이동시킴
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # 요소 교환 (swapping)

    # 피벗을 올바른 위치로 이동시킴: 피벗보다 큰 요소들이 오른쪽에 있도록 함
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 있는 새로운 인덱스를 반환함
    return i + 1


# 사용 예시
if __name__ == "__main__":
    # 정렬할 배열 정의
    arr = [10, 7, 8, 9, 1, 5]

    # 배열의 길이를 구함
    n = len(arr)

    # 퀵소트 실행: 전체 배열을 정렬
    quicksort(arr, 0, n - 1)

    # 정렬된 결과 출력
    print("정렬된 배열:", arr)
```

### 👇 설명:

- `quicksort`: 재귀적으로 배열을 분할하는 함수입니다.
- `partition`: 피벗을 기준으로 배열을 분할하고, 피벗이 올바른 위치에 도달하도록 합니다.
- 전체 과정에서 **피벗**을 통해 배열을 두 부분으로 나누고 이 과정을 반복합니다.

예시 실행결과:
```
정렬된 배열: [1, 5, 7, 8, 9, 10]
```
