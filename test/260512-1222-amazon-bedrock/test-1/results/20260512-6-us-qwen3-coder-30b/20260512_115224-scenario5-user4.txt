물론입니다! 아래는 **퀵정렬(Quick Sort)**의 구현 코드이며, 각 줄에 **주석**으로 설명을 추가했습니다:

```python
# 퀵정렬 함수 정의. 배열과 시작 인덱스, 끝 인덱스를 매개변수로 받음
def quicksort(arr, low, high):
    # 재귀 종료 조건: 시작 인덱스가 끝 인덱스보다 크거나 같으면 종료
    if low < high:
        # 피벗을 기준으로 배열을 분할하고, 피벗의 올바른 위치 인덱스를 반환
        pi = partition(arr, low, high)

        # 피벗의 왼쪽 부분에 대해 재귀적으로 퀵정렬 호출
        quicksort(arr, low, pi - 1)

        # 피벗의 오른쪽 부분에 대해 재귀적으로 퀵정렬 호출
        quicksort(arr, pi + 1, high)

# 파티션 함수 정의. 배열을 피벗을 기준으로 두 개의 그룹으로 나누는 역할
def partition(arr, low, high):
    # 가장 오른쪽 원소를 피벗으로 설정
    pivot = arr[high]

    # i는 작은 요소들의 인덱스를 나타내며, 처음에는 -1로 초기화
    i = low - 1

    # j는 현재 탐색 중인 요소의 인덱스를 나타냄
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같은 경우
        if arr[j] <= pivot:
            # i를 증가시키고, i와 j의 위치를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동시킴 (i+1 위치에 배치)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗이 위치한 인덱스를 반환
    return i + 1

# 테스트용 배열 선언
arr = [10, 7, 8, 9, 1, 5]

# 배열의 길이를 구함
n = len(arr)

# 퀵정렬 실행: 전체 배열에 대해 호출
quicksort(arr, 0, n - 1)

# 정렬된 배열 출력
print("정렬된 배열:", arr)
```

---

### ✅ 코드 설명 요약:

- `quicksort`: 재귀적으로 배열을 정렬
- `partition`: 피벗을 기준으로 배열을 분할하고, 피벗의 최종 위치를 반환
- 피벗은 배열의 마지막 원소로 선택됨
- 시간 복잡도: 평균 O(n log n), 최악 O(n²)
- 공간 복잡도: O(log n) (재귀 스택 사용)
