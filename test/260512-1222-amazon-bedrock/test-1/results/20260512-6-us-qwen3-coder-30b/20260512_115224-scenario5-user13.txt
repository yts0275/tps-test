아래에 퀵정렬(Quick Sort) 알고리즘의 파이썬 구현 코드와 각 줄에 대한 설명 주석을 추가하였습니다.

```python
def quicksort(arr, low, high):
    # 재귀적으로 정렬할 배열의 범위를 지정하는 함수
    if low < high:
        # 파티션 작업을 수행하고 피벗의 인덱스를 얻음
        pi = partition(arr, low, high)
        
        # 피벗 앞쪽 부분을 재귀적으로 정렬
        quicksort(arr, low, pi - 1)
        
        # 피벗 뒤쪽 부분을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 배열의 가장 오른쪽 요소를 피벗으로 선택
    pivot = arr[high]
    
    # 작은 요소들을 배치할 위치를 나타내는 인덱스
    i = low - 1
    
    # 배열의 모든 요소를 순회하면서 피벗과 비교
    for j in range(low, high):
        # 현재 요소가 피벗보다 작거나 같으면
        if arr[j] <= pivot:
            # i를 증가시키고, 현재 요소와 arr[i]를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동시킴 (피벗의 왼쪽은 모든 요소가 피벗보다 작고,
    # 피벗의 오른쪽은 모든 요소가 피벗보다 큼)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗의 최종 위치 반환
    return i + 1

# 예시: 퀵소트를 적용할 배열
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)

# 퀵소트 실행
quicksort(arr, 0, n - 1)

# 정렬된 배열 출력
print("정렬된 배열:", arr)
```

### 🔍 설명

- `quicksort(arr, low, high)` : 재귀적으로 퀵정렬을 수행하는 메서드입니다.
  - `low`와 `high`는 배열의 인덱스 범위를 의미합니다.
- `partition(arr, low, high)` : 배열을 두 부분으로 분할하며, 피벗을 적절한 위치로 옮기는 역할을 합니다.
  - 피벗은 배열의 마지막 요소로 정해집니다.
  - 이 함수는 피벗이 들어갈 올바른 위치를 반환합니다.
- `arr[i]`, `arr[j]`는 배열 내에서 요소의 위치를 바꾸기 위한 스왑 처리입니다.
- 전체적인 시간 복잡도는 평균적으로 $ O(n \log n) $이며, 최악의 경우 $ O(n^2) $이 발생할 수 있습니다.
