```python
# 퀵정렬을 위한 함수 정의
def quicksort(arr):
    # 배열의 길이가 1 이하인 경우 더 이상 정렬할 필요 없음
    if len(arr) <= 1:
        return arr
    
    # 피벗을 배열의 중간 요소로 설정 (다른 방법으로도 가능)
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 값들을 모은 리스트
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 값을 모은 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 값들을 모은 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분을 정렬하고, 중간 부분과 합침
    return quicksort(left) + middle + quicksort(right)

# 예제 입력 배열
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵정렬 함수 호출 및 결과 출력
sorted_arr = quicksort(arr)
print("정렬된 배열:", sorted_arr)
```

위 코드는 퀵정렬 알고리즘을 파이썬으로 구현한 것입니다. 각 줄에 대해 상세한 설명이 주석으로 달려 있습니다.
