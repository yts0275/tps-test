```python
# 퀵소트(Quick Sort) 알고리즘을 구현하는 함수
def quicksort(arr):
    # 기저 사례: 배열의 길이가 1 이하인 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)은 배열의 중간 인덱스에 있는 요소로 설정 (여기서는 배열의 첫 번째 요소 사용)
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들을 모은 리스트
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들을 모은 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들을 모은 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬하고, 중간 부분과 결합하여 전체 결과를 반환
    return quicksort(left) + middle + quicksort(right)

# 테스트용 예제 배열
test_array = [3, 6, 8, 10, 1, 2, 1]

# 퀵소트 함수 호출 및 결과 출력
sorted_array = quicksort(test_array)
print("정렬된 배열:", sorted_array)
```

### 설명:

1. `quicksort` 함수는 주어진 배열을 정렬하는 재귀 함수입니다.
2. `base case` (기저 사례)로 배열의 길이가 1 이하일 경우 그대로 반환합니다.
3. 피벗은 배열의 중간 값을 사용하고, 이를 기준으로 배열을 세 가지로 분할합니다:
   - 피벗보다 작은 값들
   - 피벗과 같은 값들
   - 피벗보다 큰 값들
4. 각각의 부분 배열에 대해 재귀적으로 `quicksort`를 호출한 후 결합해서 최종 결과를 얻습니다.
