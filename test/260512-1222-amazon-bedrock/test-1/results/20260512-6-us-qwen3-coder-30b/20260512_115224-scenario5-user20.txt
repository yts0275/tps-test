```python
# 퀵정렬(Quick Sort) 알고리즘을 구현한 함수입니다.
def quick_sort(arr):
    # 기저 사례: 배열의 길이가 1 이하인 경우, 이미 정렬된 것으로 간주합니다.
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)은 배열의 중간 요소를 선택합니다.
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 값을 담을 리스트
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 값을 담을 리스트
    middle = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 값을 담을 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분을 정렬하고, 중간값을 합쳐서 반환합니다.
    return quick_sort(left) + middle + quick_sort(right)

# 예시 입력 데이터
arr = [64, 34, 25, 12, 22, 11, 90]

# 퀵정렬 함수 호출 및 결과 출력
sorted_arr = quick_sort(arr)
print("정렬된 배열:", sorted_arr)
```

해당 코드는 퀵정렬 알고리즘을 Python으로 구현한 것입니다.  
피벗을 기준으로 배열을 분할하고, 재귀적으로 각 부분배열을 정렬하여 전체 배열을 정렬하는 방식입니다.
