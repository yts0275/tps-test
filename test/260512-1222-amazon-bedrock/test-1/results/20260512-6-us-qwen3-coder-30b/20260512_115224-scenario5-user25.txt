```python
# 퀵 정렬(Qucik Sort) 알고리즘을 구현하는 함수입니다.
def quicksort(arr):
    # Base case: 배열의 길이가 1 이하이면 그대로 반환합니다.
    if len(arr) <= 1:
        return arr

    # pivot(기준 요소)를 배열의 중간에 있는 요소로 설정합니다.
    pivot = arr[len(arr) // 2]

    # pivot보다 작은 요소들을 모은 리스트
    left = [x for x in arr if x < pivot]
    
    # pivot과 같은 요소들을 모은 리스트  
    middle = [x for x in arr if x == pivot]
    
    # pivot보다 큰 요소들을 모은 리스트
    right = [x for x in arr if x > pivot]

    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬한 후, 결과를 연결합니다.
    return quicksort(left) + middle + quicksort(right)

# 예제로 사용할 배열을 정의합니다.
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵 정렬을 수행하고 결과를 출력합니다.
print("정렬 전:", arr)
sorted_arr = quicksort(arr)
print("정렬 후:", sorted_arr)
```

### 설명:
- **Base Case**: 배열의 길이가 1 이하일 경우 더 이상 정렬할 필요가 없으므로 그대로 반환합니다.
- **Pivot 선택**: 배열의 중간 요소를 기준으로 삼습니다.
- **분할 과정**:
  - `left`: pivot보다 작은 값들
  - `middle`: pivot과 같은 값들
  - `right`: pivot보다 큰 값들
- **재귀 호출**: 왼쪽과 오른쪽 배열을 각각 퀵소트하여 결과를 합칩니다.

이 코드는 파이썬에서 간단하게 퀵소트를 구현하는 방법을 보여줍니다. 시간 복잡도는 평균적으로 O(n log n), 최악의 경우 O(n²)입니다.
