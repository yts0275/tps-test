아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘 예시입니다.  
코드의 **모든 줄**에 한 줄씩 주석을 달아 이해를 돕고 있습니다.  

```python
# quick_sort 함수 정의: 입력 배열 arr을 정렬된 리스트로 반환
def quick_sort(arr):                                           # ① 함수 정의 및 주석
    # 종료 조건: 배열 길이가 0 또는 1이면 이미 정렬 완료된 상태
    if len(arr) <= 1:                                           # ② 종료 조건 검사
        return arr                                              # ③ 배열 그대로 반환
    # 피벗 선택: 배열의 가운데 값을 기준으로 삼음
    pivot = arr[len(arr) // 2]                                  # ④ 피벗 값 선택
    # 피벗보다 작은 값들로 구성되는 서브 배열
    left = [x for x in arr if x < pivot]                        # ⑤ 작은 값들만 골라 리스트 생성
    # 피벗과 동일한 값들로 구성되는 서브 배열
    middle = [x for x in arr if x == pivot]                     # ⑥ 같은 값들만 골라 리스트 생성
    # 피벗보다 큰 값들로 구성되는 서브 배열
    right = [x for x in arr if x > pivot]                       # ⑦ 큰 값들만 골라 리스트 생성
    # 재귀적으로 left와 right를 정렬한 뒤, 모두 합쳐 최종 결과를 반환
    return quick_sort(left) + middle + quick_sort(right)         # ⑧ 재귀 호출 및 리스트 결합

# 메인 실행 블록
if __name__ == "__main__":                                      # ⑨ 실행 시점 검사
    # 정렬을 테스트할 예시 배열
    arr = [3, 6, 8, 10, 1, 2, 1]                                # ⑩ 예시 배열 초기화
    # quick_sort 함수 호출로 배열 정렬
    sorted_arr = quick_sort(arr)                                 # ⑪ 정렬 수행
    # 정렬 결과 출력
    print(sorted_arr)                                            # ⑫ 결과 출력
```

**주요 포인트**  
- `pivot = arr[len(arr) // 2]` : 가운데 요소를 피벗으로 사용해 평균적인 분할을 기대합니다.  
- `left`, `middle`, `right` : 피벗 기준으로 배열을 나눈 세 부분을 각각 재귀 호출합니다.  
- 최종 `return quick_sort(left) + middle + quick_sort(right)` : 재귀 결과를 합쳐 정렬된 배열을 완성합니다.  

필요에 따라 피벗 선택 전략이나 in‑place 변형을 적용해 성능을 더 개선할 수도 있으니 참고하시기 바랍니다.
