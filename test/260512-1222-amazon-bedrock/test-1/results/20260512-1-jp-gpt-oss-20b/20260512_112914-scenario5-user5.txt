아래는 파이썬으로 작성한 퀵소트(QuickSort) 구현입니다.  
프로그램의 **각 줄마다** 한 줄 주석을 달아 기능을 자세히 설명했습니다.

```python
# 퀵소트(QuickSort) 구현 (Python)

def quicksort(arr):                  # 재귀적인 퀵소트 함수 정의
    if len(arr) <= 1:                # 입력 리스트가 공백이거나 원소가 한 개이면 그대로 반환
        return arr                   # (이미 정렬된 상태) 재귀 호출 종료

    pivot = arr[len(arr) // 2]       # 리스트 중간을 피벗(pivot)으로 선택
    less   = []                      # 피벗보다 작은 원소들을 저장할 리스트
    equal  = []                      # 피벗과 같은 원소들을 저장할 리스트
    greater= []                      # 피벗보다 큰 원소들을 저장할 리스트

    for x in arr:                    # 모든 원소를 순회하며 분할
        if x < pivot:                # 피벗보다 작은 경우
            less.append(x)           # less 리스트에 추가
        elif x == pivot:             # 피벗과 같은 경우
            equal.append(x)          # equal 리스트에 추가
        else:                       # 피벗보다 큰 경우
            greater.append(x)        # greater 리스트에 추가

    # 재귀적으로 각각을 정렬한 뒤, less, equal, greater 를 합쳐 최종 정렬 결과 반환
    return quicksort(less) + equal + quicksort(greater)  

# 사용 예시
if __name__ == "__main__":           # 직접 실행할 때만 아래 코드가 동작
    unsorted = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 대상 리스트
    sorted_list = quicksort(unsorted)   # 퀵소트 호출
    print("정렬 전:", unsorted)        # 원본 리스트 출력
    print("정렬 후:", sorted_list)     # 정렬 결과 출력
```

#### 코드 해설
1. **함수 정의**: `quicksort`는 입력 리스트 `arr`을 받아 재귀적으로 정렬합니다.  
2. **기저 조건**: 리스트가 비었거나 한 개의 원소만 있을 때는 그대로 리턴합니다.  
3. **피벗 선택**: 리스트의 중간 인덱스에 있는 값을 피벗으로 사용합니다.  
4. **분할**: `for` 루프를 이용해 원소를 `less`, `equal`, `greater` 세 리스트에 분리합니다.  
5. **재귀 호출 및 합치기**: `less`와 `greater`를 각각 재귀적으로 정렬하고,  
   `equal`을 포함해 세 리스트를 연결한 결과를 반환합니다.  
6. **메인 블록**: 테스트용으로 사용 예시를 실행하여 동작을 확인합니다.

이렇게 하면 **매줄에 주석**이 달린 퀵소트 구현이 완성됩니다. 필요에 따라 피벗 선택 방식을 바꾸거나, 정렬 안정성을 개선하는 방식으로 확장할 수 있습니다.
