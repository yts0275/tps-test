아래는 파이썬으로 구현한 퀵소트(QuickSort) 코드입니다.  
**모든 줄마다 한글 주석을 달아** 동작 원리를 상세히 설명했습니다.

```python
# 퀵소트(QuickSort)를 구현한 함수
def quicksort(arr):
    """
    주어진 리스트 arr을 오름차순으로 정렬한다.
    재귀적으로 호출되며, “분할(Partition)” 단계와 “정복(Recursion)” 단계로 나뉩니다.
    """
    # 정렬할 리스트의 길이가 0 또는 1이면 그대로 반환 (이미 정렬된 상태)
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 리스트의 마지막 요소로 선택 (임의로 중간값도 가능)
    pivot = arr[-1]

    # 피벗보다 작은 값들을 담을 리스트 left
    left = []
    # 피벗보다 큰 값들을 담을 리스트 right
    right = []

    # 리스트를 순회하며 피벗과 비교해 left 또는 right에 분리
    for num in arr[:-1]:            # 마지막 원소(피벗)는 제외하고 순회
        if num < pivot:
            left.append(num)       # 피벗보다 작으면 left에 추가
        else:
            right.append(num)      # 피벗보다 크거나 같으면 right에 추가

    # 재귀 호출: left와 right를 각각 정렬한 뒤,
    # 피벗을 중간에 삽입해 완전한 정렬 결과를 반환
    return quicksort(left) + [pivot] + quicksort(right)


# 예시 사용법
if __name__ == "__main__":
    unsorted_list = [34, 7, 23, 32, 5, 62, 3, 5, 12]
    print("정렬 전:", unsorted_list)
    sorted_list = quicksort(unsorted_list)
    print("정렬 후:", sorted_list)
```

#### 코드 흐름 요약
1. **기저 조건**  
   `len(arr) <= 1`이면 재귀 종료, 이미 정렬된 작은 리스트를 그대로 반환.

2. **피벗 선택**  
   일반적으로 마지막 원소를 피벗으로 사용 (`pivot = arr[-1]`).  
   다른 전략(중간값, 랜덤 선택 등)도 가능.

3. **분할(Partition)**  
   피벗보다 작은 원소를 `left`, 큰(혹은 같은) 원소를 `right`에 저장.

4. **정복(Recursion)**  
   `quicksort(left)`와 `quicksort(right)`를 재귀적으로 호출해 각각 정렬하고,  
   `left + [pivot] + right` 형태로 합쳐서 최종 결과를 얻음.

이 코드는 단순히 이해를 돕기 위해 `list`를 그대로 사용했으며,  
필요에 따라 인-place 버전(리스트를 직접 바꾸는 버전)으로 바꾸거나  
피벗 선택 전략을 수정해 성능을 개선할 수 있습니다.
