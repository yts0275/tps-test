아래는 파이썬으로 작성한 **퀵소트(quick sort)** 구현 예시입니다.  
코드의 **각 줄마다** 한글 주석을 달아 이해를 돕도록 했습니다.

```python
def quicksort(arr, low, high):  # QuickSort 함수 정의 : arr(정렬할 리스트), low~high(정렬 범위)
    if low < high:  # 재귀 종료 조건: low가 high보다 작을 때만 분할·정렬 진행
        pivot_index = partition(arr, low, high)  # 파티션 수행 후 피벗 위치 반환
        quicksort(arr, low, pivot_index - 1)      # 피벗 왼쪽 부분 재귀 정렬
        quicksort(arr, pivot_index + 1, high)     # 피벗 오른쪽 부분 재귀 정렬

def partition(arr, low, high):  # 파티션 함수 : 피벗을 기준으로 요소 재배치
    pivot = arr[high]  # 피벗을 배열의 마지막 원소로 선택
    i = low - 1        # i 는 작은 원소를 모아둘 인덱스(초기값은 low-1)
    for j in range(low, high):  # j 는 현재 검사 중인 인덱스
        if arr[j] < pivot:  # 현재 원소가 피벗보다 작으면
            i += 1          # i 를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # i와 j 위치에 있는 원소를 교환
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치에 놓음
    return i + 1  # 피벗이 최종적으로 위치한 인덱스를 반환

# 사용 예시
if __name__ == "__main__":
    arr = [8, 4, 7, 3, 9, 1, 6, 2, 5]  # 정렬할 배열
    quicksort(arr, 0, len(arr) - 1)   # QuickSort 실행
    print(arr)  # 정렬된 결과 출력
```

> **주의**  
> - `quicksort` 함수는 **in-place(자리에서 바로 정렬)** 방식으로 구현되었습니다.  
> - 파티션 시 피벗을 끝 원소로 고정했으며, 그 외의 구현 방법(첫번째/중간 원소 등)으로 바꿔도 같은 로직이 적용됩니다.  
> - 재귀 깊이가 배열 길이와 비슷할 경우(예: 이미 정렬된 배열) 최악의 시간복잡도 O(n²)이 발생할 수 있어, 실제 서비스에서는 `median of three` 등으로 피벗 선택을 개선합니다.
