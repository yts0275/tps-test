아래는 파이썬으로 작성한 **퀵소트(Quick Sort)** 구현 예시입니다.  
각 코드 라인마다 한 줄 주석을 붙여, 무엇을 하고 있는지 바로 알 수 있도록 했습니다.

```python
def quicksort(arr):
    # 배열 길이가 0 또는 1이면 이미 정렬이 끝난 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)은 배열 마지막 원소를 사용
    pivot = arr[-1]

    # 피벗 이하(<=) 원소들을 담을 리스트
    less = []
    # 피벗 초과(>) 원소들을 담을 리스트
    greater = []

    # 피벗 앞에 있는 모든 원소를 순회하면서 분리
    for x in arr[:-1]:
        # 현재 원소가 피벗보다 작거나 같으면 `less`에 추가
        if x <= pivot:
            less.append(x)
        # 그렇지 않으면 `greater`에 추가
        else:
            greater.append(x)

    # 재귀적으로 정렬한 왼쪽 부분, 피벗, 오른쪽 부분을 합쳐 완전한 정렬 결과 반환
    return quicksort(less) + [pivot] + quicksort(greater)

# 예시 사용
print(quicksort([3, 6, 8, 10, 1, 2, 1]))
```

#### 동작 방식
1. **베이스 케이스**: 배열이 한 개 이하라면 그대로 반환합니다.  
2. **피벗 선택**: 이 구현에서는 가장 오른쪽 요소를 피벗으로 사용합니다.  
3. **분할**: 피벗보다 작거나 같은 요소를 `less`, 더 큰 요소를 `greater`에 나눕니다.  
4. **재귀 호출**: `less`와 `greater`를 각각 재귀적으로 정렬한 뒤,  
   `left + [pivot] + right` 형태로 합쳐 최종 정렬된 리스트를 반환합니다.

*이 구현은 함수형(immutable) 방식이므로 원본 배열은 그대로 두고 정렬된 새로운 배열을 반환합니다.*  
필요에 따라 **in‑place**(제자리) 버전을 쓰면 메모리 사용량을 줄일 수 있습니다.✨
