아래는 파이썬으로 구현한 **퀵소트**(Quick Sort) 알고리즘입니다.  
각 줄마다 한 줄씩 한국어 주석을 달아 이해를 돕도록 했습니다.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

# 1. 파이썬 스크립트 시작 시에 파일 인코딩을 명시합니다.

def partition(arr, low, high):
    # 2. 루트(피벗) 요소를 선택하고, 왼쪽에서부터 오른쪽으로 순회하며
    #    피벗보다 작은 요소를 왼쪽으로, 큰것은 오른쪽으로 움직입니다.
    
    pivot = arr[high]            # 3. 배열의 가장 오른쪽 요소를 피벗으로 사용
    i = low - 1                  # 4. i는 마지막으로 정렬된 작은 요소의 인덱스를 가리킵니다.
    
    for j in range(low, high):   # 5. low부터 high-1까지 순회
        if arr[j] <= pivot:      # 6. 현재 요소가 피벗 이하라면
            i += 1               # 7. i를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]  # 8. arr[i]와 arr[j]를 교환
    # 9. 마지막으로 피벗과 i+1번째 요소를 교환해 피벗을 올바른 위치에 둡니다.
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    return i + 1                 # 10. 피벗이 이동한 인덱스를 반환

def quicksort(arr, low, high):
    # 11. quicksort 함수: 재귀적으로 정렬을 수행합니다.
    if low < high:  # 12. 배열이 비어 있지 않거나 두 원소만 있을 때만 재귀 호출
        pi = partition(arr, low, high)  # 13. 피벗을 기준으로 분할하고 피벗 인덱스를 받음
        
        # 14. 피벗보다 작은 구간을 왼쪽에서, 큰 구간을 오른쪽에서 재귀적으로 정렬
        quicksort(arr, low, pi - 1)     # 15. 피벗보다 왼쪽 구간 정렬
        quicksort(arr, pi + 1, high)    # 16. 피벗보다 오른쪽 구간 정렬

# 17. 테스트용 main 블록: 입력 배열을 정렬하고 결과를 출력
if __name__ == "__main__":
    arr = [3, 6, 8, 10, 1, 2, 1]  # 18. 정렬할 배열 정의
    print("정렬 전:", arr)       # 19. 정렬 전 배열을 출력
    quicksort(arr, 0, len(arr) - 1)  # 20. quicksort 호출
    print("정렬 후:", arr)       # 21. 정렬 후 배열을 출력
```

---

### 코드 설명

1. **`partition` 함수**  
   - 선택한 피벗(`arr[high]`)을 기준으로 배열을 두 부분으로 나눕니다.  
   - 피벗보다 작은 값은 왼쪽에, 큰 값은 오른쪽에 위치하도록 교환합니다.  
   - 함수 끝에서 피벗이 올바른 위치로 이동하도록 `i+1`번 인덱스와 피벗을 교환합니다.  
   - 피벗의 최종 인덱스를 반환합니다.

2. **`quicksort` 함수**  
   - 재귀적으로 `partition` 함수를 호출하며, 피벗을 기준으로 좌우 구간을 나눕니다.  
   - 각 구간이 하나 이상의 원소를 가질 때만 재귀를 진행합니다.

3. **main 블록**  
   - 예시 배열을 정의하고, `quicksort`를 호출해 정렬 후 결과를 확인합니다.
