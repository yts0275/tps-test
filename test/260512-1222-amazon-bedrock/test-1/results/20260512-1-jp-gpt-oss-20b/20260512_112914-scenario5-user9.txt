아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘입니다.  
코드의 **각 줄마다** 주석을 달아 이해를 돕겠습니다.

```python
# 뒤에서부터 전역 스코프를 열고, 모듈을 실행 가능하게 합니다.
if __name__ == "__main__":  # 실행 파일로서 직접 실행될 때만 아래 코드가 실행됩니다.
    pass                    # (임시선) 실제 코드는 아래에 정의됩니다.


# --------------------------------------------------------------
# 퀵소트(QuickSort) 함수 정의
# --------------------------------------------------------------
def quicksort(arr):                # arr: 정렬하려는 리스트(정수 또는 비교 가능한 객체)
    """
    인수로 받은 리스트를 오름차순으로 정렬합니다.
    이 구현은 재귀를 사용하고, 피벗을 기준으로 배열을 분할합니다.
    """
    # 1. 길이가 0 또는 1인 경우, 이미 정렬이 끝난 상태이므로 그대로 반환
    if len(arr) <= 1:              # 리스트가 0개 혹은 1개이면 자기 자신을 반환
        return arr                 # 재귀 종료: 이 서브리스트는 이미 정렬됨

    # 2. 피벗(pivot) 선택 – 비슷한 성능을 위해서 마지막 원소를 사용
    pivot = arr[-1]                # 리스트의 마지막 값이 피벗 역할을 함
    left = []                      # 피벗보다 작은 원소들을 모을 리스트
    right = []                     # 피벗보다 큰 원소들을 모을 리스트

    # 3. 피벗을 기준으로 나머지 원소들을 left와 right로 분할
    for x in arr[:-1]:             # 피벗을 제외한 모든 원소를 순회
        if x < pivot:              # 현재 원소가 피벗보다 작으면
            left.append(x)         # left 리스트에 추가
        else:                      # 그렇지 않으면
            right.append(x)        # right 리스트에 추가

    # 4. 재귀적으로 left와 right를 정렬하고, 피벗을 중간에 합침
    # 순서: 정렬한 left + 피벗 + 정렬한 right
    # 이때 재귀 호출이 계속 이어지며 배열을 분할하고 정리
    return quicksort(left) + [pivot] + quicksort(right)  # 완성된 정렬 결과 반환


# --------------------------------------------------------------
# 테스트 코드
# --------------------------------------------------------------
if __name__ == "__main__":        # 실제 실행 모드에서만 아래 코드가 실행됩니다.
    # 예시 배열
    data = [34, 7, 23, 32, 5, 62]
    print("원본:", data)          # 입력 배열 출력
    sorted_data = quicksort(data) # 퀵소트 실행
    print("정렬된 결과:", sorted_data)   # 정렬 결과 출력
```

---

### 코드 구조 요약

| 줄 | 기능 |
|---|---|
| `if __name__ == "__main__":` | 모듈이 직접 실행될 때만 아래 테스트 코드를 실행하도록 함 |
| `def quicksort(arr):` | 퀵소트 함수 정의 |
| `if len(arr) <= 1:` | 단일 요소 혹은 빈 리스트 처리 |
| `pivot = arr[-1]` | 마지막 원소를 피벗으로 지정 |
| `left = [], right = []` | 피벗 기준으로 나눌 두 개의 리스트 초기화 |
| `for x in arr[:-1]:` | 피벗을 제외한 모든 원소를 순회 |
| `if x < pivot:` | 피벗보다 작은 경우 left에 추가 |
| `else:` | 피벗보다 큰 혹은 같은 경우 right에 추가 |
| `return quicksort(left) + [pivot] + quicksort(right)` | 왼쪽 부분과 오른쪽 부분을 재귀 정렬 후 합침 |
| 테스트 코드 | 예시 입력 배열과 결과를 출력 |

이 코드는 파이썬에서 가장 직관적인 형태의 퀵소트 구현입니다.  
각 줄에 대한 주석이 포함돼 있어 이해하기 쉽도록 구성했습니다.
