아래는 **Python** 으로 구현한 퀵소트(quick‑sort) 예제입니다.  
코드의 **각 줄**마다 한국어 주석을 달았으니, 함수가 어떻게 동작하는지 한눈에 확인할 수 있습니다.

```python
# -------- 1. 퀵소트 함수 정의  --------
def quicksort(arr):            # 1️⃣ 인자로 정렬할 리스트를 받아들임
    if len(arr) <= 1:          # 2️⃣ 리스트가 0개 혹은 1개라면 이미 정렬되어 있음
        return arr             # 3️⃣ 그대로 반환

    pivot = arr[len(arr)//2]   # 4️⃣ 중앙값을 피벗으로 선택 (중앙값이 안정적인 기준)
    left = [x for x in arr if x < pivot]      # 5️⃣ 피벗보다 작은 값만 모음
    middle = [x for x in arr if x == pivot]   # 6️⃣ 피벗과 같은 값만 모음
    right = [x for x in arr if x > pivot]     # 7️⃣ 피벗보다 큰 값만 모음

    # 8️⃣ 재귀적으로 왼쪽·중간·오른쪽을 정렬하고 합침
    return quicksort(left) + middle + quicksort(right)


# -------- 2. 사용 예시  --------
if __name__ == "__main__":       # 9️⃣ 스크립트가 직접 실행될 때만 아래 코드를 실행
    data = [3, 6, 8, 10, 1, 2, 1]  # 🔟 예시로 사용할 무작위 리스트
    sorted_data = quicksort(data)   # ㊞ 퀵소트를 이용해 정렬
    print(sorted_data)              # ㊟ 정렬된 결과 출력
```

### 코드 설명
- **1번 줄**: `quicksort` 함수 정의, 입력으로 리스트 `arr`를 받습니다.  
- **2‑3번 줄**: `arr`가 0 또는 1 원소이면 이미 정렬된 상태이므로 그대로 반환합니다.  
- **4번 줄**: 피벗(pivot)을 중앙값(`len(arr)//2`)으로 정합니다. 중앙값 사용은 평균 성능을 확보하는 데 자주 쓰입니다.  
- **5‑7번 줄**: 리스트를 피벗보다 작은 `left`, 같은 `middle`, 큰 `right` 세 개의 하위 리스트로 분할합니다.  
- **8번 줄**: `left`와 `right`에 대해 재귀 호출을 수행하고, 정렬된 `middle`과 함께 합쳐서 반환합니다.  
- **9‑10번 줄**: 모듈이 직접 실행될 때만 테스트 코드를 실행합니다.  
- **11‑13번 줄**: 예시 입력을 정리하고, 결과를 출력합니다.

이 구현은 **재귀적(구조적)** 정렬이며, 평균 시간복잡도는 **O(n log n)**, 최악의 경우 **O(n²)** 입니다.  
메모리 사용량은 함수 호출 스택과 분할된 리스트를 저장하기 위해 **O(n)** 입니다.  
다른 선택 (예: in‑place 퀵소트)을 원한다면 데이터를 직접 교환하도록 코드를 수정하면 됩니다.
