아래는 파이썬으로 구현한 퀵소트(Quick Sort) 알고리즘입니다.  
코드의 **각 줄마다** 한 줄씩 설명 주석을 달았습니다.

```python
def quicksort(arr):                            # 1. 함수 정의, 정렬할 배열을 인자로 받는다.
    if len(arr) <= 1:                           # 2. 배열의 길이가 0 또는 1이면 이미 정렬된 상태라 그대로 반환
        return arr                                 # 3. 정렬된 배열 반환
    pivot = arr[-1]                              # 4. 피벗(pivot)을 배열의 마지막 원소로 선택
    left = []                                    # 5. 피벗보다 작은 값들을 저장할 리스트 초기화
    right = []                                   # 6. 피벗보다 큰 값들을 저장할 리스트 초기화
    for x in arr[:-1]:                           # 7. 피벗을 제외한 모든 원소를 순회
        if x <= pivot:                          # 8. 현재 원소가 피벗보다 작거나 같으면 left 리스트에 추가
            left.append(x)                      # 9. left 리스트에 원소를 삽입
        else:                                   # 10. 그렇지 않으면 right 리스트에 추가
            right.append(x)                     # 11. right 리스트에 원소를 삽입
    return quicksort(left) + [pivot] + quicksort(right)  # 12. 재귀 호출로 정렬된 left와 right에 피벗을 합쳐 반환
```

### 사용 예시
```python
arr = [3, 6, 8, 10, 1, 2, 1]
print(quicksort(arr))  # 출력: [1, 1, 2, 3, 6, 8, 10]
```

주석을 통해 각 줄이 수행하는 역할이 명확히 드러나므로, 퀵소트의 동작 방식을 한눈에 이해할 수 있습니다. 🚀
