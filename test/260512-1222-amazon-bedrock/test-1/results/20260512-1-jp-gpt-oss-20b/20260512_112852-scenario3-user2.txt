아래 예시는 파이썬으로 구현한 **퀵소트(Quick Sort)** 알고리즘입니다.  
각 줄마다 그 기능을 설명하는 주석을 달아 이해를 돕도록 하였습니다.

```python
def quick_sort(arr):
    # 1. 배열이 0개 혹은 1개일 때는 그대로 반환(정렬이 끝난 것)
    if len(arr) <= 1:
        return arr

    # 2. 가장 마지막 원소를 피벗(pivot)으로 사용
    pivot = arr[-1]

    # 3. pivot보다 작은 원소들을 담을 리스트(왼쪽 파티션)
    left = []

    # 4. pivot보다 큰 혹은 같은 원소들을 담을 리스트(오른쪽 파티션)
    right = []

    # 5. 피벗 이전에 있는 모든 원소를 순회
    for x in arr[:-1]:
        # 6. 현재 원소가 피벗보다 작으면 왼쪽 파티션에 추가
        if x < pivot:
            left.append(x)
        # 7. 아니면 오른쪽 파티션에 추가
        else:
            right.append(x)

    # 8. 왼쪽 파티션에 대해 재귀적으로 퀵소트 수행
    sorted_left = quick_sort(left)

    # 9. 오른쪽 파티션에 대해 재귀적으로 퀵소트 수행
    sorted_right = quick_sort(right)

    # 10. 정렬된 왼쪽 + 피벗 + 정렬된 오른쪽을 합쳐서 반환
    return sorted_left + [pivot] + sorted_right


# 11. 사용 예시
if __name__ == "__main__":
    # 12. 정렬할 원본 배열
    data = [33, 10, 55, 71, 29, 4, 18, 63]

    # 13. 퀵소트 함수 호출
    sorted_data = quick_sort(data)

    # 14. 결과 출력
    print("정렬 전:", data)
    print("정렬 후:", sorted_data)
```

**주요 포인트**

- `quick_sort` 함수는 재귀적으로 배열을 분할합니다.
- 피벗을 기준으로 `left`와 `right` 두 개의 파티션으로 나누어 각각을 다시 정렬합니다.
- 최종적으로 `sorted_left + [pivot] + sorted_right` 를 합쳐 정렬된 배열을 반환합니다.
