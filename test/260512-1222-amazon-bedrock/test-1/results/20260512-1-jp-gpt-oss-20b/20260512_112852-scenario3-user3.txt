아래는 **Python** 으로 작성한 퀵소트 구현입니다.  
코드의 각 줄마다 한글 주석을 달아, 수행되는 단계와 역할을 명확히 하였습니다.

```python
def quicksort(arr):                      # 1. 퀵소트 함수 정의 (arr: 정렬할 리스트)
    if len(arr) <= 1:                    # 2. 리스트 길이가 0 또는 1이면 이미 정렬 완료
        return arr                      # 3. 그대로 반환
    pivot = arr[len(arr) // 2]          # 4. 중앙값을 피벗으로 선택 (중앙값을 기준으로 하여 한 변수가 중심이 되는 경우가 적음)
    
    left = [x for x in arr if x < pivot]  # 5. 피벗 보다 작은 요소들을 모은 리스트
    middle = [x for x in arr if x == pivot]  # 6. 피벗과 같은 요소들을 모은 리스트
    right = [x for x in arr if x > pivot]  # 7. 피벗 보다 큰 요소들을 모은 리스트
    
    # 8. 재귀 호출: left와 right 부분을 다시 퀵소트로 정렬하고, 결과 합치기
    return quicksort(left) + middle + quicksort(right)
```

#### 사용 예시
```python
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", sample)                 # 9. 정렬 전 리스트 출력
    sorted_list = quicksort(sample)           # 10. 퀵소트 함수 호출
    print("정렬 후:", sorted_list)            # 11. 정렬 된 결과 출력
```

이 구현은 `O(n^2)` 최악의 경우를 피하기 위해 피벗을 중앙값으로 설정했으며, 평균적으로 `O(n log n)` 시간복잡도로 동작합니다. 리스트를 재할당하지 않고 참조만 이동시키는 것이 아니라 새 리스트(`left`, `middle`, `right`)를 만들어 합치는 방식이기 때문에 메모리 사용량이 추가적으로 줄어듭니다 (작은 입력에 적합).  
필요에 따라 인-플레이스(제자리) 퀵소트 버전으로 바꾸면 메모리 사용을 최소화할 수도 있습니다.
