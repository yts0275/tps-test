아래 예시는 **Python** 로 작성된 퀵소트(quick‑sort) 구현입니다.  
프로그램의 각 줄 뒤에 `#` 으로 주석을 달아, 왜 그 줄이 필요한지 한눈에 보이도록 해 두었습니다.  

```python
def quicksort(arr):                 # 1: 정렬할 배열을 인자로 받음
    if len(arr) <= 1:              # 2: 배열이 0개 또는 1개이면 이미 정렬 완료임
        return arr                # 3: 그대로 반환

    pivot = arr[len(arr) // 2]     # 4: 기준값(pivot)을 배열 중앙의 값으로 선정
    left = []                      # 5: 기준값보다 작은 요소들을 모을 리스트
    middle = []                    # 6: 기준값과 같은 요소들을 모을 리스트
    right = []                     # 7: 기준값보다 큰 요소들을 모을 리스트

    for x in arr:                  # 8: 배열의 모든 요소를 순회
        if x < pivot:              # 9: 기준값보다 작다면
            left.append(x)         #10: left 리스트에 추가
        elif x == pivot:           #11: 기준값과 같다면
            middle.append(x)       #12: middle 리스트에 추가
        else:                      #13: 기준값보다 크다면
            right.append(x)        #14: right 리스트에 추가

    # 15: 왼쪽 리스트는 재귀적으로 정렬하고, 뒤에 middle, right 를 덧붙임
    return quicksort(left) + middle + quicksort(right)

# --------- 사용 예시 (테스트용) ---------
if __name__ == "__main__":        # 16: 모듈이 직접 실행될 때만 아래 코드 실행
    unsorted = [34, 7, 23, 32, 5, 62]   # 17: 정렬할 배열 정의
    sorted_arr = quicksort(unsorted)    # 18: quicksort 함수 호출
    print(sorted_arr)                  # 19: 결과 출력: [5, 7, 23, 32, 34, 62]
```

### 코드 해설

| 라인 | 내용 | 주석 |
|------|------|------|
| 1 | `quickSore` 함수 선언 | 배열을 입력받아 반환한다는 선언 |
| 2~3 | 기저 조건 (배열 길이가 0 또는 1) | 재귀가 종료되는 조건 |
| 4 | 피벗 선택 | 중앙값을 기준값으로 사용 (랜덤 또는 마지막/첫 번째 요소도 가능) |
| 5~7 | 분리할 리스트 초기화 | 작은값, 같은값, 큰값 세 그룹 |
| 8~14 | 반복문으로 원소 분류 | 피벗과 비교해 적절히 분류 |
| 15 | 재귀 호출 및 병합 | 왼쪽(작은값)을 정렬, 중간(같은값)을 그대로, 오른쪽(큰값)을 정렬 후 이어 붙임 |
| 16~19 | 예시 실행 | 표준 입력이 아닌 경우 실행, 정렬 전/후를 보여줌 |

이 코드는 **시간 복잡도**가 평균 \(O(n \log n)\) 이지만, 최악의 경우(이미 정렬된 배열에서 피벗을 가장 끝값으로 고를 때) \(O(n^2)\) 가 될 수 있습니다.  
데이터가 무작위로 섞여 있다면 이 구현으로 충분히 빠른 성능을 기대할 수 있습니다.
