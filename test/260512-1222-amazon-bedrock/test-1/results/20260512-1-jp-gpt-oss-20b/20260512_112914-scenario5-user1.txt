```python
# Quick Sort 구현 (Python)

def quicksort(arr):                 # 1. 리스트를 인자로 받아 정렬된 리스트를 반환하는 함수 정의
    if len(arr) <= 1:               # 2. 리스트가 빈 리스트이거나 한 요소만 있는 경우 그대로 반환
        return arr                 # 3. 이미 정렬되어 있으므로 그 배열을 반환

    pivot = arr[len(arr) // 2]      # 4. 중간 요소를 피벗으로 선택 (pivot)

    left = [x for x in arr if x < pivot]   # 5. 피벗보다 작은 요소들로 이루어진 서브리스트 생성
    middle = [x for x in arr if x == pivot]# 6. 피벗과 같은 요소들로 이루어진 서브리스트 생성
    right = [x for x in arr if x > pivot]  # 7. 피벗보다 큰 요소들로 이루어진 서브리스트 생성

    # 8. 재귀 호출을 통해 왼쪽 서브리스트와 오른쪽 서브리스트를 정렬하고, 세 부분을 합쳐 반환
    return quicksort(left) + middle + quicksort(right)

# 예시 사용법
if __name__ == "__main__":          # 9. 스크립트가 직접 실행될 때만 아래 코드가 실행되게 보호
    sample = [3, 6, 8, 10, 1, 2, 1] # 10. 정렬하려는 예시 리스트 생성
    sorted_list = quicksort(sample) # 11. quicksort 함수를 호출하여 정렬된 리스트를 반환받음
    print(sorted_list)             # 12. 정렬 결과를 콘솔에 출력
```

> **설명**  
> - `quicksort` 함수는 재귀적으로 동작하며, 피벗을 기준으로 왼쪽, 중간, 오른쪽 세 리스트를 만들어 합칩니다.  
> - 각 줄마다 주석을 달아 동작을 명확히 설명했습니다.  
> - 리스트 내포와 재귀 호출을 활용해 간결하게 구현했습니다.
