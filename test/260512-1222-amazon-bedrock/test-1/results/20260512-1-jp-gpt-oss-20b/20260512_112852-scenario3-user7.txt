아래는 **파이썬**으로 구현한 퀵소트(Quick Sort) 예시입니다.  
코드의 각 줄마다 한 줄 주석이 달려 있으니, 렌더링 시마다 그 의미가 바로 눈에 들어옵니다.  

```python
# 퀵소트 구현
def quicksort(arr, low, high):
    # 배열이 더 이상 분할되지 않을 경우 종료
    if low < high:
        # 피벗의 인덱스를 반환
        pi = partition(arr, low, high)
        # 피벗보다 작은 부분 배열 정렬
        quicksort(arr, low, pi - 1)
        # 피벗보다 큰 부분 배열 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피벗을 선택 (최우측 원소)
    pivot = arr[high]
    # 작은 값이 저장될 인덱스
    i = low - 1
    # 배열을 순회
    for j in range(low, high):
        # 현재 원소가 피벗보다 작으면 i를 증가시키고 교환
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    # 피벗을 올바른 위치에 배치
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

# 예제 사용
if __name__ == "__main__":
    # 정렬할 리스트
    arr = [10, 7, 8, 9, 1, 5]
    n = len(arr)
    # 퀵소트 호출
    quicksort(arr, 0, n - 1)
    # 결과 출력
    print("정렬된 배열:", arr)
```

### 코드 줄별 설명
1. **①** 퀵소트 함수 정의를 시작합니다.  
2. **②** `arr`(배열), `low`(저작 시작 인덱스), `high`(저작 끝 인덱스)를 매개변수로 받습니다.  
3. **③** `low < high` 조건이 성립하면 재귀적으로 더 이상 분할이 가능한지를 판단합니다.  
4. **④** 분할 함수 `partition`을 호출해 피벗의 최종 인덱스 `pi`를 얻습니다.  
5-6. **⑤~⑥** 피벗보다 작은 부분과 큰 부분을 각각 재귀 호출로 정렬합니다.  
7. **⑦** `partition` 함수 정의를 시작합니다.  
8. **⑧** 배열의 가장 오른쪽 원소를 피벗으로 선택합니다.  
9. **⑨** 피벗보다 작은 원소가 저장될 인덱스를 초기화합니다 (`i = low - 1`).  
10. **⑩** `low`부터 `high-1`까지 순회합니다.  
11. **⑪~⑫** 현재 원소가 피벗보다 작으면 `i`를 증가시키고, 해당 원소와 `arr[i]`를 교환합니다.  
12. **⑫~⑬** 최종적으로 피벗을 `i+1` 위치로 옮겨 줍니다.  
13. **⑭** `i+1`을 반환해 피벗 위치를 알려 줍니다.  
14-20. **⑮~⑰** 예제 실행 블록(`if __name__ == "__main__":`)에서 배열을 정의하고, 퀵소트를 호출하며 결과를 출력합니다.  

이 코드를 그대로 실행하면 `[1, 5, 7, 8, 9, 10]` 이 출력되는 것을 확인할 수 있습니다.
