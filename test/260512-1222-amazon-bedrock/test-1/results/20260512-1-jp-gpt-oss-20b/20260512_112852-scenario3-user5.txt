아래는 파이썬으로 구현한 퀵소트 예시이며, **각 줄 끝에 주석을 달아 코드가 수행하는 내용을 한눈에 알 수 있도록 했습니다**.

```python
# 파이썬으로 퀵소트를 구현한 예시입니다.  
def quicksort(arr):  # 정렬할 리스트를 인자로 받는다.  
    if len(arr) <= 1:  # 리스트가 비었거나 하나의 요소만 있을 때 정렬이 필요 없다.  
        return arr  # 그대로 반환한다.  
    pivot = arr[len(arr) // 2]  # 중간 인덱스의 값을 피벗으로 선택한다.  
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 값들을 새로운 리스트에 담는다.  
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 값들을 새로운 리스트에 담는다.  
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 값들을 새로운 리스트에 담는다.  
    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 정렬한 결과를 합쳐 반환한다.  

if __name__ == "__main__":  # 직접 실행될 때만 아래 코드를 실행한다.  
    data = [3, 6, 8, 10, 1, 2, 1]  # 예시 데이터.  
    sorted_data = quicksort(data)  # 퀵소트 실행.  
    print("정렬 전: ", data)  # 원본 데이터 출력.  
    print("정렬 후: ", sorted_data)  # 정렬된 데이터 출력.
```

- **`quicksort`** 함수는 피벗을 선택하고, 피벗보다 작은/같은/큰 값들을 각각의 리스트로 분리한 뒤, 재귀 호출을 통해 정렬한 결과를 결합합니다.  
- **`if __name__ == "__main__"`** 블록은 스크립트가 직접 실행될 때만 테스트 데이터를 정렬하고 결과를 출력하도록 설정합니다.  

위 코드를 그대로 복사해 실행하면 다음과 같은 출력이 나옵니다:

```
정렬 전:  [3, 6, 8, 10, 1, 2, 1]
정렬 후:  [1, 1, 2, 3, 6, 8, 10]
```

필요에 따라 삽입 정렬 등의 변형을 적용해도 동일하게 주석을 각각 줄에 달아 주면 됩니다!
