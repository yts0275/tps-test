아래는 **Python**으로 구현한 퀵소트(Quick Sort) 예제이며, **모든 줄에 한국어 주석**을 달아 이해를 돕겠습니다.  
주석은 각 줄의 기능을 한눈에 파악할 수 있도록 최대한 명확하게 작성했습니다.

```python
# 퀵소트(Quick Sort) 함수 정의
def quicksort(arr):
    # 1. 기저사례: 배열에 원소가 0개 또는 1개만 있으면 정렬이 필요 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr                           # 정렬된 배열 반환

    # 2. 피벗(pivot) 선택: 여기서는 가장 오른쪽 원소를 피벗으로 선택
    pivot = arr[-1]                          # 피벗 값 저장

    # 3. 피벗보다 작거나 같은 요소들을 'less' 리스트에 모음
    less = [x for x in arr[:-1] if x <= pivot]  # 피벗 이하 리스트 생성

    # 4. 피벗보다 큰 요소들을 'greater' 리스트에 모음
    greater = [x for x in arr[:-1] if x > pivot]  # 피벗 초과 리스트 생성

    # 5. 재귀적으로 less와 greater를 정렬하고, 피벗을 중간에 삽입
    return quicksort(less) + [pivot] + quicksort(greater) # 최종 정렬된 배열 반환

# ================================
# 아래는 예시 실행 코드 (옵션입니다)
if __name__ == "__main__":
    unsorted = [10, 7, 8, 9, 1, 5]            # 정렬 전 배열
    print("정렬 전:", unsorted)                # 정렬 전 상태 출력
    sorted_arr = quicksort(unsorted)           # 퀵소트 함수 호출
    print("정렬 후:", sorted_arr)              # 정렬 결과 출력
```

### 코드 해설
| 줄 번호 | 코드 | 주석 |
|--------|------|------|
| 1 | `def quicksort(arr):` | 퀵소트 함수 정의 |
| 2 | `if len(arr) <= 1:` | 기저사례 검사 |
| 3 | `return arr` | 정렬 필요 없음: 그대로 반환 |
| 5 | `pivot = arr[-1]` | 피벗 선택 (마지막 원소) |
| 7 | `less = [x for x in arr[:-1] if x <= pivot]` | 피벗 이하 리스트 생성 |
| 9 | `greater = [x for x in arr[:-1] if x > pivot]` | 피벗 초과 리스트 생성 |
| 11 | `return quicksort(less) + [pivot] + quicksort(greater)` | 재귀 정렬 및 피벗 삽입 |
| 15 | `if __name__ == "__main__":` | 모듈 실행 시 테스트 코드 실행 |
| 16 | `unsorted = [10, 7, 8, 9, 1, 5]` | 테스트용 배열 초기화 |
| 17 | `print("정렬 전:", unsorted)` | 정렬 전 배열 출력 |
| 18 | `sorted_arr = quicksort(unsorted)` | 퀵소트 함수 호출 |
| 19 | `print("정렬 후:", sorted_arr)` | 정렬 후 배열 출력 |

**시간복잡도**  
- 평균: **O(n log n)**  
- 최악: **O(n²)** (같은 값이 반복되며 피벗이 항상 가장 큰/작은 값일 경우)

**공간복잡도**  
- 재귀 호출 stack 깊이: **O(log n)** (평균), 최악 시 **O(n)**  
- 추가 저장 공간: **O(n)** (피벗 뺀 나머지 원소를 새 리스트에 담으므로)

필요에 따라 피벗 선택 방식을 다르게 하거나, **in‑place** 버전을 구현하면 공간복잡도를 개선할 수 있어요. 📦
