아래는 파이썬으로 구현한 **퀵소트**(QuickSort) 알고리즘입니다.  
모든 코드 라인마다 한 줄씩 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr):  # 퀵소트 알고리즘 시작, 리스트를 정렬하고 새로운 리스트를 반환하는 함수
    if len(arr) <= 1:  # 리스트가 0개 또는 1개일 때는 이미 정렬이 끝난 상태이므로 그대로 반환
        return arr  # 입력값 그대로 반환
    pivot = arr[-1]  # 리스트의 마지막 요소를 피벗으로 선택
    less = [x for x in arr[:-1] if x <= pivot]  # 피벗보다 작거나 같은 값들을 모은 리스트
    greater = [x for x in arr[:-1] if x > pivot]  # 피벗보다 큰 값들을 모은 리스트
    return quicksort(less) + [pivot] + quicksort(greater)  # 왼쪽(작은 값) 정렬 + 피벗 + 오른쪽(큰 값) 정렬을 이어붙여 반환

# 예시 사용:
if __name__ == "__main__":  # 스크립트가 직접 실행될 때만 아래 코드가 실행
    sample = [3, 6, 8, 10, 1, 2, 1]  # 정렬하려는 예시 리스트
    print(quicksort(sample))  # 정렬된 결과를 출력
```

이 코드에서는 재귀 호출을 통해 `less` 와 `greater` 두 부분을 다시 정렬하고,  
피벗을 포함한 최종 정렬 결과를 하나의 리스트로 합쳐 반환합니다.  
각 라인 뒤에 부여한 주석이 그 줄이 수행하는 구체적인 역할을 설명합니다.
