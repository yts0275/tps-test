아래는 파이썬으로 구현한 퀵소트(QuickSort) 예시입니다.  
각 코드 줄마다 한 줄에 한 개씩 주석을 달아 이해를 돕고 있습니다.

```python
def quicksort(arr):  # 배열을 정렬하는 재귀 함수 정의
    if len(arr) <= 1:  # 배열이 비었거나 원소가 하나이면 그대로 반환(베이스 케이스)
        return arr
    pivot = arr[-1]  # 마지막 원소를 피벗(pivot)으로 선택
    less = [x for x in arr[:-1] if x <= pivot]  # 피벗보다 작거나 같은 원소들을 모음
    greater = [x for x in arr[:-1] if x > pivot]  # 피벗보다 큰 원소들을 모음
    return quicksort(less) + [pivot] + quicksort(greater)  # 재귀 호출로 정렬 후 합침

if __name__ == "__main__":  # 스크립트가 직접 실행될 때만 아래 코드 실행
    data = [8, 3, 1, 7, 0, 10, 2]  # 정렬할 예시 데이터
    sorted_data = quicksort(data)  # 퀵소트 호출
    print(sorted_data)  # 정렬 결과 출력
```

위 코드는 재귀 호출 방식을 사용해 배열을 분할(피벗 기준)하고 정렬합니다.  
`less`와 `greater` 리스트를 만들어 각각 정렬한 뒤 피벗을 중간에 삽입해 최종적으로 정렬된 배열을 반환합니다.  
필요하면 입력 배열을 그대로 바꾸는 **in-place** 형태로도 구현할 수 있습니다.
