아래는 파이썬으로 구현한 **퀵소트(Quick Sort)**입니다.  
함수의 각 줄에 한국어 주석을 달아 이해하기 쉽게 작성했습니다.

```python
def quicksort(arr, low, high):
    # 만약 low가 0보다 크거나 고유한 구간이 하나 이하일 때(종료 조건)
    if low < high:
        # partition 함수가 pivot(피벗) 위치를 반환
        pivot_index = partition(arr, low, high)
        # pivot 앞의 구간을 재귀적으로 정렬
        quicksort(arr, low, pivot_index - 1)
        # pivot 뒤의 구간을 재귀적으로 정렬
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    # 가장 오른쪽 요소를 pivot(피벗)으로 선택
    pivot = arr[high]
    # pivot보다 작은 모든 요소의 상단 인덱스
    i = low - 1
    # low부터 high-1까지 순회
    for j in range(low, high):
        # 현재 요소가 pivot보다 작으면
        if arr[j] < pivot:
            # i를 1 올려서 새로운 스왑 위치를 지정
            i += 1
            # arr[i]와 arr[j] 를 교환
            arr[i], arr[j] = arr[j], arr[i]
    # i+1 위치에 pivot을 넣어 최종 위치 결정
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    # pivot의 최종 인덱스를 반환
    return i + 1

# --------------------- 예시 사용 ---------------------

# 정렬하고 싶은 리스트
numbers = [34, 7, 23, 32, 5, 62]

# quicksort 호출 (인덱스 범위는 0 부터 len-1 까지)
quicksort(numbers, 0, len(numbers) - 1)

# 정렬된 결과 출력
print(numbers)  # 출력: [5, 7, 23, 32, 34, 62]
```

### 주요 포인트
- `quicksort`는 재귀적으로 동작하며, 각 구간을 다시 작은 두 구간으로 나눕니다.
- `partition`은 선택한 `pivot`을 기준으로 왼쪽에는 작은 값, 오른쪽에는 큰 값을 배치합니다.
- 알고리즘의 평균 시간복잡도는 **O(n log n)**이지만 최악의 경우(이미 정렬된 배열 등) **O(n²)**가 됩니다.  
  이때는 `pivot`을 무작위로 선택하거나 가장 큰/작은 값 규칙을 끊임없이 변경하는 방법으로 성능을 개선할 수 있습니다.
