아래는 **Python**으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
코드의 각 줄마다 한 줄 주석을 달아 설명해 두었으니, 이해를 돕는데 참고하세요.  

```python
def quicksort(arr):   # 1. 정렬할 배열을 인자로 받는 함수 정의
    """
    퀵소트(QuickSort) 알고리즘을 재귀적으로 구현한 함수.
    입력 리스트가 비어 있거나 한 개 이하이면 그대로 반환하여
    재귀 종료 조건을 만족한다.
    """
    if len(arr) <= 1:  # 2. 기본 케이스: 정렬 대상이 0 또는 1개라면 이미 정렬되어 있다.
        return arr         # 3. 정렬된 결과(당연히 정렬되어 있는 것)를 반환

    # 4. 피벗(pivot) 선택: 일반적으로 가장 끝 원소를 사용
    pivot = arr[-1]        # 5. 피벗을 배열의 마지막 요소로 설정

    # 6. 피벗보다 작은 값과 큰 값을 구분하기 위해 빈 리스트 두 개를 준비
    left = []            # 7. 피벗보다 작은 값을 보관할 리스트
    right = []           # 8. 피벗보다 큰 값을 보관할 리스트

    # 9. 배열(마지막 피벗 제외)을 순회하며 피벗과 비교
    for x in arr[:-1]:   # 10. 피벗을 제외한 모든 원소를 하나씩 확인
        if x <= pivot:   # 11. 현재 원소가 피벗보다 작거나 같다면 left에 추가
            left.append(x)   # 12. 작은 값 리스트에 저장
        else:            # 13. 아니라면 right에 추가(피벗보다 큰 경우)
            right.append(x)  # 14. 큰 값 리스트에 저장

    # 15. 재귀적으로 왼쪽 부분, 피벗, 오른쪽 부분을 정렬 후 결합
    #    (왼쪽 + 피벗 + 오른쪽) 순서로 결합
    return quicksort(left) + [pivot] + quicksort(right)  # 16. 최종 정렬된 결과 반환
```

### 코드 실행 예시
```python
if __name__ == "__main__":
    unsorted = [34, 7, 23, 32, 5, 62]
    print("원본:", unsorted)
    sorted_arr = quicksort(unsorted)
    print("정렬 결과:", sorted_arr)
```

#### 출력
```
원본: [34, 7, 23, 32, 5, 62]
정렬 결과: [5, 7, 23, 32, 34, 62]
```

### 시간·공간 복잡도
- 평균 시간 복잡도: **O(n log n)**
- 최악의 경우(이미 정렬된 배열 등): **O(n²)**  
  (피벗 선택을 개선하면 최악 경우를 피할 수 있음)
- 공간 복잡도: 재귀 호출 스택과 각 단계에서 생성되는 `left`, `right` 리스트 때문에 부수적인 공간이 필요합니다.  
  최악 시에는 **O(n log n)** 이지만, 평균적으로는 **O(log n)**(재귀 깊이) + 생성되는 일시적 리스트 공간을 포함해 실질적으로는 **O(n)** 가 됩니다.

필요에 따라 피벗을 무작위로 선택하거나, 중간값(median)을 선택하면 최악의 경우를 방지할 수 있으니 참고하시기 바랍니다.
