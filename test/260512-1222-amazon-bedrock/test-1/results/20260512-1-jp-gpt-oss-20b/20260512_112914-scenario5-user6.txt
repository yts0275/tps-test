아래는 파이썬으로 작성한 퀵소트(QuickSort) 구현 예시입니다.  
코드의 **각 줄**마다 한국어 주석을 달아 이해가 쉽도록 했습니다.

```python
def quicksort(arr: list) -> list:                 # arr이라는 리스트를 입력 받아 정렬된 리스트를 반환하는 함수 정의
    if len(arr) <= 1:                            # 리스트가 빈 리스트이거나 한 개일 경우 이미 정렬된 상태
        return arr                              # 그대로 반환

    pivot = arr[len(arr) // 2]                   # 가운데(중간) 원소를 피벗으로 선정
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 값들만 모음
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 값들(중복값 포함)
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 값들만 모음

    # 왼쪽과 오른쪽 부분을 재귀적으로 퀵소트 수행 후,
    # 결과를 결합해 완성된 정렬된 리스트 반환
    return quicksort(left) + middle + quicksort(right)

# --------------------- 예시 사용 ---------------------

if __name__ == "__main__":                       # 스크립트가 직접 실행될 때만 아래 코드 실행
    sample_list = [3, 6, 8, 10, 1, 2, 1]          # 정렬할 예시 리스트
    print("정렬 전:", sample_list)                # 정렬 전 상태 출력
    sorted_list = quicksort(sample_list)           # quicksort 함수 호출
    print("정렬 후:", sorted_list)                # 정렬 후 결과 출력
```

> **주요 포인트 요약**
> - `pivot`은 리스트 중간값을 사용해 간단히 구현
> - 리스트 컴프리헨션으로 `left`, `middle`, `right`를 한 줄에 분류
> - 재귀 호출로 서브 리스트를 정렬하고, 최종적으로 합성(`+`)해서 반환
> - 입력 리스트가 비어 있거나 하나인 경우 바로 반환해 재귀 깊이를 줄임
> - `__name__ == "__main__"` 블록은 모듈로 가져올 때는 실행되지 않도록 함
> 
> 이 구현은 이해도를 높이기 위해 가독성을 우선시했으며, 대용량 데이터에서는 재귀 깊이 제한과 메모리 사용량을 감안해 별도 최적화가 필요할 수 있습니다.
