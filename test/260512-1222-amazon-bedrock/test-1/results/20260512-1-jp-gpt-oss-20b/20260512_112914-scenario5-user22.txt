아래는 파이썬으로 작성한 퀵소트(Quick Sort) 구현 예시입니다.  
각 줄마다 `#` 뒤에 주석을 달아 이해를 돕도록 하였습니다.

```python
# 퀵소트 알고리즘 구현
def quick_sort(arr):
    # 1. 배열의 길이가 0 또는 1이면 이미 정렬이 완료된 상태이므로 그대로 반환
    if len(arr) <= 1:
        # 2. 길이가 1 이하인 배열은 자체가 정렬된 상태이므로 재귀 호출 종료
        return arr

    # 3. 피벗(pivot) 선택 – 여기서는 배열 중간 값을 피벗으로 사용
    pivot = arr[len(arr) // 2]

    # 4. 피벗보다 작은 값들로만 이루어진 subarray 생성
    less = [x for x in arr if x < pivot]
    # 5. 피벗과 같은 값들로만 이루어진 subarray 생성
    equal = [x for x in arr if x == pivot]
    # 6. 피벗보다 큰 값들로만 이루어진 subarray 생성
    greater = [x for x in arr if x > pivot]

    # 7. 재귀적으로 left(less)와 right(greater)를 각각 정렬
    # 8. 정렬된 left, pivot(=equal), 그리고 정렬된 right를 이어붙여 최종 정렬 결과 반환
    return quick_sort(less) + equal + quick_sort(greater)

# --------------------------------------------------------------
# 아래 부분은 예시 실행 코드이며, 실제 사용 환경에서는 이 블록을 따로 빼어도 됩니다.
if __name__ == "__main__":
    # 9. 정렬할 예시 리스트
    example_list = [3, 6, 8, 10, 1, 2, 1]
    # 10. 원본 리스트를 출력
    print("원본 리스트:", example_list)
    # 11. 퀵소트 실행 및 결과 출력
    sorted_list = quick_sort(example_list)
    print("정렬된 리스트:", sorted_list)
```

### 주요 포인트
- **피벗 선택**  
  - 코드는 배열 중간값을 피벗으로 사용합니다.  
  - 다른 방법(랜덤, 첫번째/마지막 요소 등)으로 바꾸면 평균 성능을 높일 수 있습니다.
- **재귀 종료 조건**  
  - 요소가 0개 또는 1개인 경우 더 이상 재귀를 호출하지 않고 바로 반환합니다.
- **부정적 메모리 사용**  
  - `less`, `equal`, `greater`를 새 리스트로 만들기 때문에 메모리 사용량이 증가합니다.  
  - 인플레이스(in-place) 버전이 필요하면 항목을 바로 배열에 배치하는 방식을 사용하면 됩니다.

위 예시는 이해를 돕기 위한 단순 구현이며, 실제 성능이 필요한 경우 임계값을 두고 병합소트나 인플레이스 분할 방식을 사용하세요.
