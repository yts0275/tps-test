아래는 파이썬으로 구현한 **퀵소트(QuickSort)** 알고리즘입니다.  
코드의 **각 줄**마다 그 줄이 하는 일을 한글 주석으로 설명했습니다.

```python
# 정수형 리스트를 오름차순으로 정렬하는 재귀 함수
def quicksort(arr):
    # 배열이 비었거나 하나의 요소만 있으면 이미 정렬이 완료된 것이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)으로 배열의 가운데 값을 선택
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 값들로만 이루어진 sub‑array (왼쪽)
    left = [x for x in arr if x < pivot]

    # 피벗과 같은 값들만 모은 sub‑array (가운데)
    mid = [x for x in arr if x == pivot]

    # 피벗보다 큰 값들로만 이루어진 sub‑array (오른쪽)
    right = [x for x in arr if x > pivot]

    # 왼쪽 배열, 가운데 배열, 오른쪽 배열을 재귀적으로 정렬한 뒤 합쳐서 반환
    return quicksort(left) + mid + quicksort(right)

# -----------------------------
# 아래는 코드 실행 예시입니다.
# -----------------------------
if __name__ == "__main__":
    # 정렬하기 전의 배열
    nums = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전:", nums)

    # quicksort 함수를 호출해 정렬된 결과를 출력
    print("정렬 후:", quicksort(nums))
```

**설명**  
- `quicksort` 함수는 입력 리스트 `arr`를 받아 재귀적으로 분할·정복을 수행합니다.  
- 피벗(pivot)을 가운데 값으로 고르며, 배열을 `left`, `mid`, `right` 세 부분으로 나눕니다.  
- `left`에는 피벗보다 작은 수, `mid`에는 피벗과 같은 수, `right`에는 피벗보다 큰 수를 저장합니다.  
- 각각을 재귀적으로 정렬한 뒤 `left + mid + right` 순서로 합쳐서 정렬된 배열을 반환합니다.  
- `if __name__ == "__main__":` 블록은 모듈이 직접 실행될 때 테스트용 입출력 코드를 수행합니다.
