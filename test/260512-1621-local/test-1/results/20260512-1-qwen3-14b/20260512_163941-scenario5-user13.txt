다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 예제입니다. 각 줄마다 주석을 달아 설명을 제공했습니다:

```python
def quicksort(arr, start, end):
    # 베이스 케이스: 배열의 시작이 끝보다 작거나 같으면 종료
    if start >= end:
        return

    # 피벗 선택: 배열의 마지막 요소를 피벗으로 선택
    pivot = arr[end]
    # i는 "피벗보다 작은 요소"의 위치를 가리키는 인덱스
    i = start

    # 배열을 순회하며 피벗보다 작은 요소를 왼쪽으로 이동
    for j in range(start, end):
        if arr[j] < pivot:
            # arr[j]가 피벗보다 작으면 arr[i]와 교환
            arr[i], arr[j] = arr[j], arr[i]
            # i를 증가시켜 다음 "작은 요소"의 위치로 이동
            i += 1

    # 피벗을 정확한 위치로 이동: arr[i]와 arr[end] 교환
    arr[i], arr[end] = arr[end], arr[i]

    # 왼쪽, 오른쪽 배열에 대해 재귀적으로 퀵소트 수행
    quicksort(arr, start, i - 1)  # 왼쪽 배열
    quicksort(arr, i + 1, end)    # 오른쪽 배열

# 예제 배열 초기화
arr = [3, 6, 8, 10, 1, 2, 1]
# 퀵소트 실행 (시작 인덱스: 0, 끝 인덱스: len(arr) - 1)
quicksort(arr, 0, len(arr) - 1)

# 정렬된 배열 출력
print("정렬된 배열:", arr)
```

### 주석 설명 요약:
1. **베이스 케이스**: 배열이 하나의 요소 이하일 경우 종료.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택.
3. **i 인덱스**: 피벗보다 작은 요소의 위치를 추적.
4. **배열 순회**: 각 요소를 피벗과 비교하여 작은 경우 왼쪽으로 이동.
5. **피벗 이동**: 피벗을 정확한 위치로 이동.
6. **재귀 호출**: 왼쪽, 오른쪽 배열에 대해 퀵소트 반복.

이 코드는 [3, 6, 8, 10, 1, 2, 1] 배열을 입력으로 받아 [1, 1, 2, 3, 6, 8, 10]과 같이 정렬합니다.
