다음은 퀵소트(Quick Sort) 알고리즘을 Python에서 구현한 예제입니다. 각 줄마다 주석을 달아 이해를 돕습니다:

```python
def quicksort(arr):
    # 배열이 0개 또는 1개 원소일 경우, 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피봇(pivot)을 선택합니다. 여기서는 배열의 중간 원소를 피봇으로 사용
    pivot = arr[len(arr) // 2]
    
    # 피봇보다 작은 원소들을 담을 리스트
    left = [x for x in arr if x < pivot]
    
    # 피봇보다 큰 원소들을 담을 리스트
    right = [x for x in arr if x > pivot]
    
    # 피봇을 제외한 나머지 원소들(피봇과 같은 값은 제외)을 재귀적으로 정렬
    # left와 right 리스트에 대해 quicksort를 재귀적으로 호출
    # 그리고 정렬된 left, pivot, right을 결합하여 반환
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 경우, 배열을 그대로 반환합니다. (이미 정렬됨)
2. **피봇 선택**: 배열의 중간 원소를 피봇으로 선택합니다.
3. **분할**: 피봇보다 작은 원소들을 `left` 리스트, 큰 원소들을 `right` 리스트로 분류합니다.
4. **재귀적 정렬**: `left`와 `right` 리스트에 대해 다시 `quicksort`를 호출합니다.
5. **결합**: 정렬된 `left`, `pivot`, `right`을 결합하여 최종 결과를 반환합니다.

이 구현은 **비인플레이스**(in-place)가 아닌 방식으로, 새로운 리스트를 생성하여 정렬을 수행합니다. 이는 이해하기 쉬운 구현 방식이지만, 메모리 사용량이 더 많을 수 있습니다.
