다음은 퀵소트(Quick Sort) 알고리즘의 파이썬 구현입니다. 각 줄에 주석을 추가하여 설명을 제공했습니다.

```python
def quicksort(arr, start, end):
    # 기저 조건: 시작 인덱스가 끝 인덱스보다 크거나 같으면 종료
    if start >= end:
        return

    # 피벗을 선택 (현재 배열의 마지막 요소)
    pivot = arr[end]

    # i는 '피벗보다 작은 요소의 위치'를 추적하는 인덱스
    i = start - 1

    # 배열을 순회하며 피벗보다 작은 요소를 왼쪽으로 이동
    for j in range(start, end):
        if arr[j] <= pivot:
            # i를 증가시키고, arr[i]와 arr[j]를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 올바른 위치로 이동 (i+1)
    arr[i + 1], arr[end] = arr[end], arr[i + 1]

    # 왼쪽 부분 배열 재귀 호출 (start ~ i)
    quicksort(arr, start, i)

    # 오른쪽 부분 배열 재귀 호출 (i+2 ~ end)
    quicksort(arr, i + 2, end)
```

### 예시 사용법:
```python
arr = [3, 6, 8, 10, 1, 2, 1]
quicksort(arr, 0, len(arr) - 1)
print(arr)  # [1, 1, 2, 3, 6, 8, 10]
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1인 경우 종료.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택.
3. **분할 과정**: `i`는 피벗보다 작은 요소의 위치를 추적. 배열을 순회하면서 `arr[j] <= pivot`인 요소를 `i` 위치로 이동.
4. **피벗 이동**: `arr[i + 1]`에 피벗을 정렬.
5. **재귀 호출**: 왼쪽(`start ~ i`)과 오른쪽(`i + 2 ~ end`) 부분 배열에 대해 다시 퀵소트 호출.

이 알고리즘은 평균 시간 복잡도 O(n log n)을 가지며, 공간 복잡도는 O(log n)입니다.
