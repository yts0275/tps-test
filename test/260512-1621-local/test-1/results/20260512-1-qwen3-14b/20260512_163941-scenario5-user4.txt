다음은 퀵소트 알고리즘의 파이썬 구현입니다. 각 줄마다 주석이 추가되어 있습니다.

```python
def quicksort(arr, start, end):
    # 기저 조건: 배열의 시작 인덱스가 끝 인덱스보다 작을 때만 실행
    if start < end:
        # 파티션 함수를 호출하여 피벗의 위치를 찾고, 
        # 이 위치를 기준으로 왼쪽과 오른쪽 배열로 분할
        pivot_index = partition(arr, start, end)
        
        # 피벗 기준으로 왼쪽 배열 재귀적으로 퀵소트 실행
        quicksort(arr, start, pivot_index - 1)
        
        # 피벗 기준으로 오른쪽 배열 재귀적으로 퀵소트 실행
        quicksort(arr, pivot_index + 1, end)

def partition(arr, start, end):
    # 피벗은 배열의 마지막 요소로 선택
    pivot = arr[end]
    
    # i는 배열의 왼쪽 영역(피벗보다 작은 요소)의 끝 인덱스
    i = start - 1
    
    # 배열을 순회하며 피벗보다 작은 요소를 왼쪽 영역으로 이동
    for j in range(start, end):
        if arr[j] < pivot:
            # i를 하나 증가시키고, 현재 요소와 i 위치의 요소를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 정확한 위치로 이동 (i+1)
    arr[i + 1], arr[end] = arr[end], arr[i + 1]
    
    # 피벗의 최종 위치를 반환
    return i + 1

# 예시 실행
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)
print("정렬 전 배열:", arr)
quicksort(arr, 0, n - 1)
print("정렬 후 배열:", arr)
```

### 주석 설명 요약:
1. **quicksort 함수**: 
   - 배열을 재귀적으로 분할 정복하는 메인 함수
   - `start`와 `end` 인덱스를 통해 배열 범위를 지정
   - `partition` 함수를 통해 피벗 위치를 결정하고 재귀 호출

2. **partition 함수**: 
   - 배열을 피벗 기준으로 분할
   - `pivot`은 배열의 마지막 요소
   - `i`는 피벗보다 작은 요소의 마지막 위치
   - `j`는 배열을 순회하며 요소를 비교하고 교환

3. **예시 실행**:
   - `arr` 배열을 정렬 전/후로 출력하여 결과 확인

이 구현은 O(n log n)의 평균 시간 복잡도를 가지며, 최악의 경우 O(n²)이지만, 일반적으로 빠른 성능을 보입니다.
