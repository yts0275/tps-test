다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 예시입니다. 각 줄에 주석을 달아 설명을 제공합니다.

```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1인 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot) 선택: 배열의 중앙 요소를 선택
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들을 저장할 배열
    left = []
    # 피벗보다 큰 요소들을 저장할 배열
    right = []
    
    # 피벗과 같은 요소들을 제외한 나머지를 분할
    for num in arr:
        if num < pivot:
            left.append(num)
        elif num > pivot:
            right.append(num)
    
    # 재귀적으로 왼쪽, 오른쪽 배열을 정렬하고, 피벗을 중간에 삽입
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명
1. **기저 조건**: 배열의 길이가 0 또는 1일 때, 이미 정렬된 상태이므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 중앙 요소를 피벗으로 선택합니다. (이 예시에서는 중앙 요소를 사용하지만, 다른 선택도 가능)
3. **분할**: 배열을 두 부분으로 나누어, 피벗보다 작은 요소들을 `left` 배열, 큰 요소들을 `right` 배열에 저장합니다.
4. **재귀**: `left`와 `right` 배열을 다시 퀵소트를 적용하고, 피벗을 중간에 삽입하여 최종 정렬된 배열을 반환합니다.
