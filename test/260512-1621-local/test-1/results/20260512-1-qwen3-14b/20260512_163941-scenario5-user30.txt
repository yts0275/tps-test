```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1일 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗 선택: 배열의 중앙 요소를 피벗으로 선택
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소들로 구성된 왼쪽 배열
    left = [x for x in arr if x < pivot]
    
    # 피벗과 같은 요소들로 구성된 중간 배열 (필요 시)
    equal = [x for x in arr if x == pivot]
    
    # 피벗보다 큰 요소들로 구성된 오른쪽 배열
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽 배열과 오른쪽 배열을 정렬하고, 피벗과 함께 결합
    return quicksort(left) + equal + quicksort(right)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 경우, 이미 정렬된 상태이므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 중앙 요소를 피벗으로 선택합니다. 이는 정렬 성능에 영향을 줄 수 있으나, 간단한 구현을 위해 중앙 요소를 선택했습니다.
3. **배열 분할**:
   - `left`: 피벗보다 작은 요소들로 구성된 배열.
   - `equal`: 피벗과 동일한 요소들로 구성된 배열 (필요 시).
   - `right`: 피벗보다 큰 요소들로 구성된 배열.
4. **재귀적 정렬**: 왼쪽과 오른쪽 배열을 재귀적으로 정렬하고, 피벗과 함께 결합하여 최종 정렬된 배열을 반환합니다.

이 코드는 중복된 요소를 포함한 배열에도 올바르게 작동합니다. 예를 들어 `[3, 3, 3]`과 같은 배열도 `[3, 3, 3]`로 반환됩니다.
