다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 예제입니다. 각 줄에 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr, low, high):
    # low: 정렬할 배열의 시작 인덱스
    # high: 정렬할 배열의 끝 인덱스

    # 기저 조건: 배열이 1개 요소 이하일 경우 종료
    if low < high:
        # 파티션 함수를 호출하여 피벗의 위치를 결정하고
        # 파티션을 기준으로 왼쪽과 오른쪽 배열로 분할
        pi = partition(arr, low, high)

        # 피벗을 기준으로 왼쪽 배열을 재귀적으로 정렬
        quicksort(arr, low, pi - 1)

        # 피벗을 기준으로 오른쪽 배열을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피벗으로 사용할 요소를 선택 (여기서는 마지막 요소)
    pivot = arr[high]

    # 피벗보다 작은 요소를 추적할 포인터
    i = low - 1

    # 배열을 순회하며 피벗보다 작은 요소를 찾음
    for j in range(low, high):
        if arr[j] <= pivot:
            # 작은 요소를 i의 위치로 이동
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피벗을 정확한 위치로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 피벗의 최종 인덱스 반환
    return i + 1

# 예시 배열 정렬
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)
quicksort(arr, 0, n - 1)

print("정렬된 배열:")
for i in range(n):
    print("%d" % arr[i], end=" ")
```

### 설명
1. **quicksort 함수**:
   - `low`와 `high`는 정렬할 배열의 범위를 나타냅니다.
   - `partition` 함수를 호출하여 배열을 분할하고, 분할된 두 부분을 재귀적으로 정렬합니다.

2. **partition 함수**:
   - 배열의 마지막 요소를 피벗으로 선택합니다.
   - `i`는 피벗보다 작은 요소의 위치를 추적하는 포인터입니다.
   - 배열을 순회하면서 피벗보다 작은 요소를 `i`의 위치로 이동시킵니다.
   - 마지막으로 피벗을 정확한 위치로 이동하고, 그 위치를 반환합니다.

3. **예시**:
   - `arr = [10, 7, 8, 9, 1, 5]` 배열을 퀵소트로 정렬한 결과는 `[1, 5, 7, 8, 9, 10]`입니다.
