```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1일 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)을 선택합니다. 여기서는 배열의 첫 번째 요소를 피벗으로 사용
    pivot = arr[0]
    
    # 피벗보다 작은 요소들을 담을 리스트
    left = [x for x in arr[1:] if x < pivot]
    
    # 피벗보다 크거나 같은 요소들을 담을 리스트
    right = [x for x in arr[1:] if x >= pivot]
    
    # 재귀적으로 좌측과 우측 배열을 정렬하고, 피벗을 중간에 배치하여 합성
    return quicksort(left) + [pivot] + quicksort(right)

# 예시 사용법
example_array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quicksort(example_array)
print("정렬된 배열:", sorted_array)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 경우, 이미 정렬되어 있으므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 첫 번째 요소를 피벗으로 선택합니다. 다른 선택 방식(예: 중앙값, 랜덤)도 가능합니다.
3. **분할**: 피벗보다 작은 요소들을 `left` 배열에, 크거나 같은 요소들을 `right` 배열에 분할합니다.
4. **재귀적 정렬**: `left`와 `right` 배열을 각각 `quicksort` 함수로 재귀적으로 정렬하고, 피벗을 중간에 배치하여 최종 배열을 구성합니다.
