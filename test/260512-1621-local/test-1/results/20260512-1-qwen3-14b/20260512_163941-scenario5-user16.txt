```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1이면 이미 정렬되어 있으므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗 선택 (이 예제에서는 배열의 마지막 요소를 사용)
    pivot = arr[-1]
    
    # 피벗보다 작은 요소들을 포함하는 왼쪽 배열 생성
    left = [x for x in arr[:-1] if x < pivot]
    
    # 피벗보다 큰 요소들을 포함하는 오른쪽 배열 생성
    right = [x for x in arr[:-1] if x > pivot]
    
    # 왼쪽 배열과 오른쪽 배열을 재귀적으로 정렬한 후, 피벗을 중앙에 배치
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 때, 이미 정렬되어 있으므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택합니다.
3. **왼쪽 배열 생성**: 피벗보다 작은 요소들을 포함하는 배열을 생성합니다.
4. **오른쪽 배열 생성**: 피벗보다 큰 요소들을 포함하는 배열을 생성합니다.
5. **재귀적 정렬**: 왼쪽 배열과 오른쪽 배열을 각각 `quicksort` 함수를 통해 정렬한 후, 피벗을 중앙에 배치하여 최종 결과를 반환합니다.
