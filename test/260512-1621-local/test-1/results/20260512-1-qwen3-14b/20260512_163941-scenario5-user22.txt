다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 코드입니다. 각 줄에 주석을 달아 설명해 드리겠습니다.

```python
def quicksort(arr, low, high):
    # 배열이 하나의 요소 이하일 경우 종료 (기저 조건)
    if low < high:
        # 파티션을 수행하고, 피벗의 인덱스를 반환
        pi = partition(arr, low, high)
        
        # 피벗 기준으로 왼쪽 부분 배열 재귀적으로 정렬
        quicksort(arr, low, pi - 1)
        
        # 피벗 기준으로 오른쪽 부분 배열 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피벗으로 마지막 요소를 선택
    pivot = arr[high]
    
    # 피벗보다 작은 값을 가진 요소의 마지막 인덱스
    i = low - 1
    
    # low부터 high-1까지 반복
    for j in range(low, high):
        # 현재 요소가 피벗보다 작으면 i를 증가시키고 요소 교환
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 적절한 위치로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗의 최종 위치를 반환
    return i + 1

# 예시 사용
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)
quicksort(arr, 0, n - 1)
print("정렬된 배열:", arr)
```

### 코드 설명:
1. **`quicksort` 함수**:
   - `low`: 배열의 시작 인덱스
   - `high`: 배열의 끝 인덱스
   - `partition` 함수를 호출하여 피벗을 기준으로 배열을 분할하고, 재귀적으로 왼쪽/오른쪽 배열을 정렬합니다.

2. **`partition` 함수**:
   - `pivot`: 배열의 마지막 요소를 피벗으로 선택
   - `i`: 피벗보다 작은 요소의 마지막 인덱스를 추적
   - `j`: 배열을 순회하며 피벗보다 작은 요소를 찾고, `i`와 교환
   - 마지막으로 피벗을 적절한 위치로 이동하고 그 인덱스를 반환

3. **실행 예시**:
   - `arr = [10, 7, 8, 9, 1, 5]` 배열을 퀵소트로 정렬한 결과는 `[1, 5, 7, 8, 9, 10]`이 됩니다.

이 코드는 퀵소트의 기초적인 구현이며, 시간 복잡도는 평균적으로 O(n log n)이고, 최악의 경우 O(n²)입니다.
