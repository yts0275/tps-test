다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 예제입니다. 각 줄에 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1이면 이미 정렬되어 있음
    if len(arr) <= 1:
        return arr
    
    # 피봇(pivot) 선택: 배열의 마지막 요소를 피봇으로 선택
    pivot = arr[-1]
    
    # 피봇보다 작은 요소들로 구성된 왼쪽 배열
    left = [x for x in arr[:-1] if x < pivot]
    
    # 피봇과 같은 요소들로 구성된 중간 배열
    middle = [x for x in arr[:-1] if x == pivot]
    
    # 피봇보다 큰 요소들로 구성된 오른쪽 배열
    right = [x for x in arr[:-1] if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 배열을 정렬하고, 결과를 합침
    return quicksort(left) + middle + quicksort(right)

# 예시 배열 정렬
example_array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quicksort(example_array)
print("정렬된 배열:", sorted_array)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1인 경우, 이미 정렬되어 있으므로 그대로 반환합니다.
2. **피봇 선택**: 배열의 마지막 요소를 피봇으로 선택합니다.
3. **배열 분할**:
   - `left`: 피봇보다 작은 요소들로 구성된 배열.
   - `middle`: 피봇과 같은 요소들로 구성된 배열.
   - `right`: 피봇보다 큰 요소들로 구성된 배열.
4. **재귀적 정렬**: `left`와 `right` 배열을 다시 `quicksort` 함수로 재귀적으로 정렬합니다.
5. **결과 결합**: 정렬된 `left`, `middle`, `right` 배열을 순서대로 결합하여 최종 결과를 반환합니다.

이 코드는 **비인플레이스(Non-in-place)** 방식으로 구현되어 있으며, 배열의 복사본을 생성합니다. 인플레이스 방식으로 구현하고 싶다면 추가 설명을 드릴 수 있습니다!
