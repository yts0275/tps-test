아래는 퀵소트(Quick Sort) 알고리즘을 파이썬에서 구현한 코드입니다. 각 줄마다 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1인 경우, 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피봇(pivot) 선택: 배열의 마지막 요소를 피봇으로 사용
    pivot = arr[-1]

    # 피봇보다 작은 요소들로 구성된 리스트
    left = [x for x in arr[:-1] if x < pivot]

    # 피봇보다 큰 요소들로 구성된 리스트
    right = [x for x in arr[:-1] if x > pivot]

    # 재귀적으로 좌측과 우측 리스트를 정렬하고, 피봇을 중앙에 배치
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 경우, 정렬할 필요가 없으므로 배열을 그대로 반환합니다.
2. **피봇 선택**: 배열의 마지막 요소를 피봇으로 선택합니다. 이는 퀵소트의 핵심 단계입니다.
3. **좌측 리스트**: 피봇보다 작은 요소들로 구성된 리스트를 생성합니다.
4. **우측 리스트**: 피봇보다 큰 요소들로 구성된 리스트를 생성합니다.
5. **재귀적 정렬**: 좌측과 우측 리스트를 다시 퀵소트 함수로 전달하여 정렬하고, 피봇을 중앙에 배치합니다.

### 예시:
```python
print(quicksort([3, 6, 8, 10, 1, 2, 1]))  # 출력: [1, 1, 2, 3, 6, 8, 10]
```

이 코드는 재귀적 방식으로 퀵소트를 구현하고, 각 단계에서 피봇을 기준으로 배열을 분할합니다.
