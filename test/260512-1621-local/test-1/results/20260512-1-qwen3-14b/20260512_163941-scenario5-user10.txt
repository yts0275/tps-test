```python
def quicksort(arr):
    # 배열이 빈 경우 또는 원소가 하나인 경우, 정렬이 필요 없으므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗을 선택 (이 예제에서는 중앙 원소를 선택)
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 원소를 담을 배열
    left = [x for x in arr if x < pivot]
    # 피벗보다 큰 원소를 담을 배열
    right = [x for x in arr if x > pivot]

    # 재귀적으로 왼쪽 배열과 오른쪽 배열을 정렬하고, 피벗을 중간에 삽입
    return quicksort(left) + [pivot] + quicksort(right)

# 예제 사용
sample_array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quicksort(sample_array)
print("정렬된 배열:", sorted_array)
```

### 주석 설명
1. **기저 조건**: 배열의 길이가 0 또는 1일 때, 정렬이 필요 없으므로 배열을 그대로 반환합니다.
2. **피벗 선택**: 배열의 중앙 원소를 피벗으로 선택합니다. (이 알고리즘에서는 중앙 원소를 선택하지만, 다른 방법도 가능)
3. **왼쪽/오른쪽 배열 분할**: 피벗보다 작은 원소를 `left` 배열, 큰 원소를 `right` 배열에 분리합니다.
4. **재귀적 정렬**: `left`와 `right` 배열을 재귀적으로 정렬한 후, 피벗을 중간에 삽입해 최종 배열을 반환합니다.
5. **예제 실행**: `sample_array`를 정렬한 결과를 출력합니다.

### 시간 복잡도
- **평균 시간 복잡도**: O(n log n)
- **최악의 경우**: O(n²) (예: 배열이 이미 정렬된 경우)
