```python
# 퀵소트(Quick Sort) 알고리즘 구현

def quicksort(arr):
    # 배열의 길이가 1 이하일 경우 종료 (기저 조건)
    if len(arr) <= 1:
        return arr
    
    # 피봇(pivot)을 선택 (여기서는 마지막 요소를 피봇으로 사용)
    pivot = arr[-1]
    
    # 피봇보다 작은 요소를 저장할 왼쪽 배열
    left = []
    # 피봇보다 큰 요소를 저장할 오른쪽 배열
    right = []
    
    # 피봇을 제외한 배열의 요소를 순회하며 분할
    for i in range(len(arr) - 1):
        if arr[i] < pivot:
            left.append(arr[i])  # 피봇보다 작은 요소는 왼쪽으로
        else:
            right.append(arr[i])  # 피봇보다 큰 요소는 오른쪽으로
    
    # 왼쪽 배열, 피봇, 오른쪽 배열을 합쳐 재귀적으로 정렬
    return quicksort(left) + [pivot] + quicksort(right)

# 예시 배열
example_array = [3, 6, 8, 10, 1, 2, 1]
# 퀵소트 실행
sorted_array = quicksort(example_array)
# 정렬된 결과 출력
print("정렬된 배열:", sorted_array)
```

### 주석 설명:
1. **기저 조건**: 배열의 길이가 1 이하일 때 (요소가 하나거나 없을 때) 정렬이 필요 없으므로 그대로 반환.
2. **피봇 선택**: 배열의 마지막 요소를 피봇으로 선택 (다른 선택 방식도 가능).
3. **분할**: 피봇을 제외한 요소를 순회하며, 피봇보다 작은 요소는 `left` 배열에, 큰 요소는 `right` 배열에 저장.
4. **재귀적 정렬**: `left`와 `right` 배열을 각각 퀵소트로 정렬하고, 피봇을 중간에 넣어 최종 배열 구성.

### 예시 실행 결과:
입력 배열 `[3, 6, 8, 10, 1, 2, 1]` → 정렬된 배열 `[1, 1, 2, 3, 6, 8, 10]`
