```python
# 퀵소트 함수 정의
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1일 경우 이미 정렬된 상태
    if len(arr) <= 1:
        return arr

    # 피봇 선택: 배열의 마지막 요소를 피봇으로 사용
    pivot = arr[-1]

    # 피봇보다 작은 요소를 담을 왼쪽 배열
    left = []
    # 피봇보다 큰 요소를 담을 오른쪽 배열
    right = []

    # 배열의 요소를 탐색하여 왼쪽/오른쪽 배열에 분류
    for i in range(len(arr) - 1):
        if arr[i] < pivot:
            left.append(arr[i])  # 피봇보다 작은 요소를 왼쪽 배열에 추가
        else:
            right.append(arr[i])  # 피봇보다 큰 요소를 오른쪽 배열에 추가

    # 재귀 호출: 왼쪽 배열과 오른쪽 배열을 각각 퀵소트 수행
    # 피봇을 기준으로 분할된 왼쪽, 오른쪽 배열을 재귀적으로 정렬
    return quicksort(left) + [pivot] + quicksort(right)

# 예시 실행
example = [5, 3, 8, 4, 2]
sorted_example = quicksort(example)
print("정렬된 배열:", sorted_example)
```

### 코드 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 경우 정렬할 필요가 없으므로 그대로 반환.
2. **피봇 선택**: 배열의 마지막 요소를 피봇으로 선택 (다른 선택도 가능).
3. **분할**: 배열을 피봇 기준으로 두 그룹으로 나눔.
   - 왼쪽 배열: 피봇보다 작은 요소
   - 오른쪽 배열: 피봇보다 큰 요소
4. **재귀**: 왼쪽/오른쪽 배열을 각각 퀵소트로 정렬.
5. **결합**: 정렬된 왼쪽 배열 + 피봇 + 정렬된 오른쪽 배열을 결합하여 최종 결과 반환.

이 알고리즘의 평균 시간 복잡도는 $O(n \log n)$, 최악의 경우 $O(n^2)$입니다.
