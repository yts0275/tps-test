다음은 퀵소트 알고리즘을 Python으로 구현한 코드입니다. 각 줄에 주석을 달아 설명했습니다:

```python
def quicksort(arr, start, end):
    # 기저 조건: 배열의 길이가 1 이하이거나 시작 인덱스가 끝 인덱스보다 크면 종료
    if start >= end:
        return

    # 피벗을 선택 (현재 배열의 마지막 요소로 선택)
    pivot = arr[end]
    # 피벗보다 작은 요소들의 위치를 추적하는 인덱스
    i = start

    # 배열을 순회하며 피벗보다 작은 요소를 찾아서 i의 위치에 배치
    for j in range(start, end):
        if arr[j] < pivot:
            # 피벗보다 작은 요소를 i의 위치와 교환
            arr[i], arr[j] = arr[j], arr[i]
            # i를 증가시켜 다음 작은 요소의 위치로 이동
            i += 1

    # 피벗을 적절한 위치(i)로 이동
    arr[i], arr[end] = arr[end], arr[i]

    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬
    quicksort(arr, start, i - 1)  # 왼쪽 부분 배열
    quicksort(arr, i + 1, end)    # 오른쪽 부분 배열

# 예시 사용
arr = [5, 3, 8, 4, 2]
quicksort(arr, 0, len(arr) - 1)
print("정렬된 배열:", arr)
```

### 설명:
1. **기저 조건**: 배열의 길이가 1 이하이거나 시작 인덱스가 끝 인덱스보다 크면 정렬이 필요 없으므로 종료.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택 (다른 선택 방법도 가능).
3. **분할 과정**:
   - `i`는 피벗보다 작은 요소들의 위치를 추적.
   - 배열을 순회하면서 `arr[j] < pivot`인 요소를 찾고, `i`의 위치와 교환.
   - `i`를 증가시켜 다음 작은 요소의 위치로 이동.
4. **피벗 이동**: 피벗을 `i`의 위치로 이동하여 배열을 두 부분으로 분할.
5. **재귀 호출**: 왼쪽 부분 배열 (`start` ~ `i-1`)과 오른쪽 부분 배열 (`i+1` ~ `end`)에 대해 재귀적으로 퀵소트 실행.

이 코드는 O(n log n)의 평균 시간 복잡도를 가진 퀵소트 알고리즘을 구현한 것입니다.
