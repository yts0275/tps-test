다음은 퀵소트(Quick Sort) 알고리즘의 Python 구현입니다. 각 줄에 주석을 달아 원리와 실행 흐름을 설명해 드리겠습니다.

```python
def quicksort(arr, low, high):
    # 기저 조건: 요소가 하나이거나 인덱스 범위가 유효하지 않은 경우 종료
    if low >= high:
        return

    # 피봇(pivot) 선택: 마지막 요소를 피봇으로 선택
    pivot = arr[high]
    # 더 작은 요소를 저장할 인덱스
    i = low - 1

    # 배열을 탐색하면서 피봇보다 작은 요소를 왼쪽으로 이동
    for j in range(low, high):
        if arr[j] < pivot:
            # 작은 요소를 왼쪽으로 이동
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피봇을 올바른 위치로 이동 (i+1)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    # 왼쪽, 오른쪽 하위 배열에 대해 재귀적으로 퀵소트 실행
    quicksort(arr, low, i)
    quicksort(arr, i + 2, high)

# 예시 사용법
arr = [10, 7, 8, 9, 1, 5]
print("정렬 전 배열:", arr)
quicksort(arr, 0, len(arr) - 1)
print("정렬 후 배열:", arr)
```

---

### 주석 설명

1. `def quicksort(arr, low, high):`  
   - `arr`: 정렬할 배열  
   - `low`: 배열의 시작 인덱스  
   - `high`: 배열의 끝 인덱스

2. `if low >= high: return`  
   - 배열이 한 요소 이하인 경우 종료 (기저 조건)

3. `pivot = arr[high]`  
   - 배열의 마지막 요소를 피봇(pivot)으로 선택

4. `i = low - 1`  
   - 피봇보다 작은 요소를 저장할 인덱스 초기화

5. `for j in range(low, high):`  
   - 배열을 탐색하며 피봇보다 작은 요소를 찾음

6. `if arr[j] < pivot:`  
   - 현재 요소가 피봇보다 작으면 처리

7. `i += 1`  
   - 작은 요소의 위치를 이동

8. `arr[i], arr[j] = arr[j], arr[i]`  
   - 작은 요소를 왼쪽으로 이동 (스왑)

9. `arr[i + 1], arr[high] = arr[high], arr[i + 1]`  
   - 피봇을 올바른 위치(i+1)로 이동

10. `quicksort(arr, low, i)`  
   - 피봇의 왼쪽 배열을 재귀적으로 정렬

11. `quicksort(arr, i + 2, high)`  
   - 피봇의 오른쪽 배열을 재귀적으로 정렬
