다음은 퀵소트 알고리즘을 Python에서 구현한 예제입니다. 각 줄에 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr, start, end):
    # 기저 조건: 배열의 크기가 1 이하일 때 종료
    if start >= end:
        return

    # 파티션 함수를 호출하여 피봇 인덱스를 구함
    pivot_index = partition(arr, start, end)

    # 피봇 왼쪽 부분 배열을 재귀적으로 정렬
    quicksort(arr, start, pivot_index - 1)

    # 피봇 오른쪽 부분 배열을 재귀적으로 정렬
    quicksort(arr, pivot_index + 1, end)


def partition(arr, start, end):
    # 피봇은 배열의 마지막 요소로 선택
    pivot = arr[end]

    # i는 작은 요소들이 위치할 위치를 가리킴
    i = start - 1

    # 배열을 순회하면서 피봇보다 작은 요소들을 i의 오른쪽으로 이동
    for j in range(start, end):
        if arr[j] < pivot:
            # i를 하나 증가시키고, arr[i]와 arr[j]를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 피봇을 적절한 위치로 이동 (i+1)
    arr[i + 1], arr[end] = arr[end], arr[i + 1]

    # 피봇의 최종 인덱스를 반환
    return i + 1


# 예제 실행
arr = [5, 3, 8, 4, 2]
print("정렬 전:", arr)

# 퀵소트 실행
quicksort(arr, 0, len(arr) - 1)

print("정렬 후:", arr)
```

### 설명:
1. **quicksort 함수**: 재귀적으로 배열을 정렬하는 메인 함수
   - `start`와 `end`는 배열의 시작/종료 인덱스
   - `partition` 함수를 통해 피봇을 선택하고 배열을 분할

2. **partition 함수**: 배열을 피봇 기준으로 분할
   - `pivot`은 배열의 마지막 요소
   - `i`는 작은 요소들이 위치할 인덱스
   - `j`는 배열을 순회하는 포인터
   - `i+1`에 피봇을 위치시키고, 해당 인덱스를 반환

3. **재귀적 호출**: 피봇을 기준으로 왼쪽/오른쪽 배열을 각각 정렬

이 알고리즘은 평균 시간 복잡도 O(n log n)을 가지며, 최악의 경우 O(n²)일 수 있습니다.
