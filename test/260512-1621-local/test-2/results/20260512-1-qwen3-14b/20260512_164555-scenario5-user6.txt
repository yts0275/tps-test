```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1일 경우, 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗 선택: 배열의 중앙 요소를 피벗으로 사용
    pivot = arr[len(arr) // 2]
    
    # 피벗보다 작은 요소를 담을 리스트
    left = []
    # 피벗보다 큰 요소를 담을 리스트
    right = []
    
    # 배열의 요소를 피벗과 비교하여 left, right 리스트에 분할
    for num in arr:
        if num < pivot:
            left.append(num)
        else:
            right.append(num)
    
    # 재귀적으로 left, right 리스트를 정렬하고, 피벗을 중앙에 삽입
    return quicksort(left) + [pivot] + quicksort(right)
```

1. **기저 조건**: 배열의 길이가 0 또는 1일 경우, 이미 정렬된 상태이므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 중앙 요소를 피벗으로 선택합니다. 이는 최악의 경우(예: 이미 정렬된 배열)를 방지하기 위한 전략입니다.
3. **분할**: 피벗보다 작은 요소는 `left` 리스트에, 큰 요소는 `right` 리스트에 분할합니다.
4. **재귀적 정렬**: `left`와 `right` 리스트를 각각 `quicksort` 함수로 재귀적으로 정렬합니다.
5. **결합**: 정렬된 `left` 리스트, 피벗, 정렬된 `right` 리스트를 결합하여 최종 결과를 반환합니다.

이 알고리즘은 평균적으로 **O(n log n)**의 시간 복잡도를 가지며, 최악의 경우 **O(n²)**의 시간 복잡도를 가집니다. 피벗 선택 방식에 따라 성능이 달라집니다.
