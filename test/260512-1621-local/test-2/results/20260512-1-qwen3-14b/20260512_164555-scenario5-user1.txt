다음은 퀵소트(Quick Sort) 알고리즘의 파이썬 구현입니다. 각 줄에 주석을 달아 설명을 추가했습니다.

```python
def quicksort(arr, low, high):
    # 배열이 정렬되어야 할 범위가 유효하지 않을 경우 종료
    if low < high:
        # 파티션을 나누고, 피벗의 인덱스를 반환
        pi = partition(arr, low, high)
        
        # 피벗을 기준으로 왼쪽 배열 재귀적으로 정렬
        quicksort(arr, low, pi - 1)
        
        # 피벗을 기준으로 오른쪽 배열 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피벗으로 사용할 요소를 선택 (마지막 요소)
    pivot = arr[high]
    
    # 피벗보다 작은 값을 가진 요소의 위치를 추적
    i = low - 1  # 작은 요소의 인덱스
    
    # 배열을 순회하며 피벗보다 작은 요소를 왼쪽으로 이동
    for j in range(low, high):
        if arr[j] <= pivot:
            # 작은 요소를 i+1 위치로 이동
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗의 최종 위치를 반환
    return i + 1

# 예제 사용
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)
quicksort(arr, 0, n - 1)
print("정렬된 배열:", arr)
```

### 설명:
1. **`quicksort` 함수**:  
   - `low`: 배열의 시작 인덱스  
   - `high`: 배열의 끝 인덱스  
   - `low < high` 조건이 참일 때만 정렬 진행  
   - `partition` 함수를 호출하여 피벗의 위치를 결정  
   - 피벗을 기준으로 왼쪽/오른쪽 배열 재귀적으로 정렬

2. **`partition` 함수**:  
   - `pivot`: 배열의 마지막 요소를 피벗으로 선택  
   - `i`: 피벗보다 작은 값을 가진 요소의 위치 추적  
   - `for` 루프: 배열을 순회하며 피벗보다 작은 값을 가진 요소를 왼쪽으로 이동  
   - 피벗을 올바른 위치로 이동 후, 해당 인덱스 반환

3. **예제 실행**:  
   - 배열 `[10, 7, 8, 9, 1, 5]`을 퀵소트로 정렬  
   - 결과: `[1, 5, 7, 8, 9, 10]` 출력
