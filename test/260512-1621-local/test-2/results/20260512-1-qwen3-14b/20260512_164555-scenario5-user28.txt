다음은 퀵소트(Quick Sort) 알고리즘의 파이썬 구현입니다. 각 줄에 주석을 달아 설명을 제공했습니다.

```python
def quicksort(arr, low, high):
    # 배열이 0개 또는 1개 원소일 경우 종료
    if low < high:
        # 피벗을 선택 (이 예제에서는 마지막 요소를 피벗으로 선택)
        pivot_index = partition(arr, low, high)
        
        # 피벗을 기준으로 왼쪽과 오른쪽 서브배열을 재귀적으로 정렬
        quicksort(arr, low, pivot_index - 1)
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    # 피벗을 마지막 요소로 설정
    pivot = arr[high]
    
    # i는 작은 요소들이 위치할 인덱스를 나타냄 (초기값은 low - 1)
    i = low - 1
    
    # low부터 high-1까지 반복하여 피벗보다 작은 요소를 찾음
    for j in range(low, high):
        if arr[j] < pivot:
            # 작은 요소를 i의 위치와 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피벗을 올바른 위치로 이동 (i+1)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피벗의 최종 위치를 반환
    return i + 1

# 예제 실행
if __name__ == "__main__":
    arr = [3, 6, 8, 10, 1, 2, 1]
    print("정렬 전 배열:", arr)
    quicksort(arr, 0, len(arr) - 1)
    print("정렬 후 배열:", arr)
```

### 설명:
- `quicksort` 함수는 재귀적으로 배열을 정렬합니다.
- `partition` 함수는 피벗을 기준으로 배열을 분할하고, 피벗의 올바른 위치를 반환합니다.
- 피벗은 일반적으로 마지막 요소로 선택되며, 이보다 작은 요소들은 왼쪽, 큰 요소들은 오른쪽에 배치됩니다.
- 이 알고리즘은 평균적으로 O(n log n)의 시간 복잡도를 가지며, 최악의 경우 O(n²)입니다.
