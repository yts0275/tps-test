다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 코드입니다. 각 줄에 주석을 달아 설명해 드릴게요.

```python
def quicksort(arr, low, high):
    # 배열이 정렬할 요소가 1개 이하인 경우 종료
    if low < high:
        # 배열을 분할하고 피봇의 최종 위치를 반환
        pivot_index = partition(arr, low, high)
        
        # 피봇 왼쪽 부분 배열 재귀적으로 정렬
        quicksort(arr, low, pivot_index - 1)
        
        # 피봇 오른쪽 부분 배열 재귀적으로 정렬
        quicksort(arr, pivot_index + 1, high)

def partition(arr, low, high):
    # 피봇으로 사용할 요소를 선택 (이 예제에서는 마지막 요소)
    pivot = arr[high]
    
    # i는 "작은 요소의 마지막 위치"를 나타냄
    i = low - 1
    
    # j는 배열을 순회하는 포인터
    for j in range(low, high):
        # 현재 요소가 피봇보다 작은 경우
        if arr[j] < pivot:
            # i를 증가시키고, arr[i]와 arr[j]를 교환
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피봇을 적절한 위치로 이동 (i+1)
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피봇의 최종 위치 반환
    return i + 1

# 예제 실행
arr = [10, 7, 8, 9, 1, 5]
print("정렬 전 배열:", arr)
quicksort(arr, 0, len(arr) - 1)
print("정렬 후 배열:", arr)
```

### 주요 개념 설명:
1. **퀵소트**: 분할 정복 알고리즘으로, 배열을 피봇 기준으로 두 부분으로 나누어 정렬합니다.
2. **피봇**: 기준이 되는 요소 (이 예제에서는 배열의 마지막 요소).
3. **분할(partition)**: 피봇을 적절한 위치로 이동시키고, 배열을 왼쪽(작은 값), 오른쪽(큰 값)으로 나눔.
4. **재귀 호출**: 분할된 두 부분 배열을 다시 퀵소트로 정렬.

이 코드는 O(n log n)의 평균 시간 복잡도를 가집니다. 최악의 경우 O(n²)이지만, 일반적으로 매우 빠른 성능을 보입니다.
