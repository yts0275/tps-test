```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1이면 이미 정렬되어 있음
    if len(arr) <= 1:
        return arr
    
    # 피벗 선택: 배열의 첫 번째 요소를 피벗으로 사용
    pivot = arr[0]
    
    # 배열을 피벗보다 작은 요소와 큰/같은 요소로 분할
    # 왼쪽 배열: 피벗보다 작은 요소들
    left = [x for x in arr[1:] if x < pivot]
    # 오른쪽 배열: 피벗보다 크거나 같은 요소들
    right = [x for x in arr[1:] if x >= pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 배열을 정렬하고, 피벗을 중간에 삽입
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명:
- **기저 조건**: 배열의 길이가 0 또는 1일 경우, 이미 정렬되어 있으므로 그대로 반환합니다.
- **피벗 선택**: 배열의 첫 번째 요소를 피벗으로 선택합니다. 다른 선택 방식(예: 중앙값, 랜덤)도 가능합니다.
- **분할**: 피벗을 기준으로 배열을 두 부분으로 나눕니다.
  - `left` 배열: 피벗보다 작은 요소들
  - `right` 배열: 피벗보다 크거나 같은 요소들
- **재귀 정렬**: `left`와 `right` 배열을 각각 퀵소트로 재귀적으로 정렬한 후, 피벗을 중간에 삽입합니다.
