다음은 퀵소트(QuickSort) 알고리즘의 Python 구현입니다. 각 줄에 주석을 달아 설명을 제공합니다:

```python
def quicksort(arr):
    # 배열의 길이가 1 이하인 경우 정렬이 필요 없으므로 배열 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 선택합니다. 여기서는 배열의 마지막 요소를 피벗으로 선택
    pivot = arr[-1]

    # 피벗보다 작은 요소들을 담을 왼쪽 배열
    left = []
    # 피벗보다 큰 요소들을 담을 오른쪽 배열
    right = []

    # 배열의 모든 요소를 순회하며 피벗과 비교
    for i in range(len(arr) - 1):
        if arr[i] < pivot:
            # 요소가 피벗보다 작으면 왼쪽 배열에 추가
            left.append(arr[i])
        else:
            # 요소가 피벗보다 크거나 같으면 오른쪽 배열에 추가
            right.append(arr[i])

    # 재귀적으로 왼쪽 배열과 오른쪽 배열을 정렬하고, 피벗을 중간에 넣어 합쳐 최종 배열을 반환
    return quicksort(left) + [pivot] + quicksort(right)

# 예시 사용
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quicksort(arr)
print("정렬된 배열:", sorted_arr)
```

### 주석 설명:
1. `quicksort(arr)` 함수:
   - 배열의 길이가 1 이하일 경우, 정렬이 필요 없으므로 그대로 반환합니다.
   - 피벗을 선택하고, 배열을 왼쪽(피벗보다 작은 요소)과 오른쪽(피벗보다 큰 요소)으로 분할합니다.
   - 분할된 배열을 재귀적으로 정렬한 후, 피벗을 중앙에 넣어 전체 배열을 반환합니다.

2. `pivot = arr[-1]`:
   - 배열의 마지막 요소를 피벗으로 선택합니다. 이는 퀵소트의 일반적인 구현 방법 중 하나입니다.

3. `for i in range(len(arr) - 1)`:
   - 배열의 마지막 요소(피벗)를 제외한 나머지 요소를 순회합니다.

4. `left.append(arr[i])` / `right.append(arr[i])`:
   - 각 요소를 피벗과 비교하여 왼쪽 또는 오른쪽 배열에 넣습니다.

5. `return quicksort(left) + [pivot] + quicksort(right)`:
   - 재귀적으로 왼쪽과 오른쪽 배열을 정렬하고, 피벗을 중간에 삽입하여 최종 정렬된 배열을 반환합니다.

### 시간 복잡도:
- **평균 시간 복잡도**: $O(n \log n)$
- **최악의 경우**: $O(n^2)$ (예: 이미 정렬된 배열에서 피벗을 항상 마지막 요소로 선택하는 경우)
- **공간 복잡도**: $O(n)$ (재귀 호출 스택과 추가 배열을 사용)
