```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1이라면 이미 정렬되어 있음
    if len(arr) <= 1:
        return arr

    # 피벗 요소 선택 (이 예제에서는 배열의 마지막 요소를 피벗으로 사용)
    pivot = arr[-1]

    # 피벗보다 작은 요소들을 담을 왼쪽 배열
    left = [x for x in arr[:-1] if x < pivot]

    # 피벗보다 크거나 같은 요소들을 담을 오른쪽 배열
    right = [x for x in arr[:-1] if x >= pivot]

    # 재귀적으로 왼쪽 배열과 오른쪽 배열을 정렬하고, 피벗을 중앙에 배치
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 경우, 배열은 이미 정렬되어 있으므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택합니다. 이는 퀵소트에서 흔히 사용되는 방법입니다.
3. **배열 분할**:
   - `left`: 피벗보다 작은 요소들을 담는 배열.
   - `right`: 피벗보다 크거나 같은 요소들을 담는 배열.
4. **재귀적 정렬**: `left`와 `right` 배열을 각각 퀵소트로 재귀적으로 정렬하고, 정렬된 `left` 배열, 피벗, 정렬된 `right` 배열을 결합하여 최종 결과를 반환합니다.

이 구현은 간단한 퀵소트의 기본 형태로, 평균 시간 복잡도는 **O(n log n)**입니다. 다만, 최악의 경우 **O(n²)**이 될 수 있으므로, 실제 사용 시 배열의 분할 방식을 최적화하는 것이 중요합니다.
