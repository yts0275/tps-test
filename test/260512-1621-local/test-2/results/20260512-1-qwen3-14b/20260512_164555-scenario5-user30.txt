```python
def quicksort(arr):
    # 배열의 길이가 0 또는 1이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗을 선택합니다. 여기서는 배열의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]

    # 피벗보다 작은 요소들을 담을 왼쪽 배열
    left = [x for x in arr[:-1] if x < pivot]

    # 피벗보다 큰 또는 같은 요소들을 담을 오른쪽 배열
    right = [x for x in arr[:-1] if x >= pivot]

    # 재귀적으로 왼쪽 배열과 오른쪽 배열을 정렬한 후, 피벗을 중간에 놓아 최종 배열을 구성
    return quicksort(left) + [pivot] + quicksort(right)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1인 경우, 이미 정렬된 상태이므로 그대로 반환합니다.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택합니다.
3. **분할**: 피벗을 기준으로 두 개의 배열로 나눕니다:
   - 왼쪽 배열: 피벗보다 작은 요소들
   - 오른쪽 배열: 피벗보다 크거나 같은 요소들
4. **재귀적 정렬**: 왼쪽 배열과 오른쪽 배열을 각각 퀵소트 함수로 다시 정렬합니다.
5. **결합**: 정렬된 왼쪽 배열 + 피벗 + 정렬된 오른쪽 배열을 결합하여 최종 결과를 반환합니다.
