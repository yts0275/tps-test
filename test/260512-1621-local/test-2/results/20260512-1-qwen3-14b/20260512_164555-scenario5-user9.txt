```python
def quicksort(arr):
    # 기저 조건: 배열이 0개 또는 1개 원소일 경우, 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피봇 선택 (배열 중간 원소 사용)
    pivot = arr[len(arr) // 2]
    
    # 피봇보다 작은 원소를 담는 리스트
    left = [x for x in arr if x < pivot]
    
    # 피봇과 같은 원소를 담는 리스트
    equal = [x for x in arr if x == pivot]
    
    # 피봇보다 큰 원소를 담는 리스트
    right = [x for x in arr if x > pivot]
    
    # 재귀적으로 왼쪽과 오른쪽 부분 배열을 정렬하고, 결과를 결합
    return quicksort(left) + equal + quicksort(right)
```

2. **피봇 선택**: 배열의 중간 인덱스에 있는 원소를 피봇으로 선택합니다. 이는 균형 잡힌 분할을 위해 사용됩니다.
3. **분할**: 피봇을 기준으로 배열을 세 부분으로 나눕니다:
   - `left`: 피봇보다 작은 원소들.
   - `equal`: 피봇과 같은 원소들.
   - `right`: 피봇보다 큰 원소들.
4. **재귀적 정렬**: `left`와 `right` 부분 배열을 각각 `quicksort` 함수로 재귀적으로 정렬합니다.
5. **결합**: 정렬된 `left`, `equal`, `right`을 순서대로 결합하여 최종 정렬된 배열을 반환합니다.
