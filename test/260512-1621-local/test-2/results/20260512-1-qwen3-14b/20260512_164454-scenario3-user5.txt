다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 예제입니다. 각 줄에 주석을 달아 설명했습니다.

```python
def quicksort(arr, low, high):
    # 기저 조건: low가 high보다 크면 종료 (1개 요소 또는 빈 배열)
    if low < high:
        # 배열을 분할하고 피봇의 인덱스를 반환
        pi = partition(arr, low, high)
        
        # 피봇 왼쪽 부분을 재귀적으로 정렬
        quicksort(arr, low, pi - 1)
        
        # 피봇 오른쪽 부분을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피봇으로 사용할 요소를 선택 (이 예제에서는 마지막 요소)
    pivot = arr[high]
    
    # 작은 요소의 인덱스를 초기화 (low - 1)
    i = low - 1
    
    # low부터 high-1까지의 요소를 순회
    for j in range(low, high):
        # 현재 요소가 피봇보다 작거나 같으면
        if arr[j] <= pivot:
            # 작은 요소의 인덱스를 증가
            i += 1
            
            # 작은 요소와 현재 요소를 교환
            arr[i], arr[j] = arr[j], arr[i]
    
    # 피봇 요소를 적절한 위치로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 분할된 위치를 반환 (피봇의 인덱스)
    return i + 1

# 예제 실행
if __name__ == "__main__":
    # 테스트 배열
    arr = [10, 7, 8, 9, 1, 5]
    print("정렬 전 배열:", arr)
    
    # 퀵소트 실행
    quicksort(arr, 0, len(arr) - 1)
    
    # 정렬된 배열 출력
    print("정렬 후 배열:", arr)
```

### 설명:
1. **`quicksort` 함수**:
   - 배열을 재귀적으로 정렬합니다.
   - `low`는 시작 인덱스, `high`는 끝 인덱스입니다.
   - `partition` 함수를 호출해 배열을 분할하고, 분할된 피봇을 기준으로 좌우 부분을 재귀적으로 정렬합니다.

2. **`partition` 함수**:
   - 배열을 분할하는 역할을 합니다.
   - `pivot`으로 마지막 요소를 선택합니다.
   - `i`는 "작은 요소"의 인덱스를 추적합니다.
   - `j`는 배열을 순회하며 `arr[j] <= pivot`인 요소를 찾아 `i`와 교환합니다.
   - 마지막으로 피봇을 적절한 위치로 이동하고, 그 인덱스를 반환합니다.

3. **시간 복잡도**:
   - 평균: **O(n log n)** (n: 요소 수)
   - 최악: **O(n²)** (예: 배열이 이미 정렬된 경우)

4. **공간 복잡도**:
   - **O(log n)** (재귀 호출 스택에 사용)
