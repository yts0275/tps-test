다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 코드입니다. 각 줄에 주석을 달아 설명을 제공했습니다.

```python
def quicksort(arr, low, high):
    # 기저 조건: 배열의 길이가 0 또는 1일 경우 이미 정렬되어 있음
    if low >= high:
        return

    # 피벗(pivot) 선택: 배열의 중앙 요소 선택
    pivot_index = (low + high) // 2
    pivot = arr[pivot_index]

    # 피벗을 배열의 끝으로 이동 (임시로)
    arr[pivot_index], arr[high] = arr[high], arr[pivot_index]

    # 왼쪽 포인터와 오른쪽 포인터 초기화
    left = low
    right = high - 1

    # 배열을 피벗을 기준으로 분할
    while left <= right:
        # 왼쪽 포인터: 피벗보다 큰 값을 찾음
        while left <= right and arr[left] < pivot:
            left += 1
        # 오른쪽 포인터: 피벗보다 작은 값을 찾음
        while left <= right and arr[right] > pivot:
            right -= 1

        # 두 포인터가 교차하지 않았다면 요소 교환
        if left <= right:
            arr[left], arr[right] = arr[right], arr[left]
            left += 1
            right -= 1

    # 피벗을 올바른 위치로 이동
    arr[left], arr[high] = arr[high], arr[left]

    # 왼쪽 부분 배열과 오른쪽 부분 배열에 대해 재귀적으로 퀵소트 실행
    quicksort(arr, low, left - 1)
    quicksort(arr, left + 1, high)

# 예제 배열 정의
arr = [3, 6, 8, 10, 1, 2, 1]

# 퀵소트 실행
quicksort(arr, 0, len(arr) - 1)

# 정렬된 배열 출력
print("정렬된 배열:", arr)
```

### 설명:
- **기저 조건**: 배열의 길이가 0 또는 1일 경우 정렬이 필요 없음.
- **피벗 선택**: 배열의 중앙 요소를 피벗으로 선택 (다른 선택법도 가능).
- **분할**: 배열을 피벗보다 작은 값과 큰 값으로 나눔.
- **재귀**: 분할된 왼쪽과 오른쪽 배열에 대해 다시 퀵소트 실행.

### 시간 복잡도:
- **평균**: O(n log n) (n은 배열의 크기)
- **최악**: O(n²) (피벗이 항상 최대/최소일 때 발생, 그러나 이 구현에서는 피벗 선택을 중앙으로 해 최악을 줄임)
