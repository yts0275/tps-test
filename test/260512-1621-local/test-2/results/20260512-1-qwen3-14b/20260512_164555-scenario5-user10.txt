다음은 퀵소트(Quick Sort) 알고리즘을 Python으로 구현한 예시입니다. 각 줄에 대한 주석을 달았습니다.

```python
def quicksort(arr, low, high):
    # 배열이 한 요소 이하일 경우 종료 (기저 조건)
    if low < high:
        # 파티션을 수행하여 피봇의 위치를 얻음
        pi = partition(arr, low, high)
        
        # 피봇 왼쪽 부분 배열을 재귀적으로 정렬
        quicksort(arr, low, pi - 1)
        
        # 피봇 오른쪽 부분 배열을 재귀적으로 정렬
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    # 피봇을 선택 (이 예제에서는 배열의 마지막 요소를 사용)
    pivot = arr[high]
    
    # 피봇보다 작은 요소들이 위치할 위치를 가리키는 인덱스
    i = low - 1  # 초기값은 low-1로 설정
    
    # low부터 high-1까지 순회
    for j in range(low, high):
        # 현재 요소가 피봇보다 작으면 i를 증가시키고 요소를 교환
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 마지막으로 피봇을 적절한 위치로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    
    # 피봇의 최종 인덱스를 반환
    return i + 1

# 예제 배열
arr = [10, 7, 8, 9, 1, 5]
n = len(arr)

# 퀵소트 호출
quicksort(arr, 0, n - 1)

# 정렬된 배열 출력
print("정렬된 배열:", arr)
```

### 설명:
- `quicksort` 함수: 퀵소트의 메인 로직을 처리합니다. 재귀적으로 호출됩니다.
- `partition` 함수: 배열을 피봇을 기준으로 두 부분으로 나누고, 피봇의 최종 위치를 반환합니다.
- `pivot`: 배열에서 선택한 기준 요소 (이 예제에서는 마지막 요소).
- `i`: 피봇보다 작은 요소들이 위치할 인덱스를 추적합니다.
- `j`: 배열을 순회하는 인덱스입니다.

이 코드는 배열을 O(n log n)의 평균 시간 복잡도로 정렬합니다.
