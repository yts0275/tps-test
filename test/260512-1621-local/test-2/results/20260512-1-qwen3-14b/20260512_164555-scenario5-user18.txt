다음은 퀵소트(Quick Sort) 알고리즘을 Python에서 구현한 예시입니다. 각 줄마다 주석을 달아 설명을 제공했습니다:

```python
def quicksort(arr):
    # 기저 조건: 배열의 길이가 0 또는 1인 경우 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr
    
    # 피벗(pivot)을 선택: 여기서는 배열의 마지막 요소를 피벗으로 사용
    pivot = arr[-1]
    
    # 피벗보다 작은 요소들을 담을 리스트
    left = []
    # 피벗보다 큰 요소들을 담을 리스트
    right = []
    
    # 배열의 요소를 피벗과 비교하여 left와 right에 분리
    for num in arr[:-1]:  # 마지막 요소(pivot)는 제외
        if num < pivot:
            left.append(num)  # 피벗보다 작은 요소는 left에 추가
        else:
            right.append(num)  # 피벗보다 큰 요소는 right에 추가
    
    # 재귀적으로 left와 right를 정렬하고, 피벗을 중간에 넣어 전체 배열을 반환
    return quicksort(left) + [pivot] + quicksort(right)

# 예시 배열 정렬
example_array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quicksort(example_array)
print("정렬된 배열:", sorted_array)
```

### 설명:
1. **기저 조건**: 배열의 길이가 0 또는 1일 때는 이미 정렬되어 있으므로 바로 반환합니다.
2. **피벗 선택**: 배열의 마지막 요소를 피벗으로 선택합니다. 이는 간단한 구현을 위해 선택된 방법입니다.
3. **분할**: 피벗보다 작은 요소를 `left` 리스트에, 큰 요소를 `right` 리스트에 나누어 담습니다.
4. **재귀 정렬**: `left`와 `right` 리스트를 각각 퀵소트로 정렬하고, 피벗을 중간에 넣어 전체 배열을 구성합니다.
