퀵소트를 Python으로 구현하겠습니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (기저 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들 모음
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소들 모음 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들 모음

    return quicksort(left) + middle + quicksort(right) # 좌측 재귀 + 피벗 + 우측 재귀 결합


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 입력 리스트
    print("정렬 전:", data)                             # 정렬 전 출력
    result = quicksort(data)                           # 퀵소트 실행
    print("정렬 후:", result)                           # 정렬 후 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**시간/공간 복잡도:**
- 평균: O(n log n), 최악(이미 정렬된 경우): O(n²)
- 공간: O(n) — 리스트 컴프리헨션으로 새 배열 생성
