파일 쓰기 권한이 필요합니다. 아래에 코드를 바로 제공합니다.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받는다
    if len(arr) <= 1:                                # 원소가 1개 이하면 이미 정렬된 상태이므로
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 리스트에 모은다
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트에 모은다 (중복 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 리스트에 모은다

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                           # 이 파일을 직접 실행할 때만 아래 코드를 수행
    sample = [3, 6, 8, 10, 1, 2, 1]                 # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                         # 정렬 전 리스트 출력
    result = quicksort(sample)                       # 퀵소트 실행 후 결과를 result에 저장
    print("정렬 후:", result)                         # 정렬된 리스트 출력
```

**동작 원리 요약:**
- **피벗 선택**: 리스트 중간값을 피벗으로 사용
- **분할**: 피벗 기준으로 left / middle / right 세 파트로 나눔
- **재귀**: left와 right를 재귀 호출로 정렬 후 합산
- **평균 시간복잡도**: O(n log n), 최악(이미 정렬된 경우): O(n²)
