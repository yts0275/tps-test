파일 쓰기 권한이 필요하네요. 코드를 먼저 보여드릴게요.

```python
def quicksort(arr):                          # 퀵소트 함수 정의: 리스트를 입력받아 정렬된 리스트를 반환
    if len(arr) <= 1:                        # 기저 조건: 원소가 1개 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료)

    pivot = arr[len(arr) // 2]              # 피벗 선택: 리스트 중간 원소를 기준값으로 사용
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 원소들을 왼쪽 그룹으로 분류
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 그룹으로 분류
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 오른쪽 그룹으로 분류

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀적으로 정렬 후 합쳐서 반환


if __name__ == "__main__":                   # 이 파일을 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]        # 정렬할 예시 리스트 정의
    print("정렬 전:", sample)               # 정렬 전 리스트 출력
    result = quicksort(sample)              # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)               # 정렬된 결과 출력
```

**동작 원리:**

1. **피벗 선택** — 중간 인덱스 원소를 기준값으로 선택
2. **분할(Partition)** — 피벗 기준으로 작은 값(left), 같은 값(middle), 큰 값(right) 세 그룹으로 분리
3. **재귀 정렬** — left, right 그룹을 각각 재귀 호출로 정렬
4. **합병** — 정렬된 세 그룹을 이어붙여 반환

| 항목 | 값 |
|------|-----|
| 평균 시간복잡도 | O(n log n) |
| 최악 시간복잡도 | O(n²) — 이미 정렬된 배열에서 피벗이 최솟/최댓값일 때 |
| 공간복잡도 | O(n) — 리스트 컴프리헨션 방식 |
