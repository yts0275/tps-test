파일 작성 권한이 없어서 코드를 직접 보여드립니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 리스트를 입력받아 정렬된 리스트 반환
    if len(arr) <= 1:                            # 원소가 0개 또는 1개이면 이미 정렬된 상태이므로
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 피벗 선택: 리스트 중간 인덱스의 원소를 피벗으로 사용

    left = [x for x in arr if x < pivot]        # left: 피벗보다 작은 원소들을 모아 새 리스트 생성
    middle = [x for x in arr if x == pivot]     # middle: 피벗과 같은 원소들을 모아 새 리스트 생성 (중복값 처리)
    right = [x for x in arr if x > pivot]       # right: 피벗보다 큰 원소들을 모아 새 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽을 재귀 정렬 + 피벗 + 오른쪽을 재귀 정렬 후 합쳐 반환


if __name__ == "__main__":                       # 이 파일이 직접 실행될 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 정렬되지 않은 리스트 정의
    print("정렬 전:", sample)                    # 정렬 전 원본 리스트 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)                    # 정렬된 결과 리스트 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**구조 요약:**
- **재귀 종료 조건** — 원소 0~1개이면 즉시 반환
- **피벗** — 중간 인덱스 원소 선택
- **분할** — left / middle / right 3-way 분할로 중복값도 올바르게 처리
- **시간 복잡도** — 평균 O(n log n), 최악 O(n²)
