```python
def quicksort(arr):                          # arr: 정렬할 리스트를 받는 함수
    if len(arr) <= 1:                        # 원소가 1개 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 왼쪽 배열에 모음
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 배열에 모음
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 오른쪽 배열에 모음

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀적으로 정렬 후 합침


# --- 테스트 ---
data = [3, 6, 8, 10, 1, 2, 1]   # 정렬할 예시 데이터
result = quicksort(data)          # 퀵소트 호출
print(result)                     # 출력: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리 요약:**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 중간 원소를 기준값으로 설정 |
| 분할 | 피벗 기준으로 작은 값 / 같은 값 / 큰 값 세 그룹으로 분리 |
| 재귀 | 각 그룹에 동일하게 퀵소트 재적용 |
| 병합 | 정렬된 세 그룹을 순서대로 이어붙임 |

**시간 복잡도:** 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
