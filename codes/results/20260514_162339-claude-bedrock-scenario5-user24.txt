파일 쓰기 권한이 필요합니다. 아래에 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들로 왼쪽 부분 배열 생성
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들로 중간 배열 생성 (중복 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들로 오른쪽 부분 배열 생성

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 결합


if __name__ == "__main__":                             # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 샘플 배열 정의
    print("정렬 전:", sample)                           # 정렬 전 배열 출력
    result = quicksort(sample)                         # 퀵소트 실행
    print("정렬 후:", result)                           # 정렬된 결과 출력
```

**동작 흐름 요약:**

1. **종료 조건** — 원소가 1개 이하면 바로 반환
2. **피벗 선택** — 배열 중간값을 기준으로 설정
3. **분할** — 피벗 기준으로 `left / middle / right` 세 그룹으로 나눔
4. **재귀 결합** — `left`와 `right`를 각각 재귀 정렬 후 합침

**시간 복잡도:** 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
