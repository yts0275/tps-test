```python
def quicksort(arr):                                        # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                      # 리스트 길이가 1 이하면 이미 정렬된 상태
        return arr                                         # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                             # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                  # 피벗보다 작은 원소들을 왼쪽 리스트로 분류
    middle = [x for x in arr if x == pivot]               # 피벗과 같은 원소들을 가운데 리스트로 분류 (중복 처리)
    right = [x for x in arr if x > pivot]                 # 피벗보다 큰 원소들을 오른쪽 리스트로 분류

    return quicksort(left) + middle + quicksort(right)     # 왼쪽, 가운데, 오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                                 # 직접 실행 시에만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                         # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", data)                                # 정렬 전 리스트 출력
    result = quicksort(data)                               # 퀵소트 실행
    print("정렬 후:", result)                              # 정렬 후 리스트 출력
```

**동작 설명:**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 배열 중간 원소를 기준으로 삼음 |
| 분할 | 피벗보다 작은/같은/큰 원소를 각각 `left`, `middle`, `right`로 나눔 |
| 재귀 | `left`와 `right`에 대해 동일한 과정을 반복 |
| 병합 | 정렬된 세 부분을 이어 붙여 반환 |

`[3, 6, 8, 10, 1, 2, 1]` 입력 시 출력: `[1, 1, 2, 3, 6, 8, 10]`
