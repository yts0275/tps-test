```python
def quicksort(arr):                                    # 정렬할 리스트를 받는 함수 정의
    if len(arr) <= 1:                                  # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소들을 가운데 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right) # 왼쪽·오른쪽을 각각 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 정렬 대상 리스트
    print("정렬 전:", sample)                           # 정렬 전 리스트 출력
    result = quicksort(sample)                         # 퀵소트 실행
    print("정렬 후:", result)                           # 정렬 결과 출력
```

**동작 흐름 요약:**

| 단계 | 내용 |
|------|------|
| 피벗 선택 | 중간 인덱스 원소 |
| 분할 | `left` / `middle` / `right` 3-way 분할 (중복값 안전 처리) |
| 재귀 | `left`와 `right`를 각각 재귀 정렬 |
| 합병 | 세 부분을 이어붙여 반환 |

- **시간복잡도**: 평균 O(n log n), 최악 O(n²) (이미 정렬된 배열 + 끝 원소 피벗 시)
- 중간 인덱스를 피벗으로 쓰면 정렬된 입력에서도 최악 케이스를 피할 수 있어 실용적입니다.
