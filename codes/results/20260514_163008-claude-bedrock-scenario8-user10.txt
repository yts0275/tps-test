## LangGraph Workflow 노드 흐름 상세 설명

---

### 노드 구성

| 노드 | 종류 | 역할 |
|------|------|------|
| `start` | Entry Point | 워크플로우 진입점 |
| `SoftwareEngineer` | Agent Node | 중앙 오케스트레이터 |
| `CodeAnalyzer` | Agent Node | 코드 분석 전담 |
| `Editor` | Agent Node | 코드 편집/테스트 전담 |
| `swe_tool` | Tool Node | SWE 전용 도구 |
| `code_analysis_tool` | Tool Node | 코드 분석 도구 |
| `code_edit_tool` | Tool Node | 코드 편집 도구 |
| `test_tool` | Tool Node | 테스트 실행 도구 |
| `end` | Exit Point | 워크플로우 종료점 |

---

### 전체 흐름

```
start → SoftwareEngineer
```

워크플로우는 `SoftwareEngineer`에서 시작되며, 이 노드가 **중앙 라우터(Router)** 역할을 한다.

---

### SoftwareEngineer → 분기 (Conditional Routing)

`SoftwareEngineer`는 현재 상태(state)를 판단해 다음 4가지 경로 중 하나로 분기한다.

#### 1. `analyze_code` → `CodeAnalyzer`
- **조건:** 코드를 분석해야 하는 작업이 필요할 때
- `CodeAnalyzer`로 제어권이 넘어간다.

#### 2. `edit_file` → `Editor`
- **조건:** 파일 편집/수정이 필요할 때
- `Editor`로 제어권이 넘어간다.

#### 3. `swe_tool` 직접 호출
- **조건:** SoftwareEngineer가 직접 swe_tool을 사용해야 할 때
- 도구 실행 후 `continue`를 통해 `SoftwareEngineer`로 복귀

#### 4. `end`
- **조건:** 모든 작업이 완료됐다고 판단될 때
- 워크플로우가 종료된다.

---

### CodeAnalyzer 서브루프

```
SoftwareEngineer --analyze_code--> CodeAnalyzer
                                        ↕ (dashed, loop)
                                   code_analysis_tool
                                        ↓ done
                               SoftwareEngineer
```

1. `CodeAnalyzer`가 분석 작업을 수행
2. 필요 시 `code_analysis_tool`을 **반복 호출** (점선 = tool call)
3. `code_analysis_tool` 실행 결과가 돌아오면 `continue`로 다시 `CodeAnalyzer`로 복귀 → 필요 시 반복
4. 분석이 완료되면 `done` 엣지를 통해 `SoftwareEngineer`로 복귀

---

### Editor 서브루프

```
SoftwareEngineer --edit_file--> Editor
                                    ↕ (dashed, loop)
                          code_edit_tool / test_tool
                                    ↓ done
                            SoftwareEngineer
```

1. `Editor`가 편집 또는 테스트 작업 수행
2. `code_edit_tool` 또는 `test_tool`을 **반복 호출** 가능 (둘 다 사용 가능)
3. 도구 실행 후 `continue`로 `Editor`에 복귀 → 필요 시 반복 (예: 수정 → 테스트 → 재수정)
4. 작업 완료 시 `done`으로 `SoftwareEngineer`에 복귀

---

### 핵심 패턴 요약

```
SoftwareEngineer (Router)
    ├── analyze_code  → [CodeAnalyzer ⟷ code_analysis_tool] → done → 복귀
    ├── edit_file     → [Editor ⟷ code_edit_tool/test_tool]  → done → 복귀
    ├── swe_tool      → [swe_tool] → continue → 복귀
    └── end           → 종료
```

- **실선 화살표**: 에이전트 간 상태 전이 (state transition)
- **점선 화살표**: 도구 호출 및 결과 반환 (tool call / return)
- `SoftwareEngineer`는 각 서브루프 완료 후 다시 판단하여 루프를 반복하거나 종료한다. 이 구조는 **ReAct(Reason + Act) 패턴**을 멀티-에이전트로 확장한 형태다.
