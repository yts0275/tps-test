아래는 각 줄에 주석을 단 Python 퀵소트 구현입니다.

```python
def quicksort(arr):                                   # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                 # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                    # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                        # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소들로 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                            # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                  # 테스트용 입력 리스트 정의
    print("정렬 전:", sample)                          # 정렬 전 리스트 출력
    result = quicksort(sample)                        # 퀵소트 실행 후 결과 저장
    print("정렬 후:", result)                          # 정렬된 결과 출력
```

**동작 방식:**
1. 피벗을 기준으로 리스트를 `left / middle / right` 세 파트로 분리
2. `left`와 `right`를 재귀적으로 다시 퀵소트 호출
3. 정렬된 세 파트를 합쳐서 반환

**시간 복잡도:** 평균 O(n log n), 최악 O(n²) (피벗이 항상 최솟값/최댓값일 때)
