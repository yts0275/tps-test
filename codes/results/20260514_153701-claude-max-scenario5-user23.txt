파일 쓰기가 거부되었으니 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                  # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택

    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 리스트로 분리
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트로 분리
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들을 오른쪽 리스트로 분리

    return quicksort(left) + middle + quicksort(right) # 왼쪽/오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                             # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 샘플 리스트 선언
    print("정렬 전:", sample)                           # 정렬 전 리스트 출력
    result = quicksort(sample)                         # 퀵소트 함수 호출
    print("정렬 후:", result)                           # 정렬 결과 출력
```

**동작 설명:**

| 단계 | 역할 |
|------|------|
| 기저 조건 | 길이 ≤ 1이면 즉시 반환 |
| 피벗 선택 | 중간 인덱스 원소 사용 (최악의 경우 방지) |
| 분할 | `left` / `middle` / `right` 3개 리스트로 분리 |
| 정복 | 왼쪽·오른쪽을 재귀 호출 후 병합 |

실행 결과: `정렬 전: [3, 6, 8, 10, 1, 2, 1]` → `정렬 후: [1, 1, 2, 3, 6, 8, 10]`

평균 시간복잡도 **O(n log n)**, 피벗이 항상 최솟값/최댓값일 경우 최악 **O(n²)** 입니다.
