파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소들로 중간 리스트 생성 (중복값 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                             # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                           # 정렬 전 리스트 출력
    result = quicksort(sample)                         # 퀵소트 호출, 결과를 result에 저장
    print("정렬 후:", result)                           # 정렬 후 리스트 출력
```

**동작 방식 요약:**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 배열 중간 원소를 기준으로 설정 |
| 분할 | 피벗보다 작은 것 → left, 같은 것 → middle, 큰 것 → right |
| 재귀 | left, right에 대해 반복적으로 퀵소트 적용 |
| 합산 | 세 부분을 합쳐 최종 정렬 결과 반환 |

**시간 복잡도:** 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
