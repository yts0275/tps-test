파일 쓰기 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                # 기저 조건: 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료)

    pivot = arr[len(arr) // 2]                       # 피벗 선택: 리스트 중간 인덱스의 값을 피벗으로 사용
    left = [x for x in arr if x < pivot]             # 왼쪽 파티션: 피벗보다 작은 원소들만 모음
    middle = [x for x in arr if x == pivot]          # 중간 파티션: 피벗과 같은 원소들만 모음 (중복값 처리)
    right = [x for x in arr if x > pivot]            # 오른쪽 파티션: 피벗보다 큰 원소들만 모음

    return quicksort(left) + middle + quicksort(right)  # 재귀 호출: 각 파티션을 정렬 후 합쳐서 반환


if __name__ == "__main__":                           # 직접 실행 시에만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                 # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                         # 정렬 전 리스트 출력
    result = quicksort(sample)                       # 퀵소트 함수 호출
    print("정렬 후:", result)                         # 정렬 후 결과 출력
```

**핵심 동작 원리:**
- **피벗(pivot)**: 리스트를 나누는 기준값. 여기서는 중간 인덱스 사용.
- **파티션 3분할**: `left`(피벗 미만) / `middle`(피벗 동일) / `right`(피벗 초과)로 분리.
- **재귀**: `left`와 `right`를 다시 `quicksort`로 정렬 → 분할정복(Divide & Conquer).
- **시간복잡도**: 평균 O(n log n), 최악(이미 정렬된 경우) O(n²).

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
