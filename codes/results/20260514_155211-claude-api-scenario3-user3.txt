파일 쓰기 권한이 없으므로 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                               # 퀵소트 함수 정의, 배열을 인자로 받음
    if len(arr) <= 1:                             # 배열 길이가 1 이하이면 이미 정렬된 상태
        return arr                                # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                    # 배열 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 원소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 원소들을 middle 리스트에 수집
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 원소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # left와 right를 재귀 정렬 후 middle과 합쳐 반환


if __name__ == "__main__":                        # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]              # 테스트용 정렬되지 않은 샘플 배열 정의
    print("정렬 전:", sample)                     # 정렬 전 배열 출력
    result = quicksort(sample)                    # 퀵소트 함수 호출, 결과를 result에 저장
    print("정렬 후:", result)                     # 정렬 후 배열 출력
```

**동작 원리:**

1. **피벗 선택** — 배열 중간값을 기준점으로 고름
2. **분할** — 피벗 기준으로 작은 값(`left`), 같은 값(`middle`), 큰 값(`right`)으로 나눔
3. **재귀** — `left`와 `right`에 동일한 과정을 반복
4. **병합** — 정렬된 세 부분을 순서대로 합쳐 반환

실행 결과:
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
