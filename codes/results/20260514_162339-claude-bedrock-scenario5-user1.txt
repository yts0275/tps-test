## 퀵소트 구현 (Python)

### 1. 새 리스트 반환 방식 (simple)

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 파티션에 수집
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 파티션에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들을 오른쪽 파티션에 수집

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환
```

### 2. 제자리(in-place) 방식 (메모리 효율적)

```python
def quicksort_inplace(arr, low, high):                 # 제자리 퀵소트: 추가 메모리 없이 정렬
    if low < high:                                     # 정렬 범위가 2개 이상 원소를 포함할 때만 실행
        pivot_idx = partition(arr, low, high)          # 파티션 분할 후 피벗의 최종 위치 반환
        quicksort_inplace(arr, low, pivot_idx - 1)     # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)    # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):                         # 배열을 피벗 기준으로 두 파티션으로 분할
    pivot = arr[high]                                  # 마지막 원소를 피벗으로 지정
    i = low - 1                                        # i: 피벗보다 작은 영역의 마지막 인덱스 (초기값: 범위 밖)

    for j in range(low, high):                         # j: 현재 검사 중인 인덱스, low~high-1 순회
        if arr[j] <= pivot:                            # 현재 원소가 피벗 이하이면 왼쪽 파티션으로 이동
            i += 1                                     # 작은 영역을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]            # i 위치와 j 위치의 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]      # 피벗을 최종 위치(i+1)로 이동
    return i + 1                                       # 피벗의 최종 인덱스 반환
```

### 사용 예시

```python
sample = [3, 6, 8, 10, 1, 2, 1]

# 새 리스트 방식
print(quicksort(sample))               # [1, 1, 2, 3, 6, 8, 10]

# 제자리 방식
arr = sample[:]
quicksort_inplace(arr, 0, len(arr) - 1)
print(arr)                             # [1, 1, 2, 3, 6, 8, 10]
```

---

**두 방식의 차이:**

| | 새 리스트 방식 | 제자리 방식 |
|---|---|---|
| 공간 복잡도 | O(n) 추가 메모리 | O(log n) 스택만 사용 |
| 코드 가독성 | 높음 | 중간 |
| 시간 복잡도 | 평균 O(n log n) | 평균 O(n log n) |
