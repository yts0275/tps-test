파일 생성이 거부되었으므로 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의, 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                # 리스트 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 피벗을 리스트 중간 원소로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 리스트에 모음
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트에 모음 (중복값 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 리스트에 모음

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 각각 재귀 정렬 후 합쳐서 반환


def quicksort_inplace(arr, low, high):               # 제자리(in-place) 퀵소트, 추가 메모리 없이 정렬
    if low < high:                                   # 정렬 구간에 원소가 2개 이상일 때만 진행
        pivot_idx = partition(arr, low, high)        # 파티션 수행 후 피벗의 최종 위치를 받음
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 구간 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 구간 재귀 정렬


def partition(arr, low, high):                       # 피벗 기준으로 원소를 좌우로 나누는 함수
    pivot = arr[high]                                # 오른쪽 끝 원소를 피벗으로 선택
    i = low - 1                                      # i는 피벗보다 작은 원소들의 마지막 위치 추적

    for j in range(low, high):                       # j로 low부터 high 직전까지 순회
        if arr[j] <= pivot:                          # 현재 원소가 피벗 이하이면
            i += 1                                   # 작은 원소 영역을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]          # 현재 원소를 작은 원소 영역 끝으로 스왑

    arr[i + 1], arr[high] = arr[high], arr[i + 1]   # 피벗을 최종 위치(작은 영역 바로 뒤)에 배치
    return i + 1                                     # 피벗의 최종 인덱스 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                 # 정렬할 샘플 리스트 정의
    print("원본:", sample)                            # 정렬 전 출력
    sorted_arr = quicksort(sample)                   # 퀵소트 실행
    print("정렬 후:", sorted_arr)                    # 정렬 결과 출력 → [1, 1, 2, 3, 6, 8, 10]

    sample2 = [3, 6, 8, 10, 1, 2, 1]                # 제자리 정렬용 샘플 리스트
    print("\n원본:", sample2)                         # 정렬 전 출력
    quicksort_inplace(sample2, 0, len(sample2) - 1) # 제자리 퀵소트 실행 (0 ~ 마지막 인덱스)
    print("정렬 후:", sample2)                       # 원본 리스트가 직접 수정되어 출력됨
```

---

두 가지 구현 방식을 제공했습니다.

| 방식 | 함수 | 특징 |
|------|------|------|
| **리스트 반환** | `quicksort()` | 새 리스트 생성, 코드 간결, 추가 메모리 O(n) 사용 |
| **제자리 정렬** | `quicksort_inplace()` | 원본 리스트 직접 수정, 추가 메모리 O(log n) (재귀 스택만) |

**시간 복잡도**: 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
