파일 작성 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, 리스트를 인자로 받음
    if len(arr) <= 1:                                  # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들을 왼쪽 리스트로 분류
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트로 분류
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들을 오른쪽 리스트로 분류

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 병합


def quicksort_inplace(arr, low, high):                 # 제자리(in-place) 퀵소트: 추가 메모리 없이 정렬
    if low < high:                                     # 정렬 범위가 2개 이상일 때만 진행
        pivot_idx = partition(arr, low, high)          # 파티션 수행 후 피벗의 최종 위치를 받음
        quicksort_inplace(arr, low, pivot_idx - 1)    # 피벗 왼쪽 구간을 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)   # 피벗 오른쪽 구간을 재귀 정렬


def partition(arr, low, high):                         # 파티션 함수: 피벗 기준으로 배열을 두 구간으로 나눔
    pivot = arr[high]                                  # 마지막 원소를 피벗으로 선택
    i = low - 1                                        # i는 피벗보다 작은 원소 구간의 끝 인덱스

    for j in range(low, high):                         # low부터 high 직전까지 순회
        if arr[j] <= pivot:                            # 현재 원소가 피벗 이하이면
            i += 1                                     # 작은 원소 구간을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]           # i 위치와 j 위치의 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]    # 피벗을 올바른 위치(i+1)로 이동
    return i + 1                                       # 피벗의 최종 인덱스 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 입력 리스트
    print("원본:", data)                               # 정렬 전 출력

    result = quicksort(data)                           # 새 리스트를 반환하는 방식으로 정렬
    print("퀵소트(반환):", result)                     # 정렬 결과 출력

    data2 = [3, 6, 8, 10, 1, 2, 1]                    # 제자리 정렬을 위한 별도 리스트
    quicksort_inplace(data2, 0, len(data2) - 1)       # 제자리 방식으로 정렬 (반환값 없음)
    print("퀵소트(제자리):", data2)                    # 정렬된 리스트 출력
```

---

두 가지 방식으로 구현했습니다.

**`quicksort` (반환 방식)** — 리스트 컴프리헨션으로 피벗 기준 세 구간을 만들고 재귀 병합. 코드가 간결하지만 O(n) 추가 메모리를 사용합니다.

**`quicksort_inplace` (제자리 방식)** — `partition` 함수로 원본 배열 내에서 원소를 교환. 추가 메모리 없이 O(log n) 스택 공간만 사용합니다.
