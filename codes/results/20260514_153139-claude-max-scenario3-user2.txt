`quicksort.py` 파일 작성이 차단되었습니다. 대신 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                    # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                          # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들로 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                      # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", data)                              # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                       # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", sorted_data)                      # 정렬 후 결과 출력
```

**동작 방식:**
1. **피벗 선택** — 리스트 중간값을 기준점(pivot)으로 사용
2. **분할** — 피벗보다 작은 값(`left`), 같은 값(`middle`), 큰 값(`right`)으로 분리
3. **재귀** — `left`와 `right`에 동일 과정 반복, 원소가 1개 이하이면 종료
4. **병합** — 정렬된 세 부분을 순서대로 이어붙여 반환

시간복잡도는 평균 **O(n log n)**, 최악(이미 정렬된 경우) **O(n²)** 입니다.
