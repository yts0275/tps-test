파일 쓰기 권한이 없어서, 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                    # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                           # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 원소들을 중간 리스트에 수집
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 + 중간 + 오른쪽 재귀를 합쳐 반환


if __name__ == "__main__":                              # 이 파일을 직접 실행할 때만 아래 코드 실행
    data = [3, 6, 8, 10, 1, 2, 1]                      # 정렬할 예시 데이터 리스트 정의
    print("정렬 전:", data)                              # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                       # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", sorted_data)                      # 정렬된 결과 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**핵심 동작 원리:**
- **피벗 선택**: 배열 중간값을 피벗으로 설정
- **분할**: 피벗 기준으로 작은 값(left), 같은 값(middle), 큰 값(right)으로 나눔
- **재귀**: left와 right에 대해 동일 과정을 반복, 크기 1 이하면 종료
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)
