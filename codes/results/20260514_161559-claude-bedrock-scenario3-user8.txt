퀵소트 구현 코드입니다:

```python
def quicksort(arr):                          # 퀵소트 함수 정의: 리스트를 입력받아 정렬된 리스트 반환
    if len(arr) <= 1:                        # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀의 기저 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 왼쪽 파티션으로 분류
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 파티션으로 분류 (중복값 처리)
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 오른쪽 파티션으로 분류

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 합쳐서 반환
```

**동작 방식 요약:**
- **피벗 선택** → 배열 중간값을 기준점으로 사용
- **분할(Partition)** → 피벗보다 작은/같은/큰 원소를 세 그룹으로 나눔
- **재귀(Conquer)** → 왼쪽·오른쪽 파티션을 각각 재귀적으로 정렬 후 합침

**시간복잡도:** 평균 O(n log n), 최악 O(n²) (이미 정렬된 경우)
