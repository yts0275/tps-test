```python
def quicksort(arr):
    if len(arr) <= 1:  # 원소가 1개 이하이면 이미 정렬된 상태이므로 그대로 반환
        return arr

    pivot = arr[len(arr) // 2]  # 배열 중간 인덱스의 값을 피벗으로 선택

    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 원소들을 middle 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 left, right를 정렬한 뒤 middle과 합쳐서 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]  # 테스트용 예시 배열 정의
    print("정렬 전:", sample)          # 정렬 전 배열 출력
    result = quicksort(sample)        # 퀵소트 함수 호출
    print("정렬 후:", result)          # 정렬 후 배열 출력
```

**동작 원리:**

1. **피벗 선택** — 배열 중간값을 피벗으로 선택
2. **분할(Partition)** — 피벗보다 작은 값 / 같은 값 / 큰 값으로 3개 리스트로 분리
3. **재귀 정렬** — left와 right를 재귀적으로 퀵소트, middle은 그대로 유지
4. **합치기** — `quicksort(left) + middle + quicksort(right)` 순으로 병합

**시간복잡도:** 평균 O(n log n), 최악 O(n²)  
**공간복잡도:** O(n) (리스트 컴프리헨션으로 새 리스트 생성)
