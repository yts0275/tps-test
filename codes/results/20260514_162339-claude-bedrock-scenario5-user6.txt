**새 리스트 반환 방식 (함수형)**

```python
def quicksort(arr):                          # 퀵소트 함수 정의: 리스트를 입력받아 정렬된 리스트 반환
    if len(arr) <= 1:                        # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 원소들을 왼쪽 부분 리스트로
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 리스트로 (중복 처리)
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 오른쪽 부분 리스트로

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 + 중간 + 오른쪽 재귀 합쳐 반환
```

**제자리(in-place) 방식 (메모리 효율적)**

```python
def quicksort_inplace(arr, low, high):      # 제자리 퀵소트: 추가 메모리 없이 정렬
    if low < high:                           # 정렬 범위에 원소가 2개 이상일 때만 진행
        pivot_idx = partition(arr, low, high) # 피벗을 올바른 위치에 놓고 인덱스 반환
        quicksort_inplace(arr, low, pivot_idx - 1)  # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high) # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):              # 분할 함수: 피벗 기준으로 배열을 두 구간으로 나눔
    pivot = arr[high]                        # 마지막 원소를 피벗으로 선택
    i = low - 1                              # i는 피벗보다 작은 영역의 마지막 인덱스

    for j in range(low, high):              # j로 low부터 high-1까지 순회
        if arr[j] <= pivot:                  # 현재 원소가 피벗 이하이면
            i += 1                           # 작은 영역을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i] # i 위치와 j 위치 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치(i+1)로 이동
    return i + 1                             # 피벗의 최종 인덱스 반환
```

---

두 가지 방식을 제공했습니다. **함수형**은 코드가 간결하지만 리스트 복사로 메모리를 더 쓰고, **제자리 방식**은 메모리 효율적이지만 원본 배열이 수정됩니다. 파일로 저장을 원하시면 말씀해 주세요.
