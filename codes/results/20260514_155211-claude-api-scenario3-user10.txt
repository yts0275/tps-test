파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                    # 리스트 길이가 1 이하면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                           # 중간 인덱스 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 요소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 요소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 요소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                               # 이 파일을 직접 실행할 때만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                       # 테스트용 정렬 대상 리스트 정의
    print("정렬 전:", data)                              # 정렬 전 원본 리스트 출력
    sorted_data = quicksort(data)                        # 퀵소트 함수 호출해 정렬 결과 저장
    print("정렬 후:", sorted_data)                       # 정렬된 결과 리스트 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**핵심 동작 요약:**
- **피벗 선택**: 리스트 중간 요소를 기준으로 분할
- **3-way 분할**: `left` (피벗 미만) / `middle` (피벗 동일) / `right` (피벗 초과) — 중복값도 올바르게 처리
- **재귀 정렬**: left, right를 재귀 호출하여 정렬 후 합침
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)
