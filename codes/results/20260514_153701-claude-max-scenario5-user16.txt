파일 생성 권한이 거부되었으므로 코드를 직접 보여드립니다.

```python
def quicksort(arr):                             # 퀵소트 함수 정의 (정렬할 배열을 인자로 받음)
    if len(arr) <= 1:                           # 배열 길이가 1 이하이면 이미 정렬된 상태
        return arr                              # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                 # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]       # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]    # 피벗과 같은 원소들을 가운데 리스트에 수집
    right = [x for x in arr if x > pivot]      # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 합쳐 반환


def quicksort_inplace(arr, low, high):         # 제자리 정렬 버전 (원본 배열 직접 정렬)
    if low < high:                             # 정렬 범위가 2개 이상 원소를 포함할 때만 실행
        pivot_idx = partition(arr, low, high)  # 분할 수행 후 피벗의 최종 인덱스를 받음
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):                 # 배열을 피벗 기준으로 두 부분으로 나누는 함수
    pivot = arr[high]                          # 마지막 원소를 피벗으로 선택
    i = low - 1                                # i는 피벗보다 작은 영역의 오른쪽 경계

    for j in range(low, high):                 # j를 low부터 high-1까지 순회
        if arr[j] <= pivot:                    # 현재 원소가 피벗 이하이면
            i += 1                             # 작은 영역 경계를 오른쪽으로 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]   # 경계 원소와 현재 원소 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 최종 위치로 이동
    return i + 1                               # 피벗의 최종 인덱스 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]           # 테스트용 예시 배열
    print("원본:", sample)                      # 정렬 전 배열 출력

    result = quicksort(sample)                 # 새 리스트 반환 방식으로 정렬
    print("정렬 후 (새 리스트):", result)        # 정렬 결과 출력

    quicksort_inplace(sample, 0, len(sample) - 1)  # 제자리 정렬로 원본 배열 직접 정렬
    print("정렬 후 (제자리):", sample)           # 정렬된 원본 배열 출력
```

두 가지 버전을 구현했습니다.

| 버전 | 방식 | 특징 |
|------|------|------|
| `quicksort` | 새 리스트 반환 | 코드 간결, 가독성 좋음, 메모리 O(n log n) |
| `quicksort_inplace` | 원본 배열 직접 수정 | 메모리 효율적 O(log n), `partition` 함수 필요 |

- **평균 시간 복잡도**: O(n log n)
- **최악 시간 복잡도**: O(n²) — 이미 정렬된 배열에서 발생
