아래는 주석이 달린 퀵소트 구현입니다:

```python
def quicksort(arr):                              # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                            # 원소가 1개 이하면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 부분 리스트로 수집
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 리스트로 수집 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 부분 리스트로 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]               # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", data)                       # 정렬 전 리스트 출력
    result = quicksort(data)                     # 퀵소트 함수 호출
    print("정렬 후:", result)                     # 정렬된 결과 출력
```

**동작 방식 요약:**
1. **피벗 선택** — 배열 중간 원소를 피벗으로 사용
2. **분할** — 피벗 기준으로 작은 값(`left`), 같은 값(`middle`), 큰 값(`right`)으로 나눔
3. **재귀 정렬** — `left`와 `right`에 같은 과정을 반복
4. **합치기** — 재귀가 끝난 세 부분을 순서대로 이어붙임

평균 시간복잡도는 **O(n log n)**, 최악(이미 정렬된 배열에서 나쁜 피벗 선택)은 **O(n²)** 입니다.
