파일 작성 권한이 없어 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 배열을 입력받음
    if len(arr) <= 1:                            # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]                   # 배열 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 원소들을 왼쪽 배열로 분리
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 원소들을 중간 배열로 분리 (중복 처리)
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 원소들을 오른쪽 배열로 분리

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]             # 정렬할 예시 배열 정의
    print("정렬 전:", sample)                    # 정렬 전 배열 출력
    result = quicksort(sample)                   # 퀵소트 실행
    print("정렬 후:", result)                    # 정렬 후 배열 출력
```

**동작 흐름:**

1. 피벗을 기준으로 배열을 `left / middle / right` 세 부분으로 분리
2. `left`와 `right`에 대해 재귀 호출
3. 정렬된 결과를 합쳐 반환

**시간복잡도:** 평균 O(n log n), 최악(이미 정렬된 배열) O(n²)
