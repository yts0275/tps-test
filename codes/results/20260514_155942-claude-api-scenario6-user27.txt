1. **상품 관리 시스템**: `Product`, `Order`, `InventoryManager` 세 클래스로 구성된 IT 인프라 장비(서버 랙, 스위치, 케이블 등) 재고 관리 프로그램이다.

2. **주문 처리 로직**: 주문 시 `update_stock`으로 재고를 차감하며, 재고 부족 시 주문을 거부하는 유효성 검사와 영수증 출력 기능을 포함한다.

3. **실행 흐름**: 초기 상품 등록 → 재고 확인 → 정상 주문(ORD-2024-001) 처리 → 재고 부족 주문(ORD-2024-002) 실패 → 최종 재고 및 창고 자산 가치 출력 순으로 동작한다.
