```python
def quicksort(arr):                                  # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 피벗을 리스트 중앙 원소로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 부분 리스트로 구성
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트로 구성 (중복값 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 부분 리스트로 구성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                           # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                 # 테스트용 정렬 전 리스트 정의
    print("정렬 전:", sample)                        # 정렬 전 리스트 출력
    result = quicksort(sample)                       # 퀵소트 함수 호출
    print("정렬 후:", result)                        # 정렬 결과 출력
```

**동작 방식:**

1. **피벗 선택** — 중앙 인덱스 원소를 피벗으로 사용
2. **분할** — 피벗 기준으로 `left` / `middle` / `right` 세 리스트로 분리
3. **재귀 정렬** — `left`와 `right`를 재귀 호출로 정렬
4. **합병** — 정렬된 세 부분을 이어 붙여 반환

시간 복잡도는 평균 **O(n log n)**, 최악(이미 정렬된 경우) **O(n²)** 입니다. 파일로 저장을 원하시면 쓰기 권한을 허용해 주세요.
