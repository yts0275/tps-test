파일 생성 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 리스트 길이가 1 이하이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 피벗 선택: 리스트 중앙 요소를 기준값으로 설정
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 요소만 모아 왼쪽 리스트 생성
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 요소만 모아 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 요소만 모아 오른쪽 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 결합


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]             # 정렬 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                    # 정렬 전 리스트 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)                    # 정렬된 결과 리스트 출력
```

**동작 설명:**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 중앙 인덱스 요소를 기준값으로 사용 |
| 분할 | 피벗 기준으로 작은 값(left), 같은 값(middle), 큰 값(right) 세 그룹으로 나눔 |
| 재귀 | left, right를 각각 재귀 호출하여 정렬 |
| 합병 | 세 리스트를 순서대로 이어 붙여 최종 반환 |

실행 결과:
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
