두 가지 방식으로 구현한 퀵소트입니다.

---

## 방식 1: 새 배열 반환 (직관적)

```python
def quicksort(arr):                              # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                            # 원소가 1개 이하면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 배열로
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 배열로
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 배열로

    return quicksort(left) + middle + quicksort(right)  # 왼쪽, 중간, 오른쪽을 재귀 정렬 후 합쳐서 반환
```

## 방식 2: 제자리(in-place) 정렬 (메모리 효율적)

```python
def quicksort_inplace(arr, low, high):           # 제자리 퀵소트, low/high는 정렬 범위
    if low < high:                               # 정렬 범위가 2개 이상일 때만 실행
        pivot_idx = partition(arr, low, high)    # 파티션 수행 후 피벗의 최종 위치 획득
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):                   # 배열을 피벗 기준으로 두 부분으로 나누는 함수
    pivot = arr[high]                            # 마지막 원소를 피벗으로 선택
    i = low - 1                                  # 피벗보다 작은 원소들의 경계 인덱스 초기화

    for j in range(low, high):                   # low부터 high 직전까지 순회
        if arr[j] <= pivot:                      # 현재 원소가 피벗 이하이면
            i += 1                               # 경계 인덱스를 오른쪽으로 한 칸 이동
            arr[i], arr[j] = arr[j], arr[i]      # 경계 원소와 현재 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치(경계 + 1)로 이동
    return i + 1                                 # 피벗의 최종 인덱스 반환
```

---

| 방식 | 시간복잡도 (평균) | 시간복잡도 (최악) | 공간복잡도 |
|------|---|---|---|
| 새 배열 반환 | O(n log n) | O(n²) | O(n) |
| 제자리 정렬 | O(n log n) | O(n²) | O(log n) |
