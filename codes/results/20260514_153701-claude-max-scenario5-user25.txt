```python
def quicksort(arr):                          # 퀵소트 함수 정의: 리스트를 입력받음
    if len(arr) <= 1:                        # 원소가 1개 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스의 원소를 피벗으로 선택

    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 리스트에 수집
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/중간/오른쪽을 재귀 정렬 후 합쳐 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]         # 정렬할 예시 리스트 정의
    print("정렬 전:", sample)                # 정렬 전 리스트 출력
    result = quicksort(sample)              # 퀵소트 함수 호출
    print("정렬 후:", result)               # 정렬 후 결과 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리 요약:**
- **피벗 선택**: 배열 중간 원소를 피벗으로 사용
- **분할**: 피벗 기준으로 작은 것(`left`), 같은 것(`middle`), 큰 것(`right`)으로 나눔
- **재귀**: `left`와 `right`를 재귀적으로 정렬 후 합침
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)
