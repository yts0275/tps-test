파일 작성 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 리스트 길이가 1 이하이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀의 기저 조건)

    pivot = arr[len(arr) // 2]                   # 피벗: 리스트 중간 원소를 선택

    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소만 모아 왼쪽 리스트 생성
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소만 모아 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소만 모아 오른쪽 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]              # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", data)                      # 정렬 전 리스트 출력
    result = quicksort(data)                     # 퀵소트 실행
    print("정렬 후:", result)                    # 정렬된 결과 출력
```

**동작 방식:**
- 피벗을 기준으로 작은 값 / 같은 값 / 큰 값 세 그룹으로 분리
- 왼쪽·오른쪽 그룹을 재귀적으로 정렬한 뒤 합침
- 평균 시간복잡도 **O(n log n)**, 최악(이미 정렬된 경우) **O(n²)**
