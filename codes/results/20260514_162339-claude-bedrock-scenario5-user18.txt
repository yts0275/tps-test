```python
def quicksort(arr):                                      # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                    # 리스트 길이가 1 이하면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                           # 중간 인덱스 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 요소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 요소들로 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 요소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                               # 직접 실행 시에만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                       # 테스트용 정렬 대상 리스트 정의
    print("정렬 전:", data)                               # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                        # 퀵소트 함수 호출하여 정렬 결과 저장
    print("정렬 후:", sorted_data)                        # 정렬 후 리스트 출력
```

**핵심 동작 흐름:**

1. **피벗 선택** — 중간 인덱스 요소를 기준으로 선택
2. **분할(Partition)** — 피벗보다 작으면 `left`, 같으면 `middle`, 크면 `right`로 분류
3. **재귀 정렬** — `left`와 `right`를 각각 재귀 호출로 정렬
4. **병합** — 세 리스트를 순서대로 이어붙여 반환

**시간 복잡도:** 평균 O(n log n), 최악 O(n²) (이미 정렬된 경우)
