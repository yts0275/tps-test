파일 쓰기 권한이 없어서 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                   # 퀵소트 함수 정의: 리스트를 받아 정렬된 리스트를 반환
    if len(arr) <= 1:                                 # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                    # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]                        # 피벗을 리스트 중간 원소로 선택

    left   = [x for x in arr if x < pivot]            # 피벗보다 작은 원소만 모아 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소만 모아 중간 리스트 생성 (중복 처리)
    right  = [x for x in arr if x > pivot]            # 피벗보다 큰 원소만 모아 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                            # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                  # 테스트용 샘플 리스트
    print("정렬 전:", sample)                          # 정렬 전 리스트 출력
    result = quicksort(sample)                        # 퀵소트 실행
    print("정렬 후:", result)                          # 정렬 후 리스트 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**동작 방식 요약:**
1. 리스트 중간값을 **피벗**으로 선택
2. 피벗보다 작은 것 / 같은 것 / 큰 것으로 **3분할**
3. 작은 쪽과 큰 쪽을 각각 **재귀 호출**로 정렬
4. 결과를 **합쳐서 반환**

중복 원소를 `middle` 리스트로 별도 처리해서 안전하게 동작합니다.
