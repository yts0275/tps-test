1. **상품 재고 관리 시스템**: `Product`, `Order`, `InventoryManager` 세 클래스로 구성된 간단한 재고·주문 관리 프로그램으로, 네트워크 장비(서버 랙, 스위치, 케이블 등)를 상품으로 다룬다.

2. **핵심 로직**: 주문 시 `update_stock`으로 재고를 차감하며, 재고 부족 시 주문을 거부하는 유효성 검사를 포함하고 영수증(`print_invoice`)을 출력한다.

3. **실행 흐름**: `run_system()`에서 초기 데이터 설정 → 재고 확인 → 정상 주문(ORD-001) 처리 → 재고 부족 주문(ORD-002) 거부 → 최종 재고 및 창고 자산 가치 리포트 출력 순으로 동작한다.
