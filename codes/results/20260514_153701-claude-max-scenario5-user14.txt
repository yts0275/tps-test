아래는 주석이 달린 퀵소트 구현입니다:

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, 배열을 인자로 받음
    if len(arr) <= 1:                                  # 배열 길이가 1 이하이면 더 이상 분할 불필요
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 배열 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 요소들로 왼쪽 배열 구성
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 요소들로 중간 배열 구성
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 요소들로 오른쪽 배열 구성

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 병합 반환


# ── 실행 예시 ──────────────────────────────────────────
data = [3, 6, 8, 10, 1, 2, 1]                         # 정렬할 테스트 배열 정의
print("정렬 전:", data)                                  # 정렬 전 배열 출력
result = quicksort(data)                               # 퀵소트 함수 호출
print("정렬 후:", result)                                # 정렬된 결과 배열 출력
```

**동작 흐름 요약:**

1. **피벗 선택** — 배열 중간값을 피벗으로 사용
2. **분할(Partition)** — 피벗 기준으로 `left / middle / right` 세 그룹으로 나눔
3. **재귀 정렬** — `left`와 `right`를 각각 재귀적으로 정렬
4. **병합** — 정렬된 세 배열을 순서대로 이어붙임

**예상 출력:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
