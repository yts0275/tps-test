파일 쓰기 권한이 필요합니다. 권한을 허용해 주시거나, 코드를 직접 복사해서 사용하셔도 됩니다:

```python
def quicksort(arr):                                      # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                    # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                          # 중간 인덱스 원소를 피벗으로 선택

    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들을 왼쪽 리스트로
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트로 (중복 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들을 오른쪽 리스트로

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 + 중간 + 오른쪽 재귀를 합쳐 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                      # 정렬할 테스트 데이터
    print("정렬 전:", data)                              # 정렬 전 출력
    result = quicksort(data)                            # 퀵소트 실행
    print("정렬 후:", result)                            # 정렬 후 출력
```

**동작 방식:**
1. 피벗(중간값)을 기준으로 `left / middle / right` 세 파트로 분할
2. `left`와 `right`를 재귀적으로 다시 퀵소트
3. 합쳐서 반환

시간복잡도: 평균 O(n log n), 최악 O(n²) / 공간복잡도: O(n)
