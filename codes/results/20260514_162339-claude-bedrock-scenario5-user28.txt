## 퀵소트 구현 (Python)

### 1. 기본 퀵소트 (새 리스트 방식)

```python
def quicksort(arr):                          # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                        # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]               # 피벗을 리스트의 중간 원소로 선택

    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 모아 left 리스트 생성
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 모아 middle 리스트 생성
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 모아 right 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환
```

### 2. 제자리(In-place) 퀵소트

```python
def quicksort_inplace(arr, low, high):       # 제자리 퀵소트: 추가 메모리 없이 원본 리스트 직접 정렬
    if low < high:                           # 정렬 범위가 원소 2개 이상일 때만 진행
        pivot_index = partition(arr, low, high)       # 파티션 수행 후 피벗의 최종 위치를 반환
        quicksort_inplace(arr, low, pivot_index - 1)  # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_index + 1, high) # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):               # 파티션 함수: 피벗 기준으로 원소들을 재배치하고 피벗 인덱스 반환
    pivot = arr[high]                        # 맨 오른쪽 원소를 피벗으로 선택
    i = low - 1                              # i는 피벗보다 작은 원소들의 경계 인덱스 (초기값: 범위 시작 전)

    for j in range(low, high):               # j를 low부터 high-1까지 순회
        if arr[j] <= pivot:                  # 현재 원소가 피벗보다 작거나 같으면
            i += 1                           # 경계 인덱스를 오른쪽으로 한 칸 이동
            arr[i], arr[j] = arr[j], arr[i]  # 경계 위치와 현재 위치의 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 최종 위치(i+1)에 삽입
    return i + 1                             # 피벗의 최종 인덱스 반환
```

### 3. 실행 예시

```python
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]         # 테스트용 샘플 리스트 정의
    print("원본:", sample)                   # 정렬 전 리스트 출력
    print("정렬 후:", quicksort(sample))     # 기본 퀵소트로 정렬한 결과 출력

    sample2 = [3, 6, 8, 10, 1, 2, 1]        # 제자리 정렬용 두 번째 샘플 리스트
    print("\n원본:", sample2)                # 정렬 전 리스트 출력
    quicksort_inplace(sample2, 0, len(sample2) - 1)  # 제자리 퀵소트 수행 (리스트 직접 변경)
    print("정렬 후:", sample2)               # 제자리 정렬 완료 후 리스트 출력
```

---

두 가지 버전을 구현했습니다.

| 방식 | 특징 | 시간복잡도 | 공간복잡도 |
|------|------|-----------|-----------|
| 기본 퀵소트 | 새 리스트 생성, 코드 간결 | 평균 O(n log n) | O(n) |
| 제자리 퀵소트 | 원본 리스트 직접 수정, 메모리 효율적 | 평균 O(n log n) | O(log n) |
