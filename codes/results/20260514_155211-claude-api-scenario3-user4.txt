파일 쓰기 권한이 없어서 코드를 직접 보여드립니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 배열을 입력받아 정렬된 배열을 반환
    if len(arr) <= 1:                            # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스 원소를 피벗으로 선택

    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 부분 배열로 수집
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 배열로 수집 (중복값 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 부분 배열로 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬을 합쳐 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 정렬되지 않은 샘플 배열 정의
    print("정렬 전:", sample)                    # 정렬 전 배열 출력
    result = quicksort(sample)                   # 퀵소트 실행 후 결과를 result에 저장
    print("정렬 후:", result)                    # 정렬 후 배열 출력
```

**동작 원리 요약:**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 배열 중간 원소 선택 |
| 분할 | 피벗 기준으로 left / middle / right 3분할 |
| 재귀 | left, right에 대해 동일 과정 반복 |
| 병합 | 정렬된 세 배열을 이어 붙임 |

- 평균 시간 복잡도: **O(n log n)**
- 최악(이미 정렬된 경우): **O(n²)**
- 중간 피벗 선택으로 최악 케이스 발생 가능성을 낮췄고, `middle` 배열로 중복값을 안전하게 처리합니다.
