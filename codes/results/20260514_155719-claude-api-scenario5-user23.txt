프로젝트가 Python 기반이므로 Python으로 구현합니다.

```python
def quicksort(arr):                          # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                        # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 middle 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # left와 right를 재귀 정렬 후 합쳐 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]           # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", data)                  # 정렬 전 리스트 출력
    result = quicksort(data)                 # 퀵소트 실행
    print("정렬 후:", result)               # 정렬 결과 출력
```

**동작 예시:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**시간복잡도:** 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
