## 퀵소트 구현 (`quicksort.py`)

### 방식 1: 새 리스트 반환 (함수형)

```python
def quicksort(arr):                                  # 퀵소트 함수 정의, arr는 정렬할 리스트
    if len(arr) <= 1:                                # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환
```

### 방식 2: 제자리 정렬 (in-place)

```python
def quicksort_inplace(arr, low, high):               # 제자리 퀵소트 함수, 추가 메모리 미사용
    if low < high:                                   # 정렬 범위에 원소가 2개 이상일 때만 진행
        pivot_idx = partition(arr, low, high)        # 파티션 수행 후 피벗의 최종 위치 반환
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):                       # 피벗 기준으로 배열을 두 부분으로 분리
    pivot = arr[high]                                # 맨 오른쪽 원소를 피벗으로 선택
    i = low - 1                                      # i는 피벗보다 작은 원소들의 마지막 위치 추적

    for j in range(low, high):                       # low부터 high-1까지 순회
        if arr[j] <= pivot:                          # 현재 원소가 피벗 이하면 왼쪽 영역으로 이동
            i += 1                                   # 왼쪽 영역 경계를 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]          # 현재 원소를 왼쪽 영역 끝으로 스왑

    arr[i + 1], arr[high] = arr[high], arr[i + 1]    # 피벗을 올바른 위치(i+1)로 이동
    return i + 1                                     # 피벗의 최종 인덱스 반환
```

### 실행 예시

```python
if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]
    print("원본:", data)                  # 원본: [3, 6, 8, 10, 1, 2, 1]
    print("정렬:", quicksort(data))       # 정렬: [1, 1, 2, 3, 6, 8, 10]

    data2 = [5, 4, 3, 2, 1]
    quicksort_inplace(data2, 0, len(data2) - 1)
    print("정렬:", data2)                 # 정렬: [1, 2, 3, 4, 5]
```

---

두 방식의 차이:
- **방식 1 (함수형)**: 코드가 간결하고 이해하기 쉬움, 새 리스트를 계속 생성해 메모리 사용량이 많음 `O(n log n)`
- **방식 2 (in-place)**: 원본 배열을 직접 수정, 추가 메모리 `O(log n)`만 사용 (재귀 스택)
