파일 쓰기 권한이 없어 코드를 직접 보여드립니다.

```python
def quicksort(arr):                          # 퀵소트 함수 정의 - 리스트를 입력받아 정렬된 리스트를 반환
    if len(arr) <= 1:                        # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 원소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들로 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬을 합쳐 반환


if __name__ == "__main__":                  # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]        # 테스트용 정렬되지 않은 리스트
    result = quicksort(sample)              # 퀵소트 함수 호출
    print("정렬 전:", sample)              # 원본 리스트 출력
    print("정렬 후:", result)              # 정렬된 결과 출력
```

**핵심 동작 원리:**

1. **피벗 선택** — 중간 인덱스 값을 피벗으로 사용해 최악 케이스(이미 정렬된 배열) 발생 확률을 낮춤
2. **분할** — 피벗 기준으로 `left / middle / right` 세 부분으로 나눔 (중복값 처리 포함)
3. **재귀 정복** — `left`와 `right`를 재귀적으로 정렬 후 합침

**시간 복잡도:** 평균 O(n log n), 최악 O(n²)
