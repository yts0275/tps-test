파일 쓰기 권한이 거부되었으니 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                    # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                           # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                       # 테스트용 입력 리스트
    print("정렬 전:", data)                               # 정렬 전 리스트 출력
    result = quicksort(data)                             # 퀵소트 실행
    print("정렬 후:", result)                             # 정렬 후 리스트 출력
```

**출력 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**핵심 동작 원리:**
- 피벗을 기준으로 작은 값(`left`), 같은 값(`middle`), 큰 값(`right`)으로 분할
- `left`와 `right`에 재귀적으로 퀵소트를 적용 후 합산
- 평균 시간복잡도 **O(n log n)**, 최악(이미 정렬된 경우) **O(n²)**
