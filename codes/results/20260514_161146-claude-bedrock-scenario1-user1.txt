**두 가지 방식으로 구현했습니다:**

### 1. 새 리스트 반환 방식 (이해하기 쉬움)

```python
def quicksort(arr):                                  # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 배열로 분류
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 배열로 분류 (중복 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 배열로 분류

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 결합
```

### 2. 제자리(In-place) 방식 (메모리 효율적)

```python
def quicksort_inplace(arr, low, high):               # 제자리 퀵소트 함수 정의
    if low < high:                                   # 정렬 범위가 2개 이상 원소를 포함할 때만 실행
        pivot_idx = partition(arr, low, high)        # 피벗을 제자리에 배치하고 인덱스 반환
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 재귀 정렬

def partition(arr, low, high):                       # 분할 함수: 피벗 기준으로 배열을 두 부분으로 나눔
    pivot = arr[high]                                # 마지막 원소를 피벗으로 선택
    i = low - 1                                      # 작은 원소들의 경계 인덱스 초기화

    for j in range(low, high):                       # low부터 high-1까지 순회
        if arr[j] <= pivot:                          # 현재 원소가 피벗 이하이면
            i += 1                                   # 경계 인덱스를 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]          # 경계 위치와 현재 위치 원소 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]    # 피벗을 최종 위치로 이동
    return i + 1                                     # 피벗의 최종 인덱스 반환
```

---

**시간복잡도:** 평균 O(n log n), 최악 O(n²) (이미 정렬된 배열 + 첫/끝 피벗 선택 시)
