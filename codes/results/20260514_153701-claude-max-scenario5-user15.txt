파일 쓰기 권한이 없어 코드를 직접 보여드립니다.

```python
def quicksort(arr):                          # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                        # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 리스트에 수집
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합산 후 반환


def quicksort_inplace(arr, low, high):      # 제자리(in-place) 퀵소트: 추가 메모리 없이 원본 배열을 직접 정렬
    if low < high:                          # 정렬 범위가 유효한 경우에만 진행
        pivot_idx = partition(arr, low, high)  # 파티션 수행 후 피벗의 최종 위치 반환
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):             # 파티션 함수: 피벗을 기준으로 배열을 두 부분으로 나눔
    pivot = arr[high]                      # 마지막 원소를 피벗으로 선택
    i = low - 1                            # i는 피벗보다 작은 영역의 마지막 인덱스 (초기값: low 앞)

    for j in range(low, high):             # j를 low부터 high 바로 앞까지 순회
        if arr[j] <= pivot:                # 현재 원소가 피벗 이하이면
            i += 1                         # 작은 영역을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]  # arr[i]와 arr[j]를 교환하여 작은 원소를 왼쪽으로 이동

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 올바른 위치(i+1)로 이동
    return i + 1                           # 피벗의 최종 위치 인덱스 반환


if __name__ == "__main__":                 # 스크립트 직접 실행 시에만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]      # 테스트용 샘플 리스트 정의

    result = quicksort(sample)             # 새 리스트 반환 방식 퀵소트 실행
    print("새 리스트 방식:", result)       # 정렬 결과 출력

    sample2 = [3, 6, 8, 10, 1, 2, 1]     # 제자리 정렬용 동일 샘플 리스트
    quicksort_inplace(sample2, 0, len(sample2) - 1)  # 제자리 방식 퀵소트 실행
    print("제자리 방식:  ", sample2)      # 정렬된 원본 리스트 출력
```

두 가지 방식으로 구현했습니다.

**새 리스트 방식** (`quicksort`): 피벗 기준으로 left / middle / right를 나눠 재귀 호출 후 합산. 코드가 직관적이나 추가 메모리 O(n log n) 사용.

**제자리 방식** (`quicksort_inplace` + `partition`): 원본 배열을 직접 스왑하며 정렬. 추가 메모리 O(log n)만 사용 (재귀 스택).
