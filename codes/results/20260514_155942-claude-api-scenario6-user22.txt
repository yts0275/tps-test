1. **상품 재고 관리 시스템** — `Product`, `Order`, `InventoryManager` 세 클래스로 IT 인프라 장비(서버 랙, 스위치, 케이블 등)의 재고를 등록·조회·차감하는 구조다.

2. **주문 처리 및 재고 검증** — 주문 시 `update_stock(-quantity)`로 재고를 먼저 차감하고, 재고 부족이면 `False`를 반환해 주문을 거절하는 간단한 유효성 검사를 포함한다.

3. **운영 흐름 시뮬레이션** — `run_system()`이 초기 데이터 세팅 → 재고 확인 → 정상 주문 → 재고 부족 주문 → 최종 재고 및 자산 가치 리포트 순으로 전체 흐름을 실행한다.
