파일 저장 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                          # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                        # 원소가 1개 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스의 값을 피벗으로 선택

    left = [x for x in arr if x < pivot]   # 피벗보다 작은 원소들을 왼쪽 부분 리스트로 분리
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 리스트로 분리
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 오른쪽 부분 리스트로 분리

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/중간/오른쪽을 재귀 정렬 후 합쳐 반환


# ── 테스트 ──
if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]        # 정렬할 샘플 리스트
    print("정렬 전:", sample)               # 정렬 전 출력
    result = quicksort(sample)              # 퀵소트 실행
    print("정렬 후:", result)               # 정렬 후 출력
```

**동작 흐름:**
- 피벗을 기준으로 배열을 `left / middle / right` 세 부분으로 분리합니다.
- 각 부분을 재귀적으로 정렬한 뒤 합칩니다.
- 평균 시간 복잡도 O(n log n), 최악(이미 정렬된 경우) O(n²).

파일로 저장이 필요하면 권한을 허용해 주시면 저장하겠습니다.
