Python으로 구현하겠습니다.

```python
def quicksort(arr):                        # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                      # 원소가 1개 이하면 이미 정렬된 상태
        return arr                         # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]             # 피벗: 리스트 중간 원소 선택
    left = [x for x in arr if x < pivot]  # 피벗보다 작은 원소들 → 왼쪽 분할
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 원소들 → 중간 분할 (중복 처리)
    right = [x for x in arr if x > pivot] # 피벗보다 큰 원소들 → 오른쪽 분할

    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 정렬 후 합치기


# --- 테스트 ---
data = [3, 6, 8, 10, 1, 2, 1]  # 정렬할 예시 리스트
result = quicksort(data)        # 퀵소트 호출
print(result)                   # 결과 출력: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리 요약:**
1. 피벗을 기준으로 리스트를 `left / middle / right` 세 부분으로 분리
2. `left`와 `right`를 재귀적으로 다시 퀵소트
3. 세 부분을 합쳐 정렬 완료

시간 복잡도: 평균 **O(n log n)**, 최악 **O(n²)** (이미 정렬된 경우)
