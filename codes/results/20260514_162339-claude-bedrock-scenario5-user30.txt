```python
def quicksort(arr):                          # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                        # 리스트 길이가 1 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]              # 가운데 인덱스의 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 요소들을 왼쪽 리스트에 모음
    middle = [x for x in arr if x == pivot] # 피벗과 같은 요소들을 가운데 리스트에 모음
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들을 오른쪽 리스트에 모음

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·가운데·오른쪽을 재귀 정렬 후 합쳐 반환


if __name__ == "__main__":                   # 이 파일을 직접 실행할 때만 아래 코드 실행
    data = [3, 6, 8, 10, 1, 2, 1]           # 테스트용 정렬 대상 리스트 정의
    print("정렬 전:", data)                   # 정렬 전 리스트 출력
    sorted_data = quicksort(data)            # 퀵소트 함수 호출
    print("정렬 후:", sorted_data)            # 정렬 후 결과 출력
```

**동작 방식 요약:**

1. **피벗 선택** — 리스트 가운데 요소를 피벗으로 선택
2. **분할** — 피벗보다 작은 것(`left`), 같은 것(`middle`), 큰 것(`right`)으로 분리
3. **재귀 정렬** — `left`와 `right`를 재귀적으로 다시 퀵소트
4. **합치기** — 세 부분을 순서대로 이어붙여 반환

**시간 복잡도:** 평균 O(n log n), 최악 O(n²)
