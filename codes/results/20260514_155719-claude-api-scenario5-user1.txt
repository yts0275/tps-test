파일 저장 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 원소가 1개 이하면 이미 정렬된 상태이므로
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 원소들을 왼쪽 부분 리스트로 수집
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 원소들을 중간 리스트로 수집 (중복 처리)
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 원소들을 오른쪽 부분 리스트로 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합산 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 정렬되지 않은 샘플 리스트 정의
    print("정렬 전:", sample)                    # 정렬 전 리스트 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)                    # 정렬 후 결과 출력
```

**동작 흐름 요약:**

1. 피벗을 기준으로 `left / middle / right` 세 그룹으로 분할
2. `left`와 `right`를 재귀적으로 다시 퀵소트
3. 세 부분을 합쳐 반환

**평균 시간복잡도:** O(n log n) / **최악(이미 정렬된 경우):** O(n²)
