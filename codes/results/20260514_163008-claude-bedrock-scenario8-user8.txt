## LangGraph Workflow 노드 흐름 분석

### 노드 구성

| 노드 유형 | 노드명 |
|---|---|
| Entry/Exit (oval) | `start`, `end` |
| Agent Node (purple rect) | `SoftwareEngineer`, `CodeAnalyzer`, `Editor` |
| Tool Node (light rect) | `code_analysis_tool`, `code_edit_tool`, `test_tool`, `swe_tool` |

---

### 전체 흐름 구조

```
start
  └─► SoftwareEngineer (메인 오케스트레이터)
         ├─[analyze_code]──► CodeAnalyzer ──[done]──► SoftwareEngineer
         │                       ├──► code_analysis_tool (반복 가능)
         │                       └──[continue: 자기 루프]
         │
         ├─[edit_file]────► Editor ──────[done]──► SoftwareEngineer
         │                       ├──► code_edit_tool (반복 가능)
         │                       ├──► test_tool (반복 가능)
         │                       └──[continue: 자기 루프]
         │
         ├──────────────────► swe_tool ──[continue]──► SoftwareEngineer
         │
         └─[end 조건 충족]─► end
```

---

### 노드별 상세 설명

#### 1. `start` → `SoftwareEngineer`
- 워크플로우의 진입점
- 항상 `SoftwareEngineer`로 시작

---

#### 2. `SoftwareEngineer` (중앙 오케스트레이터)
- **Supervisor 역할** — 전체 흐름을 결정하는 핵심 노드
- 현재 상태(state)를 평가한 후 **4가지 조건부 엣지(conditional edge)** 중 하나를 선택:

| 조건 | 다음 노드 | 의미 |
|---|---|---|
| `analyze_code` | `CodeAnalyzer` | 코드 분석이 필요한 경우 |
| `edit_file` | `Editor` | 파일 편집이 필요한 경우 |
| (직접 도구 사용) | `swe_tool` | 일반 소프트웨어 엔지니어링 도구 실행 |
| (작업 완료) | `end` | 태스크가 완전히 마무리된 경우 |

- `CodeAnalyzer`, `Editor`, `swe_tool` 모두 **작업 완료 후 다시 `SoftwareEngineer`로 복귀**하여 다음 지시를 받음

---

#### 3. `CodeAnalyzer` 서브그래프
- `SoftwareEngineer`의 `analyze_code` 명령으로 진입
- 내부 동작:
  1. `code_analysis_tool`을 호출하여 코드 분석 수행 (dashed 양방향 화살표)
  2. 분석 결과를 수신 후 추가 분석이 필요하면 **`continue` 자기 루프(self-loop)** 실행 → 재귀적으로 도구 재호출 가능
  3. 분석이 완료되면 `done` 엣지를 통해 `SoftwareEngineer`로 제어권 반환

---

#### 4. `Editor` 서브그래프
- `SoftwareEngineer`의 `edit_file` 명령으로 진입
- 내부 동작:
  1. `code_edit_tool`로 파일 편집 수행
  2. `test_tool`로 편집 결과 테스트 실행
  3. 두 도구 모두 **dashed 양방향 화살표** — 도구 결과를 받아 재판단 가능
  4. 편집/테스트가 더 필요하면 **`continue` 자기 루프** 실행 (반복 수정 사이클)
  5. 완료되면 `done` 엣지를 통해 `SoftwareEngineer`로 반환

---

#### 5. `swe_tool`
- `SoftwareEngineer`가 `CodeAnalyzer`나 `Editor`를 거치지 않고 **직접 사용하는 범용 도구 노드**
- 실행 후 `continue` 엣지로 `SoftwareEngineer`에 결과 반환

---

#### 6. `end`
- `SoftwareEngineer`가 태스크 완료를 판단했을 때 도달하는 **종료 노드**

---

### 핵심 패턴 요약

- **Supervisor Pattern**: `SoftwareEngineer`가 전체를 지휘하며 서브 에이전트에 위임 후 결과를 수집
- **Tool Calling Loop**: `CodeAnalyzer`와 `Editor` 각각 자기 루프(`continue`)를 통해 도구를 반복 호출 가능 (ReAct 패턴)
- **Dashed edges**: LangGraph에서 도구 호출/반환 엣지 (자동 처리되는 tool node 연결)
- **Solid/Conditional edges**: 에이전트 간 라우팅 결정 엣지
