파일 저장 대신 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 리스트 길이가 1 이하이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 요소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 요소들을 middle 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 요소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 좌측 재귀 정렬 + 피벗 + 우측 재귀 정렬을 합쳐 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 수행
    data = [3, 6, 8, 10, 1, 2, 1]               # 테스트용 정렬되지 않은 리스트 정의
    print("정렬 전:", data)                       # 정렬 전 리스트 출력
    result = quicksort(data)                     # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)                     # 정렬된 결과 출력
```

**동작 흐름 요약:**

| 단계 | 설명 |
|------|------|
| 종료 조건 | 길이 0 또는 1이면 그대로 반환 |
| 피벗 선택 | 리스트 중간 요소 사용 |
| 분할 | 피벗 기준으로 left / middle / right 분리 |
| 재귀 | left, right를 각각 재귀 정렬 후 합산 |

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

평균 시간 복잡도는 **O(n log n)**, 최악(이미 정렬된 경우)은 **O(n²)** 입니다.
