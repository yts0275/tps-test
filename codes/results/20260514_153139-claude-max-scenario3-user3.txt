```python
def quicksort(arr):                                    # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                  # 리스트의 길이가 1 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 리스트에 모음
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트에 모음
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들을 오른쪽 리스트에 모음

    return quicksort(left) + middle + quicksort(right) # 왼쪽과 오른쪽을 재귀 정렬 후 중간과 합쳐 반환


if __name__ == "__main__":                             # 스크립트를 직접 실행할 때만 아래 코드 실행
    data = [3, 6, 8, 10, 1, 2, 1]                     # 정렬할 예시 리스트 선언
    print("정렬 전:", data)                             # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                      # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", sorted_data)                      # 정렬 후 리스트 출력
```

**구현 방식 설명:**

- **피벗 선택**: 중간 인덱스 원소를 피벗으로 사용 (최악의 경우를 줄이기 위함)
- **분할**: 피벗 기준으로 작은 값(`left`), 같은 값(`middle`), 큰 값(`right`) 세 그룹으로 나눔
- **재귀**: `left`와 `right`를 재귀 호출로 정렬 후 합쳐 반환
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)

실행 결과: `정렬 전: [3, 6, 8, 10, 1, 2, 1]` → `정렬 후: [1, 1, 2, 3, 6, 8, 10]`
