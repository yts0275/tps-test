```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (기저 조건)

    pivot = arr[len(arr) // 2]                         # 중앙 인덱스 원소를 피벗으로 선택

    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 그룹으로 분리
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 그룹으로 분리
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들을 오른쪽 그룹으로 분리

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                             # 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 입력 리스트 정의
    print("정렬 전:", sample)                           # 정렬 전 리스트 출력
    result = quicksort(sample)                         # 퀵소트 실행
    print("정렬 후:", result)                           # 정렬 결과 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리:**
- 피벗을 기준으로 `left / middle / right` 세 그룹으로 분할
- `left`와 `right`를 재귀 호출로 각각 정렬
- 세 그룹을 합쳐서 반환
