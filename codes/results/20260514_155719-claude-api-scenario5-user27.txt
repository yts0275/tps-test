파일 작성 권한이 없으니 코드를 직접 출력합니다.

```python
def quicksort(arr):                            # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                          # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                             # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                 # 피벗: 리스트 중간 인덱스의 값으로 선택
    left = [x for x in arr if x < pivot]      # left: 피벗보다 작은 원소들 모음
    middle = [x for x in arr if x == pivot]   # middle: 피벗과 같은 원소들 모음 (중복 처리)
    right = [x for x in arr if x > pivot]     # right: 피벗보다 큰 원소들 모음

    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 left, right 정렬 후 합쳐서 반환


if __name__ == "__main__":                     # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]           # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                  # 정렬 전 리스트 출력
    result = quicksort(sample)                 # 퀵소트 함수 호출
    print("정렬 후:", result)                  # 정렬 후 리스트 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**구조 요약:**

| 단계 | 설명 |
|------|------|
| 종료 조건 | 길이 ≤ 1이면 그대로 반환 |
| 피벗 선택 | 중간 인덱스 값 사용 |
| 분할 | `left` / `middle` / `right` 3파트로 나눔 |
| 재귀 | `left`, `right` 각각 재귀 정렬 후 합침 |

시간 복잡도: 평균 **O(n log n)**, 최악 **O(n²)**. 파일로 저장이 필요하면 권한을 허용해주세요.
