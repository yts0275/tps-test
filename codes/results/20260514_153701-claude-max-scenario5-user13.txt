Python 퀵소트 구현 코드입니다:

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소를 모아 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소를 모아 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소를 모아 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 입력 리스트 정의
    print("정렬 전:", sample)                    # 정렬 전 리스트 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출하여 정렬 결과 저장
    print("정렬 후:", result)                    # 정렬 후 리스트 출력
```

**핵심 동작 원리:**
- **피벗(pivot)**: 리스트를 나누는 기준 원소 (여기선 중간값 선택)
- **분할**: 피벗 기준으로 작은 것(`left`), 같은 것(`middle`), 큰 것(`right`)으로 분리
- **재귀**: `left`와 `right`를 각각 다시 퀵소트 → 분할 정복
- **시간 복잡도**: 평균 O(n log n), 최악 O(n²)
