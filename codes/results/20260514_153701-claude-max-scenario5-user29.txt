파일 쓰기 권한이 없어 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                   # 퀵소트 함수 정의: 배열을 받아 정렬된 배열을 반환
    if len(arr) <= 1:                                 # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                                    # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]                        # 피벗: 배열 중앙 원소를 선택
    left = [x for x in arr if x < pivot]             # left: 피벗보다 작은 원소들만 모음
    middle = [x for x in arr if x == pivot]          # middle: 피벗과 같은 원소들만 모음
    right = [x for x in arr if x > pivot]            # right: 피벗보다 큰 원소들만 모음

    return quicksort(left) + middle + quicksort(right)  # 재귀적으로 left, right 정렬 후 합쳐서 반환


def quicksort_inplace(arr, low, high):               # 제자리(in-place) 퀵소트: 추가 메모리 없이 정렬
    if low < high:                                    # 정렬 범위가 2개 이상일 때만 진행
        pivot_idx = partition(arr, low, high)         # 피벗을 제자리에 놓고 그 인덱스를 반환
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):                       # 분할 함수: 피벗을 기준으로 배열을 두 구역으로 나눔
    pivot = arr[high]                                 # 마지막 원소를 피벗으로 선택
    i = low - 1                                       # i: 피벗보다 작은 구역의 오른쪽 경계 (초기값은 범위 밖)

    for j in range(low, high):                        # j: low부터 high-1까지 순회
        if arr[j] <= pivot:                           # 현재 원소가 피벗 이하이면
            i += 1                                    # 작은 구역을 한 칸 오른쪽으로 확장
            arr[i], arr[j] = arr[j], arr[i]           # i 위치와 j 위치의 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]    # 피벗을 작은 구역 바로 오른쪽(최종 위치)에 삽입
    return i + 1                                      # 피벗의 최종 인덱스를 반환


if __name__ == "__main__":
    # --- 방식 1: 새 배열 반환 ---
    data1 = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 배열 선언
    result = quicksort(data1)                         # 퀵소트 실행 (원본 유지)
    print("방식1 (새 배열):", result)                  # 정렬 결과 출력

    # --- 방식 2: 제자리 정렬 ---
    data2 = [3, 6, 8, 10, 1, 2, 1]                   # 동일한 테스트용 배열 선언
    quicksort_inplace(data2, 0, len(data2) - 1)       # 제자리 퀵소트 실행 (원본 변경)
    print("방식2 (제자리):", data2)                    # 정렬된 원본 배열 출력
```

두 가지 방식으로 구현했습니다.

| 방식 | 함수 | 특징 |
|------|------|------|
| 방식 1 | `quicksort()` | 새 배열 반환, 코드 간결, 추가 메모리 O(n) |
| 방식 2 | `quicksort_inplace()` | 원본 배열 직접 정렬, 추가 메모리 O(log n) |

**실행 결과:**
```
방식1 (새 배열): [1, 1, 2, 3, 6, 8, 10]
방식2 (제자리): [1, 1, 2, 3, 6, 8, 10]
```
