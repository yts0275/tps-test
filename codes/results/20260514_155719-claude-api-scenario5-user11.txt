파일 쓰기 권한이 없어 직접 코드를 보여드리겠습니다.

```python
def quicksort(arr):  # 퀵소트 함수 정의, 입력: 정렬할 리스트
    if len(arr) <= 1:  # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr  # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]  # 피벗을 리스트 중간 원소로 선택

    left = [x for x in arr if x < pivot]  # 피벗보다 작은 원소들을 left에 수집
    middle = [x for x in arr if x == pivot]  # 피벗과 같은 원소들을 middle에 수집
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 right에 수집

    return quicksort(left) + middle + quicksort(right)  # 재귀 정렬 후 세 부분을 합쳐 반환


if __name__ == "__main__":  # 직접 실행 시에만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]  # 테스트용 샘플 리스트
    print("정렬 전:", sample)  # 정렬 전 리스트 출력
    result = quicksort(sample)  # 퀵소트 실행
    print("정렬 후:", result)  # 정렬 후 결과 출력
```

**구조 설명:**

| 단계 | 내용 |
|------|------|
| 기저 조건 | 원소가 1개 이하면 그대로 반환 |
| 피벗 선택 | 중간 인덱스 원소 선택 (최악 경우를 어느 정도 방지) |
| 분할 | `left / middle / right` 3-way 분할로 중복 원소 처리 |
| 정복 | 재귀 호출 후 합치기 |

- 평균 시간복잡도: **O(n log n)**
- 최악 시간복잡도: **O(n²)** (이미 정렬된 경우)
- 공간복잡도: **O(n)** (리스트 컴프리헨션 사용으로 제자리 정렬 아님)
