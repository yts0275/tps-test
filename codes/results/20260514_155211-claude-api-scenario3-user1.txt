파일 권한이 필요하지만, 코드를 바로 보여드리겠습니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                        # 중간 인덱스의 값을 피벗으로 선택

    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 리스트로
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소들을 중간 리스트로 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들을 오른쪽 리스트로

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐 반환


if __name__ == "__main__":                             # 직접 실행할 때만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                    # 정렬할 예시 리스트 정의
    print("정렬 전:", data)                            # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                     # 퀵소트 함수 호출
    print("정렬 후:", sorted_data)                    # 정렬 후 결과 출력
```

**동작 원리 요약:**

1. **피벗 선택**: 배열 중간값을 피벗으로 지정
2. **분할**: 피벗 기준으로 작은 것(left), 같은 것(middle), 큰 것(right) 세 그룹으로 나눔
3. **재귀**: left와 right를 재귀적으로 정렬
4. **병합**: `left + middle + right` 순으로 합쳐 반환

**시간복잡도**: 평균 O(n log n), 최악(이미 정렬된 배열) O(n²)
