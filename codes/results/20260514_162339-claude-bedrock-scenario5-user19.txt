프로젝트가 Python 기반이므로 Python으로 구현하여 채팅창에 출력하겠습니다.

```python
def quicksort(arr):                                   # 퀵소트 함수 정의, 리스트를 인자로 받음
    if len(arr) <= 1:                                 # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                    # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                        # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽 재귀 정렬 후 합쳐서 반환


# --- 테스트 ---
data = [3, 6, 8, 10, 1, 2, 1]                        # 정렬할 샘플 리스트
print("정렬 전:", data)                               # 정렬 전 출력
result = quicksort(data)                              # 퀵소트 실행
print("정렬 후:", result)                             # 정렬 결과 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**핵심 동작 방식:**
- **피벗 선택** → 중간 인덱스 원소 사용 (최악의 경우를 줄이기 위해 첫/끝 대신 중간 선택)
- **분할** → 피벗보다 작은 것 / 같은 것 / 큰 것으로 3분류
- **재귀 정복** → 각 부분을 재귀적으로 정렬 후 합침
- **시간복잡도** → 평균 O(n log n), 최악 O(n²)
