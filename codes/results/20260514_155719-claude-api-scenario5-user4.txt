파일 저장 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의, 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스의 값을 피벗으로 선택

    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 모아 왼쪽 리스트 생성
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 모아 중간 리스트 생성
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 모아 오른쪽 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 이어 붙여 반환


def quicksort_inplace(arr, low, high):           # 제자리(in-place) 퀵소트, 추가 메모리 없이 정렬
    if low < high:                               # 구간에 원소가 2개 이상일 때만 실행
        pivot_idx = partition(arr, low, high)    # 피벗 위치를 구하고 배열을 분할
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 구간 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 구간 재귀 정렬


def partition(arr, low, high):                   # 분할 함수: 피벗을 올바른 위치에 놓고 인덱스 반환
    pivot = arr[high]                            # 마지막 원소를 피벗으로 선택
    i = low - 1                                  # 피벗보다 작은 영역의 경계 인덱스 초기화

    for j in range(low, high):                   # low부터 high-1까지 순회
        if arr[j] <= pivot:                      # 현재 원소가 피벗 이하이면
            i += 1                               # 작은 영역 경계를 오른쪽으로 확장
            arr[i], arr[j] = arr[j], arr[i]      # 경계 원소와 현재 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 최종 위치(i+1)로 이동
    return i + 1                                 # 피벗의 최종 인덱스 반환


if __name__ == "__main__":                       # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 정렬되지 않은 리스트

    result = quicksort(sample)                   # 재귀 방식 퀵소트 실행
    print("재귀 방식:", result)                  # 정렬 결과 출력

    sample2 = [3, 6, 8, 10, 1, 2, 1]            # in-place용 별도 리스트 (원본 보존)
    quicksort_inplace(sample2, 0, len(sample2) - 1)  # in-place 퀵소트 실행
    print("제자리 방식:", sample2)               # 정렬 결과 출력
```

두 가지 방식을 구현했습니다.

- **재귀 방식 (`quicksort`)**: 피벗을 기준으로 left/middle/right 리스트를 새로 만들어 합침. 코드가 간결하지만 추가 메모리 사용.
- **제자리 방식 (`quicksort_inplace` + `partition`)**: 배열 내에서 원소를 직접 교환해 정렬. 추가 메모리 없이 O(log n) 스택만 사용.
