파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 리스트 중간 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 리스트로 분류
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트로 분류
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 리스트로 분류

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 + 중간 + 오른쪽 재귀 합쳐서 반환


def quicksort_inplace(arr, low, high):               # 제자리(in-place) 퀵소트 함수 정의
    if low < high:                                   # 정렬 범위가 유효한 경우에만 실행
        pivot_index = partition(arr, low, high)      # 파티션 수행 후 피벗의 최종 위치 획득
        quicksort_inplace(arr, low, pivot_index - 1) # 피벗 왼쪽 부분 배열을 재귀적으로 정렬
        quicksort_inplace(arr, pivot_index + 1, high)# 피벗 오른쪽 부분 배열을 재귀적으로 정렬


def partition(arr, low, high):                       # 파티션 함수: 피벗 기준으로 배열을 분할
    pivot = arr[high]                                # 마지막 원소를 피벗으로 선택
    i = low - 1                                      # 피벗보다 작은 원소들의 경계 인덱스 초기화

    for j in range(low, high):                       # low부터 high-1까지 순회
        if arr[j] <= pivot:                          # 현재 원소가 피벗 이하이면
            i += 1                                   # 경계 인덱스를 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]          # 현재 원소와 경계 위치 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]    # 피벗을 올바른 위치(경계+1)에 배치
    return i + 1                                     # 피벗의 최종 인덱스 반환


if __name__ == "__main__":                           # 직접 실행 시에만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                 # 테스트용 정렬되지 않은 리스트

    result = quicksort(sample)                       # 일반 퀵소트 실행
    print("일반 퀵소트 결과:", result)               # 결과 출력

    sample2 = [3, 6, 8, 10, 1, 2, 1]                # in-place 테스트용 리스트 (별도 복사)
    quicksort_inplace(sample2, 0, len(sample2) - 1) # in-place 퀵소트 실행 (원본 배열 직접 수정)
    print("in-place 퀵소트 결과:", sample2)          # 결과 출력
```

두 가지 버전을 구현했습니다.

**일반 퀵소트** (`quicksort`): 새 리스트를 만들며 분할하는 방식. 코드가 직관적이지만 메모리를 더 사용합니다.

**in-place 퀵소트** (`quicksort_inplace` + `partition`): 원본 배열을 직접 수정하는 방식. 메모리 효율적이지만 코드가 더 복잡합니다.

**시간 복잡도**: 평균 O(n log n), 최악(이미 정렬된 배열) O(n²)
