퀵소트 구현 코드입니다:

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 피벗: 리스트 중간 원소를 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 리스트로 분류
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 리스트로 분류 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 리스트로 분류

    return quicksort(left) + middle + quicksort(right)  # 왼쪽, 중간, 오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 입력 리스트
    print("정렬 전:", sample)                    # 정렬 전 출력
    result = quicksort(sample)                   # 퀵소트 실행
    print("정렬 후:", result)                    # 정렬 결과 출력
```

**핵심 동작 방식:**
- **피벗 선택**: 중간 인덱스(`len//2`)의 원소를 피벗으로 사용
- **분할(Partition)**: 피벗 기준으로 left / middle / right 세 그룹으로 나눔 (중복 원소도 안전하게 처리)
- **재귀 정렬**: left와 right를 재귀 호출로 정렬 후 합침
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)
