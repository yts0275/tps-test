파일 쓰기 권한이 필요합니다. 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 배열을 입력받아 정렬된 배열을 반환
    if len(arr) <= 1:                            # 배열의 길이가 1 이하이면 재귀 탈출 조건 (이미 정렬됨)
        return arr                               # 그대로 반환 (기저 사례)

    pivot = arr[len(arr) // 2]                   # 피벗: 배열 중간 인덱스의 값을 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 부분 배열로 수집
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 배열로 수집 (중복값 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 부분 배열로 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐 반환


def quicksort_inplace(arr, low, high):           # 제자리(in-place) 퀵소트: 추가 배열 없이 원본을 직접 정렬
    if low < high:                               # 정렬 범위가 2개 이상의 원소를 포함할 때만 진행
        pivot_idx = partition(arr, low, high)    # 파티션 수행 후 피벗의 최종 위치 인덱스를 받음
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분을 재귀적으로 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분을 재귀적으로 정렬


def partition(arr, low, high):                   # 파티션 함수: 피벗을 기준으로 배열을 두 구간으로 나눔
    pivot = arr[high]                            # 마지막 원소를 피벗으로 선택
    i = low - 1                                  # i: 피벗보다 작은 영역의 오른쪽 경계 (처음엔 범위 밖)

    for j in range(low, high):                   # j를 low부터 high-1까지 순회하며 각 원소를 피벗과 비교
        if arr[j] <= pivot:                      # 현재 원소가 피벗 이하이면 왼쪽 영역에 포함시킴
            i += 1                               # 작은 영역의 경계를 한 칸 오른쪽으로 확장
            arr[i], arr[j] = arr[j], arr[i]      # 현재 원소를 작은 영역의 끝으로 스왑

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 작은 영역 바로 오른쪽(최종 위치)에 삽입
    return i + 1                                 # 피벗의 최종 인덱스를 반환


if __name__ == "__main__":
    # --- 새 배열 반환 방식 테스트 ---
    sample = [3, 6, 8, 10, 1, 2, 1]             # 정렬할 예시 배열 정의
    print("원본:", sample)                        # 정렬 전 배열 출력
    result = quicksort(sample)                   # 퀵소트 실행 (새 배열 반환)
    print("정렬 후:", result)                     # 정렬 결과 출력

    # --- 제자리 정렬 방식 테스트 ---
    sample2 = [3, 6, 8, 10, 1, 2, 1]            # 동일한 예시 배열로 제자리 정렬 테스트
    print("\n원본:", sample2)                     # 정렬 전 배열 출력
    quicksort_inplace(sample2, 0, len(sample2) - 1)  # 제자리 퀵소트 실행 (원본 배열 직접 수정)
    print("정렬 후:", sample2)                    # 정렬 결과 출력
```

두 가지 구현 방식을 제공했습니다.

**`quicksort` (새 배열 반환)** — 이해하기 쉬운 함수형 방식. 피벗을 중간값으로 선택하고 left/middle/right로 분리 후 재귀 결합. 메모리 O(n log n) 사용.

**`quicksort_inplace` (제자리 정렬)** — 실무에서 쓰이는 방식. `partition` 함수로 스왑을 통해 원본 배열을 직접 수정. 추가 메모리 O(log n)만 사용.
