파일 쓰기 권한이 필요합니다. 권한을 허용하거나, 아래 코드를 직접 사용하셔도 됩니다.

```python
def quicksort(arr):                                          # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                        # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                           # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                               # 가운데 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                    # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]                 # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]                   # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)       # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 결합


if __name__ == "__main__":                                   # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                         # 테스트용 샘플 리스트
    print("정렬 전:", sample)                                 # 정렬 전 출력
    result = quicksort(sample)                               # 퀵소트 실행
    print("정렬 후:", result)                                 # 정렬 후 출력
```

**동작 흐름:**

1. 피벗을 중간 원소로 선택
2. 전체 리스트를 `left / middle / right` 세 구간으로 분리
3. `left`와 `right`를 재귀적으로 다시 퀵소트
4. 세 구간을 합쳐서 반환

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

평균 시간 복잡도는 O(n log n), 최악(이미 정렬된 경우)은 O(n²)입니다.
