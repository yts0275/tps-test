파일 쓰기 권한이 없으니 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                  # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                        # 피벗 선택: 중간 인덱스의 요소를 피벗으로 설정

    left = [x for x in arr if x < pivot]              # 피벗보다 작은 요소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 요소들을 middle 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 요소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                  # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                          # 정렬 전 리스트 출력
    result = quicksort(sample)                        # 퀵소트 함수 호출
    print("정렬 후:", result)                          # 정렬 후 결과 출력
```

**동작 원리 요약:**

| 단계 | 설명 |
|------|------|
| 1. 종료 조건 | 길이 ≤ 1이면 그대로 반환 |
| 2. 피벗 선택 | 배열 중간 요소를 피벗으로 사용 |
| 3. 분할 | 피벗 기준으로 left / middle / right 세 그룹으로 나눔 |
| 4. 재귀 | left와 right를 각각 재귀 호출 후 합침 |

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
