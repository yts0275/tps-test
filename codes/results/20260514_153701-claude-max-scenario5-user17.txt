```python
def quicksort(arr):                                      # 퀵소트 함수 정의: 리스트를 받아 정렬된 리스트를 반환
    if len(arr) <= 1:                                    # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                           # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 원소들을 왼쪽 리스트에 모음
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 원소들을 중간 리스트에 모음 (중복 처리)
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 원소들을 오른쪽 리스트에 모음

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 세 부분을 합쳐 반환


if __name__ == "__main__":                               # 이 파일을 직접 실행할 때만 아래 코드를 수행
    sample = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 입력 리스트 정의
    print("정렬 전:", sample)                             # 정렬 전 리스트 출력
    result = quicksort(sample)                           # 퀵소트 실행
    print("정렬 후:", result)                             # 정렬된 결과 출력
```

**동작 원리 요약:**

1. **피벗 선택** — 중간 인덱스 원소를 피벗으로 사용
2. **분할** — 피벗 기준으로 `left / middle / right` 세 그룹으로 나눔
3. **재귀** — `left`와 `right`를 각각 재귀 호출로 정렬
4. **합산** — 세 부분을 이어 붙여 반환

**시간 복잡도:** 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
