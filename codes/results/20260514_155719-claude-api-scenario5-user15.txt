파일 쓰기 권한이 없어 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 리스트 길이가 1 이하이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 원소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 원소들을 middle 리스트에 수집
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 원소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 결합


if __name__ == "__main__":                       # 이 파일이 직접 실행될 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]             # 정렬할 예시 리스트 정의
    print("정렬 전:", sample)                    # 정렬 전 리스트 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출하여 정렬 결과 저장
    print("정렬 후:", result)                    # 정렬 후 리스트 출력
```

**동작 설명:**

- **피벗 선택**: 중간 인덱스 원소를 피벗으로 사용해 편향을 줄임
- **분할**: `left` / `middle` / `right` 세 그룹으로 나눔 (중복 원소도 안전하게 처리)
- **재귀**: `left`와 `right`를 재귀적으로 정렬 후 합침
- **시간 복잡도**: 평균 O(n log n), 최악 O(n²)
