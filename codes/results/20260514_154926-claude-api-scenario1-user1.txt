파일 쓰기 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr, low, high):                              # 배열과 정렬 범위(low~high)를 받는 재귀 함수 정의
    if low < high:                                          # 정렬 범위가 2개 이상의 원소를 가질 때만 진행
        pivot_index = partition(arr, low, high)             # 피벗을 기준으로 분할하고, 피벗의 최종 위치 반환
        quicksort(arr, low, pivot_index - 1)                # 피벗 왼쪽 부분 배열 재귀적으로 정렬
        quicksort(arr, pivot_index + 1, high)               # 피벗 오른쪽 부분 배열 재귀적으로 정렬


def partition(arr, low, high):                              # 피벗을 기준으로 배열을 두 부분으로 나누는 함수
    pivot = arr[high]                                       # 마지막 원소를 피벗으로 선택
    i = low - 1                                             # 피벗보다 작은 원소 경계를 가리키는 인덱스 초기화

    for j in range(low, high):                              # low부터 high 직전까지 순회
        if arr[j] <= pivot:                                 # 현재 원소가 피벗 이하이면
            i += 1                                          # 작은 원소 경계를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]                # 경계 위치와 현재 위치의 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]          # 피벗을 올바른 위치(i+1)로 이동
    return i + 1                                            # 피벗의 최종 위치 반환


# ── 실행 예시 ──────────────────────────────────────────
data = [64, 34, 25, 12, 22, 11, 90]                        # 정렬할 샘플 배열 선언
print("정렬 전:", data)                                      # 정렬 전 배열 출력

quicksort(data, 0, len(data) - 1)                           # 배열 전체 범위에 대해 퀵소트 호출

print("정렬 후:", data)                                      # 정렬 후 배열 출력
```

**실행 결과:**
```
정렬 전: [64, 34, 25, 12, 22, 11, 90]
정렬 후: [11, 12, 22, 25, 34, 64, 90]
```

**구조 요약:**

| 함수 | 역할 |
|---|---|
| `quicksort` | 재귀적으로 배열을 반으로 나눠 정렬 |
| `partition` | 피벗 기준으로 작은 값/큰 값 분리, 피벗을 제자리로 이동 |

- 시간복잡도: 평균 O(n log n), 최악(이미 정렬된 배열) O(n²)
- 공간복잡도: 재귀 스택 O(log n)
