파일 작성 권한을 주시면 바로 저장할 수 있습니다. 코드는 아래와 같습니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의 (배열을 인자로 받음)
    if len(arr) <= 1:                                    # 배열의 길이가 1 이하이면 (기저 조건)
        return arr                                       # 정렬할 필요 없으므로 그대로 반환

    pivot = arr[len(arr) // 2]                           # 배열 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 원소들을 왼쪽 배열에 모음
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 원소들을 중간 배열에 모음
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 원소들을 오른쪽 배열에 모음

    return quicksort(left) + middle + quicksort(right)   # 왼쪽 재귀 + 중간 + 오른쪽 재귀를 합쳐 반환


if __name__ == "__main__":                               # 스크립트를 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 정렬되지 않은 배열 정의
    print("정렬 전:", sample)                             # 정렬 전 배열 출력
    result = quicksort(sample)                           # 퀵소트 함수 호출하여 정렬 결과 저장
    print("정렬 후:", result)                             # 정렬 후 배열 출력
```

**동작 설명:**

| 단계 | 내용 |
|------|------|
| 기저 조건 | 길이 1 이하 → 바로 반환 |
| 피벗 선택 | 중간 인덱스 값 선택 (최악의 경우 방지) |
| 분할 | 피벗 기준으로 left / middle / right 3개로 분할 |
| 재귀 | left, right에 다시 quicksort 적용 후 병합 |

- 평균 시간 복잡도: **O(n log n)**
- 최악 시간 복잡도: **O(n²)** (이미 정렬된 경우)
- 중간 피벗 선택으로 최악 케이스 발생 확률을 낮췄습니다.
