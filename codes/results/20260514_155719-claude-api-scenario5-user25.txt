파일 쓰기 권한이 없어 코드를 직접 출력합니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                           # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 원소들만 모아 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 원소들 (중복 값 처리)
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 원소들만 모아 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 결합 후 반환


if __name__ == "__main__":                               # 이 파일을 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                             # 정렬 전 리스트 출력
    result = quicksort(sample)                           # 퀵소트 함수 호출, 결과를 result에 저장
    print("정렬 후:", result)                             # 정렬된 결과 출력
```

**핵심 동작 흐름:**

1. **기저 조건** — 길이 1 이하면 즉시 반환
2. **분할** — 피벗을 기준으로 `left / middle / right` 세 그룹으로 나눔
3. **재귀** — left와 right를 각각 재귀 호출로 정렬
4. **결합** — 세 결과를 이어 붙여 반환

실행 결과: `정렬 전: [3, 6, 8, 10, 1, 2, 1]` → `정렬 후: [1, 1, 2, 3, 6, 8, 10]`
