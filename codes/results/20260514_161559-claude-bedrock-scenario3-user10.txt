아래가 각 줄마다 주석을 단 퀵소트 구현입니다.

```python
def quicksort(arr):  # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:  # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr     # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스의 원소를 피벗으로 선택

    left   = [x for x in arr if x < pivot]  # 피벗보다 작은 원소들을 왼쪽 리스트로 수집
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 리스트로 수집 (중복 처리)
    right  = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 오른쪽 리스트로 수집

    return quicksort(left) + middle + quicksort(right)  # 세 부분을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                   # 이 파일을 직접 실행할 때만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]           # 정렬할 예시 리스트 정의
    print("정렬 전:", data)                   # 정렬 전 리스트 출력
    sorted_data = quicksort(data)            # 퀵소트 실행
    print("정렬 후:", sorted_data)            # 정렬 결과 출력
```

**동작 원리 요약:**

| 단계 | 설명 |
|------|------|
| **피벗 선택** | 중간 인덱스 원소를 기준값으로 사용 |
| **분할** | 피벗보다 작은/같은/큰 원소를 세 리스트로 나눔 |
| **재귀** | 왼쪽·오른쪽을 재귀적으로 정렬 |
| **병합** | `left + middle + right` 순으로 합쳐서 반환 |

- **시간 복잡도:** 평균 O(n log n), 최악 O(n²)
- `middle` 리스트를 별도로 두어 중복 원소를 올바르게 처리합니다.
