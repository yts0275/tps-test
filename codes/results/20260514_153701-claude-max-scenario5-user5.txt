파일 작성 권한이 필요합니다. 승인해 주시면 `quicksort.py`를 생성합니다.

승인이 어려우시면 아래 코드를 직접 복사해 사용하실 수 있습니다.

---

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 기저 조건: 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                               # 정렬할 필요 없이 그대로 반환

    pivot = arr[len(arr) // 2]                   # 피벗: 리스트 중간 원소를 기준값으로 선택
    left = [x for x in arr if x < pivot]        # 왼쪽 파티션: 피벗보다 작은 원소 모음
    middle = [x for x in arr if x == pivot]     # 중간 파티션: 피벗과 같은 원소 모음 (중복 처리)
    right = [x for x in arr if x > pivot]       # 오른쪽 파티션: 피벗보다 큰 원소 모음

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽 재귀 정렬 후 병합


def quicksort_inplace(arr, low, high):           # 제자리(in-place) 퀵소트: 추가 메모리 없이 정렬
    if low < high:                               # 구간에 원소가 2개 이상 있을 때만 진행
        pivot_idx = partition(arr, low, high)    # 피벗을 제자리에 배치하고 그 인덱스를 반환
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 구간 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 구간 재귀 정렬


def partition(arr, low, high):                   # 파티션 함수: 피벗을 기준으로 원소를 재배치
    pivot = arr[high]                            # 맨 오른쪽 원소를 피벗으로 선택
    i = low - 1                                  # i: 피벗보다 작은 원소들의 경계 인덱스 (초기값: 구간 시작 - 1)

    for j in range(low, high):                   # j: 현재 검사 중인 원소의 인덱스
        if arr[j] <= pivot:                      # 현재 원소가 피벗 이하면 왼쪽 파티션에 포함
            i += 1                               # 작은 원소 경계를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]      # 경계 원소와 현재 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 최종 위치(i+1)로 이동
    return i + 1                                 # 피벗의 최종 인덱스를 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 샘플 리스트

    # --- 방식 1: 새 리스트 반환 ---
    result = quicksort(sample[:])                # 원본 유지를 위해 복사본 전달
    print("새 리스트 반환:", result)              # 정렬 결과 출력

    # --- 방식 2: 제자리 정렬 ---
    inplace = sample[:]                          # 원본 유지를 위해 복사본 생성
    quicksort_inplace(inplace, 0, len(inplace) - 1)  # 제자리 정렬 실행
    print("제자리 정렬:  ", inplace)             # 정렬 결과 출력
```

---

두 가지 구현을 포함했습니다.

| 구현 | 특징 |
|---|---|
| `quicksort()` | 새 리스트 반환, 코드가 직관적, 메모리 O(n) 추가 사용 |
| `quicksort_inplace()` | 원본 리스트를 직접 수정, 메모리 O(log n) (재귀 스택만 사용) |
