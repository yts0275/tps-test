파일 쓰기 권한이 없으니, 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                          # 퀵소트 함수 정의: 리스트 arr을 입력받음
    if len(arr) <= 1:                        # 원소가 1개 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 중간 리스트에 수집
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 결합


if __name__ == "__main__":                   # 스크립트 직접 실행 시에만 아래 코드 수행
    data = [3, 6, 8, 10, 1, 2, 1]           # 정렬할 예시 리스트 정의
    print("정렬 전:", data)                  # 정렬 전 리스트 출력
    result = quicksort(data)                 # 퀵소트 함수 호출하여 정렬 결과 출력
    print("정렬 후:", result)                # 정렬 후 리스트 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리 요약:**

1. **피벗 선택** — 배열 중간값을 피벗으로 사용
2. **분할** — 피벗 기준으로 left / middle / right 세 그룹으로 나눔
3. **재귀 정렬** — left와 right를 재귀적으로 다시 퀵소트
4. **병합** — 정렬된 세 부분을 이어붙임

시간 복잡도: 평균 **O(n log n)**, 최악(이미 정렬된 경우) **O(n²)**
