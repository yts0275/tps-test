파일 쓰기 권한이 필요합니다. 코드를 직접 보여드리겠습니다:

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 리스트를 입력받아 정렬된 리스트를 반환
    if len(arr) <= 1:                            # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 left 리스트에 수집
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 middle 리스트에 수집
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", sample)                    # 정렬 전 리스트 출력
    result = quicksort(sample)                   # 퀵소트 실행
    print("정렬 후:", result)                    # 정렬된 결과 출력
```

**동작 방식:**
- **피벗 선택**: 배열 중간 값을 피벗으로 사용
- **분할**: 피벗보다 작은/같은/큰 세 그룹으로 나눔
- **재귀**: 작은 그룹과 큰 그룹을 각각 재귀적으로 정렬 후 합침
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)
