파일 쓰기 권한이 없어 파일 생성이 막혔습니다. 코드는 아래와 같습니다.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 리스트로 수집
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 리스트로 수집
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 리스트로 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                           # 직접 실행할 때만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 입력 리스트 정의
    print("정렬 전:", data)                           # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                    # 퀵소트 함수 호출
    print("정렬 후:", sorted_data)                   # 정렬 후 결과 출력
```

**동작 방식 요약:**
- 피벗을 기준으로 작은 값(`left`), 같은 값(`middle`), 큰 값(`right`)으로 분리
- `left`와 `right`를 재귀적으로 정렬 후 합산
- 평균 시간복잡도 O(n log n), 최악(이미 정렬된 경우) O(n²)
