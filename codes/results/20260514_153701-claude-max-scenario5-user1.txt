```python
def quicksort(arr):                           # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                         # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                            # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]    # 피벗보다 작은 요소들을 왼쪽 리스트로 분류
    middle = [x for x in arr if x == pivot] # 피벗과 같은 요소들을 중간 리스트로 분류
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 요소들을 오른쪽 리스트로 분류

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 + 중간 + 오른쪽 재귀를 합쳐 반환


if __name__ == "__main__":                   # 이 파일을 직접 실행할 때만 아래 코드 수행
    sample = [3, 6, 8, 10, 1, 2, 1]         # 정렬할 예시 리스트 정의
    print("정렬 전:", sample)               # 정렬 전 리스트 출력
    result = quicksort(sample)               # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)               # 정렬된 결과 리스트 출력
```

**동작 방식 요약:**

| 단계 | 설명 |
|---|---|
| 1. 피벗 선택 | 리스트 중간값을 피벗으로 사용 |
| 2. 분할 | 피벗 기준으로 left / middle / right 3개로 분류 |
| 3. 재귀 | left, right를 각각 재귀 호출하여 정렬 |
| 4. 병합 | 정렬된 세 리스트를 순서대로 합침 |
