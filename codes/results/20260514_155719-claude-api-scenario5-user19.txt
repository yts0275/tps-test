```python
def quicksort(arr):                          # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                        # 원소가 1개 이하면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 원소들을 left 리스트로 분류
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소들을 middle 리스트로 분류
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 원소들을 right 리스트로 분류

    return quicksort(left) + middle + quicksort(right)  # 재귀 정렬 후 세 부분 합쳐서 반환
```

**동작 원리:**

1. **기저 조건** — 원소가 0~1개면 즉시 반환
2. **분할(Partition)** — 피벗 기준으로 `left / middle / right` 세 그룹으로 나눔
3. **재귀(Recurse)** — `left`와 `right`를 각각 재귀 정렬
4. **합산(Combine)** — 정렬된 세 부분을 순서대로 이어붙임

**시간 복잡도:** 평균 O(n log n), 최악(이미 정렬된 경우) O(n²)
