파일 쓰기 권한이 없어서, 코드를 직접 출력합니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 배열을 입력받아 정렬된 배열을 반환
    if len(arr) <= 1:                            # 배열의 길이가 1 이하이면 이미 정렬된 상태이므로
        return arr                               # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]         # 피벗보다 작은 원소들로 왼쪽 부분 배열 생성
    middle = [x for x in arr if x == pivot]      # 피벗과 같은 원소들로 중간 배열 생성 (중복값 처리)
    right = [x for x in arr if x > pivot]        # 피벗보다 큰 원소들로 오른쪽 부분 배열 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬을 합쳐 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 샘플 배열 정의
    print("정렬 전:", sample)                    # 정렬 전 배열 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)                    # 정렬된 결과 배열 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**핵심 동작 방식:**
1. **피벗 선택** — 배열 중간 원소를 기준값으로 선택
2. **분할** — 피벗보다 작으면 `left`, 같으면 `middle`, 크면 `right`로 분류
3. **재귀 정복** — `left`와 `right`를 각각 재귀적으로 정렬 후 합침
4. **시간복잡도** — 평균 O(n log n), 최악 O(n²) (이미 정렬된 경우)
