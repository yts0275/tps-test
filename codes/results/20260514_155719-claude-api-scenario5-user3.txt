파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의 (입력: 정렬할 리스트)
    if len(arr) <= 1:                                  # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택

    left   = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들 → 왼쪽 파티션
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들   → 중간 파티션
    right  = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들   → 오른쪽 파티션

    return quicksort(left) + middle + quicksort(right)  # 세 파티션을 재귀 정렬 후 이어 붙여 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 입력 리스트
    print("정렬 전:", data)                             # 정렬 전 출력
    result = quicksort(data)                           # 퀵소트 실행
    print("정렬 후:", result)                           # 정렬 후 출력
    # 출력 결과: 정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리 요약**

| 단계 | 설명 |
|------|------|
| 1. 피벗 선택 | 리스트 중간 원소를 기준값으로 사용 |
| 2. 분할 | 피벗 기준으로 left / middle / right 세 파티션으로 나눔 |
| 3. 재귀 | left와 right를 각각 재귀적으로 정렬 |
| 4. 합병 | 정렬된 세 파티션을 이어 붙여 최종 결과 반환 |

- **평균 시간복잡도**: O(n log n)
- **최악 시간복잡도**: O(n²) — 이미 정렬된 배열에서 첫/마지막 원소를 피벗으로 고를 때
- **중간값 피벗**을 사용하여 최악의 경우를 줄이는 방식입니다.
