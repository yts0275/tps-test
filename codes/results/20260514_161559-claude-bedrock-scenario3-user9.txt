아래는 각 줄에 주석을 달아 구현한 퀵소트입니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]              # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]           # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]             # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합산


if __name__ == "__main__":                             # 직접 실행 시에만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 정렬 대상 리스트 정의
    print("정렬 전:", data)                             # 정렬 전 원본 리스트 출력
    result = quicksort(data)                           # 퀵소트 함수 호출하여 정렬 수행
    print("정렬 후:", result)                           # 정렬된 결과 리스트 출력
```

**동작 원리 요약:**

1. **피벗 선택** — 배열 중간 원소를 피벗으로 사용
2. **분할** — 피벗 기준으로 left / middle / right 세 구역으로 나눔 (중복 원소 안전 처리)
3. **재귀** — left와 right를 재귀적으로 다시 퀵소트
4. **합산** — 정렬된 left + middle + 정렬된 right 순으로 합쳐 반환

실행 결과: `정렬 전: [3, 6, 8, 10, 1, 2, 1]` → `정렬 후: [1, 1, 2, 3, 6, 8, 10]`
