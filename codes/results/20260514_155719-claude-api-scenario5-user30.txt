파일 생성 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                     # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                   # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                      # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                          # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들로 왼쪽 부분 배열 구성
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들로 중간 배열 구성 (중복 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들로 오른쪽 부분 배열 구성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                    # 테스트용 입력 배열
    print("정렬 전:", sample)                            # 정렬 전 배열 출력
    result = quicksort(sample)                          # 퀵소트 실행
    print("정렬 후:", result)                            # 정렬 결과 출력
```

**동작 흐름:**

1. `pivot`을 중간 원소로 선택
2. 배열을 `left / middle / right` 세 부분으로 분할
3. `left`와 `right`를 재귀적으로 다시 퀵소트
4. 세 부분을 합쳐서 반환

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**시간 복잡도:** 평균 O(n log n), 최악 O(n²) (이미 정렬된 배열에서 첫/마지막 원소를 피벗으로 쓸 때). 중간 원소를 피벗으로 선택해 최악의 경우를 줄였습니다.
