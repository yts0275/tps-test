파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                # 리스트 길이가 1 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]                       # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들로 왼쪽 부분 배열 생성
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들로 중간 배열 생성 (중복 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들로 오른쪽 부분 배열 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                           # 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                 # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                         # 정렬 전 원본 리스트 출력
    result = quicksort(sample)                       # 퀵소트 실행 후 결과 저장
    print("정렬 후:", result)                         # 정렬 결과 출력
```

**실행 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**핵심 로직 요약:**
- **피벗 선택**: 배열 중간값을 피벗으로 사용
- **분할**: 피벗 기준으로 작은 값(left) / 같은 값(middle) / 큰 값(right) 세 그룹으로 분리
- **재귀**: left와 right를 재귀적으로 정렬 후 합침
- **시간복잡도**: 평균 O(n log n), 최악 O(n²)
