파일 작성 권한이 필요합니다. 코드를 텍스트로 제공합니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                            # 원소가 1개 이하면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                  # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 배열로 분리
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 배열로 분리 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 배열로 분리

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]              # 테스트용 입력 배열
    print("정렬 전:", data)                      # 정렬 전 배열 출력
    result = quicksort(data)                    # 퀵소트 실행
    print("정렬 후:", result)                    # 정렬 결과 출력
```

**동작 방식:**
1. 피벗을 중간 원소로 선택
2. 피벗 기준으로 `left / middle / right` 세 배열로 분할
3. `left`와 `right`를 재귀 호출로 정렬 후 합산

`middle` 배열을 따로 분리하여 중복 값도 올바르게 처리합니다. 시간복잡도는 평균 O(n log n), 최악 O(n²)입니다.
