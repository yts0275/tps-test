파일 쓰기 권한이 없어 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):
    # 배열의 길이가 1 이하이면 이미 정렬된 상태이므로 그대로 반환
    if len(arr) <= 1:
        return arr

    # 피벗(pivot)을 배열의 가운데 원소로 선택
    pivot = arr[len(arr) // 2]

    # 피벗보다 작은 원소들을 left 리스트에 모음
    left = [x for x in arr if x < pivot]

    # 피벗과 같은 원소들을 middle 리스트에 모음 (중복 원소 처리)
    middle = [x for x in arr if x == pivot]

    # 피벗보다 큰 원소들을 right 리스트에 모음
    right = [x for x in arr if x > pivot]

    # left, middle, right를 재귀적으로 정렬 후 합쳐서 반환
    return quicksort(left) + middle + quicksort(right)


if __name__ == "__main__":
    # 테스트용 정렬되지 않은 샘플 배열
    sample = [3, 6, 8, 10, 1, 2, 1]

    # 퀵소트 실행
    result = quicksort(sample)

    # 정렬 전 배열 출력
    print(f"정렬 전: {sample}")

    # 정렬 후 배열 출력
    print(f"정렬 후: {result}")
```

**동작 원리 요약:**

| 단계 | 설명 |
|------|------|
| **기저 조건** | 배열 크기 ≤ 1이면 즉시 반환 |
| **피벗 선택** | 가운데 인덱스 원소 사용 |
| **분할** | left / middle / right 3분할 |
| **재귀** | left, right를 재귀 정렬 후 합병 |

- **평균 시간복잡도**: O(n log n)
- **최악 시간복잡도**: O(n²) — 이미 정렬된 배열 + 끝 원소 피벗 선택 시
- **공간복잡도**: O(n) — 새 리스트 생성 방식이라 in-place가 아님
