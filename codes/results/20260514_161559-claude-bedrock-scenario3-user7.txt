Python으로 퀵소트를 구현하겠습니다.

```python
def quicksort(arr):                                         # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                       # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                          # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                              # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]                   # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]                # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]                  # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right)      # 왼쪽·오른쪽을 각각 재귀 정렬 후 합쳐서 반환


# --- 테스트 ---
data = [3, 6, 8, 10, 1, 2, 1]                              # 정렬할 예시 리스트
result = quicksort(data)                                    # 퀵소트 호출
print(result)                                               # 결과 출력: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리 요약**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 리스트 중간 원소를 기준값으로 선택 |
| 분할 | 피벗 기준으로 작은 것 / 같은 것 / 큰 것 세 그룹으로 나눔 |
| 재귀 | 작은 그룹과 큰 그룹을 각각 다시 퀵소트 |
| 합산 | 정렬된 세 부분을 이어 붙여 반환 |

- **평균 시간 복잡도**: O(n log n)
- **최악 시간 복잡도**: O(n²) — 피벗이 항상 최솟값/최댓값일 때
- **공간 복잡도**: O(n) — 분할 리스트를 새로 생성하는 방식이므로
