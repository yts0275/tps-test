```python
def quicksort(arr):                                # 퀵소트 함수 정의: 리스트를 받아 정렬된 리스트를 반환
    if len(arr) <= 1:                              # 리스트 길이가 1 이하면 이미 정렬된 상태이므로
        return arr                                 # 그대로 반환 (기저 조건)

    pivot = arr[len(arr) // 2]                     # 리스트 중간 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]           # 피벗보다 작은 요소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]        # 피벗과 같은 요소들로 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]          # 피벗보다 큰 요소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀적으로 정렬 후 합쳐 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                 # 정렬할 예시 리스트
    print("정렬 전:", data)                         # 정렬 전 리스트 출력
    sorted_data = quicksort(data)                  # 퀵소트 함수 호출
    print("정렬 후:", sorted_data)                  # 정렬 후 결과 출력
```

**동작 설명:**

1. **기저 조건** — 원소가 1개 이하면 즉시 반환
2. **분할** — 피벗 기준으로 `left / middle / right` 세 그룹으로 나눔
3. **재귀** — `left`와 `right`를 재귀 호출로 정렬 후 이어 붙임

실행 결과:
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```
