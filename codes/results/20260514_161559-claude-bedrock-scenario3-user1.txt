파일 쓰기 권한이 필요합니다. 권한을 허용해 주시면 파일을 생성하겠습니다. 그 전에 코드를 미리 보여드립니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들을 왼쪽 리스트로 분류
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트로 분류
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들을 오른쪽 리스트로 분류

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                             # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 정렬되지 않은 리스트
    print("정렬 전:", sample)                          # 정렬 전 리스트 출력
    result = quicksort(sample)                         # 퀵소트 실행 후 결과 저장
    print("정렬 후:", result)                          # 정렬 후 리스트 출력
```

**구조 설명:**
- **피벗 선택**: 중간 인덱스 원소 사용 → 이미 정렬된 배열에서 최악의 성능(O(n²))을 피함
- **분할**: 피벗보다 작은 것 / 같은 것 / 큰 것 세 그룹으로 나눔 (중복 원소 안전 처리)
- **재귀**: 왼쪽·오른쪽을 재귀 호출 후 합산 → 평균 O(n log n)
