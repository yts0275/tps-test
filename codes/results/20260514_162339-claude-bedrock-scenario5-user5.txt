파일 쓰기 권한이 없어 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                              # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                            # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                               # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                   # 피벗을 리스트 중간 원소로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들로 왼쪽 부분 리스트 생성
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들로 중간 리스트 생성 (중복 처리)
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들로 오른쪽 부분 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 정렬 + 중간 + 오른쪽 재귀 정렬 합쳐서 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]               # 테스트용 정렬되지 않은 리스트 준비
    print("정렬 전:", data)                       # 정렬 전 리스트 출력
    result = quicksort(data)                     # 퀵소트 호출하여 결과 저장
    print("정렬 후:", result)                     # 정렬 후 리스트 출력
```

**핵심 동작 방식:**
- **피벗 선택** — 중간 원소를 피벗으로 사용
- **분할** — 피벗 기준으로 left / middle / right 세 그룹으로 나눔 (중복값 안전 처리)
- **재귀** — left와 right를 재귀 호출로 정렬 후 합침
- **시간 복잡도** — 평균 O(n log n), 최악 O(n²)
