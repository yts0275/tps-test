**새 배열 반환 방식 (직관적)**

```python
def quicksort(arr):                                     # 퀵소트 함수 정의: 배열을 입력받아 정렬된 배열 반환
    if len(arr) <= 1:                                   # 원소가 1개 이하이면 이미 정렬된 상태
        return arr                                      # 그대로 반환 (재귀의 기저 조건)

    pivot = arr[len(arr) // 2]                          # 배열의 중간 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들로 왼쪽 부분 배열 생성
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들로 중간 배열 생성 (중복값 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들로 오른쪽 부분 배열 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 middle과 합쳐 반환
```

**제자리(in-place) 방식 (메모리 효율적)**

```python
def quicksort_inplace(arr, low, high):                  # 추가 메모리 없이 원본 배열을 직접 정렬
    if low < high:                                      # 정렬 범위에 2개 이상의 원소가 있을 때만 실행
        pivot_idx = partition(arr, low, high)           # 파티션 수행 후 피벗의 최종 위치 반환
        quicksort_inplace(arr, low, pivot_idx - 1)      # 피벗 왼쪽 부분을 재귀적으로 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)     # 피벗 오른쪽 부분을 재귀적으로 정렬


def partition(arr, low, high):                          # 파티션: 피벗 기준으로 배열을 두 구간으로 분리
    pivot = arr[high]                                   # 마지막 원소를 피벗으로 선택
    i = low - 1                                         # i: 피벗보다 작은 구간의 끝 인덱스 (초기값은 범위 밖)

    for j in range(low, high):                          # j: low부터 high-1까지 순회하며 각 원소 검사
        if arr[j] <= pivot:                             # 현재 원소가 피벗 이하이면
            i += 1                                      # 작은 구간을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]            # 현재 원소를 작은 구간 끝으로 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]      # 피벗을 최종 위치로 이동
    return i + 1                                        # 피벗의 최종 인덱스 반환
```

---

두 방식의 차이:

| | 새 배열 방식 | 제자리 방식 |
|---|---|---|
| 메모리 | O(n) 추가 사용 | O(log n) — 재귀 스택만 |
| 코드 가독성 | 높음 | 낮음 |
| 실무 사용 | 학습/간단한 경우 | 성능이 중요한 경우 |
