파일 작성 권한이 없으니 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                      # 퀵소트 함수 정의, 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                    # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                           # 리스트 중간 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]                # 피벗보다 작은 원소를 모아 왼쪽 리스트 생성
    middle = [x for x in arr if x == pivot]             # 피벗과 같은 원소를 모아 중간 리스트 생성 (중복값 처리)
    right = [x for x in arr if x > pivot]               # 피벗보다 큰 원소를 모아 오른쪽 리스트 생성

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                               # 이 파일을 직접 실행할 때만 아래 코드 실행
    sample = [3, 6, 8, 10, 1, 2, 1]                     # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                             # 정렬 전 리스트 출력
    result = quicksort(sample)                           # 퀵소트 함수 호출
    print("정렬 후:", result)                             # 정렬 결과 출력
```

**동작 방식 요약:**

1. **피벗 선택** — 중간 인덱스 값을 기준으로 분할
2. **3-way 분할** — `left` / `middle` / `right` 로 나눠 중복값도 정확히 처리
3. **재귀 병합** — 왼쪽과 오른쪽을 재귀적으로 정렬한 뒤 이어 붙임

평균 시간복잡도 **O(n log n)**, 최악(이미 정렬된 경우) **O(n²)** 입니다.
