파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                          # 퀵소트 함수 정의, 리스트를 인자로 받음
    if len(arr) <= 1:                        # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 기저 조건)

    pivot = arr[len(arr) // 2]              # 중간 인덱스 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]   # 피벗보다 작은 요소들을 왼쪽 리스트로 분리
    middle = [x for x in arr if x == pivot] # 피벗과 같은 요소들을 중간 리스트로 분리
    right = [x for x in arr if x > pivot]  # 피벗보다 큰 요소들을 오른쪽 리스트로 분리

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽 재귀 정렬 후 합쳐서 반환


def quicksort_inplace(arr, low, high):       # 제자리(in-place) 퀵소트, 추가 메모리 없이 정렬
    if low < high:                           # 부분 배열의 범위가 유효할 때만 실행
        pivot_idx = partition(arr, low, high) # 분할 수행 후 피벗의 최종 위치 반환
        quicksort_inplace(arr, low, pivot_idx - 1)  # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high) # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):               # 피벗을 기준으로 배열을 두 부분으로 분할
    pivot = arr[high]                        # 마지막 요소를 피벗으로 선택
    i = low - 1                              # 피벗보다 작은 요소들의 경계 인덱스 초기화

    for j in range(low, high):              # low부터 high-1까지 순회
        if arr[j] <= pivot:                 # 현재 요소가 피벗 이하이면
            i += 1                          # 경계 인덱스를 오른쪽으로 한 칸 이동
            arr[i], arr[j] = arr[j], arr[i] # 경계 위치와 현재 위치의 요소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 피벗을 최종 위치(경계+1)로 이동
    return i + 1                            # 피벗의 최종 인덱스 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]           # 테스트용 정렬되지 않은 리스트
    print("원본:", data)                     # 정렬 전 출력

    result = quicksort(data)                 # 새 리스트 반환 방식으로 정렬
    print("퀵소트(반환):", result)           # 정렬 결과 출력

    data2 = [3, 6, 8, 10, 1, 2, 1]         # 제자리 정렬용 테스트 리스트
    quicksort_inplace(data2, 0, len(data2) - 1)  # 제자리 방식으로 정렬 (반환값 없음)
    print("퀵소트(제자리):", data2)          # 정렬된 원본 리스트 출력
```

두 가지 방식으로 구현했습니다.

**`quicksort` (새 리스트 반환 방식)**
- 피벗을 중간 요소로 선택
- left / middle / right 세 리스트로 분리 후 재귀 정렬
- 중복값도 안전하게 처리 (middle 리스트 덕분)

**`quicksort_inplace` + `partition` (제자리 정렬 방식)**
- 추가 메모리 없이 원본 배열 내에서 직접 정렬
- `partition`이 피벗을 올바른 위치에 놓고 인덱스를 반환
- 실무에서 더 많이 쓰이는 방식 (O(log n) 스택 공간만 사용)
