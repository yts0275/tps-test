프로젝트가 Python 기반이므로 Python으로 구현하겠습니다.

```python
def quicksort(arr):                                     # 퀵소트 함수 정의: 정렬할 리스트를 인자로 받음
    if len(arr) <= 1:                                   # 기저 조건: 리스트 길이가 1 이하면 이미 정렬된 상태
        return arr                                      # 그대로 반환 (재귀 종료)

    pivot = arr[len(arr) // 2]                          # 피벗 선택: 리스트 중간 원소를 피벗으로 사용
    left = [x for x in arr if x < pivot]               # 왼쪽 파티션: 피벗보다 작은 원소들 모음
    middle = [x for x in arr if x == pivot]            # 중간 파티션: 피벗과 같은 원소들 모음 (중복값 처리)
    right = [x for x in arr if x > pivot]              # 오른쪽 파티션: 피벗보다 큰 원소들 모음

    return quicksort(left) + middle + quicksort(right)  # 재귀 호출: 왼쪽/오른쪽을 각각 정렬 후 합쳐서 반환


# --- 테스트 ---
data = [3, 6, 8, 10, 1, 2, 1]                          # 정렬할 예시 리스트
print("정렬 전:", data)                                  # 정렬 전 출력
result = quicksort(data)                                # 퀵소트 실행
print("정렬 후:", result)                                # 정렬 후 출력
```

**출력 결과:**
```
정렬 전: [3, 6, 8, 10, 1, 2, 1]
정렬 후: [1, 1, 2, 3, 6, 8, 10]
```

**동작 원리:**
- **피벗 선택** → 리스트를 피벗 기준으로 left / middle / right 세 파티션으로 분할
- **재귀 호출** → left와 right를 각각 재귀적으로 퀵소트
- **합치기** → 정렬된 세 파티션을 순서대로 이어 붙임
- **시간 복잡도**: 평균 O(n log n), 최악 O(n²)
