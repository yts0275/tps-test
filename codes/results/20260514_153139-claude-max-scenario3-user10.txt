파일 쓰기 권한이 필요합니다. 권한을 승인하거나, 아래 코드를 직접 사용하세요.

```python
def quicksort(arr):                                  # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                   # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                       # 중앙 인덱스의 값을 피벗으로 선택
    left = [x for x in arr if x < pivot]             # 피벗보다 작은 원소들을 왼쪽 부분 배열로 수집
    middle = [x for x in arr if x == pivot]          # 피벗과 같은 원소들을 중간 배열로 수집 (중복 처리)
    right = [x for x in arr if x > pivot]            # 피벗보다 큰 원소들을 오른쪽 부분 배열로 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 + 중간 + 오른쪽 재귀를 합쳐 반환


def quicksort_inplace(arr, low, high):               # 제자리(in-place) 퀵소트 함수 정의
    if low < high:                                   # 정렬 범위가 2개 이상일 때만 실행
        pivot_idx = partition(arr, low, high)        # 파티션 함수로 피벗 위치 확정
        quicksort_inplace(arr, low, pivot_idx - 1)   # 피벗 왼쪽 부분 배열 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)  # 피벗 오른쪽 부분 배열 재귀 정렬


def partition(arr, low, high):                       # 파티션 함수: 피벗 기준으로 배열을 두 부분으로 나눔
    pivot = arr[high]                                # 맨 오른쪽 원소를 피벗으로 선택
    i = low - 1                                      # 피벗보다 작은 영역의 마지막 인덱스 (초기값: low-1)

    for j in range(low, high):                       # low부터 high-1까지 순회
        if arr[j] <= pivot:                          # 현재 원소가 피벗 이하이면
            i += 1                                   # 작은 영역을 한 칸 확장
            arr[i], arr[j] = arr[j], arr[i]          # 현재 원소를 작은 영역 끝으로 스왑

    arr[i + 1], arr[high] = arr[high], arr[i + 1]   # 피벗을 올바른 위치(작은 영역 바로 오른쪽)로 스왑
    return i + 1                                     # 피벗의 최종 인덱스 반환


if __name__ == "__main__":                           # 직접 실행 시에만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 입력 배열

    # --- 방식 1: 새 리스트 반환 방식 ---
    result = quicksort(data[:])                      # 원본 보존을 위해 복사본으로 정렬
    print("새 리스트 방식:", result)                  # 정렬 결과 출력

    # --- 방식 2: 제자리 정렬 방식 ---
    data2 = data[:]                                  # 원본 보존을 위해 복사본 생성
    quicksort_inplace(data2, 0, len(data2) - 1)      # 제자리 정렬 실행 (첫 인덱스=0, 마지막 인덱스=len-1)
    print("제자리 정렬 방식:", data2)                 # 정렬 결과 출력
```

두 가지 방식으로 구현했습니다.

**방식 1 - 새 리스트 반환 (`quicksort`)**: 코드가 직관적이고 짧으며, 피벗 기준으로 `left / middle / right`를 나눠 재귀 합산합니다. 중복 원소도 `middle`로 올바르게 처리합니다.

**방식 2 - 제자리 정렬 (`quicksort_inplace` + `partition`)**: 추가 메모리를 O(1)만 사용합니다. Lomuto 파티션 방식으로, `i` 포인터가 "피벗보다 작은 영역의 경계"를 관리하며 `j`가 스캔합니다.
