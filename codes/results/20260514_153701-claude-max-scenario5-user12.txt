파일 쓰기가 허용되지 않았으니 코드를 직접 보여드립니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr: 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right) # 왼쪽 재귀 정렬 + 피벗 + 오른쪽 재귀 정렬 결합 후 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 샘플 리스트 정의
    print("정렬 전:", sample)                           # 정렬 전 리스트 출력
    result = quicksort(sample)                         # 퀵소트 실행
    print("정렬 후:", result)                           # 정렬 후 리스트 출력
```

**동작 흐름:**

1. **피벗 선택** - 배열 중간값을 피벗으로 사용 (최악의 경우를 줄이기 위해 첫/마지막 대신 중간 선택)
2. **분할** - 피벗 기준으로 left / middle / right 세 그룹으로 나눔 (`middle`은 중복값 처리용)
3. **재귀** - left와 right를 각각 재귀 호출하여 정렬 후 합침

**시간 복잡도:** 평균 O(n log n), 최악 O(n²)  
**공간 복잡도:** O(n) (새 리스트 생성 방식이므로 in-place 아님)
