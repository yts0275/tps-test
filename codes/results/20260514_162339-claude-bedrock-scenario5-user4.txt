```python
def quicksort(arr):                                      # 퀵소트 함수 정의: 리스트를 입력받아 정렬된 리스트를 반환
    if len(arr) <= 1:                                    # 리스트 길이가 0 또는 1이면 이미 정렬된 상태
        return arr                                       # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]                          # 피벗: 리스트 중간 인덱스의 값을 기준으로 선택

    left = [x for x in arr if x < pivot]               # left: 피벗보다 작은 원소들만 모은 리스트
    middle = [x for x in arr if x == pivot]            # middle: 피벗과 같은 원소들만 모은 리스트 (중복값 처리)
    right = [x for x in arr if x > pivot]              # right: 피벗보다 큰 원소들만 모은 리스트

    return quicksort(left) + middle + quicksort(right) # left와 right를 재귀 정렬 후 middle과 합쳐서 반환


# --- 실행 예시 ---

data = [3, 6, 8, 10, 1, 2, 1]                          # 정렬할 예시 리스트 정의
print("정렬 전:", data)                                  # 정렬 전 리스트 출력

sorted_data = quicksort(data)                           # quicksort 함수 호출하여 정렬 수행
print("정렬 후:", sorted_data)                          # 정렬 후 결과 출력
```

**동작 설명:**

| 단계 | 설명 |
|------|------|
| 피벗 선택 | 중간 인덱스 값을 피벗으로 사용 |
| 분할 | 피벗 기준으로 left / middle / right 세 그룹으로 나눔 |
| 재귀 | left, right를 각각 재귀 호출로 정렬 |
| 합치기 | `quicksort(left) + middle + quicksort(right)` 순서로 병합 |

`middle` 리스트로 피벗과 같은 값을 별도로 모으기 때문에 중복값도 안전하게 처리됩니다. 파일로 저장을 원하시면 말씀해 주세요.
