```python
def quicksort(arr):                              # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                            # 원소가 0개 또는 1개이면 더 이상 분할 불필요
        return arr                               # 그대로 반환 (기저 조건)

    pivot = arr[len(arr) // 2]                   # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]        # 피벗보다 작은 원소들을 왼쪽 파티션으로 모음
    middle = [x for x in arr if x == pivot]     # 피벗과 같은 원소들을 중간 파티션으로 모음
    right = [x for x in arr if x > pivot]       # 피벗보다 큰 원소들을 오른쪽 파티션으로 모음

    return quicksort(left) + middle + quicksort(right)  # 왼쪽/오른쪽을 재귀 정렬 후 합쳐서 반환


if __name__ == "__main__":                       # 이 파일을 직접 실행할 때만 아래 코드 동작
    sample = [3, 6, 8, 10, 1, 2, 1]             # 테스트용 입력 리스트 정의
    print("정렬 전:", sample)                     # 정렬 전 리스트 출력
    result = quicksort(sample)                   # 퀵소트 함수 호출
    print("정렬 후:", result)                     # 정렬 결과 출력
```

**동작 원리:**

1. **피벗 선택** — 리스트 중간값을 피벗으로 선택
2. **파티션** — 피벗 기준으로 작은/같은/큰 세 그룹으로 분할
3. **재귀** — 왼쪽·오른쪽 파티션에 동일하게 적용
4. **병합** — `left + middle + right` 순으로 합침

정렬 후: [1, 1, 2, 3, 6, 8, 10]
