파일 생성 권한이 없어서 코드를 직접 출력합니다.

```python
def quicksort(arr):                                    # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                                  # 원소가 1개 이하면 이미 정렬된 상태
        return arr                                     # 그대로 반환 (재귀의 기저 조건)

    pivot = arr[len(arr) // 2]                         # 중간 인덱스 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]               # 피벗보다 작은 원소들을 왼쪽 리스트에 수집
    middle = [x for x in arr if x == pivot]            # 피벗과 같은 원소들을 중간 리스트에 수집 (중복 처리)
    right = [x for x in arr if x > pivot]              # 피벗보다 큰 원소들을 오른쪽 리스트에 수집

    return quicksort(left) + middle + quicksort(right) # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐서 반환


def quicksort_inplace(arr, low, high):                 # 제자리(in-place) 퀵소트, low~high 범위를 정렬
    if low < high:                                     # 범위에 원소가 2개 이상일 때만 진행
        pivot_idx = partition(arr, low, high)          # 파티션 수행 후 피벗의 최종 위치를 받음
        quicksort_inplace(arr, low, pivot_idx - 1)     # 피벗 왼쪽 부분 재귀 정렬
        quicksort_inplace(arr, pivot_idx + 1, high)    # 피벗 오른쪽 부분 재귀 정렬


def partition(arr, low, high):                         # 파티션 함수: 피벗 기준으로 배열을 두 부분으로 나눔
    pivot = arr[high]                                  # 맨 오른쪽 원소를 피벗으로 선택
    i = low - 1                                        # i는 피벗보다 작은 원소들의 경계 (초기값: 범위 시작 전)

    for j in range(low, high):                         # j로 low부터 high-1까지 순회
        if arr[j] <= pivot:                            # 현재 원소가 피벗 이하이면
            i += 1                                     # 경계를 한 칸 오른쪽으로 이동
            arr[i], arr[j] = arr[j], arr[i]            # 경계 원소와 현재 원소를 교환

    arr[i + 1], arr[high] = arr[high], arr[i + 1]      # 피벗을 경계 바로 오른쪽(최종 위치)으로 이동
    return i + 1                                       # 피벗의 최종 인덱스 반환


if __name__ == "__main__":
    sample = [3, 6, 8, 10, 1, 2, 1]                   # 테스트용 샘플 리스트

    result = quicksort(sample)                         # 새 리스트를 반환하는 방식으로 정렬
    print("새 리스트 방식:", result)                    # 결과 출력

    sample2 = [3, 6, 8, 10, 1, 2, 1]                  # 제자리 정렬 테스트용 리스트
    quicksort_inplace(sample2, 0, len(sample2) - 1)    # 원본 리스트를 직접 수정하는 방식으로 정렬
    print("제자리 방식:   ", sample2)                  # 결과 출력
```

두 가지 방식을 구현했습니다.

| 방식 | 함수 | 특징 |
|------|------|------|
| 새 리스트 반환 | `quicksort()` | 코드가 간결, 메모리 추가 사용 |
| 제자리 정렬 | `quicksort_inplace()` | 메모리 효율적, 원본 배열 직접 수정 |

실행하면 `[1, 1, 2, 3, 6, 8, 10]`이 출력됩니다.
