파일 쓰기 권한이 없어서 코드를 직접 보여드립니다:

```python
def quicksort(arr):                          # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                        # 원소가 0개 또는 1개이면 이미 정렬된 상태
        return arr                           # 그대로 반환 (재귀 종료 조건)

    pivot = arr[len(arr) // 2]               # 중간 인덱스의 원소를 피벗으로 선택
    left = [x for x in arr if x < pivot]    # 피벗보다 작은 원소를 left 리스트에 수집
    middle = [x for x in arr if x == pivot] # 피벗과 같은 원소를 middle 리스트에 수집
    right = [x for x in arr if x > pivot]   # 피벗보다 큰 원소를 right 리스트에 수집

    return quicksort(left) + middle + quicksort(right)  # 왼쪽 재귀 + 피벗 + 오른쪽 재귀 결합


if __name__ == "__main__":                   # 스크립트 직접 실행 시에만 아래 코드 동작
    data = [3, 6, 8, 10, 1, 2, 1]           # 정렬할 예시 리스트 정의
    print("정렬 전:", data)                   # 정렬 전 리스트 출력
    sorted_data = quicksort(data)            # 퀵소트 호출하여 결과 저장
    print("정렬 후:", sorted_data)            # 정렬 후 결과 출력
```

**동작 방식:**
1. **피벗 선택** — 배열 중간 원소를 피벗으로 사용
2. **분할** — 피벗보다 작은/같은/큰 원소로 세 그룹 분리
3. **재귀** — 왼쪽과 오른쪽을 각각 재귀 정렬 후 합침

실행 결과: `정렬 전: [3, 6, 8, 10, 1, 2, 1]` → `정렬 후: [1, 1, 2, 3, 6, 8, 10]`
