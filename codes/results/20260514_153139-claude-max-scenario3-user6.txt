파일 쓰기 권한이 없어서 코드를 직접 보여드리겠습니다.

```python
def quicksort(arr):                                # 퀵소트 함수 정의, arr은 정렬할 리스트
    if len(arr) <= 1:                              # 원소가 0개 또는 1개면 이미 정렬된 상태
        return arr                                 # 그대로 반환 (재귀 탈출 조건)

    pivot = arr[len(arr) // 2]                     # 중간 인덱스의 값을 피벗으로 선택

    left = [x for x in arr if x < pivot]           # 피벗보다 작은 원소들을 왼쪽 리스트로
    middle = [x for x in arr if x == pivot]        # 피벗과 같은 원소들을 중간 리스트로
    right = [x for x in arr if x > pivot]          # 피벗보다 큰 원소들을 오른쪽 리스트로

    return quicksort(left) + middle + quicksort(right)  # 왼쪽·중간·오른쪽을 재귀 정렬 후 합쳐 반환


if __name__ == "__main__":
    data = [3, 6, 8, 10, 1, 2, 1]                 # 정렬할 예시 리스트
    print("정렬 전:", data)                         # 정렬 전 출력
    sorted_data = quicksort(data)                  # 퀵소트 실행
    print("정렬 후:", sorted_data)                  # 정렬 후 출력
```

**핵심 동작 흐름:**

1. **탈출 조건** — 원소가 1개 이하면 즉시 반환
2. **피벗 선택** — 배열 중간값을 피벗으로 사용 (최악 케이스 확률 감소)
3. **분할** — 피벗 기준으로 left / middle / right 세 그룹으로 나눔
4. **재귀** — left와 right를 재귀 호출로 정렬 후 합산

`middle` 리스트를 별도로 두어 **중복 값도 올바르게 처리**합니다. 평균 시간 복잡도는 **O(n log n)** 입니다.
